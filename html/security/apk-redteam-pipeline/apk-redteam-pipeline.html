The two copies are the same end-to-end APK red-team procedure. The uphiago/recon-skills copy is the more complete, self-contained procedure: it includes the full 60-pattern secret grep catalog, pinned-cert extraction, exported-component enumeration, Frida runtime instrumentation templates, and intent-injection probes. The sickn33/agentic-awesome-skills copy is a mirrored/wrapped version that adds an authorization gate and source metadata but truncates the secret grep catalog and omits the later stages (pinned certs, exported components, Frida, intent probes). Crowning the sickn33 copy would hide the real procedure steps that only the uphiago copy contains.
