# ppt-creator

## Status Check
Before executing any PPT task, determine which variant of this skill is installed:

1. **If the daymade/claude-code-skills variant is present**: This skill is DEPRECATED as of 2026-08-07. Do not execute any PPT generation steps. Inform the user that this skill is frozen and, if they have access to the private daymade-skills-pro repository, direct them to use deck-creator (Route B · draft) instead. For external users, note that this is the final public version and no further updates will be provided.

2. **If the LeoYeAI/openclaw-master-skills variant is present**: Proceed with the operational workflow below.

## Operational Workflow (LeoYeAI variant only)

### 1. PPT Creation
- **From text**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js create_from_text --text "<topic>" --font_name "<font>" --color "<color>" --language "<lang>" --report "<true/false>"`
- **From custom outline**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js create_from_custom_outline --custom_data '<JSON>' --font_name "<font>" --color "<color>" --report "<true/false>"`
- **From file**: Read the file, convert to JSON outline, present to user for confirmation, then call create_from_custom_outline.
- **From file with review**: Use the two-phase create_from_file_with_review workflow. User confirmation of the outline is mandatory before generation.
- **From project analysis**: Use create_from_project_analysis to scan the project and generate a summary PPT.

### 2. Modification
- **Add speaker notes**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js add_notes --task_id "<ID>" --report "<true/false>"`
- **Insert page**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js insert_page --task_id "<ID>" --slide_number "<n>" --slide_type "<type>" --text "<content>" --report "<true/false>"`
- **Regenerate with new style**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js regenerate --task_id "<ID>" --font_name "<font>" --color "<color>" --cover_id "<template>" --transition "<1/2>" --report "<true/false>"`

### 3. Template & Preview
- **Preview covers**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js preview_covers --title "<title>" --style "<style>" --color "<color>" --count 4`
- **Check task status**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js check_status --task_id "<ID>"`

### 4. Image-Based PPT (Banana Style)
- **List styles**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js list_banana_styles --type "<style/template>"`
- **Create**: `node {{SKILL_PATH}}/scripts/chatppt_creator.js create_banana_ppt --text "<topic>" --style "<styleID>" --complex "<1/2/3>"`
- Must inform user that image-based PPTs are not text-editable before proceeding.
- Must proactively report the file path when the task completes.

### 5. Style Knowledge Base
Use the built-in style table to recommend style IDs based on user descriptions (e.g., "cute", "business", "minimal").
