# PPTX Posters

## Scope
Use this skill when the requested deliverable is a PowerPoint research/conference poster or slide deck. Do not use it for original research writing, figure fabrication, or unspecified poster requests.

## Choose a Workflow
Select one of the following workflows based on the user's explicit request and available assets:

### Workflow A: Strict Local .pptx (Manifest-Driven)
Use when exact physical, printer, accessibility, provenance, and package-security checks are required.
1. Confirm the author has supplied exact poster content and source records.
2. Confirm conference and printer requirements.
3. Install exact dependencies: `python-pptx==1.0.2`, `Pillow==12.3.0`, `lxml==6.1.3`.
4. Build a JSON manifest from the template, resolving all tokens and approvals.
5. Validate the manifest and local assets using the provided scripts.
6. Generate the .pptx file locally.
7. Perform manual author review and printer checks.

### Workflow B: HTML/CSS Poster (AI-Visuals)
Use when the user requests an HTML-based poster or needs quick iteration with AI-generated visuals.
1. Plan visual elements (hero, methods, results, conclusions).
2. Generate visuals using AI tools, ensuring poster-readable font sizes (80pt+ labels, 120pt+ numbers) and high contrast.
3. Assemble visuals into the HTML template.
4. Add text content, keeping total word count between 300-800 words.
5. Export to PDF via browser print or convert to PPTX.

### Workflow C: Script-Based Converter
Use when converting a paper abstract or PDF into a structured poster or slide deck.
1. Validate the input source (abstract text or PDF).
2. Extract and structure content into layout sections.
3. Run the conversion script with the desired format and template.
4. Review the output for layout and citation accuracy.

## Common Constraints
- Do not fabricate missing material, figures, or citations.
- Ensure all text is readable at poster viewing distances.
- Verify final output against conference and printer requirements.
- If inputs are incomplete, request only the minimum additional information needed.
