# Comprehensive SEO Skill

This skill combines strategic planning, technical execution, and audit orchestration.

## 1. Strategic Planning & Prioritization

**Workflow Order:**
1. **Technical**: Fix crawlability, indexing, and sitemaps first.
2. **On-Page**: Optimize metadata, structure, and schema.
3. **Content**: Develop keyword clusters and optimize content.
4. **Off-Page**: Build backlinks and authority.

**Priorities:**
- **P0 (Blocker)**: Crawlability, indexing, robots blocking.
- **P1 (Core)**: Title, meta, schema, sitemap, internal links.
- **P2 (Important)**: Open Graph, Twitter Cards, IndexNow.
- **P3 (Nice to have)**: Rich results, sitelinks.

**Product-Led SEO:**
- Leverage existing product content (features, use cases).
- Do SEO around product/users, not just industry keywords.

## 2. Technical Execution & Code Standards

**Crawlability:**
- **robots.txt**: Allow `/`, Disallow `/admin/`, `/api/`. Include `Sitemap:` directive.
- **Meta Robots**: Use `index, follow` by default. Use `noindex` for private pages.
- **Canonicals**: Use self-referencing canonicals to prevent duplicate content.

**Sitemaps:**
- Max 50,000 URLs or 50MB per file.
- Include only canonical, indexable URLs.
- Update `lastmod` accurately.

**On-Page:**
- **Title Tags**: 50-60 chars (linting proxy). Unique per page. Keyword near start.
- **Meta Descriptions**: 150-160 chars (linting proxy). Compelling and unique.
- **URLs**: Lowercase, hyphens, <75 chars, no parameters if possible.

## 3. Audit Orchestration & Quality Gates

**Orchestration Logic:**
1. Detect business type (SaaS, Local, E-commerce, etc.).
2. Delegate to subagents: technical, content, schema, sitemap, performance, visual, geo.
3. Generate unified report with SEO Health Score (0-100).
4. Create prioritized action plan (Critical -> High -> Medium -> Low).

**Quality Gates & Constraints:**
- **FAQ Schema**: Only for government/healthcare sites for Google rich results. Flag as Info for commercial sites (AI benefit only).
- **HowTo Schema**: Do not recommend (deprecated).
- **Core Web Vitals**: Use INP (Interaction to Next Paint), never FID.
- **Thin Content**: Warning at 30+ location pages; Hard Stop at 50+ without justification.

**Scoring Weights:**
- Technical: 22%
- Content: 23%
- On-Page: 20%
- Schema: 10%
- Performance: 10%
- AI Search: 10%
- Images: 5%
