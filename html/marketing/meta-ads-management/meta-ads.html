# Meta Ads Management

## Workflow Selection
1. **Check for External Workflow**: If operating within the `nowork-studio/notfair-plugin` environment, read `<plugin-root>/meta-ads/manage/WORKFLOW.md` completely. If this file is missing, stop and report a packaging error. Do not substitute other skills.
2. **Inline Guidance**: If no external workflow is available or if the user requests general guidance, follow the steps below.

## Campaign Structure & Setup
- **Hierarchy**: Campaign → Ad Set → Ad.
- **Principle**: One objective per campaign. Consolidate by objective to help the algorithm learn.
- **Naming**: Use `META_[Objective]_[Audience]_[Offer]_[Date]`.
- **Objectives**: Select Awareness, Traffic, Conversions, or Engagement based on the goal.

## Audience & Targeting
- **Lookalikes**: Base on high-LTV customers, not all customers.
- **Advantage+**: Use for automated audience discovery and broad targeting.
- **Exclusions**: Always exclude existing customers and recent converters (7–14 days).

## Creative Best Practices
- **Image**: Clear product, human faces, text <20% of image.
- **Video**: 15–30s duration. Hook (0–3s), Problem (3–8s), Solution (8–20s), CTA (20–30s).
- **Volume**: Test 3–5 ad variants per ad set.

## Optimization & Performance
- **Learning Phase**: Aim for 50+ conversions per ad set per week. Avoid changes during this phase.
- **Budgets**: Use CBO (Campaign Budget Optimization) for scaling; ABO for specific ad set control.
- **Frequency**: Keep below 3 to avoid fatigue.
- **Metrics**: Monitor ROAS, CPM, CTR, and audience overlap.

## Pre-Launch Checklist
- [ ] Meta Pixel and Conversions API configured.
- [ ] Conversion events firing correctly.
- [ ] Landing page is mobile-friendly and fast.
- [ ] 3+ creatives ready per ad set.
- [ ] Audience exclusions applied.
