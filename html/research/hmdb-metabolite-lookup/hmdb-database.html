# HMDB Database

## When to Use
- You need to look up a metabolite by common name, synonym, or HMDB ID.
- You need to extract standardized chemical, biological, clinical, or spectral fields for downstream analysis.
- You want to build a local, scriptable pipeline to mine HMDB data instead of manually browsing the website.
- You need to map HMDB identifiers to external resources such as KEGG, PubChem, ChEBI, MetaCyc, PDB, UniProt, or GenBank.
- You are preparing metabolomics datasets and need pathway, enzyme, transporter, or concentration annotations.

## Access Options

### 1. Web Interface
- Use https://www.hmdb.ca/ for interactive searches.
- Text searches: metabolite name, synonym, HMDB ID, disease association, pathway involvement, or specimen type.
- Structure searches: use ChemQuery for structure/substructure, molecular weight, SMILES, or InChI.
- Spectral searches: LC-MS, GC-MS, or NMR spectral matching for metabolite identification.
- Advanced searches: combine multiple criteria and filter by biological location or specimen type.

### 2. Downloadable Datasets
- Download bulk data from https://www.hmdb.ca/downloads.
- Available formats include XML, SDF, FASTA, TXT, and CSV/TSV.
- Use XML for comprehensive field extraction.
- Use SDF for structure-based cheminformatics workflows.
- Use CSV/TSV for tabular analysis pipelines.
- Check the dataset version date before use.
- Free for academic and non-commercial research; commercial use requires explicit permission.
- Cite the HMDB publication when using the data.

### 3. Programmatic Access
- HMDB does not provide a public REST API.
- For API access, contact the HMDB development team.
- For R-based queries, use the Bioconductor hmdbQuery package.
- For local Python pipelines, parse downloaded XML or CSV files.

## Local Python XML Pipeline

### Dependencies
- Python >= 3.9
- Standard library xml.etree.ElementTree
- Optional: pandas >= 1.5 for tabular outputs

### Steps
1. Download the HMDB metabolite XML dataset from https://www.hmdb.ca/downloads.
2. Save the file locally, for example as data/hmdb_metabolites.xml.
3. Use a parser such as HMDBParser to load the XML file.
4. Search by metabolite name, synonym, or HMDB ID.
5. Extract chemical fields such as formula, molecular weight, InChI, and SMILES where available.
6. Extract biological fields such as pathways, enzymes, transporters, and subcellular locations.
7. Extract clinical fields such as disease associations, biomarker information, and biofluid concentration ranges.
8. Extract external identifiers for cross-database mapping.
9. Optionally structure results into tabular outputs for downstream analysis.

### Example
```python
from scripts.hmdb_parser import HMDBParser

def main():
    xml_path = "data/hmdb_metabolites.xml"
    parser = HMDBParser(xml_path)
    results = parser.search("Caffeine")
    if not results:
        print("No results found.")
        return
    first = results[0]
    print("Top match:")
    print(first)

if __name__ == "__main__":
    main()
```

## Common Research Workflows

### Metabolite Identification in Untargeted Metabolomics
1. Obtain experimental MS or NMR spectra from samples.
2. Use HMDB spectral search tools to match against reference spectra.
3. Verify candidates by checking molecular weight, retention time, and MS-MS fragmentation.
4. Review biological plausibility, including expected specimen type and known pathways.

### Biomarker Discovery
1. Search HMDB for metabolites associated with the disease of interest.
2. Review concentration ranges in normal versus disease states.
3. Identify metabolites with strong differential abundance.
4. Examine pathway context and biological mechanisms.
5. Cross-reference with literature via PubMed links.

### Pathway Analysis
1. Identify metabolites of interest from experimental data.
2. Look up HMDB entries for each metabolite.
3. Extract pathway associations and enzymatic reactions.
4. Use linked pathway resources for pathway diagrams.
5. Identify pathway enrichment for biological interpretation.

### Database Integration
1. Download HMDB data in XML or CSV format.
2. Parse and extract relevant fields for a local database.
3. Link with external IDs such as KEGG, PubChem, and ChEBI for cross-database queries.
4. Build local tools or pipelines incorporating HMDB references.
