# Write

This skill handles two distinct workflows based on context:

## 1. Authoring Agent Skills
Use this when creating or revising `SKILL.md` files.
- **Trigger:** The frontmatter `description` must clearly state what the skill does and when to use it.
- **Token Economy:** Keep the main file short. Use `references/` for long docs and `scripts/` for fragile operations.
- **Procedures:** Write imperative rules and decision points, not essays. Match the procedure to the deliverable's shape.
- **Validation:** Test the skill on a fresh agent run to ensure predictability.

## 2. Drafting Academic Papers
Use this when drafting sections of a research paper.
- **Context:** Read existing drafts, notes, and bibliography before writing.
- **Routing:** Select the section (intro, strategy, results, conclusion, abstract) based on user input.
- **Standards:**
  - Introduction: 1000-1500 words, hook to roadmap.
  - Results: 800-1500 words, effect sizes with units.
  - Abstract: 100-150 words, question to implication.
- **LaTeX Conventions:** Use `\citet{}` for textual and `\citep{}` for parenthetical citations. Use `booktabs` for tables.
- **Quality Check:** Ensure all equations are labeled, citations exist in the bibliography, and no banned hedging phrases are used.
- **Humanizer:** Apply a pass to strip AI-specific patterns (e.g., 'delve', 'leverage', rule-of-three) before finalizing.
