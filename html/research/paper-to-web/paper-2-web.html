# Paper2All: Academic Paper Transformation Pipeline

## Overview

This skill enables the transformation of academic papers into multiple promotional and presentation formats using the Paper2All autonomous pipeline. The system converts research papers (LaTeX or PDF) into three primary outputs:

1. **Paper2Web**: Interactive, explorable academic homepages with layout-aware design
2. **Paper2Video**: Professional presentation videos with narration, slides, and optional talking-head
3. **Paper2Poster**: Print-ready conference posters with professional layouts

## When to Use This Skill

Use this skill when:
- Creating conference materials (posters, videos, websites).
- Promoting research or preprints.
- Generating video abstracts or presentation videos.
- Creating promotional materials for social media or lab websites.

## Boundary

This skill owns the transformation of an existing paper into dissemination assets. It reuses provided figures and paper assets. 

**Conflicts**: 
- `foryourhealth111-pixel/Vibe-Skills` states this skill does **not** generate new scientific diagrams.
- `FreedomIntelligence/OpenClaw-Medical-Skills` and `aipoch/medical-research-skills` instruct to **always** consider adding scientific diagrams using the `scientific-schematics` skill.

## Core Capabilities

### 1. Paper2Web
Converts papers into layout-aware, interactive academic homepages.
- Responsive, multi-section layouts.
- Interactive figures, tables, and citations.
- Automatic logo discovery.

### 2. Paper2Video
Generates professional presentation videos.
- Automated slide generation.
- Speech synthesis and synchronized cursor movements.
- Optional talking-head video (requires GPU).

### 3. Paper2Poster
Creates print-ready academic posters.
- Custom dimensions and professional templates.
- QR code generation.
- High-resolution output (300+ DPI).

## Quick Start

### Prerequisites

1. **Install Paper2All**:
   ```bash
   git clone https://github.com/YuhangChen1/Paper2All.git
   cd Paper2All
   conda create -n paper2all python=3.11
   conda activate paper2all
   pip install -r requirements.txt
   ```

2. **Configure API Keys** (create `.env` file):
   ```
   OPENAI_API_KEY=your_openai_api_key_here
   # Optional: GOOGLE_API_KEY and GOOGLE_CSE_ID for logo search
   ```

3. **Install System Dependencies**:
   - LibreOffice
   - Poppler utilities
   - NVIDIA GPU (optional, for talking-head videos)

### Basic Usage

**Generate All Components**:
```bash
python pipeline_all.py \
  --input-dir "path/to/paper" \
  --output-dir "path/to/output" \
  --model-choice 1
```

**Generate Website Only**:
```bash
python pipeline_all.py \
  --input-dir "path/to/paper" \
  --output-dir "path/to/output" \
  --model-choice 1 \
  --generate-website
```

**Generate Video**:
```bash
python pipeline_light.py \
  --model_name_t gpt-4.1 \
  --model_name_v gpt-4.1 \
  --result_dir "path/to/output" \
  --paper_latex_root "path/to/paper"
```

## Visual Enhancement (Optional/Conflicting)

If following the `FreedomIntelligence` or `aipoch` variants, consider adding scientific diagrams:
- Use the **scientific-schematics** skill to generate AI-driven publication-grade figures.
- Describe the diagram in natural language.
- Run: `python scripts/generate_schematic.py "your diagram description" -o figures/output.png`

If following the `Vibe-Skills` variant, do **not** generate new diagrams; reuse existing paper assets only.
