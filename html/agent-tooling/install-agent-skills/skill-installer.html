# Skill Installer

Install, validate, and register skills into the local skills directory. Use the appropriate procedure based on the environment and user request.

## Codex / GitHub Installer

Use when the user asks to list, install, or install from a GitHub repo.

1. List skills with `scripts/list-skills.py` (or `scripts/list-curated-skills.py` in composio-community). Pass `--path skills/.experimental` for experimental skills.
2. Install from the curated list or a GitHub repo with `scripts/install-skill-from-github.py --repo <owner>/<repo> --path <path/to/skill>` or `--url <github-url>`.
3. Install into `$CODEX_HOME/skills/<skill-name>` (defaults to `~/.codex/skills`).
4. If download fails with auth/permission errors, fall back to git sparse checkout (HTTPS first, then SSH).
5. Abort if the destination skill directory already exists.
6. After installing, tell the user the skill will be available on the next turn or to restart Codex.

## Enterprise / Local Installer

Use when the user asks to install, validate, register, or verify a skill in the local ecosystem.

1. Detect skills with `scripts/detect_skills.py` or `install_skill.py --detect`.
2. Validate the skill with `scripts/validate_skill.py` (10 checks).
3. Install with `scripts/install_skill.py --source <path>` (11 steps). Use `--dry-run` to simulate, `--force` to overwrite, and `--name` to override the skill name.
4. Register the skill in the registry and verify with `scripts/scan_registry.py`.
5. Package the skill with `scripts/package_skill.py` (ZIP integrity check).
6. Use `--health` to check all skills and `--health --repair` to auto-fix issues.
7. Use `--rollback <skill-name>` to restore from backup, `--uninstall <skill-name>` to remove, and `--reinstall-all` to re-register all skills.
8. Use `--status` for a dashboard and `--log` for operation history.

## Conflicts

- sickn33/agentic-awesome-skills uses a 6-layer validation pipeline, registry, backups, rollback, and health checks, while openai/skills, foryourhealth111-pixel/Vibe-Skills, and composio-community/awesome-codex-skills use a simpler GitHub-based installer without these features.
- sickn33/agentic-awesome-skills is written in Portuguese and targets a Windows path, while the other copies are in English and target $CODEX_HOME/skills.
