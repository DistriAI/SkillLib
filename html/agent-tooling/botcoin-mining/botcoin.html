# Botcoin (Disambiguation)

This skill name maps to two distinct systems. Determine which one the user intends before proceeding.

## Option A: BankrBot BOTCOIN Miner
- **Base URL:** `https://coordinator.agentmoney.net`
- **Auth:** `BANKR_API_KEY` env var.
- **Token:** `0xA601877977340862Ca67f816eb079958E5bd0BA3` (BOTCOIN on Base).
- **Mechanism:** Stake-gated mining. Requires 25M+ BOTCOIN staked on `0xcF5F2D541EEb0fb4cA35F1973DE5f2B02dfC3716`.
- **Steps:**
  1. Authenticate via `curl https://api.bankr.bot/agent/me`.
  2. Check balances via Bankr prompt API.
  3. Stake BOTCOIN if below threshold.
  4. Fetch challenge from coordinator.
  5. Solve and submit receipt.

## Option B: Botfarmer.ai Puzzle Game
- **Base URL:** `https://botfarmer.ai`
- **Auth:** Ed25519 keypair (local generation).
- **Token:** `0x139bd7654573256735457147C6F1BdCb3Ac0DA17` ($BOTFARM on Base).
- **Mechanism:** Puzzle solving with X/Twitter verification and hold-to-play.
- **Steps:**
  1. Generate Ed25519 keypair locally.
  2. Register wallet via API (requires X verification).
  3. Link EVM address for withdrawals.
  4. Pick and solve hunts.
  5. Claim on-chain (throttled to 1/30 days).
