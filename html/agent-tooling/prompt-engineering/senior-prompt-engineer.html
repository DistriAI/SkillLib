# Senior Prompt Engineer

This skill covers prompt engineering patterns, LLM evaluation, and agentic system design for production-grade AI systems.

## Quick Start

### 1. Prompt Optimization
Analyze prompts for token efficiency, clarity, and structure.

```bash
# Analyze a prompt file
python scripts/prompt_optimizer.py prompt.txt --analyze

# Generate an optimized version
python scripts/prompt_optimizer.py prompt.txt --optimize --output optimized.txt

# Count tokens for cost estimation
python scripts/prompt_optimizer.py prompt.txt --tokens --model gpt-4
```

**Key Metrics:**
- Token count and estimated cost
- Clarity score (0-100)
- Redundancy detection

### 2. RAG Evaluation
Evaluate Retrieval-Augmented Generation quality.

```bash
# Evaluate retrieval and generation quality
python scripts/rag_evaluator.py --contexts retrieved.json --questions eval_set.json

# Export detailed results
python scripts/rag_evaluator.py --contexts retrieved.json --questions eval_set.json --output report.json --verbose
```

**Key Metrics:**
- Context Relevance (target: >0.80)
- Answer Faithfulness
- Retrieval Precision@5

### 3. Agent Orchestration
Validate and visualize agent workflows.

```bash
# Validate agent configuration
python scripts/agent_orchestrator.py agent.yaml --validate

# Visualize workflow (ASCII or Mermaid)
python scripts/agent_orchestrator.py agent.yaml --visualize
```

**Validation Checks:**
- Tool configuration (API keys, permissions)
- Flow depth and potential infinite loops
- Token estimation per run
