# Anatomy Quiz Master

## When to Use
- Medical students preparing for anatomy practical exams or USMLE Step 1 anatomy questions.
- Self-assessment after lectures or dissections.
- Identifying weak anatomical regions for focused study.
- Creating practice questions for study groups or remediation.
- Teaching assistants generating quiz materials for labs.

## Do NOT Use When
- As the primary learning resource (use textbooks/atlas first).
- As a substitute for cadaver lab attendance.
- For pathology or physiology questions (use specialized skills).
- For board exam registration or scheduling (use official NBME resources).

## Integration
- Upstream: usmle-case-generator, anki-card-creator.
- Downstream: study-limitations-drafter, performance-tracker.

## Core Capabilities

### 1. Regional Anatomy Quizzes
Generate focused quizzes by body region (head/neck, thorax, abdomen, pelvis, upper limb, lower limb, back) with subtopics and question types as documented in the skill references.

```python
from scripts.quiz_generator import QuizGenerator
generator = QuizGenerator()
quiz = generator.generate_quiz(
    region="thorax",
    topics=["heart", "lungs", "mediastinum", "thoracic_wall"],
    difficulty="intermediate",
    n_questions=20
)
quiz.export(format="json", filename="thorax_quiz.json")
```

### 2. Neuroanatomy Pathway Tracing
Generate quizzes for motor, sensory, cranial nerve, reflex, and vascular pathways.

```python
neuro_quiz = generator.generate_neuro_quiz(
    pathway_type="motor",
    include_lesions=True,
    clinical_correlations=True
)
```

### 3. Clinical Correlation Questions
Integrate anatomy with clinical scenarios (surgery, radiology, physical exam).

```python
clinical_quiz = generator.generate_clinical_quiz(
    region="abdomen",
    scenario_types=["surgery", "radiology", "physical_exam"],
    difficulty="advanced"
)
```

### 4. Adaptive Learning System
Track performance and generate personalized quizzes targeting weak areas.

```python
from scripts.adaptive import AdaptiveEngine
engine = AdaptiveEngine()
student_progress = engine.track_performance(
    student_id="student_001",
    quiz_results=results,
    time_per_question=True
)
personalized = engine.generate_adaptive_quiz(
    student_progress=student_progress,
    focus_areas=["thorax_vessels", "cranial_nerves"],
    mastery_threshold=0.80
)
```

## Common Patterns

### Pre-Exam Comprehensive Review
```bash
python scripts/main.py \
  --mode comprehensive \
  --regions all \
  --difficulty intermediate \
  --n-questions 100 \
  --timed \
  --output pre_practice_exam.json
```

### Adaptive Focus on Weak Areas
```bash
python scripts/main.py \
  --mode adaptive \
  --focus abdomen,pelvis \
  --difficulty advanced \
  --n-questions 30 \
  --output adaptive_review.json
```
