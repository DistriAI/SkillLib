# Skill: lex (Catalog Mismatch)

This catalog entry contains two unrelated skills that share the folder name 'lex'.

## Option A: LEX Legal Truth Engine

Use when the task involves cross-jurisdictional legal context (US, EU, CA) or contract scaffolding.

### Steps
1. Identify the target jurisdiction (USA, Canada, or EU).
2. Run `lex search <query>` to find matching legal templates.
3. Run `lex get <path>` to read granular metadata and requirements.
4. Run `lex draft <description>` to generate a foundation-level document scaffold.
5. Run `lex verify` to fetch official government links and include a "Verified Sources" section in the output.
6. Use tables when comparing results across multiple jurisdictions.
7. If the jurisdiction is outside US/EU/CA scope, state that it is outside LEX coverage.

## Option B: Warden Agent Builder

Use when the task involves building or deploying LangGraph-based agents for the Warden Protocol.

### Steps
1. Study the example agents in the Warden community repository to learn patterns; do not recreate them.
2. Identify a unique use case that differs from existing example agents.
3. Initialize a new agent project using `python scripts/init-agent.py <name> --template <typescript|python> --description "..."`.
4. Implement the agent's LangGraph workflow, tools, and configuration.
5. Deploy via LangSmith Deployments or custom infrastructure.
6. Ensure the agent is API-accessible and isolated (one agent per LangGraph instance).
