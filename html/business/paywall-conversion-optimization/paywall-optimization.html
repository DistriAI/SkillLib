# Paywall Optimization

## 1. Initial Assessment
1. Check for `app-marketing-context.md` if available.
2. Ask for the **App ID** and **paywall framework** (RevenueCat / Superwall / Adapty / native).
3. Ask for current **paywall view → trial start** and **trial → paid** rates (last 30 days).
4. Ask for a **screenshot of the current paywall**.
5. Ask for **plan structure** and **gating strategy** (what is free vs. paid, and why).
6. Identify the **value/aha moment** and where users currently hit the paywall.

## 2. Diagnose the Funnel
Run the **Paywall Conversion Funnel** before changing anything:

| Stage | Healthy Range | Red Flag |
|---|---|---|
| App open → paywall view | 60–95% | <50% (paywall buried) |
| Paywall view → CTA tap | 25–45% | <15% (copy/offer weak) |
| CTA tap → purchase confirm | 70–90% | <50% (StoreKit friction) |
| Trial start → paid conversion | 25–60% | <15% (wrong audience/price) |

Identify the weakest stage. If trial-to-paid is the issue, consider `subscription-lifecycle` tactics.

## 3. Gating Strategy & Placement
- **Gating:** The free tier must deliver a real aha. Gate value that scales with usage/success, not the core value that proves the product works.
- **Placement:** Default to a **soft paywall after the first value moment** unless data supports a hard paywall for high-intent installs.
- **Anti-Patterns:** Do not gate the core aha, do not show the wall on first open, and do not use dark patterns.

## 4. The 7-Element Paywall Audit
Score the current paywall (1–5):
1. **Headline** — outcome-led, not feature-led.
2. **Value props** — 3–5 max, benefit-led.
3. **Social proof** — rating, user count, or testimonials above the fold.
4. **Plan picker** — annual default-selected, savings % visible.
5. **Price anchoring** — annual shown as monthly equivalent + total.
6. **Trust elements** — "Cancel anytime", restore button visible.
7. **CTA** — single primary action, high-contrast.

Anything ≤2 is a quick win. Anything 3 is an A/B test candidate.

## 5. A/B Testing Playbook
Test ONE element at a time. Use these sample-size floors for ~10% lift detection:
- 5% baseline: ~6,000 users/variant
- 15% baseline: ~2,000 users/variant
- 30% baseline: ~1,000 users/variant

**Test Priority Order:**
1. Gating strategy / Trigger timing (highest leverage)
2. Headline copy
3. Trial offer (3-day vs 7-day vs no trial)
4. Plan default (annual vs monthly)
5. CTA copy
6. Social proof element
7. Visual style

## 6. Metrics & Guardrails
Track both conversion and guardrail metrics:
- **Conversion:** Free→paid, trial-start, trial→paid, ARPU.
- **Guardrails:** Free-user retention, churn rate, refund/chargeback rate.

A paywall that converts but spikes churn or refunds is not a win.
