# Company Research

This skill covers two distinct workflows. Choose the one that matches the user's intent.

## Workflow A: PM Strategy & Interview Brief (single company)

Use when the user wants a company profile for interview prep, competitive analysis, partnership evaluation, or market-entry context.

1. **Define Research Scope**
   - Capture the company name, research purpose, and key questions.
   - If the user already supplied the company and purpose, skip re-asking.

2. **Gather Company Overview**
   - Document name, headquarters, industry, founding year, size, and key historical milestones.
   - Sources: company website, LinkedIn, Crunchbase/PitchBook, Wikipedia.

3. **Extract Executive Quotes on Strategic Vision**
   - Find recent quotes from CEO, COO, VP Product, or Group PM.
   - Focus on product strategy, transformation initiatives, and organizational dynamics.

4. **Synthesize Product & Organizational Insights**
   - Cover product strategy, recent launches, innovation focus, PLG approach, and how PM influences strategy.
   - Use the Executive Insights Framework: Company Overview, Executive Quotes, Product Insights, Transformation Strategies, Organizational Impact, Future Roadmap, PLG.

5. **Produce the Brief**
   - Output a markdown brief using the template structure.
   - Emphasize executive perspective and product-centric insights, not financial analysis or SWOT.

## Workflow B: Sales ICP Discovery & Scoring (multiple companies)

Use when the user wants to find companies to sell to, build a target list, or do ICP/market research on prospects.

**Prerequisites:** `BROWSERBASE_API_KEY` env var and `browse` CLI installed.

1. **Deep Company Research**
   - Understand the user's company, product, and ICP.
   - Ask for company name or URL if not provided.

2. **Depth Mode Selection**
   - Choose quick/deep/deeper based on the number of targets desired.

3. **Discovery**
   - Use `browse cloud search` with diverse queries to find target companies.
   - Deduplicate URLs using `node {SKILL_DIR}/scripts/list_urls.mjs /tmp`.

4. **Deep Research & Scoring**
   - For each target, use the Plan→Research→Synthesize pattern.
   - Extract page content with `node {SKILL_DIR}/scripts/extract_page.mjs "<url>"`.
   - Score ICP fit and write one markdown file per company to `{OUTPUT_DIR}/{company-slug}.md`.
   - Apply anti-hallucination rules: never infer product description from design; quote or paraphrase specific homepage content; cap score at 3 if content is inaccessible.

5. **Report & CSV**
   - Compile results with `node {SKILL_DIR}/scripts/compile_report.mjs {OUTPUT_DIR} --open`.
   - Output a scored CSV and HTML report to the user's Desktop.

## Conflicts

- **deanpeters/Product-Manager-Skills::skills/company-research/SKILL.md** is a single-company, PM-strategy brief using manual public-source synthesis. **browserbase/skills::skills/company-research/SKILL.md** is a multi-company, sales-ICP discovery pipeline using the Browserbase Search API and automated scripts. They are not interchangeable; select the workflow that matches the user's goal.
