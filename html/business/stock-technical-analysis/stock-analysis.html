# Stock Analysis

## Task Goal
- Perform stock and crypto analysis for user-provided tickers.
- Support technical analysis, portfolio management, watchlists/alerts, dividend analysis, trend detection, and rumor/early-signal detection.
- Trigger when the user asks to analyze a stock, predict a short-term move, manage a portfolio, check alerts, scan trends, or find rumors.

## Prerequisites
- Python 3 with requests, numpy, and pandas installed.
- uv installed for running the LeoYeAI script suite.
- Optional: Twitter/X authentication via bird CLI for social sentiment.

## Standard Workflow

1. **Identify and validate the ticker**
   - Accept A-share codes (e.g., 000001, sh600000, 000001.SZ), HK codes (e.g., 00700.HK), US tickers (e.g., AAPL), and crypto pairs (e.g., BTC-USD).
   - Use the stock code format reference for A-share codes.

2. **Fetch market data**
   - For A-share/China technical analysis, run `scripts/fetch_stock_data.py --stock_code <code> --days 30` to get real-time quotes and historical K-line data.
   - For US/crypto analysis, use the LeoYeAI scripts which pull from Yahoo Finance, CoinGecko, and Google News.

3. **Compute technical indicators**
   - Run `scripts/analyze_stock.py --data_file <file>` to calculate MA5/MA10/MA20/MA60, MACD, RSI, support/resistance levels, gap analysis, volume analysis, and trend judgment.
   - For US stocks, also run the 8-dimension scoring via `uv run {baseDir}/scripts/analyze_stock.py <ticker>`.

4. **Analyze current trend**
   - Evaluate moving-average alignment, MACD crossovers, RSI overbought/oversold states, volume confirmation, K-line patterns, and gap support/resistance.
   - For US stocks, incorporate the 8-dimension score breakdown.

5. **Predict short-term movement**
   - For A-share/China analysis, provide a 3-day forecast with probability estimates for up/down/sideways and strength.
   - For US/crypto, provide signal-based outlooks from the scoring model.

6. **Generate actionable output**
   - For A-share/China: give buy/hold/sell/observe advice, entry/exit price ranges, stop-loss/take-profit levels, and gap-related operational tips.
   - For US/crypto: provide portfolio summaries, watchlist alerts, dividend metrics, trending lists, and rumor impact scores.
   - Always include a risk disclaimer stating that analysis is for reference only and does not constitute investment advice.

## Portfolio Management
- Create portfolios: `uv run {baseDir}/scripts/portfolio.py create "Name"`
- Add assets: `uv run {baseDir}/scripts/portfolio.py add <ticker> --quantity <n> --cost <price>`
- View portfolio: `uv run {baseDir}/scripts/portfolio.py show`
- Analyze portfolio: `uv run {baseDir}/scripts/analyze_stock.py --portfolio "Name" --period weekly`

## Watchlist and Alerts
- Add to watchlist: `uv run {baseDir}/scripts/watchlist.py add <ticker> [--target <price>] [--stop <price>] [--alert-on signal]`
- View watchlist: `uv run {baseDir}/scripts/watchlist.py list`
- Check alerts: `uv run {baseDir}/scripts/watchlist.py check [--notify]`
- Remove from watchlist: `uv run {baseDir}/scripts/watchlist.py remove <ticker>`

## Dividend Analysis
- Analyze dividends: `uv run {baseDir}/scripts/dividends.py <ticker>`
- Compare dividend stocks: `uv run {baseDir}/scripts/dividends.py <ticker1> <ticker2> --output json`

## Trend and Rumor Scanning
- Hot Scanner: `python3 {baseDir}/scripts/hot_scanner.py [--no-social] [--json]`
- Rumor Scanner: `python3 {baseDir}/scripts/rumor_scanner.py`
- Best practice: run Rumor Scanner at 07:00 before US market open.

## Notes
- Technical analysis is based on historical data and does not guarantee future performance.
- Real-time data may be delayed; verify with actual trading data.
- Combine technical analysis with fundamental analysis and market context for comprehensive judgment.
- All recommendations must include risk warnings.

## Conflicts
- anbeime/skill focuses on A-share/China technical analysis with a 3-day forecast and gap analysis; LeoYeAI/openclaw-master-skills focuses on US/crypto multi-tool analysis with 8-dimension scoring, portfolio, watchlist, dividend, hot-scanner, and rumor-scanner features.
- anbeime/skill requires requests, numpy, and pandas; LeoYeAI/openclaw-master-skills requires uv and uses uv run.
- anbeime/skill outputs a fixed 3-day prediction with buy/sell advice; LeoYeAI/openclaw-master-skills outputs multi-dimension scores, portfolio summaries, alerts, and rumor impact scores.
