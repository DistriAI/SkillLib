# App Clips: Strategy and Implementation

## 1. Strategy and Discovery
- **Core Value:** Identify the minimum experience that demonstrates your app's core value (e.g., pay for parking, view menu).
- **Discovery Channels:** App Clips appear in App Store search, Smart App Banners, QR/NFC codes, Safari, Messages, and Maps.
- **Card Design:**
  - Title: Max 18 chars (clear action, e.g., "Order Coffee").
  - Subtitle: Max 13 chars (reinforce value, e.g., "Skip the line").
  - Header Image: 3000x2000px (show outcome, not UI).
- **ASO Implication:** App Clip cards inherit main app metadata; optimize your main listing to improve Clip discoverability.

## 2. Technical Setup
- **Target Configuration:**
  - Create a new App Clip target in Xcode.
  - Bundle ID must be prefixed by the full app's bundle ID (e.g., `com.example.MyApp.Clip`).
  - Verify entitlements:
    - App Clip: `com.apple.developer.on-demand-install-capable`
    - App Clip: `com.apple.developer.parent-application-identifiers`
    - Full App: `com.apple.developer.associated-appclip-app-identifiers`
- **Size Limit:** Keep the App Clip binary under 15MB. Use Xcode size reports to identify bloat.

## 3. Invocation and Routing
- **URL Scheme:** Configure associated domains (`appclips:yourdomain.com`) on both targets.
- **AASA File:** Host an AASA file with the App Clip app identifier.
- **Routing:**
  - Use `NSUserActivityTypeBrowsingWeb` for web-based invocations.
  - SwiftUI: `.onContinueUserActivity(NSUserActivityTypeBrowsingWeb)`.
  - UIKit: Handle `connectionOptions.userActivities` in `scene(_:willConnectTo:options:)` and `scene(_:continue:)`.
- **App Store Connect:** Configure the default experience and any advanced experiences (location, campaign) with specific URLs.

## 4. Data and Handoff
- **Authentication:** Use Sign in with Apple or Apple Pay. Avoid custom sign-up flows.
- **Data Handoff:** Use App Groups for non-secret state. Use Keychain (iOS 15.4+ one-way rule) or Sign in with Apple for secure data migration to the full app.
- **Promotion:** Show `SKOverlay` after the user has experienced value, not immediately.

## 5. Validation Checklist
- [ ] App Clip target is under 15MB.
- [ ] Entitlements are correctly assigned to both targets.
- [ ] URL routing works for both App Clip and full app (cold launch and continuation).
- [ ] AASA file is live and associated domains are configured.
- [ ] App Store Connect experiences are configured with correct metadata.
- [ ] Data handoff to full app is tested.
- [ ] `SKOverlay` is shown post-value.
