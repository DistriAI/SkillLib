# GeoPandas

## Environment Setup
- **Standard**: `uv pip install geopandas` (plus optional `pyarrow`, `folium`, `mapclassify`).
- **Strict/Audit**: Use Python 3.12+ with pinned versions (e.g., `geopandas==1.2.0`, `shapely==2.1.2`) and local audit tools if provenance is critical.

## Core Workflow
1. **Load Data**: Use `gpd.read_file` for vector formats (GeoJSON, GPKG, SHP). Use `use_arrow=True` for performance if `pyarrow` is installed.
2. **CRS Management**: 
   - Check `gdf.crs`.
   - Use `set_crs` only if metadata is missing and known.
   - Use `to_crs` to transform coordinates. Always reproject to a local/equal-area CRS before calculating area or distance.
3. **Spatial Analysis**:
   - **Joins**: Use `gpd.sjoin` for predicate-based joins and `gpd.sjoin_nearest` for proximity.
   - **Overlay**: Use `gpd.overlay` for intersection/union/difference.
   - **Statistics**: For spatial autocorrelation or regression, load PySAL references.
4. **Visualization**: Use `.plot()` for static maps or `.explore()` for interactive folium maps.

## Safety & Correctness
- **Provenance**: Record source hashes and CRS for every derived artifact.
- **Privacy**: Generalize coordinates and avoid publishing exact addresses or small-area joins.
- **Validation**: Check for invalid geometries and ensure CRS units match the operation (e.g., meters for buffer).
