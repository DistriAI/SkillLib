# Statsmodels: Statistical Modeling and Econometrics

## Overview

Statsmodels is Python's premier library for statistical modeling, providing tools for estimation, inference, and diagnostics. Apply this skill for rigorous statistical analysis, from simple linear regression to complex time series models.

## Compatibility and Setup

- **Version Pinning**: Use statsmodels 0.15.0 with Python 3.12+ (NumPy 2.5.3, SciPy 1.18.1).
- **Imports**: Use `statsmodels.api` for stable high-level imports.
- **API Changes**: In 0.15, use `result_object=True` for ADF/KPSS tests and `rng=` instead of `seed`.

## When to Use This Skill

- Fitting regression models (OLS, WLS, GLS, quantile regression)
- Performing generalized linear modeling (logistic, Poisson, Gamma, etc.)
- Analyzing discrete outcomes (binary, multinomial, count, ordinal)
- Conducting time series analysis (ARIMA, SARIMAX, VAR, forecasting)
- Running statistical tests and diagnostics

## Best Practices

1. **Data Preparation**:
   - **Intercept**: Always add a constant for array-based models (`sm.add_constant`).
   - **Missing Values**: Use `missing="raise"` during construction to catch unexpected NaNs.
   - **Scaling**: Record units and estimate scaling on training data only.

2. **Model Building**:
   - Start with a simple model and add complexity as needed.
   - Match the model to the outcome type (e.g., Logit for binary, Poisson for counts).

3. **Inference**:
   - Report effect sizes and confidence intervals, not just p-values.
   - Use robust standard errors when heteroskedasticity or clustering is present.

4. **Model Evaluation**:
   - Check residuals (plot vs fitted, Q-Q plot).
   - Use AIC/BIC only for comparable likelihoods on the same response and rows.

## Quick Start Examples

### Linear Regression (OLS)

```python
import statsmodels.api as sm

X = sm.add_constant(X_data)
model = sm.OLS(y, X)
results = model.fit()
print(results.summary())
```

### Time Series (ARIMA)

```python
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.stattools import adfuller

# Check stationarity
adf_result = adfuller(y_series, result_object=True)
print(f"ADF p-value: {adf_result.pvalue:.4f}")

model = ARIMA(y_series, order=(1, 1, 1))
results = model.fit()
forecast = results.get_forecast(steps=10).summary_frame()
```

## Reporting

- Use `.summary()` for detailed output.
- Document transformations and excluded observations.
- Interpret coefficients carefully, accounting for link functions (e.g., exp(β) for log link).
