# Seaborn Statistical Visualization

## Overview

Seaborn is a Python visualization library for creating publication-quality statistical graphics. Use this skill for dataset-oriented plotting, multivariate analysis, automatic statistical estimation, and complex multi-panel figures with minimal code.

## Environment and Installation

Reviewed against Seaborn 0.13.2 documentation. Native synthetic checks used Python 3.13, Seaborn 0.13.2, Matplotlib 3.11.2, pandas 3.0.6, NumPy 2.5.3.

```bash
# Reproducible install for examples in this skill
uv pip install "seaborn==0.13.2"

# Include optional statistical dependencies when needed
uv pip install "seaborn[stats]==0.13.2"
```

Recommended imports:

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import seaborn.objects as so
```

`sns.load_dataset()` downloads public CSV example data from the `mwaskom/seaborn-data` repository when it is not cached. For private, regulated, or offline work, load local files explicitly with pandas and pass the resulting DataFrame to seaborn.

## Design Philosophy

1. **Dataset-oriented**: Work directly with DataFrames and named variables.
2. **Semantic mapping**: Automatically translate data values into visual properties.
3. **Statistical awareness**: Built-in aggregation, error estimation, and confidence intervals.
4. **Aesthetic defaults**: Publication-ready themes and color palettes.
5. **Matplotlib integration**: Full compatibility with matplotlib customization.

## Quick Start

```python
import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

df = sns.load_dataset('tips')
sns.scatterplot(data=df, x='total_bill', y='tip', hue='day')
plt.show()
```

## Core Plotting Interfaces

### Function Interface (Traditional)
Specialized plotting functions organized by visualization type. Each category has **axes-level** functions (plot to single axes) and **figure-level** functions (manage entire figure with faceting).

**When to use:**
- Quick exploratory analysis
- Single-purpose visualizations

### Objects Interface (Modern)
The `seaborn.objects` interface provides a declarative, composable API similar to ggplot2. Upstream describes this interface as experimental in 0.13.2; prefer the function interface for conservative production code.

**When to use:**
- Complex layered visualizations
- Fine-grained control over transformations

```python
from seaborn import objects as so

(
    so.Plot(data=df, x='total_bill', y='tip')
    .add(so.Dot(), color='day')
    .add(so.Line(), so.PolyFit(order=1))
)
```

## Current API Notes (Seaborn 0.13)

- **Keyword Arguments**: Most plotting functions require keyword arguments for variables. Prefer `sns.scatterplot(data=df, x="x", y="y")`.
- **Error Bars**: `errorbar` replaces the old `ci` parameter in `lineplot()`, `barplot()`, and `pointplot()`. Regression functions (`regplot()`, `lmplot()`) still use `ci`.
- **Categorical Scale**: Use `native_scale=True` when numeric or datetime categories should keep their original scale.
- **Palette**: Passing `palette` without `hue` is deprecated for categorical functions. Assign a redundant hue (e.g., `hue="day"`) and set `legend=False` if needed.
- **Renamed Parameters**: Use `violinplot(density_norm=..., common_norm=...)` instead of `scale`/`scale_hue`.

## Plotting Functions by Category

### Relational Plots
- `scatterplot()`: Display individual observations.
- `lineplot()`: Show trends and changes (aggregates and computes CI).
- `relplot()`: Figure-level interface with automatic faceting.

**Key parameters:** `x`, `y`, `hue`, `size`, `style`, `col`, `row`.

```python
sns.scatterplot(data=df, x='total_bill', y='tip', hue='time', size='size', style='sex')
sns.relplot(data=df, x='total_bill', y='tip', col='time', row='sex', hue='smoker', kind='scatter')
```

### Distribution Plots
- `histplot()`: Bar-based frequency distributions.
- `kdeplot()`: Smooth density estimates.
- `ecdfplot()`: Empirical cumulative distribution.
- `jointplot()`: Bivariate plot with marginal distributions.
- `pairplot()`: Matrix of pairwise relationships.

**Key parameters:** `stat` ("count", "density"), `bins`, `bw_adjust`, `fill`, `multiple`.

```python
sns.histplot(data=df, x='total_bill', hue='time', stat='density', multiple='stack')
sns.jointplot(data=df, x='total_bill', y='tip', kind='scatter', hue='time')
```

### Categorical Plots
- `stripplot()`: Points with jitter.
- `swarmplot()`: Non-overlapping points.
- `boxplot()`: Quartiles and outliers.
- `violinplot()`: KDE + quartile information.
- `barplot()`: Mean/aggregate with confidence intervals.
- `catplot()`: Faceted categorical plots.

**Key parameters:** `order`, `hue_order`, `dodge`, `orient`, `kind`.

```python
sns.swarmplot(data=df, x='day', y='total_bill', hue='time')
sns.catplot(data=df, x='day', y='total_bill', col='time', kind='violin', inner='quartile')
```

### Matrix Plots
- `heatmap()`: Rectangular data mapping.
- `clustermap()`: Hierarchical clustering with heatmap.

```python
corr = df.select_dtypes("number").corr(numeric_only=True)
sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm", center=0, square=True)
```

## Data Structure Requirements

- **Long-Form Data (Preferred)**: Each variable is a column, each observation is a row.
- **Wide-Form Data**: Supported for matrix-like inputs (heatmaps), but may require `pandas.melt()` for general plotting.

## When Not to Use

- Do not use for interactive plots (use Plotly).
- Do not use for final publication styling without additional Matplotlib customization (use scientific-visualization skill).
