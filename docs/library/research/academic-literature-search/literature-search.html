# Literature Search

## Overview

This skill searches academic literature using one or more of the following approaches, depending on the user's needs and available tools:

1. **Multi-source CLI/API search** (LeoYeAI style): Use the `lit` CLI or TypeScript API to search arXiv, Semantic Scholar, OpenAlex, PubMed, CrossRef, DBLP, CORE, IEEE Xplore, Google Scholar, Unpaywall, and Web Search. Supports query expansion, PDF download, and smart sorting.
2. **Agent-driven web search with verification** (brycewang-stanford style): Search field-appropriate databases (Google Scholar, Web of Science, JSTOR, Semantic Scholar, and field-specific sources), web-fetch every candidate paper to verify title, authors, year, and DOI, curate results, and output a markdown table.
3. **Valyu semantic search** (FreedomIntelligence style): Use the Valyu API to search PubMed, arXiv, bioRxiv, and medRxiv with natural language queries, returning full-text content and images.

## When to Use

- The user asks to search for papers, review literature, find references, verify a paper exists, or build a bibliography.
- The user needs comprehensive coverage across multiple academic sources.
- The user needs PDFs of open-access papers.
- The user needs full-text content from biomedical and preprint sources.

## Conflicts

- **LeoYeAI/openclaw-master-skills** uses a local CLI (`lit`) and TypeScript API with a wide range of sources and PDF download capabilities. It does not require per-paper web verification or a specific markdown table output.
- **brycewang-stanford/Auto-Empirical-Research-Skills** mandates web-fetching every candidate paper to verify existence and DOI, curating results, and outputting a markdown table with specific columns. It does not use a local CLI or the Valyu API.
- **FreedomIntelligence/OpenClaw-Medical-Skills** requires a Valyu API key and uses the Valyu semantic search API for PubMed, arXiv, bioRxiv, and medRxiv. It returns full-text content and images, which the other two do not.

## Steps

### 1. Determine the Search Approach

- If the user needs PDFs or a wide range of sources, use the **Multi-source CLI/API** approach.
- If the user needs verified citations for a bibliography, use the **Agent-driven web search with verification** approach.
- If the user needs full-text content from biomedical and preprint sources, use the **Valyu semantic search** approach.

### 2. Multi-source CLI/API Search (LeoYeAI style)

- Use the `lit` CLI or TypeScript API.
- Specify sources, limit, and sort criteria.
- Optionally download PDFs.

### 3. Agent-driven Web Search with Verification (brycewang-stanford style)

- Identify the research field from context.
- Choose field-appropriate databases.
- Search with specific queries.
- Web-fetch every candidate paper to verify title, authors, year, and DOI.
- Curate results and output a markdown table.

### 4. Valyu Semantic Search (FreedomIntelligence style)

- Ensure a Valyu API key is available.
- Use the Valyu API to search PubMed, arXiv, bioRxiv, and medRxiv.
- Process results using `jq` or the Valyu SDK.

## Output Format

- **Multi-source CLI/API**: JSON or markdown with paper metadata and optional PDF paths.
- **Agent-driven web search**: Markdown table with columns: `Authors (Year)`, `Title`, `Venue`, `DOI`, `Relevance`.
- **Valyu semantic search**: JSON with `success`, `type`, `query`, `result_count`, `results` (including `title`, `url`, `content`, `source`, `relevance_score`, `images`), and `cost`.

## Verification

- For the agent-driven approach, every paper in the final list must be web-fetched and verified.
- For the other approaches, verify that the search was successful and that the results are relevant.
