# Research Grant Writing

## Overview
Develop competitive funding proposals for NSF, NIH, DOE, DARPA, and NSTC. Grants must demonstrate scientific rigor, innovation, feasibility, and broader impact.

## 1. Establish the Governing Opportunity
- Record agency, opportunity ID, due date, eligibility, and submission stage.
- Verify current notices and the original solicitation.
- **NIH Policy Warning:** For NIH, use this skill for requirements, critique, and consistency checks. NIH policy excludes applications substantially developed by AI. Preserve applicant ownership of substantive science.

## 2. Compliance and Structure
- Build a requirement-to-source-to-draft-location gap matrix.
- **NSF:** 15-page limit, Intellectual Merit + Broader Impacts.
- **NIH:** 1-page Specific Aims, 12-page Research Strategy (R01).
- **DARPA:** High-risk/high-reward, phased execution, transition pathways.
- **NSTC:** CM03 form, bilingual abstract, research architecture diagram.

## 3. Visual Elements
- **Requirement:** Include 1-3 figures (timelines, workflows, conceptual frameworks).
- **Method:** Use the `scientific-schematics` skill or local tools (matplotlib, Illustrator).
- **Disclosure:** If using AI generation, ensure sensitive data is not transmitted to third-party APIs.

## 4. Drafting and Review
- Draft core sections (Aims, Significance, Approach, Budget).
- Use local scripts (e.g., `compliance_checker.py`) if available in the repository for format checks.
- Ensure budget justifications align with the workplan and agency constraints (e.g., NIH modular budgets).
