# Breadth Chart Analyst

## Overview
Analyze market breadth using two complementary charts: the S&P 500 Breadth Index (200-Day MA based) for strategic positioning and the US Stock Market Uptrend Stock Ratio for tactical timing. All analysis and output are conducted in English.

## When to Use
- User provides breadth chart images for analysis
- User requests market breadth assessment or positioning recommendations
- User wants medium-term strategic and short-term tactical market outlook
- User requests breadth analysis without chart images (CSV data mode)

## Core Principles
1. Dual-Timeframe Analysis: Combine strategic and tactical perspectives
2. Backtested Strategy Focus: Apply proven systematic strategies
3. Objective Signal Identification: Use clearly defined thresholds and transitions
4. English Communication: All analysis and reports in English
5. Actionable Recommendations: Specific positioning guidance for different investor types

## Chart Types and Purposes

### Chart 1: S&P 500 Breadth Index (200-Day MA Based)
**Purpose**: Medium to long-term strategic market positioning

**Key Elements**:
- 8-Day MA (Orange Line): Short-term breadth trend, primary entry signal generator
- 200-Day MA (Green Line): Long-term breadth trend, primary exit signal generator
- Red Dashed Line (73%): Average peak level - market overheating threshold
- Blue Dashed Line (23%): Average 8MA trough level - extreme oversold
- Triangles: Purple ▼ = 8MA troughs, Blue ▼ = 200MA troughs, Red ▲ = 200MA peaks
- Pink Background: Downtrend periods

**Backtested Strategy**:
- BUY: When 8MA reverses from a trough (especially below 23%)
- SELL: When 200MA forms a peak (typically near/above 73%)

### Chart 2: US Stock Market - Uptrend Stock Ratio
**Purpose**: Short-term tactical timing and swing trading

**Key Elements**:
- Uptrend Stock Definition: Stocks above 200MA/50MA/20MA with positive 1-month performance
- Green Regions: Market in uptrend phase
- Red Regions: Market in downtrend phase
- ~10% Level: Short-term bottom, extreme oversold
- ~40% Level: Short-term top, market overheating

**Swing Trading Strategy**:
- ENTER LONG: When color changes from red to green (especially from <10-15% levels)
- EXIT LONG: When color changes from green to red (especially from >35-40% levels)
- Timeframe: Days to weeks

## Analysis Workflow

### Step 1: Determine Data Source
- If user provides chart images, use image-based analysis (Step 2A)
- If no chart images are provided, fetch CSV data from public sources (Step 2B)

### Step 2A: Image-Based Analysis
1. Confirm receipt of chart image(s) and identify which chart(s) are provided
2. Read the comprehensive breadth chart methodology from references/breadth_chart_methodology.md
3. Review sample charts in assets/ for reference on chart format and visual elements
4. Extract current readings from the chart image:
   - Current 8MA level (orange line) and 200MA level (green line)
   - 8MA and 200MA slopes (rising, falling, or flat)
   - Distance from 73% and 23% thresholds
   - Most recent date visible on the chart
5. CRITICAL: Focus on the rightmost 3-5 data points for latest trend direction
   - Confirm line colors: 8MA = ORANGE, 200MA = GREEN
   - Analyze the very latest trajectory of each line
6. Identify signals based on thresholds and transitions

### Step 2B: CSV Data Analysis
1. Fetch CSV data from public sources:
   - Market Breadth: tradermonty.github.io/market-breadth-analysis/market_breadth_data.csv
   - Uptrend Ratio: tradermonty/uptrend-dashboard/data/uptrend_ratio_timeseries.csv
   - Sector Summary: tradermonty/uptrend-dashboard/data/sector_summary.csv
2. Extract current readings from CSV data:
   - 200-Day MA, 8-Day MA, Trend, Dead Cross status
   - Current ratio, 10MA, slope, trend (UP/DOWN), color (GREEN/RED)
   - Per-sector ratio, trend, status (overbought/oversold)
3. Identify signals based on thresholds and transitions

### Step 3: Signal Identification
- Identify buy/sell signals based on backtested strategy rules
- Note proximity to key thresholds (73%, 23%, ~10%, ~40%)
- Identify recent transitions (red to green, green to red)

### Step 4: Scenario Analysis
- Develop scenario analysis with probabilities
- Consider both strategic and tactical perspectives
- Identify risks and potential catalysts

### Step 5: Positioning Recommendations
- Provide specific positioning guidance for different investor types
- Include entry/exit levels and timeframes
- Note risk management considerations

## Output
Generate markdown analysis reports saved to the reports/ directory:
- Chart 1 only: breadth_200ma_analysis_[YYYY-MM-DD].md
- Chart 2 only: uptrend_ratio_analysis_[YYYY-MM-DD].md
- Both charts: breadth_combined_analysis_[YYYY-MM-DD].md

Reports include executive summaries, current readings, signal identification, scenario analysis with probabilities, and actionable positioning recommendations.
