# Paper Poster

## Conflicts
- wanshuiyin/Auto-claude-code-research-in-sleep says the LaTeX/tcbposter pipeline is deprecated and the agent must immediately proceed with /paper-poster-html, passing through all user arguments unchanged.
- brycewang-stanford/Auto-Empirical-Research-Skills says the agent should generate the poster using an article + tcbposter LaTeX pipeline with venue-specific color schemes, A0/A1 sizing, and LaTeX compilation constraints.

## Steps
1. Determine the intended poster pipeline from the user's request and available skills.
2. If the user or environment expects the deprecated LaTeX/tcbposter flow, note that wanshuiyin/Auto-claude-code-research-in-sleep marks it deprecated and redirects to /paper-poster-html.
3. If the user or environment expects the full LaTeX/tcbposter flow, follow brycewang-stanford/Auto-Empirical-Research-Skills:
   - Set constants: VENUE, POSTER_SIZE, ORIENTATION, COLUMNS, PAPER_DIR, OUTPUT_DIR, REVIEWER_MODEL, AUTO_PROCEED, COMPILER, ENGINE.
   - Apply the venue color scheme table.
   - Persist state to poster/POSTER_STATE.json after each phase.
   - Use article class, never beamer.
   - Never use adjustbox; use plain \includegraphics.
   - Use \tcbuselibrary{poster,skins,fitting}, not \usepackage[most]{tcolorbox}.
   - Use [table]{xcolor} for \rowcolor.
   - Follow tcbposter layout rules to avoid content overflow.
4. If the user wants the modern HTML/CSS pipeline, proceed with /paper-poster-html as directed by the deprecated skill.
