# PDF Processor

## When to Use
- Extract text, tables, or structured data from PDF documents.
- Merge, split, or extract specific pages from PDFs locally.
- Convert PDFs to markdown.
- Create a simple PDF from a text file.

## Choose Your Path

### Path A: Local-Only Processing (No Network)
Use when the user needs offline PDF manipulation or extraction without external services.

**Dependencies:** Python 3.9+, `pip install -r scripts/requirements.txt`

**Operations:**
- **Merge PDFs:** `python scripts/pdf_tool.py --operation merge --inputs "a.pdf" "b.pdf" --output "out.pdf"`
- **Split PDFs:** `python scripts/pdf_tool.py --operation split --inputs "input.pdf" --output "out_dir"`
- **Extract Pages:** `python scripts/pdf_tool.py --operation extract-pages --inputs "input.pdf" --pages "1-3,5" --output "extracted.pdf"`
- **Extract Text:** `python scripts/pdf_tool.py --operation extract-text --inputs "input.pdf" --output "output.txt"`
- **Extract Tables:** `python scripts/pdf_tool.py --operation extract-tables --inputs "input.pdf" --output "tables_out_dir"`
- **Create PDF:** `python scripts/pdf_tool.py --operation create --inputs "input.txt" --output "created.pdf"`

**Constraints:** No network calls. No OCR. Page numbering starts at 1. Invalid pages are ignored.

### Path B: Cloud-Based Extraction (Network Required)
Use when the user provides PDF URLs and needs AI-assisted extraction, table detection, or markdown conversion.

**Setup:** Read credentials from `~/.gooseworks/credentials.json`:
```bash
export GOOSEWORKS_API_KEY=$(python3 -c "import json;print(json.load(open('$HOME/.gooseworks/credentials.json'))['api_key'])")
export GOOSEWORKS_API_BASE=$(python3 -c "import json;print(json.load(open('$HOME/.gooseworks/credentials.json')).get('api_base','https://api.gooseworks.ai'))")
```
If credentials are missing, tell the user to run `npx gooseworks login`.

**Steps:**
1. **Fetch PDF Content (Linkup):**
```bash
curl -s -X POST $GOOSEWORKS_API_BASE/v1/proxy/orthogonal/run \
  -H "Authorization: Bearer $GOOSEWORKS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"api":"linkup","path":"/fetch","body":{"url":"https://example.com/document.pdf"}}'
```
2. **Extract with AI (ScrapeGraph SmartScraper):**
```bash
curl -s -X POST $GOOSEWORKS_API_BASE/v1/proxy/orthogonal/run \
  -H "Authorization: Bearer $GOOSEWORKS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"api":"scrapegraph","path":"/v1/smartscraper","body":{"website_url":"https://example.com/report.pdf","user_prompt":"Extract all financial figures, tables, and key metrics from this document"}}'
```
3. **Extract Tables (Riveter):**
```bash
curl -s -X POST $GOOSEWORKS_API_BASE/v1/proxy/orthogonal/run \
  -H "Authorization: Bearer $GOOSEWORKS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"api":"riveter","path":"/v1/run","body":{"input":{"urls":["https://example.com/report.pdf"]},"output":{"tables":{"prompt":"Extract all tables with titles, headers, and rows","contexts":["urls"]}}}}'
```
4. **Convert to Markdown (ScrapeGraph Markdownify):**
```bash
curl -s -X POST $GOOSEWORKS_API_BASE/v1/proxy/orthogonal/run \
  -H "Authorization: Bearer $GOOSEWORKS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"api":"scrapegraph","path":"/v1/markdownify","body":{"website_url":"https://example.com/document.pdf"}}'
```

**Tips:** Specify exact data needed for better extraction. Use schemas for consistent structured output. Handle multi-page documents in chunks. Verify extracted numbers against source.

## Validation and Safety
- Validate required inputs before execution.
- Do not fabricate data.
- For local path: ensure no writes occur outside the specified output path.
- For cloud path: ensure credentials are present and valid.
- Return a structured deliverable with a short validation summary.
