# Unslop

Remove AI writing patterns from text before publishing, committing, or sending.

## Option A: Manual Editing (Agent-Driven)

1. Scan the text for AI patterns (puffery, AI vocabulary, em dashes, chatbot phrases, etc.).
2. Rewrite to preserve meaning while matching the intended tone.
3. Add human voice: have opinions, vary rhythm, acknowledge complexity, use first person where appropriate, and be specific.
4. Self-audit: ask "What makes this obviously AI generated?" and fix remaining tells.

## Option B: CLI Post-Processing (Deterministic)

1. Install the tool: `pipx install unslop` or `uv tool install unslop`.
2. Pipe text through the CLI: `cat draft.md | unslop --stdin --deterministic > clean.md`.
3. Use `--deterministic` for reproducible output in CI or commit hooks.
4. Review the output, as automated cleanup may occasionally alter meaning.

## Conflicts

- **michaelshimeles/skills** prescribes a manual, agent-driven editing process with a detailed pattern list.
- **sickn33/agentic-awesome-skills** prescribes a CLI-based, deterministic post-processing pipeline.

Choose Option A for nuanced, voice-driven edits. Choose Option B for automated, reproducible cleanup in pipelines.
