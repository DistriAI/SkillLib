# Presentation Generation Skill

## Overview
This skill supports two distinct workflows for creating presentations: generating a web-based HTML deck using Reveal.js, or generating a PowerPoint (.pptx) file using a local Python/JS framework.

## Workflow 1: Reveal.js HTML Deck
Use this when the user wants a browser-based presentation or does not have the local PPT framework installed.

1. **Design Analysis**: Analyze the topic to determine tone, industry, and brand colors. Declare the design scheme (color palette, fonts, layout strategy) before coding.
2. **Color Palette**: Select a 3-5 color palette that matches the theme. Avoid generic defaults; use bold or unexpected combinations if appropriate.
3. **HTML Structure**: Create a single HTML file using Reveal.js CDN links.
   - Include `reset.css`, `reveal.css`, a theme CSS, and `reveal.js`.
   - Structure slides using `<div class="reveal"><div class="slides"><section>...</section></div></div>`.
4. **Styling**: 
   - Ensure `.reveal` and `.slides` are 100% width/height.
   - Use flexbox for centering content.
   - Apply visual hierarchy with font sizes (48-72px titles, 24-32px body).
   - Use diverse layouts (two-column, full-screen charts) to avoid monotony.
5. **Initialization**: Initialize Reveal.js with `width: "100%"`, `height: "100%"`, and `margin: 0`.

## Workflow 2: Local PPTX Export
Use this when the user specifically requests a `.pptx` file and the local framework is available at `D:\SKILL\project\ppt`.

1. **Validation**: Run `python scripts/validate_skill.py --help` to verify the environment.
2. **Authoring**: Create a JavaScript file in `projects/` (e.g., `demo.js`).
   - Define `const SLIDES = [...]`.
   - Each slide object should include `badge`, `title`, `subtitle`, `clickHint`, and `elements`.
   - Use component types like `comparison`, `timeline`, `stats`, `valueCards`, `quote`, `ending`.
3. **Preview**: Generate an HTML preview by running `python build_html.py <project_name>`.
4. **Export**: Convert to PowerPoint by running `python convert_to_pptx.py <project_name>`.
5. **Output**: The final `.pptx` file will be in the `output/` directory.

## General Design Principles
- **Content-Driven**: Match colors and fonts to the subject matter.
- **Visual Variety**: Avoid repeating the same layout on consecutive slides.
- **Conciseness**: Keep text minimal; use bullets and visual components.
- **Contrast**: Ensure high contrast between text and background for readability.
