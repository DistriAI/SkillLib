help

combined

The two skills share the same name and high-level intent (display a help/reference guide), but they are not reproductions of one another. The first is a thin wrapper that reads and outputs a GSD command reference from a plugin workflow file, with strict constraints against adding commentary. The second is a self-contained, versioned Diverga help guide that embeds a detailed, formatted reference for 24 research agents across 9 categories, commands, and usage examples. Neither copy contains the other's material steps or content, and they disagree on the reference content, versioning, and output format, so crowning one would hide a real alternative.

---
name: help
description: Display the help reference for the active tool or plugin
---

<objective>
Display the complete help reference for the active tool or plugin.
</objective>

<process>
1. Determine which help reference applies to the current context (e.g., GSD command reference or Diverga agent guide).
2. If the reference is stored in an external file (e.g., @${CLAUDE_PLUGIN_ROOT}/workflows/help.md), read that file and output its content directly.
3. If the reference is embedded in this skill, output the embedded content directly.
4. Do not add project-specific analysis, git status, file context, next-step suggestions, or commentary beyond the reference content.
</process>
