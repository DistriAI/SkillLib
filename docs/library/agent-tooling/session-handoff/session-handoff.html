# Session Handoff

Create a comprehensive handoff document to enable a fresh agent or human to continue work with zero ambiguity.

## 1. Determine Mode
- **Create**: User wants to save state, context is full, or session is ending.
- **Resume**: User wants to load previous context.

## 2. Create Workflow

### Step 1: Audit State
- Run `git status -s` and `git diff --stat` to establish grounded reality.
- If using the `softaworks` toolkit, run `python scripts/create_handoff.py [task-slug]` to generate a scaffold.

### Step 2: Capture Context
Fill in the following sections (using the `mohitagw15856` format as a guide for structure):

**🎯 Objective**
- The goal in 1–2 lines and the definition of done.

**✅ Done so far**
- Key work completed and decisions made (with rationale).
- Explicitly record negative decisions (discarded paths) to prevent re-attempting failed solutions.

**📍 Current state**
- Exactly where things stand: branch/PR, what runs, what's failing, files touched.
- Separate facts from speculation. Label untested assumptions as `[UNVERIFIED]`.

**⏭️ Next step**
- The single most important, atomic, unambiguous action to take next.
- Followed by the next 2–3 steps.

**⚠️ Gotchas & dead ends**
- What was tried and didn't work, constraints, and sharp edges.

**🔗 Pointers**
- Key files (`path:line`), commands to run, and links.

**📂 Open Loops**
- List unaddressed edge cases or deferred tasks.
- Every open loop must specify an owner (`Human` or `Agent`) and a deterministic verification criteria.

### Step 3: Validate
- If using the `softaworks` toolkit, run `python scripts/validate_handoff.py <handoff-file>`.
- Ensure no `[TODO]` placeholders remain.
- Ensure no secrets are included.
- Check that the next step is specific enough to act on immediately.

### Step 4: Confirm
- Report the handoff location and a summary of captured context to the user.

## 3. Resume Workflow

### Step 1: Find Handoffs
- List available handoffs (e.g., `python scripts/list_handoffs.py` or check `.claude/handoffs/`).

### Step 2: Check Staleness
- If using the `softaworks` toolkit, run `python scripts/check_staleness.py <handoff-file>`.
- Assess if the context is still valid based on git changes since the handoff.

### Step 3: Load and Verify
- Read the handoff document completely.
- Verify project directory, git branch, and environment state match the handoff.
- Check if blockers have been resolved.

### Step 4: Begin Work
- Start with the "Immediate Next Step" from the handoff.
- Reference "Critical Files" and "Gotchas" as you work.

## 4. Anti-Patterns
- Do not write vague status updates (e.g., "worked on the feature").
- Do not omit dead ends.
- Do not assume shared memory; the reader may have zero prior context.
- Do not provide broad lists for the next action; specify the exact command or file edit.
