# Claude Skill (Combined)

This skill covers three distinct capabilities associated with the name 'claude':

## 1. Claude Code CLI Orchestration
Use when delegating tasks to the `claude` CLI.

**Defaults & Invocation:**
- **dzhng approach:** Use `claude -p --model opus --effort high`. Verify all claims. Use `--max-budget-usd` for exploratory tasks.
- **LeoYeAI approach:** Use `--dangerously-skip-permissions` in isolated environments. Use `--output-format stream-json` for structured logs. Implement poll-and-extend timeouts instead of hard kills.

**Safety:**
- **dzhng:** Never grant fewer tools than required by the output contract. Require evidence (file paths, command output) for all claims.
- **LeoYeAI:** Use worktrees for isolation. Use tmux for mid-task steering.

## 2. Claude Design System (bergside)
Use when authoring design guidelines for the 'Claude' brand aesthetic.
- **Aesthetic:** Research-journal style, warm ivory parchment, near-black slate ink.
- **Typography:** Anthropic Sans (UI), Anthropic Serif (Display).
- **Tokens:** primary=#141413, secondary=#FAF9F6.
- **Workflow:** Restate intent -> Define tokens -> Component rules -> Accessibility -> QA checklist.

## 3. Claude Skills Meta-Skill (Vibe-Skills)
Use when creating or refactoring other SKILL.md files.
- **Structure:** `SKILL.md` + `references/` + `scripts/`.
- **Frontmatter:** `name` must match `^[a-z][a-z0-9-]*$`. `description` must be decidable.
- **Quality Gate:** Run `validate-skill.sh` before delivery.
- **Rules:** No bluffing on external facts. Keep Quick Reference <= 20 patterns.
