These four skills all address the creation of agent skills, but they are distinct, non-interchangeable procedures. cangjie-skill is a specific pipeline for distilling long-form content (books/videos) into skills. agent-skills-platform is a general-purpose factory for creating skills from workflow descriptions with a focus on cross-platform export and security. Vibe-Skills is a governed runtime entry point for executing complex tasks with strict phase controls. context-engineering-collection is a reference library of patterns for building agent systems, not a step-by-step creation procedure. Because they cover different inputs, outputs, and execution models, crowning one would hide the others' unique value.

# Agent Skill Creation Suite

This skill acts as a router to determine the best method for creating or executing an agent skill based on the user's request.

## Routing Logic

1.  **Analyze User Intent and Input:**
    *   **Input is a long-form document (book, video, course):** Route to `cangjie-skill`.
    *   **Input is a workflow description, script, or process to automate:** Route to `agent-skills-platform`.
    *   **User wants to execute a complex, multi-phase task with strict governance:** Route to `vibe`.
    *   **User is asking for architectural patterns or principles for building agent systems:** Route to `context-engineering-collection`.

2.  **Execute the Routed Skill:**
    *   Follow the specific instructions, phases, and output structures defined in the chosen skill's SKILL.md.

3.  **Handle Ambiguity:**
    *   If the user's intent is unclear, ask a clarifying question to determine the best route. For example: "Are you trying to create a new skill from a document, automate a specific workflow, or execute a complex task?"
