# Find Skills

Use this skill when the user asks how to do a task, asks to find a skill, or wants to extend agent capabilities.

## Step 1: Understand the Need
Identify the domain, specific task, and whether a dedicated skill likely exists. Prefer a task-specific skill over stretching a general-purpose one.

## Step 2: Choose an Ecosystem and Search

### Option A: Orthogonal Skill Library
1. Ensure the Orthogonal CLI is installed: `npm install -g @orth/cli`.
2. Load credentials from `~/.gooseworks/credentials.json`:
   ```bash
   export GOOSEWORKS_API_KEY=$(python3 -c "import json;print(json.load(open('$HOME/.gooseworks/credentials.json'))['api_key'])")
   export GOOSEWORKS_API_BASE=$(python3 -c "import json;print(json.load(open('$HOME/.gooseworks/credentials.json')).get('api_base','https://api.gooseworks.ai'))")
   ```
   If the file does not exist, tell the user to run `npx gooseworks login`.
3. Search: `orth skills search "<keyword>"`.
4. Browse: `orth skills list` or https://orthogonal.com/skills.
5. Install: `orth skills add <slug>`.
6. Skills install to `~/.openclaw/skills/<slug>/`. Read `~/.openclaw/skills/<slug>/SKILL.md` for usage.

### Option B: Open Agent Skills Ecosystem
1. Search: `npx skills find <query>`.
2. Browse: https://skills.sh/.
3. Install: `npx skills add <owner/repo@skill> -g -y`.
4. Check for updates: `npx skills check` and `npx skills update`.

## Step 3: Present Options
Show the user the skill name, what it does, the install command, and a link to learn more.

## Step 4: Install if Requested
Run the appropriate install command for the chosen ecosystem.

## When No Skills Are Found
1. Acknowledge that no existing skill was found.
2. Offer to help with the task directly using general capabilities.
3. Suggest creating a custom skill if the task is recurring.

## Tips
- Use specific keywords for better search results.
- Try alternative terms if the first search returns nothing.
- Check skill requirements (API keys, credentials) before installing.
