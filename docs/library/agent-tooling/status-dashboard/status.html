# status

Choose the dashboard that matches the user's request.

## Drill-me learning status

1. Run `date +%Y-%m-%d`.
2. Read `~/.drill-me/index.md` and every file in `~/.drill-me/topics/`. If the directory does not exist, say so and suggest `/drill:me <topic>` to start.
3. Print a compact report:
   - A table of topics: cards, due now, next due date, last session.
   - Weak spots: cards flagged `cw` or `leech`, and any card with stability under 2 days after 3+ reviews.
   - Recommendation: the single best next action.

Keep it under a screenful.

## Status Page construction

Status Page construction is maintained in Pagina. Install and use page-builder:

```bash
npx skills add kostja94/pagina --skill page-builder
```

Ask the agent to use page-builder to build a new Status Page.

## Memory health dashboard

1. Locate memory files:
   - `MEMORY_DIR="$HOME/.claude/projects/$(pwd | sed 's|/|%2F|g; s|%2F|/|; s|^/||')/memory"`
   - Count lines in `MEMORY.md`, list topic files, count `CLAUDE.md` lines, and count files in `.claude/rules/`.
2. Analyze capacity using the thresholds:
   - MEMORY.md lines: < 120 healthy, 120-180 warning, > 180 critical.
   - CLAUDE.md lines: < 150 healthy, 150-200 warning, > 200 critical.
   - Topic files: 0-3 healthy, 4-6 warning, > 6 critical.
   - Stale entries: 0 healthy, 1-3 warning, > 3 critical.
3. Check stale references by verifying that file paths referenced in MEMORY.md still exist.
4. Output a dashboard with line counts, topic files, capacity status, stale references, duplicates, and recommendations.

Support `--brief` for a one-line summary.
