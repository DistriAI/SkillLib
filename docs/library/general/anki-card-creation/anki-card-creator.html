# Anki Card Creator

## When to Use
- Preparing for medical board exams (USMLE, MCAT, specialty boards).
- Memorizing drug names, mechanisms, side effects, anatomy, and pathways.
- Converting lecture notes, textbook chapters, or Q&A material into active recall cards.

## Do NOT Use When
- Learning conceptual understanding (use textbooks/videos first).
- Memorizing without context (ensure comprehension first).
- Creating cards for rapidly changing information.
- Substituting clinical experience or procedural skills.

## Workflow
1. Confirm the study objective, learner level, card format, and content source.
2. Check whether the material is in Q/A form, needs restructuring, or is too incomplete. If required content is missing, stop and request only the minimum additional input.
3. Choose the card type:
   - **Basic/Reversible**: For Q/A pairs. Use `create_basic_cards` with `reversible=True` for bidirectional recall.
   - **Cloze Deletion**: For dense text. Use `create_cloze_cards` with strategies: single deletion, multiple deletions, or hierarchical.
   - **Image Occlusion**: For diagrams. Use `create_image_occlusion` with occlude_regions and card_type (one_by_one, all_at_once, transparent, colored).
4. Apply automated tagging using a hierarchical structure (e.g., Source::Subject::Topic::Difficulty).
5. Generate output in the desired format:
   - **TSV**: For simple Anki import. Use `scripts/main.py` with `--input`, `--output`, and domain flags (`--drug`, `--anatomy`).
   - **.apkg**: For full deck with media. Use `scripts/main.py` with `--card-type`, `--n-cards-per-page`, and `--tags`.
6. Review the generated cards for atomicity, accuracy, and importability.
7. Return cards or a card blueprint with assumptions, tagging guidance, and validation notes.

## Parameters (CLI)
| Parameter | Type | Required | Default | Description |
|-----------|------|----------|---------|-------------|
| `--input`, `-i` | string | No | - | Input text/PDF file |
| `--output`, `-o` | string | No | `anki_cards.txt` | Output TSV or .apkg file |
| `--drug` | flag | No | false | Create a drug card |
| `--anatomy` | flag | No | false | Create an anatomy card |
| `--card-type` | string | No | basic | basic, cloze, image_occlusion |
| `--n-cards-per-page` | int | No | 3 | Cards per page for cloze |
| `--tags` | string | No | - | Hierarchical tags (e.g., First_Aid::Cardiology) |

## Python API
```python
from scripts.card_creator import AnkiCardCreator

creator = AnkiCardCreator()

# Cloze
cards = creator.create_cloze_cards(text=text, n_cards=3, difficulty="intermediate", tags=["Pathology"])

# Basic
cards = creator.create_basic_cards(content={"Q": "A"}, reversible=True, tags=["Pharmacology"])

# Image Occlusion
cards = creator.create_image_occlusion(image_path="diagram.png", occlude_regions=[{"label": "Nerve", "coords": (100, 200, 300, 400)}], card_type="one_by_one")
```

## Output Discipline
- Keep results reproducible and atomic.
- Identify assumptions explicitly.
- Avoid undocumented side effects.
- Validate input file paths before execution.
- Restrict output directory to workspace.
