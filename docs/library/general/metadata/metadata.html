# Metadata

This skill covers two distinct domains. Determine the user's intent to select the appropriate procedure.

## 1. SEO Page Metadata (Marketing)
Use when the user requests a page metadata audit, title/description optimization, or implementation of HTML meta tags.

**Procedure:**
1. **Discover:** Build a page inventory from production navigation, sitemaps, and routes. Identify missing or duplicate metadata.
2. **Classify:** Determine page type, search intent, and unique value proposition. Apply the "Swap Test" to ensure metadata is page-specific.
3. **Route:** Delegate specific writing tasks to specialist skills (title-tag, meta-description, open-graph, etc.).
4. **Localize:** Research locale-specific intent. Do not simply translate source metadata. Verify hreflang and canonical relationships.
5. **Implement:** Edit the source of truth (CMS fields, layout templates, or code). Ensure internal consistency between title, description, and social tags.
6. **Validate:** Run build checks and inspect server-rendered HTML for representative URLs. Verify no duplicate or empty tags.
7. **Verify:** Recheck production URLs post-deployment and monitor Search Console for query/CTR changes.

## 2. Scholarly Metadata & Bibliometrics (Research)
Use when the user requests DOI resolution, citation analysis, author disambiguation, or reference management.

**Procedure:**
1. **Identify Need:** Determine if the task involves DOI resolution, citation metrics, author identity, or reference library management.
2. **Select Tool:** Choose the appropriate sub-skill from the catalog:
   - **DOI/Metadata:** `crossref-api`, `datacite-api`, `doi-content-negotiation`.
   - **Citations/Metrics:** `opencitations-api`, `h-index-guide`, `journal-metrics-guide`, `plumx-metrics-api`.
   - **Author/Org Identity:** `orcid-api`, `ror-organization-api`, `viaf-authority-api`.
   - **Reference Management:** `zotero-actions-tags-guide`, `zoplicate-dedup-guide`, `sophosia-reference-guide`.
3. **Execute:** Read the selected sub-skill's SKILL.md and follow its specific API or workflow instructions.
