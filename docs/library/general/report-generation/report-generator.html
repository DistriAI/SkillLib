# Report Generator

This skill handles three distinct reporting workflows. Identify the context based on the input data and user request.

## 1. Influencer Marketing Reports
**Context:** Post-campaign wrap-ups, executive summaries, client results.
**Procedure:**
1. Identify audience (executive, client, team, board).
2. Use pre-computed metrics from `performance-analyzer` and `roi-calculator`. Do not compute raw ROI.
3. Structure the report with narrative, key learnings, and recommendations.
4. **Privacy Constraint:** Use opaque refs (`client_ref`, `creator_ref`) in all saved artifacts. Resolve names only in-memory for transient rendering. Never save resolved PII.
5. Save to `memory/influencer/report-generator/YYYY-MM-DD-<topic>.md` only with explicit WARM-save authorization.

## 2. SEO/GEO Analysis Reports
**Context:** AI search visibility, technical SEO audits, competitive analysis.
**Procedure:**
1. Determine report type (Executive Summary, Technical Analysis, Comprehensive GEO).
2. Collect data from GEO audits, citation monitoring, and competitive sources.
3. Generate visualizations:
   - Line charts for trends.
   - Bar charts for engine comparisons (ChatGPT, Claude, Perplexity, SGE).
   - Heatmaps for keyword opportunities.
4. Output in requested format (Markdown, HTML, JSON, Excel). HTML should include interactive elements and CSS styling.

## 3. Video Compression Reports
**Context:** Post-processing video silence removal or compression.
**Procedure:**
1. Run the report script:
   ```bash
   python3 scripts/generate_report.py \
       --original <original.mp4> \
       --compressed <compressed.mp4> \
       --segments <segments.json> \
       --output <report.json>
   ```
2. Ensure `ffprobe` is available for duration measurement.
3. Output JSON must include `original_duration_seconds`, `compressed_duration_seconds`, `removed_duration_seconds`, `compression_percentage`, and `segments_removed`.

## Conflicts & Disambiguation
- If the user provides video files, use Workflow 3.
- If the user provides SEO/GEO metrics or asks for AI visibility reports, use Workflow 2.
- If the user provides campaign metrics or asks for stakeholder reports, use Workflow 1.
- Do not mix privacy constraints from Workflow 1 with the open data visualization of Workflow 2 unless explicitly requested for a client-facing SEO report (in which case, apply Workflow 1 privacy rules to the output).
