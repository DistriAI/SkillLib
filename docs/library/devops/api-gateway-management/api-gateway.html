# API Gateway

This skill covers two distinct services named 'API Gateway'. Determine which service the user intends to use.

## 1. AWS API Gateway
Use this section when the user wants to create, manage, or troubleshoot AWS API Gateway resources (REST or HTTP APIs).

- **Core Concepts**: Understand API types (HTTP, REST, WebSocket) and components (Resources, Methods, Integrations, Stages).
- **Common Patterns**:
  - **Create HTTP API**: Use `aws apigatewayv2 create-api` or SAM templates.
  - **Create REST API**: Use `aws apigateway create-rest-api`, `create-resource`, `put-method`, and `put-integration`.
  - **Lambda Integration**: Configure Lambda Proxy or Custom integrations.
  - **CORS**: Configure CORS for HTTP APIs via `update-api` or for REST APIs via `put-method`/`put-integration` for OPTIONS.
  - **Authorization**: Set up JWT or IAM authorizers.
- **Troubleshooting**: Check CloudWatch logs and API Gateway access logs.

## 2. Maton.ai API Gateway
Use this section when the user wants to interact with third-party SaaS APIs (e.g., Slack, Gmail, Notion) using managed OAuth.

- **Prerequisites**: Requires `MATON_API_KEY` environment variable.
- **Base URL**: `https://gateway.maton.ai/{app}/{native-api-path}`.
- **Authentication**: Include `Authorization: Bearer $MATON_API_KEY` in all requests.
- **Connection Management**:
  - **List Connections**: `GET https://ctrl.maton.ai/connections`.
  - **Create Connection**: `POST https://ctrl.maton.ai/connections` with `app` name.
  - **Specify Connection**: Use `Maton-Connection` header if multiple connections exist for an app.
- **Usage**: Call native API endpoints directly through the gateway (e.g., `https://gateway.maton.ai/slack/api/chat.postMessage`).
