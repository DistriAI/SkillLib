# Blueprint

This skill name covers two distinct tasks. Determine which one applies before proceeding.

## Task A: WordPress Playground Blueprint JSON

Use this when the deliverable is a WordPress Playground Blueprint JSON file or bundle.

1. Create or edit a JSON file that conforms to the WordPress Playground Blueprint schema.
2. Use only documented top-level properties: `$schema`, `landingPage`, `description`, `meta`, `preferredVersions`, `features`, `extraLibraries`, `constants`, `plugins`, `siteOptions`, `login`, and `steps`.
3. Set `$schema` to `"https://playground.wordpress.net/blueprint-schema.json"`.
4. Use `preferredVersions` with `php` (major.minor only, e.g. `"8.3"`) and `wp` (e.g. `"latest"`).
5. Use shorthands (`login`, `plugins`, `siteOptions`, `constants`) for simple cases; use explicit `steps` when execution order matters.
6. Use resource references (`wordpress.org/plugins`, `wordpress.org/themes`, `url`, `git:directory`, `literal`, `literal:directory`, `bundled`, `zip`) to point to files.
7. For `git:directory`, set `refType` when using a branch or tag name.
8. For `literal:directory`, use nested objects for subdirectories; do not use path separators in keys.
9. Validate the file against the schema before use.

## Task B: Construction Plan Generator

Use this when the task is to turn a one-line objective into a step-by-step construction plan that a fresh coding agent can execute cold.

1. Research: scan the codebase, read project memory, and run pre-flight checks.
2. Design: break the objective into one-PR-sized steps, identify parallelism, and record model constraints.
3. Draft: generate the plan from a structured template with branch workflow rules, CI policy, and rollback strategies.
4. Review: review the plan against acceptance criteria; delegate only when explicitly authorized.
5. Register: save the plan in an authorized project location.

## Conflicts

- WordPress/agent-skills: 'blueprint' refers to a WordPress Playground JSON file format and its schema.
- sickn33/agentic-awesome-skills: 'blueprint' refers to a planning skill that generates multi-step construction plans for coding agents.

Do not mix procedures from the two tasks. Select the task that matches the user's deliverable.
