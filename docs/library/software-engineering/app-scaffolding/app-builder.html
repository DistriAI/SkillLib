# App Builder

This skill handles application creation requests. Determine the target platform to select the appropriate workflow.

## 1. Determine Application Type
- **Power Platform / Model-Driven App**: If the user requests a model-driven app, CRM, or Power Apps solution, follow the **Power Apps Workflow**.
- **General Full-Stack / Mobile / Desktop App**: If the user requests a web, mobile, or desktop application using standard tech stacks, follow the **General Scaffolding Workflow**.

## 2. Power Apps Workflow (Microsoft)
1. **Plugin Check**: Run `node "${PLUGIN_ROOT}/scripts/check-version.js"`.
2. **Interactive Authoring**: Run the authoring flow in the main conversation (do not use subagents).
   - Select environment.
   - Define jobs-to-be-done.
   - Author App Spec (JSON) including tables, columns, relationships, forms, and views.
   - **Critical**: Paste all preview wireframes, dry-run plans, and lint findings verbatim into the chat message; do not rely on collapsed tool output.
3. **Build**: Use `cds-maker-sdk` to build the app from the spec.
4. **Edit**: Download deployed app to spec for idempotent re-builds.

## 3. General Scaffolding Workflow (sickn33)
1. **Project Detection**: Read `project-detection.md` to identify project type.
2. **Tech Stack Selection**: Read `tech-stack.md` to choose the stack (e.g., Next.js, FastAPI, Flutter).
3. **Template Selection**: Select the matching template from the 13 available (e.g., `nextjs-fullstack`, `react-native-app`).
4. **Agent Coordination**: Coordinate specialized agents (`project-planner`, `frontend-specialist`, `backend-specialist`, etc.) to build components.
5. **Scaffolding**: Create directory structure and core files based on the selected template.

## Conflicts
- **Repository: microsoft/power-platform-skills** vs **sickn33/agentic-awesome-skills**: The Microsoft skill mandates running interactive steps in the main loop and explicitly forbids subagents for authoring, whereas the sickn33 skill relies on coordinating multiple specialized agents for execution. The Microsoft skill is restricted to Power Apps, while the sickn33 skill is for general-purpose applications.
