Combined skill

---
name: implement
description: Implement a piece of work based on a spec, PRD, or set of tickets.
---

Implement the work described by the user in the spec, PRD, or tickets.

If the user passes a ticket reference, fetch it from the issue tracker and state its title before starting. If the reference is ambiguous, ask.

Use the project's actual test workflow at pre-agreed seams. If a TDD skill or command is available, use it; otherwise, follow the project's standard test-driven development practices. Preserve the attached plan and existing todos.

Run typechecking regularly, single test files regularly, and the full test suite once at the end.

Review the net diff and actual verification evidence. If a code-review skill or command is available, use it; otherwise, perform the review directly.

Commit only the authorized scope on a topic branch following repository policy. Inspect staged files and preserve unrelated work. Do not commit to a protected default branch or publish merely because implementation was requested.
