Use when targeting ACM Conference on Security and Privacy in Wireless and Mobile Networks (WiSec) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for wireless/mobile security.

When to use

  • targeting WiSec
  • deciding if a manuscript fits WiSec
  • conference-fit read for wireless manuscripts
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence-gap, anonymity, artifact, rebuttal, or re-routing issues
  • wireless, mobile, IoT, sensing, RF, and network security/privacy submissions

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • generic CS papers without wireless/mobile security focus
  • distributed-computing scalability and scheduling papers
  • protocol or wireless-performance papers without a security threat model
  • finance or privacy central frame papers
  • HPC venues
