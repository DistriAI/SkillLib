frontend-to-backend-requirements

authentic

Document frontend data needs for backend developers. Use when frontend needs to communicate API requirements to backend, or user says 'backend requirements', 'what data do I need', 'API requirements', or is describing data needs for a UI.

When to use

  • Documenting frontend data needs
  • Communicating API requirements to backend
  • Describing data needs for a UI
  • Listing actions and states to handle
  • Surfacing uncertainties and business rules

When not to use

  • Specifying endpoints
  • Defining field names
  • Designing API structure
  • Implementing backend logic
