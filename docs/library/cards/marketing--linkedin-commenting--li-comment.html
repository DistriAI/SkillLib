li-comment

separate

Write comments on other people's LinkedIn posts that read as a person with an opinion, not a bot. Use when the user pastes a post and wants a comment, says "comment on this", "engage with this", "what do I say here", or wants a batch of comments for their engagement round.

When to use

  • Write comments on LinkedIn posts
  • Engage with pasted posts
  • Generate batch comments for engagement rounds
  • Create human-sounding LinkedIn comments

When not to use

  • Auto-posting comments
  • Using browser tools to publish comments
  • Scraping the feed
  • Guessing post content from URLs
