ipsn-topic-selection

separate

Use when deciding whether a sensing/embedded project is an IPSN Information-Processing (IP) contribution or a Sensor Platforms, Tools and Design Methods (SPOTS) contribution, and whether it should go to the IPSN lineage (now the merged SenSys at CPS-IoT Week), a CPS-IoT Week neighbor (RTAS/ICCPS/HSCC), MobiSys/MobiCom, INFOCOM, or a signal-processing journal.

When to use

  • Deciding between IP track and SPOTS track
  • Selecting venue for sensing/embedded projects
  • Evaluating if project fits IPSN lineage or SenSys
  • Applying model-swap and platform-swap tests
  • Checking evidence maturity for sensing claims
  • Conducting cheap reconnaissance before committing

When not to use

  • Pure ML results with sensing datasets
  • Pure networking results
  • Deep estimation/signal-processing results with no systems payoff
