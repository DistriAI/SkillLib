soft

separate

Classic style skill, opt-in: it runs only when called by name. A calm, polished look with soft contrast, generous whitespace and spring motion.

When to use

  • high-end visual design
  • agency-level digital experiences
  • UI/UX architecture
  • motion choreography
  • premium layout archetypes
  • haptic micro-aesthetics
  • fluid dynamics
  • Awwwards-tier design

When not to use

  • standard linear or ease-in-out transitions
  • generic 1px solid gray borders
  • harsh dark drop shadows
  • edge-to-edge sticky navbars
  • symmetrical 3-column Bootstrap-style grids
  • using banned fonts like Inter or Roboto
  • using standard thick-stroked icons
  • instant state changes without interpolation
