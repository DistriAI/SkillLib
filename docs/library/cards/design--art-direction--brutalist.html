brutalist

separate

Classic style skill, opt-in: it runs only when called by name. A hard mechanical look with Swiss type, rigid grids, extreme scale contrast and utilitarian colour.

When to use

  • Swiss Industrial Print UI
  • Tactical Telemetry & CRT Terminal UI
  • Rigid modular grid layouts
  • Extreme typographic scale contrast
  • Utilitarian color palettes
  • Simulated analog degradation effects

When not to use

  • Conventional consumer UI patterns
  • Mixing light and dark substrates
  • Alternating or mixing visual modes
  • Gradients
  • Soft drop shadows
  • Modern translucency
