oopsla-topic-selection

separate

Use when judging whether a project is OOPSLA-shaped — a PL contribution whose evidence spans design, implementation, formalism, or empirical study — and routing within the SIGPLAN family from OOPSLA's seat: POPL for theory-first, PLDI for implementation-performance, ICFP for functional, Onward! for vision, ECOOP, or SE venues.

When to use

  • judging whether a project is OOPSLA-shaped
  • routing within the SIGPLAN family
  • identifying center of mass
  • checking exemplar precedent
  • verifying current scope text
  • committing to a round or re-route

When not to use

  • product description novelty
  • theorems standing alone without implementation story
  • evaluation as speedup contribution
  • speculative ideas needing permission
