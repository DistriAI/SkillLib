scenario-skyboxes

separate

Use when a task involves generating or iterating on skyboxes, 360 panoramas, equirectangular images, environment maps, HDRI-style backdrops, or VR backdrops through the Scenario MCP. Triggers include text-to-skybox, turning a photo into a 360 environment, restyling a panorama's mood, upscaling a skybox without breaking the seam wrap, or exporting equirectangular or cubemap layouts for game engines such as Unity, Unreal, or Godot.

When to use

  • text-to-skybox
  • turning a photo into a 360 environment
  • restyling a panorama's mood
  • upscaling a skybox without breaking the seam wrap
  • exporting equirectangular or cubemap layouts for game engines

When not to use

  • prompting a generic image model for a 360 panorama
  • upscaling with a generic upscaler
