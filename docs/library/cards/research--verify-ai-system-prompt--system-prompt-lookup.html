system-prompt-lookup

authentic

Checks what a shipped AI product's system prompt and tool schema actually say by reading a dated public archive instead of recalling them. Use when the user asks what some agent is instructed to do, quotes a system prompt and wants it verified, shows an extracted or leaked prompt, or compares how two products are set up. Read-only; fetches public files from github.com.

When to use

  • The user asks what a product's system prompt says, or quotes one and asks whether it is real.
  • You are about to state that some agent "is instructed to" do something.
  • The user shows an extracted or leaked prompt and wants it verified.
  • You are comparing products: prompt size, how many tools ship, how a refusal is phrased.
  • You are writing a harness and want to see how shipped ones solve the same problem.

When not to use

  • concluding how a product behaves today
