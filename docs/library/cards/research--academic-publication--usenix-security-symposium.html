usenix-security-symposium

separate

Use when targeting USENIX Security Symposium (USENIX Security) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for security flagship.

When to use

  • targeting USENIX Security Symposium
  • deciding if a manuscript fits the venue
  • conference-fit read for systems security
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • routing decisions for security flagship submissions

When not to use

  • substitute for current year's CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
  • routing to IEEE S&P, CCS, NDSS, PETS, or SOUPS as primary venue
