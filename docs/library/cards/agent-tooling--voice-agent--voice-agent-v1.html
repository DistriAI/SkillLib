voice-agent-v1

separate

Gives the agent a complete voice layer using ElevenLabs. Clones the principal's voice, generates MP3 audio from any text (VSL, podcasts, video scripts, nurturing sequences), and deploys a conversational AI agent for automated inbound and outbound calls via Twilio. Self-configures by navigating elevenlabs.io autonomously via virtual-desktop — no manual API key setup required. Use when the agent needs to speak, call leads, answer prospects, or produce audio content at scale.
