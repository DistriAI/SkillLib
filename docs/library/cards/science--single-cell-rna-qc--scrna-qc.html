scrna-qc

separate

Execute the MAD-based single-cell RNA-seq QC workflow to filter low-quality cells and emit reports plus filtered AnnData files.

When to use

  • filter low-quality cells
  • compute metrics
  • apply MAD thresholds
  • generate standard plots
  • filter genes
  • emit qc_summary.json

When not to use

  • doublet handling
  • batch correction
