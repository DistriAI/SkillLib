ors-literature-positioning

separate

Use when placing an Operations Research (OR) manuscript against the OR/MS literature — separating your model, results, and algorithmic guarantees from the closest prior work so the novelty is unambiguous. Positions the contribution; it does not formulate the model (ors-theory-development) or write the contribution statement (ors-contribution-framing).

When to use

  • placing an OR manuscript against the OR/MS literature
  • separating model, results, and algorithmic guarantees from prior work
  • identifying the closest 3-5 papers
  • stating technical deltas against prior work
  • cross-stream placement
  • making novelty checkable
  • addressing positioning pushback patterns

When not to use

  • formulating the model
  • writing the contribution statement
