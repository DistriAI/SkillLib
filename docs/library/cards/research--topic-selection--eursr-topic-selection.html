eursr-topic-selection

separate

Use when deciding whether a sociology project fits the European Sociological Review (ESR) and whether to write a full Article, a Comment/Reply, or a Data Brief. ESR is Europe's flagship quantitative-sociology journal, so the test is a portable mechanism studied with a rigorous comparative or longitudinal quantitative design. Frames the question; it does not collect data.

When to use

  • Choosing among possible projects or framings for ESR
  • Deciding among a full Article, a Comment/Reply, and a Data Brief
  • Pressure-testing fit before investing
  • Evaluating if a paper feels single-country, merely descriptive, or atheoretical
  • Assessing quantitative core, portable mechanism, and comparative leverage

When not to use

  • Collecting data
  • Purely theoretical papers
  • Purely ethnographic papers
  • Smuggling a new study into a Comment
  • Using a Data Brief for a full causal argument
