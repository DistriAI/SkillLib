profiler

separate

Capture read-only Unity runtime performance snapshots

When to use

  • Checking runtime performance
  • Taking a profiler snapshot
  • Inspecting memory/frame stats
  • Get performance statistics
  • Get memory usage overview
  • Get top N objects by runtime memory usage
  • Get memory usage of all loaded textures
  • Get memory usage of all loaded meshes

When not to use

  • profiler_start
  • profiler_stop
  • profiler_record
  • profiler_analyze
  • profiler_get_fps
  • Scene performance hints
  • Optimization suggestions
  • Continuous sampling
