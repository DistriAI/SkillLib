Point to Paul Bakaus's Impeccable design skill and explain when to use it. Use when asked how to install impeccable, which skill critiques and audits a built UI, or what handles the critique stage of the design pipeline. Produces the install command, the one-time init step, guidance on when it fits and when it does not, and credit to the author with a link. Contains no upstream skill content.

When to use

  • installing impeccable
  • critiquing and auditing a built UI
  • handling the critique stage of the design pipeline
  • design review covering hierarchy, clarity and polish
  • deterministic checks and model-led critique

When not to use

  • tasks where nothing is built yet
  • seeing the page rendered at real widths
  • written critique with no install
  • running it together with the direction skill
