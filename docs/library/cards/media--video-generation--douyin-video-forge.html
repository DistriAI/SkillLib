douyin-video-forge

separate

抖音短视频全链路自动化制作。适用于：收到客户项目需要制作抖音推广视频、 策划短视频内容、生成视频脚本、分析抖音热点趋势、制作爆款短视频。 通过浏览器采集抖音热榜和视频数据，生成分段脚本，调用可灵API生成视频并拼接成片。

When to use

  • 制作抖音推广视频
  • 策划短视频内容
  • 生成视频脚本
  • 分析抖音热点趋势
  • 制作爆款短视频
  • 采集抖音热榜和视频数据
  • 调用可灵API生成视频
  • 拼接成片

When not to use

  • 直接复制爆款内容
  • 在对话中要求输入 API Key
