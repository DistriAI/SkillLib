Use when designing the summary tables and conceptual figures for an Annual Review of Psychology (ARPsych) review — the who-found-what tables and the one framework diagram that carries the spine. Designs exhibits; it does not design the spine itself (arpsych-organizing-framework) or run a meta-analysis (arpsych-transparency-and-reproducibility).
