task-dispatcher

separate

智能任务分发与子代理协调中枢。当用户提交任何任务时，执行需求分析、任务拆解、分发策略制定，分发给合适的 subagent 执行，监控进度并阶段汇报，最终汇总结果。失败时自动兜底处理。适用于：（1）用户直接下达的任务（2）cron/heartbeat 触发的任务（3）任何需要多步骤处理的工作。

When to use

  • 用户直接下达的任务
  • cron/heartbeat 触发的任务
  • 任何需要多步骤处理的工作
  • 需求分析
  • 任务拆解
  • 分发策略制定
  • 进度监控
  • 阶段汇报
