miniqmt

separate

miniQMT 极简量化交易终端 - 支持外接Python获取行情数据和程序化交易，基于xtquant SDK。

When to use

  • 获取行情数据
  • 程序化交易
  • A股、ETF、可转债、期货、期权、融资融券交易
  • 历史K线数据下载与获取
  • 实时行情订阅
  • Level 2数据获取
  • 财务数据查询
  • 算法交易执行

When not to use

  • 可视化分析
  • 手动交易
  • 非Windows环境运行
