debug-app

separate

Diagnose Power Apps mobile install/startup failures, npm run dev errors, missing package entry points, or QR/device-opening problems even before an app is loaded. Inspect locally first; restore locked dependencies or restart Metro only with explicit approval, never upgrade packages or patch host/MSAL source. For a running native app, monitor sanitized project-local Metro logs and diagnose runtime errors or silent failures such as empty lists and blank screens. Supports startup-only diagnosis, symptoms, port/platform filters, bounded monitoring, and non-mutating --no-fix mode. Verify the original symptom, not merely installation or quiet logs.

When to use

  • Power Apps mobile install/startup failures
  • npm run dev errors
  • missing package entry points
  • QR/device-opening problems
  • runtime errors or silent failures
  • empty lists and blank screens
  • startup-only diagnosis
  • monitoring sanitized project-local Metro logs

When not to use

  • upgrading packages
  • patching host/MSAL source
  • stopping Metro
  • installing background watchers
