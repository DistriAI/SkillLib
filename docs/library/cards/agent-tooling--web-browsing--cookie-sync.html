cookie-sync

separate

Sync cookies from local Chrome to a Browserbase persistent context so the browse CLI can access authenticated sites. Use when the user wants to browse as themselves, sync cookies, or log into sites via Browserbase.

When to use

  • sync cookies from local Chrome
  • browse as themselves
  • log into sites via Browserbase
  • filter cookies by domain
  • refresh cookies in existing context
  • use verified browser mode
  • use residential proxy with geolocation
  • reuse contexts for scheduled jobs
