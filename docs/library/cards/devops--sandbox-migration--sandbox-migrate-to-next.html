sandbox-migrate-to-next

separate

Migrate Cloudflare Sandbox apps from stable @cloudflare/sandbox to @cloudflare/sandbox@next (SDK 1.0 preview). Use sandbox-next for apps already on the preview.

When to use

  • Migrating stable Sandbox apps to @next
  • Porting code to Sandbox SDK 1.0 preview
  • Upgrading Worker package and container image to @next
  • Replacing stable APIs with @next equivalents
  • Auditing codebase for deprecated stable patterns

When not to use

  • New projects starting on @next
  • Day-to-day stable work
  • Deprecated-API cleanup without moving to @next
  • Self-deployed bridge migration
