io-submission

separate

Use when running the final pre-submission preflight for International Organization (IO) via Editorial Manager — article-type selection, double-blind preparation (third-person self-citation), word caps, separate abstract/word-count/acknowledgments, short author-date footnotes, supplementary material (~20 pages), ORCID, and the Data Availability Statement. Final checks; it does not draft content.
