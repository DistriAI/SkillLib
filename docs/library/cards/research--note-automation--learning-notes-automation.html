learning-notes-automation

separate

学习笔记自动化：视频/播客转录 → 知识点提取 → 闪卡生成 → 知识图谱更新。触发词：学习笔记、闪卡、Anki、知识提取、视频学习

When to use

  • Transcribing YouTube, Bilibili, podcast, Douyin, and WeChat articles
  • Extracting core concepts, facts, methodologies, and insights
  • Generating Anki-compatible flashcards
  • Updating knowledge graph with entities and relationships
  • Creating structured Markdown learning notes

When not to use

  • Extracting without personal reflection
  • Generating excessive flashcards (more than 30 per video)
  • Creating isolated knowledge without associations
