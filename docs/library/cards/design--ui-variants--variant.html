variant

separate

Builds multiple variants of a component you're working on and helps you iterate and pick one.

When to use

  • Building multiple variants of a component
  • Iterating on UI design
  • Choosing between design options

When not to use

  • Reviewing existing UI
  • Stress testing one component
  • Working through a component's states
