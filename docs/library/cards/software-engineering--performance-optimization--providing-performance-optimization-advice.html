providing-performance-optimization-advice

separate

Produce a prioritized performance-optimization roadmap across frontend, backend, and infrastructure. Use as an explicit/manual helper after bottlenecks are known or suspected, not as the owner of regression detection, profiling capture, or test execution.

When to use

  • Prioritizing known or suspected performance bottlenecks from existing logs, traces, benchmarks, or user reports.
  • Get recommendations for improving website loading speed.
  • Optimize database query performance.
  • Improve API response times.
  • Reduce infrastructure costs.

When not to use

  • Build-to-build regression detection
  • Raw benchmark execution or profiling capture
  • Test-result packaging for QA audiences
