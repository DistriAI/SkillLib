database-schema-designer

combined

Database Schema Designer Design robust, scalable database schemas for SQL and NoSQL databases. Provides normalization guidelines, indexing strategies, migration patterns, constraint design, and performance optimization. Ensures data integrity, query performance, and maintainable data models.

When to use

  • Designing a new feature that needs database tables
  • Reviewing a schema for performance or normalization issues
  • Adding multi-tenancy to an existing schema
  • Generating TypeScript types from a Prisma schema
  • Planning a schema migration for a breaking change

Skill page

Conflict

The two copies overlap on the core task of designing database schemas, but each contains material steps the other lacks. The softaworks copy provides a four-phase process (analysis, design, optimization, migration), normalization guidance, SQL/NoSQL selection, indexing strategy, and anti-patterns. The LeoYeAI copy adds concrete engineering artifacts and constraints: Row-Level Security policies, seed data generation, TypeScript/Python type generation, ERD generation in Mermaid, and cross-cutting concerns like multi-tenancy, soft deletes, audit trails, and optimistic locking. Neither copy is a reproduction of the other, so crowning one would hide a real alternative.
