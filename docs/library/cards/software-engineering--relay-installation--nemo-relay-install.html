nemo-relay-install

separate

Use this skill when choosing or running NeMo Relay installation for an agent runtime, application language, framework integration, or plugin bundle, or checking a runtime's native Relay readiness. Do not use it for first-run instrumentation or export configuration.

When to use

  • choosing NeMo Relay installation
  • running NeMo Relay installation
  • agent runtime installation
  • application language installation
  • framework integration installation
  • plugin bundle installation
  • checking runtime's native Relay readiness

When not to use

  • first-run instrumentation
  • export configuration
