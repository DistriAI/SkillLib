replica-backend

separate

Builds the backend of an app clone: auth, database migrations and access rules, payments with Stripe, email, background jobs and third-party integrations through official APIs only, plus a security checklist. Use when the user says "add login", "set up auth", "wire up the database", "add payments", "connect Stripe", "add Google Calendar", "send emails", "backend for my clone", or when /replica-build is running on fake data.

When to use

  • add login
  • set up auth
  • wire up the database
  • add payments
  • connect Stripe
  • add Google Calendar
  • send emails
  • backend for my clone

When not to use

  • calling original app's private endpoints
  • reusing original app's OAuth client
  • proxying through original app
  • signing up for services
  • typing passwords, cards, or live keys
  • building card forms
