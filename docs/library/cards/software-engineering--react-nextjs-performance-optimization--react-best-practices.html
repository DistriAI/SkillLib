The three copies are the same Vercel React/Next.js performance guide, but they disagree on scope and rule count. The vercel-labs copy is the most complete (70 rules, including async-cheap-condition-before-await, bundle-analyzable-paths, server-auth-actions, server-dedup-props, server-hoist-static-io, server-no-shared-module-state, server-parallel-nested-fetching, client-passive-event-listeners, client-localstorage-schema, and many rerender/rendering rules). The benchflow-ai copy is a narrower variant focused on visual stability, CLS, flickering, hydration, and font loading, and it omits several rules present in the other two. The sickn33 copy matches the 45-rule set of the benchflow copy and adds a pointer to a compiled AGENTS.md plus generic limitations. Because each copy has material steps or constraints the others lack, and they disagree on the rule inventory, crowning one would hide a real alternative.
