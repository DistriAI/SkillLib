sn-ppt-workbench

separate

Use when the user asks to open, preview, inspect, or visually edit an existing SenseNova HTML presentation in the PPT Workbench, using an explicit deck_dir or the latest deck in the current workspace.

When to use

  • open the WebUI/editor/workbench
  • inspect or edit previously generated slides
  • start or reuse the AI PPT editing WebUI
  • preview an existing HTML slide deck

When not to use

  • run sn-ppt-entry
  • run sn-ppt-standard
  • run page-html
  • run batch-page-html
  • run export
  • edit slide files directly
  • regenerate the deck
