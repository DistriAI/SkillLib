Use when targeting ACM Symposium on User Interface Software and Technology (UIST) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for UI systems.

When to use

  • targeting ACM Symposium on User Interface Software and Technology (UIST)
  • deciding whether a computer-science manuscript fits this venue
  • conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for UI systems
  • interactive techniques, input, prototyping tools, AR/VR interaction, fabrication, and UI engineering
  • re-framing from journal style or arXiv style into a selective CS conference narrative
  • evidence-gap, anonymity, artifact, rebuttal, or re-routing diagnosis for this venue

When not to use

  • substitute for the current year's CFP, author kit, ethics policy, or submission portal
  • manuscripts where the central contribution is not genuinely in UI systems
  • generic CS papers that do not name the exact subcommunity, contribution type, and proof or empirical standard
