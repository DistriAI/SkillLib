separate

Use when targeting Conference on Computational Natural Language Learning (CoNLL) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for NLP learning.

When to use

  • targeting CoNLL
  • deciding if a manuscript fits CoNLL
  • conference-fit read for machine learning for language
  • re-framing journal or arXiv style into CS conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • routing computational natural language learning contributions
  • checking submission-cycle details for CoNLL

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • broad empirical NLP not central to language-learning methodology
  • resources or evaluation papers better suited for LREC-COLING
  • speech papers better suited for INTERSPEECH or SLT
  • generic CS papers without specific NLP learning focus
