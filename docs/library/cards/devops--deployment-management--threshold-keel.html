threshold-keel

separate

Safety guardrails for autonomous agents. Intercepts destructive actions, requires structured approval before irreversible operations, with CLI-backed cryptographic audit trails and policy enforcement. Your lobster has claws. Keel is the rubber band.

When to use

  • Intercepting destructive actions
  • Requiring structured approval for irreversible operations
  • Providing CLI-backed cryptographic audit trails
  • Enforcing policy
  • Classifying actions into risk tiers
  • Managing quarantine periods
  • Verifying hash chains
  • Syncing policies with Threshold Cloud

When not to use

  • Creating ~/.keel/ directories in instructions mode
  • Creating store.json in instructions mode
  • Creating WAL files in instructions mode
  • Proceeding without structured approval for T3 actions
