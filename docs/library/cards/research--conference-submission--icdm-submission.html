icdm-submission

separate

Use when auditing an ICDM (IEEE International Conference on Data Mining) submission for readiness, covering Research-vs-Applied track choice and its anonymity regime, the triple-blind sweep, the 10-page IEEE all-inclusive cap, the single June deadline, in-paper artifact references, and the desk-level triggers that get an ICDM paper rejected without review.

When to use

  • ICDM submission readiness audit
  • Research vs Applied track choice
  • Triple-blind anonymity sweep
  • 10-page IEEE all-inclusive cap check
  • In-paper artifact reference verification
  • Desk-level rejection trigger identification

When not to use

  • KDD-style cycle submissions
  • Non-ICDM conference submissions
