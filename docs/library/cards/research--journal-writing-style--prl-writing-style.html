prl-writing-style

separate

Use when polishing the prose of a Physical Review Letters manuscript for APS house style, concision, precise notation, and out-of-subfield readability. Polishes language; does not restructure the result or manage length budget.

When to use

  • Polishing PRL manuscript prose
  • Applying APS house style
  • Improving concision and directness
  • Ensuring precise notation and symbol definition
  • Enhancing out-of-subfield readability
  • Calibrating claims to evidence
  • Refining sentence architecture for four-page format

When not to use

  • Restructuring the result
  • Managing length budget
  • Fitting page limits
  • Writing cover letters
