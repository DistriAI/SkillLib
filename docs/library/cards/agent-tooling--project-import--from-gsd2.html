from-gsd2

separate

Import a GSD-2 (.gsd/) project back to GSD v1 (.planning/) format

When to use

  • Import GSD-2 project to GSD v1
  • Reverse-migrate .gsd/ to .planning/
  • Map Milestone, Slice, and Task hierarchy
  • Preserve completion state and research files

When not to use

  • Migrate GSD-2 cost/token ledger
  • Migrate database state
  • Migrate VS Code extension state
