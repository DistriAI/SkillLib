recsys-author-response

separate

Use when drafting an ACM RecSys rebuttal during the author-response window, covering the short narrative RecSys allows, anonymity, anchoring answers to submitted evidence and the anonymous repository, the recurring objections about untuned baselines, leakage, and offline-online gaps, and Senior-PC-focused clarification.

When to use

  • drafting an ACM RecSys rebuttal
  • clarifying misconceptions in author-response
  • addressing untuned baselines
  • addressing temporal leakage
  • addressing offline-online gaps
  • Senior-PC-focused clarification

When not to use

  • adding new experiments reviewers cannot see
  • pasting new result tables
  • revealing institution or platform names
  • revealing repository owner
