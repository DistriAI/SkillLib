aeri-rebuttal

separate

Use when responding to an American Economic Review: Insights (AER: Insights) conditional-accept decision — addressing the editor's letter within the short window, usually without a second referee round. Drafts a concise, decisive response and revision plan; it does not redo the analysis (see aeri-robustness / aeri-identification).

When to use

  • responding to AER: Insights conditional-accept decision
  • addressing editor's letter within short window
  • drafting concise and decisive response
  • creating revision plan
  • mapping requested changes to concrete edits
  • finalizing replication package for AEA Data Editor
  • deciding next steps after a reject

When not to use

  • redoing the analysis
  • arguing with the editor as if multi-round R&R
  • adding text or exhibits that re-breach word or exhibit caps
  • writing long defensive response letters
  • letting requested additions sprawl the paper beyond its single insight
