space-video

separate

视频创作总控/导演。把一条视频从「参考素材 → 选题 → 脚本 → 剪辑 → B-roll → 字幕 → 封面」串成一条流水线，判断当前该走哪一步、调用哪个 space-video-* 子技能，并在成片后做复盘。当用户说「做个视频」「我要拍条口播」「这个视频从头帮我做」「视频工作流」「video pipeline」，或不确定该用哪个视频子技能时触发。

When to use

  • 视频工作流
  • video pipeline
  • 从头做一条视频
  • 判断视频制作步骤
  • 调用视频子技能
  • 视频复盘

When not to use

  • 亲自剪辑
  • 亲自写脚本
  • 子技能之间直接互相调用
