newms-tables-figures

separate

Use when building exhibits for a New Media & Society (NM&S) manuscript — quote/excerpt tables, coding-scheme tables, network and computational figures, and screenshots of platform interfaces. Makes exhibits clear and self-contained; it does not run the analysis.

When to use

  • Designing any table or figure
  • Qualitative exhibits and platform screenshots
  • Fixing exhibits found unclear, redundant, or unconvincing
  • Deciding what to keep in-text vs. trim
  • Quote / excerpt tables
  • Coding-scheme tables
  • Network and computational figures
  • Platform screenshot / interface exhibits

When not to use

  • Running the analysis
