anti-sleep

combined

Keep a Mac awake for a set duration or while a process runs. Use only when the user explicitly invokes /anti-sleep. Keep a Mac awake with caffeinate during long builds, downloads, or supervised automation runs.

When to use

  • Use when the user wants the Mac to stay awake during a long supervised task.
  • Use when a build, download, or automation run should not be interrupted by sleep.

When not to use

  • Adapted from `davidondrej/skills`; verify local paths, tools, credentials, and agent features before acting.
  • For commands, remote access, scheduling, browser automation, or file-changing workflows, get explicit user approval and confirm the target environment first.

Skill page

Conflict

The two copies implement the same goal but with materially different, non-interchangeable procedures. The davidondrej copy mandates a bundled LaunchAgent-based launcher (scripts/anti-sleep.sh) with strict rules against raw backgrounding, automatic replacement of active sessions, and a separate verify step. The sickn33 copy is a direct-caffeinate approach that explicitly recommends running in a visible cmux pane or as a background task, uses pgrep/pmset for verification, and includes a 'gotcha' about the silent prompt. Crowning one would hide a real alternative (managed LaunchAgent vs. direct process).
