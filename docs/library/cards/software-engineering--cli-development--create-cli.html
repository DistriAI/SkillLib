create-cli

separate

Design command-line interface parameters and UX: arguments, flags, subcommands, help text, output formats, error messages, exit codes, prompts, config/env precedence, and safe/dry-run behavior. Use when you’re designing a CLI spec (before implementation) or refactoring an existing CLI’s surface area for consistency, composability, and discoverability.

When to use

  • designing a CLI spec
  • refactoring an existing CLI's surface area
  • defining arguments and flags
  • specifying output formats
  • defining error messages and exit codes
  • designing config and env precedence
  • defining safe and dry-run behavior

When not to use

  • implementation
  • drifting into implementation
