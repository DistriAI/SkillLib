amr-literature-positioning

separate

Use when you must identify which theoretical conversation an Academy of Management Review (AMR) manuscript enters and how it "challenges and extends" that conversation. Positions the argument within a literature; it does NOT summarize the field (AMR punishes review-essays) and does NOT build the new theory (that is amr-theory-development).

When to use

  • Identify which theoretical conversation an AMR manuscript enters
  • Determine how a manuscript challenges and extends a conversation
  • Position an argument within a literature
  • Name the primary theoretical stream
  • Define constructs built on or revised
  • Select a positioning move

When not to use

  • Summarize the field
  • Build the new theory
  • Write a review-essay
  • Select a topic
