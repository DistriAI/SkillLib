tunnel-doctor

separate

MUST be used first for tunnel / proxy-path connectivity failures or slow throughput (网络故障 / 连不上 / 代理或隧道下超时). Diagnoses Tailscale, proxy, TUN, DNS and SSH-tunnel problems on macOS and Windows/WSL, e.g. Tailscale ping works but SSH fails, curl works but browser gets 503, Git/Docker fails behind the proxy, or downloads crawl despite a reachable proxy. Not for application-layer bugs (use debugging-network-issues).

When to use

  • tunnel connectivity failures
  • slow throughput
  • Tailscale ping works but SSH fails
  • curl works but browser gets 503
  • Git/Docker fails behind proxy
  • downloads crawl despite reachable proxy
  • TUN-state failure modes
  • SSH access to WSL instances

When not to use

  • application-layer bugs
  • SSE/CDN/application protocol behavior
  • unknown boundary symptoms
