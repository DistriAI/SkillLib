jev-model-routing

separate

Use to pick the cheapest good-enough model or effort for a turn or a delegated task (lanes small to escalate), to decide continue/retry/verify/escalate/complete after each cycle, or to tune routing.

When to use

  • pick the cheapest good-enough model or effort for a turn
  • pick the cheapest good-enough model or effort for a delegated task
  • decide continue/retry/verify/escalate/complete after each cycle
  • tune routing
  • classify lane and model/effort for a task
  • route a prompt to a model
  • manage Hermes routing modes (shadow, on, off)
  • override lane mappings via lanes.json

When not to use

  • writing code
  • writing patches
  • writing designs
  • picking models by feel
  • enabling disabled reasoning
  • emitting an applied-effort notice for an unchanged request
  • cross-provider discovery
  • editing live routing mode via provider aliases
