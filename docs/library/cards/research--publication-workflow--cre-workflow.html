cre-workflow

separate

Use when deciding which cre-* sub-skill to invoke next, or when sequencing manuscript work from topic selection through rebuttal for 《中国农村经济》 (China Rural Economy). Routes — does not replace — the specialized skills.

When to use

  • Deciding which cre-* sub-skill to invoke next
  • Sequencing manuscript work from topic selection through rebuttal
  • Judging current bottleneck for a rural economy draft
  • Switching to rebuttal mode after receiving external review comments

When not to use

  • Replacing specialized cre-* skills
  • Handling manuscripts for journals other than 《中国农村经济》 unless explicitly stated
  • Performing identification strategy before literature review
  • Beautifying tables before identification strategy is established
  • Generating rebuttal letters before revising the main text
  • Submitting general empirical work that does not fit the rural economy context
