space-video-transcript

separate

从 YouTube、小宇宙、B站、抖音和小红书链接提取字幕或逐字稿；优先读取平台字幕，无字幕时自动提取音频并调用可用 ASR，输出 Markdown 与 SRT。用户发送这些平台链接、要求提取字幕/文案/逐字稿/视频转文字，或在字幕完成后希望下载原视频时使用。字幕成功后必须询问用户是否下载原视频；小宇宙对应下载原音频。
