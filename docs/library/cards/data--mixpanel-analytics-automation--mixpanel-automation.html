Automate Mixpanel tasks via Rube MCP (Composio): events, segmentation, funnels, cohorts, user profiles, JQL queries. Always search tools first for current schemas.

When to use

  • Aggregate event data
  • Run segmentation queries
  • Analyze funnels
  • Manage user profiles
  • Manage cohorts
  • Run JQL and insight queries

When not to use

  • Creating funnels in Mixpanel UI
  • Creating or managing cohorts in Mixpanel UI
