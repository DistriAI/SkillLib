jbf-data-analysis

separate

Use when building or auditing the empirical data and estimation pipeline for a Journal of Banking & Finance manuscript, including financial datasets, bank panels, winsorization, fixed effects, robustness, and reproducible scripts.

When to use

  • constructing the sample, variables, or estimation pipeline
  • robustness, heterogeneity, mechanism, or economic-magnitude checks
  • reproducible but non-redistributable workflow for proprietary finance datasets
  • bank-panel stress checks
  • data construction and variable definition
  • estimation with fixed effects and clustering
  • reproducibility and replication package preparation
  • economic-magnitude benchmarks for bank panels
