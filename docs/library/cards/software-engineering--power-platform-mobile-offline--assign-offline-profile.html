assign-offline-profile

separate

Use when the user needs to bind users or teams to a Mobile Offline Profile so they actually receive offline sync on their devices. Without this, the profile exists in Dataverse but no one's app uses it.

When to use

  • bind users to Mobile Offline Profile
  • bind teams to Mobile Offline Profile
  • assign offline profile membership
  • unassign user from offline profile
  • unassign team from offline profile
  • discover existing offline profile memberships

When not to use

  • create Mobile Offline Profile
  • setup offline profile
