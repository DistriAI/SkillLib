compose-ui-testing-patterns

separate

Use when writing or reviewing Jetpack Compose UI tests, screenshot tests or baseline-recording evidence, previews, semantics assertions, fake image loading, keyboard input, focus assertions, interaction state (hover/pressed/focused), or tests for plain state-driven UI composables.

When to use

  • writing Jetpack Compose UI tests
  • reviewing Jetpack Compose UI tests
  • screenshot tests
  • baseline-recording evidence
  • previews
  • semantics assertions
  • fake image loading
  • keyboard input

When not to use

  • production code changes unrelated to test seams
  • moving test-only helpers into production
