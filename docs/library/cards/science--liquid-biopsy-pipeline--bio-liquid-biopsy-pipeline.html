bio-liquid-biopsy-pipeline

separate

Cell-free DNA analysis pipeline from plasma sequencing to tumor monitoring. Preprocesses cfDNA reads, analyzes fragment patterns, estimates tumor fraction from sWGS, and optionally detects mutations from targeted panels.

When to use

  • analyzing liquid biopsy samples for cancer detection
  • analyzing liquid biopsy samples for cancer monitoring
  • cfDNA preprocessing
  • fragment pattern analysis
  • tumor fraction estimation from sWGS
  • mutation detection from targeted panels
  • CHIP filtering
  • longitudinal tracking
