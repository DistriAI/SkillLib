cryptotokenkit

separate

Access security tokens and smart cards using CryptoTokenKit. Use when building TKTokenDriver or TKSmartCardTokenDriver extensions, communicating with smart cards via TKSmartCard/TKSmartCardSlotManager, using iOS 26+ NFC smart-card sessions, registering smart cards, querying token-backed keychain items with kSecAttrTokenID, monitoring TKTokenWatcher, or configuring certificate-based smart-card authentication.

When to use

  • building TKTokenDriver or TKSmartCardTokenDriver extensions
  • communicating with smart cards via TKSmartCard/TKSmartCardSlotManager
  • using iOS 26+ NFC smart-card sessions
  • registering smart cards
  • querying token-backed keychain items with kSecAttrTokenID
  • monitoring TKTokenWatcher
  • configuring certificate-based smart-card authentication

When not to use

  • passkeys/WebAuthn
  • account sign-in
  • Secure Enclave
  • CryptoKit primitives
  • keychain architecture
  • certificate pinning
  • trust policy
