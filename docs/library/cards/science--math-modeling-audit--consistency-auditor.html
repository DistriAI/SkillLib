consistency-auditor

authentic

Run scoped or final cross-media consistency checks for mathematical-modeling artifacts, comparing canonical numbers, symbols, parameters, decisions, files, and paper claims without performing full-workspace audits for low-risk changes.

When to use

  • scoped consistency checks for CANONICAL or FROZEN changes
  • final cross-media consistency checks before assembly
  • checking numerical claims against frozen values
  • verifying symbols and units against the global symbol table
  • resolving method roles and decisions to human decision IDs

When not to use

  • full-workspace audits for low-risk changes
  • formatting, comments, or scratch work audits
  • ordinary pre-freeze exploration
  • repairing divergences inside the audit
  • approving final assembly directly
