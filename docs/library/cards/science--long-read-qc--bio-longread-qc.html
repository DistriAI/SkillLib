bio-longread-qc

separate

Quality control for long-read sequencing data using NanoPlot, NanoStat, and chopper. Generate QC reports, filter reads by length and quality, and visualize read characteristics. Use when assessing ONT or PacBio run quality or filtering reads before assembly or alignment.

When to use

  • assessing ONT or PacBio run quality
  • filtering reads before assembly or alignment
  • generating read length distributions
  • generating quality score plots
  • generating summary statistics
  • filtering reads by length and quality thresholds
  • visualizing read characteristics
  • adapter trimming
