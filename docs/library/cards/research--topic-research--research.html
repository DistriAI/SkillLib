Skill page

Conflict

The two skills both perform research, but they define different procedures and outputs. mattpocock/skills is a lightweight, source-grounded investigation that delegates to a background agent and writes a single cited Markdown note. Weizhena/Deep-Research-skills is a multi-step preliminary research workflow that builds a framework, supplements it via a web-search agent, asks the user for existing fields, and outputs structured outline.yaml and fields.yaml files. Neither copy is a reproduction, shortening, or wrapper of the other; each contains material steps and constraints the other lacks, so crowning one would hide a real alternative.
