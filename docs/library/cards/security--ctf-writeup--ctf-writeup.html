ctf-writeup

separate

Generates a single standardized submission-style CTF writeup for competition handoff and organizer review. Use after solving a CTF challenge to document the solution steps, tools used, and lessons learned in a structured format.

When to use

  • documenting solution steps
  • documenting tools used
  • documenting lessons learned
  • generating submission-style writeup
  • competition handoff
  • organizer review

When not to use

  • unsolved challenges
  • multiple alternative solves
  • long background sections
  • raw terminal dumps without explanation
