work-pipeline

separate

Triggers the WORK-PIPELINE when a user request starts with a [] tag (e.g., [new-feature], [bugfix], [WORK start]). Use this skill whenever you detect a [] tag at the beginning of a user message.

When to use

  • Requests starting with [new-feature]
  • Requests starting with [bugfix]
  • Requests starting with [WORK start]
  • Requests starting with any custom square bracket tag
  • Orchestrating specifier, planner, scheduler, builder, verifier, and committer agents

When not to use

  • Messages not starting with a [] tag
