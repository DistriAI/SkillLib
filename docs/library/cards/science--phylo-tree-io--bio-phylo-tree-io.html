bio-phylo-tree-io

separate

Read, write, and convert phylogenetic tree files using Biopython Bio.Phylo. Use when parsing Newick, Nexus, PhyloXML, or NeXML tree formats, converting between formats, or handling multiple trees.

When to use

  • parsing Newick, Nexus, PhyloXML, or NeXML tree formats
  • converting between formats
  • handling multiple trees
  • reading trees from files or strings
  • writing trees to various formats
  • serializing trees to strings
  • inspecting tree structure and properties
  • accessing tree nodes and clades
