io-tables-figures

separate

Use when building tables and figures for an International Organization (IO) manuscript so exhibits are self-contained, accessible, reproducible, and count toward the word budget correctly. IO word limits include tables, figures, and notes (but exclude the bibliography), and exhibits must survive IO's pre-publication result verification. Designs exhibits; it does not run the analysis.

When to use

  • Designing the main results table/figure
  • Designing a key descriptive/measurement exhibit
  • Deciding what belongs in the article vs. the supplementary material
  • Fixing an exhibit that is unclear, mislabeled, or non-self-contained
  • Trimming to the word cap by moving exhibits to supplementary material

When not to use

  • Running the analysis
