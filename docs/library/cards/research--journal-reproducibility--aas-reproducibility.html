aas-reproducibility

separate

当你在为《自动化学报》(Acta Automatica Sinica, AAS) 提升实验可复现性、组织复现包、防范数据污染时调用。覆盖环境与依赖固定、随机种子与多次运行、数据划分与防泄露、控制仿真的求解器/步长/系统参数记录、超参数与调参协议披露、以及配合双盲的匿名化复现材料，帮助控制/自动化/模式识别方向的中文稿在 Acta Automatica Sinica 外审中经得起"结果能否复现"的追问。

When to use

  • 环境与依赖固定
  • 随机种子与多次运行统计
  • 数据划分与防泄露
  • 控制仿真求解器与参数记录
  • 超参数与调参协议披露
  • 双盲匿名化复现材料
  • 复现包组织与版本维护

When not to use

  • 非《自动化学报》期刊的投稿规范
  • 未涉及实验可复现性的纯理论推导
