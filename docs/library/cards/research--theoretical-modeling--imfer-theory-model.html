imfer-theory-model

separate

Use when an IMF Economic Review (IMFER) manuscript needs an open-economy model to discipline, interpret, or generate counterfactuals for its evidence — whether a full international-finance model leads the paper or a light framework supports an empirical estimate. Right-sizes the theory to IMFER's policy-relevant bar; it does not design identification (imfer-identification) or run robustness (imfer-robustness).

When to use

  • discipline, interpret, or generate counterfactuals for evidence
  • full international-finance model leads the paper
  • light framework supports an empirical estimate
  • name the open-economy mechanism
  • map a reduced-form coefficient to a structural parameter
  • deliver a welfare or counterfactual number
  • generate cross-country sign/heterogeneity predictions
  • right-size a generic NK-SOE model

When not to use

  • design identification
  • run robustness
