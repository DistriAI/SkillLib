When not to use

Skill page

Conflict

The two copies are the same MiniMax-based autonomous review loop, but they disagree on the stop condition, file locations, and allowed tools. The wanshuiyin copy is more specific (review-stage/ paths, legacy fallbacks, explicit AND stop condition, warning against external schedulers), while the brycewang copy uses project-root paths and an OR-based stop condition with different verdict vocabulary. Crowning one would hide a real alternative, so the combined instruction preserves both variants and flags the conflicts.
