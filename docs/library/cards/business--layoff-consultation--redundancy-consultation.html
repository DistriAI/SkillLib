redundancy-consultation

authentic

Structure a redundancy consultation process and draft key communications (UK employment law focus). Use when asked to plan a redundancy process, write a redundancy letter, structure a consultation, or manage a reduction in force. Produces a structured consultation plan and draft letters; always recommends qualified HR/legal advice before proceeding.

When to use

  • plan a redundancy process
  • write a redundancy letter
  • structure a consultation
  • manage a reduction in force
  • draft at-risk letter
  • draft redundancy confirmation letter
  • UK employment law redundancy

When not to use

  • proceeding without qualified HR/legal advice
  • using template letters without customisation
  • omitting genuine exploration of alternatives
  • omitting statutory redundancy pay guidance
  • undocumented selection criteria
