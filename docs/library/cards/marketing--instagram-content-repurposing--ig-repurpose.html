ig-repurpose

separate

Turn one long asset - a YouTube video, podcast, livestream, newsletter, blog post or client call - into a week of reels and carousels. Use when the user says "repurpose this", "turn this into reels", "I have a video/podcast/ transcript", "cut this up", or pastes something long and wants it on Instagram.

When to use

  • repurpose long assets
  • turn videos into reels
  • convert podcasts to carousels
  • cut up transcripts
  • create Instagram content from newsletters

When not to use

  • summarizing videos
  • creating posts that reference the source asset
