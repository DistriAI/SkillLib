govern-topic-selection

separate

Use when deciding whether a project fits Governance: An International Journal of Policy, Administration, and Institutions and how to frame it. The test is comparative/institutional significance for how the state governs — not single-country administrative novelty. Helps frame the question; it does not collect data.

When to use

  • Choosing among possible projects or framings for a Governance submission
  • Pressure-testing fit before investing in a project
  • Deciding how to frame an empirical finding so it speaks to comparative governance
  • Evaluating if a topic is in scope vs. corporate governance or a literature review

When not to use

  • Collecting data
  • Corporate governance (firm boards, shareholders, corporate compliance)
  • Literature review / state-of-the-field essay
  • Pure bibliometric / citation-mapping study
  • Practitioner how-to with no theoretical contribution
  • Pure regulatory-instrument design with no comparative/institutional reach
