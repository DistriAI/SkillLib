asplos-artifact-evaluation

separate

Use when preparing an ASPLOS artifact for the post-acceptance evaluation committee — writing the ae.tex Artifact Appendix with software/hardware/dataset dependencies, targeting the Available / Functional / Reproducible badges, archiving on a public repository, and planning the collaborative back-and-forth with evaluators.

When to use

  • preparing ASPLOS artifact
  • writing ae.tex Artifact Appendix
  • targeting Available, Functional, Reproducible badges
  • archiving on public repository
  • planning collaborative back-and-forth with evaluators
  • defining software, hardware, and dataset dependencies
  • creating package layout for evaluators
  • mitigating hardware-dependent claims

When not to use

  • pre-acceptance submission preparation
  • anonymizing artifact pointers in the submission itself
