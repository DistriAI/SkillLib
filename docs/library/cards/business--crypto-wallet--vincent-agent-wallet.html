vincent-agent-wallet

separate

Use this skill to safely create a wallet the agent can use for transfers, swaps, and any EVM chain transaction. Also supports raw signing and polymarket betting.

When to use

  • Creating agent wallets
  • Transferring ETH or tokens
  • Swapping tokens on DEXs
  • Interacting with smart contracts
  • Raw message signing
  • Polymarket prediction market trading
  • Checking token balances
  • Setting spending policies

When not to use

  • Exposing private keys to the agent
