jetson-video-capability

separate

Use when Jetson codec, profile, chroma, bit-depth, dimension, engine-count, or operational support must be reconciled from live APIs, authenticated NVIDIA samples, and NVIDIA documentation; also applies the content-DRM scope.

When to use

  • Jetson codec capability reconciliation
  • Profile and chroma support verification
  • Bit-depth and dimension support checks
  • Engine-count and operational support analysis
  • Hardware encode/decode of non-DRM bitstreams
  • PyNvVideoCodec capability queries
  • Native Video Codec SDK capability reports
  • Documentation cross-checking for product support

When not to use

  • PSNR, SSIM, or objective quality metrics
  • Netflix, Widevine, or PlayReady content-DRM playback
  • CDM or secure-playback requirement descriptions
  • Browser, DRM module, or workaround recommendations
  • Package installation or mutation of setup files
  • Infering SKU from memory or engine count
