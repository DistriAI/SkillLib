acl-topic-selection

separate

Use when deciding whether a project fits ACL versus EMNLP, NAACL, EACL, TACL, Computational Linguistics, COLM, or an ML venue, covering contribution typing for NLP work, long-versus-short paper choice, the annual theme track, Findings-tier expectations, and sharpening the computational-linguistics framing before writing starts.

When to use

  • deciding venue fit for NLP projects
  • typing contributions for NLP work
  • choosing between long and short papers
  • aligning with annual theme tracks
  • assessing Findings-tier expectations
  • sharpening computational-linguistics framing

When not to use

  • writing the first draft
  • conducting experiments
  • performing related work search
  • evaluating artifacts
