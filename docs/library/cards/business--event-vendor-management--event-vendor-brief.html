event-vendor-brief

authentic

Brief an event supplier so they quote accurately and deliver what you pictured — the outcome, the constraints, the deliverables, and the questions you need answered in the quote. Use when asked to brief an event supplier, write a vendor brief for caterers, AV, or production, send an RFP for an event, or compare supplier quotes that are not comparable. Produces the outcome brief, the deliverables and constraints, the quote-response template that makes bids comparable, the evaluation criteria, and the questions each supplier must answer.

When to use

  • brief an event supplier
  • write a vendor brief for caterers
  • write a vendor brief for AV
  • write a vendor brief for production
  • send an RFP for an event
  • compare supplier quotes that are not comparable
