model-prompt-pack

authentic

Use when asked to write prompts for image-to-3D or text-to-3D tools, generate 3D models of a topic's parts, plan the assets for a 3D explorer, or build a labelled parts list with sources. Produces prompts for image-to-3D tools, one per object, plus a parts list for labelling in which every label names a trusted source, and states that generated geometry is illustrative, not authoritative. Second step of explorer-pipeline.

When to use

  • write prompts for image-to-3D or text-to-3D tools
  • generate 3D models of a topic's parts
  • plan the assets for a 3D explorer
  • build a labelled parts list with sources
