who-is-this

separate

Research a person''s public track record and give a short credibility assessment. Use only when the user explicitly invokes /who-is-this.

When to use

  • Research a person's public track record
  • Give a short credibility assessment
  • Verify identity via bio, company, location, and photo
  • Scrape GitHub, LinkedIn, and X profiles
  • Extract key facts and determine archetype

When not to use

  • Use built-in search, fetch, or a browser
  • Guess a person if identity is missing
  • Invent a profile if data is missing or private
  • Include congrats, logo spam, or paid press
  • Use tables, sub-bullets, or tweet dumps in output
