run-paid-campaigns-apply-and-log

separate

Step of the run-paid-campaigns playbook: stages the week's approval items, applies only what the marketer approves and keeps the change log. Run run-paid-campaigns instead; not for direct use.

When to use

  • Staging approval items
  • Applying marketer-approved changes
  • Keeping the change log
  • Managing Meta budget changes
  • Managing Meta creative replacements
  • Managing Meta ad pushes
  • Logging decisions and outcomes

When not to use

  • Direct use
  • Approving on the marketer's behalf
  • Pausing on own judgement or schedule
  • Reverting for a kill
  • Breaking the connector rule
