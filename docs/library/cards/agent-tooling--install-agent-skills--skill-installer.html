skill-installer

combined

Install Codex skills into $CODEX_HOME/skills from a curated list or a GitHub repo path. Use when a user asks to list installable skills, install a curated skill, or install a skill from another repo (including private repos). Instala, valida, registra e verifica novas skills no ecossistema. 10 checks de seguranca, copia, registro no orchestrator e verificacao pos-instalacao.

When to use

  • When the user mentions "instalar skill" or related topics
  • When the user mentions "install skill" or related topics
  • When the user mentions "registrar skill" or related topics
  • When the user mentions "nova skill" or related topics
  • When the user mentions "new skill" or related topics
  • When the user mentions "adicionar skill ao ecossistema" or related topics

When not to use

  • The task is unrelated to skill installer
  • A simpler, more specific tool can handle the request
  • The user needs general-purpose assistance without domain expertise
  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.

Skill page

Conflict

The copies describe two different procedures. The openai, foryourhealth111-pixel, and composio-community copies are near-identical Codex skill installers that use list-skills.py and install-skill-from-github.py to install from openai/skills or arbitrary GitHub paths. The sickn33 copy is a different enterprise-grade installer with a 6-layer validation pipeline, 11-step install, registry, backups, rollback, health checks, and dry-run, using install_skill.py, validate_skill.py, detect_skills.py, and package_skill.py. Crowning one would hide a real alternative.
