make-content-two-pass-edit

separate

Edits an existing draft in order: a substance pass (arguable thesis, swap test, fakes removed, CTA fit), a claims and fact check that cuts or softens unproven lines, a readability and voice-match pass, then an AI-tell sweep, with an edit note listing open gaps. Use alone when you already have a finished draft and the brand's voice samples and approved claims; otherwise run make-content.

When to use

  • editing existing drafts
  • substance pass
  • claims and fact check
  • readability and voice-match pass
  • AI-tell sweep
  • refresh redline
  • repurposed set

When not to use

  • creating new content from scratch
  • when brand voice samples or approved claims are missing
