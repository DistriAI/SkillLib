prl-methods

separate

Use when deciding what methodological detail belongs in a Physical Review Letters body versus Supplemental Material, so a physicist can trust the result without the Letter becoming a long paper. Partitions methods; does not design figures or run analysis.

When to use

  • Deciding methodological detail placement in PRL body vs SM
  • Partitioning methods for trust-minimum
  • Compressing apparatus or derivation details
  • Identifying load-bearing methodological elements
  • Pre-empting obvious objections in the body
  • Formatting uncertainty statements
  • Creating SM pointers for exhaustive details

When not to use

  • Designing figures
  • Running analysis
