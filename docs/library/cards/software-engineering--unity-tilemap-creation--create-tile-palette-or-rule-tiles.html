create-tile-palette-or-rule-tiles

separate

Create a 2D tile palette from sprites or textures, or make tiles change based on their neighbours. Use for tile palettes or self-connecting tiles, even when the user doesn't name them.

When to use

  • organize tiles for 2D level design
  • create rectangular grid layout
  • create hexagonal grid layout
  • create isometric grid layout
  • create isometric Z as Y grid layout
  • create blank RuleTile
  • create HexagonalRuleTile
  • create IsometricRuleTile
