setup-offline-profile

separate

Use when the user wants to enable offline mode for a Power Apps mobile app and create a Mobile Offline Profile in Dataverse — designs per-table row scope, relationships, columns, and sync frequency through a 3-gate approval flow.

When to use

  • enable offline mode for Power Apps mobile app
  • create Mobile Offline Profile in Dataverse
  • design per-table row scope
  • configure relationships and columns
  • set sync frequency
  • write offline-profile.json

When not to use

  • modify power.config.json
  • scaffold duplicate app-owned offline runtime code
  • custom filter mode
  • user/team membership assignment
  • row-count download estimation
  • web-only projects
