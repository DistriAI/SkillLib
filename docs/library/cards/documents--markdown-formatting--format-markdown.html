format-markdown

separate

Summarize and format markdown files, then apply mkdocs/material-compatible structural spacing fixes for math, list, and table blocks. Outputs to {filename}_formatted.md by default.

When to use

  • Summarize markdown files
  • Format markdown files
  • Apply mkdocs/material-compatible structural spacing fixes
  • Fix math, list, and table blocks
  • Analyze content for readability
  • Add metadata or structural aids
  • Improve headings, bold, lists, tables
  • Run structural compatibility script

When not to use

  • Rewriting text content in structural-fix mode
  • Modifying non-markdown files
