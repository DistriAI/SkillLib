transcript-fixer

separate

Corrects ASR/STT transcription errors — homophones, garbled terms, person-name errors, mixed Chinese/English — with dictionary rules plus Claude's built-in AI, no external API key required. Use to clean meeting notes, lecture transcripts, interviews or speech-recognition text, even when the user only says "fix this transcript". Not for structuring a clean transcript into minutes (use meeting-minutes-taker).

When to use

  • Correcting ASR/STT transcription errors
  • Fixing homophones and garbled terms
  • Correcting person-name errors
  • Handling mixed Chinese/English text
  • Cleaning meeting notes
  • Cleaning lecture transcripts
  • Cleaning interviews
  • Cleaning speech-recognition text

When not to use

  • Structuring a clean transcript into minutes
