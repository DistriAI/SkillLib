separate

Manage n8n workflows and automations via API. Use when working with n8n workflows, executions, or automation tasks - listing workflows, activating/deactivating, checking execution status, manually triggering workflows, or debugging automation issues.

When to use

  • listing workflows
  • activating/deactivating workflows
  • checking execution status
  • manually triggering workflows
  • debugging automation issues
  • creating complete workflows
  • validating workflow structure
  • performance optimization

When not to use

  • creating placeholder nodes
  • generating workflows with only TODO comments
  • making incomplete workflows requiring manual node addition
  • using text-only nodes as substitutes for real functionality
