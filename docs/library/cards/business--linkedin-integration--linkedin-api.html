linkedin-api

separate

LinkedIn API integration with managed OAuth. Share posts, manage profile, run ads, and access LinkedIn features. Use this skill when users want to share content on LinkedIn, manage ad campaigns, get profile/organization information, or interact with LinkedIn's platform. For other third party apps, use the api-gateway skill (https://clawhub.ai/byungkyu/api-gateway). Requires network access and valid Maton API key.

When to use

  • share content on LinkedIn
  • manage ad campaigns
  • get profile/organization information
  • interact with LinkedIn's platform
  • upload media
  • access the Ad Library

When not to use

  • other third party apps
