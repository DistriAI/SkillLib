economic-science

separate

Use when targeting 《经济科学》(Economic Science) or deciding whether a Chinese social-science/econ/management manuscript fits this journal. Applies the journal's fit, framing, method, house-style, official-submission-check, and desk-reject heuristics.

When to use

  • targeting 《经济科学》
  • deciding if a manuscript fits the journal
  • rewriting a manuscript for the journal's narrative
  • listing high-frequency rejection risks
  • checking official submission requirements
  • evaluating method and evidence standards

When not to use

  • replacing the latest official submission guidelines
  • submitting to other journals like 《经济研究》 or 《经济评论》
  • using secondary submission website formats
