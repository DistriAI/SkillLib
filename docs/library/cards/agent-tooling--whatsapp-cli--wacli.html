wacli

separate

Send WhatsApp messages to other people or search/sync WhatsApp history via the wacli CLI (not for normal user chats).

When to use

  • Send WhatsApp messages to other people
  • Search WhatsApp history
  • Sync WhatsApp history
  • Backfill WhatsApp history
  • List WhatsApp chats
  • Send WhatsApp files

When not to use

  • Normal user chats
  • Routine user chats
  • Chatting with the user on WhatsApp
