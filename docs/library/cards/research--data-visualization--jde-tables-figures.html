jde-tables-figures

separate

Use when designing the main exhibits for a Journal of Development Economics (JDE) manuscript — figure-forward presentation of treatment effects, heterogeneity, and event studies for development settings, with self-contained notes. Shapes exhibits; it does not run the estimation.

When to use

  • designing main exhibits for JDE manuscripts
  • figure-forward presentation of treatment effects
  • presenting heterogeneity across subgroups
  • creating event study plots
  • designing self-contained exhibit notes
  • scaling effects to welfare-relevant units
  • creating spatial or map figures

When not to use

  • running the estimation
