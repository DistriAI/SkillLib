find

combined

Helps users discover and install agent skills when they ask questions like "how do I do X", "find a skill for X", "is there a skill that can...", or express interest in extending capabilities. This skill should be used when the user is looking for functionality that might exist as an installable skill. Find and install skills from the Orthogonal skill library. Use when you need capabilities you don't have, want to discover available skills, or need to add new tools to your agent.

When to use

  • Asks "how do I do X" where X might be a common task with an existing skill
  • Says "find a skill for X" or "is there a skill for X"
  • Asks "can you do X" where X is a specialized capability
  • Expresses interest in extending agent capabilities
  • Wants to search for tools, templates, or workflows
  • Mentions they wish they had help with a specific domain (design, testing, deployment, etc.)

When not to use

  • creating new skills
  • updating installed skills
  • checking for skill updates

Skill page

Conflict

The three copies describe two different skill ecosystems. The gooseworks-ai copy targets the Orthogonal library using the `orth` CLI, requires a GOOSEWORKS_API_KEY from ~/.gooseworks/credentials.json, and installs to ~/.openclaw/skills. The LeoYeAI and FreedomIntelligence copies are identical and target the open agent skills ecosystem using `npx skills`, with no API key requirement and a different install syntax. Because the procedures use different CLIs, authentication, and install paths, crowning one would hide a real alternative.
