python-code-reviewer

authentic

Review, run, debug, and verify approved Python modeling code against its code plan, data contract, method decision, risk conditions, and experiment outputs, saving one compact JSON review.

When to use

  • Review Python modeling code
  • Run and debug Python code
  • Verify code against code plan
  • Check input and output contracts
  • Evaluate method alignment
  • Assess reproducibility
  • Save JSON review

When not to use

  • Approve toy diagnostic reference as official baseline
  • Silently change mathematical meaning
  • Create success logs beyond the review JSON
  • Pad evidence to reach a count
  • Fabricate execution or outputs
