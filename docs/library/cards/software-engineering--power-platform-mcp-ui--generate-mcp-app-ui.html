generate-mcp-app-ui

separate

Generate a single-file MCP App widget for an MCP tool, with either bundled runtime code or user-approved public CDN imports. Describe the visual and provide a plain structured payload or a full tool result with content, structuredContent, and meta.

When to use

  • generate mcp app widget
  • create html widget for tool
  • build tool visualization
  • display tool output visually
  • self-contained widget generation
  • cdn-based widget generation

When not to use

  • standalone web applications
  • multi-page navigation
  • search bars duplicating chat input
  • re-listing LLM text explanations
