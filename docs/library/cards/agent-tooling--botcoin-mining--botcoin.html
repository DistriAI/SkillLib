Conflict

The two copies describe different products and protocols that happen to share the name 'botcoin'. The BankrBot copy is a stake-gated mining flow on Base using a Bankr API key, a coordinator endpoint, and a specific BOTCOIN token address. The LeoYeAI copy is a puzzle game on botfarmer.ai using Ed25519 keys, X/Twitter verification, and a $BOTFARM token. They disagree on the base URL, authentication method, token address, and core mechanics, so crowning one would hide a real alternative.
