When to use

  • Explore methodological approaches
  • Structured analysis of research questions

  • Assess scope of methodological decisions
  • Problem decomposition for research questions

When not to use

  • Planning implementation
  • Answering how to implement
  • Proceeding directly to planning when requirements are clear
