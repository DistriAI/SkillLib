imfer-referee-strategy

separate

Use when anticipating the objections a dual academic/policy IMF Economic Review (IMFER) referee will raise, so a manuscript pre-empts them before submission or addresses them in revision. Plans the defense; it does not draft the response letter (imfer-rebuttal) or run the submission preflight (imfer-submission).

When to use

  • stress-test a paper against referees before submission
  • decide which robustness checks to run before submitting
  • map referee concerns to concrete responses after R&R
  • understand how IMFER's double-blind, dual-audience review shapes strategy
  • pre-empt predictable objections in the paper
  • war-game the design and policy claim
  • triage which checks to run before vs. after submission
  • make reproducibility visible to defuse restricted-data concerns

When not to use

  • draft the response letter (imfer-rebuttal)
  • run the submission preflight (imfer-submission)
