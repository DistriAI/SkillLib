core-fix-skill-docs

separate

Internal maintenance support for checking and fixing generated Rust skill documentation references. Use only when explicitly invoked by /fix-skill-docs.

When to use

  • checking missing reference files in dynamic skills
  • fixing generated Rust skill documentation references
  • scanning skills directory for SKILL.md references
  • fetching documentation from docs.rs
  • removing invalid references from SKILL.md

When not to use

  • general Rust code generation
  • non-Rust skill documentation
  • invocation without /fix-skill-docs command
