hsb-app

separate

Discover and run Holoscan Sensor Bridge example applications on a connected devkit. Filters available apps by the user's platform, HSB software version, board type, and sensors. Supports timed execution, failure analysis, code-edit suggestions, and iterative re-runs.

When to use

  • Discover HSB example applications
  • Run HSB applications on devkit
  • Filter apps by platform and sensors
  • Monitor application output
  • Analyze application failures
  • Suggest code or environment edits
  • Iterative re-runs of applications
  • Generate session report

When not to use

  • Devkit setup
  • SSH configuration
  • Demo container building
  • Host configuration
  • Board connection setup
