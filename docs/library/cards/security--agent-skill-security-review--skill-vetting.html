skill-vetting

combined

Vet ClawHub skills for security and utility before installation. Use when considering installing a ClawHub skill, evaluating third-party code, or assessing whether a skill adds value over existing tools. Vet an agent skill before installing it — read the SKILL.md and any scripts for the red-flag patterns (credential access, obfuscation, exfiltration, prompt injection), audit its blast radius, and produce a risk-tiered verdict. Use when asked is this skill safe to install, vet this SKILL.md, review this skill from a marketplace, or check what this skill can do to my machine. Produces the risk classification with quoted evidence, the permission-surface audit, the red-flag checklist results, and an install/sandbox/reject recommendation.

When to use

  • Vetting ClawHub skills
  • Evaluating third-party code
  • Assessing skill utility
  • Security risk evaluation
  • Prompt injection detection
  • Manual code review
  • Utility assessment

When not to use

  • Installing skills without vetting
  • Rationalizing prompt injection findings

Skill page

Conflict

Both copies vet agent skills before install, but they are different procedures. The first is a judgment framework that reads the skill folder, sweeps for red flags, audits blast radius, and produces a tiered verdict with quoted evidence and a human-decision gate. The second is a ClawHub-specific workflow that downloads to /tmp, runs a bundled scanner, applies immutable prompt-injection rules, assesses utility against existing tools, and uses a security/utility decision matrix. Each has material steps the other lacks, so crowning one would hide a real alternative.
