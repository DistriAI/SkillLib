read-codex-history

separate

Reads, searches and exports local OpenAI Codex history without continuing work: session inventory, timelines, verbatim user input, indexed search, and rollout identity/fork lineage. Use when the user asks what they told Codex, wants a Session ID, or evidence of what a run did. Not for Claude Code (use read-claude-code-history); with no platform named, start at local-conversation-history.

When to use

  • session inventory
  • timelines
  • verbatim user input
  • indexed search
  • rollout identity/fork lineage
  • finding what user told Codex
  • getting Session ID
  • evidence of what a run did

When not to use

  • Claude Code history
  • continuing the old task
  • changing the project
