obsidian-markdown

authentic

Create and edit Obsidian Flavored Markdown with wikilinks, embeds, callouts, properties, and other Obsidian-specific syntax. Use when working with .md files in Obsidian, or when the user mentions wikilinks, callouts, frontmatter, tags, embeds, or Obsidian notes.

When to use

  • Create and edit Obsidian Flavored Markdown
  • Working with .md files in Obsidian
  • Using wikilinks, callouts, frontmatter, tags, embeds, or Obsidian notes
  • Adding frontmatter with properties
  • Linking related notes using wikilinks
  • Embedding content from other notes, images, or PDFs
  • Adding callouts for highlighted information
  • Using Obsidian-specific syntax like comments, highlights, math, and diagrams

When not to use

  • Standard Markdown (headings, bold, italic, lists, quotes, code blocks, tables)
