icdm-related-work

separate

Use when positioning an ICDM (IEEE International Conference on Data Mining) paper's related work - lineage against prior ICDM editions and IEEE data-mining neighbors, the mechanism-contrast novelty sentence, avoiding KDD/SDM/CIKM/WSDM venue misattribution, and citing your own prior work in the third person so the section stays triple-blind-safe.

When to use

  • positioning ICDM related work
  • contrasting mechanisms with prior work
  • verifying citation venues on dblp
  • avoiding venue misattribution
  • writing triple-blind-safe self-citations
  • handling concurrent work
  • pruning citations for page limits

When not to use

  • positioning by benchmark leaderboard results
  • attributing KDD/SDM/CIKM/WSDM work to ICDM
