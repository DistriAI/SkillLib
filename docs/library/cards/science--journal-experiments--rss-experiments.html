rss-experiments

separate

Use when designing or auditing the experimental campaign for an RSS (Robotics: Science and Systems) paper — hypothesis-shaped robot experiments, trial protocols and per-condition counts, mechanism-isolating ablations, simulation-versus-hardware evidence splits, and failure attribution that supports a scientific claim rather than a demo reel.

When to use

  • designing experimental campaigns for RSS papers
  • auditing RSS paper experiments
  • defining hypothesis-shaped robot experiments
  • establishing trial protocols and per-condition counts
  • designing mechanism-isolating ablations
  • splitting simulation versus hardware evidence
  • performing failure attribution
  • budgeting hardware trial time

When not to use

  • creating demo reels
  • showcasing systems without testing claims
  • using post-hoc success criteria
  • averaging simulation and hardware results
  • reporting bare means without dispersion
  • using anecdotal trial counts
