release-kotlin-library

separate

Use when preparing, publishing, or checking readiness for a Kotlin library release, including verifying its gradle-maven-publish-plugin prerequisite, reconciling changelogs and API snapshots, and checking publication.

When to use

  • preparing a Kotlin library release
  • publishing a Kotlin library release
  • checking readiness for a Kotlin library release
  • verifying gradle-maven-publish-plugin prerequisite
  • reconciling changelogs
  • reconciling API snapshots
  • checking publication

When not to use

  • installing or migrating publishing plugins
  • creating a changelog if not specified
  • treating non-Metalava API dumps as snapshots
  • running both local publication and tag-triggered CI
