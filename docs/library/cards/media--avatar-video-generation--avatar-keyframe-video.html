avatar-keyframe-video

separate

将法天象地、同源巨大法相或角色力量显现的视觉参考制作成连续关键帧，再使用用户选择或可用的图生视频工具分段生成、检查和合成动作视频，不绑定成片平台。适用于本体与法相同框、领域展开、凝实与同步出招；不负责整部小说改编或普通图片轮播。

When to use

  • 法天象地连续帧成片
  • 本体与法相同框
  • 领域展开
  • 凝实与同步出招
  • 关键帧制作
  • 分段视频生成
  • 动作视频合成

When not to use

  • 整部小说改编
  • 普通图片轮播
