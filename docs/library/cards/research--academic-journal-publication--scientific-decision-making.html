scientific-decision-making

separate

Use when targeting 《科学决策》(Scientific Decision Making — 中国航天系统科学与工程研究院等主办的决策科学月刊) or deciding whether a Chinese decision-science/policy-evaluation manuscript fits this venue. Encodes the journal's fit, framing, footnote house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting 《科学决策》
  • deciding if a manuscript fits 《科学决策》
  • rewriting a manuscript for 《科学决策》
  • listing desk-reject risks for 《科学决策》
  • checking 《科学决策》 submission requirements

When not to use

  • replacing the latest official submission guidelines
  • targeting 《中国软科学》
  • targeting 《科学学研究》
  • targeting 《科学学与科学技术管理》
  • targeting 《科研管理》
  • targeting 《科学管理研究》
  • targeting 《证券市场导报》
  • targeting 《中国管理科学》
