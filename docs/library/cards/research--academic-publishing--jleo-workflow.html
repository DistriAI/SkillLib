jleo-workflow

separate

Use when deciding which jleo-* sub-skill to invoke next, or when sequencing manuscript work from topic selection through rebuttal for a Journal of Law, Economics, and Organization (JLEO) submission. Routes — it does not replace — the specialized skills.

When to use

  • deciding which jleo-* sub-skill to invoke next
  • sequencing manuscript work from topic selection through rebuttal
  • diagnosing current bottleneck against law-economics-organization bar
  • switching into revision mode after a decision letter
  • determining if paper belongs at JLEO versus sibling journals

When not to use

  • replacing specialized jleo-* skills
  • performing the actual manuscript writing or analysis
