strudel-music

separate

Audio deconstruction and composition via Strudel live-coding. Decompose any audio into stems, extract samples, compose with the vocabulary, render offline to WAV/MP3.

When to use

  • Compose from natural language
  • Stream a saved composition into Discord VC
  • Show available compositions with metadata
  • Manage sample packs
  • Play a setlist in Discord VC
  • Reverse-engineer any audio track into stems, samples, and generative programs
  • Render offline to WAV/MP3

When not to use

  • Run the renderer inline in your main conversation
