material

combined

Edit material and shader properties across Built-in/URP/HDRP Google's Material Design with layered surfaces, dynamic theming, built-in motion, and responsive cross-platform patterns.

When to use

  • Changing how a surface looks
  • Tweaking material parameters
  • Swapping shaders
  • Creating materials
  • Assigning materials
  • Setting material colors
  • Setting material textures
  • Querying material properties

When not to use

  • Deleting material assets
  • Per-object material instance editing

Skill page

Conflict

The two copies use the same skill name for completely different tasks. The first is a Unity engine skill for editing material and shader properties via a specific API (material_create, material_set_color, etc.). The second is a web design skill for authoring Material Design system guidelines (tokens, accessibility, component rules). They do not overlap in procedure, parameters, or domain, so crowning one would hide a real alternative.
