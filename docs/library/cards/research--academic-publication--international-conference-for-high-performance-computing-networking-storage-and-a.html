Use when targeting International Conference for High Performance Computing, Networking, Storage and Analysis (SC) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for HPC flagship.

When to use

  • targeting SC
  • deciding if a manuscript fits SC
  • conference-fit read for HPC manuscripts
  • re-framing journal or arXiv style into SC narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues for SC
  • routing HPC flagship contributions to SC

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • routing architecture-only work to ISCA/HPCA
  • routing cross-layer PL/OS/architecture mechanisms to ASPLOS
  • routing distributed cloud/HPC systems below supercomputing scale to HPDC
