filesystem-context

authentic

This skill should be used when agent work needs file-backed context: durable scratchpads, tool-output offloading, just-in-time discovery, cross-agent handoff files, filesystem memory, or cleanup policies for context stored outside the prompt.

When to use

  • durable scratchpads
  • tool-output offloading
  • just-in-time discovery
  • cross-agent handoff files
  • filesystem memory
  • cleanup policies for context stored outside the prompt
  • persisting state across long trajectories
  • sharing information between sub-agents

When not to use

  • semantic cross-session memory
  • entity tracking
  • temporal knowledge graphs
  • conversation summarization
  • compaction
  • durable handoff wording
  • token-efficiency tactics that do not require file-backed storage
  • multi-agent topology or handoff protocol design
