separate

Use when auditing an AAMAS main-track submission for OpenReview readiness, the 8-page-plus-references limit, the full-paper versus 2-page extended-abstract choice, double-blind anonymity, the supplementary zip cap, track fit across the AAAI/JAAMAS/Blue Sky tracks, dual-submission rules, and desk-reject triggers before upload.

When to use

  • AAMAS main-track submission audit
  • OpenReview readiness check
  • 8-page-plus-references limit verification
  • Full-paper versus 2-page extended-abstract choice
  • Double-blind anonymity enforcement
  • Supplementary zip cap verification
  • Track fit across AAAI/JAAMAS/Blue Sky tracks
  • Dual-submission rules and desk-reject triggers

When not to use

  • Workshop submissions
  • Tutorial submissions
  • Neighbor conference submissions
