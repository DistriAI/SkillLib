aeri-theory-model

separate

Use when a model — a full theory paper's argument or the structural/conceptual scaffolding behind an empirical AER: Insights short-format manuscript — needs to be made minimal, so it carries the single insight in a few pages. Keeps only what the insight requires; it does not develop a general framework.

When to use

  • making a theory paper's argument minimal
  • creating structural scaffolding for an empirical AER: Insights manuscript
  • tightening a model for a single result
  • reducing a model that has grown beyond what the result needs
  • freeing word budget for result and identification

When not to use

  • developing a general framework
  • creating foundational framework papers for AER or field journals
