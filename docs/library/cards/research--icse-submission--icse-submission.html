icse-submission

separate

Use when auditing an ICSE research-track submission for HotCRP readiness, covering the mandatory abstract deadline, the 10-page-plus-2-reference-page IEEE format, double-anonymous rules, the open-science Data Availability section, supplementary uploads, and desk-reject triage before the AoE cutoff.

When to use

  • ICSE research-track submission audit
  • HotCRP readiness check
  • Abstract deadline verification
  • 10-page-plus-2-reference-page format check
  • Double-anonymous rules compliance
  • Open-science Data Availability section review
  • Supplementary uploads check
  • Desk-reject triage

When not to use

  • Non-ICSE conference submissions
  • ICSE industry track submissions
  • Post-submission review process
  • Paper writing or content creation
