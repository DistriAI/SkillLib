roi-calculator

separate

Use when the user asks to "calculate influencer ROI", "prove campaign value", or "what was our ROAS"; produces direct ROI/ROAS, earned media value, attribution-modeled revenue, LTV-based ROI, and a stakeholder-ready summary. Not for building the full slide/written report — use report-generator. 达人营销ROI计算/投资回报测算

When to use

  • calculate influencer ROI
  • prove campaign value
  • what was our ROAS
  • measuring or projecting influencer campaign ROI
  • justifying or defending budgets
  • comparing ROI across campaigns or channels
  • evaluating individual influencer or tier value
  • preparing executive-level ROI numbers

When not to use

  • building the full slide/written report
