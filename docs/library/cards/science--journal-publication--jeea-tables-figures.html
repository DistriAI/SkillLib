jeea-tables-figures

separate

Use when building or revising tables and figures for a Journal of the European Economic Association (JEEA) manuscript so exhibits read clean for a general-interest audience and respect JEEA house norms. Shapes exhibits; it does not change the underlying estimates.

When to use

  • building tables for JEEA manuscripts
  • revising figures for JEEA manuscripts
  • formatting exhibits for general-interest audiences
  • creating three-line tables
  • generating event-study plots
  • creating model-fit overlays
  • creating counterfactual curves
  • ensuring exhibits support the argument in-text

When not to use

  • changing underlying estimates
  • over-formatting to mimic typeset journal style
  • using significance asterisks
  • using boldface for significance
  • dumping exhibits at the end rather than supporting the argument
