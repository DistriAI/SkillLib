burpsuite-project-parser

combined

Searches and explores Burp Suite project files (.burp) from the command line. Use when searching response headers or bodies with regex patterns, extracting security audit findings, dumping proxy history or site map data, or analyzing HTTP traffic captured in a Burp project.

When to use

  • Extracting security audit findings from Burp projects
  • Dumping proxy history or site map data
  • Analyzing HTTP traffic captured in a Burp project file

The trailofbits copy is the more complete and operationally rigorous procedure: it defines the wrapper script's exit-code contract, a control-query method to distinguish a genuinely empty result from an unloaded parser, and pipefail/PIPESTATUS handling. The sickn33 copy adds a distinct, material constraint set that the trailofbits copy does not state: a hard 1000-character body truncation rule, a mandatory jq truncation pattern, and a catalog note that the supporting scripts are not bundled and must be resolved from an external installation. Neither copy is a pure reproduction of the other; crowning one would hide either the exit-code/control-query safety procedure or the body-truncation and missing-supporting-material constraints.
