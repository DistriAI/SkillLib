mw-rebuttal

separate

用于回应《管理世界》R&R 审稿意见，产出逐条回复信并同步修订正文。Use when 收到《管理世界》退修通知、已有 1—3 份审稿意见和编委意见、需要撰写逐条回复信并对齐正文修改、或处理多位审稿人意见冲突时使用。锚定《管理世界》国务院发展研究中心主办、管理学与经济学并重、规范实证大刊的审稿语境，落实"先修订正文、再写导览式回复信"的顺序原则，对识别、机制、政策三条线实质补强，逐条标注正文修订位置，并审慎控制不接受意见的比例。 本技能服务于《管理世界》(Management World, MW)。

When to use

  • 收到《管理世界》退修通知
  • 已有 1—3 份审稿意见和编委意见
  • 撰写逐条回复信并对齐正文修改
  • 处理多位审稿人意见冲突
  • 落实先修订正文再写回复信的顺序
  • 对识别、机制、政策三条线实质补强
  • 逐条标注正文修订位置
  • 审慎控制不接受意见的比例

When not to use

  • 一行式“已修改”回复
  • 回复信比正文还长
  • 三个审稿人意见冲突全部接受导致正文自相矛盾
  • 把不接受的回复写得很 defensive
  • 仅口头辩护不补分析
  • 把原结果换个说法
  • 加一句“建议政府重视”
  • 仅在回复信致谢不动正文
