govern-submission

separate

Use when running the final pre-submission preflight for a Governance: An International Journal of Policy, Administration, and Institutions manuscript on the Wiley submission system — double-blind anonymization plus separate title page, the ≤ 9,000-word cap, ~150-word abstract, the Data Availability Statement, ORCID, and scope self-check. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • double-blind anonymization check
  • separate title page verification
  • word count cap verification
  • abstract length check
  • Data Availability Statement verification
  • ORCID readiness check
  • scope self-check

When not to use

  • drafting content
