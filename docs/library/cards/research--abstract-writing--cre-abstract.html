cre-abstract

separate

Use when drafting or revising the 中文摘要 or 英文 abstract for a 《中国农村经济》(China Rural Economy, CRE) manuscript — the CSSCI 权威三农期刊 run by 中国社会科学院农村发展研究所. 当摘要写成"为乡村振兴提供新视角"式套话、缺核心数据 / 识别策略 / 量化发现、或中英文语义不对齐时使用。Enforces the five-sentence pattern, requires quantified household-survey findings (CHIP / CFPS / CLDS / CRRS), and forbids empty-significance phrases.

When to use

  • Drafting Chinese abstract for CRE manuscript
  • Revising English abstract for CRE manuscript
  • Fixing abstracts with empty-significance phrases
  • Aligning Chinese and English abstract semantics
  • Ensuring abstracts include core data and identification strategies
  • Ensuring abstracts include quantified findings

When not to use

  • Tasks not related to CRE manuscript abstracts
