Skill page

Conflict

The two copies implement the same Gmail operations (read, send, search, labels, drafts) but through fundamentally different mechanisms. The first copy (benchflow-ai) uses local Node.js CLI scripts with local OAuth token management and multi-account support via a --account flag. The second copy (LeoYeAI) uses a remote Maton API gateway with a MATON_API_KEY and connection management via ctrl.maton.ai. They disagree on authentication (local token.json vs. remote API key), execution environment (local npm scripts vs. remote HTTP calls), and multi-account handling (--account flag vs. Maton-Connection header). Crowning one would hide a valid alternative implementation.
