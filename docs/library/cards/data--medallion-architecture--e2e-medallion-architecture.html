e2e-medallion-architecture

authentic

Plans and builds end-to-end Fabric data platforms on the Bronze, Silver, and Gold medallion pattern: ingestion to analytics, PySpark and Delta layers, pipeline orchestration, per-layer Spark tuning, Materialized Lake View versus notebook choices for Silver and Gold, and Direct Lake handoff. Use for layered architecture design, planning and recommendations. For questions over an existing Power BI report use fabriciq.

When to use

  • layered architecture design

  • ingestion to analytics
  • PySpark and Delta layers
  • pipeline orchestration
  • per-layer Spark tuning
  • Materialized Lake View versus notebook choices
  • Direct Lake handoff

When not to use
