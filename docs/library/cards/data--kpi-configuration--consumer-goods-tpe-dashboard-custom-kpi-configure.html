consumer-goods-tpe-dashboard-custom-kpi-configure

separate

Customize the Trade Promotion Effectiveness (TPE) Analytics dashboards' generic KPI slots (Promotion Measure 1-3, Tactic Measure 1-2) with customer-chosen KPI measure codes and display names, without touching the shipped base model. Use when a customer/admin wants to \"customize TPE dashboards\", \"change the KPIs on the Promotion/Tactic Analysis dashboard\", or \"swap in our own measure codes on the TPE dashboard\".

When to use

  • customize TPE dashboards
  • change the KPIs on the Promotion/Tactic Analysis dashboard
  • swap in our own measure codes on the TPE dashboard
  • clone base TPE Analytics semantic-model parameters
  • clone base TPE Analytics visualizations
  • clone base TPE Analytics dashboards
  • apply per-measure overrides to KPI slots

When not to use

  • installing the TPE Analytics app
  • installing the Extended TPM Analytics SDM
  • creating underlying measure data
  • mutating the shipped base model in place
