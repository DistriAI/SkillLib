factory-recover

separate

Experimental workflow for finding and resuming interrupted coding runs. Use after an agent host restart or an interrupted automation.

When to use

  • finding interrupted coding runs
  • resuming incomplete automation
  • recovering after agent host restart
  • checking candidate run status
  • verifying worktree integrity
  • rechecking external state before retry

When not to use

  • restarting every stopped task
  • restoring canceled work
  • granting new authorization
  • resetting, cleaning, or stashing worktrees
  • attaching another task's branch
  • repeating completed writes, replies, approvals, merges, or deployments
