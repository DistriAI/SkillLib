factory-human-digest

separate

Experimental workflow for summarizing work that still needs human judgment across configured pull requests, issues, feedback, errors, and delivery signals. Use for a human decision queue or bounded review.

When to use

  • summarizing work needing human judgment
  • human decision queue
  • bounded review
  • grouping patterns by user impact
  • reporting recurring themes
  • identifying items held for missing context or risk

When not to use

  • replying to items
  • approving or merging pull requests
  • assigning or closing issues
  • changing status
  • notifying people
  • taking actions from the digest
