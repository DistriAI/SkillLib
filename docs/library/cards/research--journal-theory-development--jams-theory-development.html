jams-theory-development

separate

Use when building the conceptual framework and mechanism for a Journal of the Academy of Marketing Science (JAMS) manuscript — deriving hypotheses from marketing theory, specifying mediators and boundary conditions, and carrying the logic through to a managerial implication. Builds the argument; it does not select the question (jams-topic-selection) or run the analysis (jams-data-analysis).

When to use

  • building conceptual framework
  • deriving hypotheses from marketing theory
  • specifying mediators and boundary conditions
  • carrying logic to managerial implication
  • developing theory for JAMS manuscript
  • defining focal constructs
  • drawing nomological net
  • crafting hypotheses

When not to use

  • selecting the question
  • running the analysis
