jue-referee-strategy

separate

Use when anticipating the objections a Journal of Urban Economics (JUE) referee will raise before submission, so the manuscript pre-empts them. Maps the recurring JUE spatial pushbacks to where each is answered in the paper; it does not run the analysis or draft the response letter (jue-rebuttal).

When to use

  • Anticipating JUE referee objections
  • Mapping spatial pushbacks to manuscript sections
  • Pre-empting sorting and spillover critiques
  • Distinguishing fatal from cosmetic objections
  • Designing for design and urban-economics referee personas
  • Strategically suggesting and excluding reviewers

When not to use

  • Running the analysis
  • Drafting the response letter
