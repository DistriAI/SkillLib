jue-referee-strategy

separate

Use when anticipating the objections a Journal of Urban Economics (JUE) referee will raise before submission, so the manuscript pre-empts them. Maps the recurring JUE spatial pushbacks to where each is answered in the paper; it does not run the analysis or draft the response letter (jue-rebuttal).
