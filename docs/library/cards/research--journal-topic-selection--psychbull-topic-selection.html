psychbull-topic-selection

separate

Use when deciding whether a question is review-worthy and meta-analyzable for Psychological Bulletin and which synthesis type fits (meta-analysis, systematic review, meta-review/meta-synthesis, qualitative review). Tests fit for an APA research-synthesis flagship; it does not write the review.

When to use

  • deciding if a question fits Psychological Bulletin
  • choosing between meta-analysis, systematic review, or qualitative review
  • testing if a topic is too narrow or already reviewed
  • scoping the question with PICO-style structure
  • screening fit as a referee would apply it

When not to use

  • writing the review
  • drafting content
  • reporting new data
  • pure theory
  • primary studies
