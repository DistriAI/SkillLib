react-navigation

separate

Provides React Navigation UI patterns for stacks, tabs, drawers etc. Use when building navigation UIs with React Navigation, configuring headers, bottom sheets or handling safe areas and insets.

When to use

  • Building navigation UI patterns such as stacks, tabs, drawers, sheets
  • Configuring headers and other built-in navigator UI
  • Handling safe areas and insets in navigation UI
  • Showing screens and modals in a stack
  • Showing bottom sheets or form sheets
  • Showing screens in bottom tabs or responsive sidebars
  • Showing screens in native tabs on iOS & Android
  • Using a drawer or sidebar

When not to use

  • React Navigation versions other than 7
