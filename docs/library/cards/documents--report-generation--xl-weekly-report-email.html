xl-weekly-report-email

separate

通用周报收集和邮件推送技能，支持交互式填写周报内容，自动计算周数和日期范围，生成美观的HTML格式邮件。

When to use

  • 写周报
  • 配置周报邮箱
  • 收集周报内容
  • 生成HTML格式邮件
  • 计算周数和日期范围
  • 发送邮件

When not to use

  • 自动发送邮件
  • 一次性抛出所有问题
  • 手写HTML
  • 直接输出文本
