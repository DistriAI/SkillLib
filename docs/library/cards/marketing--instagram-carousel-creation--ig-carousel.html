ig-carousel

separate

Build an Instagram carousel - the cover that earns the swipe, slide-by-slide copy, and the 1080x1350 files to upload. Use when the user says "carousel", "slides", "swipe post", "turn this into a carousel", or has a list-shaped or step-shaped idea that would die as a single image.

When to use

  • Use a carousel when the idea has **sequence and needs to be re-read**: steps, a framework with parts, a before and after, a list worth screenshotting. Use a Reel when the idea has motion, a face, or a payoff that has to be seen happening.…

When not to use

  • Reels
  • ideas with motion
  • ideas with a face
  • payoffs that have to be seen happening
  • single claim ideas
