ecj-rebuttal

separate

Use when a The Economic Journal (EJ) decision letter (R&R or reject-with-encouragement) has arrived and you need to draft the response-to-referees letter and revision plan. Structures the response and the diff; it does not redo the analysis (route back to ecj-identification / ecj-theory-model / ecj-robustness first).

When to use

  • drafting response-to-referees letter
  • creating revision plan
  • structuring point-by-point responses
  • summarizing changes for editor
  • handling EJ-typical demands
  • planning replication readiness

When not to use

  • redoing analysis
  • writing response letter before doing revisions
  • skipping or merging referee points
  • defensive or dismissive tone
  • conceding correct results without evidence
  • promising future work instead of current analysis
  • dismissing exposition requests as cosmetic
  • ignoring editor's prioritization
