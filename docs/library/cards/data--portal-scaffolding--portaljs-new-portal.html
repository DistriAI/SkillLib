portaljs-new-portal

separate

Scaffold a new PortalJS data portal from a brief. Copies the canonical template from examples/portaljs-catalog and substitutes project tokens. Use when starting a brand-new data portal project from scratch.

When to use

  • Scaffold a new PortalJS data portal
  • Copy canonical template from examples/portaljs-catalog
  • Substitute project tokens
  • Set namespace mode and UI language
  • Seed datasets named in interview
  • Install dependencies
  • Verify scaffold with type check

When not to use

  • Running next build
  • Forcing local mode when stale
