deepxiv

authentic

Search and progressively read open-access academic papers through DeepXiv. Use when the user wants layered paper access, section-level reading, trending papers, or DeepXiv-backed literature retrieval.

When to use

  • layered paper access
  • section-level reading
  • trending papers
  • DeepXiv-backed literature retrieval
  • progressive section-level reading
  • paper brief
  • section map
  • web search

When not to use

  • Batch search
  • PDF download
  • Published venue metadata
  • Citation counts
  • Instant LLM-optimized summary of one paper
