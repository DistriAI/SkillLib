anki-card-creator

combined

Convert medical textbook content, lecture notes, and study materials into Use anki-card-creator for academic writing workflows that need structured execution, explicit assumptions, and clear output boundaries for study-card generation.

When to use

  • Preparing for medical board exams (USMLE, MCAT, specialty boards)
  • Memorizing drug names, mechanisms, and side effects
  • Learning anatomy structures and relationships
  • Retaining biochemical pathways and reactions
  • Creating pathology differential diagnosis cards
  • Converting lecture notes to active recall format
  • Building comprehensive review decks from textbooks
  • Learning conceptual understanding → Use textbooks/videos first

When not to use

  • **Context Dependency**: May miss nuanced explanations without full context
  • **Image Licensing**: Must verify copyright for extracted images
  • **Complex Diagrams**: Simple occlusion may not capture complex relationships
  • **Personalization**: Generic cards lack personal memory hooks
  • **Volume Control**: Easy to create too many cards; requires curation
  • **Active Learning**: Cards supplement but don't replace active problem-solving

Skill page

Conflict

The two copies describe the same skill but with materially different procedures and capabilities. The aipoch copy is a lightweight, script-driven workflow focused on TSV output, drug/anatomy flags, and a strict stop-on-missing-input rule. The LeoYeAI copy is a richer, Python-class-based workflow supporting cloze, image occlusion, reversible cards, automated hierarchical tagging, and .apkg output, with explicit 'do not use' boundaries and integration with other skills. Neither is a simple reproduction of the other; crowning one would hide the alternative approach and its unique steps (e.g., image occlusion, cloze strategies, tagging hierarchy).
