xxx-security-audit

separate

OpenClaw 安全巡检工具，一键执行系统安全扫描并生成通俗易懂的报告。 使用场景：用户说"安全巡检"、"安全检查"、"安全审计"、"巡检"、"security audit"、"检查安全"、"系统安全"等。 触发条件：任何与 OpenClaw 安全检测、审计、巡检相关的请求。

When to use

  • 安全巡检
  • 安全检查
  • 安全审计
  • 巡检
  • security audit
  • 检查安全
  • 系统安全
  • OpenClaw 安全检测

When not to use

  • 非 OpenClaw 系统的安全审计
  • 使用系统 crontab 配置定时任务
  • 在定时任务中启用 --push 参数
