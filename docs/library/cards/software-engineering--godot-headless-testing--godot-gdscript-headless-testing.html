godot-gdscript-headless-testing

separate

Run GDScript test suites from the command line with `godot --headless`, using a SceneTree/MainLoop runner script that exits non-zero on failure so CI can gate merges. Use when a Godot project needs unit tests without opening the editor, when wiring a CI job (GitHub Actions or similar) that must fail the build on a failing `.gd` test, or when a `godot --headless` invocation hangs, opens a window, or exits 0 despite failed assertions.

When to use

  • Use when a Godot project has no testing addon installed and needs a fast way to
  • Use when wiring a CI job that must fail the build when a `.gd` test fails.
  • Use when debugging why a `godot --headless` invocation hangs, opens a window, or

When not to use

  • GDScript syntax or language features
  • Export/build pipeline and platform templates
  • Producing binaries via --headless
