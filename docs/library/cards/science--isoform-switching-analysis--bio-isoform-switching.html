bio-isoform-switching

separate

Analyzes isoform switching events and functional consequences using IsoformSwitchAnalyzeR. Predicts protein domain changes, NMD sensitivity, ORF alterations, and coding potential shifts between conditions. Use when investigating how splicing changes affect protein function.

When to use

  • Identify genes where the dominant isoform switches between conditions
  • Predict how isoform switches alter protein domains, coding potential, and localization
  • Determine which isoform switches cause functional changes
  • Visualize isoform switch events and summarize functional consequence patterns
  • Investigate how splicing changes affect protein function

When not to use

  • Identify differential events first
  • PSI-level analysis
  • Pathway enrichment of switching genes
