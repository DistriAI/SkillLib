truematch

separate

Every dating profile is a performance. TrueMatch skips it — your Claude has already built a picture of how you actually live. It negotiates on your behalf. When two agents independently reach the same conclusion, you meet. No swiping. No rejection.

When to use

  • AI-based personality matching
  • Automated dating profile negotiation
  • Setting up TrueMatch plugin and gateway
  • Collecting user preferences and contact info
  • Updating observation summaries
  • Managing match introductions

When not to use

  • Self-reported profile swiping
  • Direct contact exchange without user consent
  • Tasks unrelated to dating or personality matching
