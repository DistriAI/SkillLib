model-card

authentic

Document a deployed ML/AI model so others can use it responsibly. Use when asked to write a model card, document a model's intended use and limitations, or prepare an AI model for review/launch. Produces a complete model card — intended use, training data, evaluation metrics across slices, limitations, ethical considerations, and a deployment checklist.

When to use

  • write a model card
  • document a model's intended use and limitations
  • prepare an AI model for review/launch
  • document model evaluation metrics across slices
  • document model ethical considerations
  • create a deployment checklist

When not to use

  • report a single aggregate metric without slice breakdown
  • leave intended use open-ended
  • omit known biases
  • present accuracy without class balance
  • ship without a monitoring plan
