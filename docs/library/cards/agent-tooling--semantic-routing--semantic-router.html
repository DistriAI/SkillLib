semantic-router

separate

让 AI 代理根据对话内容自动选择最合适的模型。层2（多词非连续命中）+ 层1（单词兜底）并行决定模型池；层3（embedding）永远独立运行决定会话切换。B+ 连续漂移计数器（第3次警告，第4次强制 C-auto）。soft_keywords 泛用词降权机制。四池架构（高速/智能/人文/代理），五分支路由，全自动 Fallback 回路。

When to use

  • 根据对话内容自动选择模型
  • 四池架构路由（高速/智能/人文/代理）
  • 五分支路由决策
  • 会话隔离与 Cron Job 隔离
  • 关键词与指示词检测
  • 上下文关联度评分
  • 配置引导与自动回滚
  • Webhook 路由服务

When not to use

  • 不向外部服务器泄露对话内容或模型凭证
  • 不直接访问 API 密钥或秘密
  • 不修改 ~/.openclaw/ 和技能工作区之外的文件
  • 不以提升权限（sudo/root）运行
  • 不自动安装额外软件包
