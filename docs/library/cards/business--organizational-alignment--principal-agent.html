principal-agent

separate

当用户选择职业/组织/合作方式、困惑「为什么大公司磨洋工/小公司拼命」「该不该自己干」时调用。 核心理念: 委托人(主人)会把事做好, 代理人会为自己利益优化; 收益与创造价值绑得越紧, 越像委托人; 别让媒体洗脑你需要代理人。 不适用于: 具体薪酬谈判数字、组织架构设计细节。 Triggers: 激励/代理/主人/打工 vs 创业/利益绑定/principal/agent/incentive

When to use

  • 职业选择：大公司 vs 小创业公司
  • 打工 vs 自己干
  • 合作设计：分成/激励结构
  • 诊断团队磨洋工或外包问题
  • 自我诊断：为谁利益工作
  • 识别委托人与代理人角色

When not to use

  • 具体薪酬谈判数字
  • 组织架构设计细节
  • 具体薪酬谈判话术
  • 管理细节（监督/考核）
