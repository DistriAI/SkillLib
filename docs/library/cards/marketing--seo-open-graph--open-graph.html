open-graph

separate

When the user wants to add, audit, implement, or optimize Open Graph metadata for social sharing, including og:title, og:description, og:image, og:url, Facebook previews, LinkedIn previews, or social share previews. For a full metadata lifecycle use page-metadata; for X-specific previews use twitter-cards.

When to use

  • add Open Graph metadata
  • audit Open Graph tags
  • implement og:title, og:description, og:image, og:url
  • optimize social share previews
  • Facebook previews
  • LinkedIn previews
  • Next.js App Router Open Graph configuration
  • HTML Open Graph tag implementation

When not to use

  • full metadata lifecycle
  • X-specific previews
  • Twitter card specific tags
  • creating OG images
