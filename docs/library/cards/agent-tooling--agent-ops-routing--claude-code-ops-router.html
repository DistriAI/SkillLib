claude-code-ops-router

separate

plugin/Skill repair, marketplace, statusline, model profiles/source sync, 1M/[1m] context, usage/quota reset ping, memory→docs, .txt repair, MCP startup context. Routes Claude Code to one bundled specialist, including turning auto memory off. History, hooks, and Lark keep their own entries.

When to use

  • Repair a Claude Code plugin or Skill
  • Install, change, or repair the Claude Code statusline
  • Repair line wrapping, tables, paths, or tool output in an exported Claude Code .txt conversation
  • Create or maintain a Claude Code plugin marketplace
  • Analyze Claude Code/Desktop Code token use, cost, cache, quota burn, or 5-hour blocks
  • Configure isolated Claude Code model-provider profiles, aliases, source-backed Claude/Codex Skill activation, or context-window size
  • Migrate existing Claude personal memory into tool-agnostic AGENTS.md reference documents
  • Set a one-shot local ping after a Claude subscription quota reset

When not to use

  • conversation-history reading and continuation
  • prior-work retrieval
  • hooks
  • CLAUDE.md editing
  • Lark
  • Claude.ai web-conversation export
  • terminal color screenshots
  • relayed web-search repair
