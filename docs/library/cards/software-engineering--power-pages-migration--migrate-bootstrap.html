migrate-bootstrap

separate

Migrates a traditional Power Pages site from Bootstrap 3 to Bootstrap 5. Downloads the site, runs the pac pages bootstrap-migrate engine, reviews the change report, applies AI-assisted fixes for the residual hierarchy/CSS changes the engine only flags, uploads the migrated site (which auto-enables the Bootstrap 5 runtime flag), verifies the flag, and validates. Use when the user wants to upgrade an older Bootstrap-3 portal to Bootstrap 5. NOT for code sites (React/Vue/Angular/Astro) — those are never Bootstrap-3.

When to use

  • Migrate traditional Power Pages site from Bootstrap 3 to Bootstrap 5
  • Run pac pages bootstrap-migrate engine
  • Apply AI-assisted fixes for residual hierarchy/CSS changes
  • Upload migrated site to auto-enable Bootstrap 5 runtime flag
  • Verify Bootstrap 5 flag flip via pac-log.txt
  • Validate migrated site

When not to use

  • Migrate code sites (React/Vue/Angular/Astro)
  • Migrate sites that are not Bootstrap-3-based
