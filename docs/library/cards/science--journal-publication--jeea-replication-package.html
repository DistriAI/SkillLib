jeea-replication-package

separate

Use when assembling the data and code replication package for a Journal of the European Economic Association (JEEA) manuscript so it clears the JEEA Data Editor's pre-acceptance verification under the DCAS standard. Builds the package and README; it does not run the analysis.

When to use

  • Assembling JEEA replication package
  • Building package and README
  • Preparing for JEEA Data Editor verification
  • Creating one-click reproduction path
  • Documenting data provenance and access
  • Pinning software versions and packages
  • Mapping outputs to scripts
  • Preparing package for Zenodo deposit

When not to use

  • Running the analysis
