harness-capu

separate

Fund OpenCAP inference from Capminal with staked CAPU on Base. Buy or mint CAPU, stake it for daily inference credit, create a wallet-owned OpenCAP API key through Ethereum sign-in, check quota, and recover or rotate the key. Use when the user wants CAPU-funded AI compute or OpenCAP key setup; Capminal trading-wallet credentials and Harness account management are separate workflows.

When to use

  • Buy or mint CAPU
  • Stake CAPU for daily inference credit
  • Create wallet-owned OpenCAP API key
  • Check quota
  • Recover or rotate the key
  • CAPU-funded AI compute setup

When not to use

  • Capminal trading-wallet credentials
  • Harness account management
