chi-submission

separate

Use when auditing an ACM CHI Papers submission for PCS readiness, covering the September full-paper deadline, the anonymized single-column template, word-count norms instead of page limits, subcommittee designation, supplementary and video upload, anonymization of external links, and CHI's desk-reject triage before upload.

When to use

  • auditing ACM CHI Papers submission
  • checking PCS readiness
  • verifying September full-paper deadline
  • checking anonymized single-column template
  • checking word-count norms
  • designating subcommittee
  • checking supplementary and video upload
  • anonymization of external links

When not to use

  • OpenReview submissions
  • CMT submissions
