sync

separate

Run /sync as the last step after a change is complete, around merge, to keep durable knowledge current. Updates root and nested AGENTS.md, reconciles the scope from repo evidence, and flags specs the change made stale. Surgical edits only: it adds lines, and rewrites single lines it owns. Never a whole section, never curated prose.

When to use

  • Update root and nested AGENTS.md
  • Reconcile scope from repo evidence
  • Flag specs the change made stale
  • Create nested AGENTS.md for net new areas
  • Reconcile spec Status lines
  • Tick completed sub tasks from evidence

When not to use

  • Create or restructure root AGENTS.md
  • Create nested docs for existing undocumented areas
  • Clear Assumed specs
  • Edit spec content
  • Add or reorder features in scope
  • Overwrite curated AGENTS.md prose
