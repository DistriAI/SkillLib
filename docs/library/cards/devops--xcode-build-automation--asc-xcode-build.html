asc-xcode-build

separate

Build, archive, export, and manage Xcode version/build numbers with asc, including portable iOS compilation and packaging. Use when creating an IPA or PKG for App Store Connect, TestFlight, or registered-device release testing.

When to use

  • Build, archive, and export Xcode projects
  • Manage Xcode version and build numbers
  • Create IPA or PKG for App Store Connect
  • Prepare builds for TestFlight
  • Prepare builds for registered-device release testing
  • Portable iOS compilation and packaging

When not to use

  • Device/profile reconciliation
  • Isolated signing
  • Private publication
  • Resumability
  • Live verification
