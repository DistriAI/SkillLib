pnasnexus-statistics

separate

Use to enforce PNAS Nexus's statistics and reproducibility reporting — n and replication, test choice and assumptions, effect sizes with uncertainty, multiple-comparison control, randomization/blinding, sample-size justification, and reproducible code. Also covers whether a Registered Report (Stage 1/2) is the right route for confirmatory work.

When to use

  • Statistics and reproducibility reporting
  • Effect sizes with uncertainty
  • Multiple-comparison control
  • Randomization and blinding
  • Sample-size justification
  • Registered Report Stage 1/2
  • Reproducible code and data

When not to use

  • Reporting P values without effect sizes or n
  • Counting technical replicates as independent observations
  • Inferring no effect from underpowered non-significant tests
  • Presenting post-hoc findings as pre-specified
  • Deferring the reproducibility package
