ieeesp-topic-selection

separate

Use when deciding whether a security or privacy project belongs at IEEE S&P (Oakland), including the threat-model test, SoK fit, routing among USENIX Security, CCS, NDSS, PETS, and CRYPTO, and whether the one-year resubmission embargo or the 40% overlap rule constrains the plan.

When to use

  • deciding if a project belongs at IEEE S&P
  • threat-model test
  • SoK fit
  • routing among USENIX Security, CCS, NDSS, PETS, and CRYPTO
  • checking one-year resubmission embargo
  • checking 40% overlap rule

When not to use

  • writing the paper
  • projects where security is a motivating anecdote rather than the analyzed object
  • simulation-only evidence
  • literature reviews that do not overturn a belief or reveal structure
