jpe-rebuttal

separate

Use when a Journal of Political Economy (JPE) decision letter (R&R or reject-with-encouragement) has arrived and you need to draft the response-to-referees letter and revision plan. Structures the response and the diff; it does not redo the analysis (route back to jpe-identification / jpe-theory-model / jpe-robustness first).

When to use

  • drafting response-to-referees letter
  • creating revision plan
  • structuring point-by-point responses
  • handling JPE-typical demands
  • summarizing changes for co-editor
  • planning replication readiness

When not to use

  • redoing the analysis
  • writing the response letter before doing the revisions
  • skipping or merging referee points
  • defensive or dismissive tone
  • conceding a correct result without evidence
  • promising future work instead of current analysis
