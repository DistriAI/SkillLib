jetson-customize-camera

separate

Enable MIPI/GMSL camera sensors on a Jetson Thor or Orin custom carrier by rendering a kernel-DT overlay from the in-tree sensor DTSI. Do NOT use for UPHY lane allocation or ODMDATA edits.

When to use

  • Enable MIPI/GMSL camera sensors
  • Configure CSI
  • Wire a Hawk / Owl / IMX sensor
  • Bring up tegra-capture-vi / NVCSI
  • Multi-sensor bring-up
  • Render kernel-DT overlay from in-tree sensor DTSI

When not to use

  • UPHY lane allocation
  • ODMDATA edits
