where-to-start-situation-save

separate

Step of the where-to-start playbook: saves the founder's answers and the agreed first move with the brand, so later visits and other playbooks don't ask again. Run where-to-start instead; not for direct use.

When to use

  • saving founder's answers
  • saving agreed first move
  • updating brand/situation.md
  • updating profile fields
  • recording site observations
  • recording agent's read

When not to use

  • direct use
  • saving before founder answers recommendation
  • writing claims, voice, or positioning
  • using user_context for brand facts
  • saving without a real brand
