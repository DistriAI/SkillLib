isca-artifact-evaluation

separate

Use when preparing an accepted ISCA paper's artifact for evaluation under the ACM Review and Badging policy — scoping which results are reproducible within evaluator budgets, packaging simulator-heavy workflows others can run, writing the evaluator-facing appendix, and earning badges that print on the paper.

When to use

  • scoping which results are reproducible within evaluator budgets
  • packaging simulator-heavy workflows others can run
  • writing the evaluator-facing appendix
  • earning badges that print on the paper
  • defining tolerance statements for simulation results
  • managing third-party licenses for workloads
  • conducting cold-start rehearsals for artifact evaluation

When not to use

  • preparing artifacts for non-accepted papers
  • managing the acceptance decision process
