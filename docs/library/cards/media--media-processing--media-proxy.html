media-proxy

separate

Shared helper that routes ALL paid media generation (FAL image/video, ElevenLabs music) through the GooseWorks proxies so every call is charged to your GooseWorks credits — never a provider SDK's default host. Host-swaps the FAL queue URLs, loads the agent token from the sandbox env (GW_MEDIA_PROXY_TOKEN) or ~/.gooseworks/credentials.json, and returns the result CDN URL. Every video-ad media capability imports this; templates never call a provider directly.

When to use

  • Routing FAL image/video generation
  • Routing ElevenLabs music generation
  • Charging calls to GooseWorks credits
  • Host-swapping FAL queue URLs
  • Loading agent token from sandbox env
  • Handling crash-resume for paid renders
  • Polling through outages
  • Resuming unfinished FAL jobs

When not to use

  • Calling provider SDKs directly
  • Retrying policy rejections
  • Re-firing submitted jobs to avoid double-billing
