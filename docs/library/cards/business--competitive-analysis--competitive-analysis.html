competitive-analysis

combined

Compare UX patterns, features, strengths, and gaps across rival products. Use when you need to know what others actually do. For deliberately adopting their conventions, use `jakobs-law` (interaction-design). Analiza competidores y crea documentación de panorama competitivo con matrices de características, mapas de posicionamiento y recomendaciones estratégicas. Usa cuando se te pida analizar competidores, crear un análisis competitivo, comparar características con competidores, construir un panorama competitivo, rastrear posicionamiento competitivo o preparar insumos para sales battlecard. Produce perfiles de competidores estructurados, matriz de comparación de características, análisis de ganancias/pérdidas y recomendaciones estratégicas priorizadas. Para un desglose puntual de un rival único usa competitor-teardown; para un informe de mercado recurrente usa competitive-intelligence-monitor.

When to use

  • Compare UX patterns and features
  • Identify design strengths and gaps
  • Create feature comparison matrices
  • Analyze pricing and positioning
  • Build competitor profiles
  • Identify win/loss patterns
  • Prepare sales battlecard inputs
  • Create opportunity maps

When not to use

  • Deliberately adopting conventions (use jakobs-law)
  • Single rival point-by-point breakdown (use competitor-teardown)
  • Recurring market intelligence reports (use competitive-intelligence-monitor)

Skill page

Conflict

The two skills overlap in producing a competitive analysis with a feature matrix and competitor profiles, but they target different audiences and add material steps the other lacks. The first is a UX/design lens (interaction patterns, accessibility, mobile, UX quality scoring, aspirational benchmarks) and does not include pricing, win/loss, or positioning maps. The second is a product/business lens (pricing, positioning map, win/loss, strategic recommendations, sourcing/anti-patterns, and optional professional-brain integration) and does not include UX-specific evaluation dimensions. Crowning one would hide a real alternative.
