manual-scene

separate

Manually navigate, save, and manage scenes using Unity Editor UI. For simple Scene view workflows that do not need REST automation.

When to use

  • Navigating the Scene view with mouse and keyboard
  • Saving the current scene
  • Switching between loaded scenes
  • Additive scene workflows
  • Framing the camera on an object
  • Toggling 2D or orthographic view

When not to use

  • Querying scene contents
  • Batch loading or unloading scenes
  • Dependency analysis
  • Screenshot capture
  • Switching scenes programmatically across many scenes
