module-analyzer-generate-doc

separate

Java/Maven single-module deep documentation generator. Generates L3(file-level) to L2(module-level) business logic docs for specified module. Supports multi-subagent parallel processing, context compression, checkpoint resume, and auto-retry.

When to use

  • Single Java/Maven module deep analysis
  • L3 file-level documentation generation
  • L2 module-level documentation generation
  • Business logic documentation
  • Module architecture index
  • Core business process documentation
  • Dependency relationship summary
  • Source code analysis for specific modules

When not to use

  • Full project multi-module scanning
  • L1 project-level documentation generation
  • Deleting low-quality documents without user confirmation
  • Analyzing non-Java or non-Maven projects
