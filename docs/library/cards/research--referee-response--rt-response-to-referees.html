rt-response-to-referees

separate

Use after an R&R (or the simulated rehearsal) to turn a referee report into a point-by-point response letter plus a revision plan — editor first, every comment answered, each empirical fix backed by a real re-run via the target pack's skill and the execution bridge. Defers the venue's response format to the pack + source-map.

When to use

  • point-by-point response to R&R letter
  • convert rt-simulated-referee output into rehearsed reply
  • inventory and tag referee comments
  • draft response letter with editor first
  • back substantive fixes with real re-runs
  • summarize changes in a scannable table

When not to use

  • final scientific sign-off
  • regenerating replication package outputs
