scenario-godot-architecture

separate

Use when structuring Godot 4.7 game code: folders, scenes and nodes, signals or an event bus autoload, custom Resources for item data, components (health, hitbox, hurtbox), an inventory, save and load, InputMap and key rebinding for keyboard, mouse and gamepad, GDScript static typing and style, or GDScript vs C#; or when code is spaghetti, a folder scan breaks in the export, a save loads wrong, the gamepad does nothing, or @onready is null.

When to use

  • structuring Godot 4.7 game code
  • folders, scenes and nodes
  • signals or an event bus autoload
  • custom Resources for item data
  • components (health, hitbox, hurtbox)
  • inventory, save and load
  • InputMap and key rebinding
  • GDScript static typing and style

When not to use

  • code is spaghetti
  • a folder scan breaks in the export
  • a save loads wrong
  • the gamepad does nothing
  • @onready is null
