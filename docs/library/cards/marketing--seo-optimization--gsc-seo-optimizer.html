gsc-seo-optimizer

separate

Analyze Google Search Console exports or authorized API data to prioritize page improvements. Use for traffic changes, page/query opportunities, indexing evidence, and deciding when to leave recently edited or weakly supported pages alone.

When to use

  • traffic changes
  • page/query opportunities
  • indexing evidence
  • deciding when to leave recently edited pages alone
  • deciding when to leave weakly supported pages alone
  • prioritize page improvements
  • read-only diagnosis
  • execute changes within explicit authorization

When not to use

  • publishing without explicit authorization
  • spending without explicit authorization
  • installing packages or connectors unless needed
  • starting OAuth unless needed
  • extracting cookies, browser profile data, or passwords
  • mixing scopes in comparisons
  • treating short-term movement as causality
  • concluding a page has no keywords without stronger evidence
