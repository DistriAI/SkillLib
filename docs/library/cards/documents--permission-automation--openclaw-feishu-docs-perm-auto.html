openclaw-feishu-docs-perm-auto

separate

自动为飞书文档添加用户权限。每次创建飞书文档（多维表格/文档/电子表格/文件夹/云空间文件/知识库节点等）后自动添加用户权限，或用户反馈文档无权限时补充添加权限。适用于 OpenClaw Agent。

When to use

  • Adding permissions after creating Feishu documents
  • Supplementing permissions when users report no access
  • Handling multi-dimensional tables, docs, sheets, folders, and wiki nodes
