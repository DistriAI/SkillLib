commres-tables-figures

separate

Use when building tables and figures for a Communication Research (CR) manuscript so exhibits are self-contained, accessible, and formatted to APA. CR is quantitative, so exhibits must show effect sizes and uncertainty, not just stars. Designs exhibits; it does not run the analysis.

When to use

  • Designing the main results table/figure
  • Designing a key descriptive/measurement exhibit
  • Deciding what belongs in the article vs. the online supplement
  • Fixing an exhibit that is unclear, mislabeled, or not self-contained
  • Presenting mediation/moderation results readably
  • Generating exhibits from fitted results using StatsPAI or Stata MCP
  • Performing an exhibit pass for Communication Research

When not to use

  • Running the analysis
