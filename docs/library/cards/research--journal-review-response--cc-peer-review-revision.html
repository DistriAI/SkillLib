cc-peer-review-revision

separate

Use when responding to Cancer Cell (Cell Press) reviewer reports — planning new experiments, writing a point-by-point response, and calibrating claims for revision. It structures the rebuttal and revision; it does not run the experiments or design them from scratch.

When to use

  • responding to Cancer Cell reviewer reports
  • planning new experiments
  • writing a point-by-point response
  • calibrating claims for revision
  • triaging requested experiments vs. textual changes
  • reconciling consultative or cross-referee comments
  • framing pushback for consultative review

When not to use

  • running experiments
  • designing experiments from scratch
