rn-motion-director

separate

Motion-first AI video director for topic-to-video creation. Use when the user gives a theme, idea, article, script, or brief and wants AI to freely create a real animated video instead of a PPT/slideshow-style explainer; when deciding visual metaphors, motion grammar, scene beats, component choices, generated image needs, HyperFrames/Remotion implementation strategy, and anti-PPT QC.

When to use

  • topic-to-video creation
  • deciding visual metaphors
  • defining motion grammar
  • planning scene beats
  • choosing component implementations
  • determining generated image needs
  • HyperFrames/Remotion implementation strategy
  • anti-PPT quality control

When not to use

  • PPT/slideshow-style explainers
  • replacing ra-video-production-director
  • replacing hyperframes
  • replacing remotion
  • replacing image generation tools
  • replacing QC tools
