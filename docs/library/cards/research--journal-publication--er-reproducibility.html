er-reproducibility

separate

Use when organizing a reproducible research package (folder structure, master do-file, data availability statement) so empirical results survive 《经济研究》 referee scrutiny and录用后的扩展资料提交.

When to use

  • organizing reproducible research package
  • setting up folder structure
  • creating master do-file
  • writing data availability statement
  • preparing for referee code scrutiny
  • preparing post-acceptance supplementary materials
  • ensuring results are reproducible in clean environment

When not to use

  • replacing official journal requirements
  • manually editing data in Excel
  • hardcoding absolute paths in scripts
  • mixing cleaning and analysis in one script
  • hand-copying tables from logs to Word
