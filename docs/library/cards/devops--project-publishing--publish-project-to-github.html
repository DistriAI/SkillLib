publish-project-to-github

separate

Package a finished local project into an intentional GitHub repository, create a strong README and visual preview, push it safely, configure a public GitHub Pages URL when the project is compatible, and verify the deployed result. Use when a user asks to upload, publish, open-source, share, or turn a local HTML/CSS/JavaScript experiment or small web project into a documented GitHub repository with a live demo.

When to use

  • upload local project to GitHub
  • publish local HTML/CSS/JavaScript experiment
  • open-source small web project
  • share local project as documented repository
  • turn local project into live demo
  • create GitHub Pages site for compatible web projects

When not to use

  • force-push to existing remote
  • overwrite existing remote
  • change repository visibility without authorization
  • replace existing Pages configuration without authorization
  • publish mixed workspace with unrelated experiments
  • publish projects with API keys or private data
