outlook-automation

authentic

Automate Outlook tasks via Rube MCP (Composio): emails, calendar, contacts, folders, attachments. Always search tools first for current schemas.

When to use

  • Search and filter emails
  • Query emails in a folder
  • Manage calendar events
  • Manage contacts
  • Manage mail folders
  • Download attachments

When not to use

  • Non-Microsoft 365/Enterprise accounts
  • Filtering by recipient or body content in single folder queries
