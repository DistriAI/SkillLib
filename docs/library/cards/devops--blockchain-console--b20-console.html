b20-console

separate

Inspect B20 token contract addresses on Base through B20 Console. Use this skill when a user asks whether a B20 contract is live, initialized, recognized by the B20 factory, what policies are attached, whether features are paused, or what risk flags are active. Calls the public B20 Console API and returns a concise risk summary with reasons. No API key required.

When to use

  • check if a B20 contract is live
  • verify if a token is recognized by the B20 factory
  • inspect B20 token initialization state
  • check attached policies
  • check if features are paused
  • identify active risk flags
  • compare policy, pause, and supply state
  • explain B20 risk flags

When not to use

  • buy, sell, transfer, sign, deploy, approve, or broadcast transactions
  • set wallet recipients, amounts, or transaction parameters
  • return unsigned transactions, calldata bundles, gas values, nonces, or signing payloads
  • act as an authoritative transaction source
  • automatic approval based on low risk score
