aqara-open-api

separate

Query and control Aqara/Lumi Studio smart home devices and manage spaces via the Aqara Open Platform API (HTTP JSON). Use when the user asks to list Aqara devices, get device status, control lights/switches/sensors, or manage rooms/spaces. Requires AQARA_OPEN_API_TOKEN and AQARA_ENDPOINT_URL.

When to use

  • list Aqara devices
  • get device status
  • control lights/switches/sensors
  • manage rooms/spaces
  • device discovery
  • device type lookup
  • space listing, creation, update
  • device assignment to spaces

When not to use

  • guessing device IDs or capability fields
  • using non-whitelisted request types
  • executing GetAllDevicesWithSpaceRequest via curl
