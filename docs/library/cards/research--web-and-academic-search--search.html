Prefer it over a browser when you just need search results, not page content. Returns structured results with titles, URLs, authors, and dates. 31 database search skills. Skill page

Conflict

The two skills both address search, but they target different systems and workflows. The first is a concrete procedure for the Browserbase Search API (curl, API key, request/response schema, error codes). The second is a catalog/index of 31 academic database search skills (arXiv, PubMed, OpenAlex, etc.) and does not provide a single executable procedure. Neither copy is a reproduction of the other, and crowning one would hide a real alternative.
