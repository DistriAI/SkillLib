jfe-internet-appendix

separate

Use when organizing the journal-hosted Internet Appendix for a Journal of Financial Economics (JFE) manuscript — what to move off the main text, how to cross-reference it, and how to keep it self-contained. Structures the appendix; it does not decide which robustness tests to run (jfe-robustness).

When to use

  • Organizing JFE Internet Appendix
  • Moving robustness tables and proofs to appendix
  • Cross-referencing main text to appendix exhibits
  • Keeping appendix self-contained
  • Numbering appendix exhibits in IA series
  • Auditing untabulated claims

When not to use

  • Deciding which robustness tests to run
  • Preparing code and data replication package
