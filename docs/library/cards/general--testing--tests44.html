tests44

separate

适用于在前进平台为**已部署工作负载**创建持续更新流水线（代码克隆 → 构建 → 镜像构建 → 镜像更新部署）。生成 Jenkinsfile 前必须完整阅读本 SKILL 内「流水线骨架」节模板，禁止凭记忆默写。

When to use

  • 为已部署工作负载创建持续更新流水线
  • 实现代码克隆、依赖安装与代码构建、镜像构建、镜像更新部署的全流程自动化
  • 每次触发后自动将新镜像滚动更新到已有工作负载

When not to use

  • 首次创建工作负载
  • 基础设施初始化
