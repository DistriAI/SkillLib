yaml-editing

separate

Last-resort guidance for safely hand-editing Unity YAML

When to use

  • Hand-editing YAML when REST cannot reach
  • Fixing m_Script GUIDs
  • Fixing broken fileID references
  • Fixing .meta files
  • Resolving merge conflicts
  • Patching hidden ProjectSettings fields
  • Repairing references after script rename or move

When not to use

  • Normal object/asset work
  • GameObjects / components
  • Prefabs
  • ScriptableObjects
  • Scenes
  • Importers
  • Graphics / rendering
  • Hand-editing YAML for convenience
