aos-writing-style

separate

Use when polishing the prose of an Accounting, Organizations and Society (AOS) manuscript — sustained argumentative writing that carries theory and evidence together, a self-contained abstract, disciplined length despite the absence of a hard cap, and full anonymization for double-anonymized review. Polishes prose; it does not run the submission preflight (aos-submission).

When to use

  • polishing AOS manuscript prose
  • ensuring sustained argumentative writing
  • creating a self-contained abstract
  • managing length discipline
  • anonymizing for double-anonymized review
  • applying terminology ledger
  • conducting paragraph audit

When not to use

  • running the submission preflight
  • aos-submission
