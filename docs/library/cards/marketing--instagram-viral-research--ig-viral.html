ig-viral

separate

Go and find the reels that are actually working right now in the user's niche, rank them by how far each beat its own account, name the hook formula each one used, and turn that into a swipe file they can shoot from. Use when the user says "find viral videos", "what's working right now", "what are people posting in my niche", "reverse engineer this account", "build me a swipe file", "why is this reel doing numbers", or asks what to make next and has no evidence to answer with.

When to use

  • find viral videos
  • what's working right now
  • what are people posting in my niche
  • reverse engineer this account
  • build me a swipe file
  • why is this reel doing numbers
  • asks what to make next

When not to use

  • logging into Instagram on the user's behalf
  • asking for a password
  • automated collection at volume
  • building a crawler
  • using a scraping service
  • looping in the background
  • copying the video script, voice, or edit
