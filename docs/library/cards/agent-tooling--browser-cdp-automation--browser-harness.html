browser-harness

authentic

Direct browser control via CDP. Use when the user wants to automate, scrape, test, or interact with web pages. Connects to the user's already-running Chrome.

When to use

  • automate web pages
  • scrape web pages
  • test web pages
  • interact with web pages
  • JS-heavy flows
  • logged-in sessions
  • visual verification
  • remote browsers for parallel sub-agents

When not to use

  • tasks needing no interaction
  • just wanting page content
  • setup, install, or connection problems
  • task-specific edits
