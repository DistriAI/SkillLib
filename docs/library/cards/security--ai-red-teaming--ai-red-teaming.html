Conflict

The two copies share the same core procedure (threat scenarios, test categories, adversarial prompt library, and a Python harness), but the second copy adds material constraints the first lacks: an explicit authorized-use warning, a mandatory confirmation gate before any probing or data extraction, and a caveat that the harness is a template that must be adapted to a synthetic sandbox with a validated target adapter and independent rubric. The first copy lacks these safety and scope controls. Crowning the first copy would hide a real alternative that adds required pre-flight authorization and sandboxing steps, so the copies should be combined.
