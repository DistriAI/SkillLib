jbv-theory-development

separate

Use when building the theoretical argument for a Journal of Business Venturing (JBV) manuscript — constructing a multidisciplinary mechanism (economics, psychology, sociology) for an entrepreneurial phenomenon, and choosing between hypothesis-testing and narrative/interpretive theorizing. Builds the argument; it does not pick the question (jbv-topic-selection) or run the analysis (jbv-data-analysis).

When to use

  • constructing a multidisciplinary mechanism
  • choosing between hypothesis-testing and narrative/interpretive theorizing
  • building the theoretical argument
  • picking the disciplinary engine
  • building moderation/mediation around the phenomenon
  • executing a theory pass
  • returning a ledger of claims and evidence
  • comparing against sibling journals

When not to use

  • picking the question
  • running the analysis
