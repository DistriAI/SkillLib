webmcp-gen

separate

Create, compile, and validate site-specific WebMCP init scripts from a target URL and desired tool capability. Use when the user wants to author WebMCP tools for a website, produce a webmcp.init.js artifact, or test WebMCP registration and invocation through Stagehand.

When to use

  • author WebMCP tools for a website
  • produce a webmcp.init.js artifact
  • test WebMCP registration and invocation through Stagehand
  • write manifest.json
  • compile manifest to init script
  • validate Chrome tool registration

When not to use

  • calling a nested agent
  • using Playwright, Puppeteer, or Stagehand inside implementation.source
  • using XPath helpers or agent/browser commands inside implementation.source
  • including API keys, bearer tokens, cookies, or user credentials
  • using eval or new Function
  • performing destructive actions unless explicitly asked
