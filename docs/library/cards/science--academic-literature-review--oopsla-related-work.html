oopsla-related-work

separate

Use when building an OOPSLA related-work section — positioning against the PACMPL family (POPL, PLDI, ICFP, OOPSLA itself) plus ECOOP, Onward!, and SE venues, citing journal-era OOPSLA papers in PACMPL volume/issue form, verifying every venue attribution on dblp, and stating per-line technical deltas.

When to use

  • building an OOPSLA related-work section
  • positioning against PACMPL family venues
  • citing journal-era OOPSLA papers in PACMPL volume/issue form
  • verifying venue attribution on dblp
  • stating per-line technical deltas
  • sweeping PACMPL issues for novelty
  • handling concurrent work in the same volume

When not to use

  • citing pre-2017 OOPSLA papers as conference proceedings
  • omitting technical deltas in citations
  • misattributing PLDI/POPL/ECOOP results as OOPSLA
