msom-workflow

separate

Use when deciding which msom-* sub-skill to invoke next, or when sequencing manuscript work from topic selection through rebuttal for a Manufacturing & Service Operations Management (M&SOM) manuscript. Routes — it does not replace — the specialized skills.

When to use

  • deciding which msom-* sub-skill to invoke next
  • sequencing manuscript work from topic selection through rebuttal
  • identifying the current stage of an M&SOM manuscript
  • determining if an operations decision is central
  • planning the next step for a half-built M&SOM manuscript
  • switching into response mode after a decision letter

When not to use

  • replacing specialized msom-* skills
  • performing topic selection
  • developing theory or models
  • conducting data analysis
  • framing contributions
  • formatting tables and figures
  • editing writing style
  • submitting manuscripts
