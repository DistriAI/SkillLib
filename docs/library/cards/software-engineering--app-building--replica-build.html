replica-build

separate

Rebuilds an app screen by screen from the recon map: app shell first, then the core flow as a vertical slice, then every screen with all its states, ticking off the feature matrix as it goes. Writes every line fresh, never the original's code, assets or copy. Use when the user says "build the clone", "build screen S07", "start building", "rebuild this screen", "implement the booking page", or after /replica-design.

When to use

  • build the clone
  • build screen S07
  • start building
  • rebuild this screen
  • implement the booking page
  • after /replica-design

When not to use

  • paste the original's HTML, CSS, JavaScript, SVGs or images
  • load anything from its domain or CDN
  • view source and adapt
  • dig into its code or network calls
