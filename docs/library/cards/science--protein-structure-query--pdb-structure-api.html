pdb-structure-api

separate

Search and retrieve 3D protein structures from the RCSB Protein Data Bank

When to use

  • Retrieve metadata for a structure by PDB ID
  • Retrieve protein or nucleic acid entity details
  • Retrieve ligand or small molecule metadata
  • Perform full-text searches across PDB entries
  • Perform attribute-based searches
  • Perform sequence similarity searches
  • Perform structure similarity searches

When not to use

  • Bulk data downloads via FTP
