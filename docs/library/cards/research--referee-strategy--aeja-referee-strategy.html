aeja-referee-strategy

separate

Use when anticipating the objections a sophisticated American Economic Journal: Applied Economics (AEJ: Applied) referee will raise, so a manuscript pre-empts them before submission or addresses them in revision. Plans the defense; it does not draft the response letter (aeja-rebuttal) or run the submission preflight (aeja-submission).

When to use

  • stress-test manuscript against referees
  • decide which robustness checks to run before submitting
  • map referee concerns to concrete responses
  • understand AEJ: Applied single-blind peer-review process
  • pre-empt predictable objections in the paper
  • war-game the design against hostile referee sentences
  • sequence robustness checks between main paper and appendix
  • anticipate external-validity asks

When not to use

  • draft the response letter
  • run the submission preflight
