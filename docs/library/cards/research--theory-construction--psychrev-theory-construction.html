psychrev-theory-construction

separate

Use when building the actual theory or formal/computational model for a Psychological Review manuscript — turning a framed problem into explicit assumptions, mechanisms, formal structure, and derivations. Constructs the model; it does NOT derive and test predictions against data (that is psychrev-argument-development) or set scope and identifiability limits (psychrev-boundary-conditions).
