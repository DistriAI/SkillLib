Comprehensive citation management for academic research. Search Google Scholar and PubMed for papers, extract accurate metadata, validate citations, and generate properly formatted BibTeX entries. This skill should be used when you need to find papers, verify citation information, convert DOIs to BibTeX, or ensure reference accuracy in scientific writing.

When to use

  • Searching for specific papers on Google Scholar or PubMed
  • Converting DOIs, PMIDs, or arXiv IDs to properly formatted BibTeX
  • Extracting complete metadata for citations (authors, title, journal, year, etc.)
  • Validating existing citations for accuracy
  • Cleaning and formatting BibTeX files
  • Finding highly cited papers in a specific field
  • Verifying that citation information matches the actual publication
  • Building a bibliography for a manuscript or thesis

When not to use

  • Creating diagrams for documents built from citations

Skill page

Conflict

The K-Dense-AI/scientific-agent-skills copy is the most complete and current procedure: it adds OpenAlex as a primary search source, a mandatory metadata-enrichment phase, explicit security guidance for untrusted metadata, and environment-variable configuration. The other copies reproduce the same core workflow but each contains material steps or constraints the K-Dense copy lacks or frames differently: zLanqing and benchflow include a full scientific-schematics section with a generate_schematic.py command; foryourhealth111-pixel includes a detailed metadata-sources list (CrossRef, PubMed E-utilities, arXiv, DataCite) and explicit extract_metadata.py variants for DOI/PMID/arXiv/URL. Because crowning one copy would hide these real alternatives, the decision is combine.
