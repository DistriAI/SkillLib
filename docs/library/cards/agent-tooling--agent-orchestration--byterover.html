byterover

separate

You MUST use this for gathering contexts before any work. This is a Knowledge management for AI agents. Use `brv` to store and retrieve project patterns, decisions, and architectural rules in .brv/context-tree. Uses a configured LLM provider (default: ByteRover, no API key needed) for query and curate operations.

When to use

  • gathering contexts before any work
  • storing project patterns
  • retrieving project patterns
  • storing decisions
  • retrieving decisions
  • storing architectural rules
  • retrieving architectural rules
  • managing long-term memory

When not to use

  • information already present in current context
  • general knowledge queries
  • transient information relevant only to current task
  • unchanged stored information
