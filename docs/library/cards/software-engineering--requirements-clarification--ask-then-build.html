ask-then-build

separate

Clarify a feature, change, or refactor through questions, then write a build prompt for another agent. Use for /ask-then-build or requests to ask questions before producing an implementation prompt.

When to use

  • Clarifying feature ideas
  • Clarifying changes
  • Clarifying refactors
  • Producing implementation prompts
  • Handling /ask-then-build requests

When not to use

  • Bundling multiple questions
  • Writing prompts before all answers are received
