obsidian-experiment-log

separate

Use this skill when the user discusses experiment design, ablations, training runs, evaluation, baselines, metrics, failures, or result interpretation that should be logged into Obsidian experiment and result notes.

When to use

  • experiment design
  • ablations
  • training runs
  • evaluation
  • baselines
  • metrics
  • failures
  • result interpretation

When not to use

  • creating note sprawl
  • storing raw logs in canonical notes
  • storing metric dumps in canonical notes
  • storing temporary analysis fragments in canonical notes
