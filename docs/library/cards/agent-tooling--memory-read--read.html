Preview a distilled wiki page from inside Claude Code. Prints title, summary, source count, and the local md path. Full body lives on disk — open with the user's editor. Invoked as `/read <title_or_id>`.

When to use

  • User asks "show me the page on X", "what's in <title>", "preview that".
  • After `/distill` finishes, follow up with `/read "<title>"` (titles

When not to use

  • Reading the full body → open the md file in the user's editor.
