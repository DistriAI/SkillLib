session-logs

separate

Search and analyze your own session logs (older/parent conversations) using jq.

When to use

  • searching prior chats
  • analyzing parent conversations
  • retrieving historical context
  • extracting user messages
  • searching assistant responses
  • calculating session costs
  • counting messages and tokens
  • analyzing tool usage

When not to use

  • tasks not referencing older or parent conversations
  • tasks where context is already in memory files
