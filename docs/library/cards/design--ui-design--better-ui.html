better-ui

separate

Polishes the surfaces, icons and motion in your project with exact values for border radius, optical alignment, shadows, icon states and animation.

When to use

  • surface polish
  • icon states
  • motion design
  • border radius calculation
  • optical alignment
  • shadow recipes
  • image outlines
  • animation timing

When not to use

  • text wrapping
  • font rendering
  • tabular numbers
  • text spacing
  • hit areas
  • keyboard support
  • ARIA
  • color tokens
