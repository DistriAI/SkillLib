cell-star-methods

separate

Use to build Cell's mandatory STAR Methods — the Key Resources Table, the three Resource Availability subsections, Experimental Model and Subject Details, Method Details, and Quantification and Statistical Analysis, in the exact required order.

When to use

  • Building Key Resources Table
  • Creating Resource Availability subsections
  • Writing Experimental Model and Subject Details
  • Drafting Method Details
  • Consolidating Quantification and Statistical Analysis
  • Formatting Cell STAR Methods

When not to use

  • Submitting free-text Methods sections
  • Omitting RRIDs or catalog numbers
  • Dropping Resource Availability subsections
  • Leaving statistics only in figure legends
