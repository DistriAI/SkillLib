figure-first-paper-reader

separate

Reads a paper figure by figure before re-integrating the full narrative, so the user can identify the core findings quickly and check whether each visual actually supports the authors' main claims. Always separate figure content, figure-linked claim, evidentiary strength, and unsupported interpretation. Never fabricate references, PMIDs, DOIs, figure content, panel labels, result values, or study details that were not actually provided.

When to use

  • capture the core findings of a paper quickly
  • understand the paper's logic without reading every paragraph first
  • see how each figure contributes to the argument
  • identify where the paper's interpretation is stronger or weaker than the visual evidence
  • reconstruct the paper's argumentative structure
  • test whether the visuals truly carry the conclusions
  • map main claims to figures
  • identify where the paper overinterprets

When not to use

  • generic paper summary
  • substitute for full methods appraisal
  • admire visual presentation
  • invent figure contents that were not provided or visible
  • infer exact numeric values, p-values, or sample sizes when the figure text does not show them
  • patient-specific clinical advice
  • certify the paper as correct without inspecting the visual evidence basis
  • simply paraphrase figure captions
