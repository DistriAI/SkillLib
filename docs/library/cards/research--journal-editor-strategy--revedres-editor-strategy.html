revedres-editor-strategy

separate

Use when anticipating editor and reviewer expectations, framing the contribution, and positioning scope for a Review of Educational Research (RER) submission. Aligns the review with how RER is refereed; it does not run the submission preflight (revedres-submission) or draft the response to reviewers (revedres-revision).

When to use

  • Anticipating editor and reviewer expectations
  • Framing the contribution
  • Positioning scope for RER submission
  • Pre-empting predictable reviewer objections
  • Weighing RER against sibling venues
  • Checking fit with RER Guidelines for Reviewers

When not to use

  • Running the submission preflight
  • Drafting the response to reviewers
