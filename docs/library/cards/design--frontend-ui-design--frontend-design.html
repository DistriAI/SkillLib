Conflict

The anthropics/skills copy is a distinct, more rigorous design-lead procedure (subject-matter grounding, specific anti-default calibration, two-pass plan/build/critique, and typographic constraints). The other three copies are near-identical to each other (with only minor description and agent-name differences) and provide a different, more implementation-focused procedure (bold tone selection, CSS variables, specific motion libraries, and spatial composition rules). Because the anthropics copy lacks the specific implementation guidelines of the others, and the others lack the rigorous planning and anti-default calibration of the anthropics copy, crowning one would hide a real alternative approach.
