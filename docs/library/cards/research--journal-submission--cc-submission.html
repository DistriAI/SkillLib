cc-submission

separate

Use when running the final pre-submission preflight for Cancer Cell (Cell Press) — file completeness, STAR Methods / Key Resources Table, deposition accessions, statistics reporting, ethics statements, figure integrity, and portal logistics. It is the last gate before submitting.

When to use

  • final pre-submission preflight
  • file completeness check
  • STAR Methods and Key Resources Table verification
  • deposition accession verification
  • statistics reporting check
  • ethics statement verification
  • figure integrity check
  • portal logistics verification

When not to use

  • formatting advice before blockers are resolved
  • polishing before re-routing decision
  • submitting with data available on request
  • submitting with missing RRIDs
  • submitting with unauthenticated cell lines
  • submitting with representative images lacking quantification
  • submitting with mismatched accessions
  • submitting with broken cross-references
