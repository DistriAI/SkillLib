kotlin-tooling-cocoapods-spm-migration

separate

Migrate KMP projects from CocoaPods (kotlin("native.cocoapods")) to Swift Package Manager (swiftPMDependencies DSL) — replaces pod() with swiftPackage(), transforms cocoapods.* imports to swiftPMImport.*, and reconfigures the Xcode project.

When to use

  • Migrate KMP projects from CocoaPods to Swift Package Manager
  • Replace pod() with swiftPackage()
  • Transform cocoapods.* imports to swiftPMImport.*
  • Reconfigure Xcode project
  • Update Gradle configuration
  • Remove CocoaPods plugin from Gradle
  • Verify Gradle and Xcode builds
  • Write MIGRATION_REPORT.md

When not to use

  • Projects using Kotlin versions earlier than 2.4.0-Beta2 without upgrade
  • Projects not using Xcode 16.4 or 26.0+
