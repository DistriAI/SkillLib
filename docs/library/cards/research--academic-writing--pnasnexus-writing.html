pnasnexus-writing

separate

Use to choose the PNAS Nexus article type, structure the main text, and hold the page-based length budget — Research Report / Brief Report / Perspective / Review / Registered Report — keep Materials and Methods in the main text, and select the required research-area classification at submission.

When to use

  • choose the PNAS Nexus article type
  • structure the main text
  • hold the page-based length budget
  • keep Materials and Methods in the main text
  • select the required research-area classification
  • order Results by logic of the claim
  • manage length by moving detail to Supporting Information

When not to use

  • writing the Significance Statement
  • writing the Abstract
  • determining venue fit
