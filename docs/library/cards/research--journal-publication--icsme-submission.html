icsme-submission

separate

Use when auditing an IEEE ICSME research-track submission for EasyChair readiness, covering the abstract-then-paper two-step deadline, the IEEEtran two-column 10+2 page budget, double-anonymous review, the open-science data-availability expectation, and desk-reject triage before the AoE cutoff.

When to use

  • auditing ICSME research-track submissions
  • checking EasyChair readiness
  • verifying abstract-then-paper deadlines
  • checking IEEEtran two-column 10+2 page budget
  • performing double-anonymous review sweep
  • checking open-science data-availability expectations
  • triaging desk-reject risks

When not to use

  • ACM acmart single-column formatting
  • ICSE-adjacent ACM venues
  • FSE submissions
