Guide for translating Python classes, inheritance, and object-oriented patterns to Scala. Use when converting Python code with classes, dataclasses, abstract classes, inheritance, properties, static methods, class methods, or design patterns.

When to use

  • translating Python classes to Scala
  • converting Python dataclasses to case classes
  • translating Python properties to Scala
  • converting Python inheritance to Scala
  • translating Python abstract classes and interfaces
  • converting Python multiple inheritance to traits
  • translating Python static and class methods
  • converting Python design patterns like factory and enums
