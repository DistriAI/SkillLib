pr-squash-message

separate

Generate one short Conventional Commits squash message describing only the net diff between the PR's base and head, set its header as the PR title, validate it with the repository's commitlint and both copy its description to the clipboard and display it, when asked for a squash message. Works in any Scenario repository, whatever its default branch.

When to use

  • Generate squash message for a PR
  • Describe net diff between PR base and head
  • Validate commit message with commitlint
  • Set PR title from squash message header
  • Copy squash message description to clipboard
  • Handle trusted and untrusted PRs
  • Determine commit type from net effect
  • Format co-authored-by footer

When not to use

  • Building message from git log history
  • Describing individual commits or journey
  • Including per-file inventory or test-case lists
  • Including verification narrative or review history
  • Hardcoding base branch name
  • Running branch code on untrusted PRs without asking
