research-audience-signals-and-hooks

separate

For a list of companies, finds dated, linked timing signals from the last 90 days (funding, new leaders, hiring, launches), drops stale ones and noise, scores timing, and gives one personal hook per person from their recent public work. Facts only, no message copy. Use alone when you already have the company list and, for hooks, the people; otherwise run research-audience.

When to use

  • finding dated timing signals
  • scoring timing
  • finding personal hooks
  • filtering stale signals
  • filtering noise
  • recording facts with URLs and dates

When not to use

  • writing outreach copy
  • generating message copy
  • using banned topics
