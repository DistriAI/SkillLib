jetson-customize-pinmux

separate

Per-pin SFIO / direction / initial-state configurator for a Jetson Orin or Thor custom carrier from the pinmux XLSM. Do NOT use for kernel-DT overlay or ODMDATA edits.

When to use

  • configure pin
  • set SFIO
  • edit pinmux DTSI
  • set pin direction
  • set initial state
  • repurpose a CVM ball
  • fix HSIO pin mismatch
  • author pinmux from XLSM

When not to use

  • kernel-DT overlay
  • ODMDATA edits
  • OVERLAY_DTB_FILE edit
  • render_conf.py hand-off
