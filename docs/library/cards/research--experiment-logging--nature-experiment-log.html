nature-experiment-log

separate

标准化实验日志记录——直接上传或读取本地图片、语音和文字，产出带 YAML frontmatter 的 Markdown；可选集成飞书 CLI 与 Obsidian。

When to use

  • 标准化实验日志记录
  • 处理上传的图片、音频、语音转录或文字
  • 读取本地文件或文件夹路径并整理
  • 从飞书群读取消息和附件
  • 生成带 YAML frontmatter 的 Markdown 日志
  • 归档原始附件到指定目录
  • 更新实验索引和异常记录
  • 集成 Obsidian vault 建立索引

When not to use

  • 猜测缺失或模糊的实验条件或结果
  • 在未指定目录时擅自选择保存路径
