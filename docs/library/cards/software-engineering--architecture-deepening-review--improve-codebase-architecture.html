improve-codebase-architecture

authentic

Scan a codebase for deepening opportunities, present them as a visual HTML report, then grill through whichever one you pick.

When to use

  • Scanning codebase for architectural friction
  • Identifying shallow modules
  • Proposing deepening opportunities
  • Generating visual HTML architecture reports
  • Grilling through selected refactoring candidates
  • Updating domain glossary and ADRs

When not to use

  • Proposing interfaces before user selection
  • Re-litigating existing ADRs without real friction
  • Listing every theoretical refactor an ADR forbids
