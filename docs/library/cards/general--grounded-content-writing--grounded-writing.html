grounded-writing

separate

Use when drafting or reviewing public developer documentation, other text the user will publish or send, or a user-owned draft under an explicit editorial review, including review comments, replies, and internal technical reports.

When to use

  • drafting public developer documentation
  • reviewing public developer documentation
  • drafting text the user will publish or send
  • reviewing text the user will publish or send
  • editorial review of user-owned drafts
  • review comments
  • replies
  • internal technical reports

When not to use

  • ordinary assistant replies
  • quoted source text
  • prose attributed to someone else
