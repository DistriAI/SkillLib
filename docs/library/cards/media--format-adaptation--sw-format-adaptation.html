sw-format-adaptation

separate

Screenplay format, page craft, the writing process and adaptation (剧本格式/写作流程/改编) — merged from Wendy Henson (spec format rules), Richard Walter (page craft, revision), Neill Hicks (selling vs shooting script, draft chain), Syd Field (master shot, card method, adaptation as original work), Robert McKee (step outline → treatment → screenplay), Julian Hoxter (format elements, adaptation four questions), Diamond & Weissman (one-page nine-step) and Eric Bork — plus an exact typographic grid, element conventions (V.O./O.S., MORE/CONT'D, dual dialogue), a machine-writable output contract (Fountain, with forced markers for Chinese), and Asian industry formats (Chinese 场号制 影视剧本格式, Japanese 柱・ト書き・セリフ / 決定稿). Use when formatting a spec script, choosing the output file format, deciding what goes in action lines, planning drafts and outlines, cutting pages, adapting a novel, play or true story, writing a Chinese TV/film or Japanese-style script page, or preparing a submission-ready draft.

When to use

  • formatting a spec script
  • choosing the output file format
  • deciding what goes in action lines
  • planning drafts and outlines
  • cutting pages
  • adapting a novel, play or true story
  • writing a Chinese TV/film or Japanese-style script page
  • preparing a submission-ready draft

When not to use

  • writing shooting scripts with camera directions
  • mimicking online storyboard scripts
  • using non-standard fonts to manipulate page count
