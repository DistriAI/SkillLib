fda-database

combined

Query openFDA API for drugs, devices, adverse events, recalls, regulatory submissions (510k, PMA), substance identification (UNII), for FDA regulatory data analysis and safety research. Query the openFDA API to retrieve FDA regulatory datasets (drugs, devices, adverse events, recalls, submissions, UNII) when you need programmatic safety/regulatory evidence for analysis or research.

When to use

  • **Drug research**: Safety profiles, adverse events, labeling, approvals, shortages
  • **Medical device surveillance**: Adverse events, recalls, 510(k) clearances, PMA approvals
  • **Food safety**: Recalls, allergen tracking, adverse events, dietary supplements
  • **Veterinary medicine**: Animal drug adverse events by species and breed
  • **Chemical/substance data**: UNII lookup, CAS number mapping, molecular structures
  • **Regulatory analysis**: Approval pathways, enforcement actions, compliance tracking
  • **Pharmacovigilance**: Post-market surveillance, safety signal detection
  • **Scientific research**: Drug interactions, comparative safety, epidemiological studies

Skill page

Conflict

The three copies describe the same openFDA Python client, but they are not interchangeable. The Vibe-Skills and OpenClaw copies are near-identical reference documents that enumerate endpoints and point to reference files, while the aipoch copy adds concrete, runnable analysis patterns (safety profile, monthly trend, serious-event rate, pagination/aggregation notes, dependency pinning) and names additional reference files. Crowning one copy would hide either the detailed endpoint catalog or the operational analysis steps, so the catalog should combine them.
