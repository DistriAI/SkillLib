jpube-writing-style

separate

Use when polishing prose for a Journal of Public Economics (JPubE / JPubEc) manuscript — a 250-word abstract stating purpose, results, and policy conclusion; an intro that lands the government-role question; author-date references; and clear translation of estimates into welfare terms. Late-stage polish; it does not change the analysis.

When to use

  • Polishing prose for JPubE manuscripts
  • Checking abstract word count and content
  • Formatting references in author-date style
  • Translating estimates into welfare terms
  • Reviewing intro structure for policy questions
  • Verifying editable source file formats
  • Declaring generative AI assistance

When not to use

  • Changing the analysis
  • Early-stage drafting
  • Routing to sibling journals like JDE or JIE
