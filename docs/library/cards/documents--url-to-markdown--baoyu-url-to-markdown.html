baoyu-url-to-markdown

combined

Fetch any URL and convert to markdown using baoyu-fetch CLI (Chrome CDP with site-specific adapters). Built-in adapters for X/Twitter, YouTube transcripts, Hacker News threads, and generic pages via Defuddle. Handles login/CAPTCHA via interaction wait modes. Use when user wants to save a webpage as markdown. Fetch any URL and convert to markdown using Chrome CDP. Saves the rendered HTML snapshot alongside the markdown, uses an upgraded Defuddle pipeline with better web-component handling and YouTube transcript extraction, and automatically falls back to the pre-Defuddle HTML-to-Markdown pipeline when needed. If local browser capture fails entirely, it can fall back to the hosted defuddle.md API. Supports two modes - auto-capture on page load, or wait for user signal (for pages requiring login). Use when user wants to save a webpage as markdown.

When to use

  • save a webpage as markdown
  • fetch X/Twitter
  • fetch YouTube transcripts
  • fetch Hacker News threads
  • fetch generic pages via Defuddle
  • handle login/CAPTCHA

Conflict

The three copies describe the same task but disagree on the underlying tooling, CLI surface, and setup behavior. JimLiu/baoyu-skills is the most complete and appears to be the upstream procedure (baoyu-fetch CLI, site-specific adapters, media download, first-time setup). anbeime/skill is a simplified wrapper around a local main.ts script with a different flag set and no first-time setup. LeoYeAI/openclaw-master-skills is a mirror of the upstream with a different version, additional fallbacks, and a different runtime resolution strategy. Crowning one would hide the real alternatives and conflicting parameters.
