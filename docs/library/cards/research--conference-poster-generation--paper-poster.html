Conflict

The two copies are not the same procedure. The first copy is a deprecated redirect that explicitly forbids the LaTeX/tcbposter flow and instructs the agent to use /paper-poster-html. The second copy is a full LaTeX/tcbposter poster-generation skill with detailed constants, venue color schemes, LaTeX architecture constraints, and state persistence. Because they disagree on the core method and the second contains material steps absent from the first, crowning one would hide a real alternative.
