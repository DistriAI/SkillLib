run-memory

separate

Shared step of the marketing playbooks (analyze-performance, run-paid-campaigns, research-competitors, email-lifecycle): reads the last run's record, checks whether its recommendations were done and whether they worked, and saves a short record of this run for the next one. Loaded by those playbooks; not for direct use.

When to use

  • Reading last run's record
  • Checking if recommendations were done
  • Checking if recommendations worked
  • Saving short record of this run
  • Weekly or monthly automation memory
  • Playbooks that run more than once for the same brand

When not to use

  • Direct use
  • One-off makers
  • Single post
  • One photo set
  • Replacing playbook working logs
  • Keeping a second, different copy of state
