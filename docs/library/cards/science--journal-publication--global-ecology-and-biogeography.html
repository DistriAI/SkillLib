global-ecology-and-biogeography

separate

Use when targeting Global Ecology and Biogeography (GEB) or deciding whether a macroecology/biogeography manuscript fits this large-scale, pattern-focused venue. Encodes the journal's fit, framing, method-and-evidence bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting Global Ecology and Biogeography
  • deciding if a macroecology manuscript fits GEB
  • choosing between GEB, Journal of Biogeography, Ecography, and Ecology Letters
  • testing macroecological theory across large spatial extents
  • assessing GEB scale and spatial-statistics expectations
  • evaluating desk-reject criteria for GEB
  • framing broad-scale biodiversity patterns for GEB
  • checking GEB house style and structure

When not to use

  • replacing the journal's current official submission guidelines
  • local or site-specific results without macroecological generality
  • pattern description without a process-level advance
