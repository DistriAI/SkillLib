anmath-supplementary

separate

Use when deciding what belongs in appendices versus the main text of a pure-mathematics manuscript for Annals of Mathematics — technical/auxiliary results, long computations, and machine-assisted computation. Math journals generally have no science-style "supplemental material"; everything essential stays in the main text.

When to use

  • deciding placement of technical/auxiliary results
  • handling long computations
  • documenting machine-assisted computation
  • structuring appendices for pure-mathematics manuscripts
  • determining if auxiliary material requires a companion paper

When not to use

  • science-style supplemental material
  • hiding proof gaps in appendices
  • parking unproved steps in companion papers
