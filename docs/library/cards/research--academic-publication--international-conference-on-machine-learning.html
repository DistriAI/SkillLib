international-conference-on-machine-learning

separate

Use when targeting International Conference on Machine Learning (ICML) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for AI/ML flagship.

When to use

  • targeting International Conference on Machine Learning (ICML)
  • deciding whether a computer-science manuscript fits this venue
  • conference fit, framing, evidence bar, submission-cycle checks
  • rebuttal posture, and desk-reject risks for AI/ML flagship
  • manuscript in core machine learning methods needs a conference-fit read
  • re-framed from journal style or arXiv style into a selective CS conference narrative
  • evidence-gap, anonymity, artifact, rebuttal, or re-routing diagnosis for this venue
  • core machine learning methods, theory, applications, and responsible deployment

When not to use

  • substitute for the current year's CFP, author kit, ethics policy, or submission portal
  • representation-learning framing to ICLR
  • broader AI/society/systems mix to NeurIPS
  • statistical inference to AISTATS
  • ML systems to MLSys
  • vision to CVPR/ICCV/ECCV
  • NLP to ACL-family
  • learning theory to COLT
