agent-manager

authentic

Manage multiple local CLI agents via tmux sessions (start/stop/monitor/assign) in an explicitly authorized workspace.

When to use

  • run multiple local CLI agents in parallel (separate tmux sessions)
  • start/stop agents and tail their logs
  • assign tasks to agents and monitor output
  • prepare a scoped plan for repeated agent work only when scheduling is explicitly requested

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.
