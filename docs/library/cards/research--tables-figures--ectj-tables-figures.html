ectj-tables-figures

separate

Use when compressing The Econometrics Journal (EctJ) tables, figures, Monte Carlo displays, empirical-application exhibits, theorem summaries, and appendix references under a roughly 20-page printed-paper constraint.

When to use

  • compressing EctJ tables
  • compressing EctJ figures
  • Monte Carlo displays
  • empirical-application exhibits
  • theorem summaries
  • appendix references
  • exhibit diagnosis
  • main-text compression

When not to use

  • tasks not involving EctJ exhibits
  • non-EctJ journal formatting
