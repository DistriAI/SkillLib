ier-topic-selection

separate

Use when deciding whether a question is broad and rigorous enough for an International Economic Review (IER) manuscript, and which branch (theory / structural-macro / econometric method / applied micro) frames it. Tests fit and scope; it does not invent evidence or citations.

When to use

  • deciding if a question is general-interest
  • testing if a question clears IER's broad-rigor bar
  • confirming theory fit for IER
  • choosing between IER, Econometrica/QE, top-5, and field journals
  • sharpening the research question
  • running generality, two-referee, and sibling tests

When not to use

  • inventing evidence
  • inventing citations
