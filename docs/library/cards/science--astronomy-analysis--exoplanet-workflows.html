exoplanet-workflows

separate

General workflows and best practices for exoplanet detection and characterization from light curve data. Use when planning an exoplanet analysis pipeline, understanding when to use different methods, or troubleshooting detection issues.

When to use

  • planning an exoplanet analysis pipeline
  • understanding when to use different methods
  • troubleshooting detection issues
  • exoplanet detection from light curves
  • choosing period search algorithms
  • signal validation
  • multi-planet system analysis
  • preprocessing light curve data

When not to use

  • radial velocity planet detection
  • eclipsing binaries with non-box shapes
