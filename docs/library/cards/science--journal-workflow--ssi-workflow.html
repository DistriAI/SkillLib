ssi-workflow

separate

当需要对一篇投往《中国科学：信息科学》(Scientia Sinica Informationis, SSI) 的稿件做从选题到见刊的全流程编排时调用。串联选题与栏目定位、中文写作、实验与可复现、相关工作、投稿审计、三审三校审稿、修回答复、录用定稿校样等阶段，给出各阶段的顺序、交付物、时间意识与所用技能。作为国家级大信息学科综合旗舰，本刊以重大原创与评述为主、强调科学价值与创新高度；本技能是把 12 个 SSI 技能编织起来的总控，并厘清与英文姊妹刊 Science China Information Sciences 的择一投稿关系。

When to use

  • SSI 稿件全流程编排
  • 选题与栏目定位
  • 中文写作与框架搭建
  • 实验与可复现性管理
  • 投稿审计与提交
  • 三审三校审稿流程
  • 修回答复与录用定稿
  • SSI 与 SCIS 择一投稿判断

When not to use

  • 非 SSI 期刊的独立投稿流程
  • 英文姊妹刊 SCIS 的独立投稿流程
  • 兄弟刊（如计算机学报）的独立投稿流程
