wsdm-topic-selection

separate

Use when deciding whether a project belongs at WSDM or a neighbor - tests for the web/social-data core and the practical-yet-principled bar, scope coverage from web search and recommendation to social networks and responsible web AI, routing against SIGIR, KDD, WWW, CIKM, RecSys, and ICWSM, and long-versus-short-track fit.

When to use

  • deciding if a project is WSDM-shaped
  • testing the web or social-web data gate
  • testing the practical yet principled gate
  • checking 2026 CFP scope coverage
  • routing against SIGIR, KDD, WWW, CIKM, RecSys, and ICWSM
  • assessing long-versus-short-track fit
  • evaluating foundation-model-era fit through the web lens

When not to use

  • formatting a page
  • tabular-ML, vision, and generic NLP work
  • principled-only theory toward theory-friendly venues
  • practical-only system reports toward industry tracks
  • core IR theory without web-mining angle
  • general-purpose mining/ML method with incidental web data
  • web systems, standards, platform measurement, web economics
  • learning theory or new architecture evaluated on static benchmarks
