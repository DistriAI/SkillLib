github-release-briefing

separate

Create a source-linked briefing for the latest published GitHub release of a public repository. Use for engineering teams tracking a dependency release; do not use it to publish releases or change repositories.

When to use

  • tracking a dependency release
  • briefing for latest published release
  • public GitHub repository release info

When not to use

  • publish releases
  • change repositories
  • download release assets
  • authenticate
  • modify a repository
