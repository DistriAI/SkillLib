Conflict

The two copies describe different browser automation stacks. The browserbase/skills copy is a detailed procedure for the browse CLI with local/remote modes, CDP tailing, and a large command surface. The LeoYeAI copy is a minimal Puppeteer-based skill that only documents a read command. They overlap in the goal of browsing and extracting content, but each contains material steps and constraints the other lacks, and they disagree on the underlying tooling, so crowning one would hide a real alternative.
