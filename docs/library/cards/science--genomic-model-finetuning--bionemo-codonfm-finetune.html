bionemo-codonfm-finetune

separate

Fine-tune public CodonFM Encodon checkpoints on labeled coding-sequence or coding-variant data using LoRA, head-only, or full fine-tuning. Use when a user explicitly asks to fine-tune CodonFM or Encodon for regression or classification. Support generic public-v1 Encodon workflows only; reject Decodon, MissenseDataset, missense_synom_agg, and generation workflows.

When to use

  • Fine-tune public CodonFM Encodon checkpoints
  • Labeled coding-sequence data
  • Labeled coding-variant data
  • LoRA fine-tuning
  • Head-only fine-tuning
  • Full fine-tuning
  • Regression tasks
  • Classification tasks

When not to use

  • Decodon workflows
  • MissenseDataset
  • missense_synom_agg
  • Generation workflows
