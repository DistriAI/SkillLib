pnas-citation

separate

Use to convert references to PNAS's numbered citation style — cited in order of appearance, a numbered reference list, full author lists, abbreviated journal titles. Provides formats for article/book/chapter/dataset/preprint and an author-date → PNAS conversion table. Late-stage style pass.

When to use

  • converting author-date citations to PNAS style
  • ordering reference lists by citation appearance
  • expanding truncated author lists in bibliographies
  • converting in-text citations to numeric format
  • applying PNAS reference formats for articles, books, chapters, datasets, and preprints

When not to use

  • using Science's exact reference formatting
  • alphabetizing the reference list
  • truncating author lists with 'et al.' in the bibliography
  • leaving author-date citations in a PNAS manuscript
