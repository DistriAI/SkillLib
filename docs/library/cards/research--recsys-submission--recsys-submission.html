recsys-submission

separate

Use when auditing an ACM RecSys submission before the deadline — routing between the Main, Reproducibility, Industry and Resource tracks, the ACM two-column content-page budgets with appendices counted inside, double-blind anonymization for recommender papers, the anonymous-repository expectation, and desk-reject triage.

When to use

  • Auditing ACM RecSys submissions
  • Routing between Main, Reproducibility, Industry, and Resource tracks
  • Checking ACM two-column content-page budgets
  • Verifying double-blind anonymization for recommender papers
  • Checking anonymous-repository expectations
  • Desk-reject triage

When not to use

  • Experiment design or baseline tuning details
  • Non-RecSys venue submissions
