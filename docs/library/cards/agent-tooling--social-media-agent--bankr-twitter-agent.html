bankr-twitter-agent

authentic

Build and run a Twitter/X agent with a distinct personality and automated workflows

When to use

  • creating a Twitter/X agent
  • managing a Twitter/X agent
  • automating a Twitter/X agent
  • defining agent personality and voice
  • tracking ongoing narrative and storyline
  • composing and posting tweets
  • running guardrail checks on drafts
  • routing flagged drafts to Telegram for approval

When not to use

  • cold-replies to strangers' timelines
  • quote-tweets of random accounts
  • reply-chains the agent isn't tagged in
  • trending-topic replies
  • drive-by replies to big accounts
  • autonomously tagging @bankrbot
