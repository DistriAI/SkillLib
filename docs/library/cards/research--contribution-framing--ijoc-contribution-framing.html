ijoc-contribution-framing

separate

Use when the one-sentence computational/methodological claim of an INFORMS Journal on Computing (IJOC) manuscript is not sharp, or the contribution reads as application rather than computing. Sharpens the "what is new and by how much"; it does not run the experiments that back it.

When to use

  • Sharpening the one-sentence computational claim
  • Framing contribution as method rather than application
  • Calibrating claim verbs to evidence
  • Identifying primary contribution type
  • Ensuring claim consistency across abstract, intro, and conclusion

When not to use

  • Running experiments
  • Selecting topics
  • Creating tables and figures
