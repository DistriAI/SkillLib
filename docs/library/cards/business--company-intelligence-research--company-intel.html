company-intel

combined

Research a company, industry, or competitor set using web search and seven analytical lenses. Use when you need structured intel that feeds downstream PM skills. Full company intelligence report - overview, team, funding, products, news

When to use

  • Research engine that builds deep, structured understanding of companies, industries, and competitor sets. Produces a stable output format that you can hand off to other skills and agents to generate battlecards, SWOT analyses, positioning…

When not to use

  • Generic encyclopedia lookup
  • Final deliverable creation

Skill page

Conflict

The two copies implement the same named skill but with fundamentally different procedures. The gooseworks copy is a tooling wrapper that calls a specific external API (Gooseworks/Orthogonal) via curl to retrieve brand, people, and scrape data. The deanpeters copy is a pure reasoning workflow that uses web search and seven analytical lenses to produce a structured 11-section report without any specific API dependency. They overlap in intent (company intel) but disagree on the mechanism (API calls vs. analytical reasoning) and output structure (raw data vs. structured lenses).
