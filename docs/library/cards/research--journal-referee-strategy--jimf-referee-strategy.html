jimf-referee-strategy

separate

Use when anticipating and pre-empting referee objections before submitting a Journal of International Money and Finance (JIMF) manuscript. Maps the likely international-finance pushbacks to fixes you make now; it does not draft the post-decision response (jimf-rebuttal).

When to use

  • Anticipating referee objections before submission
  • Pre-empting predictable JIMF objections
  • Deciding which checks to run now versus hold in reserve
  • Addressing framing issues that invite rejection
  • Building a pre-submission pre-emption plan
  • Pre-writing response paragraphs for dangerous objections
  • Framing contribution in cover letter to avoid desk-rejection

When not to use

  • Drafting the post-decision response
  • Responding to a real referee report after decision
