nature-ref-verifier

separate

对学术文献逐条执行多源交叉验证，逐字段对比作者、标题、年份、卷期、页码， 标记卷年/DOI年冲突、作者顺序异常、页码偏差等问题，输出结构化验证报告。 可批量处理整篇论文/开题报告的参考文献列表，也可单条校验，支持与 Zotero 同步修正。

When to use

  • 开题报告/论文提交前参考文献最终核查
  • 审稿意见指出引用错误时精准定位问题
  • 从旧项目迁移参考文献批量验证有效性
  • Zotero 库定期健康检查
  • 单条参考文献校验
  • BibTeX 文件逐条校验
  • DOI 可解析性检查
  • 字段级对比与差异评级

When not to use

  • 产品手册/专利元数据验证
