validation

separate

Validate project and scene health plus cleanup

When to use

  • Checking broken or missing references
  • Validating scene/project integrity
  • Cleaning up before a build
  • Find objects with missing scripts
  • Remove missing script components
  • Remove empty folders
  • Find potentially unused assets
  • Check texture sizes

When not to use

  • Unused/duplicate asset cleanup
  • Missing script fix via cleaner module
  • Compile errors
  • Cleanup operations in cleaner module
