ssc-theory-contribution

separate

Use when articulating the original theoretical contribution for 《中国社会科学》 (Social Sciences in China) — turning empirical findings into a concept / proposition / analytical framework, and positioning the work within China's autonomous knowledge system (自主知识体系) rather than verifying imported theory. Use when the contribution still reads as "we find that X affects Y".

When to use

  • articulating original theoretical contribution
  • turning empirical findings into concepts or propositions
  • positioning work within China's autonomous knowledge system
  • defining contribution as new concept, proposition, or framework
  • calibrating contribution weight for 《中国社会科学》
  • performing proposition pressure tests
  • drafting contribution statements
  • conducting mini-refinement exercises

When not to use

  • verifying imported theory
  • stating contributions as 'we find that X affects Y'
  • using 'enriched XX research' as a contribution
  • listing findings without theoretical refinement
  • treating special national conditions as contribution without generalization
