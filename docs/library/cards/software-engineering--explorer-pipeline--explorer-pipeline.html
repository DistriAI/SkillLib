explorer-pipeline

authentic

Use when asked to make an interactive 3D explorer of a topic from start to finish, go from a topic to a clickable 3D learning page, or run the whole 3D explorer process. Produces a staged run of explorer-interface-brief, model-prompt-pack and explorer-viewer-builder in order for one topic, with the hand-offs between them, and a build checklist that tracks every asset, source and test until the explorer ships.

When to use

  • make an interactive 3D explorer of a topic from start to finish
  • go from a topic to a clickable 3D learning page
  • run the whole 3D explorer process
  • run the whole 3D explorer pipeline

When not to use

  • starting with the 3D model without the brief
  • declaring it done before the mesh-name check
  • skipping the subject-expert review
