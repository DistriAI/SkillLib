itcs-review-process

separate

Use to model the ITCS reviewing pipeline — a program committee plus external reviewers, conceptual-novelty weighting, lightweight double-blind, no author-response/rebuttal phase, and a single accept/reject decision — and to understand where the (limited) author leverage actually is.

When to use

  • modeling the ITCS reviewing pipeline
  • understanding ITCS decision criteria
  • calibrating expectations for ITCS submissions
  • pre-empting reviewer objections
  • understanding lightweight double-blind rules
  • identifying author leverage stages

When not to use

  • writing rebuttals
  • handling revise-and-resubmit
  • managing second-round reviews
  • anonymizing reference lists
