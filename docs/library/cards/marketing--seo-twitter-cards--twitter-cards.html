twitter-cards

separate

When the user wants to add, audit, implement, or optimize Twitter Card metadata for X link previews, including twitter:card, twitter:title, twitter:description, twitter:image, or X previews. For a full metadata lifecycle use page-metadata; for broader social previews use open-graph.

When to use

  • Add Twitter Card metadata
  • Audit Twitter Card metadata
  • Implement Twitter Card metadata
  • Optimize Twitter Card metadata
  • Configure X link previews
  • Set twitter:card tags
  • Set twitter:image tags
  • Define X-specific copy

When not to use

  • Full metadata lifecycle
  • Broader social previews
  • Open Graph tags
  • X post copy and engagement
  • Programmatic Twitter Card image generation
