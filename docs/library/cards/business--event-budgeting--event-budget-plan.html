Build an event budget that survives the event — every cost line including the ones people forget, the contingency sized to the actual risk, and the tracking that shows overspend while it can still be stopped. Use when asked to build an event budget, cost an event, price a conference or wedding, or explain why an event went over budget. Produces the full cost breakdown, the commonly-forgotten lines, the contingency sizing, the payment and cash-flow schedule, the per-head economics, and the variance tracker.
