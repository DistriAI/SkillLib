card-sort-analysis

separate

Analyse open or closed card sort results into a proposed grouping and label set. Use after running a sort study. For turning that evidence into a full structure, use `information-architecture` (ux-strategy).

When to use

  • Analyzing card sorting results
  • Informing information architecture decisions
  • Identifying common category patterns
  • Creating a similarity matrix
  • Recommending IA structure
  • Flagging ambiguous items
  • Suggesting next steps

When not to use

  • Turning evidence into a full structure
