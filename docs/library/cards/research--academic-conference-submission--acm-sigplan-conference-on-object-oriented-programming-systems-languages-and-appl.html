Use when targeting ACM SIGPLAN Conference on Object-Oriented Programming, Systems, Languages, and Applications (OOPSLA) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for programming languages.

When to use

  • targeting OOPSLA
  • deciding if a manuscript fits OOPSLA
  • conference fit read for programming languages
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • programming languages and software systems contributions
  • language design, types, verification, and empirical PL
  • submission strategy and venue selection

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • generic CS papers without specific PL subcommunity focus
  • language resources and computational linguistics
  • functional-programming-specific work
  • PL implementation/performance where PLDI is primary
  • manuscripts where OOPSLA is merely a convenient deadline
