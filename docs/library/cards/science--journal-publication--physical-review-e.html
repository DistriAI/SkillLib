physical-review-e

separate

Use when targeting Physical Review E (PRE) or deciding whether a statistical, nonlinear, soft-matter, or complex-systems physics manuscript fits this APS archival venue. Encodes the journal's fit, framing, method-and-evidence bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting Physical Review E
  • deciding if a statistical physics manuscript fits PRE
  • deciding if a nonlinear dynamics manuscript fits PRE
  • deciding if a soft-matter manuscript fits PRE
  • deciding if a complex-systems manuscript fits PRE
  • choosing between PRE, PRL, and specialist journals
  • checking PRE scope boundaries
  • checking PRE desk-reject criteria

When not to use

  • replacing the journal's current official submission guidelines
