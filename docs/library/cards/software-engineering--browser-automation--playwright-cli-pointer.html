playwright-cli-pointer

authentic

Point to Microsoft's playwright-cli and its skill, and explain when to use it. Use when asked how to install playwright-cli, how to verify a page in a real browser at mobile and desktop widths, or what handles the verification stage of the design pipeline. Produces the install commands, the Node prerequisite, a screenshot routine for both widths, an optional interface guidelines audit step, and credit to the author with a link. Contains no upstream skill content.

When to use

  • installing playwright-cli
  • verifying a page in a real browser
  • checking mobile and desktop widths
  • verification stage of the design pipeline
  • taking screenshots of a main flow
  • fixing layout issues and re-checking

When not to use

  • when nothing is built yet
  • getting a design opinion
  • when a working browser tool is already in the session
