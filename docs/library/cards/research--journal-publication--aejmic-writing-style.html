aejmic-writing-style

separate

Use when prose buries the result or the abstract/intro do not land for an American Economic Journal: Microeconomics (AEJ: Micro) manuscript. Applies AEA house style and the theory-paper intro arc; it does not produce the result (see aejmic-theory-model) or build exhibits (see aejmic-tables-figures).

When to use

  • AEJ: Micro manuscript writing style
  • Theory-paper intro arc
  • Abstract and introduction polish
  • AEA house style conventions
  • Late-stage polish before submission

When not to use

  • Producing the result
  • Building exhibits
  • Model and proofs settlement
