Model editable meshes with ProBuilder for blockout

When to use

  • Blocking out levels
  • Building or editing ProBuilder geometry
  • Prototyping shapes in-editor
  • Procedural mesh refinement
  • Level geometry creation

When not to use

  • Regular primitive GameObjects
  • Ordinary primitive objects without editable topology
  • Material asset creation
  • Shader work
