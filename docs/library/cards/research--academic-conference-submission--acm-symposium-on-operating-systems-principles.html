Use when targeting ACM Symposium on Operating Systems Principles (SOSP) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for systems flagship.

When to use

  • targeting ACM Symposium on Operating Systems Principles (SOSP)
  • deciding whether a computer-science manuscript fits this venue
  • conference fit, framing, evidence bar, submission-cycle checks
  • rebuttal posture, and desk-reject risks for systems flagship
  • operating systems, distributed systems, storage, reliability, security, and systems abstractions
  • re-framing from journal style or arXiv style into a selective CS conference narrative
  • evidence-gap, anonymity, artifact, rebuttal, or re-routing diagnosis

When not to use

  • substitute for the current year's CFP, author kit, ethics policy, or submission portal
  • recommendation/ranking behavior, user modeling, platform evaluation, or recommender fairness
  • implementation-heavy systems (OSDI)
  • networked systems (NSDI/SIGCOMM)
  • storage depth (FAST)
  • hardware/software co-design (ASPLOS)
  • security venues when the threat model is central
