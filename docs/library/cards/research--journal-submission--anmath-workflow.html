anmath-workflow

separate

Use when deciding which anmath-* sub-skill to invoke next, or when sequencing work on a pure-mathematics manuscript from scope check through major revision for an Annals of Mathematics submission. Routes — does not replace — the specialized skills.

When to use

  • Deciding which anmath-* sub-skill to invoke next
  • Sequencing work on a pure-mathematics manuscript
  • Finding the current bottleneck in a draft
  • Switching into revision mode after receiving a referee report
  • Confirming the result clears the Annals importance bar
  • Preparing the final preflight for submission
  • Anticipating how an expert referee will probe the proof

When not to use

  • Replacing specialized anmath-* skills
  • Generic LaTeX or writing optimization for readability alone
  • Polishing exposition while a proof gap remains open
  • Drafting a revision reply before fixing the text
  • Using anmath-supplementary as a dumping ground for essentials
