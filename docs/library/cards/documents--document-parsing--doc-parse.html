doc-parse

separate

将 PDF/PPT/Excel/Word 等多格式文档解析为结构化 Markdown，并输出元数据与解析置信度，作为 RAG 与四色卡片的数据底座。

When to use

  • PDF 解析
  • PPT 解析
  • Excel 解析
  • Word 解析
  • 多格式文档解析
  • 结构化 Markdown 生成
  • RAG 数据底座
  • 四色卡片数据底座

When not to use

  • 未通过安全扫描的文件
  • 残缺结果输出
