When to use

  • create a campaign report
  • build an executive summary
  • deliver client results

Skill page

Conflict

The three skills share the name 'report-generator' but target completely different domains and workflows. The first is for influencer marketing campaign reports with strict privacy/authorization constraints. The second is for SEO/GEO analysis reports with multi-format output (HTML/JSON/Excel) and visualization. The third is a specific utility for video compression statistics using ffprobe. None of these are reproductions of the others; they are distinct tools that happen to share a generic name. Combining them is necessary to preserve the distinct procedures for marketing, SEO, and video processing.
