corl-supplementary

separate

Use when assembling CoRL supplementary material — the strongly encouraged overview video under the 250 MB cap and roughly three minutes, the optional appendix inside the same PDF that reviewers need not read, code and data attachments, and anonymization of everything, with the PMLR no-video rule shaping camera-ready plans.

When to use

  • assembling CoRL supplementary material
  • creating overview video under 250 MB cap
  • structuring optional appendix in same PDF
  • preparing anonymized code and data attachments
  • planning camera-ready external hosting
  • anonymizing video and code bundles

When not to use

  • writing the main 8-page paper body
  • submitting to non-CoRL venues
  • handling PMLR proceedings pipeline directly
