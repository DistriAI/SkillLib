Connect Codex to any app via the Composio CLI. Send emails, create issues, post messages, update databases - take real actions across Gmail, Slack, GitHub, Notion, and 1000+ services from the terminal.

When to use

  • **Send that email** instead of drafting it
  • **Create that issue** instead of describing it
  • **Post that message** instead of suggesting it
  • **Update that database** instead of explaining how

When not to use

  • Drafting emails
  • Describing issues
  • Suggesting messages
  • Explaining how to update databases

Skill page

Conflict

Both copies describe the same goal (using Composio to take real actions across 1000+ apps) and share the same supported-app categories and examples. However, they disagree on the primary interface and setup: one is a Claude Agent SDK / MCP integration using COMPOSIO_API_KEY and a Python client, while the other is a Codex/terminal workflow using the Composio CLI (composio login, link, execute, run, proxy). Each contains material steps the other lacks, so crowning one would hide a real alternative.
