hsb-flash

separate

Flash the FPGA on an HSB board connected to an NVIDIA devkit. Supports HSB Lattice boards (FPGA versions 2407, 2412, 2507, 2510) and Leopard Imaging VB1940 "all-in-one" cameras (FPGA versions 2507, 2510). Uses release-specific YAML manifests and board-type-specific program commands. Lattice and VB1940 commands must never be mixed.

When to use

  • Flash HSB Lattice boards
  • Flash Leopard Imaging VB1940 cameras
  • Upgrade or downgrade FPGA firmware
  • Detect board type
  • Read current FPGA version
  • Select target FPGA version
  • Execute flashing procedure
  • Clean up flash artifacts

When not to use

  • Mixing Lattice and VB1940 commands
  • Running automatically without explicit user invocation
  • Proceeding if board type is ambiguous or mismatched
