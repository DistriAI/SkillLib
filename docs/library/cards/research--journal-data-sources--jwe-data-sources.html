jwe-data-sources

separate

Use when choosing or defending the data behind a 《世界经济》 (The Journal of World Economy) manuscript — customs micro data (firm-product-destination), cross-country panels, and GVC / input-output decomposition (KWW value-added, ADB / WIOD MRIO). Steers away from generic provincial panels toward internationally-credible sources.

When to use

  • Choosing data for 《世界经济》 manuscripts
  • Customs micro data (firm-product-destination)
  • Cross-country panels
  • GVC / input-output decomposition
  • KWW value-added decomposition
  • ADB / WIOD MRIO
  • Defending data international attributes
  • Data matching and cleaning for trade research

When not to use

  • Generic provincial panels
  • Listed company panels without international dimension
  • Tasks not related to 《世界经济》 journal requirements
