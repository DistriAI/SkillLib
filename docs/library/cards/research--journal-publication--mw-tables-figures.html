mw-tables-figures

separate

用于最终化《管理世界》稿件的回归表与图形，使表图成为审稿专家判断"研究是否规范"的正向信号。Use when 主表列数过多（8 列以上）被吐槽信息密度高、表格用了边框/阴影/颜色不合本刊规范、标准误用了 t/z 值、或图形分辨率不足/配色不专业（彩虹色）时使用。锚定《管理世界》国务院发展研究中心主办、规范实证大刊的呈现传统，落实三线表（无竖线、≤6 列）、聚类标准误置于括号、注释含聚类层次与显著性定义、图形≥300dpi 与双主色克制，使表图达到本刊已刊论文形态。 本技能服务于《管理世界》(Management World, MW)。

When to use

  • 主表列数过多（8 列以上）被吐槽信息密度高
  • 表格用了边框/阴影/颜色不合本刊规范
  • 标准误用了 t/z 值
  • 图形分辨率不足/配色不专业（彩虹色）

When not to use

  • 定性/案例研究
