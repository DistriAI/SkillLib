lang-data-and-transparency

separate

Use when preparing the data, annotation, and reproducibility materials for a Language (LSA) manuscript — shared datasets and code, glossed corpora, sound files, and the ethics of working with language consultants and communities. Language values transparent, documented data; over-stating a mandated deposit is as wrong as hiding materials. Documents and shares; it does not run the analysis.

When to use

  • Assembling data/code/annotation for submission
  • Deciding what can and cannot be shared
  • Writing a data-availability statement
  • Documenting elicitation and transcription workflow
  • Sharing analysis-ready data and scripts
  • Archiving recordings and annotations
  • Anonymizing speakers and managing consent
  • Executing a transparency review pass

When not to use

  • Running the analysis
  • Inventing a journal replication mandate
  • Treating community data as open without consent
  • Exposing speaker identities
