send-email-tool

separate

邮件发送工具。配置 SMTP 发件人后，通过脚本发送纯文本或 HTML 邮件，支持附件、抄送、密送。在需要发送邮件通知、报告、自动化邮件时触发。

When to use

  • 发送纯文本邮件
  • 发送 HTML 邮件
  • 发送带附件的邮件
  • 发送抄送和密送邮件
  • 发送 Markdown 格式邮件
  • 内嵌图片到邮件正文
  • 使用模板渲染邮件
  • 管理 SMTP 发件人配置

When not to use

  • 接收邮件
  • 管理邮件列表
  • 非 SMTP 协议邮件发送
