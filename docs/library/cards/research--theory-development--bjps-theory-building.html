bjps-theory-building

separate

Use when building the theoretical argument of a British Journal of Political Science (BJPS) manuscript into a contribution of general interest — whether the work is formal/game-theoretic, empirical with explicit mechanisms, interpretive, or normative. BJPS rewards a clear, portable argument over a bare finding. Structures the argument; it does not run analyses.

When to use

  • building theoretical argument
  • formal/game-theoretic work
  • empirical with explicit mechanisms
  • interpretive work
  • normative work
  • stating mechanisms, assumptions, and scope conditions
  • deciding what to model in formal modeling

When not to use

  • running analyses
