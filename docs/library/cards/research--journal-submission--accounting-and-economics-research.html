Use when targeting 《会计与经济研究》(Accounting and Economics Research — 上海市教委主管、上海立信会计金融学院主办、双向匿名评审、不收版面费的财经双月刊) or deciding whether a Chinese accounting/finance/econ manuscript fits this venue. Encodes the journal's fit, framing, abstract/keyword/citation house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting 《会计与经济研究》
  • deciding if a manuscript fits the venue
  • rewriting a manuscript for the journal's narrative
  • listing high-frequency rejection risks
  • checking abstract and keyword house style
  • verifying official submission requirements

When not to use

  • replacing the latest official submission guidelines
  • using second-hand submission website formats
  • submitting manuscripts where accounting is not the core contribution
