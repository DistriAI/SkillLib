sandbox-simulator

separate

沙盘推演系统：模拟多人物社交对话互动。基于 sessions_spawn 能力实现并行推演， 支持10+人物、5个并行session、分批调度。用户可作为干预者暂停、修改状态、注入事件。 所有数据以 Markdown 文件存储，支持命令和自然语言双模式交互。

When to use

  • Simulating multi-character social dialogue
  • Parallel execution of character roles
  • Managing simulation state and history
  • User intervention via pause, modify, or inject
  • Batch scheduling of character tasks
  • Generating status panels and event summaries

When not to use

  • Direct execution of file read/write operations
  • Direct use of exec or search tools
  • Single-character roleplay without simulation context
