iclr-related-work

separate

Use when positioning an ICLR paper against prior work, concurrent OpenReview submissions, arXiv papers, benchmark lineages, and adjacent learning-representation claims. Use when a reviewer cites a paper you missed, when a public comment disputes your novelty, or when separating "shares a component with" from "solves the same representation-learning problem" so the claim survives permanent public scrutiny.

When to use

  • positioning an ICLR paper against prior work
  • addressing concurrent OpenReview submissions
  • comparing against arXiv papers
  • analyzing benchmark lineages
  • separating shared components from same problem solving
  • responding to reviewer citations of missed papers
  • defending novelty against public comments

When not to use

  • polishing prose without addressing novelty risk
  • making priority arguments without documented dates
  • using dismissive language toward prior work
