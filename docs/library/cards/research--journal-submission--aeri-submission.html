aeri-submission

separate

Use when running the final pre-submission preflight for American Economic Review: Insights (AER: Insights) via the AEA/ScholarOne submission system — the word-count and exhibit-count gates, abstract limit, fees, author metadata, declarations, and the AEA Data and Code Availability Policy. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • verifying word count and exhibit count gates
  • checking abstract limit
  • confirming fees and author metadata
  • verifying declarations and data/code policy
  • checking single-blind author metadata

When not to use

  • drafting content
