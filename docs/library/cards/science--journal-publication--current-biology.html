current-biology

separate

Use when targeting Current Biology or deciding whether a general-biology manuscript fits this venue. Encodes the journal's fit, framing, method-and-evidence bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting Current Biology
  • deciding if a general-biology manuscript fits
  • assessing novelty and completeness for evolutionary biology, ecology, or animal behavior
  • evaluating cross-disciplinary scope
  • assessing desk-reject patterns
  • re-routing options
  • framing and re-framing manuscripts
  • checking method-and-evidence bar

When not to use

  • replacing the journal's current official submission guidelines
