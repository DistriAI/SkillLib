bio-genome-assembly-assembly-polishing

separate

Polish genome assemblies to reduce errors using short reads (Pilon), long reads (Racon), or ONT-specific tools (medaka). Essential for improving long-read assembly accuracy.

When to use

  • Polishing genome assemblies
  • Reducing assembly errors
  • Improving long-read assembly accuracy
  • Using Pilon for Illumina polishing
  • Using medaka for ONT assemblies
  • Using Racon for quick long-read polishing
  • Executing multi-round polishing workflows

When not to use

  • De novo genome assembly
  • Read alignment without polishing
  • Variant calling
  • Sequence quality control
