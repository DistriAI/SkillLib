cc-sdd-new-agent

separate

Add or extend coding-agent support in cc-sdd by executing the SOP in docs/cc-sdd/sop-new-agent.md end-to-end. Use when introducing a new agent, adding a subagent-capable variant, or evaluating migration of an existing supported agent to skills-based templates.

When to use

  • introducing a new agent
  • adding a subagent-capable variant
  • evaluating migration of an existing supported agent to skills-based templates
  • creating plan document for agent integration
  • implementing agent registry and manifest updates
  • converting YAML frontmatter to target-agent format
  • running verification tests for new agent

When not to use

  • inventing a new process instead of using existing SOP
  • skipping the plan document without explicit user request
