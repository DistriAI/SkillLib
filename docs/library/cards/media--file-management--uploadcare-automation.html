uploadcare-automation

authentic

Automate Uploadcare file management including listing, storing, inspecting, downloading, and organizing file groups through natural language commands

When to use

  • listing project files
  • storing uploads permanently
  • retrieving file metadata
  • getting download URLs
  • managing file groups
  • filtering files by storage status
  • sorting files by upload date
  • paginating file lists

When not to use

  • uploading files
  • using cursor-based pagination
