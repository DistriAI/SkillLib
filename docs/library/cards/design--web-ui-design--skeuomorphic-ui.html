skeuomorphic-ui

separate

Create skeuomorphic web UI surfaces with layered gradients, stacked inner and outer shadows, reflective gradient borders, micro texture, and embossed text or icon details. Use when asked for pressed, carved, tactile, realistic, soft-plastic, soft-metal, or premium physical interface styling.

When to use

  • tactile cards, buttons, switches, dials, inputs, toolbars, or controls
  • physical depth without glossy or cartoonish appearance
  • pressed, carved, raised, soft-plastic, soft-metal, or premium hardware-like UI

When not to use

  • glossy or cartoonish surfaces
  • mixing glassmorphism, neumorphism, and skeuomorphism in the same component
