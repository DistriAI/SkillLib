naacl-artifact-evaluation

separate

Use when packaging datasets, models, prompts, or annotation materials for a NAACL-bound submission — building the artifact around the Responsible NLP checklist's artifact questions, documenting provenance and licensing for language data, and handling community-owned or Indigenous-language resources correctly.

When to use

  • packaging datasets for NAACL submission
  • packaging models for NAACL submission
  • packaging prompts for NAACL submission
  • packaging annotation materials for NAACL submission
  • documenting provenance and licensing for language data
  • handling community-owned language resources
  • handling Indigenous-language resources
  • aligning artifacts with Responsible NLP checklist section B

When not to use

  • retraining models
  • reverse-engineering archive limits from previous cycles
