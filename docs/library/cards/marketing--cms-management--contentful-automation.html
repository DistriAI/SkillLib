Automate headless CMS operations in Contentful -- list spaces, retrieve space metadata, and update space configurations through the Composio Contentful integration.

When to use

  • List all Contentful spaces
  • Retrieve detailed space metadata
  • Update space name
  • Audit space inventory
  • Manage space-level metadata

When not to use

  • Create or modify entries
  • Create or modify content types
  • Create or modify assets
