pubar-theory-building

separate

Use when building the theoretical argument of a Public Administration Review (PAR) manuscript into a contribution that advances public-management theory and informs practice. PAR rewards a clear, portable mechanism with explicit scope conditions plus a defensible practitioner "so-what." Structures the argument; it does not run analyses.

When to use

  • building theoretical argument for PAR manuscript
  • defining key constructs and mechanisms
  • stating scope conditions and observable implications
  • creating Evidence for Practice box
  • conceptualizing public administration thought pieces
  • positioning contribution within PA theory conversations

When not to use

  • running analyses
