Skill page

Conflict

The two copies describe different agent-memory systems with different installation, APIs, and workflows. The first is an MCP-based Node.js server (agentMemory) with memory_search/memory_write/memory_read/memory_stats tools, a review-and-approve setup, and markdown sync. The second is a Python AgentMemory class installed via clawdhub with remember/learn/recall/get_lessons/track_entity methods and a SQLite database. Neither is a shortened or wrapped version of the other, so crowning one would hide a real alternative.
