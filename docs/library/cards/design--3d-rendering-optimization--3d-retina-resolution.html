3d-retina-resolution

separate

Render a 3D canvas sharply on Retina and HiDPI displays, including explicit 200 percent resolution, synchronized renderer and post-processing sizes, correct pointer coordinates, and measured quality fallbacks. Use for blurry WebGL output, 2x rendering, high-resolution previews, and display-density changes.

When to use

  • blurry WebGL output
  • 2x rendering
  • high-resolution previews
  • display-density changes
  • explicit 200 percent resolution
  • synchronized renderer and post-processing sizes
  • correct pointer coordinates
  • measured quality fallbacks

When not to use

  • CSS scaling
  • image-rendering: pixelated
  • fixing blurry textures
  • fixing coarse models
  • fixing shadow maps
  • fixing low-resolution reflections
