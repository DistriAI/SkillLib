respol-data-analysis

separate

Use when executing and stress-testing the empirical analysis for a Research Policy (RP) manuscript — building bibliometric/patent variables, running estimation or qualitative coding, and assembling robustness that an innovation-studies referee will accept. Executes the analysis; it does not choose the design (respol-methods) or present exhibits (respol-tables-figures).

When to use

  • building bibliometric/patent variables
  • running estimation or qualitative coding
  • assembling robustness checks
  • documenting variable construction steps
  • testing robustness to alternative measures
  • addressing count outcomes with appropriate models
  • reporting inter-coder reliability
  • executing analysis battery

When not to use

  • choosing the research design
  • presenting exhibits
  • respol-methods
  • respol-tables-figures
