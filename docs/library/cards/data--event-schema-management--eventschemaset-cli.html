eventschemaset-cli

authentic

Governs Event Schema Sets, the Fabric registries of event types and message payload schemas. Covers create, rename, update and delete of a definition, and listing, property reads or base64 decoding. Every Event Schema Set task belongs here. Ingestion pipelines are eventstream-cli.

When to use

  • create event schema set
  • rename event schema set
  • update event schema set definition
  • delete event schema set
  • list event schema sets
  • inspect event schema set properties
  • decode event schema set definition
  • enumerate eventTypes and schemas

When not to use

  • ingestion pipelines
  • eventstream-cli tasks
  • eventhouse-cli tasks
  • KQL Database tasks
