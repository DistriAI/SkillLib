slack-gif-creator

combined

Knowledge and utilities for creating animated GIFs optimized for Slack. Provides constraints, validation tools, and animation concepts. Use when users request animated GIFs for Slack like "make me a GIF of X doing Y for Slack." Toolkit for creating animated GIFs optimized for Slack, with validators for size constraints and composable animation primitives. This skill applies when users request animated GIFs or emoji animations for Slack from descriptions like "make me a GIF for Slack of X doing Y".

When to use

  • creating animated GIFs for Slack
  • validating GIFs against Slack requirements
  • drawing graphics from scratch using PIL
  • working with user-uploaded images
  • applying animation concepts like shake, pulse, bounce, spin, fade, and slide

When not to use

  • using emoji fonts
  • assuming pre-packaged graphics exist

Skill page

Conflict

The copies split into two distinct, non-reproducible procedures. The anthropics/skills and LeoYeAI copies describe a low-level workflow using PIL ImageDraw primitives, core.gif_builder, core.easing, and core.frame_composer, with guidance on drawing polished graphics from scratch. The davepoon and Prat011 copies describe a high-level workflow using pre-built animation primitives from templates.* (shake, bounce, spin, pulse, fade, zoom, explode, wiggle, slide) and a different set of validators (check_slack_size, validate_dimensions). Each group contains material steps and constraints the other lacks (e.g., drawing-from-scratch guidance vs. composable template functions; different validator APIs; different Slack parameter ranges). Crowning one would hide a real alternative implementation.
