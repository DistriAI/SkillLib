rfs-referee-strategy

separate

Use when choosing suggested/opposed referees or running an objection pre-mortem before submitting a The Review of Financial Studies (RFS) manuscript. Anticipates reviewer concerns; does NOT write the rebuttal (that is rfs-rebuttal).

When to use

  • Choosing suggested referees
  • Choosing opposed referees
  • Running an objection pre-mortem
  • Anticipating reviewer concerns
  • Preparing the cover letter's referee section

When not to use

  • Writing the rebuttal
