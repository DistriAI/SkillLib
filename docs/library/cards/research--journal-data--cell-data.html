cell-data

separate

Use to build Cell's data and code deposition plan and the Data and Code Availability statement that lives inside STAR Methods Resource Availability — approved repositories, accessions/DOIs at submission, and Cell's three-bullet availability format with Mendeley Data as Elsevier's default.

When to use

  • Drafting Data and Code Availability statement
  • Selecting approved repositories for data deposition
  • Obtaining accession numbers and DOIs
  • Archiving code with citable DOIs
  • Formatting the three-bullet availability statement
  • Mirroring accessions in Key Resources Table

When not to use

  • Writing Materials Availability statements
  • Writing Ethics approvals or Experimental Model details
  • Writing free-floating data paragraphs outside STAR Methods
