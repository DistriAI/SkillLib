remote-api-footguns

separate

Remote API traps in Kotlin Multiplatform: Ktor clients, defensive parsing, Resource envelopes, OK responses that dropped your data, auth callbacks, retry backoff, downloads, websockets, clock sync. Use when calls succeed but data never lands.

When to use

  • Ktor client architecture
  • Defensive parsing
  • Response to domain flow
  • Auth callbacks
  • Retry backoff
  • Parallel chunked downloads
  • Websockets
  • Clock sync

When not to use

  • Local database migrations
  • UI layout design
  • Server-side API implementation
