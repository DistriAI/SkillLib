search-consumption-cli

authentic

Finds Fabric items across every workspace with the Catalog Search API when the workspace is unknown, locating an item by display name, inventorying one item type tenant-wide, and returning the workspace and item IDs later calls need. Dataflow Gen1 and Gen2 items are not supported. Use only to locate items; once found, query them with the owning item skill such as sqldw-cli, spark-cli, eventhouse-cli or fabriciq.

When to use

  • locating an item by display name
  • inventorying one item type tenant-wide
  • returning workspace and item IDs
  • searching by description
  • searching by workspace name
  • listing all items of a type

When not to use

  • Dataflow Gen1 items
  • Dataflow Gen2 items
  • finding a workspace by name
  • querying source data after the workspace/item is known
