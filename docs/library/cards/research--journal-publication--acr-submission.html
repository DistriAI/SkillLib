acr-submission

separate

Use for the pre-submission preflight to 《会计研究》 (Accounting Research) — checking footnote (当页下注) conventions, the 著者—出版年制 reference style, abstract/keyword limits, article length, the online-only submission system via the Accounting Society of China site, double-blind anonymity, and document hygiene. Use right before submitting; verify every rule against the journal's current 投稿指南.

When to use

  • pre-submission preflight
  • checking footnote conventions
  • verifying reference style
  • checking abstract and keyword limits
  • verifying article length
  • checking double-blind anonymity
  • document hygiene
  • online submission system verification

When not to use

  • email submission
  • paper mail submission
  • using endnotes instead of footnotes
  • using numbered citation style instead of author-year
  • relying on memory for formatting rules
