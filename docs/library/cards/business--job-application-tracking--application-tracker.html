application-tracker

authentic

Set up and keep a job application tracker: one master CV, every tailored version, where each was sent, its status, next action and follow-up date, plus a weekly review of what is working. Use when asked to track my job applications, organise my job search, which CV did I send to which company, or what should I follow up on this week. Produces a tracker table (markdown or CSV) with one row per application, a version log linking each to its tailored CV, this week's actions, and a short weekly review of response rates by source.

When to use

  • track job applications
  • organise job search
  • identify which CV was sent to which company
  • determine weekly follow-ups
  • review response rates by source

When not to use

  • storing passwords or ID numbers
