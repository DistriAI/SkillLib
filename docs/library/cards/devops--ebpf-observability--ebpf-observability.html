ebpf-observability

authentic

Use eBPF for deep kernel-level observability — trace syscalls, network flows, and application behavior without code changes using Cilium, Tetragon, and bpftrace.

When to use

  • Deep performance debugging
  • Network observability without sidecars
  • Security monitoring at the kernel boundary
  • Continuous profiling in production
  • Service mesh replacement or augmentation

When not to use

  • Kernel version below 4.19
  • Managed platforms that restrict BPF capabilities
  • Debugging needs fully met by application-level tracing
