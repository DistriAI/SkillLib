jole-topic-selection

separate

Use when deciding whether a research question fits the Journal of Labor Economics (JOLE) — a general-interest labor-economics quarterly — and how to frame it so it matters to labor economists broadly, not just one niche. Tests fit; it does not run the analysis.

When to use

  • deciding if a research question fits JOLE
  • framing a question for labor economists broadly
  • choosing among angles on the same dataset
  • deciding between JOLE and non-labor journals
  • testing if a question is labor-first
  • assessing general-interest within labor
  • sharpening the research question
  • sanity-checking against JOLE word economy

When not to use

  • running the analysis
  • labor-adjacent papers without a core labor question
  • narrow program evaluations with no broader lesson
  • empirical questions with unavailable data
