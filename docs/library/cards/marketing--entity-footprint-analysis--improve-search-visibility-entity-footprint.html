improve-search-visibility-entity-footprint

separate

Step of the improve-search-visibility playbook: checks the profiles answer engines read, plus local listings and reviews, against the brand's facts and writes corrections. Run improve-search-visibility instead; not for direct use.

When to use

  • checking profiles answer engines read
  • checking local listings and reviews
  • writing corrections for entity footprint
  • confirming canonical facts
  • marking profile status
  • listing mismatches
  • writing exact field values for corrections
  • creating review-request briefs

When not to use

  • direct use
  • drafting Wikipedia articles
  • adding unsourced Wikidata items
  • suggesting fake or gated reviews
  • suggesting incentives tied to positive ratings
  • adding keywords to Business Profile name
  • drafting replies to reviews
