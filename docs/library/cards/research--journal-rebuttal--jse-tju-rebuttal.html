jse-tju-rebuttal

separate

Use when revising a manuscript and preparing a point-by-point response for 《系统工程学报》 (Journal of Systems Engineering, Tianjin University), especially for reviewer concerns about system boundaries, assumptions, propositions and proofs, algorithms, numerical experiments, simulation, empirical evidence, reproducibility, and requests that cannot be accepted without narrowing claims.

When to use

  • revising a manuscript
  • preparing a point-by-point response
  • addressing reviewer concerns about system boundaries
  • addressing assumptions, propositions and proofs
  • addressing algorithms and numerical experiments
  • addressing simulation and empirical evidence
  • addressing reproducibility
  • handling requests that cannot be accepted without narrowing claims

When not to use

  • submission system operations
  • file and author information restrictions
