plan-campaign-goal-chain

separate

Checks whether a stated goal is reachable on a given budget: fills an economics box with a source on every number, subtracts the baseline, works out the implied cost per customer against history or labelled base rates, and flags when the goal needs renegotiating. Use alone when you already have the goal (metric, number, date), budget, order value, margin and baseline; otherwise run plan-campaign.

When to use

  • Checking goal reachability on a given budget
  • Filling an economics box with sourced numbers
  • Subtracting baseline to find incremental target
  • Calculating implied cost per customer
  • Breaking incremental target into per-leg targets
  • Running conservative, expected, and optimistic scenarios
  • Checking forecast against stock or capacity
  • Writing a renegotiation case if the goal is missed

When not to use

  • Inventing the goal, margin, or conversion rate
  • Picking the renegotiation lever for the marketer
  • Crediting the campaign for the baseline
