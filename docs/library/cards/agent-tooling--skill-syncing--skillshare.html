Manage skills, agents, extras, hooks, plugins, and MCP connection settings with the Skillshare CLI. Use when the user asks to configure or run Skillshare, install or sync resources across AI tools, manage shared memory notes, review a session for lessons or dream over saved memories, import MCP settings, manage targets, audit skills, recover backups, or troubleshoot Skillshare configuration and sync. Covers global and project modes, noninteractive automation, and guidance for the terminal UI.

When to use

  • configure or run Skillshare
  • install or sync resources across AI tools
  • manage shared memory notes
  • review a session for lessons or dream over saved memories
  • import MCP settings
  • manage targets
  • audit skills
  • recover backups

When not to use

  • launching or scheduling an agent
  • resolving secrets
  • copying OAuth credentials
  • starting servers
  • probing their tools
  • commit, push, or publish
