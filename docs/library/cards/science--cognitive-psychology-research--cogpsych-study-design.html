cogpsych-study-design

separate

Use when designing the experiments for a Cognitive Psychology (Elsevier) manuscript so they tightly control confounds, discriminate competing models, and have adequate power across a multi-experiment program. Hardens stimulus construction, counterbalancing, design logic, and sample-size justification; it does not write analysis or modeling code.

When to use

  • Designing experiments or multi-experiment series
  • Constructing stimuli and item sets
  • Creating counterbalancing schemes
  • Justifying sample size for critical contrasts
  • Controlling researcher and stimulus degrees of freedom
  • Arguing construct validity and generality

When not to use

  • Writing analysis or modeling code
