mental-health-analyzer

combined

分析心理健康数据、识别心理模式、评估心理健康状况、提供个性化心理健康建议。支持与睡眠、运动、营养等其他健康数据的关联分析。

When to use

  • 需要分析情绪、焦虑、抑郁评分、治疗进展或危机风险时使用。
  • 任务涉及心理健康趋势、情绪模式识别或与睡眠/运动/营养的关联分析。
  • 用户请求心理健康报告、风险预警或治疗进展追踪时使用。

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.

Skill page

Conflict

The two copies share the same name and high-level purpose, but they are structurally different. The first copy is a thin wrapper that defers to an external detailed guide and provides only usage/limitation notes. The second copy is a self-contained, step-by-step procedure with specific data files, scoring formulas, crisis-risk thresholds, and a report template. Because the first copy lacks the concrete steps and the second copy lacks the wrapper's explicit safety/clarification constraints, crowning one would hide a real alternative. The combined instruction merges the wrapper's safety/clarification requirements with the detailed procedure's steps.
