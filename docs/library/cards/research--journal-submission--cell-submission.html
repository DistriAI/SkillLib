cell-submission

separate

Use as the final preflight before submitting to Cell — a complete checklist across significance, narrative, Highlights/eTOC/Graphical Abstract, Summary, figures, STAR Methods, data, references, and required files. Bundles the checklist and cover-letter templates.

When to use

  • Preflight check before uploading to Editorial Manager
  • Confirming outputs from other cell-* skills
  • Checking for regressions in revised manuscripts
  • Verifying Highlights, eTOC, and Graphical Abstract
  • Reviewing STAR Methods and Key Resources Table
  • Checking data deposition and code availability
  • Validating references and required metadata
  • Drafting the cover letter

When not to use

  • Writing the main manuscript text
  • Performing statistical analysis
  • Creating figures or graphical abstracts
  • Responding to referee comments
