stoc-artifact-evaluation

separate

Use when deciding what evidence objects a STOC (ACM Symposium on Theory of Computing) paper must ship, given that STOC runs no artifact-evaluation track — the durable artifact is the public full version on arXiv/ECCC, plus verifiable certificates whenever a proof leans on computation, and optional mechanization.

When to use

  • Deciding evidence objects for STOC papers
  • Planning computer-assisted proof steps
  • Preparing arXiv/ECCC full versions
  • Shipping verifiable certificates
  • Auditing full version completeness
  • Handling optional mechanized proofs

When not to use

  • ML-conference artifact checklists
  • STOC artifact-evaluation track
  • STOC badges
  • STOC code-upload channels
