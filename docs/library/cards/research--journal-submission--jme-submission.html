jme-submission

separate

Use when running the final pre-submission preflight for the Journal of Monetary Economics (JME) via Elsevier Editorial Manager — the US$350 (US$200 PhD) up-front fee, single-anonymized review, the 40-page / ≤10 tables-and-figures cap, 100-word abstract, line numbers, author-date references, JEL codes, and the supplementary-materials deposit. Final checks; it does not draft content.
