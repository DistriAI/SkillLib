  • Use as the umbrella entry point when multiple SEO dimensions are in scope.
  • Use when the task spans technical SEO, content, schema, sitemaps, and AI search readiness together.

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.

Skill page

Conflict

The three skills cover the same domain but operate at different levels of abstraction and contain material, non-overlapping procedures. The first is a strategic planning guide (workflow order, prioritization, product-led SEO). The second is a technical execution guide (Lighthouse audits, specific code snippets for robots.txt, sitemaps, and meta tags). The third is an orchestration framework (subagent delegation, industry detection, scoring methodology, and specific quality gates like the FAQ schema restriction). No single copy contains the full procedure of the others; combining them is necessary to capture the strategic, technical, and orchestration constraints.
