one-note

separate

OneNote API integration with managed OAuth via Microsoft Graph. Access notebooks, sections, section groups, and pages. Use this skill when users want to create or manage OneNote notebooks, organize notes, or work with page content. For other third party apps, use the api-gateway skill (https://clawhub.ai/byungkyu/api-gateway).

When to use

  • create or manage OneNote notebooks
  • organize notes
  • work with page content
  • access notebooks, sections, section groups, and pages

When not to use

  • other third party apps
