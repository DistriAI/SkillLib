spatial-communication

combined

Maps cell-cell communication and ligand-receptor co-expression in spatial transcriptomics (Visium, Xenium, MERFISH, CosMx, Slide-seq) with Squidpy ligrec, COMMOT, stLearn, CellChat-spatial, and NicheNet. Use when choosing a method by whether spatial distance is actually modeled (squidpy ligrec is space-blind cluster-permutation vs COMMOT optimal-transport is distance-aware vs stLearn neighborhood vs CellChat-spatial filter) and by secreted-vs-contact-dependent range; choosing the ligand-receptor database knowingly because it drives the result as much as the algorithm; guarding against segmentation-spillover circularity that fabricates short-range hits; treating every ligand-receptor score as a co-expression hypothesis on a confidence ladder, not validated signaling; correcting for thousands of pair-by-cell-type-pair permutation tests; and recognizing that a targeted imaging panel rarely contains the relevant ligands and receptors so a "no communication" call is uninformative.

When to use

  • Analyze cell-cell communication in spatial context
  • Infer intercellular signaling
  • Identify communication pathways
  • Visualize interaction networks
  • Ligand-receptor analysis with Squidpy

Skill page

Conflict

The two skills cover the same task (spatial cell-cell communication) but with different depths and emphases. The first copy (OpenClaw) provides a complete, executable Python workflow using Squidpy, including code for filtering, visualization (heatmaps, networks), and custom databases. The second copy (GPTomics) provides a critical methodological framework, emphasizing the limitations of co-expression vs. signaling, the impact of segmentation spillover, and a decision table for choosing between space-blind (Squidpy) and distance-aware (COMMOT) methods. The first copy lacks the critical caveats and method selection logic of the second, while the second copy lacks the detailed implementation code for visualization and custom analysis found in the first. Combining them yields a skill that is both methodologically rigorous and practically executable.
