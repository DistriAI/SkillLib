space-chart-image

separate

使用 AI 图片生成技术绘制美观的图表。支持 10 种图表类型：流程图、架构图、ER 图、商业模式画布、用户旅程图、思维导图、竞品分析图、SWOT 分析、产品路线图、组织架构图。6 种内置视觉风格。 触发词："画个 XX 图"、"生成商业模式画布"、"做个架构图"、"画 ER 图"、"帮我画个流程图"、"生成用户旅程图"、"做个思维导图"、"竞品分析图"、"SWOT 分析图"、"产品路线图"、"组织架构图"、"帮我可视化图表"。 【公众号配图版】用户给内容 → 产出公众号配图。优先用当前环境内置出图模型（Codex 内置 image_gen/image2、workbuddy 出图模型）直接生成 PNG；无内置模型时回退 scripts/ 下的 API 脚本。

When to use

  • 绘制流程图
  • 生成架构图
  • 画 ER 图
  • 生成商业模式画布
  • 画用户旅程图
  • 做思维导图
  • 生成竞品分析图
  • 画 SWOT 分析图

When not to use

  • 生成可编辑 HTML 图表
  • 生成微信公众号排版布局
