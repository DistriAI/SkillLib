pnpm

authentic

Node.js package manager with strict dependency resolution. Use when running pnpm specific commands, configuring workspaces via pnpm-workspace.yaml, or managing dependencies with catalogs, patches, overrides, config dependencies, or the global virtual store.

When to use

  • running pnpm specific commands
  • configuring workspaces via pnpm-workspace.yaml
  • managing dependencies with catalogs
  • managing dependencies with patches
  • managing dependencies with overrides
  • managing config dependencies
  • managing the global virtual store
  • CI/CD setup and migration
