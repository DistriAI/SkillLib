component-spec

separate

Specify one component — props, states, variants, accessibility, and usage rules. Use when defining a library component. For the reusable doc scaffold use `documentation-template`; for a problem-solution pattern use `pattern-library`.

When to use

  • defining a library component
  • writing component specifications
  • specifying component anatomy
  • defining component variants
  • documenting component states
  • specifying component accessibility
  • writing component usage guidelines

When not to use

  • reusable doc scaffold
  • problem-solution pattern
