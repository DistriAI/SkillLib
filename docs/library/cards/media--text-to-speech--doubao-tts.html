doubao-tts

separate

使用豆包（火山引擎）语音合成大模型 API 将文本转换为语音音频文件。支持声音复刻音色（S_ 开头的音色ID）和官方预置音色。当用户要求"语音合成"、"文字转语音"、"TTS"、"朗读文本"、"生成语音"、"用我的声音读"、"豆包语音"、"声音复刻合成"等相关请求时，务必使用此 skill。即使用户只是说"帮我把这段话读出来"或"生成一段音频"，也应触发此 skill。

When to use

  • 语音合成
  • 文字转语音
  • TTS
  • 朗读文本
  • 生成语音
  • 用我的声音读
  • 豆包语音
  • 声音复刻合成
