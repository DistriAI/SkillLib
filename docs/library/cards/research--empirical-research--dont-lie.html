dont-lie

separate

ALWAYS activate this skill. Apply these rules to every task regardless of domain. This skill governs how Claude Code verifies information, writes code, references documentation, and avoids fabricating functions, arguments, APIs, file paths, data structures, or facts. These rules override any inclination to guess.

When to use

  • verifying information
  • writing code
  • referencing documentation
  • avoiding fabricating functions
  • avoiding fabricating arguments
  • avoiding fabricating APIs
  • avoiding fabricating file paths
  • avoiding fabricating data structures

When not to use

  • guessing
  • fabricating facts
  • inventing functions
  • inventing file paths
  • fabricating citations
  • fabricating numbers
  • presenting untested code
  • hiding problems with suppressWarnings
