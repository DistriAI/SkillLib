research-keywords

separate

Finds high-value SEO and GEO keywords using web search, AI analysis, and optionally paid tools like Ahrefs or Semrush. Produces a validated keywords.csv file with a fixed schema for downstream pipeline consumption.

When to use

  • SEO keyword research
  • GEO keyword research
  • Brand intelligence gathering
  • Keyword discovery via web search
  • Keyword validation and pruning
  • Keyword analysis and clustering
  • Generating keywords.csv artifact

When not to use

  • Content writing
  • Website development
  • Paid advertising management
