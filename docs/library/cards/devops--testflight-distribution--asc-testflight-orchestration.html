asc-testflight-orchestration

separate

Orchestrate TestFlight distribution, groups, testers, and What to Test notes using asc. Use when rolling out betas.

When to use

  • managing TestFlight testers
  • managing TestFlight groups
  • build distribution
  • rolling out betas
  • exporting TestFlight config
  • uploading builds without distribution
  • managing What to Test notes

When not to use

  • combining upload-only with existing build-id
  • combining upload-only with groups
  • combining upload-only with tester notifications
  • combining upload-only with test notes
  • combining upload-only with beta-review submission
