er-tables-figures

separate

Use when finalizing regression tables and figures for an Economic-Research manuscript. Enforces three-line table style, footnote conventions, column-count discipline, and figure aesthetics.

When to use

  • finalizing regression tables
  • finalizing figures
  • enforcing three-line table style
  • enforcing footnote conventions
  • enforcing column-count discipline
  • enforcing figure aesthetics

When not to use

  • hand-copying numbers
  • using t-values or z-values for standard errors
  • using borders, shadows, or colors in tables
  • writing 'data from public channels' without naming databases
  • stacking multiple fit statistics like R-squared, AIC, and BIC
  • using long legends in figures
  • overlaying multiple curves, line types, and colors in one figure
  • pasting screenshots of Stata or R output into Word
