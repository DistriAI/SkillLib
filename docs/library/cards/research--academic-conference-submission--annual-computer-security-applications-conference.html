annual-computer-security-applications-conference

separate

Use when targeting Annual Computer Security Applications Conference (ACSAC) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for applied security.

When to use

  • targeting ACSAC
  • deciding if a manuscript fits ACSAC
  • conference-fit read for applied security
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • applied computer security, assurance, usable security, systems, and operational defenses

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • generic CS papers without specific subcommunity or contribution type
  • European research-community general security work (route to ESORICS)
  • privacy-first work (route to PETS)
  • finance/cryptocurrency work (route to FC)
  • broad flagship submissions (route to CCS/S&P/USENIX/NDSS)
