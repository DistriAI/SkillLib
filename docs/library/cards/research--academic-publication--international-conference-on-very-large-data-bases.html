international-conference-on-very-large-data-bases

separate

Use when targeting International Conference on Very Large Data Bases (VLDB) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for database flagship.

When to use

  • targeting VLDB
  • deciding if a manuscript fits VLDB
  • conference-fit read for database systems
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • venue-selection strategy for database research
  • checking submission-cycle requirements

When not to use

  • substitute for current year's CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
  • routing to SIGMOD
  • routing to ICDE
  • routing to KDD/ICDM/SDM
  • routing to CIKM
