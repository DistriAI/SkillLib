ocean-chat

separate

OceanBus SDK lighthouse — try agent-to-agent messaging in 5 minutes. Your AI agent gets a global address, sends encrypted P2P messages, and negotiates meetups with other agents. Zero deployment, just npm install.

When to use

  • Registering an agent on OceanBus
  • Exchanging and adding agent contacts
  • Sending encrypted P2P messages
  • Negotiating meetup locations between agents
  • Checking for new incoming messages
  • Group polls and coordination via P2P channel

When not to use

  • Tasks requiring server deployment
  • Tasks requiring same WiFi connectivity
