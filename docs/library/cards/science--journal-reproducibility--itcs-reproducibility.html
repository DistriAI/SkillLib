itcs-reproducibility

separate

Use to make an ITCS paper's mathematics independently checkable — complete proofs of every central claim, self-contained definitions, pinned dependencies on prior results, and a matching full version on arXiv/ECCC/ePrint — the pure-theory analogue of a reproducibility package.

When to use

  • making ITCS paper mathematics independently checkable
  • ensuring complete proofs of central claims
  • creating self-contained definitions and notation
  • pinning dependencies on prior results
  • maintaining a matching full version on arXiv/ECCC/ePrint
  • running checkability passes before upload

When not to use

  • rerunning code
  • re-mining datasets
