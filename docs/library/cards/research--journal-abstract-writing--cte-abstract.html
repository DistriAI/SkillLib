cte-abstract

separate

Use when drafting or revising the 中文摘要 or 英文 abstract for a 《财贸经济》(Finance & Trade Economics, CTE) manuscript — the CSSCI 财经权威期刊 run by 中国社会科学院财经战略研究院. 当摘要写成"为高质量发展提供新思路"式套话、缺核心数据 / 识别策略 / 量化发现、或中英文语义不对齐时使用。Enforces the five-sentence pattern, requires quantified findings with named data sources (CSMAR / WIND / CEIC / 统计年鉴), and forbids empty-significance phrases.

When to use

  • Drafting Chinese abstract for CTE manuscript
  • Revising English abstract for CTE manuscript
  • Fixing abstracts with empty-significance phrases
  • Aligning Chinese and English abstract semantics
  • Ensuring abstracts include quantified findings
  • Naming specific data sources in abstracts

When not to use

  • Writing full manuscript body
  • Formatting submission documents
  • Non-CTE journal abstracts
