expo-dev-client

authentic

Build and distribute Expo development clients locally or via TestFlight for internal testing. For production TestFlight releases and store submission, use the eas-app-stores skill.

When to use

  • Build development clients locally
  • Distribute via TestFlight
  • Test native code changes on physical devices
  • Create custom Expo Go clients
  • Test branches of app
  • Use local Expo modules
  • Test Apple targets
  • Test third-party native modules

When not to use

  • Production TestFlight releases
  • Store submission
