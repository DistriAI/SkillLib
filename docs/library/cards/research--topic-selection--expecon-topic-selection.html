expecon-topic-selection

separate

Use when deciding whether a question is a method-defined fit for an Experimental Economics (ExpEcon) manuscript and which treatment contrast to build it around. Frames the fit decision; it does not invent results or citations.

When to use

  • deciding if a question fits Experimental Economics
  • choosing the treatment contrast
  • determining if the design is the contribution
  • selecting the appropriate journal venue
  • deciding on pre-registration or Registered Report status
  • choosing the experiment type (lab, lab-in-field, field)
  • evaluating if a clean null result is publishable

When not to use

  • inventing results
  • inventing citations
  • analyzing field-survey data
  • calibrating structural objects
  • illustrating game-theoretic theory
  • writing topic-first papers
