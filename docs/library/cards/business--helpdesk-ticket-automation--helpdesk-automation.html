Automate HelpDesk tasks via Rube MCP (Composio): list tickets, manage views, use canned responses, and configure custom fields. Always search tools first for current schemas.

When to use

  • list tickets
  • manage views
  • use canned responses
  • configure custom fields
  • browse support tickets
  • retrieve reply templates
  • view custom field definitions

When not to use

  • ticket creation
  • ticket update
  • ticket reply operations
  • creating or modifying views
  • managing canned responses in UI
  • configuring custom fields in admin panel
