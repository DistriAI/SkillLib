dx-org-manage

authentic

Use to EXECUTE Salesforce org operations immediately via the sf CLI (this skill runs them, it does NOT generate scripts): create scratch orgs (from edition, definition file, snapshot, or org shape), list/display/resume/delete scratch orgs, open orgs in browser. Trigger: 'create scratch org', 'create org from snapshot', 'delete scratch org', 'open my org'. Do NOT use for switching the default org (use dx-org-switch), deploying metadata (use platform-metadata-deploy), or creating/checking/listing/deleting org snapshots (use dx-org-snapshot-manage).

When to use

  • create scratch orgs
  • create org from snapshot
  • create org from definition file
  • create org from org shape
  • list scratch orgs
  • display scratch orgs
  • resume scratch orgs
  • delete scratch orgs

When not to use

  • switching the default org
  • deploying metadata
  • creating org snapshots
  • checking org snapshots
  • listing org snapshots
  • deleting org snapshots
  • generating scripts
