bio-microbiome-taxonomy-assignment

separate

Taxonomic classification of ASVs using reference databases like SILVA, GTDB, or UNITE. Covers naive Bayes classifiers (DADA2, IDTAXA) and exact matching approaches. Use when assigning taxonomy to ASVs after DADA2 amplicon processing.

When to use

  • Assigning taxonomy to ASVs
  • Classifying amplicon sequence variants
  • Using DADA2 assignTaxonomy
  • Using QIIME2 feature-classifier
  • Using VSEARCH exact matching
  • Using IDTAXA classifier
  • Filtering low-confidence assignments
  • Combining taxonomy into phyloseq

When not to use

  • Read-level taxonomic classification
  • Generating ASV table
  • Analyzing classified communities
