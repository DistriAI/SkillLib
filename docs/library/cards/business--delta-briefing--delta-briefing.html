delta-briefing

authentic

Make a recurring brief report what changed since the last edition instead of restating everything. Use when a weekly or monthly report keeps repeating itself, when setting up a scheduled monitor or digest, or when asked to make a recurring update delta-aware. Produces a changes-first brief plus the state record the next run will diff against.

When to use

  • weekly or monthly reports that keep repeating
  • setting up a scheduled monitor or digest
  • making a recurring update delta-aware
  • generating a changes-first brief
  • creating a state record for the next edition

When not to use

  • restating unchanged items at full length
  • fabricating a delta to make a quiet cycle look productive
  • diffing against memory or vibes instead of stored state
  • tracking items resolved two editions ago
