swarmclaw

separate

Manage your SwarmClaw agent fleet, create and assign tasks, check agent and session status, trigger workflows, and orchestrate multi-agent work from chat. Use when asked to dispatch work to other agents, check what agents are doing, run diagnostics, or coordinate across a SwarmClaw dashboard instance.

When to use

  • dispatch work to other agents
  • check what agents are doing
  • run diagnostics
  • coordinate across a SwarmClaw dashboard instance
  • create and assign tasks
  • check agent and session status
  • trigger workflows
  • manage agents, tasks, sessions, schedules, and memory

When not to use

  • run commands that modify or delete agents without explicit user confirmation
