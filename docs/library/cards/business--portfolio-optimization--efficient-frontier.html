efficient-frontier

separate

Apply the same orchestration as `/efficient-fable` to any high-cost frontier model: delegate research, coding, and testing to cheaper subagents while keeping planning, synthesis, and final review with the expensive model.

When to use

  • delegating research scans
  • delegating repository inventory
  • delegating docs extraction
  • delegating browser/testing passes
  • delegating log reduction
  • delegating test failure clustering
  • delegating narrow coding
  • delegating mechanical edits

When not to use

  • delegating immediate blockers
  • multiple agents editing same files simultaneously
  • trusting subagent conclusions blindly when risk is high
