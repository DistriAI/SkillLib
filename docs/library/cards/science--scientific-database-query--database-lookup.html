database-lookup

separate

Queries documented public database APIs with explicit endpoints, filters, pagination, and provenance. Used when a scientific, regulatory, financial, or other database-backed fact must be retrieved reproducibly from a named source rather than inferred from general knowledge.

When to use

  • retrieving scientific facts from named sources
  • regulatory database lookups
  • financial database queries
  • biomedical retrievals
  • identifier resolution
  • exhaustive dataset retrieval
  • targeted lookups
  • cross-checking database coverage

When not to use

  • inferring facts from general knowledge
  • broad searching without explicit identifiers
  • plausible summaries without provenance
  • unbounded raw data dumps
