amanthro-research-design

separate

Use when defending the research design of an American Anthropologist (AA) manuscript — fieldwork and participant observation, interview and archival design for ethnographic/qualitative work, material/contextual analysis for archaeology, and appropriate lab/quantitative design for biological anthropology. AA judges each mode on its own terms with reflexivity. Strengthens the design; it does not write code or run fieldwork.

When to use

  • defending research design
  • fieldwork and participant observation
  • interview and archival design
  • material/contextual analysis
  • lab/quantitative design
  • planning consent and anonymization
  • justifying evidence against rival readings

When not to use

  • writing code
  • running fieldwork
