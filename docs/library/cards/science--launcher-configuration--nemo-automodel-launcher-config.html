nemo-automodel-launcher-config

separate

Configure NeMo AutoModel job launches for interactive runs, Slurm clusters, and SkyPilot cloud execution.

When to use

  • Configuring Slurm or SkyPilot job submission
  • Setting up multi-node launch scripts
  • Debugging job submission failures
  • Switching between interactive and cluster launch modes
  • Interactive execution
  • Containers
  • Mounts
  • Profiling

When not to use

  • Implementing or registering new model architectures
  • Hugging Face state-dict adapters
  • Model files
  • Capability flags
  • Model onboarding tasks
