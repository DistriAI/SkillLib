mathfin-tables-figures

separate

Use when preparing figures, numerical tables, theorem maps, appendix exhibits, and algorithm displays for a Mathematical Finance manuscript, ensuring every exhibit supports a rigorous result rather than acting as stand-alone empirical evidence.

When to use

  • preparing figures
  • preparing numerical tables
  • preparing theorem maps
  • preparing appendix exhibits
  • preparing algorithm displays
  • organizing appendices
  • creating assumption dependency diagrams
  • rewriting captions

When not to use

  • stand-alone empirical evidence
  • empirical-style claims
  • broad empirical validation
