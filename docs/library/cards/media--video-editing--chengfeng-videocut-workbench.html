chengfeng-videocut-workbench

separate

操作 chengfeng-videocut 剪辑工作台的已有工程，通过 Runtime CLI 查工程与词句位置、添加或替换画面覆盖层、移除画面、删除明确指定的词句或片段、拆分裁剪移动已有片段、调整画布比例并回读核验。用户说插入片段、删掉这句、移除动画、换个画面、调整顺序或管理时间线时使用；先区分画面覆盖与主轨顺延插入，不负责自动判断口误、创作动画、制作字幕、导出或排查安装故障。

When to use

  • 查工程与词句位置
  • 添加或替换画面覆盖层
  • 移除画面
  • 删除明确指定的词句或片段
  • 拆分裁剪移动已有片段
  • 调整画布比例
  • 回读核验

When not to use

  • 自动判断口误
  • 创作动画
  • 制作字幕
  • 导出
  • 排查安装故障
  • 通用插入命令
  • 自动启动额外 Agent
  • 自动安装缺失 Skill
