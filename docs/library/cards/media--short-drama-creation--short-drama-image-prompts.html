short-drama-image-prompts

为短剧人物、造型、地点、道具和状态编写或修改可直接复制的图片提示词 Markdown。用户提到角色设定图、三视图、参考图、场景板、道具图、风格帧、Look Development、状态变体或局部编辑提示词时使用；不生成图片，也不调用供应商。

When to use

  • 角色设定图
  • 三视图
  • 参考图
  • 场景板
  • 道具图
  • 风格帧
  • Look Development
  • 状态变体

When not to use

  • 生成图片
  • 调用供应商
