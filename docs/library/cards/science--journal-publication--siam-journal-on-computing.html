siam-journal-on-computing

separate

Use when targeting SIAM Journal on Computing (SICOMP) or deciding whether a theoretical-computer-science manuscript fits this foundational algorithms-and-complexity venue. Encodes the journal's fit, framing, proof-and-rigor bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting SIAM Journal on Computing (SICOMP)
  • deciding if a theoretical-computer-science manuscript fits SICOMP
  • preparing full journal version of STOC/FOCS results
  • manuscripts proving new algorithmic guarantees or complexity bounds
  • manuscripts proving hardness results
  • checking SICOMP expectations on rigor and exposition
  • checking SICOMP submission norms

When not to use

  • replacing the journal's current official submission guidelines
  • replacing the editorial board's judgment
