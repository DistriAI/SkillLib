aes-writing-style

separate

当你按《电子学报》(Acta Electronica Sinica, AES) 规范打磨中文科技论文写作时使用。覆盖中英文题名、结构式中文摘要与英文 Abstract、中英文关键词、中图分类号(TN 大类)、量和单位与法定计量、公式与变量排版、图表规范、GB/T 7714 顺序编码制参考文献中英文著录、以及电子/信息/信号处理领域术语与数学表达的一致性。帮助作者写出符合《电子学报》体例、语言严谨、可被外审专家顺畅评阅的中文旗舰学报稿件，避免因写作不规范在初审或外审被扣分。

When to use

  • 中英文题名规范
  • 结构式中文摘要与英文 Abstract
  • 中英文关键词
  • 中图分类号(TN 大类)
  • 量和单位与法定计量
  • 公式与变量排版
  • 图表规范
  • GB/T 7714 顺序编码制参考文献
