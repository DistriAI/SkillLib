add-table-to-offline-profile

separate

Internal mobile-app workflow read and executed only by mobile orchestrators to add one Dataverse table to an existing Mobile Offline Profile.

When to use

  • Add a single table to an existing Mobile Offline Profile
  • Configure offline availability for a new Dataverse table
  • Extend an existing offline profile with a new table

When not to use

  • Create a new Mobile Offline Profile
  • Edit existing tables in the profile
  • Delete tables from the profile
  • User-invocable tasks
  • Model-invocation tasks
