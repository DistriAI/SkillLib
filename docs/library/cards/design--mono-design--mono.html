mono

separate

Monospace-driven, matrix-inspired design with high-contrast elements, compact density, and a hacker-chic aesthetic.

When to use

  • Monospace-driven design
  • Matrix-inspired design
  • High-contrast elements
  • Compact density layout
  • Hacker-chic aesthetic
  • Design system guideline authoring
  • Accessibility compliance
  • Component rule definition

When not to use

  • Low contrast text
  • Inconsistent spacing rhythm
  • Decorative motion without purpose
  • Ambiguous labels
  • Mixing multiple visual metaphors
  • Inaccessible hit areas
