aer-topic-selection

separate

Use when evaluating whether a research idea clears the AER top-5 bar, when routing between AER, AER:Insights, and the AEJ family, or when sharpening a fuzzy contribution sentence into one publishable claim. Apply before any writing begins.

When to use

  • A new project just started and the contribution sentence cannot be written in one line
  • The user is undecided between submitting to AER, AER: Insights, or an AEJ
  • A prior submission was desk-rejected and the user wants to diagnose whether the topic itself was the problem
  • The paper "feels solid" but no senior colleague has agreed to send it to AER

When not to use

  • writing the manuscript
  • drafting the introduction
  • performing identification strategy analysis
  • conducting literature search protocol
