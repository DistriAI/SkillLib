mobicom-topic-selection

separate

Use when deciding whether a project belongs at MobiCom or a sibling venue — testing whether the core contribution is a mobile/wireless-networking mechanism the SIGMOBILE flagship rewards, and routing platform, sensing, broad-networking, security, or ubicomp misfits to MobiSys, SenSys, SIGCOMM/NSDI, WiSec, or IMWUT before a cycle is committed.

When to use

  • deciding if a project belongs at MobiCom
  • testing if contribution is a mobile/wireless-networking mechanism
  • routing platform misfits to MobiSys
  • routing sensing misfits to SenSys
  • routing broad-networking misfits to SIGCOMM/NSDI
  • routing security misfits to WiSec
  • routing ubicomp misfits to IMWUT
  • identifying common misfit patterns

When not to use

  • substitute for the current CFP scope list
  • evaluating simulation-only stories without over-the-air evidence
