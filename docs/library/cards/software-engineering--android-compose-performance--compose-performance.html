Use when investigating Jetpack Compose recomposition cost, compiler stability reports, skippability, unstable parameters, frame-rate State reads, cross-phase snapshot back-writing, or @ReadOnlyComposable contracts.

When to use

  • investigating Jetpack Compose recomposition cost
  • compiler stability reports
  • skippability
  • unstable parameters
  • frame-rate State reads
  • cross-phase snapshot back-writing
  • @ReadOnlyComposable contracts

When not to use

  • working around the sandbox
  • prescribing callback swaps without evidence
  • prescribing equality guards without evidence
  • prescribing content-layout rewrites without evidence
