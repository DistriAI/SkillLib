ab-test-planner

authentic

Diseña pruebas A/B estadísticamente rigurosas para características de producto, cambios de UI, flujos de onboarding y experimentos de precios. Úsalo cuando te pidan configurar un experimento, diseñar una prueba A/B, calcular tamaño de muestra o interpretar resultados de pruebas. Produce un plan de prueba completo con hipótesis, definición de variantes, tamaño de muestra, estimación de duración, métricas de seguridad y una guía de interpretación de resultados.

When to use

  • configurar un experimento
  • diseñar una prueba A/B
  • calcular tamaño de muestra
  • interpretar resultados de pruebas
  • características de producto
  • cambios de UI
  • flujos de onboarding
  • experimentos de precios

When not to use

  • pruebas sin hipótesis direccional
  • revisar resultados antes de alcanzar el tamaño de muestra
  • probar múltiples cambios independientes en una sola variante
  • usar métricas de engagement como métrica primaria para ingresos o retención
  • ignorar métricas de seguridad
