jleo-referee-strategy

separate

Use when anticipating the referee read on a Journal of Law, Economics, and Organization (JLEO) manuscript before submitting — modeling the institutional/organizational economist who will review it and pre-empting the objections that sink JLEO papers. Anticipates objections; it does not write the response to an actual report (jleo-rebuttal).

When to use

  • Anticipating JLEO referee objections
  • Modeling institutional/organizational economist reviewers
  • Pre-empting credibility gaps
  • Deciding which weaknesses to fix before submission
  • Addressing sibling boundary concerns
  • Triaging objection severity
  • Preparing cover letter limitations
  • Suggesting TCE/PPE reviewers

When not to use

  • Writing the response to an actual report
  • jleo-rebuttal
