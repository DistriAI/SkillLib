Conflict

The three copies are nearly identical, but they disagree on the target agent and the chat history file path. The davepoon and ComposioHQ copies target Claude Code and read ~/.claude/history.jsonl, while the composio-community copy targets Codex and reads $CODEX_HOME/history.jsonl (defaulting to ~/.codex/history.jsonl). Because the file path is a core step, crowning one copy would hide a real alternative for the other agent.
