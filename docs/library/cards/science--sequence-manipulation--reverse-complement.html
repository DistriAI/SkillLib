reverse-complement

separate

Generate reverse complements and complements of DNA/RNA sequences using Biopython, including IUPAC ambiguity codes, gapped alignments, and minus-strand features. Use when working with the opposite strand, building reverse primers, normalizing strand orientation before alignment, or extracting a coding sequence from a minus-strand feature.

When to use

  • working with the opposite strand
  • building reverse primers
  • normalizing strand orientation before alignment
  • extracting a coding sequence from a minus-strand feature
  • generating reverse complements of DNA sequences
  • generating complements of DNA sequences
  • generating reverse complements of RNA sequences
  • generating complements of RNA sequences

When not to use

  • hand-rolling the complement table
  • reimplementing Biopython's reverse_complement
  • transcribing the coding strand without complementing
