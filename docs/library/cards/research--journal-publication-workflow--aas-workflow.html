aas-workflow

separate

当你在为《自动化学报》(Acta Automatica Sinica, AAS) 规划一次完整投稿的时间线、把 12 个技能编排成从选题到见刊的流水线时调用。给出选题定位→写作→实验→匿名投稿→双盲三审→多轮退修→录用定稿的阶段划分、每阶段的准入准出、里程碑与常见延误点，帮助作者在 Acta Automatica Sinica 的双盲三审制与中英文双语综述长文传统下合理排期，避免作者承诺漏交、双盲泄露、退修超期等踩坑，并在每个节点指明应调用哪个 aas- 技能。

When to use

  • 规划 AAS 投稿时间线
  • 编排 aas- 技能流水线
  • 定义阶段准入准出标准
  • 制定里程碑与责任人排期
  • 识别常见延误点与规避措施
  • 维护跨阶段一致性
  • 按栏目分化流程侧重

When not to use

  • 具体论文写作
  • 实验设计与执行
  • 审稿意见逐条答复
  • 定稿校样处理
