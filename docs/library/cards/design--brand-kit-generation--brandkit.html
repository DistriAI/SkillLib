brandkit

combined

Premium brand-kit image generation skill for creating high-end brand-guidelines boards, logo systems, identity decks, and visual-world presentations. Trained for minimalist, cinematic, editorial, dark-tech, luxury, cultural, security, gaming, developer-tool, and consumer-app brand systems. Optimized for intentional logo concepting, refined composition, sparse typography, strong symbolic meaning, premium mockups, art-directed imagery, and flexible grid layouts. Generate a complete, accessible brand design system from a brief — primitive → semantic → component DTCG tokens (color, type, spacing, radius, shadow, motion), light + dark, plus a single theme.css — verified for WCAG. Use when the user wants a from-scratch brand/design foundation, a new palette + type system, or a themeable token kit for a product.

Skill page

Conflict

The two skills share the name 'brandkit' but define fundamentally different procedures. The first (Leonxlnx) is an image-generation skill that produces a single visual brand-guidelines board (a 'brand world' in one image) using art-direction principles, grid layouts, and logo concepting. The second (plugin87) is a code/token-generation skill that produces a structured design-token system (DTCG JSON, CSS variables, OKLCH colors) with automated WCAG verification scripts. They do not overlap in output format, tools, or steps; one is for visual presentation, the other for engineering foundations. Combining them is necessary to capture both the visual identity board and the underlying token system, as neither is a reproduction of the other.
