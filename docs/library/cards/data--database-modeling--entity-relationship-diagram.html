entity-relationship-diagram

authentic

Turn a data model into an entity-relationship (ER) diagram. Use when asked to design a schema, model data, show how tables/entities relate, or diagram a database. Produces a ready-to-render Mermaid ER diagram (renders live, exportable as PNG/SVG) plus key attributes, cardinality, and design notes.

When to use

  • design a schema
  • model data
  • show how tables/entities relate
  • diagram a database

When not to use

  • drawing relationships without cardinality
  • leaving many-to-many unresolved when a join table is needed
  • dumping every conceivable column
  • omitting foreign keys
  • breaking Mermaid with unquoted spaced labels
