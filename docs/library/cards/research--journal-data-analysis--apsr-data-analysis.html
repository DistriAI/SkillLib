apsr-data-analysis

separate

Use when executing and reporting the analysis for an American Political Science Review (APSR) manuscript so it survives expert, double-anonymous review — honest uncertainty, robustness, and triangulation appropriate to quantitative, experimental, or computational work. Guides analysis norms; it does not fabricate results.

When to use

  • Running main and supporting analyses
  • Building the results section
  • Addressing reviewer requests for robustness or heterogeneity
  • Reconciling preregistered vs. exploratory analyses
  • Making the analysis reproducible before deposit
  • Executing computational or text-as-data analyses
  • Reporting uncertainty and effect sizes
  • Managing multiple comparisons and inference

When not to use

  • Fabricating results
  • Design decisions (covered by apsr-research-design)
  • Transparency and data policy (covered by apsr-transparency-and-data-policy)
