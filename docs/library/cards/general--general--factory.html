factory

separate

Experimental workflow for configuring an autonomous software delivery factory. Use when choosing feedback sources, schedules, worktree behavior, autonomy gates, or host automations.

When to use

  • configuring autonomous software delivery factory
  • choosing feedback sources
  • setting schedules
  • configuring worktree behavior
  • setting autonomy gates
  • configuring host automations
  • setting action policies
  • adding per-skill prompts

When not to use

  • assuming a provider
  • assuming a repository
  • assuming a schedule
  • assuming an autonomy level
  • putting credentials or tokens in config
