arpsych-transparency-and-reproducibility

separate

Use when documenting the literature search and making any embedded meta-analysis reproducible for an Annual Review of Psychology (ARPsych) review. Covers search transparency, meta-analytic rigor, and open materials; it does not run the narrative search (arpsych-literature-synthesis) or design exhibits (arpsych-tables-figures).

When to use

  • documenting literature search reproducibly
  • making embedded meta-analysis reproducible
  • reporting search protocol
  • depositing effect-size data and code
  • reporting heterogeneity and bias diagnostics
  • preparing conflict-of-interest disclosures

When not to use

  • running the narrative search
  • designing exhibits
