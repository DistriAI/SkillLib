chengfeng-check-updates

separate

剪辑环境的唯一管理者：就绪检查（skills 是否最新 → Runtime 是否配套）、Skills 更新激活、Runtime 安装与体检。用户说检查更新、安装剪辑环境、装播放器、检查剪辑环境、剪辑环境就绪了吗、配置转录凭证时使用；业务 Skill（剪口播/字幕/画面/导出）第 0 步也引用本 Skill 的就绪检查。不用于剪辑、字幕、画面、导出本身或项目数据迁移。

When to use

  • checking for skill updates
  • installing the editing environment
  • installing the player
  • checking environment readiness
  • configuring transcription credentials
  • activating skill updates
  • Runtime installation and health check

When not to use

  • video editing
  • subtitling
  • visual editing
  • exporting
  • project data migration
  • creating projects
  • opening Studio
  • transcribing media
