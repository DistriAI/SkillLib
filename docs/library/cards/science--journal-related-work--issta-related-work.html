issta-related-work

separate

Use when positioning an ISSTA submission against the testing and analysis literature, covering the sibling venues (ICSE, FSE, ASE, ICST, PLDI, CAV), delta-first framing against the nearest technique, double-anonymous self-citation, distinguishing the closest tool baseline, and avoiding the venue-confusion of citing a paper to the wrong conference.

When to use

  • positioning an ISSTA submission
  • auditing novelty and positioning
  • sweeping sibling venues
  • framing delta against nearest technique
  • managing double-anonymous self-citation
  • distinguishing closest tool baseline
  • checking venue attribution
  • declaring archival overlap

When not to use

  • surveying the field
  • advising on dual-submission rules without reopening the call
