jet-topic-selection

separate

Use when testing whether a project clears the Journal of Economic Theory (JET) scope gate — a rigorous, original theoretical contribution in a core theory area, with empirical/computational work only when firmly grounded in theory.

When to use

  • Deciding whether a result belongs at JET versus a field or empirical journal
  • Evaluating if data, experiments, or computations can go to JET
  • Choosing which of several results to lead with
  • Testing if a project is a rigorous, original theoretical contribution
  • Determining if empirical content is firmly grounded in theory

When not to use

  • Structural estimation or calibration exercises
  • Stand-alone empirical papers
  • Computational exercises with no characterization result
  • Marginal generalizations of published theorems
  • Applied-micro or finance papers with a token model bolted on
