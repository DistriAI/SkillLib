bio-rna-quantification-tximport-workflow

separate

Import transcript-level quantifications from Salmon, kallisto, or other tools into R for gene-level analysis using tximport or tximeta. Use when importing transcript counts into R for DESeq2 or edgeR.

When to use

  • Importing transcript counts into R
  • Gene-level differential expression analysis
  • Using tximport or tximeta
  • Creating tx2gene mappings
  • Summarizing transcripts to gene level
  • Handling version numbers in transcript IDs
