x-twitter-connect

separate

Connect TweetClaw to pull public X/Twitter marketing signals into OpenClaw workflows. Use when the user wants social listening, tweet search, reply search, follower export, user lookup, media review, monitor setup, webhook-backed tracking, giveaway evidence, or approval-gated post and reply workflows. Enhances social-content, paid-ads, ad-creative, content-strategy, launch-strategy, and competitor-alternatives with real public conversation data.
