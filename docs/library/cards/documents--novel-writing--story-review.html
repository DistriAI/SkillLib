story-review

separate

多视角对抗式审查。full/lean 模式在已部署 reviewer agents 时并行 spawn；缺失/异常 agents 或 spawn 失败时自动降级 solo，参考文件不可读时使用内置 rubric fallback。触发方式：/story-review、/审查、「审查一下」「帮我审一下」。

When to use

  • 审查小说结构
  • 审查角色设计
  • 审查文字表达
  • 审查设定一致性
  • 提供修改建议

When not to use

  • 验证正确性
  • 查询或记录作者记忆
  • 降低 rubric 严重度
  • 跳过平台门禁
