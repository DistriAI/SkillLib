lang-literature-positioning

separate

Use when positioning a Language (LSA) manuscript within the literature so it reads as in dialogue with current linguistics across frameworks. Language reviewers are drawn from across subfields; the positioning must engage the strongest rival accounts fairly, not build a subfield-only wall. Maps the conversation; it does not write the literature review.

When to use

  • Drafting or restructuring the literature/positioning section
  • Writing a Discussion Note or Perspectives Commentary
  • Deciding which debates to foreground for a general linguistics readership
  • Engaging the strongest rival account fairly
  • Cross-framework positioning
  • Building a three-column map of debate, tension, and delta
  • Returning a ledger of claim, evidence, risk, and location
  • Comparing against sibling journals for re-routing

When not to use

  • Writing the literature review
  • Refereeing a framework war
  • Building a subfield-only wall
  • Straw-manning the rival account
  • Filling an empty descriptive cell
  • Giving submission-ready advice before checking official source map
