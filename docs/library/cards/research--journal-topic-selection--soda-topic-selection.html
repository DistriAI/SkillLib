soda-topic-selection

separate

Use when deciding whether a result is SODA-shaped (ACM-SIAM Symposium on Discrete Algorithms) — concrete algorithmic problems, data structures, and discrete mathematics with quantitative progress — versus routing to STOC/FOCS, ESA, ICALP, ITCS, SOSA, ALENEX, SoCG, or a journal, judged from SODA's algorithms-first identity.

When to use

  • deciding if a result is SODA-shaped
  • routing to STOC/FOCS, ESA, ICALP, ITCS, SOSA, ALENEX, SoCG, or a journal
  • evaluating concrete algorithmic problems
  • evaluating data structures
  • evaluating discrete mathematics with quantitative progress
  • applying the three-question fit test
  • adjudicating borderline cases
  • identifying anti-fit signals

When not to use

  • results needing a general theory-of-computation audience
  • results needing a systems audience
  • new complexity-theoretic barriers or models
  • bold new problems with modest technical depth
  • contributions where a known result becomes simple
  • contributions focused on implementation and measurement
  • computational geometry core
  • distributed or parallel model as the point
