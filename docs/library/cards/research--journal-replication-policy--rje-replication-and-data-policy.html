rje-replication-and-data-policy

separate

Use to assemble a reproducible replication package for a RAND Journal of Economics (RJE) industrial-organization manuscript and to handle RJE's supporting-information rules correctly — the journal discourages supplementary material and does not host data/code itself. Reflects what is and is NOT confirmed in RJE policy.

When to use

  • Preparing data and code for an RJE submission or revision
  • Deciding what to attach as supporting information
  • Confirming RJE's data/code policy requirements
  • Building a clean replication package for IO reproducibility
  • Documenting restricted data access and construction code
  • Handling RJE-specific supporting information rules

When not to use

  • Assuming an AER/QJE-style mandatory deposit exists at RJE
  • Dumping core estimates into discouraged supporting information
  • Promising to share restricted data not licensed for release
