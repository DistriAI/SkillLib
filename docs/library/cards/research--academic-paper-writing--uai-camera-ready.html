Use when converting an accepted UAI paper into its PMLR proceedings version, covering de-anonymization, final formatting against the UAI template, metadata for the PMLR volume, restoring public code and data links, poster and spotlight preparation for the conference, and sequencing work back from the camera-ready deadline.

  • final formatting against UAI template
  • metadata for PMLR volume
  • restoring public code and data links
  • poster and spotlight preparation
  • sequencing work back from camera-ready deadline

When not to use

  • smuggling in new results
  • altering claims
