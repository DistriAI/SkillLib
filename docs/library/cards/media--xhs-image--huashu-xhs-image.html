为小红书笔记生成高质量配图。默认AI生成（Gemini），仅精确数据表格用HTML兜底。当用户提到"小红书配图"、"小红书封面"、"小红书图片"、"做张小红书图"、"笔记配图"时使用此技能。

When to use

  • 小红书配图
  • 小红书封面
  • 小红书图片
  • 做张小红书图
  • 笔记配图

When not to use

  • HTML截图（非精确数据表格）
  • 赛博霓虹/深蓝底风格
  • 包含署名/水印的封面图
