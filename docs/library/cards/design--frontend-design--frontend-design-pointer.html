frontend-design-pointer

authentic

Point to Anthropic's frontend-design skill and explain when to use it. Use when asked how to install frontend-design, which skill sets aesthetic direction for a UI, or what handles the direction stage of the design pipeline. Produces the install command, a check that the install worked, guidance on when it fits and when it does not, and credit to the author with a link. Contains no upstream skill content.

When to use

  • Installing Anthropic's frontend-design skill
  • Setting aesthetic direction for a new UI
  • Choosing a skill for the direction stage of the design pipeline
  • Resolving name clashes with local frontend-design skills

When not to use

  • Following an existing design system
  • Reviewing already built designs
  • Verifying rendering correctness
  • Overriding an existing brand
