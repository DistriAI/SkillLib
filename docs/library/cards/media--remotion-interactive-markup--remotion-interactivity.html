Structure Remotion markup for interactivity

When to use

  • Use when this upstream workflow matches the user's stated goal.
  • Use when the task requires the procedures documented in this skill.
  • Allowing items to be selected by clicking on them
  • Allowing drag+drop, resizing and rotation
  • Editing the CSS styles
  • Making keyframes and easing values editable

When not to use

  • Imported upstream skill; verify credentials, permissions, and safety boundaries before execution.
  • Does not replace environment-specific validation, testing, or maintainer review.

Conflict

The remotion-dev/skills copy is the upstream, versioned procedure and focuses on the Interactive.withSchema() wrapper, schema field types, and layout options. The sickn33/agentic-awesome-skills copy is a mirror of an earlier version (4.0.526 vs 4.0.535) that adds concrete authoring rules the upstream copy omits: inline text, descriptive hardcoded names, inline CSS style objects, inline interpolate() calls with specific supported input expressions, use of scale/translate/rotate over transform, and inline composition metadata. Because the mirror contains material steps and constraints the upstream copy lacks, crowning one would hide a real alternative.
