eacl-related-work

separate

Use when positioning an EACL paper against fast-moving NLP literature, covering ACL-Anthology-first citation, correct Findings attribution, handling concurrent preprints fairly, freshness sweeps across recent *ACL rounds and European venues like LREC-COLING, and framing related work as a contrastive argument rather than a list.

When to use

  • positioning an EACL paper against NLP literature
  • ACL-Anthology-first citation
  • correct Findings attribution
  • handling concurrent preprints fairly
  • freshness sweeps across recent *ACL rounds
  • freshness sweeps across European venues like LREC-COLING
  • framing related work as a contrastive argument

When not to use

  • cataloguing the field
  • neutral literature dump
  • listing only famous references
