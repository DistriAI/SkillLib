create-mobile-app

separate

Use when the user wants to start a new Power Apps mobile app (Expo / React Native / TypeScript, targeting iOS and Android) from scratch.

When to use

  • start a new Power Apps mobile app
  • Expo / React Native / TypeScript app creation
  • targeting iOS and Android
  • creation from a fresh template
  • continuation of unfinished creation

When not to use

  • editing an existing app
  • cloning, degit, or copying a template
  • adopting, repairing, or overwriting a completed app
  • provisioning ADO npm tokens
