rje-writing-style

separate

Use to make a manuscript conform to The RAND Journal of Economics (RJE) Style Guide — author-date citations with no page numbers, references with no issue numbers, numbered sections with unnumbered subsections, flush-right equation numbering, and the journal's distinctive house usage rules. Style and usage polish, not content drafting.

When to use

  • Final language and citation polish before submission to RJE
  • Converting a draft from a numbered/footnote citation style to RJE author-date
  • Catching the journal's specific usage rules that copy editors enforce
  • Style and usage polish

When not to use

  • Content drafting
