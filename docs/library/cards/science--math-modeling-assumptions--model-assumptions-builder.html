model-assumptions-builder

authentic

Extract and maintain global and method-specific mathematical-model assumptions from the problem frame, active method cards, data profile, and risk probes, while leaving necessity and impact judgments to the human modeler.

When to use

  • Extract explicit problem assumptions
  • Extract method-induced assumptions
  • Remove filler statements
  • Record assumption scope and source
  • Identify conflicts across Qx
  • Present unresolved necessity/impact trade-offs
  • Log human assumption_necessity decisions
  • Save planning/model_assumptions.md

When not to use

  • Finalize necessary/simplifying judgments
  • Finalize impact judgments
  • Invent generic assumptions
  • Leave many repeated sentinels in the final file
