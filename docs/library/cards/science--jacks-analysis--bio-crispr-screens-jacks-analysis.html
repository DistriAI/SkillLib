bio-crispr-screens-jacks-analysis

separate

JACKS (Joint Analysis of CRISPR/Cas9 Knockout Screens) for modeling sgRNA efficacy and gene essentiality. Use when analyzing multiple CRISPR screens simultaneously or when accounting for variable sgRNA efficiency across experiments.

When to use

  • analyzing multiple CRISPR screens simultaneously
  • accounting for variable sgRNA efficiency across experiments
  • modeling sgRNA efficacy and gene essentiality
  • joint analysis across experiments
  • classifying genes as essential or enriched
  • assessing sgRNA performance
  • identifying low-efficacy guides
