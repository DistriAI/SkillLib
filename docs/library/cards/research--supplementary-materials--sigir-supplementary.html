sigir-supplementary

separate

Use when deciding what goes inside a SIGIR paper's page budget versus the cited repository — SIGIR counts appendices inside the 9-page (full) and 4-page (short) limits with only references free, so overflow material must be re-homed into run files, repository docs, or cut, without hiding review-critical evidence outside the paper.

When to use

  • Deciding what goes inside a SIGIR paper's page budget
  • Managing overflow material for SIGIR submissions
  • Triage of content between paper body and cited repository
  • Compressing content to fit 9-page or 4-page limits
  • Ensuring reviewers can accept the paper without opening the repository
  • Structuring the cited repository as an appendix

When not to use

  • Hiding review-critical evidence outside the paper
  • Smuggling content into bibliography notes
  • Buying space by deleting significance-testing sentences or seed counts
  • Placing acceptance-dependent evidence only in the repository
