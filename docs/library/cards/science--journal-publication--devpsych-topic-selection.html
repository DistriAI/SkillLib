devpsych-topic-selection

separate

Use when deciding whether a project fits Developmental Psychology (APA) and which length tier to target. The journal publishes seminal empirical work that advances knowledge and theory about development across the life span; the core test is whether the contribution is about developmental change, not just a phenomenon measured in one age group. Frames the question; it does not collect data.

When to use

  • Choosing among projects or framings for Developmental Psychology
  • Deciding which length tier to target
  • Placing a study run on minors or older adults
  • Evaluating if work is about developmental change
  • Triaging work to sibling venues

When not to use

  • Collecting data
  • One-age finding with no change story
  • Personality/social process not centered on age
