authentic

Classify each parsed mathematical-modeling subquestion by required output and structure, surface ambiguous framing trade-offs for human choice, and record primary/secondary task types without selecting algorithms.

When to use

  • Classify subquestions by required output
  • Assign primary and secondary task types
  • Identify mixed or ambiguous framings
  • Record human framing decisions
  • Surface framing trade-offs for human choice

When not to use

  • Propose or choose methods
  • Select algorithms
  • Create long taxonomy reports
  • Classify only from keywords
