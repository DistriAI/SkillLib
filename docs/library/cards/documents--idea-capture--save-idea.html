save-idea

separate

Save ideas, observations, content topics, projects, and convictions in ~/path/to/ideas. Use when the user asks to capture an idea or insight. Adds to idea backlogs, not reminders or tasks.

When to use

  • capture an idea or insight
  • save video ideas
  • save podcast or content topics
  • save personal observations or hypotheses
  • save marketing ideas
  • save startup ideas
  • save mini-projects
  • save article ideas or convictions

When not to use

  • reminders
  • tasks
  • writing to the old startup repo
  • writing to startup/review/DISCARDED.md
