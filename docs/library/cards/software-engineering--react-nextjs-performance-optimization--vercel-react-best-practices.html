The two copies are the same Vercel React/Next.js performance skill, but they disagree on the rule count and include different rule sets. The LeoYeAI copy is a superset with 57 rules and additional entries (e.g., server-auth-actions, client-passive-event-listeners, rerender-memo-with-default-value, rendering-usetransition-loading, advanced-init-once), while the am-will copy lists 45 rules and omits those. Crowning one would hide the other's extra constraints, so the catalog should combine them.
