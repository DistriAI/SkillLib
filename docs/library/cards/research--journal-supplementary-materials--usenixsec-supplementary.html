usenixsec-supplementary

separate

Use when deciding what goes where in a USENIX Security Symposium paper — the 13-page body, the two mandatory one-page appendices (Ethical Considerations, Open Science), optional appendices after the references, and external artifacts — so nothing decision-critical lands where reviewers won't look.

When to use

  • deciding placement of content in USENIX Security papers
  • structuring the 13-page body
  • placing mandatory Ethical Considerations and Open Science appendices
  • managing optional appendices after references
  • routing external artifacts and code
  • triaging overflow when the body runs long
  • applying the demotion test for appendix material

When not to use

  • writing the actual content of the paper
  • selecting the research topic
  • designing experiments
  • formatting whitespace or template surgery
