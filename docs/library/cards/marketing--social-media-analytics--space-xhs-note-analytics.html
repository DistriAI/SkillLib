space-xhs-note-analytics

separate

小红书个人笔记数据复盘——基于用户自己创作者后台（创作中心/蒲公英）的笔记数据，做漏斗定位、卡点归因和多篇横向规律发现。当用户说"笔记数据复盘""这条为什么没流量""帮我看看这条数据""小红书数据分析""曝光高但没人点""涨粉不行""哪类内容该加码""我导出了后台数据帮我看看"，或直接贴出后台数据截图/CSV/Excel/几个数字时使用。只分析用户自己账号的笔记表现，不抓取平台数据、不做刷量。

When to use

  • 笔记数据复盘
  • 单篇诊断
  • 多篇横向对比
  • 找规律
  • 曝光高但没人点
  • 涨粉不行
  • 哪类内容该加码
  • 分析后台数据

When not to use

  • 账号整体定位/主页/人设诊断
  • 封面改稿
  • 标题改写
  • 抓取平台数据
  • 刷量刷互动
  • 批量起号
