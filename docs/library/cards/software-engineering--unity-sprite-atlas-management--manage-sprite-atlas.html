manage-sprite-atlas

separate

Manages SpriteAtlas assets through a prebuild pipeline, covering master and variant atlases, packing settings, and platform overrides. Use when asked to create or optimize sprite atlases.

When to use

  • create sprite atlases
  • optimize sprite atlases
  • manage master and variant atlases
  • configure packing settings
  • apply platform overrides
  • prebuild pipeline generation
  • Addressables late-binding setup

When not to use

  • runtime-only SpriteAtlas access
  • editor-only SpriteAtlasAsset scripting
  • mixing editor and runtime contexts
  • using older deprecated APIs
