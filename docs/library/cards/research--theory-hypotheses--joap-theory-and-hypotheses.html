joap-theory-and-hypotheses

separate

Use when building the theoretical model and hypotheses for a Journal of Applied Psychology (JAP) manuscript. JAP demands a genuine I-O theoretical contribution with an explicit mechanism, directional hypotheses, and a clear confirmatory/exploratory split — theory stated before the data, not after. Structures the argument; it does not run analyses.
