verification-before-completion

authentic

Use when about to claim work is complete, fixed, or passing, before committing or creating PRs - requires running verification commands and confirming output before making any success claims; evidence before assertions always

When to use

  • claiming work is complete
  • claiming work is fixed
  • claiming tests pass
  • claiming build succeeds
  • committing changes
  • creating PRs
  • verifying regression tests
  • verifying agent completion

When not to use

  • expressing satisfaction without verification
  • trusting agent success reports
  • relying on partial verification
  • using words like 'should' or 'probably'
  • claiming success based on previous runs
