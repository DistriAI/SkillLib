minimalist

Classic style skill, opt-in: it runs only when called by name. Editorial product UI with a warm monochrome palette, typographic contrast and flat bento grids.

When to use

  • Editorial product UI
  • Warm monochrome palette
  • Typographic contrast
  • Flat bento grids
  • Document-style web interfaces
  • Premium utilitarian minimalism

When not to use

  • Generic SaaS design trends
  • Inter, Roboto, or Open Sans typefaces
  • Lucide, Feather, or standard Heroicons
  • Tailwind default heavy drop shadows
  • Primary colored backgrounds for large elements
  • Gradients, neon colors, or 3D glassmorphism
  • rounded-full for large containers or primary buttons
  • Emojis in code, markup, or text
