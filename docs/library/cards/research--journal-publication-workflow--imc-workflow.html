imc-workflow

separate

Use when planning an ACM IMC campaign end to end, covering the choice between the two annual deadlines, backward planning from the target cutoff, the registration step, the One-Shot-Revision path across deadlines, availability shepherding, the camera-ready and dataset release, and the Replicability Track calendar.

When to use

  • planning an ACM IMC campaign
  • choosing between two annual deadlines
  • backward planning from target cutoff
  • registration step planning
  • One-Shot-Revision path across deadlines
  • availability shepherding
  • camera-ready and dataset release
  • Replicability Track calendar

When not to use

  • writing the paper draft
  • conducting measurements
  • obtaining IRB approval
  • responding to specific reviewer comments
  • selecting a different conference
