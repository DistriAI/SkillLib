bio-workflows-longread-sv-pipeline

End-to-end workflow for detecting structural variants from long-read sequencing data. Covers ONT/PacBio alignment with minimap2 and SV calling with Sniffles or cuteSV.

When to use

  • detecting structural variants from long reads
  • ONT/PacBio alignment with minimap2
  • SV calling with Sniffles or cuteSV
  • multi-sample SV calling
  • filtering SVs with bcftools
  • annotating SVs with AnnotSV
