qje-tables-figures

separate

Use when finalizing the main exhibits of a Quarterly Journal of Economics (QJE) manuscript — making the paper figure-forward, with clean tables and self-contained notes that read well in QJE's single-PDF, author-date format. Designs exhibits; it does not run new analysis.

When to use

  • finalizing main exhibits of a QJE manuscript
  • making the paper figure-forward
  • creating clean tables and self-contained notes
  • designing exhibits for QJE single-PDF format
  • converting dense tables to figures
  • auditing table notes for completeness
  • plotting event-study, RDD, or binscatter results

When not to use

  • running new analysis
