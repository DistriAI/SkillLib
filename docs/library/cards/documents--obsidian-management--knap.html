knap

separate

Render Markdown from templates and structured data using Knap CLI. Use when the user asks to apply a Knap template, turn JSON or CSV data into notes, batch-generate Markdown files, or format Defuddle output into a note.

When to use

  • apply a Knap template
  • turn JSON or CSV data into notes
  • batch-generate Markdown files
  • format Defuddle output into a note
  • render Markdown templates with variables, filters, and logic
  • validate Knap templates
  • override variables or pipe JSON data
  • create one file per CSV row, JSON array object, or JSON file in a folder

When not to use

  • supply Web Clipper browser variables
  • supply selectors
  • supply prompts
  • supply DOM-dependent HTML filters
