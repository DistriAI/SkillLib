bioinformatics-singlecell

separate

Advanced single-cell multi-omics analysis including scRNA-seq, scCITE-seq, scATAC-seq, and TARGET-seq. Use when analyzing single-cell data, cell type identification, trajectory analysis, differential expression, UMAP/clustering, integrating protein and RNA modalities (TotalVI), or working with Scanpy, Seurat, scvi-tools.

When to use

  • analyzing single-cell data
  • cell type identification
  • trajectory analysis
  • differential expression
  • UMAP/clustering
  • integrating protein and RNA modalities (TotalVI)
  • working with Scanpy, Seurat, scvi-tools
  • MPN, hematologic malignancies, megakaryocyte biology
