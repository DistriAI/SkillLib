european-symposium-on-research-in-computer-security

separate

Use when targeting European Symposium on Research in Computer Security (ESORICS) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for security.

When to use

  • targeting ESORICS
  • deciding if a manuscript fits ESORICS
  • conference fit read
  • re-framing from journal or arXiv style
  • evidence-gap diagnosis
  • anonymity diagnosis
  • artifact diagnosis
  • rebuttal posture

When not to use

  • substitute for current year's CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
  • routing privacy-enhancing-technology work to PETS
  • routing operational security practice to ACSAC
  • routing finance/cryptocurrency security to FC
