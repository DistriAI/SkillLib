Use when generating, extending, or editing video with Gemini Omni models on Scenario via MCP: text-to-video, image-to-video from a first frame, reference-to-video keeping a character, product, or place consistent, appending footage to a clip, restyling footage by prompt (season, wardrobe, art style), native audio with dialogue and ambience, or picking between first-frame and reference conditioning. Keywords: Gemini Omni Flash, 1.1 Flash, Google, T2V, I2V, V2V, extend, subject consistency.

When to use

  • text-to-video
  • image-to-video from a first frame
  • reference-to-video keeping a character, product, or place consistent
  • appending footage to a clip
  • restyling footage by prompt
  • native audio with dialogue and ambience
  • picking between first-frame and reference conditioning

When not to use

  • Gemini image models
  • Gemini TTS
