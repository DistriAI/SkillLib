tex-render-guide

separate

Render LaTeX math expressions to images in PNG, JPEG, and SVG

When to use

  • LaTeX to image rendering
  • Equation rendering for presentations
  • Batch rendering of equations
  • SVG math generation
  • High DPI scaling
  • Transparent background handling

When not to use

  • Native LaTeX rendering
  • TikZ rendering
  • Advanced math commands unsupported by KaTeX
