curranthro-writing-style

separate

Use when drafting or polishing a Current Anthropology (CA) manuscript so it reads across all subfields for a worldwide audience, follows CA house style (free-format accepted; final files use Chicago author-date), fits the article-type word caps (Major Article 6,000–10,000 words; Report 3,000–5,000; abstract ≤ 200 words), and uses clear, jargon-light, inclusive language. Tightens prose and format; it does not invent content.

When to use

  • Drafting the introduction
  • Framing the intervention
  • Final polish
  • Cutting text over the word cap
  • Writing the abstract
  • Aligning citations and format to CA house style

When not to use

  • Inventing content
