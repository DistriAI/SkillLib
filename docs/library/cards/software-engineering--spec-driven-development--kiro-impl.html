kiro-impl

authentic

Implement approved tasks using TDD with subagent dispatch. Runs all pending tasks autonomously or selected tasks manually.

When to use

  • Implement approved tasks
  • Run pending tasks autonomously
  • Execute selected tasks manually
  • Dispatch sub-agents for implementation
  • Perform independent review after each task
  • Validate approvals in spec.json
  • Discover validation commands
  • Establish repo baseline

When not to use

  • Unapproved tasks
  • Batching multiple sub-tasks into a single sub-agent dispatch
