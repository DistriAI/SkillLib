jacs-supplementary

separate

Use when assembling the Supporting Information for a Journal of the American Chemical Society (JACS) manuscript — complete procedures, full compound characterization, copies of key spectra, and crystallographic CIFs/CCDC numbers. Builds and audits the SI — it does not decide which experiments to run.

When to use

  • Assembling JACS Supporting Information
  • Auditing SI for completeness
  • Verifying compound procedures and characterization
  • Checking crystallographic CIF deposits and CCDC numbers
  • Reviewing spectra copies and purity traces
  • Ensuring SI consistency with main text

When not to use

  • Deciding which experiments to run
  • Writing main text content
  • Polishing format for sibling journals
