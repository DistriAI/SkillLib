value-proposition

separate

Design a detailed value proposition using a 6-part JTBD template — Who, Why, What before, How, What after, Alternatives. Use when creating a value proposition, analyzing customer value delivery, or articulating why customers should choose your product.

When to use

  • creating a value proposition
  • analyzing customer value delivery
  • articulating why customers should choose your product
  • designing compelling customer value
  • defining core problem and JTBD
  • comparing against competitive alternatives
  • developing a positioning statement

When not to use

  • detailed pains/gains decomposition for a mature product with complex customer needs
