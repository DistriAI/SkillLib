election-data-source-countypres

separate

County Presidential Returns 2000-2024 (MIT MEDSL). Vote shares, party trends, turnout by county_fips (joins census/education data). Requires HARVARD_DATAVERSE_API_KEY. Critical: mode='TOTAL' drops ~1K counties post-2020 — use 3-pattern reconstruction

When to use

  • County-level presidential vote shares
  • Party trends
  • Turnout analysis
  • Geographic voting patterns
  • Joining with census data
  • Joining with education data
  • Voting method analysis for 2020 and 2024

When not to use

  • Non-presidential election data
  • State-level aggregate analysis without county detail
