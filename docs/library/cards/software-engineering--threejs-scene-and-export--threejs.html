threejs

combined

Use when building or debugging interactive 3D scenes on the web with Three.js (scene/camera/renderer, lights/materials, GLTF loading, controls, performance). Helpful for designers shipping 3D UI moments. Three.js scene-graph parsing and export workflows: mesh baking, InstancedMesh expansion, part partitioning, per-link OBJ export, and URDF articulation.

When to use

  • Real 3D: product spins, interactive hero scenes, shaders/material effects, 3D data viz
  • You need full control beyond “background effects”
  • You can budget time for asset pipeline + performance tuning
  • Requests 3D visualizations or graphics ("create a 3D model", "show in 3D")
  • Wants interactive 3D experiences ("rotating cube", "explorable scene")
  • Needs WebGL or canvas-based rendering
  • Asks for animations, particles, or visual effects
  • Mentions Three.js, WebGL, or 3D rendering

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.

Conflict

The three copies cover different Three.js workflows. MengTo/Skills is a general web-design skill for building and debugging interactive 3D scenes (setup, render loop, controls, performance, cleanup). benchflow-ai/skillsbench is a specialized scene-graph parsing and export skill (part partitioning, mesh baking, InstancedMesh expansion, per-part OBJ export, URDF articulation). sickn33/agentic-awesome-skills is a high-level wrapper that defers to a detailed guide and gives a generic example workflow. None is a reproduction of the others; each has material steps the others lack, so crowning one would hide real alternatives.
