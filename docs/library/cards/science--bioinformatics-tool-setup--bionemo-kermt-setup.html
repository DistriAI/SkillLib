bionemo-kermt-setup

separate

Bootstrap the KERMT agent environment — verify host docker + nvidia-container-toolkit, build the kermt:latest image from the repo's Dockerfile if it doesn't yet exist, and run a GPU smoke test inside the container. Every other kermt-* skill depends on this; invoke it first.

When to use

  • verify host docker
  • verify nvidia-container-toolkit
  • build kermt:latest image
  • run GPU smoke test
  • first-time setup
  • debugging
  • forced rebuild

When not to use

  • run training workloads
  • run inference workloads
  • pull docker images
  • push docker images
  • auto-delete kermt tags
  • prune older kermt tags
  • modify host docker daemon configuration
  • modify daemon.json
