data-bar-formatting

separate

从带单位的字符串列中提取数值并清洗，生成包含直方图、饼图、条形图和累积分布图的多维度综合分布可视化图表，用于展示数据的集中趋势与分布特征。

When to use

  • 从带单位的字符串列中提取数值
  • 清理无效和空值数据
  • 生成直方图
  • 生成饼图
  • 生成条形图
  • 生成累积分布图
  • 展示数据的集中趋势与分布特征
