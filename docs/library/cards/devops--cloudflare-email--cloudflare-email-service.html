cloudflare-email-service

separate

Implement or troubleshoot Cloudflare Email Sending and Email Routing integrations and their delivery configuration.

When to use

  • Send emails from a Cloudflare Worker
  • Send emails from an AI agent built with Cloudflare Agents SDK
  • Send emails from an external app or agent
  • Send emails from a coding agent
  • Receive and process incoming emails
  • Set up Email Sending or Email Routing
  • Improve deliverability, avoid spam folders

When not to use

  • Using email for marketing/bulk sends
