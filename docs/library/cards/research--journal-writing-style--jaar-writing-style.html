jaar-writing-style

separate

Use when drafting or polishing the prose of a Journal of the American Academy of Religion (JAAR) article so it is clear, analytic, gender-neutral, and readable across the study of religion. Improves scholarly prose; it does not invent content. For reference formatting use jaar-citation-and-style.

When to use

  • drafting the introduction/conclusion
  • doing a final prose pass
  • aligning to JAAR's language conventions
  • handling foreign-language terms
  • transliteration
  • technical vocabulary
  • improving scholarly prose

When not to use

  • inventing content
  • reference formatting
