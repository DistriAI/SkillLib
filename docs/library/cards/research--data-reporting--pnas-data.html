pnas-data

separate

Use to build PNAS's Data Availability Statement and deposition plan — mandatory deposition of data in an approved repository at submission, accession numbers/DOIs, public + archived code, and materials sharing. "Available on request" is not sufficient for primary data.

When to use

  • Building Data Availability Statement
  • Planning data deposition
  • Verifying accession numbers and DOIs
  • Ensuring code is public and archived
  • Planning materials sharing
  • Checking ethics and compliance statements

When not to use

  • Writing 'available on request' for primary data
  • Linking only to personal or lab websites
  • Submitting without accession numbers
