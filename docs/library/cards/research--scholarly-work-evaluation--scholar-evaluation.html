scholar-evaluation

combined

Provides qualitative-first, evidence-traceable developmental review of scholarly works and audit low-stakes research-assessment rubrics with optional local quality controls. Never use for ranking people or consequential decisions. Implements the ScholarEval framework to evaluate scholarly documents; trigger when the user provides a PDF/DOCX/TXT file or pasted text and requests critique, scoring, or quality assessment.

When to use

  • Provide developmental, evidence-traceable feedback on a **scholarly work**: paper, draft, protocol, literature synthesis, or research idea. Use qualitative judgment first. Optional scores only describe how submitted evidence maps to a pred…
  • Evaluate a research paper, thesis, or proposal and produce a structured critique with scores.
  • Generate actionable revision recommendations across core academic writing dimensions.
  • Compare multiple drafts/versions of a manuscript using consistent rubric-based scoring.
  • Assess submission readiness (e.g., for a conference/journal) and identify major weaknesses.
  • Review a document provided as a PDF/DOCX/TXT file when the user expects automatic text extraction.
  • Evaluating research papers for quality and rigor
  • Assessing literature review comprehensiveness and quality

When not to use

  • ranking people
  • hiring, promotion, or tenure decisions
  • admissions decisions
  • grants or funding decisions
  • prizes, honors, or awards
  • discipline, dismissal, or sanctions
  • high-impact personnel decisions
  • publication-readiness or accept/reject judgments

Skill page

Conflict

The copies describe the same ScholarEval-style task but implement materially different procedures and constraints. K-Dense-AI/scientific-agent-skills is a qualitative-first, evidence-traceable developmental review with strict safety, data, and metric-prestige boundaries, and it explicitly forbids ranking people, consequential decisions, and publication-readiness judgments. The other three copies are more operational scoring workflows: they define 8 dimensions, a 1–5 scale, JSON score files, and scripts for score calculation; aipoch/medical-research-skills adds automatic PDF/DOCX/TXT extraction; foryourhealth111-pixel/Vibe-Skills and brycewang-stanford/Auto-Empirical-Research-Skills add scientific-schematics generation and publication-readiness use. Because crowning one copy would hide real alternatives—especially the safety-first developmental version versus the scoring/extraction/schematics versions—the correct decision is combine.
