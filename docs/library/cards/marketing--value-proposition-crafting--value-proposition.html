Skill page

Conflict

The two skills approach value proposition design from different angles with distinct methodologies. The first (phuryn) uses a 6-part JTBD template (Who, Why, What Before, How, What After, Alternatives) to analyze and structure the value delivery, explicitly contrasting itself with Strategyzer's canvas. The second (mohitagw15856) focuses on the final copywriting output, providing a specific sentence structure ('For [audience] who [need]...'), a one-liner constraint, and anti-patterns for marketing copy. The first is a strategic analysis framework; the second is a tactical copywriting tool. Combining them allows an agent to first analyze the value using the JTBD structure and then craft the specific marketing statements using the copywriting templates.
