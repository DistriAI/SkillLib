humrel-contribution-framing

separate

Use when sharpening the theoretical contribution and the "so what" for a Human Relations (HR) manuscript once results exist. Frames the contribution; it does not develop the underlying theory or run analysis.

When to use

  • sharpening theoretical contribution
  • framing the 'so what'
  • naming contribution type
  • writing the contribution paragraph
  • calibrating the claim
  • structuring the discussion

When not to use

  • developing underlying theory
  • running analysis
  • firm-performance improvement
  • well-powered confirmation of a moderated hypothesis
  • pure critique with no constructive claim
  • rich description that never theorizes
