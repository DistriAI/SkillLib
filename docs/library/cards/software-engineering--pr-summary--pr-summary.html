pr-summary

separate

Refresh the current pull request description from its net changes, following the repository's PR template, when asked to update or write the PR summary. Works in any Scenario repository, whatever its default branch.

When to use

  • Update PR summary
  • Write PR description
  • Refresh PR body
  • Follow repository PR template
  • Verify PR checks
  • Update PR title
  • Apply PR changes via REST API

When not to use

  • Create new pull requests
  • Run untrusted branch code without permission
  • Run paid or production operations
  • Tick attestations about human review or approvals
