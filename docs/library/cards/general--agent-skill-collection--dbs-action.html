When to use

  • Diagnosing procrastination
  • Identifying execution blocks
  • Analyzing avoidance behaviors
  • Explaining psychological reasons for inaction

When not to use

  • Providing motivation or encouragement
  • Offering professional psychological counseling
  • Providing business strategy advice
  • Helping users find more preparation resources
