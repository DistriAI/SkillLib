aejpol-theory-model

separate

Use when an AEJ: Economic Policy manuscript needs a framework that maps reduced-form estimates into a welfare, cost-benefit, or distributional policy object — sufficient statistics, MVPF, optimal-policy, or a small applied model. Builds the estimate-to-welfare bridge and states its assumptions; it does not run the empirical estimation or write the prose.

When to use

  • mapping reduced-form estimates into welfare objects
  • cost-benefit or distributional policy objects
  • sufficient statistics
  • MVPF
  • optimal-policy
  • small applied model
  • estimate-to-welfare bridge
  • stating framework assumptions

When not to use

  • running the empirical estimation
  • writing the prose
