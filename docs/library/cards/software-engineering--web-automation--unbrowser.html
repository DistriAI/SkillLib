unbrowser

separate

Cheap first-pass web browsing without launching Chrome — fetch SSR pages, follow links, query the DOM, run JS, detect bot-wall challenges. Escalate to OpenClaw's managed browser when the page can't be served headlessly.

When to use

  • first-pass scraping of public web pages
  • navigation of SSR / static sites
  • multi-step interaction with simple HTML forms
  • authenticated tasks against user-provided credentials
  • Docs sites, GitHub/GitLab UI, PyPI/npm registry pages
  • Search-result extraction
  • SPA shell rendering where curl returns empty

When not to use

  • Credential harvesting
  • scraping login forms for user/password pairs
  • authenticating as anyone other than the requesting user
  • Mass scraping
  • denial-of-service-style request volumes
  • circumventing per-IP rate limits
  • Running arbitrary remote code
  • Pages requiring canvas/WebGL/audio rendering or screenshot OCR
