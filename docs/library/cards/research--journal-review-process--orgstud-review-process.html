orgstud-review-process

separate

Use when calibrating expectations for the Organization Studies (OS) review cycle — desk-screen odds, the developmental double-anonymized process, decision types, and how to read what reviewers and the handling editor are signalling. Sets expectations and reading strategy; it does not draft the response (see orgstud-rebuttal).

When to use

  • Calibrating desk-reject odds and timeline
  • Reading decision letters for editor signals
  • Distinguishing major-but-encouraging R&R from high-risk reject-with-resubmission
  • Deciding whether to revise for OS or reposition to a sibling journal
  • Understanding OS double-anonymized developmental review process
  • Interpreting theory-first reviewer comments
  • Separating essential editor-flagged asks from optional ones

When not to use

  • Drafting the response to reviewers
  • Developing theory
  • Framing contribution
  • Routing repositioning workflow
