ops-monitor

separate

Unified APM and monitoring surface. Polls Datadog, New Relic, and OpenTelemetry backends for active alerts, error traces, and entity health. Use --watch for live polling every 60 seconds. Use --setup to configure monitoring credentials.

When to use

  • Polling Datadog, New Relic, and OpenTelemetry backends
  • Checking active alerts, error traces, and entity health
  • Live polling every 60 seconds with --watch
  • Configuring monitoring credentials with --setup
  • Filtering by specific backend with --backend
