conbio-data-analysis

separate

Use when executing and reporting the analysis for a Conservation Biology manuscript so it survives expert, double-blind review — appropriate ecological/statistical models, honest uncertainty, robustness, and reproducibility. Covers detection, hierarchical models, spatial structure, and effect sizes that matter for conservation. Guides analysis norms; it does not fabricate results.

When to use

  • Running main and supporting analyses
  • Building the results section
  • Addressing reviewer requests for robustness or alternative models
  • Reconciling exploratory vs. confirmatory analyses
  • Making the analysis reproducible before deposit
  • Auditing unit, comparison, uncertainty, and reproducibility
  • Translating estimates into decision-relevant quantities

When not to use

  • Fabricating results
  • Design decisions
  • Polishing prose without evidence audit
