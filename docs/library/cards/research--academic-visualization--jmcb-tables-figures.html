jmcb-tables-figures

separate

Use when exhibits — IRF plots, coefficient/event-study figures, balance-sheet and regression tables — are the bottleneck for a Journal of Money, Credit and Banking (JMCB) manuscript. Makes each exhibit answer the question on its own; it does not re-run the analysis or write the prose.

When to use

  • IRF plots
  • coefficient/event-study figures
  • balance-sheet tables
  • regression tables
  • local-projection coefficient plots
  • summary tables
  • exhibit hierarchy ordering
  • table and figure notes

When not to use

  • re-running the analysis
  • writing the prose
