red-rebuttal

separate

Use when planning the response-to-referees after a Review of Economic Dynamics (RED) revise-and-resubmit — structuring a point-by-point reply for a single-anonymized, two-referee process, prioritizing model/quantitative concerns, and remembering that second-and-later resubmissions are exempt from the submission fee. Strategy; it does not write the paper.

When to use

  • planning the response-to-referees after a RED revise-and-resubmit
  • structuring a point-by-point reply for a single-anonymized, two-referee process
  • prioritizing model and quantitative concerns
  • reconciling comments from referees and the editor
  • handling requests touching the model, calibration, or code archive
  • updating data and code archives for revisions

When not to use

  • writing the paper
