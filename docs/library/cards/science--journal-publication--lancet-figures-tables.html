lancet-figures-tables

separate

Use to build and check The Lancet's clinical display items — the Table 1 baseline characteristics, Kaplan–Meier curves with numbers at risk, forest plots for subgroups/meta-analyses, the CONSORT/study-flow diagram, and maps for multi-country studies — all with confidence intervals shown.

When to use

  • Table 1 baseline characteristics
  • Kaplan–Meier curves with numbers at risk
  • forest plots for subgroups/meta-analyses
  • CONSORT/study-flow diagram
  • maps for multi-country studies
  • checking confidence intervals on effect estimates

When not to use

  • prose writing
  • statistical analysis methods
  • ethics coordination
  • reporting guidelines compliance
