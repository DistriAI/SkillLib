transcript-intelligence

combined

Use when the user wants to summarize, analyze, or repurpose transcripts from TikTok, Instagram, YouTube, Facebook, X/Twitter, LinkedIn, Rumble, or Reddit video posts. Extracts hooks, claims, quotes, content atoms, themes, and reusable scripts. Turn TikTok, Instagram, YouTube, Facebook, X, LinkedIn, Reddit, or Rumble transcripts into timestamped hooks, claims, objections, proof, calls to action, sponsorship signals, and reusable content atoms. Use directly for transcript analysis or as support for creator, competitor, trend, demand, and repurposing work.

When to use

  • summarize a video, reel, short, TikTok, podcast clip, or social video
  • analyze a creator's hooks or speaking style
  • extract quotes, claims, examples, and CTAs from transcripts
  • turn transcripts into social posts, scripts, newsletters, or content ideas
  • compare what multiple creators say about a topic

When not to use

  • summarize from the title alone if the user asked for transcript analysis

Conflict

Both copies describe the same task (turning social video transcripts into hooks, claims, objections, CTAs, and reusable atoms), but each contains material steps the other lacks. The gooseworks copy adds explicit guardrails (never invent spoken content, flag regulated claims, treat engagement as distribution not proof) and a per-video table output with confidence. The ScrapeCreators copy adds concrete API endpoints per platform, a required SCRAPECREATORS_API_KEY, a discovery step for creator/channel inputs, a detailed output template (TL;DR, swipe file, repurposing ideas), and a common-pitfalls section. Crowning one would hide the other's real operational details.
