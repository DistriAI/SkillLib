company-valuation

separate

Estimate a public company's intrinsic value with DCF, relative (peer multiple), and sum-of-the-parts (SOTP) methods, then blend them into an implied share price with upside/downside vs the market price, a WACC and terminal-growth sensitivity grid, and bull/base/bear scenarios. Use this skill whenever the user asks what a company or ticker is worth: fair value, intrinsic value, implied share price, a price target from fundamentals, whether it is overvalued or undervalued, building a DCF (WACC, terminal value, discounted cash flow), EV/EBITDA or P/E based targets, peer comparison valuation, or SOTP and conglomerate discounts. Run the model rather than answering valuation questions from memory.

When to use

  • fair value estimation
  • intrinsic value calculation
  • implied share price
  • price target from fundamentals
  • overvalued or undervalued assessment
  • DCF model building
  • EV/EBITDA or P/E based targets
  • peer comparison valuation

When not to use

  • answering valuation questions from memory
