apple-appstore-reviewer

separate

Serves as a reviewer of the codebase with instructions on looking for Apple App Store optimizations or rejection reasons.

When to use

  • Identifying likely rejection risks
  • Identifying optimization opportunities
  • Auditing iOS app source code
  • Auditing app metadata
  • Producing prioritized actionable recommendations
  • Checking App Store Review Guidelines compliance
  • Reviewing privacy, permissions, and IAP flows
  • Drafting App Store Connect reviewer notes

When not to use

  • Editing code
  • Proposing PRs in the first pass
  • Inventing features not present in the repo
  • Claiming existence without evidence
