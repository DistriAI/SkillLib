code-reviewer

combined

Analyzes code diffs and files to identify bugs, security vulnerabilities (SQL injection, XSS, insecure deserialization), code smells, N+1 queries, naming issues, and architectural concerns, then produces a structured review report with prioritized, actionable feedback. Use when reviewing pull requests, conducting code quality audits, identifying refactoring opportunities, or checking for security issues. Invoke for PR reviews, code quality checks, refactoring suggestions, review code, code quality. Complements specialized skills (security-reviewer, test-master) by providing broad-scope review across correctness, performance, maintainability, and test coverage in a single pass. Default code-quality route for broad code review, PR review, maintainability, correctness, and regression-risk checks. Do not use as the primary route for dedicated OWASP/security audits, review-feedback handling, completion verification, AI-code cleanup, or TDD/test-first work.

When to use

  • Reviewing pull requests
  • Conducting code quality audits
  • Identifying refactoring opportunities
  • Checking for security vulnerabilities
  • Validating architectural decisions
  • Working on code reviewer tasks or workflows
  • Needing guidance, best practices, or checklists for code reviewer

When not to use

  • The task is unrelated to code reviewer
  • You need a different domain or tool outside this scope

Conflict

The four copies are not reproductions of one procedure. Jeffallan/claude-skills defines a manual, structured review workflow with a specific output template and constraints. foryourhealth111-pixel/Vibe-Skills defines a routing boundary and relies on automated Python scripts (pr_analyzer, code_quality_checker, review_report_generator). zhnnky329/MathModeling-skills is a narrow router for Python vs MATLAB modeling code that outputs a JSON review contract. rmyndharis/antigravity-skills is a broad, tool-centric expert persona covering AI tools, static analysis, and infrastructure. Because they disagree on the primary mechanism (manual workflow vs scripts vs language router vs tool persona) and each contains material steps the others lack, crowning one would hide real alternatives.
