holoscan-setup

separate

Assess a host and choose a Holoscan SDK 5.x installation method using release availability, CUDA 13 compatibility, and component needs.

When to use

  • Assess host for Holoscan SDK 5.x
  • Choose Holoscan SDK 5.x installation method
  • Check CUDA 13 compatibility
  • Verify component needs for Holoscan 5.x
  • Inspect existing Holoscan installations
  • Recommend source or container installation
  • Route to specific Holoscan installation skills

When not to use

  • Installing 4.x Conda packages
  • Proving GPU passthrough or runtime success
  • Establishing Tegra/iGPU support on ARM64
  • Routing to nonexistent 5.x CUDA 12 packages
