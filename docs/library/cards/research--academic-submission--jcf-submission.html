jcf-submission

separate

Use when running the final pre-submission preflight for the Journal of Corporate Finance (JCF) via Editorial Manager — the US$340 non-refundable fee, single-anonymized (non-anonymized) manuscript, ≤250-word abstract, author-date "your paper, your way" references, Option C data statement, declarations, and the optional free SSRN preprint. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • confirming US$340 fee
  • checking abstract word count
  • verifying author-date references
  • checking Option C data statement
  • completing declarations
  • deciding on SSRN preprint
  • Editorial Manager run-sheet

When not to use

  • drafting content
