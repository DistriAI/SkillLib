Create cross-platform agent skills from workflow descriptions. Activates when users ask to create an agent, automate a repetitive workflow, create a custom skill, or need advanced agent creation. Triggers on phrases like create agent for, automate workflow, create skill for, every day I have to, daily I need to, turn process into agent, need to automate, create a cross-platform skill, validate this skill, export this skill, migrate this skill, audit this skill, is this skill safe, vet a skill before installing, what does this skill access. Supports single skills, multi-agent suites, transcript processing, template-based creation, interactive configuration, cross-platform export, spec validation, and security auditing of third-party skills before install. Vibe Code Orchestrator (VCO) is a governed runtime entry that freezes requirements, bounds execution, and enforces verification and phase cleanup.

Conflict

These four skills all address the creation of agent skills, but they are distinct, non-interchangeable procedures. cangjie-skill is a specific pipeline for distilling long-form content (books/videos) into skills. agent-skills-platform is a general-purpose factory for creating skills from workflow descriptions with a focus on cross-platform export and security. Vibe-Skills is a governed runtime entry point for executing complex tasks with strict phase controls. context-engineering-collection is a reference library of patterns for building agent systems, not a step-by-step creation procedure. Because they cover different inputs, outputs, and execution models, crowning one would hide the others' unique value.
