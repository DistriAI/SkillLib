single-sheet-export

separate

动态统计多Sheet Excel文件行数以判断大文件处理逻辑，并根据特定条件筛选数据、重命名字段后导出为包含下载链接的新Excel文件，适用于多Sheet数据探查与条件过滤导出场景。

When to use

  • 多Sheet数据探查
  • 条件过滤导出
  • 字段重命名
  • 统计关键指标
  • 生成下载链接

When not to use

  • 读取/计数/Parquet优化
