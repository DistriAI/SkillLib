ieee-transactions-on-signal-processing

separate

Use when targeting IEEE Transactions on Signal Processing or deciding whether a signal-processing methods manuscript fits this venue. Encodes the journal's fit, the algorithm-plus-analysis bar, the baseline-and-guarantee expectation, the regular-paper-vs-correspondence framing, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • fit/framing check for estimation, detection, sampling, or array/graph signal-processing manuscripts
  • re-framing methods from 'good results' to signal model, analysis, and baselines
  • choosing between this Transactions and applications-oriented SP, machine-learning, or communications venues
  • SP-theoretic framing bar and desk-reject heuristics for signal-processing methods
  • statistical signal processing: parameter estimation, detection, Cramér–Rao bounds, Bayesian/robust estimation
  • sampling, reconstruction, sparse/compressive methods, dictionary/subspace methods with recovery guarantees
  • array and sensor-array processing: beamforming, direction-of-arrival, source localization, distributed sensing
  • graph signal processing and optimization for signal processing with convergence/optimality analysis

When not to use

  • generic machine-learning papers
  • application studies that merely run an existing pipeline on new data
  • replacing the journal's current official author guidelines
