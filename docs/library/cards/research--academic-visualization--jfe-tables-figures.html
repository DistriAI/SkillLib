jfe-tables-figures

separate

Use when the exhibits of a Journal of Financial Economics (JFE) manuscript need to meet house standards — readable tables, self-contained notes, and figures that carry the argument. Handles exhibit craft; it does not decide which robustness tests to run (jfe-robustness).

When to use

  • readable tables
  • self-contained notes
  • figures that carry the argument
  • exhibit craft
  • main-text vs. Internet Appendix triage
  • reporting conventions
  • figure legibility in grayscale

When not to use

  • deciding which robustness tests to run
