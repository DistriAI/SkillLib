feishu-notify

authentic

Send notifications to Feishu/Lark. Internal utility used by other skills, or manually via /feishu-notify. Use when user says \"发飞书\", \"notify feishu\", or other skills need to send status updates.

When to use

  • Send Feishu/Lark notifications
  • Internal utility for status updates
  • Push webhook notifications
  • Interactive bidirectional approval/rejection
  • Notify on experiment done
  • Notify on review scored
  • Notify on checkpoint waiting
  • Notify on pipeline complete

When not to use

  • Blocking workflows if Feishu is unreachable
  • Requiring Feishu configuration
  • Operating when config file is absent
  • Operating when mode is off
