figma-code-connect-components

separate

Connects Figma design components to code components using Code Connect mapping tools. Use when user says "code connect", "connect this component to code", "map this component", "link component to code", "create code connect mapping", or wants to establish mappings between Figma designs and code implementations. For canvas writes via `use_figma`, use `figma-use`.

When to use

  • code connect
  • connect this component to code
  • map this component
  • link component to code
  • create code connect mapping
  • establish mappings between Figma designs and code implementations

When not to use

  • canvas writes via use_figma
  • building or updating a full-page screen in Figma from code or a description
  • implementing product code from Figma
