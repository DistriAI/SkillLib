asq-workflow

separate

Use when deciding which asq-* sub-skill to invoke next, or when sequencing manuscript work from topic selection through rebuttal for an Administrative Science Quarterly (ASQ) manuscript. Routes — it does not replace — the specialized skills.

When to use

  • Deciding which asq-* sub-skill to invoke next
  • Sequencing manuscript work from topic selection through rebuttal
  • Diagnosing the current bottleneck in a draft
  • Switching into review or rebuttal mode after a decision letter

When not to use

  • Replacing specialized asq-* skills
  • Executing specific analysis or writing tasks directly
