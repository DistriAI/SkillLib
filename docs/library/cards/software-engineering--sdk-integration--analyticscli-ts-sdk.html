analyticscli-ts-sdk

separate

Use when integrating or upgrading the AnalyticsCLI TypeScript SDK in web, TypeScript, React Native, or Expo apps.

When to use

  • adding AnalyticsCLI analytics to a JS or TS app
  • instrumenting onboarding, paywall, purchase, or survey events
  • upgrading within the current `@analyticscli/sdk` line
  • validating SDK behavior together with `analyticscli`

When not to use

  • using WRITE_KEY env names in generated host-app snippets
  • passing endpoint or adding endpoint env vars in app templates
  • using framework labels for platform
  • manually emitting duplicate session_start
  • specifying dedupeOnboardingStepViewsPerSession by default
  • specifying dedupeScreenViewsPerSession by default
  • forcing storage adapters in generated bootstrap code by default
  • keeping legacy analytics providers or event aliases active
