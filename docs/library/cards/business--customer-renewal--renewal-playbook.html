renewal-playbook

authentic

Crea un playbook de renovación estructurado para una cuenta de cliente. Úsalo cuando necesites planificar una renovación, estructurar una negociación de renovación, prepararte para una conversación de expansión, o construir una estrategia de renovación para cuentas en riesgo o saludables. Produce un brief de renovación con evaluación de salud, estrategia de negociación, respuestas a objeciones, palancas de expansión y una cronología.

When to use

  • planificar una renovación
  • estructurar una negociación de renovación
  • prepararse para una conversación de expansión
  • construir una estrategia de renovación para cuentas en riesgo
  • construir una estrategia de renovación para cuentas saludables
