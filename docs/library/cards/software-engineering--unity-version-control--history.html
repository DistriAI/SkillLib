Manage undo/redo history over the native undo stack

When to use

  • Reviewing or navigating undo history
  • Stepping undo/redo
  • Auditing what changed
  • 查看或浏览撤销历史
  • 逐步撤销/重做
  • 审查改动

When not to use

  • Persistent task-level undo
  • Conversation-level undo
  • Clearing undo history
  • Saving undo history
