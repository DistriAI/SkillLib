Skill page

Conflict

Both copies describe the same goal (connecting Claude to external apps via Composio), but they prescribe different, non-interchangeable procedures. The first copy uses a Claude Code plugin (`/plugin install composio-toolrouter` and `/composio-toolrouter:setup`) and relies on the agent to route natural-language requests. The second copy uses the Composio CLI (`curl` install, `composio login`, `composio link`, `composio execute`) and provides explicit command-line workflows, discovery, dry-runs, and environment variables. Because each copy contains material steps and constraints the other lacks, crowning one would hide a real alternative.
