jole-workflow

separate

Use when deciding which jole-* sub-skill to invoke next, or when sequencing manuscript work from topic selection through rebuttal for a Journal of Labor Economics (JOLE) submission. Routes — it does not replace — the specialized skills.

When to use

  • Deciding which jole-* sub-skill to invoke next
  • Sequencing manuscript work for a JOLE submission
  • Diagnosing the current bottleneck in a draft
  • Switching into revision mode after a decision letter

When not to use

  • Replacing specialized jole-* skills
  • Performing the actual specialized tasks of the sub-skills
