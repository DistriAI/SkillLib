cuopt-multi-objective-exploration

separate

Trace, complete, and interpret the Pareto frontier across competing objectives using repeated single-objective cuOpt solves (weighted-sum and ε-constraint).

When to use

  • balance X and Y
  • trade off
  • minimize cost and maximize coverage
  • I want options, not one answer
  • two or more objectives with no agreed-upon weighting
  • promoting constraints to parametric ε-constraints
  • sweeping ε values
  • interpreting the Pareto frontier

When not to use

  • single clear objective
  • everything else is a hard constraint
  • genuinely fixed, non-negotiable limit
  • hard budget cap
  • regulatory minimum
