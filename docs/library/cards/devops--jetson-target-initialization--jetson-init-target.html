jetson-init-target

separate

Author a new Jetson target-platform profile (reference_devkit + optional custom_carrier) and update the active pointer. Use to create a target; not for switching existing profiles.

When to use

  • create new target platform profile
  • author target platform YAML
  • add new target platform
  • bootstrap target platform configuration

When not to use

  • Owns only `reference_devkit:`, `custom_carrier:`, and the
  • Will not invent SKUs, module IDs, custom carrier metadata, or flash
