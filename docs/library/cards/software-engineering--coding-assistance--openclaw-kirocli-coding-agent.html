Run Codex CLI, Claude Code, Kiro CLI, OpenCode, or Pi Coding Agent via background process for programmatic control.

When to use

  • Run Codex CLI
  • Run Claude Code
  • Run Kiro CLI
  • Run OpenCode
  • Run Pi Coding Agent
  • Background process control
  • One-shot tasks
  • Batch PR Reviews

When not to use

  • Reviewing PRs in OpenClaw's own project folder
