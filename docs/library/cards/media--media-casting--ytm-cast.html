ytm-cast

separate

Download music from YouTube/YouTube Music and stream to Chromecast via Home Assistant. Complete CLI toolset with web server integration, configuration wizard, and playback controls.

When to use

  • download music from YouTube
  • cast music to Chromecast
  • manage local HTTP server for media
  • play downloaded MP3 or MP4 files
  • list available media players
  • stop playback on devices
  • download playlists in batch
  • create MP4 videos with album art

When not to use

  • streaming from Spotify
  • cloud-based music services
  • non-Chromecast devices
  • video streaming without audio extraction
