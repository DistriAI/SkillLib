paper-self-revise

separate

Revise an academic paper based on internal review comments. Reads review report or annotated manuscript, then applies revisions one by one with user approval. Trigger when user says "self revise" / "paper-selfrevise" / "内部修改" / "根据审稿意见修改".

When to use

  • Revise academic paper based on internal review comments
  • Apply revisions one by one with user approval
  • Draft review report if not provided
  • Process annotation comments
  • Process tracked changes in annotated manuscript

When not to use

  • Empirical tests requiring changing software code
  • Re-running regressions
  • Adding new specifications
  • Changing estimation methods
  • Running robustness checks in Stata/R/Python
  • Formatting-only comments
