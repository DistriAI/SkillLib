known-errors

separate

Use when a OpenChatCut tool call fails or returns an unexpected shape.

When to use

  • edit_item update raw shape errors
  • edit_item add raw shape errors
  • Timeline overlap errors
  • Workspace path restrictions
  • Browser video conversion failure
  • Motion Graphic requirements
  • Local dev Zero caveat
  • Timeline frame renderer caveat

When not to use

  • Forcing writes or deleting conflicting items silently
  • Asking user to re-import same file through editor UI for conversion failures
  • Using push_asset for local paths or workspace paths
  • Using push_asset for inline code arguments
