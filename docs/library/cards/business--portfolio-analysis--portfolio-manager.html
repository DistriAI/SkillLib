portfolio-manager

combined

Comprehensive portfolio analysis using Alpaca MCP Server integration to fetch holdings and positions, then analyze asset allocation, risk metrics, individual stock positions, diversification, and generate rebalancing recommendations. Use when user requests portfolio review, position analysis, risk assessment, performance evaluation, or rebalancing suggestions for their brokerage account.

When to use

  • "Analyze my portfolio"
  • "Review my current positions"
  • "What's my asset allocation?"
  • "Check my portfolio risk"
  • "Should I rebalance my portfolio?"
  • "Evaluate my holdings"
  • "Portfolio performance review"
  • "What stocks should I buy or sell?"

Conflict

The LeoYeAI copy is a bulk mirror of the tradermonty skill, but the tradermonty copy contains material operational steps the mirror lacks: a REST fallback connection check, explicit REST endpoint fallbacks for scheduled jobs, margin/leverage exposure calculations, and a position-reconciliation gate before weekly allocation review. The mirror copy, in turn, contains a detailed Step 2 (enriching positions with market, fundamental, and technical data) and a more complete Step 3 (asset allocation, diversification, and risk analysis) that the tradermonty excerpt truncates before showing. Crowning one copy would hide either the operational fallback discipline or the analytical enrichment steps, so the copies should be combined.
