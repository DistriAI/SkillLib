Conflict

The three copies overlap on the core idea that shadcn/ui is a copy-into-project component collection, but each adds material steps the others lack. The google-labs copy is the only one that documents MCP-based component discovery, registry tools, and the create/init configuration options. The jezweb copy is the only one that enforces a dependency-ordered installation sequence, documents specific runtime gotchas (Radix Select empty strings, RHF null values, Lucide tree-shaking, Dialog width breakpoints), and requires semantic token usage. The LeoYeAI copy is the only one that provides a comprehensive component category reference and a complete react-hook-form + zod form pattern. Crowning one would hide real alternatives, so the copies should be combined.
