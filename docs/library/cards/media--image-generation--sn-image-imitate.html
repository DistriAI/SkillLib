sn-image-imitate

separate

Generates a new image that imitates the style of a reference image while updating content based on user intent. Uses a three-stage pipeline: image annotation (long caption), caption rewriting, and image generation. Use when user asks to "imitate style", "保持这个风格重画", "按这张图风格生成", or "style transfer with new content".

When to use

  • style imitation
  • style transfer with new content
  • imitate this image style
  • use this style with new content
  • reference style image
  • 风格模仿
  • 风格迁移
  • 按参考图风格生成

When not to use

  • Pure neural style transfer without content change
  • Local editing / inpainting of specific regions
  • Processing video or animation input
  • Batch generation from multiple reference images
  • Guaranteeing pixel-level fidelity to the reference
