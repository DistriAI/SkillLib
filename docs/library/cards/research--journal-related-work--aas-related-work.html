aas-related-work

separate

当你在为《自动化学报》(Acta Automatica Sinica, AAS) 撰写相关工作、文献综述或确立创新性(delta)时调用。给出以差异为先的文献组织法、控制/自动化/模式识别方向代表作的覆盖策略、与最接近工作的对比表、避免"重复前人/无新意"初审退稿的自检，以及综述栏目所需的分类框架与批判性评价方法，帮助在 Acta Automatica Sinica 的中英文双语与综述长文传统下清晰界定本文相对已有研究的增量。

When to use

  • 撰写《自动化学报》相关工作
  • 撰写文献综述
  • 确立创新性(delta)
  • 控制/自动化/模式识别方向文献覆盖
  • 构建与最接近工作的对比表
  • 综述栏目分类框架与批判性评价
  • 创新性自检
  • 文献检索策略

When not to use

  • 非《自动化学报》期刊的写作规范
  • 非控制/自动化/模式识别方向的文献综述
