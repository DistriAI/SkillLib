Conflict

The three copies describe different procedures for the same skill name. Jeffallan/claude-skills is a framework-heavy enterprise workflow (Laravel/Symfony, PHPStan level 9, PHPUnit/Pest, DTOs, DI, migrations, REST/GraphQL) with explicit MUST/MUST NOT constraints and code templates. rmyndharis/antigravity-skills and sickn33/agentic-awesome-skills are nearly identical performance/idiomatic PHP guides focused on generators, SPL, memory, profiling, and built-in functions, with a preference to avoid third-party packages. These overlap in general PHP best practices but disagree on scope and constraints: one mandates framework tooling and static analysis, while the others prefer standard library and performance profiling. Crowning one would hide a real alternative.
