uai-artifact-evaluation

separate

Use when packaging code, data, samplers, solvers, and logs for a UAI submission's 50 MB supplementary ZIP or a public post-acceptance release, making probabilistic-inference claims independently runnable while keeping every file double-blind, given that UAI reviewers may open the archive but are not obliged to read it.

When to use

  • Packaging UAI supplementary ZIP
  • Preparing public post-acceptance release
  • Making probabilistic-inference claims runnable
  • Ensuring double-blind anonymity in artifacts
  • Designing artifacts for five-minute reviewer spot-checks
  • Managing data that cannot ship under size caps
  • Handling licensing for code and data

When not to use

  • Writing the main paper PDF
  • Performing the actual probabilistic inference experiments
  • Managing OpenReview submission metadata
