aas-writing-style

separate

当你在为《自动化学报》(Acta Automatica Sinica, AAS) 撰写或打磨中文稿件体例时调用。覆盖报道性中英文摘要(目的/方法/结果/结论四要素)、中英文关键词、中图分类号(自动化/计算机类 TP 打头)、参考文献 GB/T 7714 顺序编码制著录、量与单位法定计量、控制类公式与图表规范、以及综述/论文/短文三类栏目的体例差异，帮助把控制理论、模式识别、机器人、智能系统方向的中文长文写到符合 Acta Automatica Sinica 的双语传统与编排要求。

When to use

  • 撰写报道性中英文摘要
  • 规范中英文关键词与中图分类号
  • GB/T 7714 顺序编码制参考文献著录
  • 控制类公式与图表规范
  • 量与单位法定计量规范
  • 综述/论文/短文栏目体例差异
  • 英文摘要单独打磨
