portaljs-add-chart

separate

Add a chart (line, bar, area, pie, or scatter) to a dataset's showcase in a PortalJS portal. Installs recharts, writes a reusable Chart component, and renders it in the showcase Views section. Use when visualizing a dataset already registered in datasets.json.

When to use

  • Add line chart to dataset showcase
  • Add bar chart to dataset showcase
  • Add area chart to dataset showcase
  • Add pie chart to dataset showcase
  • Add scatter chart to dataset showcase
  • Visualize dataset registered in datasets.json

When not to use

  • Adding maps
  • Defining schemas
  • Adding new datasets
