icalp-submission

separate

Use when auditing an ICALP (EATCS) Track A or Track B submission for HotCRP readiness, covering the correct-track submission server, abstract registration before the full-paper deadline, the 15-page extended-abstract page budget with a clearly labelled appendix / full version, lightweight double-blind anonymity, the no-simultaneous-submission rule, and the single annual February AoE cutoff.

When to use

  • Auditing ICALP Track A or Track B submissions
  • Checking HotCRP readiness
  • Verifying correct-track submission server
  • Checking abstract registration before full-paper deadline
  • Auditing 15-page extended-abstract page budget
  • Verifying clearly labelled appendix or full version
  • Checking lightweight double-blind anonymity
  • Verifying no-simultaneous-submission rule

When not to use

  • Auditing runnable artifacts
  • Auditing non-ICALP venues
