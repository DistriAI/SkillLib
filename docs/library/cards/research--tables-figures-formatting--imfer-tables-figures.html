imfer-tables-figures

separate

Use when an IMF Economic Review (IMFER) manuscript's exhibits must communicate an international-macro result to a dual academic/policy audience — transparent country coverage, readable cross-country panels, no significance asterisks. Builds the exhibits; it does not run the robustness behind them (imfer-robustness) or write the prose (imfer-writing-style).

When to use

  • cross-country regression tables
  • country/sample coverage exhibits
  • impulse response figures
  • event-study plots
  • spillover path figures
  • heterogeneity panels
  • policy magnitude exhibits
  • summary-statistics tables

When not to use

  • running robustness checks
  • writing prose
