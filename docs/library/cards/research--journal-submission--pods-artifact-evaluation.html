pods-artifact-evaluation

separate

Use for the PODS analogue of artifact evaluation — there is no systems artifact track at this theory symposium, so this skill covers formal-claims verification instead: a complete at-submission proof appendix, a claim-to-proof mapping reviewers can check, the full-version-on-arXiv norm, and, only when a paper claims practicality, an honest optional code artifact.

  • honest optional code artifact

When not to use

  • systems artifact track
  • ACM reproducibility badges
  • systems artifact process
