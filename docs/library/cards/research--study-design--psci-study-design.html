psci-study-design

separate

Use when designing studies for a Psychological Science manuscript so they meet the journal's standards for power, sample-size justification, preregistration, and confound control. Strengthens the design and pre-analysis plan; it does not write code.

When to use

  • Planning a study or multi-study package
  • Writing a preregistration or pre-analysis plan
  • Writing a Registered Report Stage 1
  • Justifying sample size and stopping rules
  • Addressing reviewer questions on power, design, or confounds
  • Controlling researcher degrees of freedom
  • Designing multi-study logic for generalization or mechanism

When not to use

  • Writing code
  • Data analysis
