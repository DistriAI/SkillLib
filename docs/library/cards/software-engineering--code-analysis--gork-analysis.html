gork-analysis

separate

Gork data API. Uses Grok model to analyze tweet comments, extract valuable intelligence from replies, and fetch latest community sentiment on projects or topics.

When to use

  • Analyze comments on a specific tweet
  • Get latest community sentiment on a project
  • Deep dive on a topic or controversy
  • Extract insider knowledge and warnings
  • Identify sentiment signals

When not to use

  • Generic project analysis without specific context
  • Additional calls beyond max 2 per research
  • Project-level sentiment without specific tweet context
