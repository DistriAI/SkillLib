asc-id-resolver

separate

Resolve App Store Connect IDs (apps, builds, app and digital-goods versions, groups, testers) from human-friendly names using asc. Use when commands require IDs.

When to use

  • Resolve App Store Connect IDs
  • Map names to IDs
  • Resolve App IDs
  • Resolve Build IDs
  • Resolve Version IDs
  • Resolve Digital-goods version IDs
  • Resolve TestFlight IDs
  • Resolve Pre-release version IDs
