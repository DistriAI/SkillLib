cn-home-school-comms

authentic

Use when asked 怎么给老师发消息, 跟班主任沟通, 孩子在学校被欺负怎么跟老师说, 对老师的做法有意见, 请假怎么写, 家长群里怎么说话, or write a message from a parent to a teacher in China. Produces a ready-to-send WeChat or note message in Chinese, polite and specific, for the situation (asking, leave, a concern, a disagreement, bullying, thanks), a calmer version if the parent is upset, what to say if the teacher calls back, the escalation path if it is not resolved, and 家长群 etiquette.

When to use

  • Writing messages to teachers in China
  • Handling bullying or safety concerns
  • Requesting leave or information
  • Expressing disagreement with teacher actions
  • Drafting calmer versions of upset messages
  • Providing escalation paths for unresolved issues
  • Explaining 家长群 etiquette

When not to use

  • Writing messages from a teacher to parents
  • Situations where child safety is not at risk but formal procedure is not needed
