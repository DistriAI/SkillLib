chief-of-staff

combined

C-suite orchestration layer. Routes founder questions to the right advisor role(s), triggers multi-role board meetings for complex decisions, synthesizes outputs, and tracks decisions. Every C-suite interaction starts here. Loads company context automatically. Pursue a long-running goal in a single session by co-ordinating subagents.

When to use

  • Routing founder questions to C-suite roles
  • Triggering multi-role board meetings
  • Synthesizing advisor outputs
  • Tracking decisions in a log
  • Scoring decision complexity
  • Coordinating subagents for long-running goals

When not to use

  • Invoking itself
  • Exceeding maximum depth of 2
  • Circular invocations between roles

Skill page

Conflict

The two copies use the same name but define different procedures. The first is a single-session, long-running goal coordinator that emphasizes subagent context protection, schedules, and environment improvement (pit of success, no workarounds). The second is a C-suite routing/orchestration layer that scores decision complexity, routes to specific advisor roles, runs board meetings, synthesizes outputs, and maintains a decision log. Neither is a reproduction of the other; each contains material steps and constraints the other lacks, so crowning one would hide a real alternative.
