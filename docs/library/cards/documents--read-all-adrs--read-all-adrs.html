read-all-adrs

combined

Read every ADR markdown file in the project's docs/adr/ folder so you have full context on past decisions. Use only when the user explicitly calls it. Read every ADR in a project before summarizing architectural context or decisions.

When to use

  • Use when the user explicitly asks to load ADR context.
  • Use when architectural decisions must be understood before changing or judging a project.

When not to use

  • Adapted from `davidondrej/skills`; verify local paths, tools, credentials, and agent features before acting.
  • For commands, remote access, scheduling, browser automation, or file-changing workflows, get explicit user approval and confirm the target environment first.

Skill page

Conflict

The first copy is a blunt, path-specific instruction to read every file in docs/adr/. The second copy is a broader, safer procedure that discovers the ADR location, inventories files, reports unread/missing records, and summarizes decision metadata. The second copy adds material steps and constraints the first lacks, while the first is the blunt source the second adapts. Crowning one would hide the safer, more complete alternative.
