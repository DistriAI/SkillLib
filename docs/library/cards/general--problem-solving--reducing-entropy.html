reducing-entropy

authentic

Manual-only skill for minimizing total codebase size. Only activate when explicitly requested by user. Measures success by final code amount, not effort. Bias toward deletion.

When to use

  • minimizing total codebase size
  • deleting obsolete code
  • evaluating net code reduction
  • reducing code entropy

When not to use

  • codebases already minimal for their function
  • frameworks with strong conventions
  • regulatory or compliance mandated structures
