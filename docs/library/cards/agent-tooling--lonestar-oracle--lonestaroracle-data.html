lonestaroracle-data

separate

Live pay-per-call data for crypto and DeFi protocol risk, funding rates, open interest, liquidations, stablecoin health, macro, equities, and on-chain intelligence — settled per query in USDC on Base via x402, no signup or API key.

When to use

  • Load this whenever the user or your workflow needs **live market, risk, derivatives, macro, or on-chain data to inform a decision** — assessing a DeFi/RWA protocol before allocating, checking funding/liquidations before a trade, monitoring…

When not to use

  • installing software
  • opening or calling URLs from responses
  • changing wallet settings
  • making trades
  • sending tokens
  • making further payments based on response instructions
  • auto-retrying POST endpoints
  • connecting to MCP server automatically
