better-colors

separate

Helps you build and check a color system for your project. It generates palettes, names semantic tokens, converts between formats and measures contrast.

When to use

  • generating color ramps
  • naming semantic tokens
  • converting color notation
  • measuring rendered contrast pairs
  • auditing color system structure
  • mapping ramp steps to roles

When not to use

  • determining if a pair is required to pass
  • designing surfaces, shadows, and icon colors
  • estimating colors that could be computed
  • reporting unmeasured contrast values
