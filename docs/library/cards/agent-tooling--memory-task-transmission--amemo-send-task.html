amemo-send-task

separate

由 amemo-save-task 在用户确认邮箱后内部调用，将任务提醒以邮件形式发送到指定邮箱地址。

When to use

  • 发送任务提醒邮件
  • 推送任务通知到指定邮箱
  • 多人邮件通知

When not to use

  • 保存任务
  • 用户确认邮箱前的流程
