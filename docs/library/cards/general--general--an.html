separate

Open and operate Agent-Native workspace apps through Dispatch MCP, with inline app surfaces, browser-session authentication, and current screen state.

When to use

  • Open Agent-Native apps
  • Operate apps via Dispatch MCP
  • Use inline app surfaces
  • Manage browser-session authentication
  • View current screen state
  • Author content using app tools
  • Handle app failures

When not to use

  • Invent URLs
  • Use localhost URLs
  • Route around Dispatch grant
  • Hand off authoring to app agent
  • Wait on in-app question forms
  • Request, copy, or store passwords
  • Guess tool names
  • Guess ids from title or index
