discover

combined

Discover AI agents, MCP servers, and configurations on this machine or environment. Use when: "find agents", "what's configured", "doctor", "what MCP servers", "show me what's installed", "mcp inventory". Discovery phase combining research interviews, literature search, data discovery, and ideation. Routes to appropriate agents based on arguments. Replaces /interview-me, /lit-review, /find-data, /research-ideation.

When to use

  • "find agents" / "what agents are configured"
  • "what MCP servers do I have"
  • "what's configured on this machine"
  • "mcp inventory"
  • "doctor" / "check my setup"
  • "show me what's installed"

When not to use

  • modifying files
  • installing packages
  • extracting env var values

Skill page

Conflict

The two copies use the same skill name for completely different tasks. The first is a local CLI-based discovery tool that inventories AI agents and MCP server configurations on a machine. The second is a research workflow that routes to interview, literature review, data discovery, or ideation agents. They share no steps, constraints, or outputs, so crowning one would hide a real alternative.
