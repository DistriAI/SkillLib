demo-clip-storyboard

authentic

Use when asked to plan a short demo video for a repo, script a 20-second clip, storyboard a GIF for a README or launch post, or make a project look good on X or LinkedIn. Produces the script for the 20-second video that sells a repo: a shot list with a timestamp per shot, on-screen text, exactly what to record, the hook in the first two seconds, and post copy for X and LinkedIn. For a live product demo to an audience, use demo-script; for cutting clips from a long recording, use clip-factory.

When to use

  • plan a short demo video for a repo
  • script a 20-second clip
  • storyboard a GIF for a README
  • storyboard a GIF for a launch post
  • make a project look good on X
  • make a project look good on LinkedIn
  • produce a script for a 20-second video
  • create a shot list with timestamps

When not to use

  • live product demo to an audience
  • cutting clips from a long recording
