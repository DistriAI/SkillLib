ieee-infocom

separate

Use when targeting IEEE INFOCOM (INFOCOM) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for networking.

When to use

  • targeting IEEE INFOCOM
  • deciding if a manuscript fits INFOCOM
  • conference-fit read for computer communications
  • re-framing journal or arXiv style into conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • assessing desk-reject risks for networking papers

When not to use

  • substitute for current year's CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
  • routing systems-heavy networking to SIGCOMM/CoNEXT/NSDI
  • routing European systems artifacts to EuroSys
  • routing security/privacy networking to NDSS/WiSec
