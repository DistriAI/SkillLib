clinical-nlp-extractor

separate

Extracts medical entities (Diseases, Medications, Procedures) from unstructured clinical text using regex and simple rules or LLM wrappers. Converts free-text clinical notes into structured data compatible with FHIR/USDL.

When to use

  • When analyzing unstructured EHR notes.
  • To populate a patient's problem list or medication reconciliation.
  • To de-identify text (phi-removal) - *Basic version*.
