aejmic-tables-figures

separate

Use when presenting results for an American Economic Journal: Microeconomics (AEJ: Micro) manuscript — propositions, numerical examples, schematic theory figures, and empirical/experimental tables. Builds exhibits to AEA house norms; it does not derive the results (see aejmic-theory-model).

When to use

  • Presenting propositions, characterizations, and numerical examples
  • Creating schematic theory figures like timelines and type spaces
  • Formatting applied or experimental tables
  • Making formal results legible and concrete
  • Generating exhibits from fitted results

When not to use

  • Deriving the results
  • Using aejmic-theory-model
