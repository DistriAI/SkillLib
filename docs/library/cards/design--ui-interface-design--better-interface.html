Combines all of the `better-*` skills into a single review across accessibility, layout, writing, typography, color and UI polish.

When to use

  • Cross-discipline interface review
  • Accessibility review
  • Layout review
  • Writing review
  • Typography review
  • Color review
  • UI polish review
  • Consolidated ranked verdict

When not to use

  • Change-scoped review of uncommitted work
  • Branch reviews
  • Pull request reviews
  • Commit range reviews
  • Resolving change scope
