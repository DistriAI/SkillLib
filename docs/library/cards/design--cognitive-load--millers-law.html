millers-law

separate

Apply Miller's Law — chunk information into groups of about four to fit working memory. Use when grouping fields, menu items, or steps. For reducing the number of choices offered, use `hicks-law`.

When to use

  • grouping fields
  • grouping menu items
  • grouping steps
  • navigation grouping
  • form sectioning
  • data table visual grouping
  • onboarding step phasing
  • feature list chunking

When not to use

  • reducing the number of choices offered
  • applying to visual elements like colors and icons
  • justifying navigation menus of exactly 7 items
