migrate-webapi-selectall

separate

Reviews and migrates deprecated wildcard (*) values in Power Pages Web API fields site settings to least-privilege explicit Dataverse columns. Use whenever a user mentions Web API wildcard or select-all remediation, fields settings containing *, data-exposure review, wildcard deprecation readiness, or Web API failures after wildcard retirement. Applies to both traditional sites using HTML, CSS, JavaScript, Liquid, and downloaded YAML, and SPA sites using React, Vue, Angular, Astro, or TypeScript. The agent must inspect every source Web API call and consumer, report exact fixes for every wildcard, report every already-explicit configuration, apply approved edits, and verify no wildcard remains.

When to use

  • Web API wildcard remediation
  • select-all remediation
  • fields settings containing *
  • data-exposure review
  • wildcard deprecation readiness
  • Web API failures after wildcard retirement
  • traditional sites using HTML, CSS, JavaScript, Liquid, and downloaded YAML
  • SPA sites using React, Vue, Angular, Astro, or TypeScript

When not to use

  • creating or selecting another solution
  • issuing POST, PATCH, PUT, or DELETE Web API calls against a deployed site
  • downloading or uploading site content without explicit user confirmation
