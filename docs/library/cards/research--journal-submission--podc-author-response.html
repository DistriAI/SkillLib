podc-author-response

separate

Use when writing an ACM PODC rebuttal/author response, if the cycle runs one — covering how to correct a proof misreading, supply a missing lemma or bound within the anonymity envelope, prioritize soundness questions over taste, and behave correctly given that PODC has no revision round to fall back on.

When to use

  • Writing an ACM PODC rebuttal
  • Correcting a proof misreading
  • Supplying a missing lemma or bound
  • Prioritizing soundness questions over taste
  • Answering reviewer questions on correctness and model assumptions
  • Maintaining double-blind anonymity in the response

When not to use

  • Arguing taste or significance
  • Adding a new result
  • Contesting a real proof gap
  • Planning a rebuttal if the cycle does not have one
  • De-anonymizing in the response text or links
