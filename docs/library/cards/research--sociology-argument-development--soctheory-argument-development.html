soctheory-argument-development

separate

Use when stress-testing the reasoning of a Sociological Theory (ST) manuscript — turning stated propositions into a valid, warranted argument that survives rival theories and counter-cases. Develops and audits the argument; it does NOT define the concepts (soctheory-theory-construction) or bound the theory's domain (soctheory-boundary-conditions).

When to use

  • stress-testing reasoning of ST manuscripts
  • turning propositions into valid warranted arguments
  • auditing argument validity
  • checking premises and inferences
  • stating warrants for claims
  • engaging rival theories
  • constructing counter-cases or hard cases
  • applying Toulmin model to propositions

When not to use

  • defining concepts
  • bounding the theory's domain
  • empirical testing
  • using data to settle theoretical disputes
