ssi-submission

separate

当需要按《中国科学：信息科学》(Scientia Sinica Informationis, SSI) 的要求对一篇中文稿件做投稿前完整审计时调用。覆盖官网作者账户注册与 PDF 上传、LaTeX 官方模板排版、栏目自选（评述/论文/快报/学术介绍）、中英文双语摘要与关键词、参考文献与中图分类号、基金著录、版面费与样刊、伦理与学术规范（一稿多投与中英文姊妹刊 Science China Information Sciences 择一投稿），以及退稿/退修高风险项的排查。适用于投稿前最后一轮把关。

When to use

  • SSI 投稿前完整审计
  • 官网作者账户注册与 PDF 上传检查
  • LaTeX 官方模板排版验证
  • 栏目自选匹配度检查
  • 中英文双语摘要与关键词审计
  • 参考文献与中图分类号核查
  • 基金著录与单位信息核对
  • 伦理与学术规范风险排查

When not to use

  • 稿件正文写作与打磨
  • 栏目选择与改投决策
  • 信源与待核实清单管理
