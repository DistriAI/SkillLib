itcs-writing-style

separate

Use when drafting or revising an ITCS paper's abstract, introduction, and technical presentation so the conceptual innovation lands before any theorem, the model is motivated as a lens rather than a tweak, scope and limitations are owned up front, and complete proofs are deferred cleanly — matching the ITCS emphasis on new ideas over technical depth.
