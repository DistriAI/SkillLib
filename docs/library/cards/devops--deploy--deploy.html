Skill page

Conflict

The three copies are unrelated procedures that share only the generic name 'deploy'. The Azure skill executes IaC against Azure with preflight sub-agents, approval gates, and health checks. The Power Platform skill builds and pushes a code app to Power Platform. The research skill renders Quarto slides and syncs them to docs/ for GitHub Pages. None is a reproduction of the others, so crowning one would hide real alternatives.
