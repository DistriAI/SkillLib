wjttc-builder

authentic

PLAN and GENERATE WJTTC (Championship-Grade) test suites for any project. Analyzes the codebase, classifies components across the WJTTC five tiers (Brake · Engine · Aero · Tyre · Pit), writes a tiered test plan, and scaffolds executable test files.

When to use

  • AFTER defining project.faf context
  • BEFORE writing any implementation code
  • When starting a new feature (define tests first)
  • When fixing a bug (write failing test first)
  • Building regression test suites

When not to use

  • Verify commands, generated code, dependencies, credentials, and external service behavior before applying changes.
  • Do not treat examples as a substitute for environment-specific tests, security review, or user approval for destructive or costly actions.
