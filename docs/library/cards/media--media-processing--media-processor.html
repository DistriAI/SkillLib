media-processor

separate

影片与视频编辑及自媒体创作者在处理多媒体素材时，当需批量转换音视频或图像格式、调整分辨率及压缩文件时必用。一键调用底层工具自动完成转换与压缩，高效输出符合预期的媒体文件，大幅节省手动处理时间。

When to use

  • 视频格式转换
  • 视频分辨率调整和压缩
  • 图像格式转换
  • 图像分辨率调整和压缩
  • 批量处理视频或图像文件
