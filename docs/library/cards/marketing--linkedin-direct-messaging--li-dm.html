li-dm

separate

Write connection notes and DM follow-ups that get replies - the 200-character invite, the first message, and the two follow-ups. Use when the user says "write a connection request", "DM this person", "outreach message", "how do I follow up", or is reaching out to someone specific on LinkedIn.

When to use

  • write a connection request
  • DM this person
  • outreach message
  • how do I follow up
  • reaching out to someone specific on LinkedIn

When not to use

  • automated connection or message sequence
  • fabricate a mutual connection
  • fabricate a shared school
  • fabricate having read something the user has not read
  • send more than 20 invites a day
