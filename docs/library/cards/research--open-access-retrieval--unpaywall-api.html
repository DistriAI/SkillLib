unpaywall-api

authentic

Find free legal full-text versions of scholarly articles via Unpaywall

When to use

  • Find open access copies of papers
  • Assess OA status of publications
  • Integrate OA discovery into workflows
  • Check OA status for a reading list
  • Find the best available PDF
  • Audit Open Access Compliance for a Grant

When not to use

  • Commercial use
  • Higher rate limits
  • Analyses requiring more than 100K lookups
