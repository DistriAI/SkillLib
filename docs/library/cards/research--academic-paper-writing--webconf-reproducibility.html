webconf-reproducibility

separate

Use when hardening the reproducibility of a Web Conference (WWW) paper whose evidence rests on crawls, platform APIs, live systems, or user logs — covering dataset decay, temporal snapshots, seed and environment reporting, the reproducibility appendix inside the 12-page PDF, and honest claims when the Web itself cannot be replayed.

When to use

  • Hardening reproducibility of WWW papers
  • Managing dataset decay and temporal snapshots
  • Reporting seeds and environment details
  • Structuring the reproducibility appendix
  • Classifying reproducibility regimes
  • Pinning decaying evidence
  • Conducting determinism audits
  • Ensuring temporal honesty in splits

When not to use

  • Offline-ML venue reproducibility
  • Tasks not involving Web Conference papers
