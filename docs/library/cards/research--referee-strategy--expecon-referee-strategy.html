expecon-referee-strategy

separate

Use when anticipating the experimentalist referee's objections for an Experimental Economics (ExpEcon) manuscript before submission. Pre-empts the standard pushbacks; it does not draft the response letter (see expecon-rebuttal).

When to use

  • Anticipating experimentalist referee objections
  • Pre-empting standard pushbacks
  • Disarming weak points before submission
  • Deciding what to add now vs. defend later
  • Reading draft as editors and referees
  • Addressing design integrity concerns
  • Handling demand and experimenter effects
  • Conducting pre-submission self-review

When not to use

  • Drafting the response letter
