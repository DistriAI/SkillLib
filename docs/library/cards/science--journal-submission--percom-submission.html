When to use

  • checking HotCRP readiness
  • verifying IEEEtran 9+1 page budget
  • checking double-blind anonymization
  • reviewing open-data and human-subjects plans
  • triaging desk-reject risks

When not to use

  • WiP/demo/industry/workshop deadlines
  • ACM acmart formatting
