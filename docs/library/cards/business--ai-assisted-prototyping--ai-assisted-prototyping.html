ai-assisted-prototyping

separate

Help users build functional product prototypes from natural language or visual mocks using AI coding tools. This skill enables product leaders to bypass engineering bottlenecks and validate ideas through hands-on building.

When to use

  • building functional product prototypes
  • transforming abstract product concepts into interactive software
  • validating ideas through hands-on building
  • generating initial versions from descriptions or screenshots
  • refining prototypes through sequential feedback
  • gathering user feedback from interactive prototypes
  • providing high-fidelity reference code for engineering

When not to use

  • writing PRDs
  • shipping velocity optimization
  • building with AI agents
  • general product tool stack management
