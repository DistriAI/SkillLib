poq-workflow

separate

Use as the entry point for any Public Opinion Quarterly (POQ) manuscript. Routes to the right POQ sub-skill based on where you are in the lifecycle and which submission type (Original Article, Research Note, Polls in Context, Research Synthesis, Book Review) fits. It dispatches; it does not draft content.

When to use

  • Starting a new POQ paper
  • Deciding which submission type fits
  • Routing mid-project to the next skill
  • Handling decision letters
  • Framing measurement and opinion contributions
  • Ensuring AAPOR-standard disclosure

When not to use

  • Drafting content
  • Treating POQ like a generic social-science venue
  • Padding Research Notes or Polls in Context toward Article length
  • Skipping the replication package until acceptance
