amr-writing-style

separate

Use when polishing the prose and structure of an Academy of Management Review (AMR) manuscript to AOM house style and an argument-driven voice. Late-stage polish; it does NOT build theory or check logic — do those first with amr-theory-development and amr-data-analysis.

When to use

  • polishing prose and structure
  • applying AOM house style
  • ensuring argument-driven voice
  • checking structural conventions
  • verifying construct label consistency
  • signposting logic
  • formatting propositions
  • applying AOM style mechanics

When not to use

  • building theory
  • checking logic
  • data analysis
  • submission-stage facts
  • methods or results sections
