bio-atac-seq-nucleosome-positioning

separate

Extract nucleosome positions from ATAC-seq data using NucleoATAC, ATACseqQC, and fragment analysis. Use when analyzing chromatin organization, identifying nucleosome-free regions at promoters, or characterizing nucleosome occupancy patterns from ATAC-seq fragment size distributions.

When to use

  • analyzing chromatin organization
  • identifying nucleosome-free regions at promoters
  • characterizing nucleosome occupancy patterns
  • mapping nucleosome positions from ATAC-seq
  • separating nucleosome-free and mono-nucleosome fragments
  • calling nucleosome center positions
  • calculating occupancy scores
  • visualizing fragment size distribution
