file-tree

separate

Manually-invoked skill that prints a nice file tree of the current topic in a code block. Use when the user says "file-tree" or "file tree".

When to use

  • printing a file tree
  • showing high-level structure
  • displaying main files and subfolders

When not to use

  • showing all files when there are too many
  • overwhelming the user with details
