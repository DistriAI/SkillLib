icra-workflow

separate

Use when planning an ICRA submission calendar end to end — the September paper deadline, the two video-attachment windows, winter review silence, late-January notification, March camera-ready, and the May/June conference — or when interleaving a fallback RA-L or IROS plan around the single annual ICRA shot.

When to use

  • planning an ICRA submission calendar
  • managing video-attachment windows
  • interleaving a fallback RA-L or IROS plan
  • backward planning from the September deadline
  • spending the winter review silence
  • preventing failure modes like video afterthoughts
  • verifying dates against the current year-site

When not to use

  • writing the actual paper content
  • conducting experiments
  • submitting to non-robotics conferences
