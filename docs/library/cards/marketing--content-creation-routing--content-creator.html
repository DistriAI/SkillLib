Skill page

Conflict

The two copies describe fundamentally different procedures for the same skill name. The first copy is a full execution skill that instructs the agent to draft content, run local Python scripts for brand voice and SEO diagnostics, and follow specific templates. The second copy is a deprecated redirect skill that explicitly forbids handling the request directly and instead routes the user to other specialist skills (content-production, content-strategy, social-content). Because one copy performs the work and the other refuses to perform the work in favor of routing, crowning one as authentic would hide a real alternative implementation (the redirect pattern).
