jmgmt-contribution-framing

separate

Use when turning results into an explicit theoretical contribution for a Journal of Management (JOM) manuscript — the "what new theory do we learn?" statement and the discussion section. Frames the contribution; it does not build the original theory (jmgmt-theory-development) or run the analysis (jmgmt-data-analysis).
