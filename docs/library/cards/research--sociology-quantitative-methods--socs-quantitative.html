socs-quantitative

separate

Use for the quantitative path in 《社会学研究》 (Sociological Studies) — analyzing survey data (CGSS/CFPS/CLDS) with regression / Logit / multilevel / event-history (survival) / sequence analysis, and interpreting results as a sociological mechanism rather than entering an econometric identification arms race. Use when the draft only reports coefficients.

When to use

  • analyzing CGSS/CFPS/CLDS survey data
  • regression and Logit analysis
  • multilevel and event-history analysis
  • sequence analysis
  • interpreting coefficients as sociological mechanisms
  • structural heterogeneity analysis
  • operationalizing variables for sociological constructs

When not to use

  • econometric identification arms race
  • qualitative or conceptual construction
  • policy recommendation without structural meaning
  • reporting only coefficients and significance
