Use when you have a written implementation plan to execute in a separate session with review checkpoints Execute a written plan with discipline — verify each step before advancing, surface deviations instead of improvising around them, and keep a visible execution log. Skill page

Conflict

The four copies describe the same high-level task (execute a written plan with verification and logging) but disagree on the core execution model. obra/superpowers mandates continuous inline execution with a ledger and a single final review; mohitagw15856 mandates a visible execution log with a three-tier divergence classification and a plan-feedback note; sickn33 and LeoYeAI mandate batch execution with review checkpoints between batches. Because these are mutually exclusive workflows (continuous vs batched, ledger vs execution log, final review vs per-batch review), crowning one would hide real alternatives.
