Skill page

Conflict

The copies describe two different execution models. obra/superpowers is an inline, continuous-execution skill with a ledger, TDD gates, and a single final review. The other three copies (sickn33, LeoYeAI, FreedomIntelligence) are a batched, checkpoint-driven skill that pauses for review between batches. They overlap in the high-level goal (execute a written plan) but disagree on batching, stopping behavior, and required sub-skills, so crowning one would hide a real alternative.
