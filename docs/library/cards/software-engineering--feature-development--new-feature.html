new-feature

separate

Isolate repository edits in a Git worktree before starting a feature, fix, or documentation change. Preserve a worktree already assigned to the same task. Read-only reviews and investigations do not need a new worktree.

When to use

  • feature development
  • bug fixes
  • documentation changes
  • isolating repository edits
  • creating Git worktrees

When not to use

  • read-only reviews
  • investigations
  • building on main
  • reusing another task's work
