chi-author-response

separate

Use when an ACM CHI paper receives a revise-and-resubmit invitation and the five-week window opens — planning the revision triage, making tracked changes reviewers can audit, and writing the response letter that carries the paper through round 2 and the PC meeting.

When to use

  • planning revision triage
  • making tracked changes
  • writing the response letter
  • sorting reviewer criticisms
  • generating tracked-changes PDF
  • checking length norms
  • verifying anonymization

When not to use

  • short rebuttal in a text box
  • fresh submission
  • changing core claims without flagging
  • swapping the method story
  • adding an entirely new study
