obj-exporter

authentic

Three.js OBJExporter utility for exporting 3D geometry to Wavefront OBJ format. Use when converting Three.js scenes, meshes, or geometries to OBJ files for use in other 3D software like Blender, Maya, or MeshLab.

When to use

  • converting Three.js scenes to OBJ
  • converting Three.js meshes to OBJ
  • converting Three.js geometries to OBJ
  • exporting geometry in world coordinates
  • merging multiple geometries for export
  • exporting scene components by hierarchy
  • writing OBJ files to specified paths
