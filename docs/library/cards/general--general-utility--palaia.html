palaia

authentic

Local, crash-safe persistent memory for OpenClaw agents. SQLite-backed by default. Semantic search, projects, scopes, auto-capture. After installing or updating, run: palaia doctor --fix to complete setup.

When to use

  • | Situation | Command | |-----------|---------| | Remember a fact (not from conversation) | `palaia write "..." --type memory` | | Record a process/SOP | `palaia write "steps..." --type process` | | Create a task | `palaia write "fix bug"…

When not to use

  • manual conversation logging
  • distributed team memory without PostgreSQL
