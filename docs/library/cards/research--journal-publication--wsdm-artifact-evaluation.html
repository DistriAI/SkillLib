  • Handling proprietary-log dilemmas in web-scale research
  • Selecting public-benchmark substitution tiers
  • Using WSDM Cup datasets
  • Defining credible artifact release without formal badges
  • Managing model and prompt artifacts
  • Converting anonymous mirrors to citable artifacts post-acceptance

When not to use

  • Formal artifact-evaluation track or badge system processes
