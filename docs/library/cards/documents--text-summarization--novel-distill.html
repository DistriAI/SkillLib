novel-distill

separate

从用户提供的小说章节中提炼适合短视频的关键事件，核对情节依据，比较候选场面并转译成分镜与视频制作简报。适用于小说高光、角色宣传和小说预告片策划。

When to use

  • 小说高光提炼
  • 角色宣传策划
  • 小说预告片策划
  • 短视频分镜设计
  • 视频制作简报生成

When not to use

  • 模型训练
  • 视频生成
  • 流量预测
  • 无小说文本时宣称提取情节
  • 自动授权生成、上传或发布
