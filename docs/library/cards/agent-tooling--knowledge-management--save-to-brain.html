save-to-brain

separate

Shared step of the marketing playbooks (research-market, plan-campaign, make-content, analyze-performance): saves a finished file to the brand and makes it searchable. It either replaces older versions or keeps dated history, then checks that the file can be found. Loaded by those playbooks; not for direct use.

When to use

  • saving finished files to brand
  • making files searchable
  • replacing older versions
  • keeping dated history
  • verifying file searchability

When not to use

  • direct use
  • keeping only copy in chat
  • keeping only copy on local disk
  • telling marketer about workspaces
  • telling marketer about documents
  • telling marketer about imports
