aaag-tables-figures

separate

Use when building maps, figures, and tables for an Annals of the American Association of Geographers manuscript. The Annals has a dedicated Cartography Editor and Graphics Guidelines; maps are held to cartographic standards, not just plotted. Improves exhibits; it does not run the analysis.

When to use

  • Designing or revising maps
  • Creating remote-sensing figures
  • Building model plots
  • Formatting tables
  • Trimming exhibits to fit word cap
  • Fixing map projection or classification issues
  • Improving exhibit legibility

When not to use

  • Running the analysis
