bio-clip-seq-clip-preprocessing

separate

Preprocess CLIP-seq data including adapter trimming, UMI extraction, and PCR duplicate removal. Use when preparing raw CLIP, iCLIP, or eCLIP reads for peak calling.

When to use

  • adapter trimming
  • UMI extraction
  • PCR duplicate removal
  • preparing raw CLIP reads
  • preparing iCLIP reads
  • preparing eCLIP reads
  • two-pass trimming for eCLIP
  • CLIP-seq quality control

When not to use

  • peak calling
  • aligning reads
