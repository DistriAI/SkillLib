build-design

separate

Builds UI from a Figma file or a design image so it matches the design, using your project's existing tokens and components.

When to use

  • Building UI from Figma files
  • Building UI from design images
  • Mapping design values to project tokens
  • Implementing design frames and breakpoints
  • Comparing build against design screenshots

When not to use

  • Reviewing finished work
  • Exploring design alternatives
  • Stress testing components
  • Defining domain rules
  • Designing states not shown in the file
