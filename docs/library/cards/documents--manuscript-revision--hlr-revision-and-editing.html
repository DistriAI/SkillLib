hlr-revision-and-editing

separate

Use when working through the Harvard Law Review (HLR) post-acceptance editing cycle — successive substantive and technical edit rounds, responding to editor markups, and page proofs to publication. Drives the edit cycle to completion; it does not manage the offer/expedite phase (hlr-placement-strategy) or the first editor handshake (hlr-student-editor-review).
