reference-verify

separate

Verify references in an academic paper: check whether each BibTeX entry is real, whether in-text citations match the cited paper's actual content, and produce a structured verification report. Use when user says \"验证参考文献\", \"ref verify\", \"check references\", \"核实引用\", \"引用是否正确\", or wants to audit citations in a LaTeX manuscript.

When to use

  • Confirms the BibTeX entry describes a **real, published paper** (not hallucinated).
  • Locates **every place** the reference is cited in the manuscript.
  • Extracts the **claim or viewpoint** the author attributes to that reference.
  • Judges whether the cited paper's **actual content supports** the attributed claim.
  • Produces a structured **verification report** as a LaTeX table and a Markdown summary.
