jel-classification-system

separate

Use when assigning JEL classification codes to a Journal of Economic Literature (JEL) survey and relating the survey to the JEL code taxonomy that the journal itself maintains. Explains and applies the codes correctly; it does not write prose (jel-writing-style) or run the submission preflight (jel-submission).

When to use

  • assigning JEL classification codes
  • relating survey to JEL code taxonomy
  • determining code level and order
  • mapping survey scope to JEL taxonomy
  • reasoning about JEL category placement

When not to use

  • writing prose
  • running submission preflight
