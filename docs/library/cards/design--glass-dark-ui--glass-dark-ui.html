glass-dark-ui

separate

Build dark-mode glassmorphism interfaces with readable contrast, frosted surfaces, and gradient borders using a pseudo-element mask. Use when asked for glass cards, frosted dark hero sections, blur panels, or dark UI systems with gradient/glow borders.

When to use

  • glass cards
  • frosted dark hero sections
  • blur panels
  • dark UI systems with gradient/glow borders
  • dark glass hero section with glowing border cards
  • convert bright UI to dark glassmorphism
  • add border gradient glow to frosted navbar/card/modal
  • dark dashboard with glass panels and subtle depth
