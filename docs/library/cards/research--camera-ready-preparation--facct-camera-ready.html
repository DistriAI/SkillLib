facct-camera-ready

separate

Use when preparing an accepted ACM FAccT paper for camera-ready — de-anonymizing and adding the withheld Positionality/Acknowledgements statements, switching to the acmart sigconf proceedings format, ACM metadata (DOI, ORCID, CCS concepts, rights), the two-round camera-ready calendar for Accept vs Revise papers, ACM Open Access, finalizing datasheets/model cards, and integrating required changes without scope creep.

When to use

  • de-anonymizing accepted FAccT papers
  • adding Positionality and Acknowledgements statements
  • switching to acmart sigconf proceedings format
  • completing ACM metadata (DOI, ORCID, CCS concepts)
  • managing two-round camera-ready calendars
  • finalizing datasheets and model cards
  • integrating required reviewer changes

When not to use

  • tasks not stated in the skill text
