expo-examples

authentic

Expo's official example projects - the expo/examples repo of ~70 `with-*` integrations (Stripe, Clerk, Supabase, OpenAI, maps, Reanimated, SQLite, Skia, NativeWind, and more). Use when integrating a third-party library or service into an existing Expo app and you want the canonical, version-matched pattern to adapt, or when scaffolding a new project from one with `npx create-expo --example`.

When to use

  • integrating a third-party library or service into an existing Expo app
  • scaffolding a new project from an example
  • finding the canonical integration pattern
  • adapting example code to an existing project
  • checking for deprecated or renamed examples

When not to use

  • lifting an application architecture from examples
  • overwriting existing user project setup
  • copying pinned dependency versions from examples
