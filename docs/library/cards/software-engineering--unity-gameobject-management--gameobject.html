gameobject

separate

Create and manipulate GameObjects

When to use

  • Building or restructuring scene hierarchy
  • Spawning or removing objects
  • Adjusting transforms
  • Duplicating objects
  • Renaming objects
  • Setting active state
  • Setting parent
  • Setting layer or tag

When not to use

  • Adding components
  • Modifying materials or colours
  • Searching objects via scene_find_objects
