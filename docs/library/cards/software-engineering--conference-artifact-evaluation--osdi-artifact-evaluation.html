osdi-artifact-evaluation

separate

Use when preparing an OSDI artifact for sysartifacts-run evaluation — the post-acceptance timeline, the 2026 narrowing to a single Artifacts Available badge, Zenodo-grade permanent archiving, the AE-committee runbook, and the two-page Artifact Appendix that documents the result.

When to use

  • Preparing OSDI artifact for sysartifacts-run evaluation
  • Managing post-acceptance artifact submission timeline
  • Handling 2026 Artifacts Available badge requirements
  • Setting up Zenodo-grade permanent archiving
  • Following AE-committee runbook
  • Documenting results in two-page Artifact Appendix
  • Packaging system for artifact evaluation committee
  • Creating artifact anatomy with claims map

When not to use

  • Evaluating artifacts for non-OSDI conferences
  • Preparing artifacts for pre-acceptance submission
  • Optimizing for Artifacts Functional or Results Reproduced badges in 2026
