api-docs-writer

authentic

Escribe documentación clara y orientada a desarrolladores. Úsalo cuando se te pida documentar un endpoint de API, escribir docs de referencia de API, crear una guía de desarrollador, o convertir una especificación cruda o colección Postman en documentación. Produce documentación de endpoint con descripciones, parámetros, ejemplos de request/response y códigos de error.

When to use

  • documentar un endpoint de API
  • escribir docs de referencia de API
  • crear una guía de desarrollador
  • convertir una especificación cruda en documentación
  • convertir una colección Postman en documentación

When not to use

  • producir OpenAPI YAML
