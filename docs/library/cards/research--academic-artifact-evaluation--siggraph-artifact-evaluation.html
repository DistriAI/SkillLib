siggraph-artifact-evaluation

separate

Use when pursuing the Graphics Replicability Stamp (GRSI) or Code Replicability in Computer Graphics (CRCG) recognition for an accepted SIGGRAPH / TOG paper, covering how graphics replicability differs from ACM artifact badging, what volunteers actually run, deterministic result reproduction, Software Heritage archiving, and the separate post-acceptance timing.

When to use

  • pursuing Graphics Replicability Stamp (GRSI)
  • pursuing Code Replicability in Computer Graphics (CRCG)
  • accepted SIGGRAPH / TOG paper recognition
  • graphics replicability vs ACM artifact badging
  • deterministic result reproduction
  • Software Heritage archiving
  • post-acceptance timing

When not to use

  • ACM Artifact Review and Badging scheme
  • SIGSOFT artifact evaluation
  • systems venue artifact evaluation
  • pre-acceptance review
  • camera-ready deadline compliance
