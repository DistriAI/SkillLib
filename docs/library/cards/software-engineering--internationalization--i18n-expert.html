i18n-expert

separate

This skill should be used when setting up, auditing, or enforcing internationalization/localization in UI codebases (React/TS, i18next or similar, JSON locales), including installing/configuring the i18n framework, replacing hard-coded strings, ensuring en-US/zh-CN coverage, mapping error codes to localized messages, and validating key parity, pluralization, and formatting.

When to use

  • setting up i18n framework
  • auditing i18n key usage
  • replacing hard-coded strings
  • ensuring en-US/zh-CN coverage
  • mapping error codes to localized messages
  • validating key parity
  • validating pluralization
  • validating formatting

When not to use

  • adding extra locales unless explicitly requested
