ena-database

combined

Access European Nucleotide Archive via API/FTP. Retrieve DNA/RNA sequences, raw reads (FASTQ), genome assemblies by accession, for genomics and bioinformatics pipelines. Supports multiple formats. Access the European Nucleotide Archive (ENA) via REST APIs and FTP/Aspera to search and retrieve sequences, raw reads (FASTQ), assemblies, and metadata when you have accession IDs or need metadata-driven discovery for genomics pipelines.

When to use

  • Retrieving nucleotide sequences or raw sequencing reads by accession
  • Searching for samples, studies, or assemblies by metadata criteria
  • Downloading FASTQ files or genome assemblies for analysis
  • Querying taxonomic information for organisms
  • Accessing sequence annotations and functional data
  • Integrating ENA data into bioinformatics pipelines
  • Performing cross-reference searches to related databases
  • Bulk downloading datasets via FTP or Aspera

Conflict

The copies overlap heavily on ENA data types, Portal vs Browser API roles, formats, and rate limits, but they disagree on operational details and each has material steps the others lack. The aipoch copy adds explicit dependencies, a User-Agent, a complete runnable script, and a concrete exponential-backoff implementation. The Vibe-Skills and OpenClaw copies add browser-based search modes (free text, BLAST, Rulespace), cross-reference and CRAM registry endpoints, and a bulk-download pattern. Crowning one copy would hide the runnable pipeline guidance in one and the broader endpoint/search coverage in the others.
