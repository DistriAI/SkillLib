socs-submission

separate

Use for the pre-submission preflight to 《社会学研究》 (Sociological Studies) — checking in-text author-date citation (作者, 年: 页) plus end references (GB/T 7714, A–Z, 中外文分列), explanatory footnotes, abstract/keyword limits, the official online system (the journal's only channel), anonymity, and document hygiene. Verify every rule against the journal's current 投稿指南.

When to use

  • pre-submission preflight
  • checking in-text author-date citation
  • checking end references GB/T 7714
  • checking explanatory footnotes
  • checking abstract and keyword limits
  • checking anonymity and document hygiene
  • verifying rules against current submission guidelines

When not to use

  • submitting via third-party agents
  • submitting to impersonating fee-charging websites
  • using numeric endnotes instead of in-text citations
  • mixing explanatory text with source citations
