cuopt-numerical-optimization-api

separate

LP, MILP, and QP (beta) with cuOpt — Python, C, and CLI. Use when the user is solving LP, MILP, or QP with any cuOpt interface.

When to use

  • Solving LP problems
  • Solving MILP problems
  • Solving QP problems
  • Using cuOpt Python API
  • Using cuOpt C API
  • Using cuOpt CLI
  • Configuring solver settings
  • Handling dual values

When not to use

  • Integer QP
  • Maximizing quadratic objectives directly
  • Solving with quadratic constraints for duals
  • MILP duals
  • PDLP warmstart for MILP
