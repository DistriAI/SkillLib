manual-component

separate

Manually add, configure, reorder, and copy components on GameObjects using Unity Editor UI. For one-off Inspector workflows that do not need REST automation.

When to use

  • Adding a single component to a GameObject
  • Tuning component fields in the Inspector
  • Reordering components on one object
  • Copying component values to another object
  • Removing a component

When not to use

  • Adding components to many objects
  • Batch-configuring serialized fields
  • Reflecting over property names
  • Enabling/disabling many components at once
  • REST automation
