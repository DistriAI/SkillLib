amemo-save-mate

separate

当用户说「永久记住XXX」「记住这个」「保存永久记忆」时调用，将记忆内容追加写入本地 MEMORY.md 并同步到云端。

When to use

  • 永久记住XXX
  • 记住这个
  • 保存永久记忆
  • 追加写入本地 MEMORY.md
  • 同步记忆到云端

When not to use

  • 重置记忆
  • 刷新助手记忆
