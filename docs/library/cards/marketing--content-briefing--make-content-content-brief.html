make-content-content-brief

separate

Writes a one-page content brief before any draft: audience, intent, the one arguable point, what top results already say and what this piece adds, an outline, a proof inventory with gaps marked, voice, CTA and banned words, checked against six gates. Use alone when you already have the topic, format, audience and destination and want only the brief; otherwise run make-content.

When to use

  • Writing a content brief
  • Defining audience and intent
  • Creating an outline with claims
  • Building a proof inventory
  • Checking against six gates
  • Identifying information gain
  • Specifying voice and CTA

When not to use

  • Writing the full draft
  • Running the full make-content workflow
  • Generating creative assets
  • Performing web searches without a host tool
