paradiz

separate

Отвечать клиентам в VK по стоимости отдыха на основе Excel-прайса. Использовать, когда нужно быстро посчитать цену по датам, количеству гостей и номеру, и выдать короткий продающий ответ для соцсети.

When to use

  • быстрые ответы в VK по стоимости отдыха
  • расчёт цены по датам, гостям и номеру
  • проверка занятости номеров в БД
  • предложение альтернативных дат и номеров
  • формирование короткого продающего ответа
  • обработка удержаний номеров (holds)
  • расчёт комбинированного размещения для 5+ гостей

When not to use

  • предложение тарифов с питанием
  • бронирование менее 3 суток
  • запрос бюджета гостя
  • отправка реквизитов предоплаты в чат
  • просьба прислать чек в чат
