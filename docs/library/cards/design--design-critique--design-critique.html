design-critique

combined

Get honest design feedback. Upload any visual — UI design, logos, photos, graphics, PDFs — and get prioritized critique: what's broken, what works, what to polish. Theory-backed analysis using 11 frameworks. Facilitate a structured team critique — framing, feedback rules, and actionable outcomes. Use when running a session with people in the room. For a solo expert review, use `heuristic-evaluation` (prototyping-testing).

  • Graphics review
  • PDF visual analysis
  • Website URL evaluation

Skill page

Conflict

The three copies define different procedures for the same skill name. Owl-Listener is a facilitation guide for live team sessions (rules, timing, critique types, pitfalls). mohitagw15856 is a solo expert review that produces a fixed report with required inputs, a prioritized issue list, a Nielsen heuristic table, Gestalt checks, JTBD alignment, and next steps. LeoYeAI is a visual-analysis skill that accepts any image and applies 11 named frameworks, including Itten color, typography, grid, composition, Tufte, Rams/Bauhaus, and platform conventions, with a hard rule that every finding includes a Fix line. No single copy contains the other's core steps, so crowning one would hide real alternatives.
