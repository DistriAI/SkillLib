design-critique

combined

Get honest design feedback. Upload any visual — UI design, logos, photos, graphics, PDFs — and get prioritized critique: what's broken, what works, what to polish. Theory-backed analysis using 11 frameworks. Facilitate a structured team critique — framing, feedback rules, and actionable outcomes. Use when running a session with people in the room. For a solo expert review, use `heuristic-evaluation` (prototyping-testing).

Skill page

Conflict

The two skills address the same domain but perform fundamentally different tasks. The first (Owl-Listener) is a facilitation guide for human-led team meetings, focusing on social dynamics, meeting structure (timeboxes), and communication protocols. The second (LeoYeAI) is an automated analysis tool for AI agents to critique visual assets using specific design theories (Gestalt, Itten, Nielsen) and output a structured, severity-ranked list of fixes. They do not reproduce each other; one is a process for people, the other is a heuristic engine for software. Combining them allows an agent to handle both the 'human-in-the-loop' facilitation and the 'automated visual audit' aspects of design critique.
