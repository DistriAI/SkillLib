aeri-robustness

separate

Use when deciding which robustness checks belong in the few in-text words of an American Economic Review: Insights (AER: Insights) short-format manuscript versus the online Supplemental Appendix. Triages checks against the length cap; it does not design the identification (see aeri-identification).

When to use

  • deciding which robustness checks belong in-text
  • triaging checks against the length cap
  • classifying candidate checks by the triage rule
  • signposting appendix checks in one sentence
  • running the robustness battery via StatsPAI / Stata MCP

When not to use

  • designing the identification
  • treating heterogeneity splits as in-text robustness
  • reproducing the appendix robustness grid in the main text
