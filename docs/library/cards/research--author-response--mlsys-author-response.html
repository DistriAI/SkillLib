mlsys-author-response

separate

Use when drafting MLSys author responses on OpenReview under the venue's compressed rebuttal window, prioritizing systems-reviewer objections about workload representativeness, baseline tuning, and missing measurements, deciding whether to run new experiments in days, and keeping replies anonymous and decision-focused.

When to use

  • drafting MLSys author responses
  • prioritizing systems-reviewer objections
  • deciding whether to run new experiments
  • keeping replies anonymous and decision-focused
  • triaging reviews within a four-day window
  • addressing workload representativeness
  • addressing baseline tuning
  • addressing missing measurements

When not to use

  • restructuring the paper in prose
  • pasting external links or pointing to updated arXiv versions
  • revealing company, cluster names, or internal system identities
  • answering stylistic complaints
