nemo-relay-instrument-typed-wrappers

separate

Use this skill when adding NeMo Relay typed wrappers, domain types, or provider codecs while preserving JSON middleware semantics and caller-visible behavior.

When to use

  • adding NeMo Relay typed wrappers
  • defining domain types
  • implementing provider codecs
  • converting application-facing values to JSON
  • normalizing provider-specific LLM requests and responses
  • using DataclassCodec or PydanticCodec
  • using OpenAIChatCodec or AnthropicMessagesCodec

When not to use

  • initial adoption without stable domain models
  • converting application domain objects with provider codecs
