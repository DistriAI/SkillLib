molcell-star-methods

separate

Use to build Molecular Cell's mandatory STAR Methods — the Key Resources Table, the Resource Availability subsections, Experimental Model and Subject Details, Method Details, and Quantification and Statistical Analysis, in the required order and with the reagent transparency Molecular Cell reviewers demand.

When to use

  • Building Key Resources Table
  • Creating Resource Availability subsections
  • Writing Experimental Model and Subject Details
  • Drafting Method Details
  • Compiling Quantification and Statistical Analysis
  • Ensuring reagent transparency with identifiers

When not to use

  • Submitting free-text Methods sections
