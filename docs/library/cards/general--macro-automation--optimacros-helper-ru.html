optimacros-helper-ru

separate

Помощь с Optimacros: синтаксис формул, проектирование модели, выбор между справочниками/свойствами/кубами, работа с версиями и временем, DCA, UAM/МДП, Workflow, доступы, скрипты и практические паттерны моделирования. Использовать, когда пользователь просит помочь с формулами Optimacros, архитектурой модели, мультикубами, справочниками, доступами, блокировками, скриптами или разбором ошибок в OM.

When to use

  • объяснить формулу Optimacros
  • написать выражение на языке OM
  • спроектировать справочники
  • выбрать между справочником, свойством, форматом Измерение и отдельным кубом
  • настроить роли
  • объяснить UAM/МДП, DCA, Workflow, User Ban
  • объяснить типы скриптов
  • выбрать режим блокировки (Shared, Unique, Custom)
