tiktok-transcribe

separate

TikTok 视频 → 下载 → 转录 → 存为 Markdown。 支持 vm.tiktok.com / vt.tiktok.com 短链和完整链接，无需登录。

When to use

  • Transcribing TikTok videos
  • Converting TikTok links to text
  • Downloading TikTok audio
  • Handling vm.tiktok.com short links
  • Handling vt.tiktok.com short links
  • Handling full TikTok video links

When not to use

  • Batch scraping
  • Commercial crawling
  • Accessing private account content
  • Infringing others' rights
