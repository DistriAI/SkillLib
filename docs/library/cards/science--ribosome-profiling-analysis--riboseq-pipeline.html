riboseq-pipeline

separate

End-to-end Ribo-seq analysis from FASTQ through periodicity QC, P-site calibration, ORF detection, translation efficiency, and stalling. Use when orchestrating a full ribosome profiling pipeline and deciding harvest/dedup/alignment options and which downstream analyses the library can support.

When to use

  • orchestrating a full ribosome profiling pipeline
  • deciding harvest/dedup/alignment options
  • determining which downstream analyses the library can support
  • UMI handling, trimming, rRNA depletion
  • footprint-aware alignment
  • periodicity QC
  • P-site calibration
  • ORF detection and differential translation

When not to use

  • internals of any one step
