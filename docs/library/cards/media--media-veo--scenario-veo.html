scenario-veo

separate

Use when generating or extending video with Google Veo models on Scenario via MCP: text-to-video, image-to-video from a first frame, first and last frame transitions, reference-to-video (R2V) with asset or style reference images, native audio with dialogue, sound effects, and ambience, negative prompts, seeded reruns, extending a 16:9 clip, or choosing a quality, fast, or lite tier. Keywords: Veo 3.1, Veo 3.1 Fast, Veo 3.1 Lite, Extend Video, Google, T2V, I2V, V2V, 720p, 1080p.

When to use

  • text-to-video
  • image-to-video from a first frame
  • first and last frame transitions
  • reference-to-video with asset or style reference images
  • native audio with dialogue, sound effects, and ambience
  • negative prompts
  • seeded reruns
  • extending a 16:9 clip

When not to use

  • model-agnostic video work
  • extending a 9:16 clip
  • combining image with referenceImages
  • using referenceImages with Lite
  • using referenceImagesType with Fast
