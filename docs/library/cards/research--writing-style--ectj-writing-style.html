ectj-writing-style

separate

Use when revising a The Econometrics Journal (EctJ) manuscript for compact RES/OUP style covering the 150-word summary, the roughly 20-page printed-paper discipline, theorem readability, one-page simulation summaries, applied-value clarity, and template-conformant prose that survives the desk screen.

When to use

  • revising an EctJ manuscript
  • editing for compact RES/OUP style
  • revising the 150-word summary
  • managing the 20-page printed-paper discipline
  • improving theorem readability
  • summarizing simulation results in one page
  • clarifying applied value
  • ensuring template-conformant prose

When not to use

  • correcting mathematical errors
  • writing new econometric theory
  • designing new simulation experiments
  • collecting new empirical data
