context-engine

authentic

Loads and manages company context for all C-suite advisor skills. Reads ~/.claude/company-context.md, detects stale context (>90 days), enriches context during conversations, and enforces privacy/anonymization rules before external API calls.

When to use

  • Loading company context
  • Detecting stale context
  • Enriching context during conversations
  • Enforcing privacy and anonymization rules
  • Managing C-suite advisor context

When not to use

  • Silently overwriting context files
  • Sending specific revenue or burn figures externally
  • Sharing customer or employee names externally
