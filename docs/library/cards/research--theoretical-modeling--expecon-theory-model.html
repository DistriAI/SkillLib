expecon-theory-model

separate

Use when turning the behavioral or game-theoretic argument behind an Experimental Economics (ExpEcon) manuscript into pre-specified, testable predictions. Develops the hypotheses tested; it does not run estimation or invent citations.

When to use

  • turning behavioral or game-theoretic arguments into pre-specified, testable predictions
  • developing hypotheses for Experimental Economics manuscripts
  • stating which model predicts what in each treatment
  • distinguishing competing accounts like selfishness, inequity aversion, and reciprocity
  • deriving equilibrium or point predictions for pre-analysis plans
  • calibrating parameters so models separate
  • pre-specifying directional hypotheses
  • handling noise explicitly in predictions

When not to use

  • running estimation
  • inventing citations
  • providing new theorems
  • structural estimation identification
