gemini

combined

Gemini CLI for one-shot Q&A, summaries, and generation. Cross-model second opinion from Google Gemini — a different AI reviewing the same changes, with deep Google ecosystem knowledge. Three modes: review (pass/fail gate for Google Ads campaigns, SEO metadata, or code), challenge (adversarial stress-test that tries to break your changes), and consult (open Q&A with Gemini on Google Ads strategy, SEO best practices, or implementation questions). Use when the user says "gemini review", "ask gemini", "gemini challenge", "second opinion from gemini", "consult gemini", "stress test with gemini", "what would gemini say", "cross-model review", or "get another opinion". Voice aliases: "gem", "gemini check". Especially useful for Google Ads changes, SEO metadata updates, campaign structure decisions, keyword strategies, and bid/budget changes — Gemini has native Google ecosystem knowledge that complements Claude's analysis.

When to use

  • WHEN ASKED TO BE ACTIVATED
  • **Code Review**: Comprehensive code reviews across multiple files
  • **Plan Review**: Analyzing architectural plans, technical specifications, or project roadmaps
  • **Big Context Processing**: Tasks requiring >200k tokens of context (entire codebases, documentation sets)
  • **Multi-file Analysis**: Understanding relationships and patterns across many files

When not to use

  • interactive mode
  • background tasks with default approval mode

Skill page

Conflict

The three copies describe different procedures for invoking Gemini. The first is a cross-model second-opinion workflow for Google Ads/SEO that delegates to a separate WORKFLOW.md. The second is a detailed guide for running the Gemini CLI in background/automated contexts, with specific model selection, approval-mode rules, and timeout handling. The third is a minimal one-shot Q&A guide that explicitly warns against using --yolo. Because the second and third copies directly conflict on the use of --yolo, and the first copy targets a different use case (Google ecosystem review) than the CLI execution guides, crowning one would hide real alternatives.
