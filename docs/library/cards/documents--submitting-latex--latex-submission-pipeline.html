When to use

  • applying journal/conference LaTeX templates
  • resolving compile errors
  • resolving citation errors
  • fixing missing fonts
  • fixing image format incompatibility
  • automating PDF compilation via GitHub Actions
  • packaging submission zip
  • formatting with latexindent and linting with chktex
