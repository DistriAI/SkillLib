Use this when you need to generate slides from a topic/outline, edit slide content via `projects/*.js`, preview as HTML, or export a `.pptx` without relying on an existing template.

When to use

  • You need to generate a new slide deck from a topic, brief, or outline (6-10 sections) and want a consistent visual style.
  • You want to iteratively edit slide content and structure in code (`projects/*.js`) rather than in PowerPoint.
  • You need a fast HTML preview loop before exporting a final `.pptx`.
  • You must export a `.pptx` without starting from an existing PowerPoint template.
  • You want to standardize slide layouts using predefined component types (e.g., comparison, timeline, stats).

When not to use

  • Do not use this skill when the required source data, identifiers, files, or credentials are missing.
  • Do not use this skill when the user asks for fabricated results, unsupported claims, or out-of-scope conclusions.
  • Do not use this skill when a simpler direct answer is more appropriate than the documented workflow.

Conflict

The two skills describe fundamentally different technical stacks and workflows for creating presentations. The first skill (LeoYeAI) instructs the agent to generate a single HTML file using the Reveal.js library, focusing on CSS design principles, color palettes, and browser-based rendering. The second skill (aipoch) instructs the agent to use a local Python/JS framework located at a specific Windows path (D:\SKILL\project\ppt) to author slides in JavaScript files and export them to a .pptx file. Because they rely on different tools (Reveal.js vs. local Python/JS exporter) and produce different outputs (HTML vs. PPTX), crowning one would hide a valid alternative approach for users who need PowerPoint files or have the local framework installed.
