conbio-revision-and-rebuttal

separate

Use when writing the response to a Conservation Biology revise-and-resubmit. Decisions weigh novelty, transferability, methodological soundness, and direct conservation relevance, so the response must convert each reviewer while keeping the handling editor confident. Structures the response letter; it does not fabricate new results.
