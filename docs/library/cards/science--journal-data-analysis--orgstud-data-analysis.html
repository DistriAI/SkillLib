orgstud-data-analysis

separate

Use when executing and reporting the analysis for an Organization Studies (OS) manuscript — qualitative coding and the data-to-theory ladder, process analysis, or quantitative estimation and robustness. Makes the evidence-to-theory link transparent; it does not design the study (see orgstud-methods).

When to use

  • Qualitative coding and data-to-theory ladder
  • Process analysis and model construction
  • Quantitative estimation and robustness checks
  • Making evidence-to-theory links transparent
  • Auditing inference from raw data to theoretical claims

When not to use

  • Designing the study
