acmmm-topic-selection

separate

Use when deciding whether a project is a genuine ACM MM (ACM Multimedia) contribution rather than single-modality work, choosing a thematic area, and routing between ACM MM, CVPR/ICCV, ACL/EMNLP, ICMR, MMSys, NeurIPS/ICLR, and the ACM TOMM journal by finding the cross-modal or media-systems core of the contribution.

When to use

  • deciding if a project is a genuine ACM MM contribution
  • choosing a thematic area
  • routing between ACM MM, CVPR/ICCV, ACL/EMNLP, ICMR, MMSys, NeurIPS/ICLR, and ACM TOMM
  • finding the cross-modal or media-systems core of the contribution
  • identifying the single-modality trap
  • selecting the track within ACM MM

When not to use

  • writing the paper
  • single-modality work without cross-modal integration
  • pure computer-vision claims with no essential second modality
  • pure language claims
  • general ML methods where multimedia setting is incidental
