kdd-writing-style

separate

Use when revising a KDD paper into the venue's register, where the first page names a data regime, a mechanism, and scale evidence, efficiency adjectives trace to design decisions, and two-column sigconf pages punish sprawl. Covers Research vs ADS voice, dataset-size discipline, assertive contribution bullets, and 8-page compression.

When to use

  • revising a KDD paper
  • rewriting page one for data regime
  • auditing adjectives for mechanism attribution
  • compressing content to 8 pages
  • writing ADS voice sections
  • formatting contribution bullets
  • checking anonymity phrasing
  • optimizing title and abstract

When not to use

  • writing ICML papers
  • writing database papers
  • creating new datasets
  • implementing model architectures
