Skill page

Conflict

The two skills describe fundamentally different implementations of the 'perplexity' skill. The first (softaworks) is a routing and policy skill for an agent using MCP tools (Perplexity Search/Ask), defining when to use them versus other tools like Context7 or Graphite, and explicitly prohibiting a specific research tool. The second (LeoYeAI) is a standalone CLI wrapper skill that executes a Node.js script to call the Perplexity API directly, requiring an API key. They do not reproduce each other; one is a decision framework for tool selection, and the other is a direct execution script. Combining them is necessary to capture both the high-level routing logic and the low-level API execution method.
