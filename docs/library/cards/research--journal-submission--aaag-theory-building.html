aaag-theory-building

separate

Use when building the conceptual contribution of an Annals of the American Association of Geographers manuscript — turning a finding into a geographic argument grounded in geographic theory (place, scale, space-time, environment-society, spatial process). Sharpens the argument; it does not run analyses.

When to use

  • Building conceptual contribution
  • Turning findings into geographic arguments
  • Grounding arguments in geographic theory
  • Sharpening geographic arguments
  • Deciding which geographic concept the argument advances
  • Addressing reviews that papers are descriptive or atheoretical

When not to use

  • Running analyses
