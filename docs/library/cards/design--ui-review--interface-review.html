interface-review

separate

Reviews a branch, pull request or uncommitted change for the interface problems it introduced or regressed, across accessibility, layout, writing, typography, color and UI.

When to use

  • Reviewing pull requests
  • Reviewing branches
  • Reviewing uncommitted changes
  • Identifying interface regressions
  • Classifying findings by status
  • Expanding changed files to affected surfaces

When not to use

  • Whole-repository interface audits
  • General code review for correctness
  • General code review for tests
  • General code review for security
  • General code review for performance
  • Reviewing a screen rather than a change
