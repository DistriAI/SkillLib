ieee-transactions-on-medical-imaging

separate

Use when targeting IEEE Transactions on Medical Imaging (TMI) or deciding whether a medical-imaging methods manuscript fits this venue. Encodes the journal's fit, the imaging-specific-method-with-proper-validation bar, dataset and evaluation rigor, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • fit/framing check for TMI manuscripts
  • re-framing medical-imaging-specific contributions
  • venue selection between TMI and broader biomedical venues
  • dataset-and-validation bar assessment
  • desk-reject heuristics
  • image formation and reconstruction methods
  • image analysis methods
  • machine learning for medical imaging

When not to use

  • generic computer-vision methods on medical datasets
  • papers without medical-imaging specificity
  • evaluations on tiny or unrepresentative data
  • replacing the journal's current official author information
