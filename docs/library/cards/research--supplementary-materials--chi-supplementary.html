chi-supplementary

separate

Use when assembling supplementary materials for an ACM CHI submission — the video figure with mandatory closed captions, appendices, study instruments, code and data archives — all due with the paper on the single September deadline, anonymized end to end, plus the camera-ready video preview.

When to use

  • assembling supplementary materials for ACM CHI submission
  • creating video figure with mandatory closed captions
  • preparing appendices and study instruments
  • packaging code and data archives
  • anonymizing supplementary files
  • producing camera-ready video preview

When not to use

  • writing the main paper
  • managing the submission deadline itself
