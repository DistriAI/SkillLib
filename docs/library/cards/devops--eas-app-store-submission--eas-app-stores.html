eas-app-stores

authentic

Build and submit iOS and Android apps with EAS to TestFlight, the App Store, or Google Play. Supports Expo and other React Native projects, plus existing native apps. Use for eas.json setup, release pipelines, signing, app versions and build numbers, store submissions, and listing metadata. For Expo websites and API routes, use eas-hosting; for adding React Native screens to a native app, use expo-brownfield.

When to use

  • eas.json setup
  • release pipelines
  • signing
  • app versions and build numbers
  • store submissions
  • listing metadata
  • Expo and React Native projects
  • existing native apps

When not to use

  • Expo websites
  • API routes
  • adding React Native screens to a native app
