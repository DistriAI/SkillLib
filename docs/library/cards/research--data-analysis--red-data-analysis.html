red-data-analysis

separate

Use when building or auditing the quantitative analysis behind a Review of Economic Dynamics (RED) manuscript — calibration, moment-matching, structural estimation, and numerical-solution discipline for dynamic models, plus reproducible-computation hygiene that the RED code-first culture expects. Lighter on raw empirics for purely theoretical papers; focused on numerical examples and reproducible computation there.

When to use

  • Calibrating or estimating a dynamic model
  • Reporting model-vs-data fit
  • Building numerical experiments for computational papers
  • Ensuring reproducible computation for RED archives
  • Documenting numerical solution discipline
  • Creating calibration records
  • Auditing moment-matching and estimation

When not to use

  • Raw empirics for purely theoretical papers
  • Causal-inference toolchain for structural/calibration work
