ppopp-topic-selection

separate

Use when deciding whether a parallel/concurrent-computing project belongs at PPoPP or should be routed to PLDI, CGO, POPL, ASPLOS, HPCA, SC, SPAA, or OOPSLA, and when distinguishing PPoPP's "the parallelism is the point" scope from a compiler contribution (CGO/PLDI), a concurrency logic (POPL), or a microarchitecture result (ASPLOS/HPCA).

When to use

  • deciding if a project belongs at PPoPP
  • routing to PLDI, CGO, POPL, ASPLOS, HPCA, SC, SPAA, or OOPSLA
  • distinguishing PPoPP scope from compiler contributions
  • distinguishing PPoPP scope from concurrency logic
  • distinguishing PPoPP scope from microarchitecture results
  • applying the 'is the parallelism the point' test
  • applying the remove-the-parallelism test
  • applying the swap-the-machine test

When not to use

  • drafting the paper
  • writing skills
