atomgit

separate

AtomGit/GitCode 仓库管理技能，提供用户、仓库、Issue、PR、文件、分支等 API 操作。AtomGit 和 GitCode 是同一平台的不同域名（atomgit.com / gitcode.com），共享相同的 API 后端。

When to use

  • 用户 API 操作
  • 仓库 API 操作
  • Issue API 操作
  • PR API 操作
  • 文件 API 操作
  • 分支 API 操作
