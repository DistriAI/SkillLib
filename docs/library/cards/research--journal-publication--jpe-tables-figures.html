jpe-tables-figures

separate

Use when finalizing the main exhibits (tables and figures) of a Journal of Political Economy (JPE) manuscript so each one carries economic content and is self-contained. Sets exhibit design and notes standards; it does not decide which results to report (see jpe-robustness).

When to use

  • finalizing main exhibits
  • designing JPE tables
  • designing JPE figures
  • writing exhibit notes
  • deciding main text vs. online appendix content
  • ensuring exhibits are self-contained
  • reporting economic magnitudes

When not to use

  • deciding which results to report
