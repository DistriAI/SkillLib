composition-patterns

authentic

React composition patterns for building flexible, maintainable components by avoiding boolean prop proliferation. Use when refactoring components, building component libraries, or designing reusable APIs.

When to use

  • Refactoring components with many boolean props
  • Building reusable component libraries
  • Designing flexible component APIs
  • Reviewing component architecture
  • Working with compound components
  • Working with context providers
  • React 19 API changes

When not to use

  • React 18 or earlier
