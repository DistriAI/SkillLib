text-normalization

separate

对Excel文件进行文本标准化清洗（如去除异常前缀、提取纯中文字符等），并，最终输出清洗后的Excel文件并提供下载链接。

When to use

  • Excel文件文本标准化清洗
  • 去除异常前缀
  • 提取纯中文字符
  • 数值字段转换为整数
  • 大文件处理内存清理

When not to use

  • 读取Excel文件
  • 计数统计
  • Parquet优化
