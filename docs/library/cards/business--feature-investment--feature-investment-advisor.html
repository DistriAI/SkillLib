feature-investment-advisor

separate

Evaluate feature investments using revenue impact, cost structure, ROI, and strategy. Use when deciding whether a feature deserves investment.

When to use

  • Guide product managers through evaluating whether to build a feature based on financial impact analysis. Use this to make data-driven prioritization decisions by assessing revenue connection (direct or indirect), cost structure (dev + COGS…

When not to use

  • Features that are table stakes for competitive parity
  • Features with purely qualitative impact
  • Unvalidated problems requiring discovery first
  • Features requiring less than 1 week of work
