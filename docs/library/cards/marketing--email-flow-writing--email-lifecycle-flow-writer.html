email-lifecycle-flow-writer

Step of the email-lifecycle playbook: writes one lifecycle flow as a build sheet for the brand's email tool, every message finished in the brand voice. Run email-lifecycle instead; not for direct use.

When to use

  • Writing lifecycle flows as build sheets
  • Wiring flows in the tool's real syntax
  • Planning message counts and delays
  • Writing finished email messages with subject lines and CTAs
  • Self-checking copy against failure lists
  • Leaving honest gaps with placeholders
  • Defining hypotheses for the cycle
  • Placing art answers on re-runs

When not to use

  • Direct use
  • Running email-lifecycle
