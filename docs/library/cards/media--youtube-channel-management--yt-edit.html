yt-edit

separate

Turn a raw recording's transcript into an edit decision list - dead air, filler cues and retakes, with timecodes. Use for "edit this", "cut the dead space", "tighten this video", "I rambled", or any request to shorten footage from a transcript.

When to use

  • edit this
  • cut the dead space
  • tighten this video
  • I rambled
  • shorten footage from a transcript
  • identify dead air
  • identify filler cues
  • identify retakes

When not to use

  • touch media
  • opinion about B-roll
  • publishing
  • guessing at timings
