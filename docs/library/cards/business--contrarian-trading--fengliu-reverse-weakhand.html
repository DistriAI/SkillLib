fengliu-reverse-weakhand

separate

Use when evaluating stocks through Feng Liu's weak-hand (弱者体系) reverse investing lens: assume you have less information, seek asymmetric risk/reward, buy at points of maximum pessimism, and manage position by probability.

When to use

  • 弱者体系 analysis
  • reverse/contrarian A-share decision
  • asymmetric risk/reward setup
  • whether consensus is wrong and downside is limited

When not to use

  • Another skill fits better.
  • Critical data for this model is missing.
  • The user wants guaranteed returns or unbounded leverage.
  • The request is generic chatter with no decision.
