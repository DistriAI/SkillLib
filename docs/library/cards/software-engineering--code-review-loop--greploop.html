greploop

separate

Address Greptile feedback on a PR, MR, or shelved changelist through bounded review and fix cycles. Use when the task includes a Greptile review loop. Supports the alternate @greptile-apps trigger for large PRs.

When to use

  • Address Greptile feedback on a PR
  • Address Greptile feedback on an MR
  • Address Greptile feedback on a shelved changelist
  • Bounded review and fix cycles
  • Greptile review loop
  • Alternate @greptile-apps trigger for large PRs

When not to use

  • Read-only review request without authorization for code edits
  • Posting comments without authorization
  • Switching another task's checkout to the PR branch
  • Merging unless requested
  • Raising the iteration cap automatically
  • Calling a partial result complete
