para-second-brain

separate

Organize your agent's knowledge using PARA (Projects, Areas, Resources, Archive) — then make it ALL searchable. The symlink trick enables full semantic search across your entire knowledge base, not just MEMORY.md. Includes session transcript indexing and memory flush protocol. Your agent finally has a real second brain.

When to use

  • Organizing agent knowledge using PARA
  • Making notes folder searchable via symlink
  • Indexing session transcripts
  • Implementing memory flush protocol
  • Separating raw capture from curated knowledge
  • Tracking active work and ongoing responsibilities
  • Managing reference material and completed work

When not to use

  • Cloud-hosted knowledge base using Ensue API
  • Evergreen knowledge base optimized for semantic queries
