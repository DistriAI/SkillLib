pom-tables-figures

separate

Use when designing the exhibits for a Production and Operations Management (POM) manuscript — result tables, comparative-statics and sensitivity plots, model schematics, empirical tables, simulation plots — and deciding what stays in the 32-page main paper vs. the online e-companion. Designs exhibits; it does not run the analysis (pom-data-analysis).

When to use

  • Designing result tables
  • Creating comparative-statics and sensitivity plots
  • Designing model schematics
  • Formatting empirical tables
  • Creating simulation plots
  • Deciding main paper vs. e-companion placement
  • Reviewing exhibit decision-legibility

When not to use

  • Running the analysis
