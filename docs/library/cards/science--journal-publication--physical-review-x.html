Use when targeting Physical Review X (PRX) or deciding whether a physics manuscript fits this open-access, high-impact, cross-subfield, longer-form APS venue. Encodes the journal's fit, framing, method-and-evidence bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting Physical Review X
  • deciding if a physics manuscript fits PRX
  • mapping significance level and length requirements
  • understanding PRX's licensing model
  • reframing for cross-subfield importance
  • pre-submission self-check
  • official-submission re-check

When not to use

  • replacing the journal's current official submission guidelines
