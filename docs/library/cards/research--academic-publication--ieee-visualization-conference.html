ieee-visualization-conference

separate

Use when targeting IEEE Visualization Conference (IEEE VIS) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for visualization flagship.

When to use

  • targeting IEEE VIS
  • deciding if manuscript fits IEEE VIS
  • conference-fit read for information visualization
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • visual encoding rationale
  • visual analytics
  • scientific visualization

When not to use

  • generic HCI papers
  • graphics papers
  • rendering or geometry
  • substitute for current year CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
