pairwise-alignment

separate

Perform pairwise sequence alignment using Biopython Bio.Align.PairwiseAligner. Use when comparing two sequences, finding optimal alignments, scoring similarity, and identifying local or global matches between DNA, RNA, or protein sequences.

When to use

  • comparing two sequences
  • finding optimal alignments
  • scoring similarity
  • identifying local or global matches
  • DNA, RNA, or protein sequence alignment
  • Needleman-Wunsch global alignment
  • Smith-Waterman local alignment
  • semi-global alignment

When not to use

  • high-throughput screens
  • very long sequences
  • production pipelines
  • read mapping
  • k-mer search
  • primer placement
  • splice-aware DNA mapping
