tencent-cloudq

separate

腾讯云智能顾问助手 — 通过 AK/SK 鉴权调用腾讯云智能顾问 API，管理云架构图（查询目录、获取架构列表和详情、获取架构评估结果）及风险评估（查询评估项、按产品/分组/风险等级筛选）。当用户要求查看云架构、查询架构目录、获取架构详情、查看架构评估结果、查看风险评估项、巡检项、云资源风险等智能顾问相关操作时使用。

When to use

  • 查看云架构
  • 查询架构目录
  • 获取架构详情
  • 查看架构评估结果
  • 查看风险评估项
  • 巡检项
  • 云资源风险
  • 智能顾问相关操作
