er-robustness

separate

Use when building or writing the robustness-check section of an Economic-Research manuscript — organizes checks by the identification threat each one answers, not as an undifferentiated pile.

When to use

  • building robustness-check section
  • writing robustness-check section
  • organizing checks by identification threat
  • responding to reviewer identification concerns
  • DID robustness checks
  • placebo test design
  • Oster bounds calculation
  • robustness writing templates

When not to use

  • mechanism analysis
  • heterogeneity analysis
  • main regression specification
  • identification strategy design
