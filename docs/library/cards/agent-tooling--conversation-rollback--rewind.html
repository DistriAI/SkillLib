rewind

separate

Retrieve recent local Clips Rewind context when the user says "Look at Rewind," asks what just happened, or refers to something they recently said or saw.

When to use

  • Retrieve recent local Clips Rewind context
  • Answer what just happened
  • Refer to something recently said or seen
  • Search screen memory chapters
  • Read recent context range
  • Get exact visual moment frame
  • Scan bounded range contact sheet
  • Request bounded private Clip handoff

When not to use

  • Upload frames returned by local Screen Memory tools
  • Reveal archive filesystem paths
  • Crawl Clips' app-data folders
  • Bypass the Screen Memory MCP broker
  • Bypass Gatekeeper
  • Accept macOS permission prompts
  • Enable screen/audio capture on the user's behalf
  • Blend separate workstreams together
