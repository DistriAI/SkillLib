method-selector

authentic

Build and risk-screen a compact role-based method shortlist for a mathematical-modeling subquestion. Use after problem framing and data profiling, before model code generation, to propose a main candidate, a usable baseline, and at most one conditional fallback without padding the pool.

When to use

When not to use

  • Select the method or write human rationale
  • Fully implement all shortlisted methods
  • Invent missing data fields, constraints, or metrics
  • Use fixed candidate count
  • Use source-line count as validation quality
  • Call a nonfunctional toy method a baseline
