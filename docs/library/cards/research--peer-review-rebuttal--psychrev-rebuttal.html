psychrev-rebuttal

separate

Use when a Psychological Review decision letter (usually a major revision) has arrived and you must write the response document and revise the theory. Drafts the response and revision plan; it does NOT run the resubmission preflight (psychrev-submission) or build new theory from scratch (psychrev-theory-construction).
