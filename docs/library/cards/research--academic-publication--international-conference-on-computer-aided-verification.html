international-conference-on-computer-aided-verification

separate

Use when targeting International Conference on Computer Aided Verification (CAV) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for formal verification.

When to use

  • targeting CAV
  • deciding if a manuscript fits CAV
  • conference-fit read for verification manuscripts
  • re-framing journal or arXiv style into CAV narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues for CAV
  • routing verification, model checking, SMT, theorem proving, or synthesis papers to CAV

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • routing functional-language design to ICFP
  • routing logic foundations to LICS
  • routing software-testing/analysis tools to ISSTA
  • submitting generic CS papers without naming exact subcommunity and contribution type
