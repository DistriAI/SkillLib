amemo-save-task

separate

当用户说含时间词（今天/明天/后天/具体日期）的祈使句，或说「提醒我」「记得要」时调用，保存任务并创建麦小记邮件 + AI 定时双重提醒。

When to use

  • 保存任务
  • 创建麦小记邮件提醒
  • 创建AI定时提醒
  • 解析时间词语
  • 解析时段词
  • 多时间词批量处理
  • 提取任务内容
  • 检查邮件配置
