joap-data-analysis

separate

Use when analyzing and reporting results for a Journal of Applied Psychology (JAP) manuscript using SEM, multilevel (HLM) models, mediation/moderation, or meta-analysis. JAP requires effect sizes with confidence intervals, model-based indirect effects with bootstrap CIs, fit indices, full disclosure, and a clean confirmatory/exploratory split. Guides analysis norms; it does not fabricate results.

When to use

  • Specifying and reporting main and supporting analyses
  • Reporting fit indices, indirect-effect CIs, robustness, or disclosure
  • Reconciling preregistered analyses with exploratory follow-ups
  • Preparing analysis scripts and a data/codebook for deposit
  • Analyzing SEM/CFA models
  • Analyzing multilevel (HLM) models
  • Analyzing mediation and moderation
  • Conducting meta-analysis

When not to use

  • Fabricating results
