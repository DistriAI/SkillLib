pnas-submission

separate

Use as the final preflight before submitting to PNAS — a complete checklist across significance, track, Significance Statement, abstract, classification + keywords, figures, statistics, data, references, and required files. Bundles a checklist and a PNAS cover-letter template. Emits GO/NO-GO.

When to use

  • Final preflight before submitting to PNAS
  • Confirming all other pnas-* skill outputs landed
  • Checking for regressions in a revision
  • Verifying submission track eligibility
  • Checking Significance Statement and abstract compliance
  • Validating figures, statistics, and data availability
  • Reviewing required files and metadata

When not to use

  • Initial manuscript drafting
  • Selecting a different journal venue
  • Writing the main body of the manuscript
