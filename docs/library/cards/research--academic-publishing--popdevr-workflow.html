popdevr-workflow

separate

Use when starting or orienting any Population and Development Review (PDR, Wiley / Population Council) manuscript and unsure which skill applies — the entry-point router that dispatches to the right PDR sub-skill by lifecycle stage and article type (Research Article, Notes & Commentary, Data & Perspectives, Archives, Book Review). It dispatches; it does not draft content.

When to use

  • Starting a new PDR paper
  • Orienting when unsure which skill applies
  • Deciding which article type fits
  • Routing based on lifecycle stage
  • Returning with a decision letter

When not to use

  • Drafting content
  • Treating PDR like a methods-forward demography journal
  • Pure estimation papers with no development payoff
  • Policy op-eds with no population-science grounding
