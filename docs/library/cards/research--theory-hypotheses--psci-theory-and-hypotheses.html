psci-theory-and-hypotheses

separate

Use when stating the theory and hypotheses for a Psychological Science manuscript. The journal's credibility norms require a clear separation of confirmatory (preregistered) from exploratory analyses and theory stated before results. Structures the argument; it does not run analyses.

When to use

  • Writing the theoretical framing and hypotheses
  • Preparing a preregistration / pre-analysis plan
  • Reconciling predictions with findings
  • Addressing reviewer flags for post hoc or HARKed work

When not to use

  • Running analyses
