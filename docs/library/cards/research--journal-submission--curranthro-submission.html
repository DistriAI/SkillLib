Use when running the final pre-submission preflight for Current Anthropology (CA) via Editorial Manager — article-type selection, word/abstract caps, file formats (.doc/.rtf text + separate TIFF/EPS figures), Chicago author-date in final files, ethics statement, figure permissions, and the Wenner-Gren copyright assignment. Final checks; it does not draft content.
