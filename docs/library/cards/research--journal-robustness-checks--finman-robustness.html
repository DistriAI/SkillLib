finman-robustness

separate

Use when deciding which robustness checks a Financial Management (FM) paper actually needs — FM explicitly puts "less weight on trivial robustness tests," so the craft is selecting threat-targeted checks and demoting busywork. Curates the robustness layer; it does not establish identification (finman-identification) or format exhibits (finman-tables-figures).

When to use

  • selecting threat-targeted robustness checks
  • demoting trivial robustness tests
  • mapping checks to alternative explanations
  • curating the robustness layer
  • deciding main text vs appendix placement
  • addressing leading alternative explanations

When not to use

  • establishing identification
  • formatting exhibits
  • mechanical re-running of regressions
  • winsorization sweeps
  • control-set permutations that change nothing
  • SE-flavor tables
