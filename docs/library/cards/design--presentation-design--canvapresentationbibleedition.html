canvapresentationbibleedition

separate

Presentation Strategist ที่ใช้หลักการ Visual-First Design (พรีเซ้นฉลาดเน้นภาพไม่เน้นพูด) เป็นกรอบคิดหลักในการวิเคราะห์เนื้อหาและออกแบบ slide deck ก่อนสร้างจริงใน Canva เมื่อผู้ใช้ส่งเนื้อหามา skill นี้จะวิเคราะห์ตามหลัก Visual-First Design อย่างละเอียด แล้วเสนอแนวทางการออกแบบ 3 แบบให้เลือก พร้อมตัวอย่างโครงสร้าง slide เมื่อผู้ใช้เลือกแบบที่ต้องการแล้ว จึงสร้างจริงใน Canva Use this skill whenever someone asks to: - สร้าง presentation ใน Canva - ทำ slide deck หรือ pitch deck - "ช่วยสร้าง slide เรื่อง..." - "ทำ presentation ให้หน่อย" - "สร้าง deck สำหรับประชุม / สอน / ขาย / ระดมทุน" - ออกแบบ slide ให้ดูสวยและเหมาะกับเนื้อหา - "อยากได้ slide ที่ดูมืออาชีพ" - ส่งเนื้อหาดิบมาแล้วบอกให้ทำเป็น presentation Do NOT use this skill when: - ผู้ใช้ต้องการแค่ข้อมูลหรือคำแนะนำทั่วไป ไม่ได้ต้องการสร้างไฟล์จริง - ผู้ใช้ต้องการ HTML slide (ใช้ Slide Deck Generator skill แทน) - ผู้ใช้ต้องการ infographic หน้าเดียว ไม่ใช่ slide deck หลายหน้า - ผู้ใช้ต้องการไฟล์ .pptx โดยตรง (ใช้ pptx skill แทน)

When to use

  • Creating presentations in Canva
  • Making slide decks or pitch decks
  • Designing professional slides
  • Converting raw content into presentations
  • Creating decks for meetings, teaching, sales, or fundraising

When not to use

  • General information or advice without file creation
  • HTML slides
  • Single-page infographics
  • Direct .pptx file creation
