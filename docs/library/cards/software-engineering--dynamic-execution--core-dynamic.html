core-dynamic

separate

Internal command support for dynamic Rust crate skill management. Use only when explicitly invoked by /sync-crate-skills, /clean-crate-skills, or /update-crate-skill.

When to use

  • Sync all dependencies
  • Remove skills
  • Update specific skill
  • Generate crate-specific skills
  • Parse Cargo.toml dependencies
  • Check existing skills
  • Workspace support
  • Fetch crate documentation

When not to use

  • Committed to the rust-skills repository
