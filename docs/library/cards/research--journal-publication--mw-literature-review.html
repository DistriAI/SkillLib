mw-literature-review

separate

用于撰写或修改《管理世界》稿件的文献综述章节，建立国际脉络—本土研究—本文位置的三层对话式结构。Use when 中英文文献配比失衡、综述写成罗列式而非对话式、缺关键中文经典综述（《管理世界》《经济研究》《中国工业经济》同主题积累）、或审稿人指出本土文献覆盖不足时使用。锚定《管理世界》国务院发展研究中心主办、管理学与经济学并重、国家战略导向的三层综述规范、中英文配比阈值与本刊审稿期待，确保综述与边际贡献四句式首尾呼应。 本技能服务于《管理世界》(Management World, MW)。

When to use

  • 撰写《管理世界》文献综述
  • 修改综述章节
  • 解决中英文献配比失衡
  • 将罗列式综述改为对话式
  • 补充关键中文经典综述
  • 应对审稿人关于本土文献覆盖不足的指出

When not to use

  • 撰写教科书式知识介绍
  • 仅按时间线罗列文献
  • 自引扎堆（超过3条）
  • 5个并列引用不拆分
