create-talk

separate

Generate Beamer presentations for the sewage-house-prices project by dispatching the Storyteller agent (creator) and Discussant agent (critic). Supports 4 formats — job market, seminar, short, lightning. Derives all content from the paper.

When to use

  • Generate Beamer presentations
  • Create job market talks
  • Create seminar talks
  • Create short talks
  • Create lightning talks
  • Dispatch Storyteller agent
  • Dispatch Discussant agent
  • Compile Beamer .tex files

When not to use

  • Tasks not related to the sewage-house-prices project
  • Formats other than job-market, seminar, short, or lightning
