icra-supplementary

separate

Use when planning ICRA supplementary material, which in this venue means primarily the video attachment — 180 seconds, 20 MB, submitted in fixed PaperPlaza windows — plus external code links; covers storyboarding, showing failures, anonymization of footage, and what may never live only outside the 6+2-page PDF.

When to use

  • planning ICRA supplementary material
  • video attachment creation
  • storyboarding for 180 seconds
  • anonymization of footage
  • external code links management
  • meeting 20 MB file size limit
  • pre-upload checklist verification

When not to use

  • unlimited appendix PDF creation
  • non-ICRA conference supplementary material
