jf-writing-style

separate

Use when polishing the prose of a The Journal of Finance (JF) manuscript for accessible, general-interest exposition that reaches the broad AFA flagship readership. Tightens the introduction so question, finding, and economic magnitude land on page one, trims hedging, and offloads notation to the Internet Appendix; it does not change results or run analyses.

When to use

  • Polishing JF manuscript prose
  • Tightening the introduction
  • Trimming hedging
  • Offloading notation to the Internet Appendix
  • Ensuring accessible general-interest exposition
  • Delivering question, finding, and magnitude on page one

When not to use

  • Changing results
  • Running analyses
