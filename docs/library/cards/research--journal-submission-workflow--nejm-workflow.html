nejm-workflow

separate

Use when deciding which nejm-* sub-skill to invoke next, or when sequencing a clinical manuscript from significance test through response to reviewers for The New England Journal of Medicine. Routes — it does not replace — the specialized skills.

When to use

  • deciding which nejm-* sub-skill to invoke next
  • sequencing a clinical manuscript for NEJM
  • diagnosing the current bottleneck in a draft
  • switching into response mode after reviews arrive
  • routing by article type
  • running the triage gate log on incoming drafts

When not to use

  • replacing specialized nejm-* skills
  • targeting NEJM Evidence, NEJM AI, or NEJM Catalyst
  • porting JAMA-styled manuscripts without re-styling
