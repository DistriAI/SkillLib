jpart-rebuttal

separate

Use when writing the response to a Journal of Public Administration Research and Theory (JPART) revise-and-resubmit. JPART reviews are detailed and developmental, so the response must convert each reviewer while keeping the theoretical contribution intact. Structures the response letter; it does not fabricate new results.

When to use

  • writing the response to a JPART revise-and-resubmit
  • planning the revision and response letter
  • reconciling demands from disagreeing reviewers
  • writing the cover note to the editor summarizing the revision
  • structuring the point-by-point response letter

When not to use

  • fabricating new results
