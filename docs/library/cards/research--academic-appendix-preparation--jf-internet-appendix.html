jf-internet-appendix

separate

Use when deciding what belongs in the Internet Appendix vs. the main text of a The Journal of Finance (JF) manuscript. Allocates content and structures the appendix per JF's actual policy; it does not generate the results.

When to use

  • deciding what belongs in the Internet Appendix vs. the main text
  • allocating content between main text and Internet Appendix
  • structuring the Internet Appendix per JF policy
  • checking if main text is self-contained
  • verifying Internet Appendix placement in PDF
  • ensuring Internet Appendix items are cited from main text

When not to use

  • generating the results
  • handling replication code submission
  • generating tables or figures
