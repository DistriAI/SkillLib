setup-help

combined

Guide setup one step at a time and show what remains. Use only when the user explicitly asks for it by name. Walk a user through setup or installation one step at a time with the remaining steps visible.

When to use

  • Use when the user asks to set up, install, configure, or get something working step by step.
  • Use when the setup has multiple steps and benefits from one-at-a-time guidance.

When not to use

  • Adapted from `davidondrej/skills`; verify local paths, tools, credentials, and agent features before acting.
  • For commands, remote access, scheduling, browser automation, or file-changing workflows, get explicit user approval and confirm the target environment first.

Conflict

The second copy (sickn33) is a mirror of the first (davidondrej) but introduces a direct conflict in the core instruction for the 'Current step'. The original allows grouping 'tightly related actions' into 1-4 lines to optimize for fewer handoffs, while the mirror strictly defines a step as 'ONE atomic action' (1-2 lines) and explicitly forbids grouping. Because these are mutually exclusive strategies for pacing the user, crowning one would hide a valid alternative approach to the same task.
