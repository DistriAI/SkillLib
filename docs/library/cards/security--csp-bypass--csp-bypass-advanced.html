csp-bypass-advanced

separate

Advanced Content Security Policy bypass techniques. Use when XSS or data exfiltration is blocked by CSP and you need to find policy weaknesses, trusted endpoint abuse, nonce leakage, or exfiltration channels that CSP cannot block.

When to use

  • CSP bypass techniques
  • nonce leakage
  • trusted endpoint abuse
  • data exfiltration despite CSP
  • framework-specific bypasses
  • per-directive bypass techniques

When not to use

  • XSS vectors to deliver after CSP bypass
  • exfiltrate without JS when CSP blocks scripts but HTML injection exists
  • CRLF injection to inject CSP header or steal nonce
  • bypassing both WAF and CSP
  • clickjacking when CSP lacks frame-ancestors
