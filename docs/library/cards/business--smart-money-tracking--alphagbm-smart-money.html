Aggregate user-supplied disclosed buys and sells by source without automatically copying trades. Use when the user asks to smart money tracking with AlphaGBM. Use the bundled Python runner; never silently replace real results with demos.

When to use

  • smart money tracking
  • aggregating disclosed transactions
  • summarizing buys and sells by source
  • calculating net flow
  • AlphaGBM smart money workflow

When not to use

  • automatically copying trades
  • deciding who is smart
  • inferring undisclosed positions
  • claiming the workflow is live
  • using unsupported servers
