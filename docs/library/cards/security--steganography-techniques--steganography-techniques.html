steganography-techniques

separate

Steganography detection and extraction playbook. Use when analyzing images (LSB, PNG chunks, JPEG DCT, EXIF), audio (spectrogram, DTMF), files (polyglots, appended data, ADS), and text (whitespace, zero-width, homoglyphs) for hidden data.

When to use

  • image steganography analysis
  • LSB extraction
  • PNG chunk hiding detection
  • JPEG DCT analysis
  • EXIF metadata extraction
  • audio spectrogram analysis
  • file polyglot detection
  • text whitespace and zero-width analysis

When not to use

  • extracting files from network captures
  • extracting files from memory dumps
  • classical cipher analysis
