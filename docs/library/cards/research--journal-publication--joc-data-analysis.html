joc-data-analysis

separate

Use when executing and reporting the analysis for a Journal of Communication (JoC) manuscript so it survives expert, double-anonymous review — honest uncertainty, robustness, reliability, and triangulation appropriate to quantitative, computational, or content-analytic work. Guides analysis norms; it does not fabricate results.

When to use

  • Running main and supporting analyses
  • Building the results section
  • Addressing reviewer requests for robustness or heterogeneity
  • Reconciling preregistered vs. exploratory analyses
  • Making the analysis reproducible before deposit
  • Executing computational or text-as-data analyses
  • Performing an evidence pass for Journal of Communication

When not to use

  • Fabricating results
  • Making design decisions
  • Polishing prose without auditing research design
  • Giving submission-ready advice without checking official source maps
