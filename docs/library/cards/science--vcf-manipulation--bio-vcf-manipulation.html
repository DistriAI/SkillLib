separate

Merge, concatenate, sort, intersect, and subset VCF files using bcftools. Use when combining variant files, comparing call sets, or restructuring VCF data.

When to use

  • combining variant files
  • comparing call sets
  • restructuring VCF data
  • merging samples from multiple VCFs
  • concatenating regions from multiple VCFs
  • sorting unsorted VCF
  • intersecting call sets
  • extracting samples or regions
