alphafold-api

separate

Query AlphaFold protein structure predictions by UniProt accession

When to use

  • Query AlphaFold protein structure predictions
  • Retrieve predicted structures
  • Get confidence metrics (pLDDT, PAE)
  • Download structure files (PDB, mmCIF, BinaryCIF)
  • Lookup by UniProt accession
  • Get per-residue confidence scores
  • Retrieve UniProt summary in 3D-Beacons format

When not to use

  • Bulk downloads of entire proteomes
