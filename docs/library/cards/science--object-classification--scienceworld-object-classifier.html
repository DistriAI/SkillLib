scienceworld-object-classifier

separate

Moves a tested or examined object into a designated container (e.g., a specific colored box) based on a determined property. Use when you have completed a test or inspection and need to fulfill a classification or sorting subtask. It takes the object and target container as inputs and performs the move action.

When to use

  • This skill is used to finalize a classification task by moving an object into its designated container. It is triggered **after** a property test or inspection has been completed and a decision has been made.

When not to use

  • performing the initial test or inspection
  • determining the object's property
  • interpreting a circuit test
