icon-system

separate

Specify an icon system — grid, sizing, stroke weight, naming, categories, and implementation. Use when standardising iconography. For broader illustration, use `illustration-style` (ui-design).

When to use

  • standardising iconography
  • creating icon system specs
  • defining icon grid and sizing
  • establishing icon naming conventions
  • specifying icon categories
  • defining icon implementation details
  • ensuring visual consistency in icons

When not to use

  • broader illustration
