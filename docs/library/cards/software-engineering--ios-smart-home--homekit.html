homekit

separate

Control smart-home accessories and commission Matter devices using HomeKit and MatterSupport. Use when managing homes/rooms/accessories, creating action sets or triggers, reading accessory characteristics, onboarding Matter devices, or building a third-party smart-home ecosystem app.

When to use

  • managing homes/rooms/accessories
  • creating action sets or triggers
  • reading accessory characteristics
  • onboarding Matter devices
  • building a third-party smart-home ecosystem app

When not to use

  • Select and authorize a nearby Bluetooth or Wi-Fi accessory
  • Exchange Bluetooth GATT data after selection
  • Join or configure an accessory's Wi-Fi network after selection
