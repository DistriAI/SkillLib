freeze-check

separate

Checks whether registered notebooks have current, stale, or missing outputs. Use before rendering or to verify freshness.

When to use

  • Check notebook execution freshness
  • Verify notebook outputs are current
  • Identify stale or unexecuted notebooks
  • Check freeze cache existence

When not to use

  • Executing notebooks
  • Rendering notebooks
