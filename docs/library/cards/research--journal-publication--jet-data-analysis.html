jet-data-analysis

separate

Use when handling numerical, computational, or empirical content in a Journal of Economic Theory (JET) paper — JET is theory-first, so examples, simulations, and computed equilibria must stay subordinate to the theorem and reproducible.

When to use

  • worked numerical example
  • simulation
  • computed equilibrium
  • empirical/experimental evidence
  • determining acceptable computational content
  • presenting computational content
  • keeping computation subordinate to theorem

When not to use

  • stand-alone empirical paper
  • stand-alone computational paper
  • calibration/estimation with no theorem behind it
  • large simulation presented as the result
