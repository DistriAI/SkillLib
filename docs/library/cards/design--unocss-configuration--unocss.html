unocss

authentic

UnoCSS instant atomic CSS engine, superset of Tailwind CSS. Use when configuring UnoCSS, writing utility rules, shortcuts, or working with presets like Wind, Icons, Attributify.

When to use

  • configuring UnoCSS
  • writing utility rules
  • writing shortcuts
  • working with presets like Wind, Icons, Attributify
  • setting up configuration files
  • defining static and dynamic rules
  • applying variants
  • integrating with Vite or Nuxt

When not to use

  • using attributify mode when project setup is unclear
  • using advanced features when project setup is unclear
