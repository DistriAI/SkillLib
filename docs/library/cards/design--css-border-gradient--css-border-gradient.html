css-border-gradient

separate

Apply subtle gradient-border treatments for premium web surfaces. Use when cards, pricing panels, nav bars, modals, buttons, or hero surfaces need a refined edge highlight without a loud glow.

When to use

  • cards
  • pricing panels
  • nav bars
  • modals
  • buttons
  • hero surfaces
  • hover or focus states
  • dark glass UI

When not to use

  • rainbow borders
  • full-saturation neon
  • animated gradients
