starsem-conference-on-computational-semantics

separate

Use when targeting StarSem Conference on Computational Semantics (*SEM) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for computational semantics.

When to use

  • targeting StarSem Conference on Computational Semantics
  • deciding if a manuscript fits *SEM
  • conference-fit read for semantics manuscripts
  • re-framing journal or arXiv style to CS conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • routing semantics, meaning representation, or semantic parsing papers
  • checking submission-cycle and desk-reject risks

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • routing text production or controllable generation to INLG
  • routing broad NLP models to ACL/EMNLP/NAACL
  • routing non-computational semantics contributions
