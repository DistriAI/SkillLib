gcb-workflow

separate

Use as the entry point for any Global Change Biology (GCB) manuscript. Routes to the right GCB sub-skill based on where you are in the lifecycle and which article type (Primary Research Article, Technical Advance, Review / Research Review, Opinion / Perspective) fits. It dispatches; it does not draft content.

When to use

  • Starting a new GCB paper
  • Deciding which article type fits
  • Routing mid-project to the next skill
  • Handling decision letters
  • Dispatching based on user symptoms

When not to use

  • Drafting content
  • Pitching local case studies without global-change mechanism
  • Confusing GCB with conservation-practice journals
  • Submitting unsolicited GCB Reviews
