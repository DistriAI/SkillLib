tao-generate-image-embeddings

separate

Run TAO Data Services image embedding to turn a parquet of image filepaths into an embedding parquet using CLIP, SigLIP, or a TAO checkpoint. Use when a workflow needs embeddings before nearest-neighbor or unique-neighbor mining, or when the user asks to "embed images", "compute image embeddings", or "generate SigLIP embeddings".

When to use

  • embed images
  • compute image embeddings
  • generate SigLIP embeddings
  • generate CLIP embeddings
  • generate TAO checkpoint embeddings
  • prepare embeddings for nearest-neighbor mining
  • prepare embeddings for unique-neighbor mining

When not to use

  • mining nearest neighbors
  • mining unique neighbors
  • running tao-mine-od-images
  • running tao-mine-nearest-neighbors
