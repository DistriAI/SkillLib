jwe-workflow

separate

Use when deciding which jwe-* sub-skill to invoke next, or when sequencing manuscript work from open-economy positioning through rebuttal for 《世界经济》 (The Journal of World Economy). Routes — does not replace — the specialized skills, and cross-refers to economic-research / china-economic-quarterly / journal-of-financial-research / china-industrial-economics when the paper is really domestic.

When to use

  • Deciding which jwe-* sub-skill to invoke next
  • Sequencing manuscript work from open-economy positioning through rebuttal
  • Diagnosing if a paper fits the journal's open-economy focus
  • Routing between specialized jwe-* skills
  • Cross-refering to other journal skills for domestic papers

When not to use

  • Replacing specialized jwe-* skills
  • Handling papers focused on banking or monetary policy
  • Handling papers focused on domestic industrial policy
  • Handling pure domestic clean causal inference papers
