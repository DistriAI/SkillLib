knowledge-base-management

separate

管理本地 Markdown/Obsidian 知识库：素材入库、健康检查、增量索引、关键词与 semantic-lite 检索、逐字原文资料包、归档和 MCP 连接。用于搜索知识库、整理资料及为 Agent 准备可定位的引用。

When to use

  • 素材入库
  • 健康检查
  • 增量索引
  • 关键词与 semantic-lite 检索
  • 逐字原文资料包
  • 归档
  • MCP 连接
  • 整理资料

When not to use

  • 内置 wechat-article-exporter 服务或定时任务
  • 内置 sync_notes_to_kb.py 归类脚本
  • 创建 cron 调度器
  • 证实原文事实
  • 生成选题
