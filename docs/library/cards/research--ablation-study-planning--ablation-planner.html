ablation-planner

authentic

Use when main results pass result-to-claim (claim_supported=yes or partial) and ablation studies are needed for paper submission.

When to use

  • Main results pass `/result-to-claim` with claim_supported = yes or partial
  • User explicitly requests ablation planning
  • `/auto-review-loop` reviewer identifies missing ablations

When not to use

  • generating ablations for components identical to the baseline
  • pre-filtering or biasing the ablation list before Codex review
