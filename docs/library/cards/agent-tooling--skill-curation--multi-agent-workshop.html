When to use

  • multi-role discussion
  • requirement workshop
  • requirement review
  • roundtable discussion
  • plan before execution
  • multi-perspective review
  • executable plan output

When not to use

  • single-agent monologue without role separation
  • skipping phase 0 task clarification
  • using fixed role teams without task-based justification
