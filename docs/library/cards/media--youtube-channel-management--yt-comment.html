yt-comment

separate

Draft replies to YouTube comments in the creator's voice, triaged by which ones are worth answering. Use for "reply to my comments", "handle the comment section", "someone asked X", or a pasted comment thread.

When to use

  • reply to my comments
  • handle the comment section
  • someone asked X
  • pasted comment thread
  • triage comments
  • draft replies
  • pin comment selection

When not to use

  • publishing replies
  • inventing numbers or sources
  • writing comebacks to bait
  • promising unagreed videos
