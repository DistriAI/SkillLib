write-report

separate

Turns findings you already have into a report a marketer can read in 30 seconds. It has a short summary with key findings and how sure each one is, the first move, decisions needed, at most six next moves, what was not checked, and dated sources. It checks length and wording before handing over, then saves the report to the brand. Use alone when you already have the findings and their sources; otherwise run the playbook for the job (e.g. research-market, research-competitors, plan-campaign).

When to use

  • Writing reports from existing findings
  • Summarizing key findings with confidence levels
  • Defining first moves and decisions needed
  • Listing next moves and unchecked items
  • Formatting sources with dates
  • Checking report length and wording
  • Saving reports to the brand

When not to use

  • Conducting market research
  • Researching competitors
  • Planning campaigns
  • Generating findings from scratch
