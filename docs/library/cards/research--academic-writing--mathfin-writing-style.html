mathfin-writing-style

separate

Use when polishing a Mathematical Finance (Wiley) manuscript's theorem-first exposition — definitions, numbered assumptions, theorem statements, proof sketches, appendices, notation discipline for a stochastic-analysis readership, numerical-experiment prose, and the financial-modelling intuition that accompanies each formal result.

When to use

  • polishing theorem-first exposition
  • defining probability spaces and filtrations
  • numbering assumptions and theorems
  • separating financial intuition from proof
  • managing appendices and long derivations
  • checking local martingale claims
  • creating a notation ledger
  • writing proof sketches

When not to use

  • correcting mathematical proofs
  • generating new financial models
  • performing numerical experiments
