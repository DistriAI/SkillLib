scenario-multi-reference

separate

Use when one image must be composed from several reference pictures through the Scenario MCP server, each lending one thing: the character from one, the place, pose, style, light, palette, material, outfit, or layout from others. Also when a reference leaks into the result (its object, colors, or face showing where it should not) or a reference's role is ignored. Keywords: multi-reference, reference roles, combine references, style reference, pose reference, give each picture a job.

When to use

  • composing one image from several reference pictures
  • assigning specific jobs to reference images
  • preventing reference leakage into results
  • combining style, pose, and subject references
  • defining what not to take from each reference

When not to use

  • animating the result
  • handling refusals
  • holding one subject across many images
  • letter-perfect text overlay
