golang-samber-oops

separate

Structured error handling in Golang with samber/oops — error builders, stack traces, error codes, error context, error wrapping, error attributes, user-facing vs developer messages, panic recovery, and logger integration. Apply when using or adopting samber/oops, or when the codebase already imports github.com/samber/oops.

When to use

  • using or adopting samber/oops
  • codebase already imports github.com/samber/oops
  • error builders
  • stack traces
  • error codes
  • error context
  • error wrapping
  • panic recovery

When not to use

  • Go package docs, symbols, versions, importers, and known vulnerabilities
  • navigating library usage in own code (definitions, call sites, diagnostics)
