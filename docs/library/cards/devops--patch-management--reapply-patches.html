Reapply local modifications after a GSD update

When to use

  • Reapply local modifications after a GSD update
  • Merge user customizations into newly installed GSD files
  • Detect backed-up patches in gsd-local-patches directory
  • Determine baseline for three-way comparison
  • Show patch summary and status

When not to use

  • Initial installation of GSD
  • Updating GSD without local modifications
