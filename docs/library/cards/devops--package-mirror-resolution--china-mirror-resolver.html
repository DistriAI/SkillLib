china-mirror-resolver

separate

Self-healing China mirror source resolver. Automatically discovers, validates, and configures domestic mirror sources for pip/npm/yarn/pnpm/conda/Docker/Go/ Rust/Maven/Gradle/Homebrew/apt/yum/GitHub/HuggingFace when downloads are slow or timing out in mainland China. Trigger keywords: "换源", "镜像源", "下载慢", "超时", "timeout", "mirror", "registry", "proxy", "connection refused", "SSL error", "443", "ETIMEDOUT", "CondaHTTPError", "pip install failed".

When to use

  • pip mirror configuration
  • npm registry configuration
  • yarn registry configuration
  • pnpm registry configuration
  • conda channel configuration
  • Docker registry mirror configuration
  • Go proxy configuration
  • Rust cargo/rustup mirror configuration

When not to use

  • Tasks outside mainland China
  • Tools not listed in the diagnostic table
