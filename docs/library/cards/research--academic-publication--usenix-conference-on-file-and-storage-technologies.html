separate

Use when targeting USENIX Conference on File and Storage Technologies (FAST) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for storage systems.

When to use

  • targeting USENIX FAST
  • deciding if a manuscript fits FAST
  • conference-fit read for storage manuscripts
  • re-framing journal or arXiv style into conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • storage systems submission strategy
  • file systems and persistence contributions
  • memory/storage hierarchy and reliability analysis

When not to use

  • substitute for current year's CFP or author kit
  • networked systems routing to NSDI
  • broad OS routing to OSDI/SOSP
  • parallel programming abstractions to PPoPP
  • dialogue or NLP work to SIGDIAL/ACL
  • generic CS papers without specific storage subcommunity focus
