add-pdf-report

separate

Internal implementation skill invoked by /add-native for app-generated PDF report workflows using expo-print and, when present, expo-sharing.

When to use

  • Generate/export/print a report from app data
  • Share the generated local PDF from the device
  • Retain the generated PDF in Dataverse
  • Verify app initialization
  • Verify packages are already present
  • Reconcile requested artifacts
  • Write or verify src/native/pdfReport.ts

When not to use

  • Open an existing HTTPS or local file PDF in the Power Apps native viewer
  • Pick/import/upload a user-selected PDF
  • Install packages
  • Import the native PDF viewer directly
  • Edit native config
  • Fetch remote HTML inside the wrapper
