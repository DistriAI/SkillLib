repo-sync

separate

Manage automatic Git syncing on macOS with repo-sync. Use only when the user explicitly invokes /repo-sync.

When to use

  • Sync shared Git repos for team documents
  • Sync notes, skills, and context
  • Start automatic commits and pushes
  • Stop syncing one repo
  • Install or maintain the skill
  • Uninstall everything

When not to use

  • Complex software projects
  • Pull request workflows
  • Feature branches
  • Detached HEAD
  • Switching branches
  • Automatic conflict resolution
  • Force-push
