add-sample-data

authentic

Use when the user wants to seed Dataverse tables with realistic sample records so a freshly-scaffolded code app shows real-looking data on first launch. Generates contextually appropriate rows from each table's schema and inserts them in dependency order. Mirrors microsoft/power-platform-skills/power-pages/add-sample-data, adapted for mobile apps.

When to use

  • Seeding Dataverse tables with sample records
  • Generating contextually appropriate rows from table schemas
  • Inserting records in dependency order
  • Populating tables after /add-dataverse or /setup-datamodel
  • Reusing prototype seed data via --from-seed

When not to use

  • Seeding tables outside the approved scope
  • Seeding retiring or unrelated tables
  • Auto-rolling back on insertion failure
  • Treating discovery results as approval for seeding
  • Expanding scope by editing manifest or app plan
