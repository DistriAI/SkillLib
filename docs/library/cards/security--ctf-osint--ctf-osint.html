ctf-osint

separate

Provides open source intelligence techniques for CTF challenges. Use when gathering information from public sources, social media, geolocation, DNS records, username enumeration, reverse image search, Google dorking, Wayback Machine, Tor relays, FEC filings, or identifying unknown data like hashes and coordinates.

When to use

  • gathering information from public sources
  • social media OSINT
  • geolocation techniques
  • DNS records analysis
  • username enumeration
  • reverse image search
  • Google dorking
  • identifying unknown data like hashes and coordinates

When not to use

  • extraction or carving of local files or packets
  • active exploitation of a live HTTP service
  • analysis of malware samples, beacons, or suspicious binaries
