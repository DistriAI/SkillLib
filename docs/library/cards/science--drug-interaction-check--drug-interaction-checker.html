drug-interaction-checker

combined

Check for interactions between multiple medications, including severity classification and mechanism explanations.

When to use

  • Reviewing patient medication lists.
  • Prescribing new medications.
  • Pharmacovigilance monitoring.
  • Use this skill when the task needs Check for interactions between multiple medications, including severity classification and mechanism explanations.
  • Use this skill for evidence insight tasks that require explicit assumptions, bounded scope, and a reproducible output format.
  • Use this skill when you need a documented fallback path for missing inputs, execution errors, or partial evidence.

When not to use

  • Database may not include all possible drug combinations
  • Always consult healthcare professionals for medical decisions
  • Does not account for patient-specific factors (age, renal function, etc.)
  • Not a substitute for professional medical advice

Skill page

Conflict

The two copies overlap on the core task (checking drug-drug interactions and reporting severity), but each contains material steps the other lacks. The aipoch copy defines a five-level severity scale (Critical/Major/Moderate/Minor/Unknown), a JSON output schema, CLI parameters, a Python module interface, and a fallback workflow. The FreedomIntelligence copy defines a three-level severity scale (Minor/Moderate/Major), a different script path (impl.py), a different input format (comma-separated string), a measurable outcome, and allowed tools. Crowning one would hide a real alternative in severity taxonomy, interface, and execution path.
