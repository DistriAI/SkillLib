variable-library-cli

authentic

Manages Fabric Variable Library items, including definitions, libraryVariables and valueSets overrides. Covers which consumers can reference a variable and with what syntax -- pipelines, notebooks via notebookutils variableLibrary, Dataflow Gen2, Copy Jobs, shortcuts, UDFs and Plan items -- the active value set per workspace or deployment stage, and Git serialization for CI/CD.

When to use

  • create variable library
  • add a variable
  • valueSets
  • variableOverrides
  • updateDefinition
  • libraryVariables
  • notebookutils variableLibrary
  • active value set

When not to use

  • pipeline-migration
  • spark-cli
  • dataflows-cli
  • git-integration-operations-cli
  • deployment-pipelines-authoring-cli
