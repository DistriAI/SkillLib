jev-skill-select

separate

Use when unsure which of many installed skills applies to a request, if any, or when asked to make skill loading cheaper or more accurate. Jev ranks the whole catalog and may say no skill is needed.

When to use

  • selecting skills from a catalog
  • making skill loading cheaper
  • making skill loading more accurate
  • ranking skills against a turn
  • merging routing and skill selection requests

When not to use

  • acknowledgements
  • small talk
  • ordinary turns
  • pure social openers
  • pure next? continuations
