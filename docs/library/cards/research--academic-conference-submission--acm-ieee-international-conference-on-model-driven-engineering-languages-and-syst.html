Use when targeting ACM/IEEE International Conference on Model Driven Engineering Languages and Systems (MODELS) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for model-driven engineering.

When to use

  • targeting MODELS
  • deciding if a manuscript fits MODELS
  • conference-fit read for model-driven engineering
  • re-framing journal or arXiv style into conference narrative
  • evidence-gap diagnosis
  • anonymity diagnosis
  • artifact diagnosis
  • rebuttal diagnosis

When not to use

  • substitute for current year's CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
  • web-scale search papers
  • mining papers
  • recommendation papers
  • general software-engineering studies
