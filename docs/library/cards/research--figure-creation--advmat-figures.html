advmat-figures

separate

Use when designing or auditing figures for an Advanced Materials manuscript, including the lead figure, multi-panel characterization figures, and the Table-of-Contents graphic, where visual quality is a house expectation. Designs figure strategy; does not run the analysis or write prose.

When to use

  • designing figures for an Advanced Materials manuscript
  • auditing figures for an Advanced Materials manuscript
  • designing the lead figure
  • designing multi-panel characterization figures
  • designing the Table-of-Contents graphic
  • creating a coherent figure set from candidate panels
  • ensuring visual quality meets house expectations

When not to use

  • running the analysis
  • writing prose
