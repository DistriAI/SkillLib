generate-synthetic-data

authentic

Create diverse synthetic test inputs for LLM pipeline evaluation using dimension-based tuple generation. Use when bootstrapping an eval dataset, when real user data is sparse, or when stress-testing specific failure hypotheses. Do NOT use when you already have 100+ representative real traces (use stratified sampling instead), or when the task is collecting production logs.

When to use

  • bootstrapping an eval dataset
  • real user data is sparse
  • stress-testing specific failure hypotheses
  • generating diverse synthetic test inputs
  • covering the failure space of an LLM pipeline

When not to use

  • already have 100+ representative real traces
  • collecting production logs
  • complex domain-specific content (legal filings, medical records)
  • low-resource languages or dialects
  • when no one can judge realism
