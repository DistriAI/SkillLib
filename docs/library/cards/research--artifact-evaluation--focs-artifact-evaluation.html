focs-artifact-evaluation

separate

Use when planning the durable evidence objects around a FOCS (IEEE Symposium on Foundations of Computer Science) paper — a venue with no artifact track where the public arXiv/ECCC full version is the artifact of record, plus proof certificates, checker code, and the IEEE Xplore version's supporting role.

When to use

  • planning durable evidence objects for FOCS papers
  • managing public full versions on arXiv or ECCC
  • packaging proof certificates and checker code
  • maintaining version ledgers for submission, full, and proceedings versions
  • calibrating formalization claims
  • choosing between arXiv and ECCC hosts

When not to use

  • building Docker images for illustration scripts
  • creating anonymized artifact links inside submissions
  • developing interactive demos and websites
  • formatting artifact appendices after systems-conference templates
