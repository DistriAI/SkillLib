smart-pr-review

separate

Opinionated AI code reviewer — not a yes-machine. 6-layer deep review (logic, edge cases, performance, security, maintainability, architecture) with Devil's Advocate mode and standardized MUST FIX / SHOULD FIX / SUGGESTION output. Supports GitHub PR URL, local diff, commit hash. Languages: TypeScript/JavaScript, Python, Go, Rust. (中文) 有立场的智能代码审查：6 层审查维度、主动反对机制、标准化输出，支持 5 种语言。

When to use

  • GitHub PR URL review
  • Local diff review
  • Commit hash review
  • File path review
  • Security review
  • Performance review
  • Logic review
  • Architecture review

When not to use

  • Non-GitHub repositories
  • Languages other than TypeScript/JavaScript, Python, Go, Rust
