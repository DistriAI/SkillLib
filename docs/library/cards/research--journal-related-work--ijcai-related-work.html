ijcai-related-work

separate

Use when positioning an IJCAI or IJCAI-ECAI submission against archival AI literature, arXiv preprints, workshop papers, prior rejected versions, dual-submission rules, shortened prior versions, and resubmission-information requirements.

When to use

  • auditing novelty
  • auditing prior work
  • auditing submission eligibility
  • positioning against archival AI literature
  • handling dual-submission rules
  • handling resubmission-information requirements
  • distinguishing non-archival versions from published proceedings
  • preparing anonymized rejected versions

When not to use

  • submitting papers under review at other venues
  • submitting papers accepted at other venues
  • submitting papers published at other venues
