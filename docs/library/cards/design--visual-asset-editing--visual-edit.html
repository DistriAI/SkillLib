visual-edit

separate

Open and collaboratively edit a running local app in Design, with shared fallback previews and source handoff. Use when the user asks to inspect, share, or edit a real local app in Design.

When to use

  • inspect a real local app in Design
  • share a real local app in Design
  • edit a real local app in Design
  • visually edit a running localhost app
  • place explicit paths in Design canvas
  • discover routes for Design canvas

When not to use

  • generating standalone Alpine HTML
  • starting a local Design server
  • installing the skill into the target app
  • presenting a sign-in page as the requested screen
