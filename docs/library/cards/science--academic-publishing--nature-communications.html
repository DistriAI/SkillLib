Use when targeting Nature Communications (Nat Commun) or deciding whether a multidisciplinary open-access manuscript fits this venue. Encodes the journal's fit, framing, method-and-evidence bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting Nature Communications
  • deciding if a manuscript fits the venue
  • re-routing from Nature to open-access alternative
  • finding a high-visibility open-access home
  • checking scope boundaries
  • checking reporting requirements
  • checking desk-reject heuristics
  • re-framing for multidisciplinary audience

When not to use

  • replacing current official submission guidelines
  • providing current APC amounts
