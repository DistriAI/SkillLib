rust-refactor-helper

separate

Safe Rust refactoring with LSP analysis. Triggers on: /refactor, rename symbol, move function, extract, 重构, 重命名, 提取函数, 安全重构

When to use

  • rename symbol
  • extract function
  • inline function
  • move symbol to module
  • safe refactoring
  • impact analysis
  • dry-run preview

When not to use

  • navigate to symbol
  • understand call flow
  • project structure analysis
  • trait implementation exploration
