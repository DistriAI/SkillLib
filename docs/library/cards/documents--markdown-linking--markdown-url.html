markdown-url

separate

Route any website you need to visit through markdown.new by prefixing the URL. **WHEN TO USE:** - You would normally open a website link to read content (docs, blog posts, changelogs, GitHub issues, etc.) - You need a cleaner, Markdown-friendly view for copying notes or summarizing

When to use

  • Reading documentation pages
  • Reading blog posts
  • Reading changelogs
  • Reading GitHub issues
  • Reading articles and guides
  • Extracting Markdown content for notes

When not to use

  • Login or OAuth workflows
  • Checkout or payment processes
  • Authenticated workflows
  • Sites with CAPTCHAs or bot detection
  • File uploads or forms
  • Interactive widgets or dashboards
  • Local paths or non-HTTP(S) schemes
