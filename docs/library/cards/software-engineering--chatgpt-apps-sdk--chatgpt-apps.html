combined

Complete ChatGPT Apps builder - Create, design, implement, test, and deploy ChatGPT Apps with MCP servers, widgets, auth, database integration, and automated deployment Build, scaffold, refactor, and troubleshoot ChatGPT Apps SDK applications that combine an MCP server and widget UI. Use when Codex needs to design tools, register UI resources, wire the MCP Apps bridge or ChatGPT compatibility APIs, apply Apps SDK metadata or CSP or domain settings, or produce a docs-aligned project scaffold. Prefer a docs-first workflow by invoking the openai-docs skill or OpenAI developer docs MCP tools before generating code.

When to use

  • Create new ChatGPT App
  • Add MCP tool
  • Add widget
  • Configure authentication
  • Set up database
  • Validate app
  • Run tests
  • Deploy to production

When not to use

  • Static website content display
  • Complex multi-step workflows requiring external tabs
  • Duplicating ChatGPT's native capabilities
  • Ads or upsells

Skill page

Conflict

The two copies describe different procedures for the same task. The openai/skills copy is a docs-first, archetype-classification workflow that mandates fetching current OpenAI Apps SDK documentation before generating code and focuses on choosing the right upstream example or fallback scaffold. The LeoYeAI copy is a command-driven, end-to-end builder that defines specific slash commands, a fixed project structure, concrete MCP SDK class names, widget URI patterns, and a deployment path to Render. Neither copy is a reproduction of the other; each contains material steps and constraints the other lacks, so crowning one would hide a real alternative.
