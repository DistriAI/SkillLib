ectheory-submission

separate

Use when running the final pre-submission preflight for Econometric Theory (ET) via ScholarOne / Manuscript Central — single embedded-font PDF, single-anonymous (no double-blind anonymization), APA author-date references, the 50-page ceiling, the optional cover letter, and the Supplementary Material file.

When to use

  • final pre-submission preflight
  • checking single embedded-font PDF format
  • verifying APA author-date references
  • confirming 50-page ceiling
  • checking single-anonymous requirements
  • deciding Article vs Miscellanea
  • preparing Supplementary Material file

When not to use

  • double-blind anonymization
  • numeric or Chicago reference styles
  • uploading separate figure files
  • invited ET Interview submissions
