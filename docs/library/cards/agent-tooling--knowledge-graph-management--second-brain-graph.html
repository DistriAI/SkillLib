second-brain-graph

separate

Analyse the vault's link graph and report on its shape: orphan rate, average degree, components, hubs, bridges and clusters, with what each number means for retrieval. Use this skill when the user asks about the health or structure of their graph, wants metrics, asks which pages are most connected or most isolated, or asks whether the vault is fragmented. Do NOT use for fixing what it finds, which is second-brain-lint, or for answering a content question.

When to use

  • reporting graph health
  • reporting graph structure
  • providing graph metrics
  • identifying most connected pages
  • identifying most isolated pages
  • checking if vault is fragmented

When not to use

  • fixing graph issues
  • answering content questions
