imc-author-response

separate

Use when drafting ACM IMC author responses, covering the initial-review rebuttal and — distinctively — the One-Shot-Revision resubmission that must address a bounded set of action points, keep double-blind anonymity, satisfy the reviewer champion, and be re-judged by the same reviewers at the next deadline.

When to use

  • drafting ACM IMC author responses
  • initial-review rebuttal
  • One-Shot-Revision resubmission
  • addressing bounded action points
  • maintaining double-blind anonymity
  • satisfying the reviewer champion
  • triaging decision-critical points
  • structuring change summaries as ledgers

When not to use

  • tasks not related to ACM IMC author responses
