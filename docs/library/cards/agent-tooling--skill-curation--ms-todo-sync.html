ms-todo-sync

separate

A CLI skill to manage Microsoft To Do tasks via Microsoft Graph API. Supports listing, creating, completing, deleting, searching tasks and lists, viewing overdue/today/pending tasks, and exporting data.

When to use

  • listing tasks and lists
  • creating tasks and lists
  • completing tasks
  • deleting tasks and lists
  • searching tasks and lists
  • viewing overdue, today, and pending tasks
  • exporting data
  • managing Microsoft To Do via Microsoft Graph API
