ajs-submission

separate

Use when running the final pre-submission preflight for the American Journal of Sociology (AJS) via Editorial Manager — the $30 submission fee (waived for sole-author grad students), the separate cover page for double-blind review, the ~150-word abstract, mandatory figure alt text, AJS house style, and the originality statement. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • verifying $30 submission fee
  • checking double-blind anonymization
  • verifying separate cover page
  • checking ~150-word abstract
  • verifying figure alt text
  • checking AJS house style
  • verifying originality statement

When not to use

  • drafting content
