build-resource-pages

separate

Takes existing content markdown files and builds production-final resource center pages on client websites using their existing tech stack and design system. Output is live-ready — no review pass, no placeholder content, no prototype styling. Implements hub pages, section listings, article pages, and cross-linking for Blog, Guides, Learn, and Comparisons sections.

When to use

  • building resource center hub pages
  • creating section listing pages
  • implementing article pages
  • setting up content loading for markdown
  • building layout components like Resource Shell and Content Card
  • generating head metadata and structured data
  • implementing cross-linking and related content sections

When not to use

  • writing new content
  • creating placeholder content
  • using prototype styling
  • introducing competing style systems
