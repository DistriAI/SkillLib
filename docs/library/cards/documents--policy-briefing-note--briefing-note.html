briefing-note

combined

Structured policy briefing note (1-2 pages). Issue, background, analysis, options, recommendation. UK GES, Australian Treasury, consulting formats. Auto-populates from econstack data skills. Write a one-page briefing note that gets a busy principal up to speed fast. Use when asked to brief a minister/executive/official, prepare a briefing note or read-ahead, or summarize an issue for a decision or meeting. Produces a tight, single-page note: purpose, background, key facts/considerations, and a recommendation or the decision sought — scannable in two minutes.

Skill page

Conflict

The two skills share the core goal of producing a concise, decision-focused briefing note, but they diverge significantly in scope, structure, and tooling. The first skill (mohitagw15856) is a lightweight, general-purpose template for a one-page executive note with a specific 'Issue/Background/Considerations/Recommendation' structure and no external dependencies. The second skill (brycewang-stanford) is a heavy, interactive tool integrated with the 'econstack' ecosystem, supporting multiple government-specific templates (UK GES, AU Treasury), data auto-population, and complex argument parsing. Neither is a simple reproduction of the other; the first lacks the data integration and template variety of the second, while the second lacks the simplicity and specific 'anti-patterns' guidance of the first. Combining them allows for a flexible skill that can handle both quick, general briefs and complex, data-driven policy notes.
