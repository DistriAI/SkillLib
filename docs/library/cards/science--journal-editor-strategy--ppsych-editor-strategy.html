ppsych-editor-strategy

separate

Use when working with the Perspectives on Psychological Science (PoPS) editor and editorial team — proposal-stage scope, what review referees of a perspective evaluate, suggesting reviewers, and the author–editor relationship. Plans the interaction; it does not run the submission preflight (ppsych-submission) or draft the response letter (ppsych-revision).

When to use

  • proposal-stage scope
  • what review referees of a perspective evaluate
  • suggesting reviewers
  • author-editor relationship
  • calibrating the PoPS review cycle
  • bimonthly schedule

When not to use

  • submission preflight
  • draft the response letter
