spatial-transcriptomics-agent

separate

Runs STAgent to align histology images with expression matrices, perform clustering and SVG detection, and generate literature-backed spatial reports for spatial transcriptomics datasets.

When to use

  • Analysis of Visium/Xenium or similar ST datasets.
  • Visual reasoning over spatial plots, H&E images, or cluster maps.
  • Automatically generating Scanpy/Squidpy code for new ST workflows.
  • Hypothesis generation about spatial gene expression patterns.

When not to use

  • Definitive cell-type labeling without supporting markers
