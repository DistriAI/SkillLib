When to use

  • targeting 《经济问题探索》
  • deciding if manuscript fits venue
  • rewriting manuscript for journal narrative
  • listing desk-reject risks
  • checking official submission requirements

When not to use

  • replacing latest official submission guidelines
  • targeting 《治理研究》
  • targeting 《产业经济研究》
