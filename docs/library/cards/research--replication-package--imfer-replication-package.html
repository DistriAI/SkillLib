imfer-replication-package

separate

Use when an IMF Economic Review (IMFER) manuscript's data and code must be packaged for reproducibility — including restricted IMF/central-bank data paths, cross-country source lineage, and a runnable environment. Builds the package; it does not produce the exhibits (imfer-tables-figures) or run the submission preflight (imfer-submission).

When to use

  • Packaging data and code for reproducibility
  • Handling restricted IMF or central-bank data paths
  • Documenting cross-country source lineage
  • Creating a runnable environment
  • Assembling the package before submission or at acceptance
  • Responding to reproducibility checks or data-availability requests
  • Pinning seeds, versions, and build order

When not to use

  • Producing exhibits (imfer-tables-figures)
  • Running the submission preflight (imfer-submission)
