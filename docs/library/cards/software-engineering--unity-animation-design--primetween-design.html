primetween-design

separate

Source-anchored design rules for PrimeTween 1.4.6

When to use

  • Writing or reviewing PrimeTween code
  • Diagnosing tween lifecycle behavior
  • Configuring Sequence.Create, Chain, Group, and Insert
  • Handling OnComplete and OnUpdate callbacks
  • Managing Tween.Stop, Complete, and manual update control
  • Using await tween and ToYieldInstruction
  • Configuring TweenSettings and PrimeTweenConfig

When not to use

  • Async control flow or cancellation policy
  • Inspector-authored TweenSettings fields
  • Tween-heavy performance analysis
  • Addressables-loaded targets or scene lifetime
