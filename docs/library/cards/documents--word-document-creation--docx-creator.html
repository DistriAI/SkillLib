docx-creator

separate

Produces Word (.docx) and exports existing Word/WPS manuscripts to PDF, preserving revisions, tables and images, especially Chinese formal documents via a verified OpenXML generator with mandatory visual verification. Use for 生成 Word 文档 / 写合同 docx / 把 markdown 转成 Word / 中文排版. Not for Markdown → PDF (use daymade-docs:pdf-creator).

When to use

  • Generating Word documents
  • Writing contracts in docx
  • Converting markdown to Word
  • Chinese typography and layout
  • Exporting Word/WPS to PDF
  • Creating Chinese formal documents
  • Formatting info blocks and signature blocks

When not to use

  • Markdown to PDF conversion
  • Structural document engine implementation
  • Reinventing OpenXML SDK patterns
