When to use

  • converting between DNA, RNA, and protein sequences
  • finding ORFs
  • using alternative codon tables
  • transcription (DNA to RNA)
  • back transcription (RNA to DNA)
  • translation (RNA/DNA to protein)
  • CDS translation
  • six frame translation
