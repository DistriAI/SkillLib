eursr-data-analysis

separate

Use when executing and reporting the analysis for a European Sociological Review (ESR) manuscript so it survives expert double-blind review — correct multilevel and longitudinal modeling, honest uncertainty, robustness, and small-macro-N inference on comparative survey or register data. Guides analysis norms; it does not fabricate results.

When to use

  • Running main and supporting analyses
  • Building the results section
  • Addressing reviewer requests for robustness or alternative specifications
  • Reporting cross-level interactions or country-level effects
  • Making the analysis reproducible
  • Handling small macro-N inference
  • Validating latent constructs and invariance

When not to use

  • Fabricating results
  • Design decisions
  • Replication package management
