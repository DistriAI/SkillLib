voice-persona

separate

让 Agent 变成能语音对话的机器人：语音文件转文字（支持微信 silk 格式）+ 多音色人格回复（Edge TTS 免费中文音色），全本地零 API 成本。Voice persona chat: transcribe voice messages (incl. WeChat silk) and reply in persona voices.

When to use

  • Transcribe voice files to text
  • Decode WeChat .silk voice messages
  • Generate persona-based voice replies
  • Convert audio to WeChat silk format
  • List available voice personas
  • Two-way voice chat loop

When not to use

  • Cloud-based ASR/TTS services
  • Non-voice text generation
  • Paid API voice synthesis
