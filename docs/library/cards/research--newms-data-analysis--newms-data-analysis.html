newms-data-analysis

separate

Use when conducting and reporting the analysis of a New Media & Society (NM&S) manuscript across qualitative, content/discourse, computational, and mixed methods — making inference transparent and defensible on each tradition's own terms. Strengthens analysis and reporting; it does not collect data.

When to use

  • Moving from collected data to claims, themes, measures, or results
  • Addressing reviewer requests for reliability, robustness, validation, or analytic trail
  • Reporting uncertainty or limits for a cross-method audience
  • Qualitative inference for interviews and ethnography
  • Content and discourse analysis
  • Computational analysis validation and robustness
  • Inference honesty across all methods

When not to use

  • Study design
  • Data collection
