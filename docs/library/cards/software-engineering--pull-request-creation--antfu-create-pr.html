antfu-create-pr

separate

Create a reviewable GitHub pull request from the current branch with a Conventional Commits title, a concise evidence-based body, and before/after screenshots for UI changes. Use when asked to open, create, publish, or prepare a PR.

When to use

  • open a PR
  • create a PR
  • publish a PR
  • prepare a PR

When not to use

  • rewrite commits that are already pushed and under review
  • commit screenshots or other PR-only artifacts to the repo
