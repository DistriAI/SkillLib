chemical-storage-sorter

separate

Sort laboratory chemicals into safe storage groups by hazard classification (acids, bases, oxidizers, flammables, toxics). Identifies incompatible pairs, generates storage plans with warnings, and supports OSHA/NFPA compliance for lab safety.

When to use

  • Sort laboratory chemicals into safe storage groups
  • Identify incompatible pairs
  • Generate storage plans with warnings
  • Support OSHA/NFPA compliance
  • Classify chemicals into hazard groups
  • Check compatibility between chemicals

When not to use

  • Synthesize chemicals
  • Interpret SDS documents
  • Provide medical advice about chemical exposure
