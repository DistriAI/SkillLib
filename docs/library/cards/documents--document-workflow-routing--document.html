Conflict

The three copies are not reproductions of one procedure. The first is a dispatcher for office file formats (PDF/DOCX/XLSX/PPTX) that routes to other skills. The second is a specific writer for software change documentation (PR, changelog, release notes, postmortems) generated from git history. The third is a catalog of academic/research document processing tools (GROBID, Zotero, PDF parsing). They overlap only in the broad label 'document' but have disjoint steps, tools, and outputs.
