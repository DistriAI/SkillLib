upload-clawhub

separate

Execute DeFi transactions on BSC via SHLL AgentNFA. The AI handles all commands and users only need to chat.

When to use

  • Network: BSC mainnet
  • CLI: `shll-run` (alias: `shll-onchain-runner`)
  • MCP: `shll-mcp`
  • Security layer: SHLL PolicyGuard

When not to use

  • Withdraw vault funds
  • Transfer the Agent NFT
  • Bypass spending limits
  • Change policies
