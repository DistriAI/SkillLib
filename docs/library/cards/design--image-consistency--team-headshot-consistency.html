team-headshot-consistency

separate

Make a website''s team or about page photos look like one set — scan the headshot folder locally, flag photos whose aspect ratio, brightness, colour temperature, background or resolution differ from the rest, write a shared photo spec, and optionally export every photo at the same crop and size. Use when building or fixing a team page, "our team photos look inconsistent", "make all headshots the same size", "standardize staff photos", or when adding a new hire''s photo to an existing page. Uses the free ProfessionalHeadshot.io MCP for framing guidance and photo scores when connected; the local scan works without it.

When to use

  • building or fixing a team page
  • standardizing staff photos
  • making all headshots the same size
  • adding a new hire's photo to an existing page
  • scanning headshot folders for consistency
  • writing a shared photo spec
  • exporting photos at the same crop and size

When not to use

  • detecting faces
  • fixing lighting, colour or background differences
  • uploading team photos anywhere on the user's behalf
