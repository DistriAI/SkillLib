revedres-literature-synthesis

separate

Use when executing the systematic search, screening to a PRISMA flow, and extracting data for a Review of Educational Research (RER) review or meta-analysis. Builds the documented evidence corpus; it does not impose the conceptual spine (revedres-organizing-framework) or run robustness/risk-of-bias appraisal (revedres-comprehensiveness-and-balance).

When to use

  • systematic search
  • screening to a PRISMA flow
  • extracting data for a RER review
  • extracting data for a meta-analysis
  • building the documented evidence corpus
  • dual independent screening
  • snowballing to saturation
  • applying codebook to included studies

When not to use

  • imposing the conceptual spine
  • running robustness appraisal
  • running risk-of-bias appraisal
  • re-collecting primary study data
  • re-analyzing primary study raw data
