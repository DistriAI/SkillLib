cte-heterogeneity

separate

Use when designing or writing heterogeneity analysis for a 《财贸经济》 manuscript. Enforces China-finance-institution-relevant cut dimensions and theoretical-justification discipline. 本技能服务于《财贸经济》(Finance & Trade Economics, CTE)。

When to use

  • Designing heterogeneity analysis for CTE manuscripts
  • Selecting finance-institution-relevant cut dimensions
  • Writing heterogeneity sections with theoretical justification
  • Reviewing heterogeneity dimensions for CTE submission
  • Checking consistency between heterogeneity and mechanism analysis

When not to use

  • Cutting only by East/Central/West regions without theoretical reason
  • Using control variable interactions as heterogeneity
  • Interpreting results from extremely small subsamples
  • Cutting dimensions unrelated to finance or trade scenarios
  • Ignoring conflicts between heterogeneity and mechanism conclusions
