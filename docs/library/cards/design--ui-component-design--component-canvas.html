component-canvas

separate

Build a full-screen, interactive canvas to explore existing UI components and their variants with pan and zoom.

When to use

  • Explore existing UI components
  • Show component variants and states
  • Pan and zoom canvas
  • Compare component props
  • Preview components with sample data

When not to use

  • Modify component source or behavior
  • Patch libraries or browser APIs
  • Add components without permission
  • Change component design
  • Make canvas public
  • Use production credentials or data
