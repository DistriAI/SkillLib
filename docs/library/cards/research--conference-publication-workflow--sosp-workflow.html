sosp-workflow

separate

Use when planning a SOSP campaign across the annual cycle — back-scheduling from the spring abstract and paper deadlines, running the summer response and July notification, stacking the August camera-ready with artifact evaluation, and retargeting rejections across the SOSP/OSDI/EuroSys circuit.

When to use

  • planning a SOSP campaign
  • back-scheduling from spring deadlines
  • running summer response and July notification
  • stacking August camera-ready with artifact evaluation
  • retargeting rejections across SOSP/OSDI/EuroSys circuit
  • placing a project on the SOSP calendar
  • deciding actions in the current phase

When not to use

  • back-scheduling against implied dates
  • submitting the same work to overlapping review cycles
