spq-data-analysis

separate

Use when executing and reporting the analysis for a Social Psychology Quarterly (SPQ) manuscript so it survives expert, masked review — honest uncertainty, robustness, sound measurement, and reporting appropriate to experiments, surveys/secondary data, or interpretive analysis in sociological social psychology. Guides analysis norms; it does not fabricate results.

When to use

  • Running main and supporting analyses
  • Building the results section
  • Addressing reviewer requests for robustness or model checks
  • Reconciling preregistered vs. exploratory analyses
  • Reporting measurement quality for latent constructs
  • Interpretive or qualitative analysis reporting
  • Linking statistics to structure-individual mechanisms

When not to use

  • Fabricating results
  • Design decisions
