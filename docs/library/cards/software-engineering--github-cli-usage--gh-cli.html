gh-cli

combined

The gh CLI is GitHub's official command line tool for interacting with GitHub repositories, issues, pull requests, and more. When needs to interact with GitHub repositories, issues, pull requests, and more, use this skill. Enforces authenticated gh CLI workflows over unauthenticated curl, WebFetch, and MCP fetch patterns. Use when working with GitHub URLs, API access, pull requests, or issues.

When to use

  • Working with GitHub repositories, pull requests, issues, releases, or raw file URLs.
  • You need authenticated access to private repositories or higher API rate limits.
  • You are about to use `curl`, `wget`, `WebFetch`, or an MCP fetch tool against GitHub.

When not to use

  • The target is not GitHub.
  • Plain local git operations already solve the task.

Skill page

Conflict

The two skills serve different purposes. The trailofbits skill is a behavioral guardrail that enforces the use of the `gh` CLI over unauthenticated HTTP methods (curl/WebFetch) for security and rate-limit reasons. The benchflow skill is a reference manual that documents specific `gh` subcommands, flags, and search syntax. Neither contains the material steps of the other; the first lacks command documentation, and the second lacks the enforcement logic for when to use the tool. Combining them creates a complete skill that both mandates the correct tool usage and provides the necessary reference for executing it.
