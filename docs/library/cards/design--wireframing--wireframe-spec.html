wireframe-spec

separate

Specify wireframe layout — content priority, component placement, and annotation. Use when defining structure before visual design. For grid mechanics, use `layout-grid` (ui-design).

When to use

  • defining structure before visual design
  • specifying content priority
  • component placement
  • behavior annotations
  • responsive considerations
  • annotated wireframe specifications

When not to use

  • grid mechanics
  • visual design
