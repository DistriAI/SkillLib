marketing-message-test

separate

Salesforce Marketing Cloud / Engagement 360 message preview and test-send. Use this skill when the user wants to render a personalized or unpersonalized preview of an E360 message (Email, SMS, WhatsApp, Push, In-App, RCS) from a content key, or fire a test send, over the headless API — no app UI. TRIGGER when: user has a contentKey and wants to see how a message renders for a recipient, preview a message headlessly, or send a test message. DO NOT TRIGGER when: the task is authoring message content, building Data Cloud segments/DMOs (use data360-segment / data360-harmonize), or activating a segment (use data360-activate).

When to use

  • render personalized preview
  • render unpersonalized preview
  • send test message
  • preview Email message
  • preview SMS message
  • preview WhatsApp message
  • preview Push message
  • preview In-App message

When not to use

  • authoring message content
  • building Data Cloud segments
  • building DMOs
  • identity resolution
  • activating a segment
