compare-cohorts

separate

Use when comparing process cohorts, departments, periods or before-and-after results under matched definitions.

When to use

  • comparing process cohorts
  • comparing departments
  • comparing periods
  • before-and-after results
  • matched definitions

When not to use

  • object-centric comparisons
  • case-filter fallbacks
  • creating views
  • using two inclusive timeframes in one query as an A/B comparison
