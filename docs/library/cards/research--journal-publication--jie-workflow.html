jie-workflow

separate

Use when deciding which jie-* sub-skill a Journal of International Economics (JIE) manuscript needs next — given where it stands (idea, identification, data, framing, exhibits, polish, replication, review, submission, rebuttal), this router names the next skill in the trade / international macro-finance pipeline. Routes only; it does not produce manuscript content.

When to use

  • deciding which jie-* sub-skill to use next
  • determining canonical order for trade pipeline
  • determining canonical order for international macro-finance pipeline
  • identifying next step when mid-process
  • triaging by symptom to jump in
  • checking scope fit and originality gate
  • routing for Editorial Manager preflight
  • routing for R&R response letter

When not to use

  • producing manuscript content
  • writing prose or abstracts
  • performing data analysis
  • building tables or figures
  • depositing replication code
  • handling refereeing directly
