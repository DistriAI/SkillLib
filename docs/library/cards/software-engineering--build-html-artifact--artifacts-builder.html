artifacts-builder

authentic

Suite of tools for creating elaborate, multi-component claude.ai HTML artifacts using modern frontend web technologies (React, Tailwind CSS, shadcn/ui). Use for complex artifacts requiring state management, routing, or shadcn/ui components - not for simple single-file HTML/JSX artifacts.

When to use

  • creating elaborate multi-component claude.ai HTML artifacts
  • complex artifacts requiring state management
  • complex artifacts requiring routing
  • artifacts using shadcn/ui components
  • building frontend claude.ai artifacts with React and Tailwind CSS

When not to use

  • simple single-file HTML/JSX artifacts
