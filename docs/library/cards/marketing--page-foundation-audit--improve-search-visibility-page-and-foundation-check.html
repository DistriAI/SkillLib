improve-search-visibility-page-and-foundation-check

separate

Step of the improve-search-visibility playbook: audits site indexing, crawling, technical and page issues at the requested scope, or checks pages behind lost visibility questions. Run improve-search-visibility instead; not for direct use.

When to use

  • audits site indexing
  • audits crawling
  • audits technical issues
  • audits page issues
  • checks pages behind lost visibility questions
  • site-wide robots.txt and sitemap checks
  • per-page status, canonical, and structured data checks
  • near-winner query analysis

When not to use

  • direct use
  • proposing structural changes as anything but a proposal with risk and undo
  • marking an item passed that it did not see
