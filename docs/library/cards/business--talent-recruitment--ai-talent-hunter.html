ai-talent-hunter

separate

从 GitHub 找到最匹配的技术人才，生成个性化触达话术。适用于招聘工程师、寻找技术合伙人、猎头交付候选人等场景。

When to use

  • 招聘工程师
  • 寻找技术合伙人
  • 猎头交付候选人
  • 基于真实代码搜人
  • 智能排序候选人
  • 全球定位筛选
  • 人工筛选候选人
  • 生成个性化触达话术

When not to use

  • 自动发送邮件或消息
  • 购买或爬取私密数据
  • 绕过反爬机制
  • 批量骚扰候选人
