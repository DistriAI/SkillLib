separate

Cross-chain swap, bridge, and DeFi orchestration via Sequence for agents to swap tokens, bridge assets, fund wallets, and deposit into yield vaults. Integrates with Bankr submit() for on-chain execution.

When to use

  • swap tokens across chains
  • bridge assets
  • fund a Bankr wallet from any chain
  • deposit into yield vaults (Aave, Morpho)
  • get token prices
  • discover earn pools
  • quote cross-chain routes
  • Sequence swaps
