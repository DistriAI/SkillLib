cre-heterogeneity

separate

Use when designing or writing heterogeneity analysis for a 《中国农村经济》 manuscript. Enforces rural-relevant cut dimensions and theoretical-justification discipline.

When to use

  • Designing heterogeneity analysis for 《中国农村经济》
  • Selecting rural-relevant cut dimensions
  • Writing heterogeneity sections with theoretical justification
  • Reviewing heterogeneity for rural economic manuscripts
  • Checking consistency between heterogeneity and mechanism analysis

When not to use

  • Cutting only by East/Central/West regions
  • Using non-rural dimensions like corporate listing status
  • Interpreting sub-samples with N < 100
  • Adding interaction terms to control variables without theoretical basis
