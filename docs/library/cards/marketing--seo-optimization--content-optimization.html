content-optimization

separate

When the user wants to optimize content for SEO—word count, H2 keywords, keyword density, multimedia, tables, lists. Also use when the user mentions "content length," "word count," "keyword stuffing," "H2 keywords," "keyword density," "tables," "bullet points," or "content structure." For keywords, use keyword-research.

When to use

  • **Word count**: For articles, see **article-content** (word count by type). This skill covers generic content length strategy.
  • **H2 keywords**: Placement, quantity, variation
  • **Keyword density vs stuffing**: Natural use; avoid manipulation
  • **Multimedia**: Images, tables, lists, video for structure and Featured Snippets. See **featured-snippet** for snippet-specific optimization; **video-optimization** for video SEO.

When not to use

  • keyword research
  • article word count by type
  • featured snippet optimization
  • video SEO
  • image optimization
  • heading structure
  • content strategy planning
