transcribe

combined

Local speech-to-text transcription on Apple Silicon macOS. Supports wav directly and other audio formats via ffmpeg. Transcribe audio files to text with optional diarization and known-speaker hints. Use when a user asks to transcribe speech from audio/video, extract text from recordings, or label speakers in interviews or meetings.

When to use

  • Local speech-to-text transcription on Apple Silicon macOS
  • Transcribe speech from audio/video
  • Extract text from recordings
  • Label speakers in interviews or meetings
  • Speaker diarization
  • Fast text transcription
  • Diarized JSON output

When not to use

  • Prompting for gpt-4o-transcribe-diarize

Skill page

Conflict

The openai/skills and foryourhealth111-pixel/Vibe-Skills copies are identical and describe an OpenAI API-based transcription workflow with diarization. The badlogic/pi-skills copy describes a completely different, local-only workflow using a macOS arm64 binary (parakeet-cpp-transcribe) with no API key or diarization. These are distinct procedures for the same high-level task, so crowning one would hide a real alternative.
