sosp-artifact-evaluation

separate

Use when preparing a SOSP artifact for the post-acceptance evaluation run by the sysartifacts community, registering within days of notification, packaging for the cooperative review process, and targeting the ACM badges — Artifacts Available, Artifacts Evaluated Functional, and Artifacts Evaluated Reusable.

When to use

  • preparing a SOSP artifact for post-acceptance evaluation
  • registering the artifact within days of notification
  • packaging for the cooperative review process
  • targeting ACM badges (Artifacts Available, Functional, Reusable)
  • tiering artifact claims for OS-adjacent systems
  • building a kick-the-tires smoke test path
  • managing the AE HotCRP interaction window

When not to use

  • changing the paper acceptance decision
  • certifying performance portability on other silicon
  • promising badges before the year's call is pinned
