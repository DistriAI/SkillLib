geb-tables-figures

separate

Use when building exhibits for a Games and Economic Behavior (GEB) manuscript — payoff matrices, extensive-form game trees, equilibrium/result tables, and experimental plots. Makes strategic structure and results readable to a game-theory audience.

When to use

  • building exhibits for GEB manuscripts
  • creating payoff matrices
  • creating extensive-form game trees
  • creating equilibrium and result tables
  • creating experimental plots
  • formatting exhibits for elsarticle
  • reviewing exhibit standards for GEB

When not to use

  • prose writing style
  • proof derivation
  • model specification
  • non-GEB journal formatting
