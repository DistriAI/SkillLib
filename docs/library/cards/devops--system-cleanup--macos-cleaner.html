macos-cleaner

separate

Diagnoses and safely reclaims macOS disk space: caches, logs, app remnants, large/duplicate files, Docker/OrbStack, Chromium code-sign clones, developer caches. Use when a Mac is low on storage, shows “Caching needs more space”, or before deleting anything to avoid data loss. Not for Windows/Linux or permission issues (use macos-permissions).

When not to use

  • The target is Windows or Linux.
  • The requested action requires disabling SIP or bypassing macOS protections.
  • The user asks for silent or automatic deletion without an auditable scope and confirmation gate.
  • The task is only to tune application behavior and has no disk-space diagnosis or recovery goal.
