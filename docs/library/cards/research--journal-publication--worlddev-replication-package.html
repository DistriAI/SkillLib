worlddev-replication-package

separate

Use when preparing the data/code or qualitative-transparency materials for a World Development (WD) manuscript under Elsevier's research-data policy and double-anonymized review. Assembles the package; it does not invent evidence or citations.

When to use

  • Preparing data-availability statements
  • Organizing reproducible code packages
  • Creating qualitative transparency materials
  • Managing double-anonymized review versions
  • Documenting ethical constraints on data sharing
  • Assembling mixed-methods integration documentation

When not to use

  • Inventing evidence
  • Inventing citations
  • Posting raw transcripts that violate confidentiality
  • Posting geocoded conflict data or identifiable informant material
