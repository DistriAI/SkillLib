jev-compaction

separate

Use when a transcript has to be cut to a fixed size and you must choose which turns go. Jev marks each turn keep, summarize or drop. Measured: it does not make a handoff better.

When to use

  • cutting a transcript to a fixed size
  • choosing which turns go
  • marking turns keep, summarize or drop
  • creating a digest for a person to skim
  • using a small local writer
  • managing a context you cannot grow

When not to use

  • writing a handoff
  • improving handoff recall
  • asking a model whether the window is full
