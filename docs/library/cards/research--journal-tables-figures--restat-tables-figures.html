restat-tables-figures

separate

Use when building or revising the exhibits of a The Review of Economics and Statistics (REStat) manuscript so the main result is legible in one table or figure in AEA/REStat house style. Designs publication-grade exhibits; it does not run the underlying estimation.

When to use

  • building exhibits for REStat manuscripts
  • revising tables and figures
  • designing publication-grade exhibits
  • preparing exhibits for online appendix
  • creating event-study plots
  • creating RD plots
  • creating coefficient-stability figures
  • ensuring exhibits are self-contained

When not to use

  • running the underlying estimation
