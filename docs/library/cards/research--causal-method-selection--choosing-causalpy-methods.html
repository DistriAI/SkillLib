choosing-causalpy-methods

separate

Choose the appropriate CausalPy experiment class from a causal question, data structure, treatment assignment, and identification assumptions. Use before writing analysis code when the method is not yet settled.

When to use

  • translating causal questions into CausalPy experiment choices
  • design-intake for causal analysis
  • selecting methods based on data shape and treatment assignment
  • checking identifying stories and assumptions
  • recommending primary and alternative CausalPy experiments

When not to use

  • implementation of analysis code
  • constructor details
  • model configuration
  • priors
  • summaries
  • plots
  • interpretation
