journey-map

separate

Map one persona's end-to-end experience with stages, touchpoints, emotions, and pain points. Use when improving an existing experience. For the multi-channel ecosystem use `experience-map` (ux-strategy); for screen-level paths use `user-flow-diagram` (prototyping-testing).

When to use

  • improving an existing experience
  • mapping one persona's end-to-end experience
  • identifying journey stages
  • mapping touchpoints and channels
  • visualizing the emotional curve
  • prioritizing design opportunities
  • identifying moments of truth

When not to use

  • multi-channel ecosystem
  • screen-level paths
