Conflict

The two copies address the same task (writing a SKILL.md) but from different, non-overlapping angles. The first copy (mohitagw15856) is a procedural guide focused on the 'anatomy' of a skill (frontmatter, description triggers, output templates, quality controls) and provides a specific workflow for generating a new skill. The second copy (sickn33) is a conceptual reference focused on 'predictability,' 'context load,' and 'information hierarchy,' providing principles for when to use model-invocation vs. user-invocation and how to structure content (steps vs. reference). Neither copy contains the specific steps or constraints of the other; the first lacks the conceptual framework of the second, and the second lacks the concrete template and generation workflow of the first. Combining them provides a complete guide that covers both the 'how to write' (structure) and the 'why/how to design' (principles).
