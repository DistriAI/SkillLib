which

authentic

Route a fuzzy request to the right skill in this library. Use when the user is unsure which skill fits, asks 'which skill should I use for X', describes a task without naming a skill, or when a request could plausibly match several skills. Produces a best-fit recommendation with the inputs to gather, a runner-up with the tie-breaker, and a workflow recipe when the job spans multiple skills.

When to use

  • Routing fuzzy requests to the right skill
  • Answering 'which skill should I use for X'
  • Describing a task without naming a skill
  • Handling requests that could match several skills
  • Producing best-fit skill recommendations
  • Identifying inputs to gather before running a skill
  • Providing runner-up skills with tie-breakers
  • Recommending workflow recipes for multi-skill jobs

When not to use

  • Browsing 400+ skill options manually
  • Routing from memory without checking the catalog
  • Recommending more than two skills
  • Routing on topic keywords instead of deliverables
  • Asking a chain of clarifying questions
  • Inventing skill names not in the catalog
  • Recommending general skills when specific ones exist
