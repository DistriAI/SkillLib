acm-sigsoft-international-symposium-on-software-testing-and-analysis

separate

Use when targeting ACM SIGSOFT International Symposium on Software Testing and Analysis (ISSTA) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for software testing.

When to use

  • targeting ISSTA
  • deciding if a manuscript fits ISSTA
  • conference-fit read for software testing
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • software testing, analysis, fuzzing, verification, debugging, or program repair papers

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • every SE tool paper
  • software evolution and maintenance studies
  • general automated SE
  • flagship SE work where testing/analysis is not central
