platform-soql-query

authentic

Use when the user needs SOQL/SOSL authoring or optimization: natural-language-to-query generation, relationship queries, aggregates, query-plan/selectivity analysis, and performance or safety improvements. TRIGGER when the user writes, optimizes, or debugs SOQL/SOSL, touches .soql files, or asks about relationship queries, aggregates, or query performance. DO NOT TRIGGER for bulk data operations (use platform-data-manage), Apex DML logic (use platform-apex-generate), or report/dashboard queries.

When to use

  • SOQL/SOSL authoring
  • query optimization
  • natural-language-to-query generation
  • relationship queries
  • aggregate queries
  • query-plan analysis
  • selectivity analysis
  • performance improvements

When not to use

  • bulk data operations
  • Apex DML logic
  • report/dashboard queries
  • debugging via logs
  • embedding query logic inside broader Apex implementation
