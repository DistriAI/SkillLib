initiation-site-mapping

separate

Map translation initiation sites, including non-AUG and alternative starts, from initiation-drug ribosome profiling (TI-seq). Use when locating start codons, detecting near-cognate or upstream initiation, or analyzing harringtonine, lactimidomycin (GTI-seq/QTI-seq), or retapamulin (Ribo-RET) data.

When to use

  • locating start codons
  • detecting near-cognate or upstream initiation
  • analyzing harringtonine data
  • analyzing lactimidomycin (GTI-seq/QTI-seq) data
  • analyzing retapamulin (Ribo-RET) data
  • TIS detection from harringtonine/LTM data
  • cryptic/near-cognate starts detection
  • bacterial initiation analysis

When not to use

  • elongation ORF detection
  • inferring start codons from elongation periodicity without initiation-drug library
