eer-submission

separate

Use when running the final pre-submission preflight for the European Economic Review (EER) via Editorial Manager — submission fee, single-anonymized review, Elsevier format and house-style rules, declarations, and the data/replication policy. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • checking submission fee
  • verifying single-anonymized review requirements
  • confirming Elsevier format and house-style rules
  • checking declarations
  • verifying data and replication policy
  • last check before pressing submit on Editorial Manager

When not to use

  • drafting content
