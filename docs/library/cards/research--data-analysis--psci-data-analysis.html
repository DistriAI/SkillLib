psci-data-analysis

separate

Use when analyzing and reporting results for a Psychological Science manuscript. The journal requires effect sizes with confidence intervals, full disclosure of exclusions/conditions/measures, and a clear confirmatory/exploratory split, with analysis scripts and data shared. Guides analysis norms; it does not fabricate results.

When to use

  • Running and reporting main and supporting analyses
  • Reconciling preregistered analyses with exploratory follow-ups
  • Preparing analysis scripts and a data dictionary for deposit
  • Reporting effect sizes with confidence intervals
  • Full disclosure of exclusions, conditions, and measures
  • Labeling confirmatory vs. exploratory analyses
  • Justifying models and reporting assumptions/diagnostics
  • Showing robustness to alternative specifications

When not to use

  • Fabricating results
