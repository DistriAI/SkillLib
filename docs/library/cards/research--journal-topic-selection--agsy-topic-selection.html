agsy-topic-selection

separate

Use when deciding whether a project fits Agricultural Systems (AgSy) and which article type to target. AgSy is a systems-science journal, so the test is a genuine systems question — interactions among components, across hierarchical levels (field → farm → landscape → region → food system), trade-offs, and emergent behavior — analyzed with integrated modelling, NOT a single-factor field trial. Helps frame the question; it does not collect data.

When to use

  • Choosing among possible projects or framings for an AgSy submission
  • Pressure-testing fit before investing in a project
  • Deciding between a research paper and a short communication
  • Considering a perspective or comment on a published paper
  • Framing a systems question about interactions and trade-offs
  • Evaluating scale and system-boundary framing
  • Routing near-miss projects to sibling venues

When not to use

  • Collecting data
  • Single-factor field trials with no interactions
  • Descriptive synthesis without systems analysis
  • Model demos with no agricultural-systems question
