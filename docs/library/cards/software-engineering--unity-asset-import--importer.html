importer

separate

Configure asset import settings

When to use

  • Adjusting how assets import
  • Setting texture compression or sprite modes
  • Applying per-platform overrides
  • Changing import settings for textures
  • Changing import settings for audio
  • Changing import settings for models
  • Batch configuring assets of the same category

When not to use

  • File import or refresh
  • Bringing files into the project
  • Deleting assets
  • PlayMode operations
  • Reload operations
