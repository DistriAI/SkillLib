llm-wiki-setup

separate

Co-creates a personal investment-research LLM Wiki (Karpathy's pattern) by interviewing the user for THEIR OWN analysis framework, not a template — a living CLAUDE.md of pure markdown + wikilinks, no RAG in place of compilation. Use to build a compounding 投研第二大脑 / 投研知识库 / 个人投研 wiki, ingest research reports / earnings calls into an existing wiki, or run post-earnings prediction→fulfillment reviews.

When to use

  • Build a personal investment-research LLM Wiki
  • Ingest research reports or earnings calls into an existing wiki
  • Run post-earnings prediction-to-fulfillment reviews
  • Scaffold the mechanism layer of a wiki vault
  • Interview users to create a custom CLAUDE.md
  • Enable anti-rot mechanisms like linting and git hooks
  • Demonstrate first ingest with user-provided sources

When not to use

  • Using RAG to replace compilation
  • Applying a standard investment research template
  • Copying examples verbatim
  • Adding knowledge graphs
  • Adding automatic health-check mechanisms
  • Over-engineering the wiki structure
