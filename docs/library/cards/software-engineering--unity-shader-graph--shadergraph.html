shadergraph

separate

Create and inspect Shader Graph assets

When to use

  • Creating a Shader Graph
  • Inspecting graph structure
  • Making controlled blackboard/node edits
  • Creating Shader Sub Graph assets
  • Adding, moving, connecting, or disconnecting nodes
  • Setting node defaults and settings
  • Managing graph properties and keywords
  • Reimporting Shader Graph assets

When not to use

  • HLSL text shaders
  • Editing SubGraphOutputNode structure
  • Retrying reflection or type lookup failures with different argument shapes
