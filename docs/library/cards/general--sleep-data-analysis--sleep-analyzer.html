sleep-analyzer

combined

分析睡眠数据、识别睡眠模式、评估睡眠质量，并提供个性化睡眠改善建议。支持与其他健康数据的关联分析。

When to use

  • 需要分析睡眠时长、效率、作息规律或睡眠质量时使用。
  • 任务涉及失眠模式、夜间觉醒、PSQI 评分或睡眠问题识别。
  • 需要把睡眠数据与情绪、运动或其他健康因素做关联分析时使用。

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.

Skill page

Conflict

The two copies share the same name and high-level purpose but diverge significantly in procedure. The first copy is a thin wrapper that defers to an external 'detailed-guide.md' and provides no concrete steps, data sources, or algorithms. The second copy is a self-contained, detailed procedure specifying data file paths, specific analysis algorithms (linear regression, Pearson correlation), diagnostic criteria (STOP-BANG, PSQI), and a structured output format. Because the first copy lacks the material steps present in the second, and the second does not reference the external guide, crowning one would hide the other's approach (external reference vs. inline procedure).
