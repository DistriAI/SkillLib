jacs-figures

separate

Use when building schemes, spectra, structures, and reaction/mechanism figures in ACS style for a Journal of the American Chemical Society (JACS) manuscript. Designs and audits graphics — it does not generate the underlying data.

When to use

  • building reaction schemes
  • building mechanism cycles
  • building structure drawings
  • auditing spectra and plots
  • designing TOC/abstract graphics
  • ensuring ACS drawing conventions
  • crafting scope figures
  • checking figure accessibility

When not to use

  • generating underlying data
