codex-background

separate

Keep a Codex orchestrator's delegation to an installed delegate skill pending until its registered relay completes, without model-driven progress polling. Use with a selected implementer delegate skill when Codex is the orchestrator and the delegation should wait in the background; sets up its MCP server on first use.

When to use

  • Codex orchestrator background delegation
  • Waiting for delegate skill relay completion
  • Bootstraping delegate MCP server
  • Handling interrupted waits with delegate_wait
  • Reviewing adapter outcomes and resultText

When not to use

  • Model-driven sleep, status, or log polling
  • Wrapping requests in tool runners that yield early
  • Adopting or killing persisted PIDs
  • Falling back to shell polling if bootstrap fails
  • Claude's background Bash workflow
