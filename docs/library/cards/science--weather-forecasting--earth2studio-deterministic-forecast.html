Build deterministic forecast scripts with Earth2Studio (model, data source, IO, inference). Do NOT use for ensemble, diagnostics, data-only fetch, or install.

When to use

  • deterministic forecast scripts
  • model selection
  • data source compatibility
  • IO backend selection
  • nsteps calculation
  • generating earth2studio.run.deterministic scripts
  • manual loop implementation

When not to use

  • ensemble workflows
  • diagnostics
  • data-only fetch
  • installation
  • model training
