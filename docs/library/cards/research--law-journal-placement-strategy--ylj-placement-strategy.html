ylj-placement-strategy

separate

Use when planning where and when to submit a law-review piece and how to handle an expedite, with The Yale Law Journal (YLJ) as a target. It covers multi-submission timing, season strategy, and YLJ's specific expedite rules; it does not run the final upload preflight (ylj-submission).

When to use

  • Deciding the submission slate and tier
  • Timing submission to a season
  • Handling an expedite to YLJ
  • Weighing if piece is YLJ-ready
  • Planning multi-submission campaign

When not to use

  • Running the final upload preflight
  • ylj-submission
