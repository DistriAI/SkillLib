revedres-topic-selection

separate

Use when deciding whether a question is synthesis-worthy and RER-scale before committing to a Review of Educational Research (RER) review or meta-analysis. Tests fit and frames the contribution; it does not run the search (revedres-literature-synthesis) or write the protocol (revedres-proposal-and-commissioning).

When to use

  • deciding whether a question is synthesis-worthy
  • deciding whether a question is RER-scale
  • testing fit for RER review
  • framing the contribution
  • choosing the review type
  • positioning against prior reviews

When not to use

  • running the search
  • writing the protocol
  • original empirical research
