bio-clinical-databases-gnomad-frequencies

separate

Query gnomAD for population allele frequencies to assess variant rarity. Use when filtering variants by population frequency for rare disease analysis or determining if a variant is common in the general population.

When to use

  • Query gnomAD for population allele frequencies
  • Assess variant rarity
  • Filter variants by population frequency
  • Rare disease analysis
  • Determine if a variant is common in the general population
  • Retrieve exome and genome allele frequencies
  • Retrieve ancestry-specific allele frequencies
  • Apply population frequency thresholds
