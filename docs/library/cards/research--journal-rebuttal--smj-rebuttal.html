smj-rebuttal

separate

Use when drafting the response letter and revising a Strategic Management Journal (SMJ) manuscript after an R&R decision. Structures the point-by-point response; it assumes the revision plan from smj-review-process is set.

When to use

  • drafting the response letter
  • revising an SMJ manuscript after R&R
  • writing the response-to-reviewers letter
  • deciding how to respond to a comment you disagree with
  • structuring point-by-point responses
  • reconciling conflicting reviewers
  • addressing endogeneity or contribution concerns

When not to use

  • writing a response letter before actual edits exist
  • silently ignoring or partially answering a comment
  • asserting a concern is unfounded without new evidence
  • adding more control variables in place of a real identification fix
  • using defensive or combative tone
  • promising changes not in the revised manuscript
  • letting intro/discussion framing contradict claimed changes
  • treating contribution critique as solvable by piling on empirical results
