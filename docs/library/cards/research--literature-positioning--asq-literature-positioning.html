asq-literature-positioning

separate

Use when situating an Administrative Science Quarterly (ASQ) manuscript within organization-theory conversations and sharpening the gap/tension it addresses. Positions the argument; it does not develop the core theory or write the methods.

When to use

  • situating an ASQ manuscript within organization-theory conversations
  • sharpening the gap/tension it addresses
  • naming the specific scholarly conversation
  • characterizing the prevailing view
  • locating the tension in the conversation
  • staking the theoretical opening
  • engaging relevant organization-theory traditions
  • addressing near-scoop papers

When not to use

  • developing the core theory
  • writing the methods
