Conflict

The four copies describe the same generate-review-refine loop for scientific diagrams, but they disagree on the underlying models, the stopping rule, and the available CLI parameters. K-Dense-AI/scientific-agent-skills is the most complete and current (Nano Banana 2 + Gemini 3.7 Flash, max 2 iterations, explicit review-failure handling, data-leaves-machine warning, raster-only output caveat). foryourhealth111-pixel/Vibe-Skills and FreedomIntelligence/OpenClaw-Medical-Skills are older variants (Nano Banana Pro / Nano Banana 2 with Gemini 3 Pro / Gemini 3.1 Pro Preview) that omit the max-iteration cap and the review-error contract. aipoch/medical-research-skills diverges further: it names a code-capable LLM generator (default google/gemini-2.0-flash-001) with separate --generator and --reviewer overrides, requires pillow and matplotlib, and only documents journal/poster doc-types. Because each copy carries material steps or constraints the others lack, crowning one would hide real alternatives.
