sci-figures

separate

Use to finalize Science display items — panel/word budget, column-width sizing, minimum font sizes, color-accessibility, and showing the data (points over bars). Enforces figure rigor before submission.

When to use

  • Finalizing Science display items
  • Checking panel and word budgets
  • Sizing figures for column width
  • Enforcing minimum font sizes
  • Ensuring color accessibility
  • Showing data points over bars
  • Verifying figure integrity rules
  • Structuring figure legends

When not to use

  • Pasting raw software screenshots as figures
  • Using bars to hide small n with large spread
  • Leaving error bars undefined
  • Mixing SD and SEM across panels
  • Relying on red-vs-green as sole encoding
  • Selective deletion or splicing of images without disclosure
