asr-theory-building

separate

Use when building the theoretical argument of an American Sociological Review (ASR) manuscript into a portable contribution — for quantitative, demographic, comparative-historical, ethnographic, network, or computational work. ASR rewards a mechanism that travels over a setting-bound finding. Structures the argument; it does not run analyses.
