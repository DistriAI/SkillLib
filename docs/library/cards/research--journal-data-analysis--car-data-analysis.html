car-data-analysis

separate

Use when running and reporting the analysis for a Contemporary Accounting Research (CAR) manuscript — the right estimator for archival/capital-markets, experimental, or analytical-calibration work, robustness, and CAR's Data Integrity & Code Sharing Policy (code archiving, variable definitions, data availability statement). Executes and reports; it does not design the study (car-methods).

When to use

  • running and reporting analysis for CAR manuscripts
  • selecting estimators for archival, experimental, or analytical-calibration work
  • robustness and identification testing
  • preparing code archiving and variable definitions
  • data availability statement preparation
  • execution of statistical analysis via StatsPAI or Stata MCP

When not to use

  • designing the study
