agent-platform-migrate-from-ai-studio

separate

Guides agents and users through migrating from Gemini API in Google AI Studio to Gemini Enterprise Agent Platform (formerly Vertex AI). Use this skill when moving applications to Google Cloud, to leverage Cloud credits, or to unify inferencing with other Cloud infrastructure (IAM, billing, telemetry).

When to use

  • migrating from Google AI Studio to Agent Platform
  • applying Google Cloud credits to Gemini API inferencing
  • unifying inferencing pipelines with Google Cloud infrastructure
  • deploying open-source orchestration engines on Google Cloud VMs
  • enabling the Agent Platform API
  • configuring IAM permissions for inferencing
  • setting up billing alerts to avoid surprises
