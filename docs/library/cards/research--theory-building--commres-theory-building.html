commres-theory-building

separate

Use when building the theoretical argument and hypotheses of a Communication Research (CR) manuscript into a testable, mechanism-level contribution. CR rewards explicit constructs, a stated communication process, and numbered hypotheses with mediation/moderation, not a bare effect. Structures the argument; it does not run analyses.

When to use

  • building theoretical argument
  • defining key constructs
  • stating communication process
  • naming boundary conditions
  • translating mechanism into numbered hypotheses
  • connecting work to established communication theory
  • fixing atheoretical or ad hoc arguments

When not to use

  • running analyses
  • fitting PROCESS models post hoc
  • collecting data
