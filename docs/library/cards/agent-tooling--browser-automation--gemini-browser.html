gemini-browser

separate

Query Google Gemini via browser automation using OpenClaw's Browser Relay. Use when you need to ask Gemini questions and get AI responses. Requires OpenClaw with Browser Relay Chrome extension configured.

When to use

  • Query Google Gemini
  • Ask Gemini questions
  • Get AI responses
  • Extract Gemini responses
  • Browser automation for Gemini

When not to use

  • Isolated openclaw-managed profile
  • Remote access
  • Auto-attach to arbitrary tabs
