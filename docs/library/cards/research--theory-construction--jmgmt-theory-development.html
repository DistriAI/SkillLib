jmgmt-theory-development

separate

Use when the theoretical argument is the bottleneck for a Journal of Management (JOM) manuscript — building constructs, mechanisms, boundary conditions, and a priori hypotheses (or a review's organizing framework). Constructs the theory; it does not run the analysis (jmgmt-data-analysis) or write the contribution paragraph (jmgmt-contribution-framing).

When to use

  • building constructs
  • building mechanisms
  • building boundary conditions
  • building a priori hypotheses
  • building a review's organizing framework
  • theorizing mediators and moderators
  • addressing rival explanations
  • organizing meta-analysis by theory

When not to use

  • running the analysis
  • writing the contribution paragraph
