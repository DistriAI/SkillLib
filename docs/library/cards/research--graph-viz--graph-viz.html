graph-viz

separate

Converts knowledge graph data into an interactive D3.js force-directed HTML visualization with node exploration and paper preview capabilities.

When to use

  • Generate interactive D3.js force-directed graph HTML
  • Visualize knowledge graph nodes and edges
  • Explore graph nodes with side panel details
  • Preview associated papers from graph nodes
  • Search and highlight graph nodes
  • Embed paper data into visualization

When not to use

  • Creating new knowledge graphs
  • Installing D3.js locally
