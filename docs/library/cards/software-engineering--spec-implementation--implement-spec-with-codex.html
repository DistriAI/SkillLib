implement-spec-with-codex

separate

Run [implement-spec](../implement-spec/SKILL.md) with Codex doing the implementation passes while you orchestrate, integrate, and review. Use when the user asks to implement a spec with Codex, or to run implement-spec with Codex as the implementer.

When to use

  • implement a spec with Codex
  • run implement-spec with Codex as the implementer
  • orchestrate Codex implementation passes
  • integrate and review Codex diffs
  • run gates and maintenance checkpoints

When not to use

  • delegating spec loop orchestration
  • delegating plan reconciliation
  • delegating integration conflicts
  • delegating commit hygiene
  • delegating verification
