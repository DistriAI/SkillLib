Skill page

Conflict

The two copies define the same skill name but perform different tasks. The first is a technical procedure for building verified email lists using the Gooseworks/Orthogonal API (finding, verifying, and enriching contacts). The second is a copywriting procedure for writing the actual email content (subject lines, body copy, and sequencing) for a campaign. Neither is a reproduction of the other; they are complementary stages of a full email campaign workflow.
