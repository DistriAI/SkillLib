Query the Cancer Dependency Map (DepMap) for cancer cell line gene dependency scores (CRISPR Chronos), drug sensitivity data, and gene effect profiles. Use for identifying cancer-specific vulnerabilities, synthetic lethal interactions, and validating oncology drug targets. Retrieves and analyzes Cancer Dependency Map (DepMap) release data, including CRISPR Chronos gene effects, cancer model annotations, omics biomarkers, and PRISM drug sensitivity. Supports cancer-selective dependency, co-essentiality, and candidate synthetic-lethality analyses with release-aware identifiers and statistical checks.

When to use

  • **Target validation**: Is a gene essential for survival in cancer cell lines with a specific mutation (e.g., KRAS-mutant)?
  • **Biomarker discovery**: What genomic features predict sensitivity to knockout of a gene?
  • **Synthetic lethality**: Find genes that are selectively essential when another gene is mutated/deleted
  • **Drug sensitivity**: What cell line features predict response to a compound?
  • **Pan-cancer essentiality**: Is a gene broadly essential across all cancer types (bad target) or selectively essential?
  • **Correlation analysis**: Which pairs of genes have correlated dependency profiles (co-essentiality)?

Skill page

Conflict

The two skills cover the same domain (DepMap cancer dependency data) but diverge significantly on methodology and data access. The K-Dense-AI skill is a rigorous, release-aware procedure that explicitly warns against using the API endpoints suggested by the FreedomIntelligence skill, mandates checksum verification, and provides a detailed file contract table. The FreedomIntelligence skill provides a simpler, API-first approach with specific Python helper functions for selective dependency analysis and defines specific score thresholds (e.g., Chronos <= -0.5) that are absent in the K-Dense-AI skill. Because the K-Dense-AI skill explicitly states that the API endpoints used by the FreedomIntelligence skill are not verified or supported, and the FreedomIntelligence skill lacks the critical data integrity checks (MD5, release pinning) found in the K-Dense-AI skill, neither is a complete reproduction of the other. A combined skill is needed to provide the robust data acquisition and integrity checks from K-Dense-AI with the specific analytical workflows and thresholds from FreedomIntelligence.
