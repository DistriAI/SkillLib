amj-workflow

separate

Use when deciding which amj-* sub-skill to invoke next, or when sequencing manuscript work from topic selection through rebuttal for an Academy of Management Journal (AMJ) manuscript. Routes — it does not replace — the specialized skills.

When to use

  • deciding which amj-* sub-skill to invoke next
  • sequencing manuscript work from topic selection through rebuttal
  • routing AMJ manuscript tasks
  • planning next steps for a half-built AMJ manuscript
  • switching into response mode after an AMJ decision letter

When not to use

  • replacing specialized amj-* skills
  • performing topic selection
  • performing theory development
  • performing literature positioning
  • performing methods design
  • performing data analysis
  • performing contribution framing
  • performing tables and figures formatting
