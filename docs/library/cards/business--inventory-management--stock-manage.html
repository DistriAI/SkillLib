When to use

  • manage stock orders
  • manage trading rules
  • get stock information
  • add, delete, update, and query orders
  • add, delete, update, and query rules
  • fetch real-time stock data
  • filter orders by type, status, or platform
  • filter rules by type, stock code, or status
