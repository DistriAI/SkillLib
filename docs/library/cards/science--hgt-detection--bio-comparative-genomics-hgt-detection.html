bio-comparative-genomics-hgt-detection

separate

Detect horizontal gene transfer events using HGTector, compositional analysis, and phylogenetic incongruence methods. Identify foreign genes in bacterial and archaeal genomes from anomalous composition or unexpected phylogenetic placement.

When to use

  • searching for horizontally transferred genes
  • analyzing genome evolution in prokaryotes
  • identifying foreign genes in bacterial genomes
  • identifying foreign genes in archaeal genomes
  • detecting HGT using HGTector
  • detecting HGT using compositional analysis
  • detecting HGT using phylogenetic incongruence
