Use when targeting ACM SIGPLAN Symposium on Principles of Programming Languages (POPL) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for programming languages flagship.

When to use

  • targeting ACM SIGPLAN Symposium on Principles of Programming Languages (POPL)
  • deciding whether a computer-science manuscript fits this venue
  • conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks
  • programming language theory, type systems, semantics, verification, logic, and formal reasoning
  • re-framing from journal style or arXiv style into a selective CS conference narrative
  • evidence-gap, anonymity, artifact, rebuttal, or re-routing diagnosis

When not to use

  • substitute for the current year's CFP, author kit, ethics policy, or submission portal
  • manuscripts where the central contribution is not genuinely in programming languages flagship
  • functional-programming practice (route to ICFP)
  • broader language/software-engineering systems (route to OOPSLA)
  • verification-tool focus (route to CAV)
  • prototype, compiler, or runtime evidence as the center of gravity (route to PLDI)
