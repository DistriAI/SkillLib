jf-robustness

separate

Use when planning or auditing the robustness, sensitivity, and multiple-testing battery for a The Journal of Finance (JF) manuscript. Decides which checks are load-bearing; it does not design the main test.

When to use

  • planning robustness checks
  • auditing sensitivity analysis
  • multiple-testing battery
  • deciding load-bearing checks
  • triaging body vs Internet Appendix
  • applying adjusted thresholds
  • addressing factor-zoo critique

When not to use

  • designing the main test
