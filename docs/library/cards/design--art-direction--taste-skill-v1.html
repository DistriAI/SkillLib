taste-skill-v1

separate

The original taste-skill v1, kept for projects that depend on its exact behaviour. Opt-in: it runs only when called by name.

When to use

  • React or Next.js frontend generation
  • Tailwind CSS styling
  • Design variance and motion intensity configuration
  • Interactive UI state implementation
  • Typography and color calibration
  • Layout diversification
  • Dependency verification and installation

When not to use

  • Non-React/Next.js projects
  • Using emojis in code or markup
  • Using serif fonts for Dashboard/Software UIs
  • Using purple/blue AI aesthetic
  • Using h-screen for full-height Hero sections
  • Using complex flexbox percentage math
  • Assuming libraries exist without checking package.json
