gate

separate

Run the one-command quality gate and report the real N/N result. Use before claiming any build/review is done.

When to use

  • Run the full quality gate
  • Report the exact N/N line
  • List failing checks verbatim
  • Fix the cause of failures
  • Run pixel-truth checks for rendered HTML
  • Verify states and responsive behavior
  • Inspect every state and click each control

When not to use

  • Guessing contents of a file that could not be opened
  • Suppressing a check
  • Announcing success between failures
  • Claiming auto-100% on aesthetics
