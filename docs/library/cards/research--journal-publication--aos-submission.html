aos-submission

separate

Use when running the final pre-submission preflight for an Accounting, Organizations and Society (AOS) manuscript — Editorial Manager files (anonymized manuscript, separate title page, declarations), Elsevier policies (competing interests, AI, ethics), and open-access decisions. Checks readiness to submit; it does not handle the post-decision response (aos-rebuttal).
