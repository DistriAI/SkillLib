ectj-topic-selection

separate

Use when deciding whether an econometrics paper fits The Econometrics Journal's leading-case, applied-value bar rather than Journal of Econometrics, Econometric Theory, Quantitative Economics, Review of Economics and Statistics, or a field journal.

When to use

  • deciding if a paper fits The Econometrics Journal
  • evaluating leading-case contribution
  • checking applied value of econometrics paper
  • routing between EctJ and Econometric Theory
  • routing between EctJ and Journal of Econometrics
  • routing between EctJ and field journals
  • assessing fit for compact format
  • scoring fit for staggered-adoption designs

When not to use

  • generic repository for any econometric technique
  • papers where Monte Carlo evidence substitutes for applied relevance
  • contributions almost entirely formal needing longer theorem development
  • papers broader, longer, or more exhaustive than compact format
  • econometric novelty mainly a tool for substantive economics result
  • methods with applied value only in one proprietary dataset
  • topics exhaustively treated in long-format journals without new leading case
  • prediction-accuracy papers without an econometric object
