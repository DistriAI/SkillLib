Use when targeting International Conference on Automated Machine Learning (AutoML Conference) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for automated ML.

When to use

  • targeting International Conference on Automated Machine Learning
  • deciding whether a manuscript fits this venue
  • neural architecture search conference-fit read
  • re-framing journal or arXiv style into CS conference narrative
  • evidence-gap, anonymity, artifact, rebuttal, or re-routing diagnosis
  • automated ML submission strategy
  • hyperparameter optimization venue selection
  • AutoML systems and meta-learning fit assessment

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • lifelong-agent adaptation routing
  • production training/inference infrastructure routing
  • general representation-learning algorithms unless automation is central
  • generic CS paper without specific AutoML subcommunity focus
