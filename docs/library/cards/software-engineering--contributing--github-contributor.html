github-contributor

separate

Ships pull requests to open-source projects you don't maintain — CONTRIBUTING compliance, PR-size/scope checks, minimal-diff implementation, AI-disclosure PR descriptions, and rebase or bot-review replies. Use for 提 PR / 上游 PR / 贡献代码, "open a PR", "fix this upstream", "rebase against main", "respond to the bot review". Not for reviewing PRs as maintainer (use github-review-pr) or general GitHub CRUD (use github-ops).

When to use

  • 提 PR
  • 上游 PR
  • 贡献代码
  • open a PR
  • fix this upstream
  • rebase against main
  • respond to the bot review
  • CONTRIBUTING compliance

When not to use

  • reviewing PRs as maintainer
  • general GitHub CRUD
  • your own repos
  • internal team PRs with shared context
  • hot-fix branches where a maintainer is waiting on you
  • trivial single-line changes
