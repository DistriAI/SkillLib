edbt-writing-style

separate

Use when revising an EDBT paper for a data-management contribution on the first page, a reproducibly described mechanism, an evaluation that survives a database-systems reviewer, honest scope, and disciplined use of the per-shape page budget (Regular / Experiments-&-Analysis / Vision) in the OpenProceedings template.

When to use

  • revising an EDBT paper
  • stating data-management contribution on the first page
  • describing a reproducible mechanism
  • ensuring evaluation survives a database-systems reviewer
  • maintaining honest scope
  • using per-shape page budget
  • using OpenProceedings template

When not to use

  • vague performance claims
  • re-skinned ML results with a database title
  • using acmart or IEEEtran templates
