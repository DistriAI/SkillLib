review-walkthrough

separate

Generates an interactive HTML walkthrough for reviewing code changes. Use only when explicitly called.

When to use

  • reviewing code changes
  • generating interactive HTML walkthrough
  • splitting diff into logical steps
  • providing explanations and review findings

When not to use

  • running project tests
  • installing dependencies
  • changing branches
  • resetting checkout
  • altering source files
