retro

combined

Throwback design with vintage-inspired typography, high-contrast retro palettes, and nostalgic visual elements. Conduct a retrospective on a coding session.

When to use

  • retrospective on a coding session
  • suggesting environment improvements
  • retro design system guidelines
  • vintage-inspired typography
  • high-contrast retro palettes

When not to use

  • general coding tasks
  • non-retro design styles

Skill page

Conflict

The copies share the name 'retro' but describe three different procedures. mattpocock/skills and dzhng/skills are near-identical engineering retrospectives that analyze a coding session to improve the agent's environment (navigation, automated checks, coding standards, tool economy, etc.). phuryn/pm-skills is a product-management sprint retrospective that uses formats like Start/Stop/Continue or 4Ls and produces prioritized action items with owners and deadlines. bergside/awesome-design-skills is a design-system skill for creating retro/vintage visual guidelines, which is unrelated to the other two. Because the copies overlap only in name and each contains material steps the others lack, crowning one would hide real alternatives.
