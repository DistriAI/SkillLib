Skill page

Conflict

The copies describe two different integration paths for the same task. The openai and composio copies are identical and rely on the Linear MCP server with a structured 5-step workflow (setup, clarify, select tools, batch execute, summarize). The LeoYeAI copy relies on a local bash script (linear.sh) and the Linear GraphQL API, and it adds a detailed Git worktree workflow that ties Linear branch names to GitHub PR automation. Because the LeoYeAI copy contains material steps (bash commands, worktree creation, branch naming) that the MCP copies lack, and the MCP copies contain a structured tool-calling workflow that the bash copy lacks, crowning one would hide a real alternative.
