app-evolver

separate

Improves an existing application using its code, product contract, authorized work history and competitor evidence. Use for 取长补短、取其精华去其糟粕、参考竞品优化应用 or evolving an app from successful and failed work. Carries authorized changes through implementation and user-result verification, including REA and reverse Skill composition; use skill-evolver for Skills.

When to use

  • 取长补短
  • 取其精华去其糟粕
  • 参考竞品优化应用
  • evolving an app from successful and failed work
  • implementing authorized improvements
  • verifying user results
  • REA and reverse Skill composition

When not to use

  • Skills
  • competitor intelligence alone
  • new product specification
  • repository engineering
  • research
  • history access
  • release operations
