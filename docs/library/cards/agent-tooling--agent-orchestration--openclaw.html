openclaw

separate

Audits, diffs, copies, and lists providers/models, adds models, and switches the default model in local openclaw.json configs; diagnoses gateway/plugin failures (down, parked, broken, or out of date after an upgrade). Use for 虾/龙虾 config audits. Not for model-error repair (use openclaw-model-switch).

When to use

  • audit openclaw.json configs
  • diff two lobster configs
  • copy providers between configs
  • add models to providers
  • list providers and models
  • switch default model
  • diagnose gateway/plugin failures

When not to use

  • model-error repair
