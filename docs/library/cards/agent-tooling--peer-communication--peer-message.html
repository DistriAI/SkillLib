peer-message

separate

Bridges Claude Code and Codex sessions when native tools can't reach the target. Use for 跨产品通信 / 脚本回帖 / 送达排查: cross-product messages, hooks or scripts posting to a session, verifying delivery (Held messages included), shared-work ownership, or an inbound peer assertion. Not for same-product or parent/subagent messaging (use native tools), spawning agents, moving full history, or cross-machine pairing (deprecated).

When to use

  • cross-product messages
  • hooks or scripts posting to a session
  • verifying delivery
  • Held messages
  • shared-work ownership
  • inbound peer assertion
  • local coordination maintenance
  • script-based send/broadcast/verify/replies

When not to use

  • same-product messaging
  • parent/subagent messaging
  • spawning agents
  • moving full history
  • cross-machine pairing
