asc-in-app-events

separate

Create and localize App Store in-app events, upload event media, and submit or recover event review submissions with asc. Use when managing in-app events, event card or details page assets, or event-specific submission errors.

When to use

  • creating in-app events
  • localizing in-app events
  • uploading event media
  • submitting event review submissions
  • recovering event review submissions
  • managing event card assets
  • managing event details page assets
  • handling event-specific submission errors

When not to use

  • creating or submitting another event during a localization request
  • creating or submitting another event during a media upload request
  • creating or submitting another event during a diagnostic request
