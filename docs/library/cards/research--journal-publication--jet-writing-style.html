jet-writing-style

separate

Use when applying the Journal of Economic Theory (JET) house style to a manuscript — the Elsevier elsarticle theorem-proof format with definition/assumption/proposition/theorem/proof structure, disciplined notation, full references in the abstract, 250-word abstract, 1-7 keywords, optional Highlights, and author-year proof-stage references. For drafting and polishing JET prose; it does not check proofs.

When to use

  • Drafting or polishing a JET theory manuscript
  • Converting a working paper into JET's elsarticle theorem-proof format
  • Tightening notation and statements before submission
  • Applying JET house style to a manuscript
  • Formatting abstracts, keywords, and Highlights
  • Managing author-year proof-stage references
  • Performing a notation audit
  • Rewriting hedged claims in theory prose

When not to use

  • Checking proofs
  • Submitting PDF source instead of .tex
  • Using empirical-paper voice on a theory result
