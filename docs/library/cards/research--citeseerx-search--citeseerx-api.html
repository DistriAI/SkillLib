citeseerx-api

separate

Search computer science literature via the CiteSeerX digital library

When to use

  • Search computer science literature
  • Document search
  • Citation lookup
  • Metadata retrieval
  • Search by title
  • Search by author
  • Filter by year
  • Sort by citation count

When not to use

  • Primarily CS/information science (limited other fields)
  • Some metadata may be noisy (auto-extracted from PDF)
  • Coverage strongest for older papers (2000-2020)
