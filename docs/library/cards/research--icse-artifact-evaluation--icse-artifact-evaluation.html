icse-artifact-evaluation

separate

Use when preparing an artifact for the ICSE Artifact Evaluation track after paper acceptance, covering the ACM badge system (Available, Reusable, Results Reproduced/Replicated), evaluator-proof packaging, archival requirements, open licensing, and the January-window timeline anchored to recent cycles.

When to use

  • preparing ICSE artifact evaluation
  • ACM badge system compliance
  • evaluator-proof packaging
  • archival requirements with DOI
  • open licensing for code and data
  • January-window timeline planning
  • de-anonymizing review packages
  • documenting for reuse

When not to use

  • pre-acceptance reproducibility work
  • camera-ready paper formatting
  • general software engineering practices
