contributor

separate

GitHub 开源贡献辅助技能：围绕目标岗位和技术栈发现合适的开源项目与真实问题，评估维护状态、贡献规则和重复风险，准备最小可验证改动，经用户逐项确认后 fork、push、提交 PR，并跟踪 CI、review 和合并状态；当用户输入“/contributor”、想寻找项目、做 first contribution、提交 PR 或把 PR 写进简历时使用。

When to use

  • 发现合适的开源项目
  • 寻找真实问题
  • 准备最小可验证改动
  • 提交 PR
  • 跟踪 CI 和 review 状态
  • first contribution
  • 把 PR 写进简历
  • 定期执行开源贡献 routine

When not to use

  • 批量扫描
  • 自动群发
  • 绕过仓库贡献政策
  • 无依据的面试题生成
