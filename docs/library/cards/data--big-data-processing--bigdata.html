bigdata

separate

Pulls Bigdata.com (RavenPack) financial and news data via the official bigdata-client SDK and /v1/* REST endpoints — structured financials, prices, analyst estimates, entity-sentiment series, annotated chunk search, screener. Use when the Bigdata MCP's tearsheets/search feel thin and you need the machine-readable substrate: mentions of Bigdata.com, RavenPack, a bd_v2_ key, rp_entity_id, or chunk/query_unit cost.

When to use

  • The user is using **Bigdata.com / RavenPack** and the MCP result feels thin —
  • They want **forward / structured** financials for a ticker: analyst
  • They want **annotated news chunks** with numeric sentiment + entity spans, or
  • They mention a **`bd_v2_` API key**, `rp_entity_id`, `query_unit` / chunk
  • They're building an **investment-research dataset** and need a reusable,

When not to use

  • Bigdata MCP's tearsheets/search
