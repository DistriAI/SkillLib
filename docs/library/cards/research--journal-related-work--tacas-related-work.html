tacas-related-work

separate

Use when positioning a TACAS (ETAPS) submission against the verification literature across TACAS, CAV, VMCAI, FMCAD, SPIN, and journals (STTT, FMSD), writing delta-first contrast against the nearest tools and algorithms, crediting the benchmarks and solvers you build on, keeping self-citations anonymous for double-blind research papers, and handling competition-tool and prior-version overlap.

When to use

  • positioning a TACAS submission against verification literature
  • writing delta-first contrast against nearest tools and algorithms
  • crediting benchmarks and solvers
  • keeping self-citations anonymous for double-blind research papers
  • handling competition-tool and prior-version overlap
  • auditing novelty and eligibility
  • covering verification venues like CAV, VMCAI, FMCAD, SPIN, STTT, FMSD

When not to use

  • re-submitting archival work as new
  • citing only non-verification venues
  • re-reporting prior release benchmarks without new capability
