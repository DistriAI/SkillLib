isr-rebuttal

separate

Use when planning and drafting the response to an Information Systems Research (ISR) revise-and-resubmit — prioritizing the Senior Editor's binding concerns, addressing genre-specific reviewer asks (assumptions/proofs, identification/validity, evaluation), updating the contribution statement, and using the electronic companion. Drafts the revision and response; it runs after isr-review-process.

When to use

  • Planning and drafting ISR revise-and-resubmit response
  • Prioritizing Senior Editor's binding concerns
  • Addressing genre-specific reviewer asks
  • Updating the contribution statement
  • Using the electronic companion for new material
  • Building a revision control ledger
  • Writing a point-by-point response letter

When not to use

  • Drafting the letter before revising the manuscript
  • Treating reviewers as equal voices over the Senior Editor
  • Cosmetic responses without manuscript edits
  • Exceeding the page cap instead of using the electronic companion
  • Accepting mutually inconsistent reviewer requests without rationale
