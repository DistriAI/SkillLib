Develop AI-powered applications using Genkit in Go. Use when the user asks to build AI features, agents, flows, or tools in Go using Genkit, or when working with Genkit Go code involving generation, prompts, streaming, tool calling, or model providers.

When to use

  • build AI features in Go using Genkit
  • build agents in Go using Genkit
  • build flows in Go using Genkit
  • build tools in Go using Genkit
  • working with Genkit Go code involving generation
  • working with Genkit Go code involving prompts
  • working with Genkit Go code involving streaming
  • working with Genkit Go code involving tool calling

When not to use

  • A2UI client rendering
  • A2UI client implementation
