agent-memory-discipline

authentic

Teaches when to recall from long-term memory before acting and when to save durable decisions, corrections and failures afterwards. Use when a memory tool or MCP memory server is connected but the agent is not using it consistently, when the user complains that the assistant forgets preferences, conventions or past decisions between sessions, or when setting up persistent memory for a project. Works with any memory backend: a folder of Markdown files, a local MCP server, or a managed service.

When to use

  • Recalling memory before starting work on a previous project
  • Choosing libraries, patterns, or tools
  • Writing tests, commits, or documentation
  • Answering questions about usual conventions
  • Saving decisions that will matter next week
  • Saving user corrections
  • Saving failed approaches and reasons
  • Closing old memories instead of deleting them

When not to use

  • One-off factual questions
  • Arithmetic
  • Tasks fully specified in the current message
  • Saving file contents that can be read again
  • Saving restatements of the current task
  • Saving transient state
  • Saving temporary items
  • Saving secrets, tokens, or personal data
