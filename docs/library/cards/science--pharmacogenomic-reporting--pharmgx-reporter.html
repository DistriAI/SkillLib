pharmgx-reporter

separate

Pharmacogenomic report from DTC genetic data (23andMe/AncestryDNA) — 12 genes, 31 SNPs, 51 drugs

When to use

  • Pharmacogenomic analysis
  • Drug-gene interaction reports
  • 23andMe medication analysis
  • AncestryDNA medication analysis
  • CYP2D6 and CYP2C19 phenotype calling
  • Warfarin multi-gene interaction alerts
  • Single-drug lookup
  • CPIC guideline-based drug recommendations

When not to use

  • General medical diagnosis
  • Non-pharmacogenomic genetic analysis
  • LLM-guessed drug associations
  • Analysis of non-DTC genetic data formats
