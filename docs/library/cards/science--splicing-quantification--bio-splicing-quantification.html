bio-splicing-quantification

separate

Quantifies alternative splicing events (PSI/percent spliced in) from RNA-seq using SUPPA2 from transcript TPM or rMATS-turbo from BAM files. Calculates inclusion levels for skipped exons, alternative splice sites, mutually exclusive exons, and retained introns. Use when measuring splice site usage or isoform ratios from RNA-seq data.

When to use

  • measuring splice site usage
  • measuring isoform ratios
  • calculating inclusion levels for skipped exons
  • calculating inclusion levels for alternative splice sites
  • calculating inclusion levels for mutually exclusive exons
  • calculating inclusion levels for retained introns
  • quantifying splicing from RNA-seq

When not to use

  • differential splicing comparison between conditions
