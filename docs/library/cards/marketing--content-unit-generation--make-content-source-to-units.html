make-content-source-to-units

separate

Step of the make-content playbook: mines one finished asset into scored quotable units and maps a different lead unit to each platform. Run make-content instead; not for direct use.

When to use

  • Mines one finished asset into scored quotable units
  • Maps a different lead unit to each platform
  • Scores units for Alone, Charge, Novel, and Proof
  • Handles short or silent clips
  • Ranks units for sources under ~30s

When not to use

  • Direct use
  • Mining from a summary
