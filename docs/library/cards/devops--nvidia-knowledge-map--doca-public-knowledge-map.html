doca-public-knowledge-map

separate

Use this skill to locate authoritative NVIDIA DOCA information without the source tree: the docs.nvidia.com page for a library/service/tool, which DOCA libraries are installed and at what version, a sample on disk or GitHub, a path under /opt/mellanox/doca, or a 404'd/renamed doc URL. Activate on implicit phrasing only when the conversation already names DOCA, BlueField, ConnectX, or /opt/mellanox. Do not activate for generic 'which version is installed' or 'where is the sample' questions with none of that context. Refuse and route elsewhere for hands-on programming, env prep, API tutorials, or hardware/firmware mutation — those belong to doca-programming-guide, doca-setup, the per-library skills, and doca-hardware-safety.

When to use

  • locating docs.nvidia.com pages
  • checking installed DOCA library versions
  • finding samples on disk or GitHub
  • identifying paths under /opt/mellanox/doca
  • resolving 404'd or renamed doc URLs
  • documentation-routing questions
  • finding API or error references
  • locating release notes or developer forum

When not to use

  • hands-on programming
  • environment preparation
  • API tutorials
  • hardware or firmware mutation
  • generic version questions without DOCA context
  • generic sample location questions without DOCA context
