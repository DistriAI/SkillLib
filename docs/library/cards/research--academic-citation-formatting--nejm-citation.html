nejm-citation

separate

Use to convert references to NEJM's Vancouver / ICMJE numbered style — numbered in order of appearance, limited author lists then et al., NLM journal abbreviations, and a capped reference count. Late-stage style pass.

When to use

  • Converting author-date references to Vancouver/ICMJE
  • Reordering reference lists by citation appearance
  • Applying limited author lists with et al.
  • Abbreviating journal titles per NLM/Index Medicus
  • Capping reference counts for article types
  • Auditing references for evidence discipline
  • Checking for unresolved or duplicate references
  • Comparing against neighboring journals for routing

When not to use

  • Polishing manuscript content before citation style is fixed
  • Handling non-NEJM journal styles
  • Alphabetizing reference lists
  • Listing all authors for references with more than six authors
