cpa-mechanism

separate

Use when designing or writing the governance / policy-process mechanism analysis for a 《中国行政管理》 manuscript. Identifies how an effect is produced (implementation, attention allocation, central-local, incentives / accountability) via quantitative mediation or qualitative process evidence. 本技能服务于《中国行政管理》(Chinese Public Administration, CPA)。

When to use

  • designing governance mechanism analysis
  • writing policy-process mechanism analysis
  • identifying how an effect is produced
  • quantitative mediation analysis
  • qualitative process evidence
  • policy implementation mechanisms
  • attention allocation mechanisms
  • central-local relationship mechanisms

When not to use

  • using moderator variables as mechanisms
  • relying solely on Sobel tests
  • providing only narrative without evidence strength judgment
  • using future information in mechanism variable construction
