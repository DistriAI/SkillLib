acmmm-submission

separate

Use when auditing an ACM MM (ACM Multimedia) submission for OpenReview readiness — thematic-area choice, the 6-8 page ACM sigconf budget, references-only overflow, double-blind anonymity versus the single-blind Reproducibility/Open-Source/Dataset tracks, supplementary media, dual submission, desk-reject triggers, and last-week sequencing.

When to use

  • ACM MM submission audit
  • Thematic area selection
  • ACM sigconf page budget check
  • Double-blind anonymity verification
  • Single-blind track compliance
  • Supplementary media validation
  • Dual submission check
  • OpenReview profile and abstract registration

When not to use

  • Co-located workshop submissions
  • ACM MM Asia submissions
  • MMSys submissions
  • ICMR submissions
