rje-contribution-framing

separate

Use to frame the contribution of a manuscript for The RAND Journal of Economics (RJE) so the industrial-organization advance is legible to the screening Editor and two referees within the hard page caps. Sharpens the one-sentence "so what"; it does not run the analysis.

When to use

  • Framing the 'so what' for an IO audience
  • Structuring the first paragraph contribution
  • Ensuring legibility for the RJE editor screen
  • Defining the market and strategic problem
  • Identifying the structural advance
  • Naming the method that earns the result
  • Stating the lesson for competition or regulation

When not to use

  • Running the analysis
