aistats-supplementary

separate

Use when preparing AISTATS supplementary material, appendices, proof details, code/data archives, simulation scripts, additional tables, and anonymized artifacts under deadline, size, anonymity, and reviewer-discretion constraints, including how to split a theory-plus-experiments paper between body and supplement.

When to use

  • preparing AISTATS supplementary material
  • assembling appendices and proof details
  • creating code and data archives
  • writing simulation scripts
  • formatting additional tables
  • managing anonymized artifacts
  • splitting theory and experiments between body and supplement

When not to use

  • hiding essential motivation in supplement
  • hiding core method description in supplement
  • hiding main theorem statements in supplement
  • hiding primary empirical results in supplement
