jpe-theory-model

separate

Use when a Journal of Political Economy (JPE) manuscript needs an explicit economic model or mechanism — either a theory paper's model, or the framework that gives a reduced-form empirical result its economic meaning. Builds and disciplines the economic argument; it does not run estimation (see jpe-identification).

When to use

  • theory paper's model
  • framework for reduced-form empirical result
  • disciplining assumptions or comparative statics
  • connecting empirical specification to economic framework
  • identifying economic force driving result
  • minimal-model discipline for empirics-led papers
  • full-model rigor for theory-led papers
  • welfare analysis and efficiency benchmark

When not to use

  • running estimation
  • deep, self-contained macro model
  • sharp theory or market-design result
