chrome-automation

separate

网页开发工程师与运营专员在需要自动化现有 Chrome 浏览器时必用！通过 CDP 协议无缝接管当前浏览器，自动配置环境并实时可视化执行任务。完美保留登录状态，一键完成复杂网页自动化流程，让繁琐操作自动化。

When to use

  • Automating existing Chrome browser
  • Preserving login states and cookies
  • Real-time visual browser control
  • Complex web page automation
  • Installing agent-browser dependencies

When not to use

  • Using built-in browser tools (browser_use_desktop)
