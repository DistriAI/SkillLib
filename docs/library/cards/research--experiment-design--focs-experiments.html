focs-experiments

separate

Use when deciding whether and how computation appears in a FOCS (IEEE Symposium on Foundations of Computer Science) paper — a venue that accepts on theorems with no evaluation section expected — covering machine-verified case analyses, computer-discovered constructions, and honest illustrative plots.

When to use

  • machine-verified case analyses
  • computer-discovered constructions
  • honest illustrative plots
  • proof-bearing computation rigor
  • disclosure of AI-assisted search
  • placement of computation descriptions

When not to use

  • runtime comparisons against prior implementations
  • empirical sections required for persuasiveness
  • algorithms-engineering venue submissions
