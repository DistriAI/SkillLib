academic-pipeline

combined

Orchestrator for the full academic research pipeline: research -> write -> integrity check -> review -> revise -> re-review -> re-revise -> final integrity check -> finalize. Coordinates deep-research, academic-paper, and academic-paper-reviewer into a seamless 10-stage workflow with mandatory, coverage-bounded integrity checks, two-stage peer review, and auditable quality-assurance artifacts. Conflict

The two copies are different major versions of the same orchestrator. The Imbad0202 copy (v3.23.0) is a 10-stage workflow that includes a detailed routing core, escape-hatch handling, and opt-in audit/reset flags, but its text is truncated before the stage table. The brycewang-stanford copy (v2.7) is a 9-stage workflow that explicitly defines the stage table, state machine, and a final 'Process Summary' stage, but lacks the routing core and newer audit features. Because each copy contains material steps and constraints the other lacks (routing/audit vs. explicit stage table/process summary), crowning one would hide a real alternative.
