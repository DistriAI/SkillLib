react-components

separate

Converts Stitch designs into modular Vite and React components, or syncs/updates existing React components to align with the latest Stitch designs, using system-level networking and AST-based validation.

When to use

  • Converting Stitch designs into React components
  • Syncing existing React components with Stitch designs
  • Extracting style tokens from Stitch HTML
  • Building modular Vite and React applications

When not to use

  • Reading local design files without MCP retrieval
  • Skipping visual audit of screenshots
  • Using hardcoded hex values instead of theme classes
  • Creating monolithic page files
