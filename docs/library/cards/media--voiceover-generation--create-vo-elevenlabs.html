create-vo-elevenlabs

separate

Generate a voiceover (VO) clip via ElevenLabs text-to-speech, routed through the GooseWorks proxy, so the call is charged to your GooseWorks credits. Voice id + script text come from the template recipe. Use for the spoken narration of VO-driven video-ad formats (cgi-app-sizzle, flat-vector-explainer, hypermotion). Never call ElevenLabs directly — the proxy attribution is required.

When to use

  • Generate voiceover clips via ElevenLabs
  • Route TTS calls through GooseWorks proxy
  • Handle brand pronunciations with phonetic spellings
  • Apply measured pace and target words-per-second
  • Generate timestamped voiceover with character alignments
  • Support Eleven v4 and v3 models
  • Process audio tags and delivery cues
  • Save provenance and raw audio files

When not to use

  • Calling ElevenLabs directly
  • Retiming lip-synced or native talking clips
  • Using Style, Speed, speaker boost, or SSML with V4
  • Accepting tag effects without listening to the voice
  • Generating six takes by default
  • Fitting poor voice performance with automatic time stretching
