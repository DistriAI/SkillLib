Clean up and audit a Unity project

When to use

  • Reducing project bloat
  • Hunting duplicate or orphaned assets
  • Auditing before a release
  • Finding unused assets
  • Finding duplicate files
  • Finding missing references
  • Deleting assets with confirmation
  • Fixing missing scripts

When not to use

  • Deleting assets without confirmation
  • Project validation
  • Using non-existent skills like cleaner_delete or cleaner_scan
