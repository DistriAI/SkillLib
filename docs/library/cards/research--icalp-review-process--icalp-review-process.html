icalp-review-process

separate

Use when reasoning about how an ICALP (EATCS) submission is evaluated, covering lightweight double-blind review, the separate Track A and Track B program committees, the asymmetric author interaction (Track B rebuttal vs Track A correctness-only contact), correctness-driven acceptance, the single accept/reject decision, and how ICALP's process differs from STOC/FOCS/SODA.

When to use

  • reasoning about ICALP submission evaluation
  • understanding lightweight double-blind review
  • analyzing Track A and Track B program committees
  • evaluating asymmetric author interaction
  • assessing correctness-driven acceptance
  • interpreting single accept/reject decisions
  • comparing ICALP process to STOC/FOCS/SODA

When not to use

  • journal-style major revision processes
  • US-venue specific processes
  • appeals after rejection
