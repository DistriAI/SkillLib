project-scout

separate

Advise on reconnoitering an existing Unity project

When to use

  • First approaching an unfamiliar project
  • Before proposing structural changes
  • Auditing existing setup
  • Inspecting Unity version and render pipeline
  • Checking installed packages and dependencies
  • Reviewing asmdef layout and folder structure
  • Identifying existing architectural signals
  • Identifying existing conventions worth preserving

When not to use

  • Proposing a clean-slate architecture if the project already has a consistent pattern
  • Recommending new dependencies until the current stack is clear
