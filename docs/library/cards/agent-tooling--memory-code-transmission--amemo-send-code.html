amemo-send-code

separate

当用户输入 11 位手机号时调用，向该手机号发送短信验证码，完成后等待用户回复验证码进入登录流程。

When to use

  • 发送短信验证码
  • 提取11位手机号
  • 调用POST /send-code接口

When not to use

  • 完成登录流程
  • 验证验证码
