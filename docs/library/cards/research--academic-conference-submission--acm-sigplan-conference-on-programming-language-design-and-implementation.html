Use when targeting ACM SIGPLAN Conference on Programming Language Design and Implementation (PLDI) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for programming languages flagship.

When to use

  • targeting PLDI
  • deciding if a manuscript fits PLDI
  • conference-fit read for programming languages
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • submission strategy for programming languages flagship

When not to use

  • substitute for current year's CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
  • routing to POPL for semantic or type-theoretic principles
  • routing to OOPSLA for broader language/software-engineering experience reports
  • routing to ASPLOS/CGO/PACT when architecture or performance dominates
