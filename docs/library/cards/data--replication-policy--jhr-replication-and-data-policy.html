jhr-replication-and-data-policy

separate

Use when preparing Journal of Human Resources data and replication materials: archive plan footnote, public repository deposit, CC0 license, Data Availability Statement, read-me file, waiver requests, RCT pre-analysis-plan statements, and code package.

When to use

  • preparing JHR submission or acceptance
  • creating archive-plan footnote
  • drafting Data Availability Statement
  • requesting data waivers
  • managing restricted or proprietary data
  • handling RCT-based data
  • preparing replication code packages
  • defining exhibit-to-script maps

When not to use

  • tasks not related to JHR data policy
  • general data analysis without replication focus
