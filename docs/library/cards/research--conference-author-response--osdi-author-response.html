osdi-author-response

separate

Use when handling author-side dialogue in an OSDI cycle — which in 2026 means no rebuttal at all: pre-empting objections inside the submission, then treating the conditional-accept shepherd exchange as the real author response, with a protocol for mandated revisions and for cycles that reinstate a response phase.

When to use

  • pre-empting objections inside the submission
  • treating the conditional-accept shepherd exchange as the real author response
  • protocol for mandated revisions
  • cycles that reinstate a response phase
  • pre-mortem rebuttal on the draft
  • building a change matrix for shepherding
  • managing the shepherding calendar
  • handling mandates that demand new experiments

When not to use

  • drafting a rebuttal for venues with a standard author-response period
