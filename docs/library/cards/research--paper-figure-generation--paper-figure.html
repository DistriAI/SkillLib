paper-figure

authentic

Generate publication-quality figures and tables from experiment results. Use when user says \"画图\", \"作图\", \"generate figures\", \"paper figures\", or needs plots for a paper.

When to use

  • Data-driven plots
  • Comparison tables
  • Multi-panel figures
  • Line plots
  • Bar charts
  • Scatter plots
  • Heatmaps
  • Box/violin plots

When not to use

  • Architecture/pipeline diagrams
  • Generated image grids
  • Photographs / screenshots
