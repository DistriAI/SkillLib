This skill should be used when analyzing market breadth charts, specifically the S&P 500 Breadth Index (200-Day MA based) and the US Stock Market Uptrend Stock Ratio charts. Use this skill when the user provides breadth chart images for analysis, requests market breadth assessment, positioning strategy recommendations, or wants to understand medium-term strategic and short-term tactical market outlook based on breadth indicators. This skill should be used when analyzing market breadth charts, specifically the S&P 500 Breadth Index (200-Day MA based) and the US Stock Market Uptrend Stock Ratio charts. Use this skill when the user provides breadth chart images for analysis, requests market breadth assessment, positioning strategy recommendations, or wants to understand medium-term strategic and short-term tactical market outlook based on breadth indicators. Also works WITHOUT chart images by fetching CSV data directly from public sources. All analysis and output are conducted in English.

When to use

  • User provides S&P 500 Breadth Index (200-Day MA based) chart images for analysis
  • User provides US Stock Market Uptrend Stock Ratio chart images for analysis
  • User requests market breadth assessment or market health evaluation
  • User asks about medium-term strategic positioning based on breadth indicators
  • User needs short-term tactical timing signals for swing trading
  • User wants combined strategic and tactical market outlook
  • **User requests breadth analysis WITHOUT providing chart images** (CSV data mode)
  • User asks about individual stock analysis (use `us-stock-analysis` skill instead)

Skill page

Conflict

The two copies describe the same breadth-chart analysis task but disagree on the primary data source and workflow. The tradermonty copy mandates fetching CSV data from public sources as the primary input and treats chart images as supplementary, while the LeoYeAI copy is image-first, instructing the agent to receive chart images, read a local methodology reference, and view sample assets. Because each copy contains material steps the other lacks (CSV fetching vs. image-based extraction and reference loading), crowning one would hide a real alternative procedure.
