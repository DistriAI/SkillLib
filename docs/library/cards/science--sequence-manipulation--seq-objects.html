Create and manipulate Seq, MutableSeq, and SeqRecord objects using Biopython. Use when creating sequences from strings, modifying sequence data in-place, building annotated records for file output, or debugging post-1.78 Bio.Alphabet and immutability errors.

When to use

  • creating sequences from strings
  • modifying sequence data in-place
  • building annotated records for file output
  • debugging post-1.78 Bio.Alphabet and immutability errors
  • wrapping raw strings in typed sequence containers
  • transforming whole records while keeping metadata coherent
