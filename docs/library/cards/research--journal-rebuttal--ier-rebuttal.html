ier-rebuttal

separate

Use when an International Economic Review (IER) decision letter or referee report needs a response strategy and a revision plan. Triages comments and structures the response letter to a rigor-leaning, theory-tilted review; it does not invent new results.

When to use

  • IER R&R response plan
  • major/minor revision strategy
  • reject-and-resubmit strategy
  • split decision strategy
  • triaging referee comments
  • structuring response letter
  • converting comments to revision plan

When not to use

  • inventing new results
