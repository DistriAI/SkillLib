linux-privilege-escalation

combined

Execute systematic privilege escalation assessments on Linux systems to identify and exploit misconfigurations, vulnerable services, and security weaknesses that allow elevation from low-privilege user access to root-level control. Linux privilege escalation playbook. Use when you have low-privilege shell access and need to escalate to root via SUID/SGID binaries, capabilities, cron abuse, kernel exploits, misconfigurations, or credential harvesting on Linux systems.

When to use

  • This skill is applicable to execute the workflow or actions described in the overview.

When not to use

  • Unauthorized security assessments
  • Accessing data beyond scope requirements
  • Production use without test environment verification

Conflict

The two copies overlap on the core Linux privesc workflow (enumerate, SUID/SGID, capabilities, cron, kernel), but each has material content the other lacks. The yaklang copy is a detailed, command-level playbook with specific GTFOBins commands, capability exploitation examples, shared-library hijacking, and routing to companion skills. The sickn33 copy is a higher-level skill wrapper that mandates a confirmation gate, legal/ethical guardrails, operational boundaries, and points to a separate detailed guide, plus it includes worked examples. Crowning one would hide either the concrete exploitation steps or the mandatory authorization/safety constraints, so they should be combined.
