ig-reply

separate

Handle the comments under the user's own reels and posts - draft replies to the ones worth answering, sorted by which ones are. Use when the user pastes their comments, says "reply to these", "handle my comments", "someone said X on my reel", or is dealing with a critic, a hater or a lead in the comments.

When to use

  • draft replies to comments
  • handle comments on reels and posts
  • triage comments by value
  • respond to critics, haters, or leads
  • identify questions for Reels

When not to use

  • scraping comment threads with a browser tool
  • bulk-DMing people who did not comment
  • posting replies without user approval
