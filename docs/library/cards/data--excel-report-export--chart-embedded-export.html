chart-embedded-export

separate

从结构化数据中提取分类分布执行清洗与统计，生成多维度交叉分析、高分辨率对比图表及包含下载链接的完整分析报告，适用于大文件处理与嵌入式可视化场景。

When to use

  • 数据清洗
  • 处理合并单元格
  • 正则表达式清理文本
  • 建立分类映射函数
  • 多维度统计与交叉分析
  • 计算分类占比
  • 生成包含总计行的交叉表
  • 多维度评分与分级

When not to use

  • reading/counting/Parquet optimization
