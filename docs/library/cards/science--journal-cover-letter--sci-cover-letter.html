sci-cover-letter

separate

Use when writing the editor-facing cover letter for Science (AAAS) — a tight, significance-forward pitch, not a summary, that lets the editor decide within two minutes whether the paper clears the broad-interest bar and should go out for external review.

When to use

  • Writing editor-facing cover letters for Science
  • Arguing broad significance for triage
  • Structuring a one-page significance argument
  • Checking logistics and compliance statements
  • Testing significance paragraphs for copy-readiness
  • Comparing against neighboring journals for routing

When not to use

  • Summarizing the abstract
  • Using unsupported superlatives
  • Omitting originality or exclusivity statements
  • Burying the main hook after logistics
