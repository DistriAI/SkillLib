apitestcreate

separate

当用户需要根据接口规格生成API测试分析文档时使用此技能。接受OpenAPI/Swagger文档、简化接口定义或自然语言描述，基于140个常见API测试陷阱输出全面的测试分析文档，涵盖参数校验、业务逻辑、响应验证和安全测试分析点。

When to use

  • Designing test strategies for new API endpoints
  • Reviewing API test coverage completeness
  • Generating test analysis documents for team review
  • Auditing API quality against common pitfalls
  • Generating test plans and test point checklists
