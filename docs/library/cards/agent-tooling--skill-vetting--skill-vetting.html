skill-vetting

separate

Vet ClawHub skills for security and utility before installation. Use when considering installing a ClawHub skill, evaluating third-party code, or assessing whether a skill adds value over existing tools.

When to use

  • Vetting ClawHub skills for security
  • Evaluating third-party code
  • Assessing skill utility over existing tools
  • Running automated security scanners
  • Manual code review for prompt injection
  • Checking for malicious patterns

When not to use

  • Installing skills without vetting
  • Downloading skills to workspace instead of /tmp
