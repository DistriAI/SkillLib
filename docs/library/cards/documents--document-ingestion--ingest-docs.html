ingest-docs

separate

Scan a repo for mixed ADRs, PRDs, SPECs, and DOCs and bootstrap or merge the full .planning/ setup from them. Classifies each doc in parallel, synthesizes a consolidated context with a conflicts report, and routes to new-project or merge-milestone depending on whether .planning/ already exists.

When to use

  • Bootstrap .planning/ setup from pre-existing planning documents
  • Merge ingested docs into existing .planning/ setup
  • Classify ADRs, PRDs, SPECs, and DOCs in parallel
  • Synthesize consolidated context with conflicts report
  • Resolve conflicts using precedence rules
  • Generate PROJECT.md, REQUIREMENTS.md, ROADMAP.md, and STATE.md

When not to use

  • Interactive conflict resolution (reserved for future release)
  • Processing more than 50 docs per invocation
