portaljs-connect-ckan

separate

Wire a scaffolded PortalJS portal to a CKAN backend over its API. Generates a tiny server-side fetch client (no runtime dependency) and feeds the /search catalog and /@namespace/slug showcases from CKAN instead of datasets.json. Use when connecting an existing portal to a live CKAN instance instead of a static manifest.

When to use

  • Connecting an existing portal to a live CKAN instance
  • Generating a server-side fetch client for CKAN
  • Feeding the /search catalog from CKAN
  • Feeding /@namespace/slug showcases from CKAN
  • Replacing static datasets.json with CKAN API

When not to use

  • Scaffolding a new portal
  • Using @portaljs/ckan runtime dependency
  • Modifying pages/index.tsx
