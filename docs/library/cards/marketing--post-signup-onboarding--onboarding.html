Conflict

The three copies are not the same procedure. coreyhaines31/marketingskills is a detailed CRO playbook for optimizing post-signup onboarding, activation, and time-to-value. sickn33/agentic-awesome-skills is a truncated mirror of that same playbook, but it adds a different structure (flow design, multi-channel coordination, stalled-user handling, measurement, output formats, product-type patterns, experiment ideas) and omits several core concepts from the original (onboarding psychology, 10-component toolkit, activation models, MPTV reference). huytieu/COG-second-brain is a completely different onboarding skill: it is a personalization/setup routine for the COG second-brain product, not a CRO methodology. Because the copies overlap in the broad topic of onboarding but each contains material steps or constraints the others lack, and because the COG copy conflicts with the CRO copies on what the skill is for, crowning one would hide a real alternative.
