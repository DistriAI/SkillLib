domain-modeling

authentic

Build and sharpen a project's domain model. Use when discussing codebase terminology, writing or editing a GLOSSARY.md, or recording or editing an ADR.

When to use

  • discussing codebase terminology
  • writing or editing a GLOSSARY.md
  • recording or editing an ADR
  • challenging terms against the glossary
  • sharpening fuzzy language
  • discussing concrete scenarios
  • cross-referencing with code
  • updating GLOSSARY.md inline

When not to use

  • merely reading GLOSSARY.md for vocabulary
  • consuming the model without changing it
