zotero-obsidian-bridge

separate

Use this skill when papers are collected in Zotero but the user wants detailed reading notes, project-linked literature synthesis, collection-wide paper-note coverage checks, and a connected knowledge map inside the bound Obsidian project knowledge base.

When to use

  • collect and organize papers in Zotero
  • read papers from Zotero MCP
  • create or update detailed paper notes
  • synthesize notes into Knowledge notes
  • verify collection-wide paper-note coverage
  • visualize literature structure as an Obsidian canvas

When not to use

  • dumping raw full text into Obsidian
  • creating new notes if canonical paper note exists
  • creating Concepts or Datasets trees by default
  • treating Experiments, Results, or Writing as default bridge targets
  • stopping at a representative subset when full collection check is requested
