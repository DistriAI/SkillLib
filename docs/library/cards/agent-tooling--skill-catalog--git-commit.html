git-commit

separate

Execute git commit with conventional commit message analysis, intelligent staging, and message generation. Use when user asks to commit changes, create a git commit, or mentions "/commit". Supports: (1) Auto-detecting type and scope from changes, (2) Generating conventional commit messages from diff, (3) Interactive commit with optional type/scope/description overrides, (4) Intelligent file staging for logical grouping

When to use

  • commit changes
  • create a git commit
  • mentions "/commit"
  • Auto-detecting type and scope from changes
  • Generating conventional commit messages from diff
  • Interactive commit with optional type/scope/description overrides
  • Intelligent file staging for logical grouping

When not to use

  • update git config
  • run destructive commands (--force, hard reset) without explicit request
  • skip hooks (--no-verify) unless user asks
  • force push to main/master
