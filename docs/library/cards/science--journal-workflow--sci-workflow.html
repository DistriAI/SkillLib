sci-workflow

separate

Use when deciding which sci-* sub-skill to invoke next, or when sequencing a manuscript from significance test through reviewer rebuttal for Science (AAAS). Routes — it does not replace — the specialized skills.

When to use

  • deciding which sci-* sub-skill to invoke next
  • sequencing a manuscript from significance test through reviewer rebuttal
  • diagnosing the current bottleneck of a draft
  • switching into rebuttal mode after reviews arrive
  • tracking manuscript position in the pipeline

When not to use

  • replacing specialized skills
  • targeting Science Advances without flagging differences
  • targeting Science Translational Medicine without flagging differences
  • perfecting the abstract before significance and format are settled
