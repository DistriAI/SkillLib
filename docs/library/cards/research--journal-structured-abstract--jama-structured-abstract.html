jama-structured-abstract

separate

Use when writing or auditing the JAMA structured abstract and the Key Points box for a JAMA manuscript. Enforces the exact JAMA heading set and quantified results; it does NOT design the study or run statistics.

When to use

  • writing JAMA structured abstract
  • auditing JAMA structured abstract
  • writing Key Points box
  • auditing Key Points box
  • verifying JAMA heading set
  • checking quantified results in abstract

When not to use

  • designing the study
  • running statistics
