issta-writing-style

separate

Use when revising an ISSTA paper for a clear testing/analysis contribution, covering the threat-model-then-technique structure, the evaluation contract, a threats-to-validity section that is not boilerplate, claims scoped to the subjects tested, double-anonymous phrasing, and 18-page ACM sigconf discipline that survives specialist reviewers.

When to use

  • threat-model-then-technique structure
  • evaluation contract
  • threats-to-validity section
  • claims scoped to the subjects tested
  • double-anonymous phrasing
