amann-topic-selection

separate

Use when judging whether a management/organization literature is an Academy of Management Annals (Annals)-scale review topic — mature, important, fragmented, and integrable into a new framework — rather than a narrow review. Decides fit and frames the review's animating problem; it does not gather the literature (amann-literature-synthesis) or write the proposal (amann-proposal-framing).

When to use

  • Judging if literature is Annals-shaped
  • Evaluating topic maturity and importance
  • Assessing fragmentation and integrability
  • Checking tractable scope for a 50-page review
  • Framing the animating problem
  • Deciding between Annals and sibling outlets
  • Identifying if a domain is too young or narrow

When not to use

  • Gathering the literature
  • Writing the proposal
  • New theory development
  • New data or hypothesis tests
  • Narrow single-construct reviews
  • Self-retrospective reviews
