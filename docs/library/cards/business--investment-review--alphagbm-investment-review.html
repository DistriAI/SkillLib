alphagbm-investment-review

separate

Compare research records you provide to see changes in facts, scores and judgments. Use when the user asks to investment review with AlphaGBM. Use the bundled Python runner; never silently replace real results with demos.

When to use

  • Compare research records
  • Identify changes in facts, scores and judgments
  • Local comparison of authorized JSON results
  • Show comparable changes, data gaps and judgments needing review

When not to use

  • Trading-performance backtest
  • Account-history access
  • Automatic monitoring
  • New paid query
  • Obtaining new stock/options evidence
  • Interpreting unverified file hash as proof of provenance
  • Interpreting changed price as a correct thesis
