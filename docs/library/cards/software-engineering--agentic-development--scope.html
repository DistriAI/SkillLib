scope

separate

Run /scope to turn a product idea into a living, coarse scope in docs/scope/ and keep it current: plan a new product, plan the next slice, enroll one named feature, or run with no argument to reconcile after shipping and queue what is next. Seeds WHAT to build; /architect designs, /develop builds.

When to use

  • plan a new product
  • plan the next slice
  • enroll one named feature
  • reconcile after shipping
  • queue what is next
  • decompose into coarse feature sections
  • order and phase features
  • surface plan vs reality drift

When not to use

  • how to build one thing
  • designing architecture
  • building code
  • picking tools, providers, libraries, or ORMs
  • writing specs
  • writing code
  • writing AGENTS.md
