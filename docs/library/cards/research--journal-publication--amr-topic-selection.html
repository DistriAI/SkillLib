amr-topic-selection

separate

Use when the theoretical puzzle is the bottleneck for an Academy of Management Review (AMR) manuscript — deciding whether an idea is theory-worthy and AMR-fit before any theorizing begins. Frames the puzzle; it does NOT build constructs (that is amr-theory-development) or design any empirical study (AMR has none).

When to use

  • Deciding if an idea is theory-worthy
  • Checking AMR fit
  • Framing a theoretical puzzle
  • Identifying theoretical tension
  • Evaluating conceptual nature of idea
  • Assessing if idea changes how scholars think
  • Determining if scope is a journal article

When not to use

  • Building constructs
  • Designing empirical studies
  • Collecting data
  • Running empirical tests
  • Literature positioning
  • Theory development
