short-drama-edit

separate

将已生成的短剧镜头剪成成片，记录入出点、镜序、声音、字幕与交付规格。用于套剪、加字幕、统一响度、调整节奏或导出精修素材；需要补素材或修改故事时转回对应创作阶段。

When to use

  • 套剪
  • 加字幕
  • 统一响度
  • 调整节奏
  • 导出精修素材
  • 记录入出点
  • 记录镜序
  • 记录声音

When not to use

  • 补素材
  • 修改故事
  • 生成新素材
  • 改提示词
  • 改台词
  • 改镜头职责
  • 改起终状态
  • 判断成片质量
