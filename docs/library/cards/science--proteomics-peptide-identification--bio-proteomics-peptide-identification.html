bio-proteomics-peptide-identification

separate

Peptide-spectrum matching and protein identification from MS/MS data. Use when identifying peptides from tandem mass spectra. Covers database searching, spectral library matching, and FDR estimation using target-decoy approaches.

When to use

  • identifying peptides from tandem mass spectra
  • database searching
  • spectral library matching
  • FDR estimation using target-decoy approaches
  • matching experimental spectra against theoretical fragment ion patterns
  • processing search results
  • filtering PSMs by FDR

When not to use

  • loading raw MS data before identification
  • grouping peptides to proteins
  • identifying modified peptides
