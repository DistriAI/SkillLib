asset-import

separate

Use when acquiring or importing media into a OpenChatCut project asset library for video editing or creation, including local/attached videos, user-provided paths, public media URLs, web video/audio/image assets, upload fallback decisions, and deciding between import_media, download_media, or manual user action.

When to use

  • acquiring or importing media into OpenChatCut project asset library
  • handling local/attached videos
  • processing user-provided paths
  • importing public media URLs
  • importing web video/audio/image assets
  • making upload fallback decisions
  • deciding between import_media, download_media, or manual user action

When not to use

  • hosted import API
  • CLI
  • OAuth
  • reading user's filesystem
  • pre-converting, pre-trimming, or transcoding media
  • locally concatenating, pre-trimming, pre-composing, burning captions, or flattening media before import
  • creating Motion Graphics code assets
