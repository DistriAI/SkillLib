eacl-workflow

separate

Use when planning an EACL project timeline through ACL Rolling Review, covering the single viable ARR cycle with no fallback, backward planning from the one deadline, the rebuttal window, the commitment decision to EACL, notification, and camera-ready through ACL Anthology publication, plus re-routing since the next chance is another conference.

When to use

  • planning an EACL project timeline
  • backward planning from the single ARR deadline
  • managing the rebuttal window
  • making the commitment decision to EACL
  • planning camera-ready and ACL Anthology publication
  • planning re-routing to sibling venues

When not to use

  • planning for EACL editions with multiple ARR cycles
  • carrying 2027 timing to another edition
