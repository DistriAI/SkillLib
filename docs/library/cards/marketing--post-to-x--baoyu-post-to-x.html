baoyu-post-to-x

combined

Posts content and articles to X (Twitter). Supports regular posts with images/videos and X Articles (long-form Markdown). In Codex, honor explicit requests for the Codex Chrome plugin/@chrome by using the Chrome Extension workflow; otherwise use Chrome Computer Use when available and fall back to real Chrome CDP scripts only when allowed. Use when user asks to "post to X", "tweet", "publish to Twitter", or "share on X". 自媒体创作者需要在X(Twitter)发布内容时，支持图文、视频、引用推文及Markdown长文发布，通过真实Chrome浏览器绕过反自动化检测，一键完成多格式内容分发，有效规避封号风险。

When to use

  • post to X
  • tweet
  • publish to Twitter
  • share on X
  • regular posts with images/videos
  • X Articles (long-form Markdown)
  • quote tweet with comment

When not to use

  • in-app Browser for X publishing workflows

Skill page

Conflict

The two copies describe the same task but diverge on how the browser is controlled. JimLiu/baoyu-skills is the more complete, upstream-style skill: it defines three distinct execution modes (Codex Chrome plugin, Chrome Computer Use, CDP script), a required mode-selection rule, and detailed recovery/permission steps for the Chrome plugin path. anbeime/skill is a shorter, CDP-only variant that adds an EXTEND.md preferences mechanism and explicit per-script CLI examples, but it omits the Chrome plugin and Computer Use paths entirely. Because each copy contains material steps the other lacks, crowning one would hide a real alternative.
