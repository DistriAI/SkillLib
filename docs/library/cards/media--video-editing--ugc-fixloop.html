ugc-fixloop

separate

the UGC fix-loop toolkit — surgically re-render a bad window/beat of a single-take UGC master (stitch_replacement.py, pure FFmpeg) and GPT cross-model review a Seedance prompt before render (vet_seedance_prompt.py, routed through the openai-proxy). Fetch it into a one-shot UGC recipe so both scripts resolve on any machine and the vet call charged to your GooseWorks credits.

When to use

  • re-render a bad window/beat of a single-take UGC master
  • GPT cross-model review a Seedance prompt before render
  • surgical beat/window swap
  • structured review of Seedance prompts

When not to use

  • direct fal.run calls
  • direct OpenAI calls
  • local key usage
