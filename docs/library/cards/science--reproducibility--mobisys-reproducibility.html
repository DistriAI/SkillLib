mobisys-reproducibility

separate

Use when strengthening MobiSys reproducibility evidence — capturing device, SoC, OS build, framework and model versions, power-instrument setup, seeds, and thermal conditions so an on-device result survives a different phone, deciding what data and firmware can legally ship, and keeping the paper consistent with the artifact for the ACM badge pipeline.

When to use

  • strengthening MobiSys reproducibility evidence
  • capturing device, SoC, OS build, framework and model versions
  • recording power-instrument setup, seeds, and thermal conditions
  • deciding what data and firmware can legally ship
  • keeping the paper consistent with the artifact
  • mapping latency, energy, throughput, and accuracy claims to verifiable locations
  • explaining missing data, firmware, or hardware
  • defining degrees of reproducibility
