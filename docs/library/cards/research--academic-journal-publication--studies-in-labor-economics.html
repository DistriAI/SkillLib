studies-in-labor-economics

separate

Use when targeting 《劳动经济研究》(Studies in Labor Economics) or deciding whether a Chinese social-science/econ/management manuscript fits this journal. Applies the journal's fit, framing, method, house-style, official-submission-check, and desk-reject heuristics.

When to use

  • targeting 《劳动经济研究》
  • deciding if a manuscript fits the journal
  • rewriting a manuscript for the journal
  • listing high-frequency rejection risks
  • checking official submission requirements

When not to use

  • replacing the latest official submission guidelines
  • submitting to other journals like 《软科学》 or 《南方经济》
  • manuscripts where labor economics is not the core contribution
