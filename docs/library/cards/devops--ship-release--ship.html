ship

combined

Ship workflow: detect + merge base branch, run tests, review diff, bump VERSION, update CHANGELOG, commit, push, create PR. Create PR, run review, and prepare for merge after verification passes

When to use

  • detect base branch
  • run tests
  • review diff
  • bump VERSION
  • update CHANGELOG
  • commit changes
  • push to remote
  • create PR

When not to use

  • interactive confirmation steps
  • resolving unresolvable merge conflicts
  • fixing test failures
  • fixing critical review issues

Skill page

Conflict

All three skills are named 'ship' and share the high-level goal of preparing work for release, but they define materially different procedures. davepoon/buildwithclaude delegates to an external workflow file and focuses on PR creation and a continuation prompt. plugin87/ux-ui-agent-skills is a pre-release gate for a UI kit that runs specific accuracy/responsive/emoji scripts and drafts a README/changelog without tagging. LeoYeAI/openclaw-master-skills is a fully automated, non-interactive pipeline that detects the base branch, runs tests, reviews the diff, bumps VERSION, updates CHANGELOG, commits, pushes, and creates a PR, with extensive preamble and contributor-mode logic. No single copy is the procedure the others reproduce; each contains steps and constraints the others lack, so crowning one would hide real alternatives.
