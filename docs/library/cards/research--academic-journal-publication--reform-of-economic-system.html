Use when targeting 《经济体制改革》(Reform of Economic System — 四川省社会科学院主管主办的经济理论 CSSCI 双月刊, 1983 年创刊, FounderSS 在线投审稿) or deciding whether a Chinese social-science/econ/management manuscript fits this journal. Applies the journal's fit, framing, abstract/keyword house-style, official-submission-check, and desk-reject heuristics.

When to use

  • targeting 《经济体制改革》
  • deciding manuscript fit for this journal
  • rewriting general Chinese econ/management manuscripts for this journal
  • listing high-frequency rejection risks
  • checking official submission requirements
  • evaluating topic fit for economic system reform

When not to use

  • replacing the latest official submission guidelines
  • submitting work summaries or policy propaganda
  • forcing submission based on name, region, or variable similarity
  • using second-hand submission website formats
