dhdna-profiler

separate

Applies the DHDNA framework as an exploratory rubric for reasoning and writing patterns in supplied text. Used for explicit requests for DHDNA, cognitive-style reflection, a thinking-pattern profile, or comparisons of textual reasoning. Scores describe evidence in the sample, not validated psychological traits or personal identity.

When to use

  • DHDNA analysis
  • cognitive-style reflection
  • thinking-pattern profile
  • comparisons of textual reasoning
  • text pattern annotation
  • reasoning and rhetorical choice description

When not to use

  • validated psychological traits
  • personal identity
  • intelligence inference
  • diagnosis
  • honesty inference
  • latent emotion inference
  • stable cognitive architecture inference
  • MindBook scoring engine reproduction
