Use when preparing to submit to the Journal of Accounting and Economics (JAE) — the Editorial Manager preflight, submission-fee live check, double-anonymized file separation (anonymized manuscript plus title page), mandatory Highlights, keywords and JEL codes, and Elsevier author-date formatting.

When to use

  • Editorial Manager preflight
  • submission-fee live check
  • double-anonymized file separation
  • mandatory Highlights
  • keywords and JEL codes
  • Elsevier author-date formatting

When not to use

  • mandatory replication archive
  • numbered/Vancouver references
