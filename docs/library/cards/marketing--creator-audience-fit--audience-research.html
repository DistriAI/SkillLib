audience-research

combined

Use when the user wants to evaluate a creator, influencer, or brand audience using public profile signals, TikTok audience demographics, follower/following data, comments, geography, language, and content fit. Helps judge sponsorship and market fit. Evaluate whether a creator, influencer, or brand account reaches the right audience using public profile, aggregate demographic, geography, language, content, comment, and commerce signals. Use for creator comparisons, sponsorship fit, market fit, and audience-quality research.

When to use

  • check if a creator's audience fits a market
  • compare audience fit across creators
  • find US-heavy, country-specific, or niche-specific creators
  • evaluate sponsorship/influencer opportunities
  • understand who appears to engage with an account

When not to use

  • infer exact demographics from vibes
  • overpromise audience details for platforms that do not expose them publicly
  • ignore mismatch between creator location and audience location
  • infer protected or sensitive attributes about individuals
  • convert weak proxies into exact demographic percentages
  • confuse creator location, follower location, commenter language, and audience geography

Skill page

Conflict

The two skills perform the same task but each contains material steps the other lacks. The gooseworks copy explicitly names the scrapecreators-api and comment-mining tools, requires separating creator location from audience location, and mandates a confidence level based on source coverage, sample size, recency, and agreement across signals. The ScrapeCreators copy adds concrete API endpoints (/v1/tiktok/user/audience, /v1/tiktok/profile/region), a required SCRAPECREATORS_API_KEY environment variable, a specific markdown output template, and a 'When to Use' trigger list. Neither is a strict reproduction of the other, so crowning one would hide a real alternative.
