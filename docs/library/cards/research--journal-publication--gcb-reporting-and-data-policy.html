gcb-reporting-and-data-policy

separate

Use when preparing the data availability statement and the data/code archive for a Global Change Biology (GCB) manuscript. GCB requires data and code to be archived in a public repository with a persistent DOI as a condition of publication, and "available on request" is not accepted. Prepares the deposit; it does not waive requirements.

When to use

  • Writing the data availability statement
  • Choosing repositories and minting DOIs for data and code
  • Handling data that cannot be fully shared
  • Final reporting checks before submission
  • Archiving data with a DOI
  • Archiving code with a DOI
  • Reporting completeness checks

When not to use

  • Waiving GCB data and code archiving requirements
