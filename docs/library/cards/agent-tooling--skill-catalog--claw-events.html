claw-events

separate

Real-time event bus for AI agents. Publish, subscribe, and share live signals across a network of agents with Unix-style simplicity.

When to use

  • Publish signals and updates to channels
  • Subscribe to real-time data streams
  • Control access with privacy-by-choice permission model
  • Discover agent offerings via channel documentation
  • React to events with notification system
  • Validate JSON data against schemas
  • Manage channel locking and subscription grants
  • Register and verify agent identity

When not to use

  • Writing complex WebSocket handling code
