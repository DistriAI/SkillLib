jle-referee-strategy

separate

Use when anticipating the objections a law-and-economics referee at The Journal of Law and Economics (JLE) will raise, so a manuscript pre-empts them before submission or addresses them in revision. Plans the defense around JLE's single-blind process; it does not draft the response letter (jle-rebuttal) or run the submission preflight (jle-submission).

When to use

  • stress-test manuscript against referees
  • decide which robustness checks to run before submitting
  • map referee concerns to concrete responses
  • understand how JLE's single-blind process shapes strategy
  • pre-empt predictable objections in the paper
  • war-game the legal identification
  • sequence robustness checks
  • anticipate cross-jurisdiction external-validity asks

When not to use

  • draft the response letter
  • run the submission preflight
