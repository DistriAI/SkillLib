sf-topic-selection

separate

Use when deciding whether a project fits Social Forces (SF) and how to frame it. SF is a general social-science journal (centered on sociology) that prizes methodological rigor and a theoretically grounded contribution of interest to a broad audience. Helps frame the question and judge fit; it does not collect data.

When to use

  • Choosing among possible projects or framings for an SF submission
  • Judging if a paper is too narrow, descriptive, or under-identified
  • Deciding if a project is better suited to SF than a subfield or methods outlet
  • Pressure-testing fit before investing in a project
  • Framing questions for a general social-science audience
  • Scoring manuscript on venue fit, novelty, evidence readiness, and audience ownership
  • Comparing against sibling venues like ASR, AJS, Demography, or JMF

When not to use

  • Collecting data
  • Polishing format after fit is established
  • Giving submission-ready advice without checking official source maps
