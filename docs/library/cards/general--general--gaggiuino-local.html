gaggiuino-local

separate

Gaggiuino analytical skill for machine control, shot expression analysis, and high-performance visualization. It interprets shot data through profile intent and generates unified static/animated graphs or synchronized video overlays.

When to use

  • checking current machine state
  • analyzing the latest shot
  • generating static graphs
  • dialing in or troubleshooting espresso taste
  • recommending a profile
  • listing or switching profiles
  • reading or updating Gaggiuino settings
  • interpreting graph screenshots

When not to use

  • generic coffee essay generator
  • profile-name cookbook detached from real machine behavior
  • answering live-status questions from memory
  • general dial-in reasoning without machine control
