arecon-review-process

separate

Use when calibrating expectations for the Annual Review of Economics (ARE) Editorial Committee review cycle on an invited article — what happens after delivery, who reviews, the accuracy/rigor/balance bar, and the annual-volume timeline. Sets expectations; it does not run the delivery preflight (arecon-submission) or draft the response letter (arecon-revision).

When to use

  • calibrating expectations for ARE review cycle
  • understanding post-delivery review process
  • planning around annual-volume production schedule
  • resetting coauthor expectations to Committee cadence
  • pre-empting predictable referee pushbacks
  • handling author-Committee conflicts of interest

When not to use

  • running the delivery preflight
  • drafting the response letter
