Skill page

Conflict

The two copies implement the same multi-round external research review workflow, but they disagree on the reviewer backend, model, reasoning effort, MCP setup, and prompt structure. The wanshuiyin copy is a more evolved, backend-routed version (Codex or Manual) with a file-based brief, adversarial framing, and explicit scope limits. The brycewang copy is a simpler Codex-only version with inline context, xhigh reasoning, and a set of follow-up prompt templates. Neither is a strict reproduction of the other; crowning one would hide a real alternative (manual backend vs Codex-only, file brief vs inline context, ultra vs xhigh).
