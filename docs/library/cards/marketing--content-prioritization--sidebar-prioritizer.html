sidebar-prioritizer

separate

Reset and prioritize the Codex task sidebar with work categories, P0–P4 priorities, and B7 labels for tasks inactive beyond seven days. Use for sidebar cleanup, confusing task lists, or refreshing follow-up priorities.

When to use

  • sidebar cleanup
  • confusing task lists
  • refreshing follow-up priorities
  • reset and prioritize
  • audit sidebar plan
  • assign work categories
  • assign P0-P4 priorities
  • apply B7 labels

When not to use

  • resume tasks
  • change repository worktrees
  • rename Git checkouts
  • delete Git checkouts
  • reset Git checkouts
  • move Git checkouts
  • install a routine
  • include archived tasks unless requested
