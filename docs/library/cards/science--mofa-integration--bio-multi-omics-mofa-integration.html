bio-multi-omics-mofa-integration

separate

Multi-Omics Factor Analysis (MOFA2) for unsupervised integration of multiple data modalities. Identifies shared and view-specific sources of variation. Use when integrating RNA-seq, proteomics, methylation, or other omics to discover latent factors driving biological variation across modalities.

When to use

  • integrating RNA-seq, proteomics, methylation, or other omics
  • discovering latent factors driving biological variation
  • identifying shared and view-specific sources of variation
  • unsupervised integration of multiple data modalities
  • multi-group MOFA for batch- or group-structured data
  • factor interpretation via gene set enrichment
  • visualizing factor values, feature weights, and correlations
