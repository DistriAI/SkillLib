joe-replication-and-data-policy

separate

Use to prepare code and data materials for a Journal of Econometrics (JoE) submission under Elsevier's data-citation and availability norms, including reproducible Monte Carlo and the [dataset] reference tag. Reflects that JoE has no mandatory central replication archive — replication is encouraged, not universally mandated.

When to use

  • assembling code/data materials for a JoE submission
  • determining if a mandatory JoE-specific central replication archive is required
  • citing a dataset in the correct Elsevier format
  • making Monte Carlo or empirical illustration reproducible for referees
  • preparing a reproducible methodology package
  • conducting a reproducibility pass for Journal of Econometrics

When not to use

  • preparing for Econometric Society journals with mandatory Data Editor packages
  • preparing for Journal of Applied Econometrics with mandatory central archives
