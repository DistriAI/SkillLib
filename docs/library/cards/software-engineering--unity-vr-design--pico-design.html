Doc-anchored design rules for PICO Unity Integration SDK v3.4.0 — XR/MR/platform services, version diffs 2.x-3.4, hallucination shields

When to use

  • Writing or reviewing PICO Unity Integration SDK code
  • Setting up a PICO XR project or choosing the Unity OpenXR plugin route
  • Video seethrough, spatial anchors, spatial mesh, SecureMR, and platform services
  • Migrating from SDK 2.x or an older 3.x version

When not to use

  • General XR Interaction Toolkit interaction (rig/grab/teleport/XR UI)
  • Architecture and lifecycle decisions
  • Performance review hot paths
  • URP assets and rendering pipeline operations
