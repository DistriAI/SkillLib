Generate or edit artwork with built-in Codex image gen, especially transparent PNG ornaments, game sprites, emblems, and UI graphics. Use when the user requests GPT 2.5 Flare, /codex-gpt-image-2-5-flare, or this built-in transparent-asset workflow. Includes alpha verification, prompt preservation, and optional project integration.

When to use

  • Generate transparent PNG ornaments
  • Create game sprites
  • Design emblems
  • Produce UI graphics
  • Edit existing images
  • Integrate assets into projects
  • Verify PNG transparency

When not to use

  • Substitute external image APIs
  • Use CLI or external providers
  • Hand-draw SVGs
  • Invent model arguments
  • Report unverified models as fact
  • Silently chroma-key flat backgrounds
  • Paint over backgrounds
  • Substitute vector assets
