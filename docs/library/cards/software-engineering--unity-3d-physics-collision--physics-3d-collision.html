physics-3d-collision

separate

Diagnoses 3D PhysX collision and trigger problems. Use when OnCollisionEnter or OnTriggerEnter doesn't fire, objects pass through each other, raycasts miss, or a MeshCollider misbehaves. Also answers 2D and DOTS physics best-effort if no dedicated skill is available.

When to use

  • 3D PhysX collision problems
  • 3D PhysX trigger problems
  • OnCollisionEnter not firing
  • OnTriggerEnter not firing
  • objects passing through each other
  • raycasts missing
  • MeshCollider misbehavior
  • 2D physics best-effort

When not to use

  • 2D physics primary scope
  • DOTS physics primary scope
