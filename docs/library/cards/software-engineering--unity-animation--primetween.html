Inspect PrimeTween Free and generate runtime tween scripts

When to use

  • Checking PrimeTween installation status
  • Exploring supported animation APIs
  • Generating Transform animation code
  • Generating Sequence animation code
  • Reading global runtime configuration
  • Listing public static factory methods

When not to use

  • Configuring DOTween-style settings assets
  • Creating PrimeTween Pro components
  • Generating scripts for APIs outside the supported Transform set
