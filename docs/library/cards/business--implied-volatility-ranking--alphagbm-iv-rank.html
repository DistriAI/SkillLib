alphagbm-iv-rank

separate

Volatility Snapshot via the published AlphaGBM interface. Use for this focused function, not as a promise that every website API accepts API keys.

When to use

  • Volatility Snapshot
  • Reading asset identity, dates, units, and score type
  • Checking missing-data flags
  • Retrieving stock risk scores

When not to use

  • Full research workflows
  • Fabricating 252-day IV Rank
  • Generating trade instructions or guaranteed fills
  • Silent fallback to demo data
  • Treating risk scores as opportunity scores
