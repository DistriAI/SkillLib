baseline-ui

authentic

Quickly deslop UI code by fixing spacing, hierarchy, typography, and small layout issues. Use when the interface needs a fast cleanup or polish pass.

When to use

  • fixing spacing
  • fixing hierarchy
  • fixing typography
  • fixing small layout issues
  • fast cleanup
  • polish pass
  • reviewing UI files against constraints

When not to use

  • rebuilding keyboard or focus behavior by hand
  • adding animation unless explicitly requested
  • using gradients unless explicitly requested
  • using purple or multicolor gradients
  • using glow effects as primary affordances
  • modifying letter-spacing unless explicitly requested
  • introducing custom easing curves unless explicitly requested
