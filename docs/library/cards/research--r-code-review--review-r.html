review-r

authentic

Run the R code review protocol on R scripts. Checks code quality, reproducibility, domain correctness, and professional standards. Produces a report without editing files.

When to use

  • Review specific R scripts
  • Review all R scripts in a lecture
  • Review all R scripts in scripts/R/ and Figures
  • Check code quality and reproducibility
  • Check domain correctness and professional standards

When not to use

  • Editing R source files
  • Applying fixes to code
