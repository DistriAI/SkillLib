cn-official-document

authentic

Use when asked 帮我写公文, 写一份请示, 写通知 / 报告 / 函 / 纪要, 公文格式怎么排, check this document against GB/T 9704, or draft an official document for a Chinese government body, public institution or state-owned enterprise. Produces a 公文 in the right document type with every required element in the order GB/T 9704-2012 sets, heading levels and numbering, a layout specification for Word or WPS, and a check of the type-specific rules such as one matter per 请示.

When to use

  • Writing 请示, 通知, 报告, 函, or 纪要
  • Checking document format against GB/T 9704
  • Drafting official documents for Chinese government bodies
  • Drafting official documents for public institutions
  • Drafting official documents for state-owned enterprises
  • Determining correct document type and element order
  • Providing layout specifications for Word or WPS
  • Checking type-specific rules like one matter per 请示

When not to use

  • Inventing 发文字号 numbers
  • Using colloquial wording
  • Writing 报告 that asks for approval
  • Combining multiple requests in one 请示
