i4h-workflow-dataset-convert

separate

Convert workflow HDF5 recordings to LeRobot datasets for training or browser inspection. Use for conversion; do not use for replay, augmentation, or raw-data repair.

When to use

  • Preserve recorded actions, state, cameras, task text, and embodiment labels in a local LeRobot dataset.

When not to use

  • Conversion cannot reconstruct missing cameras, actions, state, task text, or successful episodes.
