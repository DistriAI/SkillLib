3d-sky-background

separate

Create a camera-correct sky background for a 3D scene with a procedural atmosphere or panorama, horizon haze, aligned sunlight, and coherent environment lighting. Use for architectural skies, outdoor 3D backgrounds, golden hour, and day-to-night sky transitions.

When to use

  • architectural skies
  • outdoor 3D backgrounds
  • golden hour
  • day-to-night sky transitions
  • procedural sky
  • panorama mapping
  • environment lighting
  • sunlight alignment

When not to use

  • adding a second renderer for the sky
  • using a background photograph alone to light PBR objects
  • using a PMREM environment to supply a shadow-casting directional sun
  • stretching a wide landscape photograph indiscriminately over a sphere
  • copying a fitted inverse tone-map function from another project
  • gating first interaction on an oversized sky image
  • rebuilding PMREM every frame
