accessibility-test-plan

separate

Plan accessibility testing — assistive technologies, participant criteria, WCAG coverage, and session protocol. Use when scheduling testing with real AT users. Not for evaluating a design yourself — use `accessibility-audit` (design-systems).

When to use

  • Planning accessibility testing
  • Scheduling testing with real AT users
  • Defining assistive technology coverage
  • Setting participant criteria
  • Defining WCAG coverage
  • Creating session protocols

When not to use

  • Evaluating a design yourself
