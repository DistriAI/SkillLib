imfer-topic-selection

separate

Use when deciding whether a question is right for an IMF Economic Review (IMFER) manuscript — international macro-finance with genuine policy relevance and an IMF-program or global-institution audience. Tests fit and scope; it does not run the identification (imfer-identification) or stake the contribution (imfer-literature-positioning).

When to use

  • deciding if a question clears IMFER's international-macro-with-policy-relevance bar
  • choosing between IMFER, JIE, JIMF, JMCB, AEJ: Macro, or Economic Policy
  • identifying the policy 'so what' for an IMF audience
  • aligning a question to a Jacques Polak ARC or special issue theme
  • evaluating if a topic is too domestic or too narrowly technical for IMFER
  • running the fit test before writing the intro
  • checking country scope for general lessons
  • distinguishing IMFER from sibling journals

When not to use

  • running the identification (imfer-identification)
  • staking the contribution (imfer-literature-positioning)
