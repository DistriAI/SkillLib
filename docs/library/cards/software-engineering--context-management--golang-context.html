golang-context

separate

Idiomatic context.Context usage in Golang — propagation through API boundaries, cancellation, timeouts and deadlines, request-scoped values, context.WithoutCancel for background work outliving requests. Apply when designing context propagation across layers, debugging leaked or unexpired contexts, choosing between context.Background/TODO/WithoutCancel, or storing values in context. Not for code that merely accepts ctx as first parameter.

When to use

  • designing context propagation across layers
  • debugging leaked or unexpired contexts
  • choosing between context.Background/TODO/WithoutCancel
  • storing values in context
  • cancellation, timeouts and deadlines
  • request-scoped values
  • context.WithoutCancel for background work

When not to use

  • code that merely accepts ctx as first parameter
