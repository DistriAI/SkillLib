Conflict

The copies overlap heavily on the core rule (invoke skills before any response), the red flags table, and skill priority. However, they disagree on the mechanism and contain material steps the others lack. The obra/superpowers copy is the canonical source but uses a different invocation model (announce and follow, no explicit Skill tool) and includes a Platform Adaptation section and a Subagent Stop guard. The other three copies (sickn33, LeoYeAI, FreedomIntelligence) are near-identical mirrors that explicitly mandate the use of the `Skill` tool and include a Graphviz flowchart. Crowning one would hide the real alternative between the 'announce/follow' model and the 'Skill tool' model.
