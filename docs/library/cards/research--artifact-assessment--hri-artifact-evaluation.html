hri-artifact-evaluation

separate

Use when packaging the artifacts of an accepted ACM/IEEE HRI paper — code, robot behaviors, de-identified data, and study materials — for openness and any ACM badges the edition offers, while being honest about the limits of reproducing an embodied human-subjects study.

When to use

  • Packaging HRI paper artifacts
  • Preparing for ACM artifact badges
  • Documenting robot-behavior specifications
  • Sharing de-identified study data
  • Providing analysis code for reproducibility
  • Managing human-subjects consent constraints

When not to use

  • Recreating exact human responses
  • Releasing identifiable data without consent
  • Chasing badges that do not exist for the cycle
  • Treating 'data available on request' as available
