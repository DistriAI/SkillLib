csj-supplementary

separate

在为《计算机科学》(Computer Science, JSJKX) 组织正文与附录/补充材料/多媒体附件的取舍时调用。本刊是计算机全学科中文综合月刊(CCF 会刊、B 类、T2 级)。技能帮助按"决定性"划分正文与附录：核心 RQ 证据留正文，完整超参表、额外数据集、证明细节、扩展实验、算法伪代码、代码与数据链接等放附录或补充材料；并规范补充材料的引用、命名与可访问性，兼顾本刊长文与综述的篇幅特点。适用于稿件内容多、需决定哪些进正文哪些进附录以保证正文可读性与外审效率的场景。

When to use

  • 划分正文与附录内容
  • 决定核心证据与支撑细节归属
  • 规范补充材料引用与命名
  • 管理长文与综述篇幅
  • 组织附录结构与可读性
  • 确保补充材料长期可访问
  • 处理综述大表格下沉
  • 根据审稿反馈动态调整内容

When not to use

  • 非《计算机科学》期刊的投稿规范
  • 会议论文投稿流程
  • 具体代码实现或算法开发
  • 数据清洗或预处理操作
