Skill page

Conflict

The two skills share the name 'scan' but perform fundamentally different tasks. The first is a lightweight codebase assessment tool that produces planning documents in .planning/codebase/ using a specific workflow file. The second is a supply chain security scanner (agent-bom) that checks packages for CVEs, scans container images, and generates SBOMs. They do not overlap in procedure, tools, or output, so crowning one would hide a real alternative.
