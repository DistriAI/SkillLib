Internal implementation skill invoked by /add-native for native PDF control workflows. Handles HTTPS and file URI PDF viewing with @microsoft/power-apps-native-pdf-viewer 0.2.9+.

When to use

  • native PDF control workflows
  • HTTPS PDF viewing
  • file URI PDF viewing
  • generating native PDF viewer wrapper
  • verifying native PDF viewer wrapper
  • showing native React Native API usage

When not to use

  • HostingSDK / PCF path
  • installing packages
  • editing native config
  • content:// URIs
  • blob: URIs
  • http:// URLs
