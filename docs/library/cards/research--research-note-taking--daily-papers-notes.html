daily-papers-notes

separate

Generate full notes for must-read recommendations, maintain concepts, and backfill links. English triggers: "generate paper notes", "batch paper notes". This is pipeline stage 3. 论文笔记生成（3 步流水线的第 3 步）。补充概念库，为推荐论文生成完整笔记， 链接回填到推荐文件；目录页默认自动刷新，git 自动化默认关闭。 触发词："批量笔记"、"跑一下论文笔记"

When to use

  • generate paper notes
  • batch paper notes
  • maintain concepts
  • backfill links
  • refresh MOC indexes
  • quality check existing notes

When not to use

  • generate notes for 'worth looking' papers
  • generate notes for 'skippable' papers
  • run without prerequisite enriched data
  • run without prerequisite recommendation file
