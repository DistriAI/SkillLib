aeja-replication-package

separate

Use when assembling the data and code replication package for an American Economic Journal: Applied Economics (AEJ: Applied) manuscript to pass the AEA Data and Code Availability Policy and the AEA Data Editor's pre-publication reproducibility check. Builds the openICPSR deposit and README; it does not run the analysis or write the paper.

When to use

  • Assembling data and code replication package
  • Building openICPSR deposit
  • Writing AEA README
  • Writing Data Availability Statement
  • Planning deposit for restricted data
  • Preparing for AEA Data Editor check

When not to use

  • Running the analysis
  • Writing the paper
