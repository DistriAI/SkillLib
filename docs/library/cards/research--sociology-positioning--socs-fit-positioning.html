socs-fit-positioning

separate

Use to judge whether a manuscript fits 《社会学研究》 (Sociological Studies) — distinguishing a genuine sociological problematic from an economics-style policy-evaluation paper, and re-routing the latter to economics or cross-disciplinary journals. Use first, before drafting, when discipline fit is uncertain.

When to use

  • judging manuscript fit for 《社会学研究》
  • distinguishing sociological problematic from policy evaluation
  • checking if data narrative is economics-style
  • confirming discipline fit before submission
  • identifying 'borderline but not fitting' rejection patterns
  • applying the 'delete policy' test
  • routing manuscripts to appropriate journals

When not to use

  • drafting the manuscript
  • conducting empirical analysis
  • writing for 《中国社会科学》
  • writing for economic journals
