nbr-hypothesis-development

separate

Use to develop hypotheses for 《南开管理评论》 (Nankai Business Review) so each is backed by an explicit theoretical mechanism, not intuition. Use when hypotheses read as "we expect a positive relationship", when mediation/moderation logic is asserted without a mechanism, or when the hypothesis set is not derived from the theory invoked in the introduction.
