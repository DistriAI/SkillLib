github-ops

separate

Operates GitHub via gh CLI and REST/GraphQL — PRs, issues, Actions, repos, collaborators, org permissions, 2FA — with explicit target, authorization, and independent readback. Use when a write reports success but state didn't change, or choosing gh/REST/GraphQL/UI-only. Not for local Git recovery (use git-safety-net), maintainer PR review (use github-review-pr), or upstream contribution (use github-contributor).

When to use

  • Create, review, merge, close, compare, or converge PRs
  • Create, edit, search, transfer, close, or bulk-manage issues
  • Inspect, clone, create, edit, rename, archive, transfer, change visibility, or delete repositories
  • Copy repositories accessible to another account while keeping the usual account active
  • Inspect or change collaborators, teams, base permissions, member privileges, or organization 2FA
  • Protect a default branch while letting collaborators contribute through PRs
  • Trigger, inspect, rerun, cancel, or purge Actions; manage secrets or variables
  • Build and publish a Docker/OCI image to GitHub Container Registry (GHCR)

When not to use

  • Local Git recovery
  • Maintainer PR review
  • Upstream contribution
