github-review-pr

separate

Reviews PRs against the live base with immutable objects and three-way merges. Use for PR review/merge readiness, main changed, closed-PR reconsideration, open-PR sweeps, review-led repair, or explicitly requested independent review of your own contribution. Not for GitHub CRUD (use github-ops), authoring/maintaining your PR (use github-contributor), or merging without fresh review.

When to use

  • PR review
  • merge readiness
  • closed-PR reconsideration
  • open-PR sweeps
  • review-led repair
  • independent review of own contribution

When not to use

  • GitHub CRUD
  • authoring/maintaining your PR
  • merging without fresh review
  • Create or administer PRs, issues, repositories, or workflows
  • Diagnose CI without reviewing the code change
  • Address already-filed review comments without performing a fresh review
  • Review an unpushed local branch or working-tree diff
  • Run a security-only diff audit
