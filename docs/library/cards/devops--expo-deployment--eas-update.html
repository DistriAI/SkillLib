eas-update

separate

Configure and use EAS Update for over-the-air JavaScript and asset updates with expo-updates and EAS CLI. Use when setting up OTA updates, running eas update:configure or eas update, publishing to preview/staging/production channels, explaining branches/channels/runtime versions, testing updates, or debugging why an installed build still shows old code. Load for TestFlight, preview, or production updates that do not appear, including questions about cold launches or reopening the app. Not for update health metrics; use eas-update-insights for adoption, crashes, and rollout monitoring.

When to use

  • setting up OTA updates
  • running eas update:configure or eas update
  • publishing to preview/staging/production channels
  • explaining branches/channels/runtime versions
  • testing updates
  • debugging why an installed build still shows old code
  • TestFlight, preview, or production updates that do not appear
  • questions about cold launches or reopening the app

When not to use

  • update health metrics
  • adoption, crashes, and rollout monitoring
