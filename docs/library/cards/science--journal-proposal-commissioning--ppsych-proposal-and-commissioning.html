ppsych-proposal-and-commissioning

separate

Use when shaping a proposal for a Perspectives on Psychological Science (PoPS) contribution — the proposal route (required for cooperative and miscellaneous pieces, optional for stand-alone), what a proposal contains, and how invited/special-issue work differs. Frames the pitch; it does not gather the literature (ppsych-literature-synthesis) or run the submission preflight (ppsych-submission).
