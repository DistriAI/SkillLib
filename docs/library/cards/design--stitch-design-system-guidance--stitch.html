stitch

combined

Semantic Design System Skill for Google Stitch. Generates agent-friendly DESIGN.md files that enforce premium, anti-generic UI standards — strict typography, calibrated color, asymmetric layouts, perpetual micro-motion, and hardware-accelerated performance. Clean, high-contrast enterprise design for data-driven workflows with intuitive drag-and-drop patterns and structured layouts.

When to use

  • Generating DESIGN.md files
  • Defining visual atmosphere
  • Mapping color palettes
  • Establishing typography rules
  • Defining hero sections
  • Describing component stylings
  • Defining layout principles
  • Defining responsive rules

When not to use

  • Using Inter font for premium contexts
  • Using generic serif fonts
  • Using pure black (#000000)
  • Using AI Purple/Blue Neon aesthetics
  • Using centered Hero layouts when variance exceeds 4
  • Using 3 equal cards horizontally
  • Using generic circular spinners
  • Using h-screen for full-height sections

Conflict

The two copies target the same Google Stitch workflow but encode different, non-reproducible procedures. Leonxlnx/taste-skill is a semantic, anti-generic design-taste generator that produces a DESIGN.md with atmosphere, banned AI clichés, typography bans, hero rules, and motion philosophy. bergside/awesome-design-skills is a brand-specific, enterprise drag-and-drop design-system authoring skill with fixed tokens (Ubuntu/Oswald, #072C2C, etc.), accessibility-first rules, and a required output structure. Neither is a shortened or wrapped version of the other; crowning one would hide a real alternative. They agree on the high-level goal (produce Stitch-ready design guidance) and on the need for explicit anti-patterns and component states, but they conflict on palette, typography, tone, and output structure.
