molcell-citation

separate

Use to convert references to the current Cell Press numbered style used by Molecular Cell — superscript numbers in order of first appearance, a reference list numbered in that order, full author lists (no et al.), abbreviated journal names. This is NOT author-date; older Cell Press author-date manuscripts must be renumbered.

When to use

  • converting author-date references to Cell Press numbered style
  • renumbering reference lists from alphabetical to citation order
  • expanding truncated author lists in bibliographies
  • porting manuscripts from name-year journals to Molecular Cell
  • merging separate STAR Methods bibliographies into a single list
  • formatting in-text citations as superscript numbers

When not to use

  • author-date citation styles
  • journals that stay name-year like Genetics
  • older Cell Press author-date manuscripts without renumbering
