education-data-source-eada

separate

EADA — college athletics gender equity (~2,000+ institutions, 2002-2021). Participation, coaching, salaries, expenses, revenues, athletic aid by gender. Not Title IX compliance data. No sector column; join IPEDS on unitid for institution type.

When to use

  • athletic participation by gender
  • coaching staff analysis
  • salaries by gender
  • athletic expenses and revenues
  • athletic aid by gender
  • gender equity overview
  • sport-specific analysis
  • trend analysis

When not to use

  • Title IX compliance assessment
  • determining Title IX compliance from EADA data alone
