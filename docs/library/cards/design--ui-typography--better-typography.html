better-typography

separate

Sets and reviews how text renders in your product, from the type scale and spacing to font features, wrapping, truncation and punctuation.

When to use

  • type scale and spacing
  • font loading and synthesis
  • wrapping and truncation
  • punctuation and case
  • line-height and letter-spacing
  • tabular numbers
  • heading hierarchy

When not to use

  • word choice and writing
  • semantic heading structure
  • spatial RTL layout
  • contrast measurement
  • accessibility pass/fail determination
  • proposing new typefaces
