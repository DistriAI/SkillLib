arpsych-editor-strategy

separate

Use when managing scope, length, deadlines, and the production relationship with the Annual Review of Psychology (ARPsych) Editor and Annual Reviews production team. Handles the editorial/production process; it does not get the initial invitation (arpsych-proposal-and-commissioning) or run the final file preflight (arpsych-submission).

When to use

  • Managing scope, length, and milestones with the Editor
  • Handling drafts drifting over assigned length or past due date
  • Addressing Editor or Committee questions about scope or overlap
  • Understanding the Annual Reviews production timeline
  • Negotiating length or scope boundaries early
  • Flagging figure permissions and balance concerns

When not to use

  • Getting the initial invitation
  • Running the final file preflight
  • arpsych-proposal-and-commissioning
  • arpsych-submission
