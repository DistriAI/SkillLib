red-tables-figures

separate

Use when designing the exhibits of a Review of Economic Dynamics (RED) manuscript — impulse-response functions, calibration tables, moment-matching (model-vs-data) tables, policy-experiment figures, and accuracy diagnostics — so a quantitative dynamic paper communicates its mechanism and fit clearly to the SED readership.

When to use

  • Designing exhibits for RED manuscripts
  • Creating impulse-response functions
  • Building calibration tables
  • Creating moment-matching tables
  • Designing policy-experiment figures
  • Creating accuracy diagnostics
  • Showing model-vs-data fit
  • Visualizing dynamic mechanisms

When not to use

  • Causal-inference toolchain tasks
  • Static regression tables as primary exhibits
  • Steady-state-only comparisons
  • Moment tables showing only targeted moments
