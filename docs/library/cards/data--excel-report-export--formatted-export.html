formatted-export

separate

从多Sheet Excel文件中识别指定条件的记录，并将筛选结果以整行标红格式导出为Excel文件，适用于数据清洗、条件筛选与可视化标记场景。

When to use

  • 数据清洗
  • 条件筛选
  • 可视化标记
  • 多Sheet Excel扫描
  • 模糊匹配定位目标列
  • 筛选空值或无效字符记录
  • 整行标红导出Excel

When not to use

  • reading/counting/Parquet optimization
