soctheory-workflow

separate

Use when deciding which soctheory-* sub-skill to invoke next, or when sequencing a Sociological Theory manuscript from theoretical-problem framing through peer-review revision for a Sociological Theory (ST) submission. Routes — does not replace — the specialized skills.

When to use

  • Deciding which soctheory-* sub-skill to invoke next
  • Sequencing a Sociological Theory manuscript
  • Locating the bottleneck in a draft
  • Handling ST decision letters and revision
  • Routing between theorizing, diagram-building, and prose

When not to use

  • Hypothesis-testing
  • Estimation
  • Producing a results section
  • Causal effect identification in a dataset
  • Replacing specialized soctheory-* skills
