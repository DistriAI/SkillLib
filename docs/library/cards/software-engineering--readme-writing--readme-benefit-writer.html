readme-benefit-writer

authentic

Use when asked to rewrite a README so strangers understand why they should care, turn a feature list into benefits, make a side project's README convincing, or explain what users get rather than what the code does. Rewrites an existing README so every feature is stated as a user benefit in plain sentences, and produces a one-line pitch, a Why section, a benefit-led feature list, a quick start, a Your data section and a contribution pointer. For a README written from scratch with badges, usage and install sections, use readme-writer.
