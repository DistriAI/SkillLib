tao-route-visual-changenet-samples

separate

Routes the weakest VCN samples (output of `tao-analyze-gaps-visual-changenet`) into per-augmentation-module

When to use

  • route VCN gap samples
  • split AOI gaps for k-NN mining and AnomalyGen
  • prepare next step after DEFT gap analysis
  • filter gap-analysis parquet by module eligibility
  • generate per-label routing summary

When not to use

  • performing gap analysis
  • executing k-NN mining
  • executing AnomalyGen generation
  • modifying source pool CSV
