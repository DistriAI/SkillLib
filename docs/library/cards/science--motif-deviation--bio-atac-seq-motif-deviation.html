bio-atac-seq-motif-deviation

separate

Analyze transcription factor motif accessibility variability using chromVAR. Use when identifying which TF motifs show variable accessibility across samples or conditions in ATAC-seq data.

When to use

  • Compute per-sample deviation scores for TF motif accessibility
  • Identify regulators driving chromatin state differences
  • Measure per-sample variability in transcription factor motif accessibility
  • Identify TF motifs with significantly different accessibility between experimental groups
