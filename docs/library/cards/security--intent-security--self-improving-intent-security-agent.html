self-improving-intent-security-agent

separate

Documentation-first skill and workflow toolkit for intent-based security. Provides templates, examples, and local helper scripts for capturing intent, reviewing actions, documenting rollbacks, and recording learnings. Use when: (1) designing or prototyping intent validation workflows, (2) documenting high-risk operations, (3) creating audit trails and rollback records, (4) building your own runtime enforcement layer.

When to use

  • designing or prototyping intent validation workflows
  • documenting high-risk operations
  • creating audit trails and rollback records
  • building your own runtime enforcement layer
  • capturing intent specifications
  • logging violations and anomalies
  • recording learnings and strategies
  • scaffolding run packs for conversation-driven workflows

When not to use

  • shipping a production runtime engine that automatically intercepts agent actions
  • automatic enforcement
  • anomaly detection
  • rollback execution
  • learning application
