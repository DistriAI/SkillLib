platform-custom-report-type-generate

authentic

Use to create, generate, or validate Salesforce Custom Report Type metadata. Trigger on custom report types, CRTs, cross-object reports, report builder data sources, exposing fields for reporting across related objects, inner vs outer joins in reports, report type categories, or deployment errors for .reportType-meta.xml files. Do NOT trigger for running, editing, or filtering existing reports; creating report folders, dashboards, or list views; or non-authoring reporting questions.

When to use

  • Enable reporting across custom objects and custom relationships not covered by standard report types
  • Curate a focused set of fields for report builders (including fields reached via lookup)
  • Control inner/outer join behavior to include or exclude primary records without related records
