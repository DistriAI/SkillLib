jegeo-rebuttal

separate

Use when a Journal of Economic Geography (JEG) decision letter arrives and you must plan a revision and response that satisfies a cross-disciplinary referee pair. Structures the rebuttal; it does not invent results or concede the core claim.

When to use

  • triage R&R or major-revision reports
  • plan revision and response for JEG
  • structure rebuttal for cross-disciplinary referees
  • decide on spatial work requests
  • draft response letter for editor and referees
  • balance economist and geographer feedback
  • classify comments by community and demand
  • handle conflicting referee requests

When not to use

  • invent results
  • concede the core claim
  • silently ignore unreasonable comments
  • report only favorable spatial checks
  • promise changes without showing evidence
