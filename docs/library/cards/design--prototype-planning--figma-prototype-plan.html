figma-prototype-plan

authentic

Plan prototype interactions and flows for user testing in Figma. Use when asked to plan a Figma prototype, set up prototype interactions, define what to prototype for a user test, or prepare a Figma prototype for usability testing. Produces a prototype scope, interaction specification, test task scripts, and Figma setup guide.

When to use

  • Plan a Figma prototype
  • Set up prototype interactions
  • Define what to prototype for a user test
  • Prepare a Figma prototype for usability testing
  • Write test task scripts
  • Determine build vs fake elements

When not to use

  • Prototype everything
  • Design flows without test task scripts
  • Skip reset process between participants
  • Plan without specifying clickable vs static interactions
  • Scope without defining research questions
