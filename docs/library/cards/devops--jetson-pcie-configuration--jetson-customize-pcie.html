jetson-customize-pcie

separate

Per-controller PCIe enable / disable / lanes / link-speed for a Jetson Thor or Orin custom carrier via ODMDATA + kernel-DT overlay. Do NOT use for UPHY lane allocation or endpoint-mode bring-up.

When to use

  • configure PCIe
  • enable PCIe controller
  • set PCIe num-lanes
  • change PCIe link speed
  • flip a pcie@N_status token
  • fix PCIe slot enumeration
  • fix PCIe link width or speed
  • bring up per-controller PCIe after UPHY re-allocation

When not to use

  • **Mode hard-pinned to RC.** Endpoint mode is only emitted when the
  • **`enable` is derived, not asked.** UPHY-allocated controllers are
  • **No upstream BSP edits.** Output lands in `Linux_for_Tegra/` +
  • **Pre-flight overlay merge is a sanity check**, not the production
  • **Flash-conf overlay registration is out of scope.** Owned by
