ecj-tables-figures

separate

Use when finalizing the main exhibits (tables and figures) of a The Economic Journal (EJ) manuscript so each one carries economic content, reads to a general audience, and is self-contained. Sets exhibit design and notes standards; it does not decide which results to report (see ecj-robustness).
