CSS — annual Clery Act crime/fire safety for Title IV institutions. Portal: hate crimes only (2005-2021); primary offenses, VAWA, arrests, fire safety need ope.ed.gov directly. Use for campus crime analysis. Identified by IPEDS unitid.

When to use

  • campus crime analysis
  • Clery Act reporting structure
  • hate crimes data via Portal
  • primary offenses analysis
  • VAWA offenses analysis
  • arrests and referrals data
  • fire safety data
  • campus geography categories

When not to use

  • non-Title IV institutions
  • data prior to 2005
  • data after 2021 for Portal mirrors
