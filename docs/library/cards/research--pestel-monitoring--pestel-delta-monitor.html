pestel-delta-monitor

separate

Quarterly re-scan of a prior PESTEL analysis. Use when checking which macro factors moved, which assumptions broke, and what's new — turning PESTEL from a workshop artifact into a radar.

When to use

  • Refresh a PESTEL analysis by diffing each factor — Political, Economic, Social, Technological, Environmental, Legal — against the prior run and reporting **material movement only**: **search plan → factor-by-factor diff → broken assumption…

When not to use

  • Running a full PESTEL analysis without a prior baseline
  • Diffing across a scope change or pivot
  • Re-debating factors with no material movement
