  • rhythm cuts

  • musical structure
  • BPM
  • mood
  • genre
  • instrument questions

When not to use

  • decoding media
  • starting inference
  • requesting CLAP embedding
  • returning CLAP embedding
  • quoting CLAP embedding
  • summarizing CLAP embedding
