svy

separate

Complex survey analysis: strata/PSU/weights, variance estimation (Taylor, BRR, jackknife, bootstrap), survey GLM, domain analysis, calibration. Polars-native. Use for NHANES, CPS, ACS PUMS, BRFSS, DHS. Non-survey regression: statsmodels/pyfixest.

When to use

  • strata/PSU/weights specification
  • variance estimation (Taylor, BRR, jackknife, bootstrap)
  • survey GLM regression
  • domain analysis
  • calibration
  • NHANES, CPS, ACS PUMS, BRFSS, DHS analysis
  • survey data I/O (SAS, SPSS, Stata)

When not to use

  • non-survey regression
  • fixed effects models
  • panel/IV models
  • ordinal logistic regression
  • Cox survival models
