Use when designing or reviewing reusable Jetpack Compose component APIs with modifier parameters, root layout placement, caller-provided variable content, primitive content parameters, optional content, or boolean shape flags.

When to use

  • designing reusable Jetpack Compose component APIs
  • reviewing reusable Jetpack Compose component APIs
  • modifier parameters
  • root layout placement
  • caller-provided variable content
  • primitive content parameters
  • optional content
  • boolean shape flags

When not to use

  • unrelated modifier, naming, or cleanup changes
  • animation design
  • state ownership changes
  • semantics or screenshot coverage
