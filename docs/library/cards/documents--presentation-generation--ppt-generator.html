Skill page

Conflict

The two copies implement fundamentally different PPT generation procedures. The anbeime/skill copy is a seven-role workflow that produces a .pptx file via python-pptx, with structured JSON, layout recommendations, and a generation script. The LeoYeAI copy is a single-file HTML slide deck generator with a strict Jobs-style minimalist vertical design, specific visual specs, and a different output format. Neither is a reproduction of the other; crowning one would hide a real alternative.
