nagent

separate

Launch a new bb worker thread with the right project, model, worktree, and task brief. Use for nagent, launching a bb session, or a standalone bb agent. Covers thread creation; use bb-cli for managing existing threads.

When to use

  • launching a bb session
  • nagent
  • standalone bb agent
  • thread creation
  • spawning bb worker threads
  • configuring bb thread permissions
  • setting up bb worktrees
  • verifying bb thread spawn

When not to use

  • managing existing threads
  • bb-cli operations
  • bypassing parent permission limits
  • creating manual worktrees unless requested
  • nesting unrelated one-off work by default
