animator

separate

Edit Unity Animator Controllers and drive runtime parameters

When to use

  • Setting up or wiring an Animator
  • Adjusting animation state machines
  • Driving animation parameters at runtime
  • Creating Animator Controllers
  • Adding layers, states, and transitions
  • Assigning controllers to GameObjects
  • Playing animation states

When not to use

  • Timeline animation
  • Component properties on Animator
  • Animation import settings
  • Creating AnimationClips
  • Deleting assets
  • PlayMode operations
  • Reload operations
