cie-mechanism

separate

Use when a 《中国工业经济》 (China Industrial Economics) manuscript needs mechanism evidence. Prefers split-channel and moderation (heterogeneity-by-mechanism) regressions and treats the three-step mediation method as suspect — per Jiang (2022, CIE 2022:5), the journal's own methodological-norm guide. Use after the main effect is identified.

When to use

  • mechanism evidence for CIE manuscripts
  • split-channel regressions
  • moderation (heterogeneity-by-mechanism) regressions
  • identifying X→M using the main identification strategy
  • explaining how moderation strengthens causal argumentation

When not to use

  • three-step mediation method as the sole mechanism
  • using OLS correlation for X→M instead of the main identification strategy
  • reporting interaction terms without explaining mechanism implications
  • treating significant control variables as mechanisms
