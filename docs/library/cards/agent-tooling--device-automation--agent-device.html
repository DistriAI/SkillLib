agent-device

separate

Automates interactions for Apple-platform apps (iOS, tvOS, macOS) and Android devices. Use when navigating apps, taking snapshots/screenshots, tapping, typing, scrolling, or extracting UI info across mobile, TV, and desktop targets.

When to use

  • navigating apps
  • taking snapshots/screenshots
  • tapping
  • typing
  • scrolling
  • extracting UI info
  • mobile, TV, and desktop targets
  • pass/fail QA from acceptance criteria

When not to use

  • open-ended bug hunt with reporting
  • browsing the web
  • using external sources
