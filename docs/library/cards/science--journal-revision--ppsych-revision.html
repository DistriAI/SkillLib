ppsych-revision

separate

Use when responding to a Perspectives on Psychological Science (PoPS) editor and reviewer decision letter — coverage gaps, balance/fairness complaints, framework/argument asks, accessibility, and open-science requests. Drafts the response and revision plan; it does not run the submission preflight (ppsych-submission) or redesign the spine from scratch (ppsych-organizing-framework).

When to use

  • responding to PoPS decision letters
  • addressing coverage gaps
  • handling balance and fairness complaints
  • answering framework and argument asks
  • improving accessibility
  • fulfilling open-science requests
  • drafting point-by-point response letters

When not to use

  • running the submission preflight
  • redesigning the spine from scratch
  • responding to primary paper reviews
