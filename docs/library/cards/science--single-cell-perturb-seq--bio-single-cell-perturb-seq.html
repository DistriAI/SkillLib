Analyze Perturb-seq and CROP-seq CRISPR screening data integrated with scRNA-seq. Use when identifying gene function through pooled genetic perturbations in single cells.

When to use

  • Perturb-seq CRISPR screen analysis
  • CROP-seq data integration
  • Linking guide RNA assignments to transcriptional phenotypes
  • Identifying gene function via pooled genetic perturbations
  • Perturbation classification using Mixscape
  • Differential expression per perturbation
  • Perturbation embedding and clustering
  • Guide assignment from CRISPR feature barcode
