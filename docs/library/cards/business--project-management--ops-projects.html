ops-projects

separate

Portfolio dashboard for all GSD-tracked projects. Scans ~/Projects and ~/gsd-workspaces for .planning/ directories, shows phase status, git state, blockers, and next actions for every project. Run /ops projects to see the full portfolio.

When to use

  • View full project portfolio
  • Show phase status
  • Display git state
  • List blockers
  • Show next actions
  • Project deep-dive
  • Sync registry data
  • Refresh dashboard

When not to use

  • Edit files
  • Write files
  • Notebook editing
