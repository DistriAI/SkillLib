navmesh

separate

Bake and query Unity NavMesh

When to use

  • Setting up navigation
  • Baking a NavMesh
  • Testing agent paths
  • Tuning bake parameters
  • Calculating paths between points
  • Sampling nearest NavMesh positions
  • Configuring NavMeshAgent components
  • Configuring NavMeshObstacle components

When not to use

  • Creating NavMesh via navmesh_create
  • Adding agent components via navmesh_add_agent_component
  • Setting agent speed via navmesh_set_agent_speed
  • General component management outside NavMesh context
