nexusweb3-safety

separate

Read-only API reference for NexusWeb3 safety protocols 21-30 on Base mainnet — kill switch status, KYA verification, audit logs, bounties, licensing, milestones, subscriptions, insolvency, referrals, and collectives.

When to use

  • Querying kill switch status
  • Verifying KYA status
  • Reading audit logs
  • Checking bounties
  • Viewing licensing
  • Checking milestones
  • Viewing subscriptions
  • Checking insolvency

When not to use

  • Write operations
  • Transaction signing
  • Registering agents
  • Submitting KYA
  • Posting bounties
