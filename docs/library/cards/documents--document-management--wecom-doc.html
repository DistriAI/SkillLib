wecom-doc

separate

文档与智能表格操作。当用户提到企业微信文档、创建文档、编辑文档、新建文档、写文档、智能表格时激活。支持文档创建/写入和智能表格的创建及子表/字段/记录写入。注意：所有文档创建和编辑请求都应使用此 skill，不要尝试用其他方式处理文档操作。

When to use

  • 创建企业微信文档
  • 编辑文档内容
  • 新建智能表格
  • 管理智能表格子表
  • 添加或更新智能表格字段
  • 写入智能表格记录

When not to use

  • 从文档URL解析docid
  • 编辑非本skill创建的文档
  • 改变智能表格字段类型
