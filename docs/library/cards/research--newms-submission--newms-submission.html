newms-submission

separate

Use for the final preflight before submitting a New Media & Society (NM&S) manuscript via Sage Track — word target, abstract, keywords, masking, SAGE Harvard referencing, ethics statement, and ORCID. Runs the checklist; it does not draft content.

When to use

  • final preflight before submitting NM&S manuscript
  • checking word target
  • verifying abstract and keywords
  • checking masking for anonymous review
  • verifying SAGE Harvard referencing
  • checking ethics and data statements
  • assembling Sage Track file set

When not to use

  • drafting content
