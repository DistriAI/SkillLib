Profile functional potential of metagenomes using HUMAnN3 and similar tools. Use when obtaining pathway abundances, gene family counts, or functional annotations from metagenomic data.

When to use

  • obtaining pathway abundances
  • gene family counts
  • functional annotations from metagenomic data
  • metabolic pathway profiling
  • batch processing metagenomic samples
  • normalizing abundance tables
  • regrouping gene families
  • differential analysis of pathways
