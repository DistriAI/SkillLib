skill-optimizer

combined

Optimizes AI skills for activation, clarity, and cross-model reliability. Use when creating or editing skill packs, diagnosing weak skill uptake, reducing regressions, tuning instruction salience, improving examples, shrinking context cost, or setting benchmark/release gates for skills. Trigger terms: skill optimization, activation gap, benchmark skill, with/without skill delta, regression, context budget, prompt salience. Diagnose and optimize Agent Skills (SKILL.md) with real session data and research-backed static analysis. Works with Claude Code, Codex, and any Agent Skills-compatible agent.

When to use

  • Improve whether a skill is actually applied by models
  • Diagnose why some criteria fail across all models
  • Prevent a skill from making outputs worse
  • Refactor skill text for stronger retrieval under context pressure
  • Build repeatable benchmark loops and release gates
  • Use when skills are not triggering as expected or seem broken
  • Use when you want to audit and improve your skill library's quality
  • Use when you want to understand which skills are underperforming or wasting context tokens

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.

Conflict

The two copies describe different procedures for the same skill name. mcollina/skills defines a forward-looking optimization loop (baseline, failure pattern, salience edits, re-run, ship) and points to rule files. sickn33/agentic-awesome-skills defines a read-only diagnostic workflow that scans session JSONL files, runs 8 analysis dimensions, and outputs a P0/P1/P2 report. They overlap in the goal of improving skill activation and context cost, but each contains material steps the other lacks, and they disagree on whether the skill should modify files or only report.
