cscw-author-response

separate

Use when a CSCW paper draws Revise and Resubmit or Revise for External Review — triaging reviewer requests, running the weeks-long revision as a project, and writing the point-by-point response letter that the same reviewers will read before they reread anything else.

When to use

  • triaging reviewer requests
  • running the weeks-long revision as a project
  • writing the point-by-point response letter
  • handling cross-tradition requests
  • managing new-data requests
  • responding to Revise-for-External-Review
  • performing exit checks before resubmission

When not to use

  • rebuttal box responses
