sn-ppt-entry

separate

Use when a user asks to create a presentation, slide deck, PPT, or PPTX from a query and optional files, or to resume an existing SenseNova presentation task.

When to use

  • create a presentation
  • create a slide deck
  • create PPT
  • create PPTX
  • resume an existing SenseNova presentation task

When not to use

  • edit existing PPTX
  • optimize existing PPTX
  • continue writing existing PPTX
  • template filling
