bio-copy-number-cnv-annotation

separate

Annotate CNVs with genes, pathways, and clinical significance. Use when interpreting CNV calls or identifying affected genes from copy number analysis.

When to use

  • Annotate CNV calls with gene names
  • Identify affected genes from copy number analysis
  • Assess clinical significance of CNVs
  • Flag known cancer-associated genes
  • Identify pathogenic ClinVar variants within CNV regions
  • Analyze recurrent CNVs using GISTIC2
  • Comprehensive annotation using AnnotSV
