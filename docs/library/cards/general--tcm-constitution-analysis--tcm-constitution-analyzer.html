tcm-constitution-analyzer

combined

分析中医体质数据、识别体质类型、评估体质特征,并提供个性化养生建议。支持与营养、运动、睡眠等健康数据的关联分析。

When to use

  • 你需要根据中医体质分类标准评估用户体质，并识别主导体质与兼夹体质。
  • 你想结合营养、运动、睡眠等健康数据分析体质特征、风险和变化趋势。
  • 你需要面向个体化调理的养生建议、趋势跟踪和相关性分析结果。

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.

Skill page

Conflict

The two copies are not a simple wrapper-and-procedure pair. The first copy (sickn33) is a thin wrapper that defers to a separate detailed guide and adds safety/limitation constraints, but it contains no executable steps, data paths, or algorithms. The second copy (FreedomIntelligence) contains the full procedure: specific data file paths, scoring formulas, constitution determination logic, and a detailed report template. Because the first copy's safety constraints and the second copy's procedural details are both material and not fully contained in the other, crowning one would hide a real alternative. The combined instruction merges the safety constraints from the first with the procedural steps from the second.
