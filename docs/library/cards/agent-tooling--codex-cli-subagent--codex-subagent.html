codex-subagent

authentic

Launch OpenAI Codex CLI as a subagent (no API key). Use when delegating a self-contained coding task to Codex from another agent — parallel implementation work, a second opinion, or an independent verification pass.

When to use

  • delegating self-contained coding tasks
  • parallel implementation work
  • second opinion on changes
  • independent verification pass
  • fixing bugs
  • implementing features
  • refactoring code
  • code review

When not to use

  • tasks requiring conversation context not fully written in prompt
  • using API keys for authentication
  • using Codex fast mode
  • using --dangerously-bypass-approvals-and-sandbox
