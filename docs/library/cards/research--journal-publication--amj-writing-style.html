amj-writing-style

separate

Use for full-manuscript prose polish of an Academy of Management Journal (AMJ) manuscript — front-loading the argument, active voice, structure, and AOM house style. Polishes language and structure; it does not create the theoretical contribution (amj-contribution-framing) or fix the analysis (amj-data-analysis).

When to use

  • full-manuscript prose polish
  • front-loading the argument
  • active voice
  • structure
  • AOM house style
  • late-stage polish
  • sentence-level moves
  • paragraph-level moves

When not to use

  • create the theoretical contribution
  • fix the analysis
