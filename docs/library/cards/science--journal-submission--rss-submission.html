rss-submission

separate

Use when auditing an RSS (Robotics: Science and Systems) submission for OpenReview readiness — the abstract/paper/supplement deadline cascade, the 8-page-excluding-references ceiling, double-blind compliance, PDF self-containment, the no-links-until-camera-ready rule, and dual-submission exposure.

When to use

  • Auditing RSS submission for OpenReview readiness
  • Checking abstract, paper, and supplement deadline cascade
  • Verifying 8-page-excluding-references ceiling
  • Checking double-blind compliance
  • Auditing PDF self-containment
  • Checking no-links-until-camera-ready rule
  • Identifying dual-submission exposure
  • Auditing OpenReview record fields

When not to use

  • Submitting demo write-ups expecting a lighter track
  • Adding new decisive results after the paper gate
