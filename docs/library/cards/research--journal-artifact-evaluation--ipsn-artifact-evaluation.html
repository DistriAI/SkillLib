ipsn-artifact-evaluation

separate

Use when packaging an IPSN-lineage artifact for the ACM badges and the IPSN Best Research Artifact Award, covering hardware-plus-software artifacts (firmware, board files, datasets), what sensor-systems evaluators check first, DOI-issuing archives, evaluator-proof documentation for a physical system, and the separate post-acceptance timing.

When to use

  • packaging IPSN-lineage artifacts
  • targeting ACM badges
  • targeting IPSN Best Research Artifact Award
  • hardware-plus-software artifacts
  • firmware and board files
  • datasets and raw traces
  • evaluator-proof documentation
  • DOI-issuing archive deposit

When not to use

  • camera-ready paper preparation
  • pre-acceptance submission timing
