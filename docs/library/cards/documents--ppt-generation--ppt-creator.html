ppt-creator

combined

专业级智能 PPT 全生命周期创作与增强套件。支持通过 yoo-ai API 自动生成、编辑与美化 PPT。当需要执行以下任务时使用此 Skill：(1) 【多源生成】：将简单主题、结构化大纲、本地文件（.docx, .txt）或 AI 编码项目（架构分析）转化为专业 PPT；(2) 【专家流】：需要“先审阅大纲、后生成内容”的高质量创作流程，支持对大纲进行增删改查；(3) 【后期增强】：为已有任务添加演讲稿（Speaker Notes）、在指定位置插入新页面、或更换全局风格（字体、颜色、模板）；(4) 【互动引导】：预览精美封面、实时追踪异步生成任务进度、以及针对“内容太少”或“格式错误”等生成失败情况进行自动诊断与修复；(5) 【绘图PPT】：生成视觉效果极佳但不可编辑的图片型 PPT。适用于“帮我做个 PPT”、“总结这个项目的架构”、“给 PPT 加演讲稿”等指令。 【DEPRECATED · 已废弃】本 skill 已于 2026-08-07 停止维护。对作者本机环境：其方法论已整体并入 deck-creator（私有仓 daymade-skills-pro 的 Route B · draft），装有 deck-creator 的环境不要调用本 skill。 对外部用户：这是最终版本，保留安装兼容，不再接收更新——你可以继续按本文档使用， 但请知悉上游已冻结。将在 daymade-docs v2.0.0 中物理移除。

When to use

  • Multi-source generation from topics, outlines, local files, or project analysis
  • Expert workflow with outline review and modification
  • Adding speaker notes to existing tasks
  • Inserting new pages at specified positions
  • Changing global styles including fonts, colors, and templates
  • Previewing covers and tracking asynchronous task progress
  • Generating image-based PPTs with high visual quality
  • Diagnosing and fixing generation failures

When not to use

  • Editing text in image-based PPTs
  • Using Microsoft YaHei font
