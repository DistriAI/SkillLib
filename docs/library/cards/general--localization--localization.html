localization

combined

Sets up and configures Unity Localization, including locales, String and Asset Tables, and CJK fonts. Use when the user asks to add languages, translate UI text, or mentions i18n or multilingual support. When the user wants to localize their App Store listing for international markets. Also use when the user mentions "localization", "translate my app", "international markets", "expand to new countries", "localize metadata", or "which countries should I target". For keyword research in specific markets, see keyword-research. For metadata writing, see metadata-optimization.

Skill page

Conflict

The three copies address three different products and workflows: Unity engine localization, web/product localization strategy, and App Store listing localization. They overlap only in the generic idea of adding language support, but each contains material steps and constraints the others lack (Unity package installation and table refresh, web URL/hreflang/coverage gates, and App Store metadata/keyword rules). Crowning one would hide real alternatives.
