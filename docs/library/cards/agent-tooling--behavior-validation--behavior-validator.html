behavior-validator

separate

Source-blind user behavior validation against a prewritten contract for apps, CLIs, APIs, and generated artifacts.

When to use

  • Validate observable behavior
  • Black-box companion to code-aware review
  • Judge running product, CLI, API, or generated artifact
  • Exercise user tasks
  • Run anti-cheat probes
  • Capture redacted evidence
  • Emit structured report

When not to use

  • Inspecting source files
  • Inspecting diffs
  • Inspecting tests
  • Inspecting git history
  • Inspecting implementation notes
  • Inspecting build internals
  • Inspecting review bundles
  • Code-quality or implementation-style concerns
