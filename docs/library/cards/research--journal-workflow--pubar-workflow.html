pubar-workflow

separate

Use when starting or navigating any Public Administration Review (PAR) manuscript and unsure which skill applies. Routes to the right PAR sub-skill based on lifecycle stage and which article type (Scholarly Take, Conceptualizing PA, Early Career Intel, Practically Speaking, Public Administration in Print) fits. It dispatches; it does not draft content.

When to use

  • Starting a new PAR paper
  • Navigating mid-project skill selection
  • Deciding which article type fits
  • Routing after a decision letter
  • Confirming scholarly and practitioner contribution

When not to use

  • Drafting content
  • Book reviews (Public Administration in Print)
  • Pure-theory venue tasks (JPART)
  • Policy-analysis venue tasks (JPAM)
