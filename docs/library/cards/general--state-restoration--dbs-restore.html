dbs-restore

separate

把上次诊断的状态拉出来，接着用。配合 dbs-save 使用。 触发方式：/dbs-restore、/续上、「接着上次」「之前的结论」「上次诊断到哪了」 Restore the most recent diagnosis snapshot saved by dbs-save. Trigger: /dbs-restore, "continue from last time", "where did we leave off"

When to use

  • Restore latest diagnosis snapshot
  • List available diagnosis archives
  • Switch to a specific project archive
  • Continue from last diagnosis
  • Display previous diagnosis status

When not to use

  • Performing new diagnosis
  • Saving new diagnosis state
  • Routing to other skills without user confirmation
