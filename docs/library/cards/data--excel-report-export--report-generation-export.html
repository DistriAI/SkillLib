report-generation-export

separate

从Excel提取多类型数据，并生成包含可视化图表与下载链接的综合分析报告。

When to use

  • 基于指定列提取有效代码或进行分类映射
  • 生成包含占比与总计行的统计表
  • 支持交叉分析
  • 识别目标值超过限值的行
  • 基于关键字定位并反向搜索限值
  • 生成高分辨率可视化图表展示分类占比
  • 保存统计结果并生成沙箱下载链接

When not to use

  • reading/counting/Parquet optimization
