asr-writing-style

separate

Use when drafting or polishing an American Sociological Review (ASR) manuscript so it reads for the whole discipline, follows the ASA Style Guide, and fits the limits (Articles <= 15,000 words including text, references, and footnotes; abstract <= 200 words). Tightens prose and format; it does not invent content.

When to use

  • Drafting the introduction
  • Framing the contribution
  • Final polish
  • Cutting text to fit word cap
  • Writing the abstract
  • Aligning citations to ASA Style Guide
  • Formatting manuscript
  • Masking self-identifying information

When not to use

  • Inventing content
  • Generating claims
