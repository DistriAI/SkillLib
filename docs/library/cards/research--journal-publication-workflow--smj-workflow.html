smj-workflow

separate

Use when deciding which smj-* sub-skill to invoke next, or when sequencing manuscript work from topic selection through rebuttal for a Strategic Management Journal (SMJ) manuscript. Routes — it does not replace — the specialized skills.

When to use

  • deciding which smj-* sub-skill to invoke next
  • sequencing manuscript work from topic selection through rebuttal
  • identifying the binding constraint in a draft
  • switching into revision mode after reviewer comments
  • stage-gate triage for SMJ manuscripts

When not to use

  • performing the work of specialized smj-* skills
  • replacing specialized skills
