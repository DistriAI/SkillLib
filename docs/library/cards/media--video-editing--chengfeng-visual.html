chengfeng-visual

separate

给剪好的口播配画面：在录屏上盖 HTML 层（圈重点标注 / 小黑整屏动画 / 推近），层绑字幕屏、由播放器逐帧驱动、直接在预览里看。用户说做分镜、配画面、加动画、圈重点、B-roll、做 storyboard 时使用。不要用于删词剪辑、字幕、物理剪切或成片渲染。

When to use

  • 做分镜
  • 配画面
  • 加动画
  • 圈重点
  • B-roll
  • 做 storyboard

When not to use

  • 删词剪辑
  • 字幕
  • 物理剪切
  • 成片渲染
