suwappu-dex

separate

Cross-chain token swaps, quotes, portfolio and prices across 14 chains via the Suwappu DEX MCP server. Read-only by default; swap execution is opt-in and gated.

When to use

  • Cross-chain token swaps
  • Token quotes
  • Portfolio tracking
  • Token prices
  • Listing supported chains
  • Listing popular tokens
  • Trending tokens
  • Prediction markets

When not to use

  • Swap execution without explicit opt-in
  • Custodial key management
