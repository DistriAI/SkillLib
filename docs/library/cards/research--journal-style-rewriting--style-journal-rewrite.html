style-journal-rewrite

separate

Rewrite drafts according to target writing style or target journal format. Triggers when user says "rewrite in XX style", "match this tone", "format for XX journal", "rewrite following this format". Input can be .docx / .md / .txt or conversation text.

When to use

  • rewrite in XX style
  • write like XX
  • match this tone
  • format for XX journal
  • rewrite following this format
  • convert to NC format
  • adjust reference style
  • adjust abstract structure

When not to use

  • factual additions
  • content expansion
  • proofreading typos
  • complete structural rewrite unrelated to style/format
  • adding references only
