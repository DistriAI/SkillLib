agsy-literature-positioning

separate

Use when positioning an Agricultural Systems (AgSy) manuscript against the literature so it reads as a systems contribution. AgSy readers span agronomy, modelling, livestock, economics, environment, and food-system science, so the paper must engage the systems and modelling literatures they expect — not only one subfield. Stakes the contribution; it does not write the lit review.

When to use

  • Drafting or revising the introduction
  • Revising the contribution paragraph
  • Addressing reviewer feedback on ignored modelling work
  • Distinguishing contribution from prior systems studies
  • Engaging systems and modelling debates
  • Locating models among existing alternatives
  • Naming precise gaps in systems understanding
  • Pre-empting obvious objections

When not to use

  • Writing the full literature review
  • Data and model evaluation
  • Systems framing and modeling
