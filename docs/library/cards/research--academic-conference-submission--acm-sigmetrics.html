acm-sigmetrics

separate

Use when targeting ACM SIGMETRICS (SIGMETRICS) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for performance measurement.

When to use

  • targeting ACM SIGMETRICS
  • deciding if a manuscript fits the venue
  • conference-fit read for performance evaluation
  • re-framing journal or arXiv style into conference narrative
  • diagnosing evidence-gap, anonymity, artifact, or rebuttal issues
  • performance evaluation, queueing, measurement, modeling, networks, systems, and stochastic analysis

When not to use

  • substitute for current year's CFP, author kit, ethics policy, or submission portal
  • treating 'we measured speedups' as fit without reusable performance lens or validated model
  • routing provocative early networking theses
  • routing mature networking mechanisms
  • routing parallel/distributed runtime or scheduling papers unless measurement/modeling is the contribution
