cte-tables-figures

separate

Use when finalizing regression tables and figures for a 《财贸经济》 manuscript. Enforces three-line table style, footnote conventions, column-count discipline, transparent data sourcing, and figure aesthetics. 本技能服务于《财贸经济》(Finance & Trade Economics, CTE)。

When to use

  • finalizing regression tables
  • finalizing figures
  • enforcing three-line table style
  • enforcing footnote conventions
  • enforcing column-count discipline
  • enforcing transparent data sourcing
  • enforcing figure aesthetics

When not to use

  • hand-copying numbers into tables
  • using borders, shadows, or colors in tables
  • using t-values or z-values for standard errors
  • writing 'public channels' for data sources
  • using low-resolution figures
  • pasting Stata screenshots directly
