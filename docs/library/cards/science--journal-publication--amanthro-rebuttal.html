amanthro-rebuttal

separate

Use when writing the response to an American Anthropologist (AA) revise-and-resubmit. AA uses anonymous peer review under an ethics of care, often with cross-subfield reviewers, so the response must convert each reviewer while keeping the editor confident and the ethnographic contribution intact. Structures the response letter; it does not fabricate new evidence.

When to use

  • writing the response to an American Anthropologist revise-and-resubmit
  • planning the revision and response letter
  • reconciling reviewers who disagree across subfields
  • writing the cover note to the editor summarizing the revision
  • addressing requests that would alter interpretation or expose interlocutors

When not to use

  • fabricating new evidence
