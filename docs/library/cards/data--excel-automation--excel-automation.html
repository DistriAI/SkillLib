excel-automation

combined

Excel Automation: create workbooks, manage worksheets, read/write cell data, and format spreadsheets via Microsoft Excel and Google Sheets integration Creates formatted Excel reports with openpyxl, parses complex xlsm financial models with stdlib zipfile+xml when openpyxl fails, and controls Excel windows on macOS via AppleScript. Reconstructs images or scans of paper forms as editable XLSX files with printable layouts.

When to use

  • create workbooks
  • manage worksheets
  • read/write cell data
  • format spreadsheets
  • upserting rows
  • Microsoft Excel integration
  • Google Sheets integration

Skill page

Conflict

The daymade skill is a local, code-first procedure using openpyxl, stdlib zipfile/xml parsing, and macOS AppleScript. The two Composio skills are identical MCP-based procedures that drive Microsoft Excel and Google Sheets through the Rube MCP server. They overlap in the goal of automating spreadsheets but use entirely different toolchains, prerequisites, and workflows. Crowning one would hide a real alternative: local file manipulation versus cloud/MCP-driven spreadsheet management.
