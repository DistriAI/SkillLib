bio-read-alignment-hisat2-alignment

separate

Align RNA-seq reads with HISAT2, a memory-efficient splice-aware aligner. Use when STAR's memory requirements are too high or for general RNA-seq alignment.

When to use

  • Align RNA-seq reads with HISAT2
  • Build HISAT2 index
  • Align paired-end reads
  • Align single-end reads
  • Handle stranded libraries
  • Discover novel splice junctions
  • Two-pass alignment
  • Prepare BAM for quantification

When not to use

  • STAR alignment
  • Alignment-free quantification
  • Differential expression analysis
