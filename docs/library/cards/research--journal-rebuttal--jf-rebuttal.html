jf-rebuttal

separate

Use when drafting the response to a The Journal of Finance (JF) revise-and-resubmit (or addressing a reject-with-comments). Structures the response letter and revision plan after the manuscript is revised.

When to use

  • Drafting JF revise-and-resubmit response
  • Addressing JF reject-with-encouragement
  • Mapping editor and referee points to changes
  • Structuring JF response letter
  • Triaging JF decision letter points
  • Routing robustness to Internet Appendix
  • Updating disclosure and replication code

When not to use

  • Initial manuscript submission
  • General journal submission guidelines
  • Non-JF journal rebuttals
