ecology-letters

separate

Use when targeting Ecology Letters (Ecol Lett) or deciding whether an ecology manuscript fits this high-impact short-format venue. Encodes the journal's fit, framing, method-and-evidence bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting Ecology Letters
  • deciding if an ecology manuscript fits Ecology Letters
  • choosing between Ecology Letters and other high-impact venues
  • re-framing a manuscript for Ecology Letters
  • checking Ecology Letters desk-reject criteria
  • assessing fit for theory-data integration papers
  • assessing fit for macroecology and global patterns
  • assessing fit for evolutionary ecology at the interface

When not to use

  • comprehensive species inventories
  • site-specific natural history
  • replacing the journal's current official submission guidelines
