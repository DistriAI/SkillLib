replica-brand

separate

Names and rebrands an app clone so it is the user's own: name candidates with the trademark, domain, store and handle checks to run, a new palette checked for contrast, a logo brief, a voice guide, and a sweep tool that finds anything of the original left in the codebase. Use when the user says "name my app", "rebrand the clone", "make it mine", "pick a name and colours", "logo brief", "brand voice", "check for leftovers", or after /replica-entrepreneur. Always runs before /replica-launch.

When to use

  • naming an app clone
  • rebranding a clone
  • checking trademarks and domains
  • creating a new color palette
  • writing a logo brief
  • defining brand voice
  • sweeping codebase for original leftovers

When not to use

  • legal clearance
  • creating the actual logo file
