stakeholder-alignment

combined

Build alignment artifacts — responsibility matrices, decision rights, and communication plans. Use when unclear ownership stalls decisions. For persuading in the moment, use `design-negotiation` (designer-toolkit). Help users master the art of leading without formal authority by identifying stakeholder incentives, neutralizing conflict through connection, and using co-creation to build shared ownership.

When to use

  • Building responsibility matrices
  • Defining decision rights
  • Creating communication plans
  • Mapping stakeholder incentives
  • Neutralizing conflict through connection
  • Using co-creation to build shared ownership
  • Standardizing communication
  • Resolving unclear ownership

When not to use

  • Persuading in the moment

Skill page

Conflict

The two skills share the name and the broad goal of aligning stakeholders, but they prescribe different procedures. The first copy is an artifact-focused playbook (stakeholder maps, RACI, decision frameworks, communication plans) aimed at clarifying ownership and decision rights. The second copy is a relationship and influence playbook (incentive mapping, conflict neutralization, co-creation, canonical sources) grounded in specific podcast-derived principles and templates. Neither copy contains the other's core steps, so crowning one would hide a real alternative approach.
