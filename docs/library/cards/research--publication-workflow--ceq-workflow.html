ceq-workflow

separate

Use when deciding which ceq-* sub-skill to invoke next, or when sequencing manuscript work from fit judgment through rebuttal for 《经济学(季刊)》 (China Economic Quarterly, CEQ). Routes — does not replace — the specialized skills.

When to use

  • deciding which ceq-* sub-skill to invoke next
  • sequencing manuscript work from fit judgment through rebuttal
  • mapping current symptoms to the next skill
  • routing tasks for CEQ submission

When not to use

  • replacing specialized ceq-* skills
  • generating rebuttal before manuscript revision
  • working on figures or abstracts before identification is established
  • tasks for journals other than CEQ
