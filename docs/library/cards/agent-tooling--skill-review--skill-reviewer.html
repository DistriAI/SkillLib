skill-reviewer

separate

Reviews skill quality with evidence-based design rubrics and read-only batch inventories. Use for self-review, external skill or repository audits, and authorized auto-PR improvements. Separates design quality from measured task benefit and host compatibility.

When to use

  • self-review
  • external skill or repository audits
  • authorized auto-PR improvements
  • batch quality judgment
  • delivery review
  • security validation
  • packaging checks

When not to use

  • editing target without authorization
  • forking target without authorization
  • publishing target without authorization
  • executing target without authorization
  • applying host schema to different runtime without checking contract
