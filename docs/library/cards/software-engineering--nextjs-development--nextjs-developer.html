nextjs-developer

separate

Use when building Next.js 14+ applications with App Router, server components, or server actions. Invoke to configure route handlers, implement middleware, set up API routes, add streaming SSR, write generateMetadata for SEO, scaffold loading.tsx/error.tsx boundaries, or deploy to Vercel. Triggers on: Next.js, Next.js 14, App Router, RSC, use server, Server Components, Server Actions, React Server Components, generateMetadata, loading.tsx, Next.js deployment, Vercel, Next.js performance.

When to use

  • building Next.js 14+ applications
  • configuring route handlers
  • implementing middleware
  • setting up API routes
  • adding streaming SSR
  • writing generateMetadata for SEO
  • scaffolding loading.tsx/error.tsx boundaries
  • deploying to Vercel

When not to use

  • using Pages Router
  • hardcoding title or meta tags in JSX
  • using plain img tags for content images
  • converting components to Client Components just to access data
  • skipping loading.tsx or error.tsx boundaries on async route segments
  • deploying without running next build
