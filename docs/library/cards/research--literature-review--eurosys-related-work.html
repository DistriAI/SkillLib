eurosys-related-work

separate

Use when positioning a EuroSys submission in the systems literature — mapping the SOSP/OSDI/NSDI/ATC/ASPLOS neighbor space plus EuroSys's own two-decade proceedings line, handling concurrent arXiv and workshop versions under double-blind rules, and declaring overlap with earlier submissions of the same work.

When to use

  • positioning a EuroSys submission
  • mapping SOSP/OSDI/NSDI/ATC/ASPLOS neighbor space
  • sweeping EuroSys proceedings line
  • handling concurrent arXiv and workshop versions
  • declaring overlap with earlier submissions
  • auditing novelty positioning
  • differencing technical deltas
  • verifying citation accuracy

When not to use

  • writing the full paper
  • designing the system
  • conducting experiments
  • formatting the submission
