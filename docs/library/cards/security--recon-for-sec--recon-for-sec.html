recon-for-sec

separate

Entry P1 category router for reconnaissance and methodology. Use when mapping scope, drawing an attack surface from one application, discovering assets, fingerprinting technology, building endpoint inventory, and choosing the first high-value security testing path.

When to use

  • You just received a new target and do not yet know what to test first
  • You need to begin by drawing the surface from the application, then asset discovery, fingerprinting, and test-route planning
  • You want to build follow-up testing on structured methodology instead of random payload enumeration
