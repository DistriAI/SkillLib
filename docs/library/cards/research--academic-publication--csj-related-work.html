csj-related-work

separate

在为《计算机科学》(Computer Science, JSJKX) 撰写相关工作章节或组织文献综述时调用。本刊是计算机全学科中文综合月刊(CCF 会刊、B 类、T2 级)，覆盖面广且综述活跃、鼓励综述投稿。技能帮助以 delta(增量) 优先的方式组织相关工作、确立创新性，并针对本刊的综述型稿件给出分类框架、批判性比较与趋势展望的写法；同时规范中外文献引用与 GB/T 7714 著录。适用于研究长文的相关工作章节，以及面向本刊专题/综述栏目的综述稿组织的场景。

When to use

  • 研究长文相关工作章节撰写
  • 综述稿组织与分类框架设计
  • GB/T 7714—2015 引用规范检查
  • 创新性 (delta) 确立与表述
  • 文献检索与中英文均衡引用
  • 相关工作与实验章节基线对应检查

When not to use

  • 会议论文写作
  • 非《计算机科学》期刊的特定格式要求
  • 实验设计与具体实现细节
  • 方法章节内部技术展开
