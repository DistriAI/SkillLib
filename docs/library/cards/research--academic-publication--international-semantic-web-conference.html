international-semantic-web-conference

separate

Use when targeting International Semantic Web Conference (ISWC) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for semantic web.

When to use

  • targeting International Semantic Web Conference (ISWC)
  • deciding whether a computer-science manuscript fits this venue
  • conference fit, framing, evidence bar, submission-cycle checks
  • rebuttal posture, and desk-reject risks for semantic web
  • semantic web, knowledge graphs, ontologies, linked data, reasoning
  • web-scale knowledge infrastructure
  • re-framing from journal style or arXiv style into a selective CS conference narrative
  • evidence-gap, anonymity, artifact, rebuttal, or re-routing diagnosis

When not to use

  • substitute for the current year's CFP, author kit, ethics policy, or submission portal
  • knowledge capture/acquisition (route to K-CAP)
  • formal reasoning (route to KR)
  • broader information/knowledge management (route to CIKM)
  • data-management systems (route to database venues)
  • database engine contributions (route to ICDE)
  • pure recognition or extraction models (route to ICPR/ACL-family venues)
