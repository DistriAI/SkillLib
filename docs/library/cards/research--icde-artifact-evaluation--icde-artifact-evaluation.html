icde-artifact-evaluation

separate

Use when packaging IEEE ICDE code, data, workload generators, and logs as supplemental material whose availability reviewers score, and for any post-acceptance reproducibility or badge process the edition runs. Covers what a builder-heavy committee inspects first, making a data-systems benchmark turnkey, and single-blind packaging.

When to use

  • packaging IEEE ICDE code
  • packaging data and workload generators
  • packaging logs as supplemental material
  • post-acceptance reproducibility processes
  • post-acceptance badge processes
  • making data-systems benchmarks turnkey
  • single-blind packaging

When not to use

  • replacing the paper's argument with the artifact
