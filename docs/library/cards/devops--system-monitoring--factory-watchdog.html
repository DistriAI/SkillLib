factory-watchdog

separate

Experimental workflow for monitoring explicitly authorized delivery tasks and reporting stalled work. Use for scheduled ship follow-through.

When to use

  • monitoring explicitly authorized delivery tasks
  • reporting stalled work
  • scheduled ship follow-through
  • finding actionable stopped work
  • notifying on verified next steps

When not to use

  • granting notification or delivery authority
  • acting on task title, branch, PR, green check, or agent summary as authorization
  • messaging when target or state cannot be proven
  • managing merge, post-merge verification, and cleanup unless explicitly assigned
