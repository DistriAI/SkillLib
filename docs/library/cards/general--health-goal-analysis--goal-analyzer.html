goal-analyzer

combined

分析健康目标数据、识别目标模式、评估目标进度,并提供个性化目标管理建议。支持与营养、运动、睡眠等健康数据的关联分析。

When to use

  • 你需要评估健康目标是否符合 SMART 原则，并识别目标设定中的薄弱点。
  • 你想跟踪目标进度，并结合营养、运动、睡眠等健康数据做关联分析。
  • 你需要面向个人健康管理的目标优化建议、风险提示和阶段性调整方案。

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.

Skill page

Conflict

The two copies share the same name, description, and high-level purpose (analyzing health goals, SMART validation, progress tracking, and correlation with nutrition/exercise/sleep). However, the FreedomIntelligence copy contains a detailed, self-contained procedure with specific scoring rubrics, habit stages, motivation thresholds, achievement definitions, correlation methods, and ECharts report templates. The sickn33 copy is a thin wrapper that defers to an external 'detailed-guide.md' and adds generic safety/limitation boilerplate. Because the FreedomIntelligence copy has material steps the other lacks, and the sickn33 copy has a distinct structural constraint (mandatory external guide reference), crowning one would hide the other's approach. They are not identical reproductions.
