spatial-statistics

combined

Detects spatially variable genes, spatial autocorrelation, and cell-type colocalization for spatial transcriptomics using Squidpy with PySAL/esda for local statistics. Use when choosing an SVG method by its null and scaling (SpatialDE/SPARK GP variance-component vs SPARK-X/nnSVG linear vs Moran/Geary graph autocorrelation); separating genes that are spatially variable because of cell-type composition from genes regulated within a cell type; choosing the right autocorrelation statistic (global Moran/Geary vs Getis-Ord hot/cold spots vs local LISA and its FDR trap); and choosing a colocalization null strong enough to defeat the abundance/compartment confound (conditional or toroidal vs the weak Squidpy default permutation).

When to use

  • computing spatial autocorrelation
  • computing co-occurrence statistics
  • calculating Moran's I
  • calculating Geary's C
  • neighborhood enrichment
  • Ripley's statistics
  • centrality scores
  • interaction matrix

Skill page

Conflict

The two skills cover the same domain but with different depth and scope. The first copy (OpenClaw) is a practical, code-heavy recipe for running specific Squidpy functions (Moran's I, Geary's C, co-occurrence, etc.) and interpreting basic outputs. The second copy (GPTomics) is a methodological guide that emphasizes the statistical pitfalls (cell-type confounding, null model choice, graph sensitivity) and provides a decision framework for choosing between different SVG methods (SpatialDE, SPARK, SPARK-X, nnSVG, Moran's I). The first copy lacks the critical methodological warnings and the broader method selection logic, while the second copy is truncated and lacks the specific code implementation details for the basic Squidpy workflows. Combining them provides both the 'how-to' code and the 'why/when' statistical reasoning.
