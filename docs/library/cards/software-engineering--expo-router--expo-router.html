When to use

  • file-based routes
  • groups and dynamic routes
  • folder organization
  • Link with previews and context menus
  • native Stack
  • page titles
  • modals and form sheets
  • NativeTabs, headers and toolbars

When not to use

  • screen styling
  • colors
  • controls
  • media
  • visual effects
  • motion
  • gestures
