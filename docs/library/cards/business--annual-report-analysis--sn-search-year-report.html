sn-search-year-report

separate

用于搜索免费官方年报、年度报告、定期报告、上市公司披露文件、债券发行人报告和海外公司年度账目。

When to use

  • 搜索A股/港股/美股/英企/日本上市公司年报
  • 搜索发债主体年度报告
  • 搜索加拿大/新加坡/澳洲上市公司年报
  • 下载公开PDF年报
  • 查询SEC EDGAR 10-K/20-F/40-F文件
  • 查询巨潮资讯A股公告

When not to use

  • 商业库或订阅服务
  • 付费下载或登录墙
  • 验证码或防护页
  • 不可访问页面
  • 中国普通非上市企业完整财务年报
  • 工商年报作为审计财报
  • 需要API key或token的接口
  • 国家企业信用信息公示系统
