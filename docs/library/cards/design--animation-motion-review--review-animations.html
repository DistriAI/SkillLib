review-animations

authentic

Reviews animation and motion code against a high craft bar derived from Emil Kowalski's design engineering philosophy. Default to flagging; approval is earned.

When to use

  • review animation code
  • review motion code
  • check easing curves
  • verify animation duration
  • assess transform-origin correctness
  • evaluate interruptibility
  • check GPU-only property usage
  • verify accessibility handling

When not to use

  • write features
  • fix unrelated bugs
  • review non-motion code
  • review general code
