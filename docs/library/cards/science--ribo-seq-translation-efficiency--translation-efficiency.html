translation-efficiency

separate

Quantify translation efficiency (TE) as ribosome occupancy relative to mRNA abundance and test for differential TE between conditions. Use when separating translational from transcriptional regulation, distinguishing genuine translational control from buffering, or choosing between riborex, Xtail, anota2seq, and DESeq2 interaction models.

When to use

  • Quantify translation efficiency
  • Test for differential TE
  • Separate translational from transcriptional regulation
  • Distinguish genuine translational control from buffering
  • Choose between riborex, Xtail, anota2seq, and DESeq2
  • Rank genes by TE
  • Classify mode of regulation

When not to use

  • Protein output measurement
  • Full-transcript RNA counting against CDS-only RPF
