icassp-topic-selection

separate

Use when deciding whether a project fits ICASSP, the IEEE Signal Processing Society flagship spanning all signal processing, and specifically for the ICASSP-versus-Interspeech routing decision for speech work, plus routing to ICIP, EUSIPCO, WASPAA, SPS journals, or ML venues by identifying the signal-processing primitive of the contribution.

When to use

  • deciding whether a project fits ICASSP
  • ICASSP-versus-Interspeech routing decision for speech work
  • routing to ICIP, EUSIPCO, WASPAA, SPS journals, or ML venues
  • identifying the signal-processing primitive of the contribution

When not to use

  • writing the paper
  • generic ML with no signal model
