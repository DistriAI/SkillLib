square-automation

authentic

Automate Square tasks via Rube MCP (Composio): payments, orders, invoices, locations. Always search tools first for current schemas.

When to use

  • List and monitor payments
  • Search and manage orders
  • Manage locations
  • Invoice management
  • Cancel pending payments
  • Update order state or details
  • Cancel scheduled or unpaid invoices

When not to use

  • Refund completed payments
  • Uncancel cancelled invoices
