platformer

separate

Build a 2D platformer: run/jump control with coyote time, jump buffering, and variable jump height, plus tiled levels and hazards. Use for a platformer or Mario/Celeste-like, or tuning jump feel.

When to use

  • Use when building a side-scrolling or single-screen platformer, a "Mario-like" /
  • Use when a jump feels floaty, unresponsive, or "unfair" and you need feel fixes

When not to use

  • top-down movement with no gravity
  • 3D first-person traversal
  • grid/turn movement
  • raw kinematic body API implementation
