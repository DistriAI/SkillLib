ig-reel

separate

Write an Instagram Reel from a raw idea - hook options off 26 formulas, the spoken script, the on-screen text, and a timed beat sheet - in the user's own voice and scored before they shoot it. Use whenever the user wants a Reel, a short-form video script, a hook, a voiceover, "make a reel about X", "what should I say in this video", or is about to record and does not have the first line yet.

When to use

  • Write an Instagram Reel
  • Create a short-form video script
  • Generate hook options
  • Write a voiceover
  • Create a timed beat sheet
  • Score hook options

When not to use

  • Publishing the Reel
  • Shooting the video
  • Writing long-form videos over 3 minutes
