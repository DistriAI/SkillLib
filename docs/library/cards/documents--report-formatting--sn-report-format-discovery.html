sn-report-format-discovery

separate

用于用户希望推荐研究成品形式，或最终形式无法从需求中直接判断时。把需求解析为一个简短的 format 字符串，不创建格式文件或 schema。

When to use

  • 推荐研究成品形式
  • 解析需求为 format 字符串
  • 确定请求级 format

When not to use

  • 创建格式文件或 schema
  • 生成 format_proposal.json
  • 生成 format.json
  • 搜索外部格式规范
  • 生成候选对象
  • 修改研究问题
  • 修改范围
  • 修改语言或流程模式
