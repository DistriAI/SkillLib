ors-review-process

separate

Use when navigating the Operations Research (OR) editorial process — the departmental area-editor routing, the soft double-anonymous model with asymmetric transparency, decision types, and how to read a decision letter from the handling Area Editor. Explains how review works and how to read a decision; it does not draft the response (ors-rebuttal) or run the preflight (ors-submission).

When to use

  • understand how Operations Research routes and decides on a manuscript
  • parse roles, signals, and the path forward from a decision letter
  • determine who sees your identity and whose names you can see
  • identify the synthesis from the Area/Associate Editor
  • separate proof concerns from exposition concerns
  • note reproducibility requests
  • watch conference/copyright items

When not to use

  • draft the response (ors-rebuttal)
  • run the preflight (ors-submission)
