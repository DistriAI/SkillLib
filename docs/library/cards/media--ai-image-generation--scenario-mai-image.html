scenario-mai-image

separate

Use when generating or editing images with Microsoft MAI Image models on Scenario via MCP: photoreal or stylized text-to-image with legible in-image typography, posters, packaging, magazine covers, ads, key art, or instruction-based editing such as text swaps, recoloring, object removal or replacement, background swaps, lighting changes, and full restyles. Keywords: MAI Image 2.5, 2.5 Pro, 2.5 Edit, 2.5 Pro Edit, Microsoft, txt2img, img2img, typography, text rendering, image edit.

When to use

  • text-to-image generation
  • image editing
  • legible in-image typography
  • posters
  • packaging
  • magazine covers
  • ads
  • key art

When not to use

  • pixel-identical result reproduction
  • print-ready output without downstream upscale
