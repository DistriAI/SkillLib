functional-ecology

separate

Use when targeting Functional Ecology (Funct Ecol) or deciding whether a mechanistic study linking organism function to ecology fits this venue. Encodes the journal's fit, framing, method-and-evidence bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting Functional Ecology
  • deciding if mechanistic study fits venue
  • linking organism function to ecology
  • trait-based or ecophysiology study venue selection
  • confirming link to ecological consequence
  • Functional Ecology mechanistic framing
  • data-archiving conventions
  • desk-reject criteria

When not to use

  • community-pattern studies lacking functional mechanism
  • biogeographic studies lacking functional mechanism
  • physiology disconnected from ecological consequence
