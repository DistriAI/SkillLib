trend-analysis

combined

基于多维度数据进行分级评估与趋势预测，通过设定差异化增长率计算预测值，并生成对比可视化图表，适用于绩效评估、目标设定等场景。 Detect long-term trends in time series data using parametric and non-parametric methods. Use when determining if a variable shows statistically significant increase or decrease over time.

When to use

  • Detect long-term trends in time series data
  • Determine statistically significant increase or decrease
  • Parametric linear regression trend analysis
  • Non-parametric Sen's slope and Mann-Kendall test
  • Environmental data trend analysis

When not to use

  • Performance evaluation
  • Goal setting
  • Multi-dimensional data grading
  • Differentiated growth rate calculation
  • Comparison visualization charts

Skill page

Conflict

The two skills share the name but describe different procedures. The first is a business/Excel workflow that grades groups by performance, applies differentiated growth rates, computes forecast values, and renders a comparison bar chart. The second is a statistical time-series guide that tests for significant long-term trends using linear regression and Sen's slope/Mann-Kendall. Neither copy is a reproduction of the other, and crowning one would hide a real alternative method.
