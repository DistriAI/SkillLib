jais-review-process

separate

Use when calibrating expectations for the Journal of the Association for Information Systems (JAIS) editorial process — the developmental, Senior-Editor-led, double-blind review; how the seven-category routing works; what a JAIS decision letter means; and when to engage the journal's developmental culture. Sets expectations and reads decisions; it does not draft the response (jais-rebuttal) or run the submission preflight (jais-submission).

When to use

  • Understanding JAIS editorial process
  • Interpreting JAIS decision letters
  • Understanding JAIS category routing
  • Engaging JAIS developmental review culture
  • Calibrating expectations for JAIS submission
  • Reading JAIS Senior Editor letters

When not to use

  • Drafting the response
  • Running the submission preflight
