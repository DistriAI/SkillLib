fable-safe-prompt

authentic

Make minimal prompt edits to reduce false-positive refusals from Fable. Use only when the user explicitly invokes /fable-safe-prompt.

When to use

  • reducing false-positive refusals
  • rephrasing cyber/auth sensitive wording
  • rephrasing bio/chem sensitive wording
  • rephrasing reasoning extraction requests
  • framing work as owned/authorized and defensive

When not to use

  • inventing authorization
  • disguising harmful intent
  • relabeling offensive work as defensive
  • changing text outside prompt tags
