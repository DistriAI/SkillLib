zerotoken

separate

Use when using ZeroToken MCP via OpenClaw for browser automation, trajectory recording and low-token replay, especially for recurring or scheduled browser tasks.

When to use

  • browser automation via OpenClaw + ZeroToken MCP
  • recurring or scheduled browser tasks
  • converting browser operation trajectories into low-token scripts
  • reusing recorded browser operation trajectories
  • executing scripts by job_id for scheduled tasks

When not to use

  • one-time browser operations without reuse needs
  • tasks heavily dependent on human decision-making
  • tasks requiring extensive fuzzy_point intervention
