hpca-topic-selection

separate

Use when deciding whether a project is HPCA-shaped or better routed to ISCA, MICRO, ASPLOS, or a systems/theory venue, weighing whether the machine, the mechanism, or the measurement is the contribution, and whether the main track or the HPCA Industry track fits, from the winter seat of the architecture calendar.

When to use

  • deciding whether a project is HPCA-shaped
  • routing to ISCA, MICRO, ASPLOS, or systems/theory venues
  • weighing machine, mechanism, or measurement contribution
  • selecting main track or HPCA Industry track

When not to use

  • pure algorithm with no machine consequence
  • full language/OS/runtime co-design
