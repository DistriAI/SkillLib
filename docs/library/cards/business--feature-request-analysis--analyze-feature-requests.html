Analyze and prioritize a list of feature requests by theme, strategic alignment, impact, effort, and risk. Use when reviewing customer feature requests, triaging a backlog, or making prioritization decisions.

When to use

  • reviewing customer feature requests
  • triaging a backlog
  • making prioritization decisions
  • categorizing requests into themes
  • assessing strategic alignment
  • prioritizing top 3 features

When not to use

  • allowing customers to design solutions
