wp-abilities-audit

separate

Audit a WordPress plugin's REST surface and produce a standardized audit document proposing Abilities API registrations. Produces a markdown doc with a YAML schema and prose sections that humans and agents can both consume when planning a registration rollout. Works on any WP plugin.

When to use

  • The task is "register Abilities API abilities for a WP plugin" and no audit
  • Planning participation in a multi-plugin abilities rollout and need a
  • Pre-flight checking a plugin's agent-readiness before implementing abilities.
  • A PM or non-implementer wants to scope the work before engineering picks it up.
