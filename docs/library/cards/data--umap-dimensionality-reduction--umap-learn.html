combined

UMAP dimensionality reduction. Fast nonlinear manifold learning for 2D/3D visualization, clustering preprocessing (HDBSCAN), supervised/parametric UMAP, for high-dimensional data. Applies UMAP-learn to nonlinear dimensionality reduction, 2D/3D embeddings, clustering preprocessing, supervised or semi-supervised UMAP, DensMAP, AlignedUMAP, and Parametric UMAP workflows.

When to use

  • 2D/3D visualization
  • clustering preprocessing
  • supervised/parametric UMAP
  • high-dimensional data embedding
  • nonlinear dimensionality reduction
  • feature engineering for downstream ML models
