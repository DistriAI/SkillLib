mind-structure-and-exposition

separate

Use when organizing a Mind article so the argument unfolds in the clearest possible order within the ~8,000-word limit. The job is architecture, not prose polish — a roadmap, the right order of premises, signposting, and a conclusion that claims exactly what was earned. Structures the paper; it does not write the sentences (see mind-writing-style).
