separate

本skill基于东方财富妙想搜索能力，基于金融场景进行信源智能筛选，用于获取涉及时效性信息或特定事件信息的任务，包括新闻、公告、研报、政策、交易规则、具体事件、各种影响分析、以及需要检索外部数据的非常识信息等。避免AI在搜索金融场景信息时，参考到非权威、及过时的信息。

When to use

  • 个股资讯
  • 板块/主题
  • 宏观/风险
  • 综合解读
  • 新闻
  • 公告
  • 研报
  • 政策

When not to use

  • 非权威信息
  • 过时信息
