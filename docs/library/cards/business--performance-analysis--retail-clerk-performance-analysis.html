retail-clerk-performance-analysis

separate

导购个人业绩深度分析工具。支持普通门店（POS数据）和AIoT门店（POS+AIoT数据）。 输出导购个人详细诊断报告，包含： 1. 核心业绩指标（销售额、排名、业绩占比） 2. 雷达图能力对比（6维能力 vs 门店平均） 3. 商品特征分析（品类/价格带/包型/颜色/新品偏好） 4. Top5 SKU爆品分析（门店贡献率、SPU集中度、上市时间） 5. 订单结构分析（折扣/连带/会员结构） 6. AIoT高试用低转化分析（仅AIoT门店） 7. AIoT客户漏斗分析（仅AIoT门店） 8. 14天销售趋势分析 9. 综合诊断与行动建议 触发条件： - 用户询问导购业绩（如"李翠业绩怎么样"） - 用户分析导购能力（如"导购销售能力如何"） - 用户需要导购诊断（如"导购有什么问题"）

When to use

  • Analyze individual clerk performance
  • Generate clerk diagnostic report
  • Analyze clerk sales metrics and ranking
  • Compare clerk capabilities vs store average
  • Analyze product feature preferences
  • Analyze Top5 SKU performance
  • Analyze order structure (discount/attach/member)
  • Analyze AIoT high trial low conversion

When not to use

  • Store-level aggregate analysis without specific clerk
  • Non-retail industry performance analysis
