statusline-generator

separate

Installs, configures, customizes, or troubleshoots the Claude Code statusline (cwd, model, token counts). Use when the user wants to set up or change the statusline, switch minimal vs full layouts, show absolute token counts instead of a percentage, add cost via ccusage, or fix a statusline that is blank, silent, stuck, or stopped updating. Trigger phrases: 状态栏, 状态栏不显示, 状态栏空白, "statusline blank", "statusline broken".
