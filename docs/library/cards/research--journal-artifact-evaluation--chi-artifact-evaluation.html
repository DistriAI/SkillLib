chi-artifact-evaluation

separate

Use when packaging the artifacts behind an ACM CHI paper — prototypes, study instruments, codebooks, datasets, analysis code — for anonymous review scrutiny and for post-acceptance archival release, in a venue with no formal artifact-evaluation committee doing it for you.

When to use

  • Packaging CHI paper artifacts
  • Preparing anonymous review archives
  • Planning post-acceptance archival release
  • Creating claims maps for reviewers
  • Managing artifact anonymity
  • Defining artifact licensing and de-identification

When not to use

  • Formal artifact-evaluation committee certification
  • Tasks in venues with formal artifact-evaluation committees
