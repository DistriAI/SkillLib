text-retrieval-conference

separate

Use when targeting Text REtrieval Conference (TREC) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for retrieval evaluation.

When to use

  • retrieval evaluation
  • tracks
  • test collections
  • search tasks
  • NIST-style benchmarking
  • conference-fit read
  • re-framing from journal style
  • evidence-gap diagnosis

When not to use

  • spoken language technology
  • user-centered search behavior
  • generic CS paper without retrieval focus
  • substitute for current year's CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
