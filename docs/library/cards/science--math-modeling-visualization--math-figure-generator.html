math-figure-generator

authentic

Generate and render-verify publication-quality mathematical-modeling figures from saved evidence, using the approved figure plan, source data, claim, type, and consistent visual system.

When to use

  • Generate publication-quality mathematical-modeling figures
  • Render-verify figures
  • Apply shared color, typography, sizing, and labeling conventions
  • Inspect final output visually
  • Check clipping, overlap, illegible text, misleading axes, legends, empty panels, and source/claim mismatch
  • Iterate until render checks pass

When not to use

  • Fabricate or manually alter plotted values
  • Use a chart type that hides concentration, uncertainty, or negative results
  • Truncate axes misleadingly
  • Create decorative 3D effects
  • Treat code execution as render verification
  • Copy Type 1 diagnostics into the paper directory
