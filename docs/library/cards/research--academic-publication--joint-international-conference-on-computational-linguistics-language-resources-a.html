Use when targeting Joint International Conference on Computational Linguistics, Language Resources and Evaluation (LREC-COLING) or deciding whether a computer-science manuscript fits this venue. Encodes conference fit, framing, evidence bar, submission-cycle checks, rebuttal posture, and desk-reject risks for language resources.

When to use

  • targeting LREC-COLING
  • deciding if a manuscript fits LREC-COLING
  • conference fit read for language resources
  • re-framing journal or arXiv style to conference narrative
  • diagnosing evidence gaps, anonymity, or artifact issues
  • rebuttal posture for LREC-COLING
  • desk-reject risk assessment for language resources

When not to use

  • substitute for current year's CFP
  • substitute for author kit
  • substitute for ethics policy
  • substitute for submission portal
  • programming-language systems
  • generation-specific papers
  • broad NLP empirical work without resource/evaluation focus
