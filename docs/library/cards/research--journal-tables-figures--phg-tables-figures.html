phg-tables-figures

separate

Use when designing the conceptual exhibits of a Progress in Human Geography (PiHG) review essay — typologies, framework diagrams, concept genealogies, and synthesis tables that do argumentative work. For a review journal these are conceptual, not data graphics. Designs exhibits; it does not build the argument itself.
