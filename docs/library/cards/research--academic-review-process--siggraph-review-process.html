siggraph-review-process

separate

Use to model the SIGGRAPH / SIGGRAPH Asia Technical Papers review pipeline and calibrate expectations, covering the single 6-point score scale, the primary/secondary/tertiary reviewer structure, the 1000-word rebuttal, the Technical Papers Committee meeting, conditional acceptance with second-stage verification, and the dual-track Journal-vs-Conference decision.

When to use

  • modeling the SIGGRAPH review pipeline
  • calibrating expectations for SIGGRAPH submissions
  • understanding the 6-point score scale
  • analyzing primary/secondary/tertiary reviewer structure
  • planning the 1000-word rebuttal
  • preparing for the Technical Papers Committee meeting
  • managing conditional acceptance and second-stage verification
  • understanding the dual-track Journal-vs-Conference decision

When not to use

  • writing the actual paper content
  • creating the supplemental video
  • submitting the paper
  • appealing the track assignment
