Applies the journal's fit, macro-policy framing, house-style, official-submission-check, and desk-reject heuristics.

When to use

  • targeting 《宏观经济研究》
  • deciding manuscript fit for 《宏观经济研究》
  • rewriting general Chinese econ/management manuscripts for 《宏观经济研究》
  • listing high-frequency rejection risks
  • checking official submission requirements
  • macro-policy framing
  • house-style compliance
  • desk-reject heuristics

When not to use

  • replacing the latest official submission guidelines
  • using second-hand submission website formats
  • forcing submission based on name, region, or variable similarity
  • industry background or local case studies without core economic contribution
