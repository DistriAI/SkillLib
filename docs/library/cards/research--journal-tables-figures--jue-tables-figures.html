jue-tables-figures

separate

Use when the exhibits of a Journal of Urban Economics (JUE) manuscript must make the spatial pattern visible — maps, event-study plots, RD/boundary figures, and clean regression tables. Designs the spatial exhibits a JUE referee expects; it does not run the analysis (jue-robustness) or write the prose (jue-writing-style).
