eccv-submission

separate

Use when auditing an ECCV submission for the two-step registration-then-paper deadline chain, the 14-page LNCS single-column limit, CET (not AoE) cutoffs, the trailing supplementary deadline, double-blind rules, the four-page dual-submission definition, the social-media embargo, and reviewer-duty exposure before upload.

When to use

  • auditing ECCV submission
  • checking registration deadline
  • verifying 14-page LNCS limit
  • checking CET cutoffs
  • verifying supplementary deadline
  • checking double-blind rules
  • verifying dual-submission definition
  • checking social-media embargo

When not to use

  • rushing a broken upload
  • quoting current dates without reopening official pages
