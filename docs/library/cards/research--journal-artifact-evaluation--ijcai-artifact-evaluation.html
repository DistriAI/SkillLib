ijcai-artifact-evaluation

separate

Use when packaging IJCAI or IJCAI-ECAI code, data, proofs, models, and appendices as reproducibility evidence or supplementary material, especially when there is no separate artifact-evaluation badge but reviewers need convincing, anonymous, deadline-safe evidence.

When to use

  • packaging IJCAI or IJCAI-ECAI code
  • packaging data, proofs, models, and appendices
  • creating reproducibility evidence
  • preparing supplementary material
  • anonymizing repository paths and metadata
  • designing minimal run maps
  • matching artifacts to claim types

When not to use

  • assuming a separate formal artifact evaluation track
