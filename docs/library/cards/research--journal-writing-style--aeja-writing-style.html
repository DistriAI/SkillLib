aeja-writing-style

separate

Use when revising the prose, abstract, and introduction of an American Economic Journal: Applied Economics (AEJ: Applied) manuscript so the design and headline estimate land in the first paragraph in AEA house style. Polishes exposition; it does not change the result (aeja-identification / aeja-robustness) or the exhibits.

When to use

  • Revising prose, abstract, and introduction
  • Polishing exposition
  • Ensuring design and headline estimate land in first paragraph
  • Formatting abstract and intro per AEA house style

When not to use

  • Changing the result
  • Changing exhibits
  • Handling identification
  • Handling robustness
