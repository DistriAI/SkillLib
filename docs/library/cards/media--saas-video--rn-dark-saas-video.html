rn-dark-saas-video

separate

Create dark cinematic SaaS/product motion videos in the Presenton-like "magic UI" style: black starfield stage, bottom purple glow, large kinetic type, cyan-to-magenta CTA buttons, prompt cards, floating UI templates, integration badges, model rings, export objects, speed-blur transitions, and short product capability arcs. Use when the user asks for "这种风格", "同款风格", dark SaaS promo, AI product demo, magic UI product video, or a style-level creation inspired by a reference video. Do not use for pixel-level or frame-accurate replication; use rn-replica-qc first for that.

When to use

  • dark SaaS promo
  • AI product demo
  • magic UI product video
  • style-level creation inspired by reference video
  • dark tech SaaS product short film
  • AI tool product demonstration

When not to use

  • pixel-level replication
  • frame-accurate replication
  • timestamp-accurate remakes
  • generic product launch video
