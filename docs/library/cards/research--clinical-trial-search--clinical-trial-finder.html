clinical-trial-finder

separate

Find clinical trials for a gene, variant, or condition from ClinicalTrials.gov + EUCTR, with FHIR R4 output

When to use

  • Find clinical trials for a gene
  • Find clinical trials for a variant
  • Find clinical trials for a condition
  • Query ClinicalTrials.gov API v2
  • Query EUCTR
  • Generate FHIR R4 ResearchStudy output
  • Gene enrichment via OpenTargets
  • Filter trials by status or country

When not to use

  • Parsing eligibility criteria
  • Automated NLP for clinical enrollment decisions
