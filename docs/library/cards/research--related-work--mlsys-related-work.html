mlsys-related-work

separate

Use when positioning an MLSys submission against the fast-moving ML-systems literature scattered across OSDI, SOSP, NSDI, ASPLOS, and ML venues, handling arXiv-first and open-source-first prior work, comparing against production systems that have no paper, and writing the delta statement two reviewer cultures will both accept.

When to use

  • positioning an MLSys submission
  • auditing positioning and novelty
  • mapping ML-systems literature across venues
  • handling arXiv-first and open-source-first prior work
  • comparing against production systems without papers
  • writing the delta statement
  • building the capability table
  • addressing the freshness problem

When not to use

  • citing famous ML-systems work to the wrong venue
  • claiming 'first to X' without qualification
  • dismissing unpublished systems as 'not peer-reviewed'
  • creating comparison tables with unverified negative cells
