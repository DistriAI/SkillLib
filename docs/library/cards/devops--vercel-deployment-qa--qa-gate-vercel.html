qa-gate-vercel

separate

Pre-production validation gate for Vercel/Supabase/Firebase stack — generates test plans, executes test suites, validates APIs, UI, toasts, LLM output quality, and produces go/no-go reports

When to use

  • generates test plans
  • executes test suites
  • validates APIs
  • validates UI
  • validates toasts
  • assesses LLM output quality
  • produces go/no-go reports

When not to use

  • writing individual unit tests
  • reading or modifying .env files
  • reading or modifying .env.local files
  • reading or modifying credential files directly
