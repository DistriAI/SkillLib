qe-writing-style

separate

Use when polishing prose, abstract, and introduction for a Quantitative Economics (QE) manuscript so a quantitative method and its economic payoff land for a general-interest Econometric Society readership. Reflects QE house rules (no significance asterisks; report SEs/coverage sets). Polishes exposition; it does not change results or estimation.

When to use

  • polishing prose
  • polishing abstracts
  • polishing introductions
  • QE manuscript writing
  • Econometric Society style
  • reporting standard errors
  • reporting coverage sets
  • quantitative method exposition

When not to use

  • changing results
  • changing estimation
  • chasing reference format
  • heavy derivations
  • extra results
