wp-data-analysis

separate

Use when executing and reporting the analysis for a World Politics manuscript so it survives expert triple-blind review and the Dataverse replication requirement — honest uncertainty, robustness, and triangulation appropriate to comparative cross-national, qualitative, or formal-empirical work. Guides analysis norms; it does not fabricate results.

When to use

  • Running main and supporting analyses
  • Building the results/findings section
  • Addressing reviewer requests for robustness or heterogeneity
  • Reconciling cross-case patterns with within-case evidence
  • Making analysis reproducible before deposit
  • Reporting uncertainty and effect sizes
  • Validating measurement across cases
  • Executing quantitative-causal analysis chains

When not to use

  • Fabricating results
  • Design decisions
  • Tasks not related to World Politics manuscript analysis
