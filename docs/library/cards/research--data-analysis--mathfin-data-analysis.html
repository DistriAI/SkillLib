mathfin-data-analysis

separate

Use when designing or auditing the numerical-experiments part of a Mathematical Finance (Wiley) manuscript — at this theory-first venue that means illustrative computation that SUPPORTS a proof (convergence, error bounds, qualitative behavior), never empirical data analysis. Keeps numerics rigorous, reproducible, and subordinate to the theorems.

When to use

  • designing numerical experiments for a Mathematical Finance manuscript
  • auditing numerical experiments for a Mathematical Finance manuscript
  • illustrating convergence, error bounds, or qualitative behavior
  • stress-testing a theorem with numerical work
  • matching numerical schemes to result types
  • conducting a pre-submission numerics audit

When not to use

  • empirical data analysis
  • routine application of computational methods to financial data
  • empirical estimation
  • calibrating to real market data and presenting it as the paper's result
  • stand-alone empirical study
