wber-submission

separate

Use when running the final pre-submission preflight for The World Bank Economic Review (WBER) via the ScholarOne ManuscriptCentral portal — the 40-page total cap, single-anonymized title page, abstract/JEL, data availability statement with DOI, and house format. Final checks; it does not draft content.

When to use

  • final pre-submission preflight for WBER
  • checking 40-page total cap
  • verifying single-anonymized title page
  • confirming data availability statement with DOI
  • checking house format and font rules
  • deciding between full-length and short-format track
  • verifying ScholarOne ManuscriptCentral submission requirements

When not to use

  • drafting content
  • writing the manuscript
  • performing peer review
  • editing scientific content
