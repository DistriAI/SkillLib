ssi-supplementary

separate

当需要为《中国科学：信息科学》(Scientia Sinica Informationis, SSI) 稿件规划附录、补充材料与多媒体附件、并决定哪些内容放正文、哪些放补充时调用。覆盖正文与补充的划分原则（决定录用的证据必须在正文）、附录用途、补充材料的格式与容量、多媒体/演示附件、以及各栏目（评述/论文/快报）的差异化处理。作为国家级大信息学科综合旗舰，本刊正文强调科学价值与创新高度，补充材料服务复核而非承载核心论证；具体格式以官网当期须知为准，未确认者标待核实。

When to use

  • 规划SSI稿件附录与补充材料
  • 决定正文与补充材料的内容划分
  • 处理SSI各栏目差异化补充策略
  • 规划多媒体与演示附件
  • 检查补充材料自足性与一致性

When not to use

  • 撰写SSI正文核心论证
  • 确定SSI具体格式与容量细节
  • 处理SSI可复现包具体构建
