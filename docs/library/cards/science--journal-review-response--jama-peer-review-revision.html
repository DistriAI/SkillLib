jama-peer-review-revision

separate

Use when responding to JAMA editor and reviewer comments after a revise decision, including the statistical-review queries. Structures the point-by-point response and revision; it does NOT fabricate new analyses or overstate changes.

When to use

  • responding to JAMA editor and reviewer comments
  • addressing statistical-review queries
  • structuring point-by-point responses
  • revising manuscript before writing response
  • handling common JAMA comment types
  • updating reporting checklists
  • preparing tracked-changes and clean copies

When not to use

  • fabricating new analyses
  • overstating changes
  • writing response before revising manuscript
  • skipping uncomfortable comments
  • claiming changes not reflected in manuscript
  • defensive or dismissive tone
  • presenting post hoc analyses as confirmatory
  • reintroducing spin
