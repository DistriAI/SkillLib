ijcai-author-response

separate

Use when drafting IJCAI or IJCAI-ECAI author responses under the official one-page template, concise-response guidance, no-new-results constraints, code-link restrictions, factual-error triage, pressing-question triage, and confidential unethical-review channel.

When to use

  • drafting IJCAI author responses
  • drafting IJCAI-ECAI author responses
  • factual-error triage
  • pressing-question triage
  • confidential unethical-review channel
  • concise-response guidance
  • no-new-results constraints
  • code-link restrictions

When not to use

  • complaining about tone
  • complaining about scores
  • complaining about reviewer identity
  • broad disagreement without a decision-relevant correction
  • uploading new code
  • uploading new links
  • uploading new experiments
  • uploading new results
