cr-commit-check

separate

【Code Review 子 Agent · 门控一】校验本迭代所有 commit 是否符合 Conventional Commits 规范及项目可追溯性格式。输入 git log 片段和项目元数据，输出结构化校验报告并以 STATUS=OK|FAIL 结尾。由 spec-driven-dev 的 code_review 阶段自动调用，不建议单独触发。

When to use

  • Validate Conventional Commits format
  • Check commit type against allowed list
  • Verify single commit per iteration
  • Check scope for us_id and iter_id
  • Verify task list completeness in commit message
  • Detect WIP or temporary commits

When not to use

  • Auto-correct non-compliant commits
  • Upgrade minor suggestions to FAIL
  • Silently pass when git_log is empty
  • Triggered independently
