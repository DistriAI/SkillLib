amr-tables-figures

separate

Use when building the conceptual exhibits of an Academy of Management Review (AMR) manuscript — process models, 2x2 typologies, multi-level frameworks, and propositions tables that carry theoretical work. These are CONCEPTUAL figures, NOT data plots; AMR has no charts of results because it has no data.

When to use

  • building conceptual exhibits for AMR manuscripts
  • creating process models
  • designing 2x2 typologies
  • developing multi-level frameworks
  • constructing propositions tables
  • visualizing theoretical work

When not to use

  • data plots
  • charts of results
  • scatterplots
  • bar charts
  • regression tables
