pinia

authentic

Pinia official Vue state management library, type-safe and extensible. Use when defining stores, working with state/getters/actions, or implementing store patterns in Vue apps.

When to use

  • defining stores
  • working with state/getters/actions
  • implementing store patterns in Vue apps
  • extending stores with plugins
  • using Vue composables within stores
  • store-to-store communication
  • unit testing with @pinia/testing
  • SSR and Nuxt integration
