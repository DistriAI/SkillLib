Use when user asks to leverage codex, gpt-5, or gpt-5.1 to implement something (usually implement a plan or feature designed by Claude). Provides non-interactive automation mode for hands-off task execution without approval prompts. A radically minimal, blank-canvas interface built as a pure edge-to-edge surface, with almost no color and typography carrying the visual weight. Black serves as the only filled color, the only divider, and the sole surface tone cards.

When to use

  • implement a plan or feature
  • non-interactive automation mode
  • hands-off task execution
  • small tasks
  • features, bugfixes, refactors
  • worktree setup through PR merge

Skill page

Conflict

The four copies are not reproductions of one procedure. dzhng/skills treats Codex as a second-opinion reviewer with a specific review command, triage, and reporting loop. softaworks/agent-toolkit treats Codex as a task runner with model selection, reasoning effort, sandbox flags, and resume syntax. LeoYeAI/openclaw-master-skills treats Codex as a managed coding agent with worktrees, tmux, polling, and PR workflow. bergside/awesome-design-skills is a design-system authoring skill that merely names Codex in its frontmatter and does not describe running the CLI. Each contains material steps or constraints the others lack, and they disagree on defaults and safety controls, so crowning one would hide real alternatives.
