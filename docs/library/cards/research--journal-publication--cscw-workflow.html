cscw-workflow

separate

Use when planning a CSCW submission timeline end to end — the PACMHCI journal model, the retired fixed cycles versus the rolling 2027+ pathway, Revise-and-Resubmit rounds that span months, and back-planning so an acceptance lands before the conference-year presentation cutoff.

When to use

  • planning CSCW submission timeline
  • managing PACMHCI journal model
  • navigating rolling 2027+ pathway
  • planning Revise-and-Resubmit rounds
  • back-planning for conference presentation cutoffs
  • verifying submission regime
  • managing revision capacity
  • tracking status reports

When not to use

  • writing author response letters
  • preparing camera-ready files
  • finalizing ethics/consent artifacts
  • conducting data collection
  • drafting response letters
