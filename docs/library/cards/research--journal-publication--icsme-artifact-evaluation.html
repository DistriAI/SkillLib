icsme-artifact-evaluation

separate

Use when packaging an IEEE ICSME artifact for the Joint Artifact Evaluation Track and ROSE Festival, covering the IEEE "Open Research Object" and "Research Object Reviewed" badges, what evaluators check first, DOI-issuing archives, evaluator-proof documentation, the shared track with SCAM and VISSOFT, and the separate post-acceptance deadline.

When to use

  • packaging an IEEE ICSME artifact
  • Joint Artifact Evaluation Track and ROSE Festival
  • IEEE Open Research Object badge
  • IEEE Research Object Reviewed badge
  • DOI-issuing archives
  • evaluator-proof documentation
  • shared track with SCAM and VISSOFT
  • post-acceptance deadline

When not to use

  • ACM badge names
  • FSE and other ACM venues
