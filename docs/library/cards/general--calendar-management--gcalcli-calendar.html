gcalcli-calendar

separate

Google Calendar via gcalcli: today-only agenda by default, bounded meaning-first lookup via agenda scans, and fast create/delete with verification--optimized for low tool calls and minimal output.

When to use

  • today-only agenda
  • bounded meaning-first lookup
  • fast create/delete with verification
  • weekday requests without mental math
  • deterministic agenda scan
  • cross-calendar overlap check
  • non-interactive deletion

When not to use

  • printing CLI commands unless explicitly asked
  • broadening calendar scope unless requested
  • using search as primary lookup method
  • writing temp .ics files
  • using quick add unless explicitly requested
