von-restorff-effect

separate

Apply the Von Restorff Effect — the element that differs from its neighbours is the one remembered. Use when a single action must dominate. For overall ordering rather than single-element emphasis, use `visual-hierarchy`.

When to use

  • single action dominance
  • visual differentiation
  • call to action emphasis
  • pricing tier highlighting
  • navigation active states
  • data table row highlighting
  • notification badges
  • onboarding step isolation

When not to use

  • overall ordering
  • single-element emphasis alternatives
  • multiple competing elements
  • decorative color pops
