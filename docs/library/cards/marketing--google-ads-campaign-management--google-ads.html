Skill page

Conflict

The two copies describe different procedures for the same skill name. The first is a self-contained strategy guide covering PMF testing, campaign structure, Performance Max asset requirements, keyword strategy, Quality Score, and bidding thresholds. The second is a thin wrapper that mandates reading and following a separate WORKFLOW.md file for operational management (bulk operations, experiments, asset management, change review). Neither copy contains the other's material steps, and the second's instruction to defer to an external file conflicts with the first's direct procedural guidance, so crowning one would hide a real alternative.
