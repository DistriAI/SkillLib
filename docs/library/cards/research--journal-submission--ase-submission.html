ase-submission

separate

Use when auditing an ASE (IEEE/ACM Automated Software Engineering) research-track submission for HotCRP readiness, covering the ACM acmart sigconf template and the 10+2 page budget, double-anonymous review, the mandatory Data Availability Statement, the early-rejection stage before rebuttal, and desk-reject triage before the deadline.

When to use

  • Auditing ASE research-track submissions
  • Checking ACM acmart sigconf template compliance
  • Verifying 10+2 page budget
  • Conducting double-anonymous review sweeps
  • Validating mandatory Data Availability Statement
  • Performing desk-reject triage
  • Checking HotCRP portal readiness

When not to use

  • Uploading to NIER, Tools-and-Datasets, or Journal-First tracks
  • Formatting papers for non-ASE conferences
  • Managing post-acceptance revisions
