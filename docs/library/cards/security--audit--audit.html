Skill page

Conflict

The two skills share the name 'audit' but perform completely different tasks. The first skill bootstraps project context by writing AGENTS.md files for AI agents. The second skill performs static security analysis on AI skill bundles to detect malicious patterns. They do not overlap in procedure, and crowning one would hide a real alternative.
