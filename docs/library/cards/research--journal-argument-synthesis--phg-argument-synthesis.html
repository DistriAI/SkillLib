phg-argument-synthesis

separate

Use when turning a mapped literature into one cumulative argument for a Progress in Human Geography (PiHG) review essay — synthesizing many sources into a claim the field could not see from any one of them. Builds the synthetic spine; it does not gather sources (see phg-literature-positioning) or make the critical turn (see phg-critical-intervention).

When to use

  • building the synthetic spine
  • turning mapped literature into a cumulative claim
  • organizing sections by sub-claims
  • making sources talk to each other
  • handling disconfirming work
  • reconciling, periodizing, or adjudicating literature

When not to use

  • gathering sources
  • making the critical turn
  • annotated bibliography structure
  • summary organized by source
