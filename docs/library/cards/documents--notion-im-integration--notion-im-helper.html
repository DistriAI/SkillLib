notion-im-helper

separate

通过即时通讯(IM)向 Notion 添加内容。支持闪念速记、待办清单、多级标题、引用、分割线、有序/无序列表、多级下拉列表（Toggle）、标签分类、项目归类等。当用户消息以 'flash:'、'待办:'、'todo:'、'搜:'、'摘抄'、'日报'、'周报' 等关键词开头，或包含 Notion 记录相关意图时触发。只追加不删除，安全可靠。

When to use

  • 添加闪念速记
  • 添加待办清单
  • 添加多级标题
  • 添加引用和分割线
  • 添加有序/无序列表
  • 添加多级下拉列表
  • 标签分类和项目归类
  • 搜索笔记和生成日报/周报

When not to use

  • 删除 Notion 内容
  • 修改已有内容块
  • 自行拼装 Notion API 调用
