research-repository

separate

Build a repository that makes findings findable, reusable, and cumulative across teams. Use when the same research keeps getting redone. For synthesising one study, use `affinity-diagram`.

When to use

  • Designing repository systems
  • Defining tagging conventions
  • Maintaining research rituals
  • Organizing insights, studies, and raw data
  • Creating controlled vocabularies
  • Establishing maintenance culture
  • Selecting repository tools
  • Testing search and retrieval

When not to use

  • Synthesising one study
