jedpsych-topic-selection

separate

Use when deciding whether an educational-psychology project fits the Journal of Educational Psychology and which manuscript type to target. JEP wants original, primary psychological research on learning and instruction that matters for real educational settings; it does not typically publish single-instrument reliability/validity studies. Frames the question; it does not collect data.

When to use

  • Choosing among possible projects or framings for JEP
  • Deciding between a single study, a multi-study package, or a meta-analysis
  • Pressure-testing fit before investing
  • Determining if a measurement/validation paper belongs in JEP

When not to use

  • Collecting data
  • Single-instrument reliability/validity studies
  • Pure program evaluation with no psychological mechanism
  • Lab effects with no plausible bridge to learning or instruction
