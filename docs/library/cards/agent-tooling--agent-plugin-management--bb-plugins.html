bb-plugins

separate

Build, install, and debug bb plugins. Use when the user wants a bb plugin, a sidebar panel, a bb CLI subcommand, an agent tool, a theme, a provider, or to extend bb itself. For running threads and the core bb CLI, use bb-cli instead.

When to use

  • create bb plugin
  • install bb plugin
  • change bb plugin
  • build sidebar panel
  • add bb CLI subcommand
  • create agent tool
  • create theme
  • create provider

When not to use

  • running threads
  • core bb CLI operations
  • operate bb projects
  • operate bb environments
