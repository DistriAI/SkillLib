Skill page

Conflict

The two copies are different versions of the same skill. The first (v3.3.1) is a newer, more complex version that adds a detailed routing core, an escape hatch, and a screening boundary, but its text is truncated before the main execution steps. The second (v2.5) is an older version that provides the complete execution flow, trigger conditions, and agent team definitions, but lacks the advanced routing logic. Because the first copy is missing the core procedure and the second is missing the advanced routing, neither is a complete reproduction of the other, and combining them is necessary to capture the full skill.
