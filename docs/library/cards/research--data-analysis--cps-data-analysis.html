cps-data-analysis

separate

Use when running and reporting the analyses for a Comparative Political Studies (CPS) manuscript — estimation, uncertainty, robustness, and multi-method triangulation on comparative data. Sets analysis norms; it does not choose the identification strategy (see cps-research-design).

When to use

  • Estimating main results, robustness, and heterogeneity
  • Addressing reviewer questions on standard errors, specification, measurement, or fragility
  • Deciding content for main text vs. supplementary/online appendix
  • Triangulating quantitative estimates with case evidence
  • Handling comparative-data hazards like few clusters and measurement error
  • Running failure-mode audits for concept equivalence and selection
  • Executing analysis batteries via StatsPAI or Stata MCP

When not to use

  • Choosing the identification strategy
