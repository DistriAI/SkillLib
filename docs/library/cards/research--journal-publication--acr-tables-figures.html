acr-tables-figures

separate

Use when finalizing tables and figures for a 《会计研究》 (Accounting Research) manuscript — keeping the main table lean, reporting coefficients with the right precision, and interpreting economic magnitude (not just significance stars) for accounting measures. Use after robustness is settled.

When to use

  • finalizing tables and figures
  • keeping main table lean
  • reporting coefficients with right precision
  • interpreting economic magnitude
  • creating event study plots
  • creating parallel trends plots
  • generating tables from fitted results
  • checking table notes completeness

When not to use

  • robustness checks
  • data collection
  • variable construction
  • model specification
