2d-pixel-perfect

separate

Sets up, diagnoses, and fixes pixel perfect 2D rendering with PixelPerfectCamera in URP or Built-in. Use when a retro-style or pixel art 2D game looks blurry, jittery, or misaligned. Not for HD 2D or high-resolution art.

When to use

  • pixel perfect 2D rendering setup
  • diagnosing blurry sprites
  • fixing jittery rendering
  • fixing misaligned sprites
  • URP PixelPerfectCamera configuration
  • Built-in PixelPerfectCamera configuration
  • retro-style 2D game rendering
  • pixel art 2D game rendering

When not to use

  • **HD 2D or high-resolution 2D games** — pixel snapping and point filtering will make smooth art look wrong
  • **UI-only scenes** — use Canvas Scaler instead
  • **HDRP projects** — Pixel Perfect Camera is not supported
