replica-launch

separate

Writes the launch for an app clone: the landing page built on the positioning angle, pricing set against the original's public pricing and its users' complaints, and the App Store and Google Play listing linted against the stores' limits and copycat rules. Use when the user says "landing page", "pricing", "how much should I charge", "App Store listing", "store screenshots", "launch plan", "Product Hunt", or after /replica-brand.

When to use

  • landing page
  • pricing
  • how much should I charge
  • App Store listing
  • store screenshots
  • launch plan
  • Product Hunt

When not to use

  • invented testimonials
  • fake user counts
  • fake star ratings
  • fake press logos
  • using the original's name in app name
  • using the original's name in store listing
  • using the original's name in keywords
  • using the original's name in ads
