pnas-statistics

separate

Use to enforce PNAS's statistics and reproducibility reporting — n and replication, test choice and assumptions, effect sizes with uncertainty, multiple-comparison control, randomization/blinding, sample-size justification, pre-registration where relevant, and reproducible code.

When to use

  • enforce PNAS statistics reporting
  • check reproducibility reporting
  • verify effect sizes and uncertainty
  • validate multiple-comparison control
  • assess randomization and blinding
  • justify sample size
  • check pre-registration
  • review reproducible code

When not to use

  • report P without effect size and n
  • count technical replicates as independent observations
  • infer no effect from non-significant underpowered tests
  • present post-hoc findings as pre-specified
