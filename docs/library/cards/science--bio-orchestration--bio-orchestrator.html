bio-orchestrator

separate

Meta-agent that routes bioinformatics requests to specialised sub-skills. Handles file type detection, analysis planning, report generation, and reproducibility export.

When to use

  • routing bioinformatics requests
  • file type detection
  • analysis planning
  • report generation
  • reproducibility export
  • multi-step analysis chaining
  • dependency checking
  • audit logging

When not to use

  • uploading genomic data to external services without confirmation
  • operating on paths outside the working directory without permission
  • destructive actions without user confirmation
