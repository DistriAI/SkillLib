mgsci-submission

separate

Use when running the final pre-submission preflight for a Management Science (INFORMS) manuscript — ScholarOne seven-step upload, double-anonymization, author-year house style, the $79 submission fee and waivers, the Data and Code Disclosure package and project-page URL, and conference-proceedings disclosure. It checks readiness to submit; it does not handle the post-decision response (mgsci-rebuttal).
