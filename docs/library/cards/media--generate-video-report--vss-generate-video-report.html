vss-generate-video-report

separate

Use this skill when producing a VSS analysis report — Mode A per-clip VLM, Mode B incident-range via video-analytics. Not for standalone video summarization, real-time alerts or ad-hoc Q&A.

When to use

  • Mode A per-clip VLM report
  • Mode B incident-range report
  • Report on recorded video clip
  • Report on incidents within a time range
  • Report on alerts

When not to use

  • Standalone video summarization
  • Real-time alerts
  • Ad-hoc Q&A
  • Archive/semantic similarity retrieval
  • Read-only incident/metrics lookup
  • Deploy/teardown/profile changes
  • Real-time alert/rule management
