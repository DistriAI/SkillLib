research-audience-fit-definition

separate

Step of the research-audience playbook: drafts the searchable fit definition, exclusions and list size that the list run then searches on. Run research-audience instead; not for direct use.

When to use

  • Drafting searchable fit definition
  • Defining exclusions
  • Determining list size
  • Identifying motion and list unit
  • Translating personas into title synonyms
  • Loading exclusions from human files and ledgers
  • Setting account value rules
  • Drafting definition without human answers

When not to use

  • Direct use
  • Running research-audience
  • Inventing customers, logos, or loss reasons
  • Copying values from fictional examples
  • Widening or narrowing definition after correction without notice
