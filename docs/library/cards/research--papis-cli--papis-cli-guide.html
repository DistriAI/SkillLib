papis-cli-guide

separate

Guide to Papis command-line document and bibliography manager for researchers

When to use

  • Managing documents and bibliography via CLI
  • Adding papers from DOI, arXiv, BibTeX, or ISBN
  • Searching and browsing library entries
  • Exporting BibTeX and BibLaTeX files
  • Updating metadata from online sources
  • Integrating with Git for version control
  • Scripting with the Papis Python API
  • Configuring multiple libraries

When not to use

  • GUI-based reference management
  • Non-terminal workflows
