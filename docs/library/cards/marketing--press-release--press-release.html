Skill page

Conflict

The two copies define different artifacts and procedures. The deanpeters copy is a planning tool based on Amazon's Working Backwards methodology, intended to be written before a product is built to test customer value and align stakeholders. It uses a 10-section structure focused on customer outcomes and explicitly states it is not for launch day. The mohitagw15856 copy is a production tool for writing a final, journalist-ready press release for an actual announcement. It uses an inverted pyramid structure, includes embargo dates, and focuses on news value and media contact details. Because they serve different stages of the product lifecycle (planning vs. launch) and have conflicting structural requirements (e.g., 'not for launch day' vs. 'ready to send to journalists'), crowning one would hide a valid alternative use case.
