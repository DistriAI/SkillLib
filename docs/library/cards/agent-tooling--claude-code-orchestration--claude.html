Conflict

The four copies are not reproductions of a single procedure. dzhng/skills and LeoYeAI/openclaw-master-skills both describe how to invoke and manage the `claude` CLI as a subagent, but they disagree on defaults, safety mechanisms, and operational details. bergside/awesome-design-skills is a design-system authoring skill that merely uses the name 'claude' for a brand aesthetic, and foryourhealth111-pixel/Vibe-Skills is a meta-skill for creating other skills. Because the copies cover distinct tasks (CLI orchestration vs. design authoring vs. skill creation) and the two CLI-focused copies contain conflicting operational constraints, crowning one would hide real alternatives.
