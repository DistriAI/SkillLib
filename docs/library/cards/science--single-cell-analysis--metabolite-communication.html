metabolite-communication

separate

Infers metabolite-mediated cell-cell communication from scRNA-seq by scoring enzyme-to-sensor pairs (MEBOCOST), with metabolic flux (scFEA), FBA state (Compass), and neurotransmitter (NeuronChat) alternatives. Use when studying metabolic crosstalk between cell types, predicting metabolite secretion and sensing, or deciding which metabolic-communication method fits and how speculative the result is.

When to use

  • metabolite crosstalk between cell types
  • predicting metabolite secretion and sensing
  • scoring enzyme-to-sensor pairs
  • per-cell metabolic flux
  • per-cell metabolic state via FBA
  • neurotransmitter communication
  • deciding which metabolic-communication method fits

When not to use

  • measuring absolute metabolite levels
  • claiming direct neighbor exchange from dissociated data
  • applying NeuronChat outside neural tissue
  • using scFEA as a direct CCC tool
  • using Compass to claim secreted metabolite communication
