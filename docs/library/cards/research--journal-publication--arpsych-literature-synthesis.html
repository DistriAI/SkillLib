arpsych-literature-synthesis

separate

Use when systematically gathering, reading, and structuring the literature for an Annual Review of Psychology (ARPsych) review so coverage is comprehensive and current. Builds the evidence base; it does not design the analytical spine (arpsych-organizing-framework) or judge balance (arpsych-comprehensiveness-and-balance).

When to use

  • systematically gathering literature
  • reading and structuring literature
  • building evidence base
  • documentable search
  • citation chasing
  • database sweep
  • building evidence matrix
  • checking coverage gaps

When not to use

  • designing the analytical spine
  • judging balance
  • arpsych-organizing-framework
  • arpsych-comprehensiveness-and-balance
