git-worktree

separate

Use Git worktrees to isolate parallel coding tasks. Use when setting up a task checkout, working in a shared repo, or managing existing worktrees.

When to use

  • setting up a task checkout
  • working in a shared repo
  • managing existing worktrees
  • isolating parallel coding tasks
  • creating and removing worktrees
  • bootstrapping worktree environment
  • merging and cleaning up worktrees

When not to use

  • running git worktree add in Cloudroom
  • sharing a working directory between agents
  • auto-merging worktrees
  • pushing task branches unless explicitly asked
