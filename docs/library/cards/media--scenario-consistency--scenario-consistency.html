scenario-consistency

separate

Use when one look must hold across Scenario generations: one character across scenes, a turnaround, or a video animated from its references, one product across angles, one style across icon sets, a character from an uploaded drawing, a variant off an approved baseline, or deciding when references stop scaling and a trained model is due. Triggers: make this match, same character, on-model, reference to video, style reference. Keywords: consistency, identity, control map, seed, LoRA.

When to use

  • one character across scenes
  • turnaround
  • video animated from references
  • one product across angles
  • one style across icon sets
  • character from an uploaded drawing
  • variant off an approved baseline
  • deciding when references stop scaling

When not to use

  • training a model
  • creating a named character or prop library
  • general scenario generation without consistency requirements
