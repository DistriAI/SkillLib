Use when running the final pre-submission preflight for an Econometrica manuscript via Editorial Express — manuscript assembly, Supplemental Material, the 45-page limit, anonymization, references, the ES-member submission fee, and Data and Code Availability Policy compliance.

When to use

  • final pre-submission preflight
  • manuscript assembly
  • Supplemental Material preparation
  • 45-page limit verification
  • anonymization checks
  • references verification
  • ES-member submission fee handling
  • Data and Code Availability Policy compliance

When not to use

  • initial manuscript drafting
  • referee selection strategy
  • replication package construction
  • post-acceptance final file submission
