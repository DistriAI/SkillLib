nbr-china-context

separate

Use to contextualize theory for 《南开管理评论》 (Nankai Business Review) — showing how the China context changes construct meanings, mechanisms, or boundary conditions, rather than using China merely as a sampling site. Use when the China context appears only in the sample description, or when the paper asserts "Chinese characteristics" without specifying how the context alters the theory.
