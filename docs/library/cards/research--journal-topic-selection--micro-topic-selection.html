micro-topic-selection

separate

Use when deciding whether a project belongs at MICRO (IEEE/ACM International Symposium on Microarchitecture) or should route to ISCA, HPCA, ASPLOS, DAC/ICCAD, SC, or MLSys — testing whether the mechanism truly lives inside the machine, gauging the MICRO evidence bar, and weighing the main track against the new Industry Track.

When to use

  • Deciding venue for microarchitecture projects
  • Testing mechanism residency
  • Gauging MICRO evidence bar
  • Weighing main track against Industry Track
  • Routing to ISCA, HPCA, ASPLOS, DAC/ICCAD, SC, or MLSys
  • Adjudicating borderline cases like microarchitectural security
  • Evaluating simulation methodology and modeling tools
  • Assessing compiler-assisted hardware

When not to use

  • Writing evaluation sections
  • Pure software optimizations
  • ISA proposals with no implementation sketch
  • Characterization with no mechanism
  • Circuits work with no architectural consequence
  • Vulnerability disclosure or software mitigation
