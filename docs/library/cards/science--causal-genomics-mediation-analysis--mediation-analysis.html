mediation-analysis

separate

Decompose total effects into direct and indirect paths through mediators using mediation, CMAverse 4-way, HIMA/HIMA2 high-dimensional, BAMA, two-step / MVMR mediation, or double-ML medDML. Use when testing whether a molecular phenotype (expression, methylation, protein) mediates a treatment-outcome relationship, decomposing exposure-mediator interaction via VanderWeele 4-way, screening high-dimensional EWAS mediators, or running MR-based mediation when sequential ignorability is implausible.

When to use

  • testing whether a molecular phenotype mediates a treatment-outcome relationship
  • decomposing exposure-mediator interaction via VanderWeele 4-way
  • screening high-dimensional EWAS mediators
  • running MR-based mediation when sequential ignorability is implausible
  • decomposing total effects into direct and indirect paths
  • handling exposure-mediator interaction
  • sensitivity to unmeasured confounding
  • high-dimensional mediator screening

When not to use

  • tasks where sequential ignorability is not assumed or tested
  • non-mediation causal inference tasks
