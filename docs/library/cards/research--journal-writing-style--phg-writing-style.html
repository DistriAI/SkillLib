phg-writing-style

separate

Use when polishing a Progress in Human Geography (PiHG) review essay to house style — the argument-forward review voice, SAGE Harvard referencing, the ~8,000-word inclusive cap, ~100-word unstructured abstract, and 5+ keywords. Polishes prose and format; it does not build the argument.

When to use

  • Polishing PiHG review essay prose
  • Fitting essay into ~8,000-word cap
  • Writing abstract and keywords
  • Enforcing SAGE Harvard referencing
  • Checking argument-forward voice
  • Removing annotated bibliography style

When not to use

  • Building the argument
  • Creating empirical reports
  • Neutral surveys
