The two copies overlap heavily on cmux topology, ref syntax, and send-input rules, but each contains material steps the other lacks. The davidondrej copy is the more complete upstream procedure (it includes the inspect/read/send sequence, surface-health checks, ownership/focus preservation, and a troubleshooting section). The sickn33 copy adds a shell detection snippet, a broader fast-start topology command set (move/split/reorder/close), and a distinct polling interval for Pi agents. Because the copies disagree on polling cadence and the catalog copy explicitly omits supporting reference files, crowning one would hide a real alternative and a real conflict.
