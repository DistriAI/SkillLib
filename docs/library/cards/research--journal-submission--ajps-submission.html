ajps-submission

separate

Use when running the final pre-submission preflight for the American Journal of Political Science (AJPS) via Editorial Manager — submission-type selection, full anonymizing for double-blind review, word/abstract caps, APSA-or-Chicago formatting, the 25-page Supporting Information limit, and human-subjects/IRB documentation. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • submission-type selection
  • full anonymizing for double-blind review
  • word/abstract caps verification
  • APSA-or-Chicago formatting check
  • 25-page Supporting Information limit check
  • human-subjects/IRB documentation verification

When not to use

  • drafting content
