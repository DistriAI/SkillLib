Skill page

Conflict

Both copies describe the same four-level Opportunity Solution Tree, but they are not interchangeable. The phuryn copy is a concise, self-contained procedure that adds the Opportunity Score formula (Importance × (1 − Satisfaction)) and specific experiment design fields (hypothesis, method, metric, success threshold). The deanpeters copy is an interactive facilitation skill that adds a two-phase process (generate OST, then select a POC), explicit anti-patterns, when-to-use/when-not-to-use guidance, and a dependency on a separate workshop-facilitation protocol. Crowning one would hide the other's real alternative workflow and scoring/facilitation constraints.
