qoder-cli

separate

Delegate coding tasks to Qoder CLI using Print mode (non-interactive). Use when: (1) building/creating new features or apps, (2) code reviews, (3) refactoring, (4) iterative coding that needs file exploration. Supports subagents, worktrees, MCP servers, quest mode, and hooks. Works in all session types (direct chat, group chat, Discord, etc.). NOT for: simple one-liner fixes (just edit), reading code (use read tool). Requires qodercli installed.

When to use

  • building/creating new features or apps
  • code reviews
  • refactoring
  • iterative coding that needs file exploration
  • spec-driven development
  • using subagents
  • using worktrees
  • using MCP servers

When not to use

  • simple one-liner fixes
  • reading code
