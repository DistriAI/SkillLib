sur-pub

separate

Create and trade tokens on SURGE via API (DEV). Full lifecycle — wallet setup, one-time free funding, token launch, and trading (pre-DEX + post-DEX). Base URL: back.surgedevs.xyz.

When to use

  • Create tokens on EVM (Base) or Solana
  • Buy and sell tokens pre-DEX and post-DEX
  • Server-managed wallet setup
  • One-time free wallet funding
  • Token launch on SURGE launchpad
  • Trading via bonding curve, Aerodrome, or Raydium CPMM

When not to use

  • Production environment usage
  • Managing private keys
