jleo-rebuttal

separate

Use when a Journal of Law, Economics, and Organization (JLEO) decision letter has arrived and you need a response-letter strategy — triaging an institutional-economist referee's report into a credible revision and point-by-point reply. Plans the rebuttal; it does not redo the analysis (route back to the relevant jleo-* skill).

When to use

  • Planning response-letter strategy
  • Triaging institutional-economist referee reports
  • Reconciling conflicting referees
  • Identifying deal-breakers
  • Drafting point-by-point responses
  • Summarizing major changes for editor

When not to use

  • Redoing the analysis
  • Running new identification work
  • Validating institutional measures
  • Running robustness checks
