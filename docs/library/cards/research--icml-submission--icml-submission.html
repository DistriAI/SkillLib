icml-submission

separate

Use when auditing an ICML main-track submission for OpenReview, LaTeX formatting, 8-page body, anonymity, supplementary material, impact statement, dual submission, concurrent ICML submissions, reciprocal reviewing, and LLM/prompt-injection policy compliance.

When to use

  • ICML main-track submission audit
  • OpenReview account readiness
  • LaTeX style verification
  • 8-page body limit check
  • Double-blind compliance
  • Impact statement inclusion
  • Dual submission check
  • Concurrent ICML submission handling

When not to use

  • Position paper submission
  • Workshop submission
  • Tutorial submission
  • Expo submission
  • Journal-to-Conference submission
