Conflict

The two skills share the same name and high-level intent (display a help/reference guide), but they are not reproductions of one another. The first is a thin wrapper that reads and outputs a GSD command reference from a plugin workflow file, with strict constraints against adding commentary. The second is a self-contained, versioned Diverga help guide that embeds a detailed, formatted reference for 24 research agents across 9 categories, commands, and usage examples. Neither copy contains the other's material steps or content, and they disagree on the reference content, versioning, and output format, so crowning one would hide a real alternative.
