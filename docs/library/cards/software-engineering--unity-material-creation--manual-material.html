manual-material

separate

Manually create and edit Materials and assign them to objects using Unity Editor UI. For one-off material tweaks that do not need REST automation.

When to use

  • Creating a new Material asset
  • Changing a material color or shader
  • Dragging a material onto a MeshRenderer or Mesh
  • One-off material tweaks

When not to use

  • Bulk material creation
  • Batch property edits
  • Shader keyword toggles across many materials
  • Render-queue changes
  • REST automation
