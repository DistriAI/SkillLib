usenixsec-related-work

separate

Use when positioning a USENIX Security Symposium paper against prior work — covering the Big-Four security venues plus specialty conferences, handling concurrent submissions across the multi-cycle calendar, citing your own work double-blind, and using USENIX's open-access proceedings for verification.

When to use

  • positioning a USENIX Security paper against prior work
  • covering Big-Four security venues
  • covering specialty security conferences
  • handling concurrent submissions
  • citing own work double-blind
  • using USENIX open-access proceedings for verification
  • drafting mechanism-level deltas
  • checking self-citation anonymity

When not to use

  • topic selection
  • writing the introduction
  • designing experiments
  • formatting the entire paper
