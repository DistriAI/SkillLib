developing-ios-apps

separate

Builds and ships iOS/macOS apps with XcodeGen, SwiftUI and SPM: Xcode build fixes, device deployment, Apple Developer signing/notarization, CI/CD pipelines. Use for XcodeGen project.yml setup, "Library not loaded @rpath" crashes, code-signing errors (Error -25294, adhoc fallback), or Electron notarization failures. Not for TCC permission dialogs (use macos-permissions) or disk cleanup (use macos-cleaner).

When to use

  • XcodeGen project.yml setup
  • Xcode build fixes
  • device deployment
  • Apple Developer signing/notarization
  • CI/CD pipelines
  • Library not loaded @rpath crashes
  • code-signing errors
  • Electron notarization failures

When not to use

  • TCC permission dialogs
  • disk cleanup
