crim-literature-positioning

separate

Use when positioning a Criminology (ASC / Wiley) manuscript against the literature so it reads as a contribution to the field's live debates, not a citation pile. Criminology readers expect engagement with the relevant theoretical tradition and the closest prior empirical work across the field's many disciplines. Stakes the contribution; it does not write the lit review.

When to use

  • Drafting or revising the introduction and contribution paragraph
  • Addressing reviewer feedback about missing key work or theory
  • Connecting solid empirics to a criminological debate
  • Distinguishing contribution from closest prior papers
  • Building a three-column map of incumbent conversation, tension, and delta
  • Returning a ledger of claim, evidence, risk, and location
  • Comparing against sibling venues like Justice Quarterly or JQC

When not to use

  • Writing the full literature review
  • Providing submission-ready advice before checking official source maps
  • Polishing format if a sibling venue owns the contribution
