fast-topic-selection

separate

Use when deciding whether a storage project belongs at USENIX FAST or should be routed to OSDI, ATC, NSDI, EuroSys, HotStorage, MSST, SYSTOR, or a storage journal (ACM TOS), and when distinguishing FAST from general-systems siblings by storage-contribution shape, real-device evidence, and the two-deadline calendar.

When to use

  • deciding if a project belongs at USENIX FAST
  • routing storage projects to OSDI, ATC, NSDI, EuroSys, HotStorage, MSST, SYSTOR, or ACM TOS
  • distinguishing FAST from general-systems siblings
  • evaluating storage-contribution shape
  • checking real-device evidence requirements
  • assessing the two-deadline calendar
  • applying storage-lesson and re-label tests
  • performing cheap reconnaissance before committing

When not to use

  • drafting the paper
  • writing code
  • conducting experiments
  • general systems work where storage is incidental
