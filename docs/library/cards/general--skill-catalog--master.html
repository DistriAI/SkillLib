master

separate

Secure key management for AI agents. Use when handling private keys, API secrets, wallet credentials, or when building systems that need agent-controlled funds. Covers secure storage, session keys, leak prevention, and prompt injection defense.

When to use

  • handling private keys
  • managing API secrets
  • managing wallet credentials
  • building systems with agent-controlled funds
  • secure storage of secrets
  • session key management
  • leak prevention
  • prompt injection defense

When not to use

  • storing raw private keys in config
  • storing raw private keys in env vars
  • storing raw private keys in memory files
  • logging or printing keys
  • trusting unvalidated input near key operations
