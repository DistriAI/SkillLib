ui-uitk

separate

Understands, edits, and generates Unity UI Toolkit UXML and USS with flex layouts. Use for requests involving UI Toolkit, UIElements, UIDocument, PanelSettings, custom elements, or UI runtime binding.

When to use

  • Understand existing Unity UI Toolkit code
  • Make targeted edits to UXML and USS
  • Generate new UXML and USS files
  • Create Manipulators
  • Handle UI runtime binding
  • Create custom UI elements
  • Generate SVG icons
  • Use Painter2D API for custom visuals

When not to use

  • Validate UXML or USS from outside the Editor
