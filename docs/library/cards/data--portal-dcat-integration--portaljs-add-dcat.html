portaljs-add-dcat

separate

Make a PortalJS portal harvestable by national/EU/US open-data portals — emit standards-compliant DCAT catalog feeds (DCAT 2/3, DCAT-AP, DCAT-US, national profiles) in JSON-LD, Turtle, and RDF/XML at build, with autodiscovery and per-profile conformance checking. Use when a portal needs to be harvested by data.europa.eu, data.gov, or a national open-data catalog.

When to use

  • Emitting DCAT 2/3, DCAT-AP, DCAT-US, and national profile feeds
  • Generating JSON-LD, Turtle, and RDF/XML serialization
  • Adding feed autodiscovery to pages/_document.tsx
  • Running per-profile conformance checking
  • Wiring generate:dcat script to predev/prebuild
  • Mapping dataset metadata to DCAT application profiles

When not to use

  • Scaffolding new PortalJS portals
  • Defining dataset schemas
  • Deploying portals
  • Runtime harvesting
