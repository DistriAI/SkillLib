brutalism

combined

Raw, anti-design aesthetic inspired by concrete architecture with unadorned elements, jarring layouts, and functional minimalism. Web and App implementation guide for Brutalism. Trigger when user wants a raw appearance, intentionally unfinished look, and rejection of standard design conventions.

When to use

  • Use this sub-style when the user's request matches the aesthetic described above. This is a child reference of the `design-it` skill and is not meant to be triggered directly.

When not to use

  • This is a styling reference and does not replace environment-specific validation, accessibility testing, or expert review.
  • Ensure appropriate contrast ratios and responsive behaviors are verified separately.

Skill page

Conflict

The two copies describe the same aesthetic but serve different purposes and contain non-overlapping, sometimes conflicting, implementation guidance. The bergside copy is a design-system authoring workflow (tokens, accessibility, QA checklist, output structure) with a specific palette (Darker Grotesque, #DD614C, #DAA144) and spacing scale. The sickn33 copy is a direct implementation guide for Web, SwiftUI, Flutter, and React Native, prescribing system fonts (Courier New, Times New Roman, Comic Sans), raw browser defaults, and a clashing palette (#0000FF, #FF0000, #C0C0C0). Crowning one would hide the other's concrete code patterns or the other's governance workflow.
