sred-project-organizer

authentic

Take a list of projects and their related documentation, and organize them into the SRED format for submission.

When to use

  • Organizing projects into SRED format
  • Classifying projects as SREDable
  • Creating SRED Project Summary documents
  • Identifying technical uncertainties
  • Documenting experiments and results

When not to use

  • Generating the initial Work Summary
  • Accessing or configuring MCP connections
