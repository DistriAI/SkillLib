The two copies are the same setup workflow but they disagree on the canonical domain-doc filenames and on how the triage section is gated. The mattpocock/skills copy uses GLOSSARY.md/GLOSSARY-MAP.md and skips Section B entirely when the triage skill is not installed, while the sickn33 copy uses CONTEXT.md/CONTEXT-MAP.md and always asks for triage label overrides. Crowning one would hide a real alternative, so the combined instruction preserves both variants and flags the conflicts.
