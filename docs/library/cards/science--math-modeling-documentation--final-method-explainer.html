final-method-explainer

authentic

Build the authoritative final method explanation for a submission-ready subquestion from the method card, human decision ledger, code plan, final results, and robustness evidence.

When to use

  • Explain the selected method completely without re-authoring why the human chose it.

When not to use

  • Re-authoring why the human chose the method
  • Inferring the chosen method from best metrics
  • Inventing the why-this-method narrative
  • Creating a new pending decision artifact
  • Restating a long iteration diary
  • Including unsupported numerical claims
