tableau-next-asset-create

separate

Build and edit Tableau Next semantic models (SDMs), vizzes, and dashboards via MCP. TRIGGER when: building a semantic model or dashboard from CSV/Excel files; ingesting a flat file/database into DLO/DMO; profiling a dataset (grain, measures, dimensions; large/wide files via `infer_object_schema`); adding a dimension, measure, AI-ready metric, join, or logical view; running a semantic query, interpreting a breakdown, analyzing account/customer engagement, or pulling counts/totals from existing Tableau Next data (even unnamed/read-only); creating/editing a viz (filter, forecast, sort, shelf, mark encoding, reference line), widget, or dashboard layout. Also: Data Cloud SQL transforms; show a dashboard; share/revoke access; reuse prod or promote Personal Org assets; provision users/licenses; data alerts ('alert me when'); list/classify verified questions or score agent SQL. DO NOT TRIGGER for: rewriting prose descriptions, layout-only dashboard review, debugging MCP, or writing app code.

When to use

  • building a semantic model or dashboard from CSV/Excel files
  • ingesting a flat file/database into DLO/DMO
  • profiling a dataset
  • adding a dimension, measure, AI-ready metric, join, or logical view
  • running a semantic query
  • creating/editing a viz, widget, or dashboard layout
  • Data Cloud SQL transforms
  • share/revoke access

When not to use

  • rewriting prose descriptions
  • layout-only dashboard review
  • debugging MCP
  • writing app code
