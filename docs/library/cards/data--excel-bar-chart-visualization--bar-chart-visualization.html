When to use

  • multi-sheet Excel file reading
  • merged cell handling
  • data cleaning
  • cross-grouped statistics
  • total row generation
  • bar chart visualization
  • Chinese and English font support

When not to use

  • Parquet optimization
  • reading/counting workflows
