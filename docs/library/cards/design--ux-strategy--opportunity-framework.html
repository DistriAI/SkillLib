opportunity-framework

separate

Identify, score, and prioritise design opportunities against impact and effort. Use when there are more ideas than capacity. For framing the one you choose, use `design-brief`.

When to use

  • Identify design opportunities
  • Score design opportunities
  • Prioritise design opportunities
  • Move from possible improvements to a prioritized roadmap
  • Use Impact-Effort Matrix
  • Use RICE Scoring
  • Use Kano Model
  • Use Value vs Complexity

When not to use

  • Framing the one you choose
