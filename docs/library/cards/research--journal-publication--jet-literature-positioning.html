jet-literature-positioning

separate

Use when staking a Journal of Economic Theory (JET) contribution against the theory frontier — show precisely which assumption is weakened, which result is generalized, or which new phenomenon is characterized relative to the closest existing theorems. Positions the result; it is not a standalone survey.

When to use

  • Writing related-work paragraphs for a JET theory paper
  • Defending originality at the desk screen
  • Positioning results theorem-relative to the nearest existing results
  • Building a theorem-delta table
  • Identifying deltas in assumptions, generality, objects, or constructiveness

When not to use

  • Standalone survey
  • Broad empirical literature review
  • Topic-relative positioning
