html-to-interaction-prompts

separate

Convert a supplied HTML page or generated HTML reference into a screenshot-backed article containing multiple reusable interaction prompts. Use when the user provides an HTML file, exported page, generated-page.html, or local/live reference and asks to extract animation/interactions, create prompts, capture screenshots for each prompt, add them to an article, or commit the resulting article/assets.

When to use

  • extract animation/interactions
  • create prompts
  • capture screenshots for each prompt
  • add them to an article
  • commit the resulting article/assets
  • daily UI inspiration workflow
  • inspect HTML, CSS, and scripts
  • write reusable prompts

When not to use

  • infer exact effects from a screenshot alone when the HTML is available
  • ship a screenshot gallery
  • append 20 shallow prompts
  • use marketplace cover image as live-video evidence
  • use thumbnail as live-video evidence
  • use screenshot pan as live-video evidence
  • use static asset slideshow as live-video evidence
  • use arbitrary viewport screenshots as section substitutes
