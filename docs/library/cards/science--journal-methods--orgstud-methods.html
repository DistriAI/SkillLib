orgstud-methods

separate

Use when choosing and justifying the research design for an Organization Studies (OS) manuscript — qualitative/ethnographic, process, historical, or quantitative — and setting the rigor bar OS reviewers expect. Designs the study; it does not run the analysis (see orgstud-data-analysis).

When to use

  • Choosing between qualitative/process and quantitative designs
  • Justifying rigor and transparency for OS reviewers
  • Designing qualitative studies with sampling logic and immersion
  • Designing quantitative studies with identification in service of theory
  • Setting trustworthiness safeguards for qualitative work
  • Specifying temporal leverage for process models

When not to use

  • Running the analysis
  • Data analysis tasks (see orgstud-data-analysis)
