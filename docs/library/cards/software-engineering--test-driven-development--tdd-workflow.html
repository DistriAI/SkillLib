Skill page

Conflict

The two skills cover the same high-level concept (TDD) but diverge significantly in scope and implementation. The first skill (sickn33) is a language-agnostic, conceptual guide to the RED-GREEN-REFACTOR cycle, focusing on principles, anti-patterns, and AI-agent roles. The second skill (brycewang-stanford) is a specific, technical implementation guide for R using the `testthat` package, including code examples, coverage requirements (80%+), and specific API usage (Edition 3). Neither is a reproduction of the other; the first lacks the R-specific tooling, and the second lacks the general conceptual framework and AI-agent patterns. Combining them provides a complete workflow: the conceptual foundation from the first and the concrete R implementation from the second.
