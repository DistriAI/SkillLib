fbt-flight

separate

分贝通机票助手 - 实现国内航班搜索、舱位查询、预订下单、机票改期、机票退票。适用于用户询问航班、查询机票价格、提交机票订单、改期航班、退票时使用。

When to use

  • 国内航班搜索
  • 舱位查询
  • 预订下单
  • 机票改期
  • 机票退票
  • 查询已创建订单的详细信息
  • 退改规则和行李额查询
  • 取消待支付状态的订单

When not to use

  • 国际航班
  • 已支付或已出票订单的取消
