nejm-writing

separate

Use to structure and tighten an NEJM Original Article into terse IMRAD — short main text (~2700 words), limited references, claim-first results, and a sober discussion with explicit limitations and calibrated clinical implications. Enforces NEJM's plain, concise house style.

When to use

  • Structuring NEJM Original Articles
  • Tightening main text to ~2700 words
  • Formatting IMRAD sections
  • Calibrating discussion implications
  • Enforcing NEJM house style
  • Checking reference limits

When not to use

  • Writing Reviews
  • Writing Brief Reports
  • Statistical analysis
  • Protocol writing
  • Supplementary appendix writing
