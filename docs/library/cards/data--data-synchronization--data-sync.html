data-sync

separate

重要数据同步工具。通过云服务器中转站在多台电脑间同步 Claude Code 关键配置（skills、hooks、记忆库、skill-factory），GitHub 作为大版本归档。支持 init/pull/push/backup/status 五个子命令。

When to use

  • Syncing Claude Code skills
  • Syncing hooks and memory libraries
  • Initializing new computer configuration
  • Pulling latest data from server
  • Pushing local changes to server
  • Backing up major versions to GitHub
  • Checking synchronization status

When not to use

  • Direct communication between two computers
  • Daily synchronization via GitHub
  • Destructive git operations
