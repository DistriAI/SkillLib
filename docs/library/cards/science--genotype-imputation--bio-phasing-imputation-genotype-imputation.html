Impute missing genotypes using reference panels with Beagle, Minimac4, or IMPUTE5. Use when increasing variant density for GWAS, harmonizing data across genotyping platforms, or inferring variants not directly typed in array data.

When to use

  • Increasing variant density for GWAS
  • Harmonizing data across genotyping platforms
  • Inferring variants not directly typed in array data

  • Minimac4 imputation
  • IMPUTE5 imputation
  • Extract imputation quality
