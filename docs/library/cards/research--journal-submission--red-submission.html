red-submission

separate

Use when running the final pre-submission preflight for the Review of Economic Dynamics (RED) — the current Elsevier Guide's USD 195 fee (USD 100 all-student; waived on second-and-later resubmissions) that gates review, submission via ScienceDirect/Editorial Manager, the ≤250-word abstract, 1-6 keywords, author-year references, single-anonymized format, AI declaration, Option C data statement, and optional SSRN preprint. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • confirming submission fee
  • verifying submission route
  • checking required front matter
  • verifying anonymization status
  • preparing AI declaration
  • staging replication archive
  • deciding SSRN preprint opt-in

When not to use

  • drafting content
