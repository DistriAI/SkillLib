factory-collect

separate

Experimental workflow for collecting and triaging product feedback, product telemetry, runtime errors, and issue reports. Use when scanning configured signal sources and applying separate fix, reply, or close rules.

When to use

  • collecting product feedback
  • triaging product telemetry
  • processing runtime errors
  • handling issue reports
  • scanning configured signal sources
  • applying fix rules
  • applying reply rules
  • applying close rules

When not to use

  • publishing changes
  • approving changes
  • merging changes
  • deploying changes
