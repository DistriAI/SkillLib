bio-restriction-fragment-analysis

separate

Analyze restriction digest fragments using Biopython Bio.Restriction to predict fragment sizes, get sequences, simulate gel patterns, and perform double digests.

When to use

  • predict fragment sizes
  • get fragment sequences
  • simulate gel electrophoresis patterns
  • perform double digests
  • linear vs circular digestion
  • calculate fragment sizes from positions
  • detailed fragment report
  • compare expected vs observed fragments
