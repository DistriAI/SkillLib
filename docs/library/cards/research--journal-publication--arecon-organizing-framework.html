arecon-organizing-framework

separate

Use when imposing an analytical structure or taxonomy on a literature for an Annual Review of Economics (ARE) review — the "spine" that turns a reading list into an argument about the field. Designs the framework; it does not gather the literature (arecon-literature-synthesis) or appraise evidence and balance (arecon-evidence-standards).

When to use

  • imposing an analytical structure on a literature
  • designing a taxonomy for an ARE review
  • creating a unifying model for scattered work
  • structuring a question sequence for a review
  • organizing a chronological or paradigm framework
  • defining a methods spectrum for appraising designs
  • turning a reading list into an argument about the field

When not to use

  • gathering the literature
  • appraising evidence and balance
  • arecon-literature-synthesis
  • arecon-evidence-standards
