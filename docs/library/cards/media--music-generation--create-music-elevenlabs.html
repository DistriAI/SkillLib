create-music-elevenlabs

separate

Generate an instrumental music bed via ElevenLabs Music, routed through the GooseWorks proxy, so the call is charged to your GooseWorks credits. Trims any sparse intro, loudnorm, fades the tail. Prompt + length from the template recipe. Use for the music layer of any video-ad format.

When to use

  • Generate instrumental music bed
  • Route calls through GooseWorks proxy
  • Trim sparse intro
  • Loudnorm audio
  • Fade tail
  • Music layer for video-ad format

When not to use

  • Skills outside the kit until they move
