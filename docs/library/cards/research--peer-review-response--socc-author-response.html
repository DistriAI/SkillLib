socc-author-response

separate

Use when drafting an ACM SoCC author response (rebuttal) during a round's response window, covering the single written turn, answering both the systems and the data/measurement reviewer, supplying the tail-latency and cost numbers reviewers ask for, staying within dual anonymity, and the fact that SoCC has no Major-Revision round to fall back on.

When to use

  • drafting an ACM SoCC author response
  • answering systems and data/measurement reviewers
  • supplying tail-latency and cost numbers
  • staying within dual anonymity
  • triaging decision-critical concerns
  • structuring the single written turn
  • addressing reviewer pushback patterns
  • performing anonymity checks

When not to use

  • journal-style revise-and-resubmit
  • Major Revision rounds
  • presenting major new experiments as if already done
  • revealing identity to make a point
  • arguing taste
  • over-promising a revision
