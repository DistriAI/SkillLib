Conflict

The two copies cover the same OpenSea surface but with materially different structure and content. The BankrBot copy is a router that delegates to five sub-skills (opensea-api, opensea-marketplace, opensea-swaps, opensea-wallet, opensea-tool-sdk) and explicitly requires reading a sub-skill before executing; it also documents wallet signing providers (Bankr, Privy, Turnkey, Fireblocks, local PRIVATE_KEY) and ERC-8257 tool building. The LeoYeAI copy is a self-contained operational guide that recommends the @opensea/cli as the primary tool, provides concrete CLI commands for collections, NFTs, listings, offers, swaps, search, and events, and lists shell-script and MCP alternatives. Neither copy is a reproduction of the other: the router lacks the CLI command tables and the self-contained copy lacks the sub-skill routing, wallet provider configuration, and tool SDK steps. Crowning one would hide a real alternative workflow.
