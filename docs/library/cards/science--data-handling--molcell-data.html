molcell-data

separate

Use to build Molecular Cell's data and code deposition plan and the Data and Code Availability statement inside STAR Methods Resource Availability — approved repositories (GEO, PDB/EMDB, PRIDE), accessions/DOIs at submission, and Cell Press's standardized availability format with Mendeley Data as Elsevier's default.

When to use

  • Drafting Data and Code Availability statement
  • Planning data deposition in approved repositories
  • Verifying accessions and DOIs for submission
  • Formatting Cell Press standardized availability statement
  • Checking structure-specific deposition requirements
  • Ensuring code is public and archived with DOI

When not to use

  • Writing Materials Availability statements
  • Handling ethics approvals and IRB/IACUC details
  • Identifying key reagents with RRIDs
  • General STAR Methods section writing
