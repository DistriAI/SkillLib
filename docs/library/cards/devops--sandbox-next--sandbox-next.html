sandbox-next

separate

Build or maintain Cloudflare Sandbox apps on @cloudflare/sandbox@next (SDK 1.0 preview). Use sandbox-migrate-to-next when porting a stable app.

When to use

  • Building new Cloudflare Sandbox apps on @next
  • Maintaining apps using @cloudflare/sandbox@next
  • Implementing process execution with exec and handles
  • Configuring environment variables and cwd
  • Using interactive terminals and PTY
  • Managing sandbox lifecycle and durability

When not to use

  • Porting stable apps to @next
  • Using default @cloudflare/sandbox without @next
  • Self-deployed bridge configurations
  • Mixing @next Worker packages with stable container images
