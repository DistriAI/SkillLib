A friendly, hand-drawn sketch interface inspired by pencil illustrations on warm cream paper. Soft teal brand accents, hand-written display headings, rounded pill controls. Sketch UI/design ideas with throwaway HTML mockups, or propose what to sketch next (frontier mode)

When to use

  • hand-drawn sketch interface design
  • pencil illustration style UI
  • warm cream paper aesthetic
  • soft teal brand accents
  • hand-written display headings
  • rounded pill controls
  • throwaway HTML mockups
  • design direction exploration

When not to use

  • low contrast text
  • inconsistent spacing rhythm
  • ambiguous labels
  • final production implementation
