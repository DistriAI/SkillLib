rn-motion-replica

separate

Analyze a public or local reference video, isolate a time range, deconstruct its layout, motion, timing, and transitions, then build an original verified motion replica with reusable templates and final MP4 QC. Use when the user says 复刻这个视频效果, 参考这个视频做同款动效, 拆解前 N 秒, 还原方框/连线/卡片动画, or provides a video or URL as a motion reference rather than asking to copy its footage or script.

When to use

  • 复刻这个视频效果
  • 参考这个视频做同款动效
  • 拆解前 N 秒
  • 还原方框/连线/卡片动画
  • build an original verified motion replica
  • deconstruct layout, motion, timing, and transitions
  • create reusable templates
  • final MP4 QC

When not to use

  • copy its footage or script
  • pixel-exact, render-frame-exact, or encoded-frame-aligned claim
  • bypass private-account controls, DRM, paywalls, or deleted media
  • ship the source media inside the finished project
  • copy the source's presenter, subtitles, script, thumbnail, or unique branded assets
