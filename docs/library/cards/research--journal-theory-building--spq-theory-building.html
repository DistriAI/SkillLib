spq-theory-building

separate

Use when building the theoretical argument of a Social Psychology Quarterly (SPQ) manuscript into a contribution to sociological social psychology — whether the work is in the symbolic-interaction, social-structure-and-personality, group-processes, identity, or affect tradition. SPQ rewards an explicit social-psychological mechanism linking structure to the individual, not a bare finding. Structures the argument; it does not run analyses.

When to use

  • Building theoretical arguments for SPQ manuscripts
  • Structuring arguments in symbolic-interaction tradition
  • Structuring arguments in social-structure-and-personality tradition
  • Structuring arguments in group-processes tradition
  • Structuring arguments in identity tradition
  • Structuring arguments in affect tradition
  • Formalizing within expectation states, affect control, or identity verification programs
  • Defining observable implications and scope conditions

When not to use

  • Running analyses
  • Tasks where the argument only explains individual processes with no social anchor
  • Tasks where the argument only explains macro patterns with no individual mechanism
