apsr-tables-figures

separate

Use when building tables and figures for an American Political Science Review (APSR) manuscript so exhibits are self-contained, accessible, and count toward the word budget correctly. APSR word counts include tables, figures, and printed footnotes, so exhibits must earn their space. Designs exhibits; it does not run the analysis.

When to use

  • Designing the main results table/figure
  • Designing a key descriptive exhibit
  • Deciding what belongs in the article vs. the online appendix
  • Fixing an exhibit that is unclear, mislabeled, or non-self-contained
  • Trimming to the word cap by moving exhibits to the appendix
  • Creating maps for geographic/spatial variation
  • Creating network diagrams
  • Creating conjoint AMCE plots

When not to use

  • Running the analysis
