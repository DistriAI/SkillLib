run-organic-social-platform-research

separate

Researches how one social platform works right now from dated sources (what gets reach, formats rising and fading, how small accounts get seen, recent changes) and finds what is getting watched in a given niche there, with linked examples and engagement read against each author's baseline. Use alone when you already have the platform and niche; otherwise run run-organic-social.

When to use

  • Researching current platform algorithms and ranking signals
  • Identifying rising and fading content formats
  • Analyzing how small or new accounts gain visibility
  • Finding niche-specific accounts and posts with engagement data
  • Documenting recent platform changes with dates and links
  • Researching paid verification effects on reach and replies

When not to use

  • Planning or writing content without prior research
  • Using memory instead of dated sources for platform mechanics
  • Relying solely on tool vendor algorithm pages
  • Treating published ranking code as confirmed current behavior
