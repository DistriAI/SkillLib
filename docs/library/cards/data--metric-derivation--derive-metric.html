derive-metric

separate

Use when a requested measure is missing, a saved custom metric needs reuse, or an ephemeral formula or derived scalar is needed.

When to use

  • resolving missing measures
  • reusing saved custom metrics
  • creating ephemeral formulas
  • deriving scalars
  • validating custom metric formulas

When not to use

  • saving metric definitions
  • creating new metrics
  • inferring formula grammar from names
  • averaging averages
  • using overlapping groups as population totals
