education-data-context

separate

Interpretation guidance for Urban Institute Portal datasets. Coded values (-1/-2/-3), year definitions, grade encoding, suppression, licensing, cross-source joins. Use when interpreting Portal data before analysis. Routes to source-specific skills.

When to use

  • Interpreting Portal coded values (-1/-2/-3)
  • Understanding year definitions (fall vs. academic year)
  • Applying correct grade encoding
  • Assessing suppression rates
  • Citing data under ODC-By license
  • Reviewing Portal data before analysis
  • Joining identifiers across CCD, IPEDS, CRDC, and other sources
  • Routing to source-specific skills
