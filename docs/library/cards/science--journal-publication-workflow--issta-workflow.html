issta-workflow

separate

Use when planning an ISSTA project timeline from venue fit through the January research-paper deadline, the March author response, the April first decision, the May Major-Revision sprint, the June final decision, artifact evaluation, and the October symposium, with backward-planning offsets for a testing/analysis tool paper and its artifact.

When to use

  • planning an ISSTA project timeline
  • backward-planning offsets for a testing/analysis tool paper
  • managing ISSTA submission milestones
  • coordinating artifact evaluation and Zenodo deposit
  • managing author response and major revision

When not to use

  • planning for a journal submission
  • planning for a conference that is not ISSTA
