generate-design

separate

Generate new screens from text prompts or images, edit existing screens with prompts and design system tokens, and generate design variants using Stitch MCP. Includes prompt enhancement pipeline, design mappings, professional UI/UX terminology, design tokens and theme system capabilities.

When to use

  • Generate new screens from text prompts
  • Generate new screens from images
  • Edit existing screens with prompts
  • Edit existing screens with design system tokens
  • Generate design variants
  • Prompt enhancement pipeline
  • Design mappings
  • Professional UI/UX terminology

When not to use

  • Include color, font, or theme instructions in generation prompts
  • Include hex codes, font names, color palettes, roundness values, or design system tokens in generation prompts
