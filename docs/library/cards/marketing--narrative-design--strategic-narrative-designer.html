strategic-narrative-designer

separate

Use when the user asks to "design our change narrative", "build the old-world-to-new-game story arc", or "frame the shift our category is undergoing"; produces a Raskin-style strategic narrative arc — old world → the undeniable shift → winners vs losers under the new rules → the promised land → proof the promised land is real — derived from the positioning truth set and the belief/objection map, feeding the TALE Architecture arc sub-item. Every proof beat is labeled Measured / User-provided / [needs source] and this skill never adjudicates a claim. Not for the message house hierarchy — use message-system-architect; not for the pitch deck narrative — use pitch-narrative-builder; not for claim substantiation — use offer-claims-registry. 变革叙事弧/旧世界/应许之地/战略叙事结构

When to use

  • design change narrative
  • build old-world-to-new-game story arc
  • frame category shift
  • stress-test story arc proof
  • name old world assumptions
  • identify undeniable shift
  • define winners and losers
  • describe promised land

When not to use

  • message house hierarchy
  • pitch deck narrative
  • claim substantiation
  • author durable message house
  • build sales/fundraising pitch deck
  • reconcile positioning against shippable reality
  • adjudicate product or comparative claim
  • compute TALE profile result
