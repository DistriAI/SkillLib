worlddev-topic-selection

separate

Use when deciding whether a development question fits World Development (WD) and which sibling journal it really belongs to. Tests scope, relevance, and outlet fit; it does not invent evidence or citations.

When to use

  • deciding if a paper fits World Development
  • distinguishing WD from JDE, WBER, JDS, EDCC
  • assessing real-world development stakes
  • evaluating multidisciplinary relevance
  • screening single-country studies for travel
  • checking if contribution is method-first or development-first

When not to use

  • inventing evidence or citations
  • providing prose edits
  • inventing editor names or fees
