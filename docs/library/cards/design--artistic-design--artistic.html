artistic

separate

High-contrast, expressive style with creative typography and bold color choices for visually striking interfaces.

When to use

  • high-contrast, expressive style
  • creative typography
  • bold color choices
  • visually striking interfaces
  • design-system guideline authoring
  • implementation-ready guidance

When not to use

  • low contrast text
  • inconsistent spacing rhythm
  • decorative motion without purpose
  • ambiguous labels
  • mixing multiple visual metaphors
  • inaccessible hit areas
