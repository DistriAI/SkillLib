soda-experiments

separate

Use when deciding whether and how experiments belong in a SODA (ACM-SIAM Symposium on Discrete Algorithms) paper — SODA's scope includes experimental validation but theorems carry the decision, so this skill designs supporting numerics honestly and routes implementation-led work to co-located ALENEX or to SEA.

When to use

  • Deciding experiment inclusion for SODA papers
  • Routing work to ALENEX or SEA
  • Designing supporting numerics for theory papers
  • Labeling claim classes for figures
  • Checking instance-generation discipline
  • Assessing experimental proportion in submissions

When not to use

  • Writing pure theory proofs
  • Creating standalone experimental papers for ALENEX
  • General algorithm implementation
