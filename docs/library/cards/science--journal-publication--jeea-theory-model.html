jeea-theory-model

separate

Use when a Journal of the European Economic Association (JEEA) manuscript contains a theoretical or structural model whose assumptions, generality, or results need sharpening to the journal's general-interest bar. Disciplines the model and makes its results legible; it does not run empirics or polish prose.

When to use

  • sharpening theoretical or structural model assumptions
  • improving model generality
  • making model results legible
  • disciplining structural model mapping to data
  • stating economic intuition in words
  • organizing proofs for headline results

When not to use

  • running empirics
  • polishing prose
