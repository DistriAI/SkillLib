Create and curate LP vaults on Uniswap or Sushi, and manage eligible Aerodrome vaults, powered by Steer.

When to use

  • Create LP vaults
  • Curate LP vaults
  • Deposit into vaults
  • Manage Aerodrome vaults
  • Prepare simulation-backed transactions
  • Inspect pool identity and price direction
  • Execute automated curated tend

When not to use

  • Install or upgrade the Steer CLI
  • Construct or alter prepared calldata
  • Use unlimited approvals
  • Set deposit minimums to zero
  • Use --skip-swap to bypass quote failure
  • Manage Steer-managed orchestrators
  • Substitute --web for Bankr execution path
