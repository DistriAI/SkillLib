add-datasource

authentic

Adds a data source or connector to a Power Apps code app. Asks what the user wants to accomplish and routes to the appropriate specialized skill.

When to use

  • Add data source to Power Apps code app
  • Route to Dataverse for structured business data
  • Route to Azure DevOps for work items
  • Route to Teams for messages
  • Route to Excel Online for spreadsheet data
  • Route to OneDrive for Business for files
  • Route to SharePoint Online for lists
  • Route to Office 365 Outlook for email and calendar

When not to use

  • Tasks not related to adding data sources or connectors
