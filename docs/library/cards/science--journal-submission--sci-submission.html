sci-submission

separate

Use as the final preflight before submitting to Science (AAAS) — a complete checklist across significance, format, figures, statistics, data availability, references, and required submission files, so nothing that triggers an editorial bounce is left unresolved. Bundles ready-to-fill templates.

When to use

  • final preflight before submitting to Science
  • confirming sci-* skill outputs landed
  • checking revision regressions
  • verifying article type and file package
  • checking length and display limits
  • verifying reporting statements and data/code
  • checking ethics and competing interests
  • comparing against Nature, PNAS, or specialist journals

When not to use

  • uploading before accession numbers/DOIs exist
  • skipping the integrity sweep
  • relying on memory instead of running the checklist
