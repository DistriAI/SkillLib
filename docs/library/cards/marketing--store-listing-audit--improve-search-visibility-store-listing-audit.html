improve-search-visibility-store-listing-audit

separate

Audits an app's App Store and Google Play listing against three competitors (title, subtitle, description opening, first screenshots and captions, rating, review themes) and writes a field-by-field rewrite with character counts, or a launch-day listing before release. Use alone when you already have the app's store links and signed-off product facts; otherwise run improve-search-visibility.

When to use

  • App Store listing audit
  • Google Play listing audit
  • Competitor comparison
  • Field-by-field rewrite
  • Launch-day listing creation

When not to use

  • Using rival trademarks
  • Claiming a keyword rank it cannot see
