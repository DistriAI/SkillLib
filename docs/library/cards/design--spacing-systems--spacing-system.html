spacing-system

separate

Create a spacing scale from a base unit with rules for when each step applies. Use when standardising padding and margins. For page-level columns and gutters, use `layout-grid`.

When to use

  • standardising padding and margins
  • creating spacing systems
  • defining spacing scale
  • applying spacing rules
  • managing density modes

When not to use

  • page-level columns and gutters
