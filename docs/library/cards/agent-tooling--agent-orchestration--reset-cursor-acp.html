reset-cursor-acp

separate

Reset a stuck Cursor ACP thread in your chat app and reload its configuration. Use only when the user explicitly invokes /reset-cursor-acp.

When to use

  • Reset a stuck Cursor ACP thread
  • Reload Cursor ACP configuration
  • Orphan cleanup and health check
  • Stop selected thread and remove orphaned processes

When not to use

  • Use when user does not explicitly invoke /reset-cursor-acp
  • Create or keep alive a global Cursor ACP server
  • Blindly run pkill -f cursor-agent
  • Restart the app for one stuck thread
  • Use the app's thread-compaction feature
