separate

Use when targeting 《南方经济》(South China Journal of Economics — 广东省社会科学院/广东经济学会主办的经济学月刊, 匿名审稿、不收版面费) or deciding whether a Chinese econ manuscript fits this venue. Encodes the journal's fit, framing, anonymous-review/fee-free policy, abstract/keyword house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting 《南方经济》
  • deciding if a Chinese econ manuscript fits this venue
  • rewriting a generic Chinese econ manuscript for this journal
  • listing high-frequency rejection risks
  • checking anonymous-review and fee-free policies
  • verifying abstract and keyword house style
  • official-submission re-check
  • desk-reject heuristics

When not to use

  • replacing the latest official submission guidelines
  • using second-hand submission website formats
  • forcing submission based on name, region, or variable similarity when other journals are a better fit
