orgstud-contribution-framing

separate

Use when sharpening the one-sentence theoretical contribution of an Organization Studies (OS) manuscript and the intro/discussion claims that carry it. Frames the contribution; it does not build the theory (see orgstud-theory-development) or run analysis.

When to use

  • sharpening the one-sentence theoretical contribution
  • framing intro and discussion claims
  • calibrating the size of the claim
  • ensuring consistency across abstract, intro, and discussion
  • mapping referee pushback to framing fixes

When not to use

  • building the theory
  • running analysis
