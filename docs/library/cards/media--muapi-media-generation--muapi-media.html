Discover current MuAPI image models and run one explicitly confirmed asynchronous image generation request with bounded polling. Conflict

The two skills cover the same MuAPI media generation workflow but differ significantly in scope and implementation. The first skill (davepoon) is strictly limited to image generation and relies on a bundled Python CLI script (`scripts/muapi_media.py`) that abstracts away the HTTP details. The second skill (sickn33) covers both image and video generation, uses raw `curl` and `jq` commands, and provides explicit API contract details (endpoints, headers) that the first skill hides behind the CLI. Because the first skill excludes video and the second includes it, and because the second provides the underlying API mechanics while the first provides a safer, higher-level wrapper, crowning one would hide a valid alternative approach (CLI vs. raw API) and a valid scope difference (image-only vs. image+video).
