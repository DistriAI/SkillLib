make-static-ads-ad-copy

separate

Step of make-static-ads: writes the text for each slot the ad's template sets, then the primary texts, headline, description and CTA around the image, from usable facts and customer words. Run make-static-ads instead; not for direct use.

When to use

  • writing on-image copy for ad templates
  • writing primary text A and B
  • writing link headline, description, and CTA
  • formatting copy to match brand voice and rules

When not to use

  • direct use
  • inventing headlines for textless ads
  • using generated persons as customers or endorsers
