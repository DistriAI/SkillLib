plow-ahead

separate

Use when the user explicitly wants autonomous progress without routine clarification stops: "plow ahead", "do not stop", "use your best judgment", "keep going until done", "finish while I am away", "do not ask questions unless truly blocked", or similar. Convert ordinary ambiguity into stated assumptions, proceed through implementation and validation, stop only for true blockers, and end with a clear recap of decisions, changes, verification, and residual risk.

When to use

  • autonomous progress without routine clarification stops
  • converting ordinary ambiguity into stated assumptions
  • proceeding through implementation and validation
  • stopping only for true blockers
  • ending with a clear recap of decisions, changes, verification, and residual risk

When not to use

  • tasks requiring explicit branch operations, history rewrites, force pushes, or deletions not directly requested
  • destructive, irreversible, or production-mutating steps
  • situations with high legal, safety, privacy, or security risk that cannot be reduced by conservative local choices
  • decisions explicitly reserved for the user
