jpart-literature-positioning

separate

Use when positioning a Journal of Public Administration Research and Theory (JPART) manuscript against the public-administration literature so it reads as a theory contribution, not a fresh data point. JPART expects engagement with the specific PA conversation (PSM, red tape, representation, performance, governance) the paper advances. Stakes the contribution; it does not write the lit review.

When to use

  • Drafting or revising the introduction
  • Revising the contribution paragraph
  • Addressing reviewer feedback on missing core PA literature
  • Connecting empirics to a named PA theory
  • Distinguishing contribution from closest prior JPART/PAR papers
  • Pre-empting sibling-venue reads

When not to use

  • Writing the lit review
