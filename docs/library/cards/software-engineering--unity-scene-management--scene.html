Manage Unity scenes

When to use

  • Opening or saving scenes
  • Loading additively
  • Switching active scene
  • Querying scene contents
  • Creating new scenes
  • Unloading additive scenes
  • Capturing Game View screenshots
  • Searching objects by name, tag, or component

When not to use

  • Deleting scene files
  • Renaming scene files
  • Listing all scene assets
  • Detailed hierarchy tree description
  • Scene statistics summarization
  • Single Game Camera off-screen rendering
