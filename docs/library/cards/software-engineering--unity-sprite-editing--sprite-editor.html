sprite-editor

separate

Edits Unity sprite rectangles, borders, pivots, outlines, and slicing by generating C# scripts. Use when the user works with sprite sheets or sprite slicing.

When to use

  • Edit sprite rectangles
  • Edit sprite borders
  • Edit sprite pivots
  • Edit sprite outlines
  • Sprite slicing
  • Work with sprite sheets
  • Modify sprite names

When not to use

  • Hand-edit .meta files
  • Use AssetPostprocessor patterns
  • Use MenuItem patterns
  • Install unity-cli
  • Confirm connected Editor
  • Add com.unity.pipeline package
  • Discover Editor command catalog
