youtube-api

combined

YouTube Data API integration with managed OAuth. Search videos, manage playlists, access channel data, and interact with comments. Use this skill when users want to interact with YouTube. For other third party apps, use the api-gateway skill (https://clawhub.ai/byungkyu/api-gateway). Use when YouTube data is needed without Google API quotas or OAuth setup: transcripts, video metadata, channel info, search results, playlists. Triggers on pasted YouTube links, creator names, @handles, topic research, video summaries, channel browsing, or any request where YouTube content would help — even if not mentioned explicitly. Not for uploads, account management, or written-source-only research.

When to use

  • Search videos
  • Manage playlists
  • Access channel data
  • Interact with comments
  • Manage Google OAuth connections

When not to use

  • Other third party apps

Skill page

Conflict

The three copies are not reproductions of one procedure; they are three different YouTube data access backends with different authentication, endpoints, and capabilities. ZeroPointRepo uses TranscriptAPI for transcripts and metadata without Google OAuth. browser-act uses a BrowserAct API key and a Python script to scrape structured metrics. LeoYeAI uses the Maton gateway to proxy the official YouTube Data API v3 with managed OAuth. Choosing one as authentic would hide the other two real alternatives.
