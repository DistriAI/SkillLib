analyze-drivers

separate

Use when seeking explanatory attributes or hypotheses for differences in process duration, waiting, utilization or rework.

When to use

  • explanatory attributes for process duration
  • hypotheses for waiting differences
  • utilization analysis
  • rework analysis

When not to use

  • event-level Resource correlation
  • Pearson correlation
  • significance testing
  • causal effect determination
