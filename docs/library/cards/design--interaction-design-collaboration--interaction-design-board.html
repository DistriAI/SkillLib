interaction-design-board

separate

Generates several distinct, clickable HTML interaction prototypes for one product surface into a Design Board and collects selection/remix feedback before implementation. Use for multiple UI versions, interaction alternatives, progressive-disclosure options, or when styling is fine but hierarchy/workflow/interaction feels off. Not for static visual-style calibration (use design-style-picker) or a settled CSS tweak.

When to use

  • multiple UI versions
  • interaction alternatives
  • progressive-disclosure options
  • hierarchy or workflow issues
  • comparing clickable interaction structures

When not to use

  • static visual-style calibration
  • settled CSS tweak
  • one-line CSS adjustment
  • implementation of approved interaction specification
  • new product-wide design system
  • static generated mockups
