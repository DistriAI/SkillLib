Step of the improve-search-visibility playbook: runs the agreed buyer questions on AI and Google surfaces, records every run and scores how often the brand is named. Run improve-search-visibility instead; not for direct use.

When to use

  • Running buyer questions on AI surfaces
  • Running buyer questions on Google surfaces
  • Recording every run
  • Scoring how often the brand is named
  • Classifying cited URLs by source type
  • Comparing brand facts to the brain
  • Calculating mention rate per surface
  • Calculating share of voice

When not to use

  • Direct use
  • Reporting one run as fact
  • Passing organic or API reads off as buyer views
  • Ranking the brand in ChatGPT
