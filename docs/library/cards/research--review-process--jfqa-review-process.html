jfqa-review-process

separate

Use when explaining how the Journal of Financial and Quantitative Analysis (JFQA) review process works — double-anonymous peer review, the seven-Managing-Editor structure, the $350 fee with $275 refund if not sent to a reviewer, and the under-9-percent acceptance reality. Use to set expectations for what happens after you submit and how decisions are made.

When to use

  • explaining JFQA review process
  • understanding double-anonymous peer review
  • describing seven-Managing-Editor structure
  • explaining $350 fee and $275 refund
  • discussing under-9-percent acceptance rate
  • decoding JFQA decision letters
  • setting expectations for post-submission decisions

When not to use

  • writing JFQA manuscripts
  • formatting JFQA submissions
  • drafting JFQA rebuttals
  • selecting JFQA topics
  • managing JFQA replication data
