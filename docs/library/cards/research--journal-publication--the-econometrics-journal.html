the-econometrics-journal

separate

Use when targeting The Econometrics Journal (EctJ) or deciding whether an econometrics manuscript fits this venue. Encodes the journal's fit, framing, method-and-evidence bar, house style, official-submission re-check, and desk-reject heuristics.

When to use

  • targeting The Econometrics Journal
  • deciding if an econometrics manuscript fits
  • choosing among econometrics venues
  • re-framing technical methods contributions
  • assessing desk-reject risks
  • checking method and evidence bar
  • reviewing house style and structure
  • re-routing to alternative venues

When not to use

  • replacing current official submission guidelines
  • applied papers using standard methods with no new contribution
  • methods without derived properties or incomplete proofs
  • token Monte Carlo evidence
  • methods indistinguishable from existing procedures
