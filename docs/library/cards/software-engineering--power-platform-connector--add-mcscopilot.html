add-mcscopilot

separate

Adds Microsoft Copilot Studio connector to a Power Apps code app. Use when invoking Copilot Studio agents, sending prompts to agents, or integrating agent responses.

When to use

  • invoking Copilot Studio agents
  • sending prompts to agents
  • integrating agent responses
  • adding Microsoft Copilot Studio connector
  • configuring ExecuteCopilotAsyncV2

When not to use

  • using ExecuteCopilot fire-and-forget
  • using ExecuteCopilotAsync
  • using conversation turn model
  • deploying the app
