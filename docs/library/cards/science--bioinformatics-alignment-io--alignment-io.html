alignment-io

separate

Read, write, and convert multiple sequence alignment files using Biopython Bio.AlignIO. Supports Clustal, PHYLIP, Stockholm, FASTA, Nexus, and other alignment formats for phylogenetics and conservation analysis. Use when reading, writing, or converting alignment file formats.

When to use

  • reading alignment files
  • writing alignment files
  • converting alignment formats
  • accessing alignment data
  • phylogenetics analysis
  • conservation analysis

When not to use

  • HAL format processing
  • chain/net format processing
  • AXT format processing
  • PSL format processing
  • GFA/rGFA format processing
  • GAF format processing
