run-github-project

separate

Use when asked to set up, review, or operate a repository's GitHub Project workflow, including ready claims, role-labelled human work, unknown remote mutation outcomes, Todo triage, epics, checkpoints, next-issue execution, or an authorized drain.

When to use

  • set up GitHub Project workflow
  • review GitHub Project workflow
  • operate GitHub Project workflow
  • ready claims
  • role-labelled human work
  • unknown remote mutation outcomes
  • Todo triage
  • epics

When not to use

  • Backlog claims
  • Backlog planning
  • Backlog triage
  • Backlog epic closure
  • Backlog cleanup resumption
