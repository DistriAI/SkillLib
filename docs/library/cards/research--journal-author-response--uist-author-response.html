uist-author-response

separate

Use when writing the UIST rebuttal — budgeting the 5,000-character self-contained response, prioritizing factual corrections and novelty defenses over taste disputes, promising only camera-ready changes you can deliver, and writing for the PC discussion that follows rather than for the reviewers alone.

When to use

  • writing the UIST rebuttal
  • budgeting the 5,000-character response
  • prioritizing factual corrections
  • defending novelty
  • promising camera-ready changes
  • writing for the PC discussion

When not to use

  • taste disputes
  • new experiments as argument
  • including links or attachments
  • hostility or meta-complaints about reviewer quality
