bio-crispr-screens-base-editing-analysis

separate

Analyzes base editing and prime editing outcomes including editing efficiency, bystander edits, and indel frequencies. Use when quantifying CRISPR base editor results, comparing ABE vs CBE efficiency, or assessing prime editing fidelity.

When to use

  • quantifying CRISPR base editor results
  • comparing ABE vs CBE efficiency
  • assessing prime editing fidelity
  • quantify base editing efficiency
  • quantify bystander edits
  • quantify indel frequencies
  • CBE analysis
  • ABE analysis

When not to use

  • general editing QC
  • guide design considerations
  • downstream variant analysis
