ndss-topic-selection

separate

Use when deciding whether a security project belongs at NDSS — the Network and Distributed System Security Symposium — or should route to IEEE S&P, USENIX Security, CCS, PETS, IMC, or ACSAC, applying NDSS's networked-adversary and deployment-realism tests before any writing begins.

When to use

  • deciding if a security project belongs at NDSS
  • routing security projects to IEEE S&P, USENIX Security, CCS, PETS, IMC, or ACSAC
  • applying NDSS networked-adversary and deployment-realism tests
  • evaluating project fit against NDSS fit tests
  • checking NDSS-specific constraints like ethics gates and submission caps
  • identifying anti-patterns for NDSS submissions

When not to use

  • calendar strategy or deadline management
  • writing the paper content
