rigor-reviewer

separate

Performs ARA Seal Level 2 semantic epistemic review on Agent-Native Research Artifacts, scoring six dimensions (evidence relevance, falsifiability, scope calibration, argument coherence, exploration integrity, methodological rigor) and producing a constructive, severity-ranked report with a Strong Accept-to-Reject recommendation. Use after Level 1 structural validation passes, when an ARA needs an objective epistemic critique before publication or release.

When to use

  • ARA Seal Level 2 semantic epistemic review
  • Scoring evidence relevance, falsifiability, scope calibration, argument coherence, exploration integrity, methodological rigor
  • Producing a constructive, severity-ranked report
  • Providing a Strong Accept-to-Reject recommendation
  • Objective epistemic critique before publication or release

When not to use

  • Level 1 structural validation
  • Re-checking reference resolution, required fields, exploration tree parsing, or cross-layer links
  • Executing code
  • Fetching URLs
  • Consulting external sources
