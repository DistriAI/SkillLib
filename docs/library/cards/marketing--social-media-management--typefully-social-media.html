typefully-social-media

separate

Create, schedule, and manage social media posts via Typefully. ALWAYS use this skill when asked to draft, schedule, post, or check tweets, posts, threads, or social media content for Twitter/X, LinkedIn, Threads, Bluesky, or Mastodon.

When to use

  • draft social media posts
  • schedule posts
  • publish posts
  • check tweets
  • manage threads
  • post to LinkedIn
  • post to Bluesky
  • post to Mastodon

When not to use

  • searching for API keys in macOS Keychain
  • grepping through config files
  • looking in user's Trash
  • constructing complex shell commands to find credentials
  • drafting content before setup is complete
