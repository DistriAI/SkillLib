openclaw-timebox

separate

基于潘农菲翻译的《时间盒》，为 OpenClaw 打造的全天任务执行系统。早晨用一段对话规划全天、讨论优先级、锁定时间盒；执行时 AI 完全不打扰；每盒结束做 30 秒快速收集；全天结束生成每日总结并自动同步到 Flomo、Notion 等工具。支持苹果日历、飞书、Google 日历自动占位，以及将时间盒任务双向同步到滴答清单（TickTick）。触发词："时间盒"、"timebox"、"开始今天的规划"、"帮我规划任务"、"start timebox"、"task planning"。

When to use

  • Morning planning and priority discussion
  • Executing timebox tasks
  • 30-second quick collection after each box
  • Daily review and summary generation
  • Syncing tasks to TickTick or Dida365
  • Creating calendar placeholders in Apple, Feishu, or Google Calendar
  • Logging execution records to local files or cloud docs

When not to use

  • Intervening in execution details within a timebox
