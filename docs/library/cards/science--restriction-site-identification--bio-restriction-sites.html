bio-restriction-sites

separate

Find restriction enzyme cut sites in DNA sequences using Biopython Bio.Restriction. Search with single enzymes, batches of enzymes, or commercially available enzyme sets.

When to use

  • Find restriction enzyme cut sites
  • Search with single enzymes
  • Search with batches of enzymes
  • Use commercially available enzyme sets
  • Analyze linear or circular DNA
  • Filter results by cutter type
  • Get enzyme information
  • Search multiple sequences

When not to use

  • Visualize cut positions on sequence
  • Choose enzymes by criteria
  • Analyze resulting fragments
