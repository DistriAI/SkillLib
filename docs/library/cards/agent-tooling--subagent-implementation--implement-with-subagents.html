implement-with-subagents

separate

Use when implementing supplied tickets or plan tasks through worker-owned bounded implementation and lead integration, or when reviewing that orchestration.

When to use

  • implementing supplied tickets
  • implementing plan tasks
  • worker-owned bounded implementation
  • lead integration
  • reviewing orchestration
  • assessing supplied orchestration

When not to use

  • invoking the separate /implement skill
  • splitting a single task into artificial pieces
  • implementing an item in the controller
  • waiving final review
  • inventing ordering or removing tasks or dependencies
