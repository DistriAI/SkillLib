eer-theory-model

separate

Use when a European Economic Review (EER) manuscript needs a theoretical model built or tightened — a pure-theory result, a quantitative/structural macro model, or a conceptual frame disciplining an empirical paper. Sharpens the model's contribution, assumptions, and link to data; it does not run the empirical identification or robustness.

When to use

  • pure theory result sharpening
  • quantitative/structural macro model discipline
  • conceptual frame for empirical papers
  • model contribution and assumption defense
  • calibration and estimation discipline
  • counterfactual analysis
  • interpreting empirical estimates

When not to use

  • running empirical identification
  • running robustness checks
