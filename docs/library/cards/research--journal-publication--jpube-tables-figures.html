jpube-tables-figures

separate

Use when designing the exhibits for a Journal of Public Economics (JPubE) manuscript — bunching density plots, event-study and RD/RKD graphs, incidence and distributional figures, and self-contained tables. Makes the public-finance design visible; it does not run the analysis (use jpube-data-analysis).

When to use

  • designing exhibits for JPubE manuscripts
  • creating bunching density plots
  • creating event-study and RD/RKD graphs
  • creating incidence and distributional figures
  • creating self-contained tables
  • making public-finance design visible
  • reviewing exhibit quality for JPubE

When not to use

  • running the analysis
  • using jpube-data-analysis
