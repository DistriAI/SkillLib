neumorphism

combined

Soft, extruded UI elements with inner and outer shadows on monochromatic surfaces for a tactile, embedded look. Web and App implementation guide for Neumorphism (Soft UI). Trigger when user wants soft shadows, extruded appearance, and light source simulation.

When to use

  • Use this sub-style when the user's request matches the aesthetic described above. This is a child reference of the `design-it` skill and is not meant to be triggered directly.

When not to use

  • This is a styling reference and does not replace environment-specific validation, accessibility testing, or expert review.
  • Ensure appropriate contrast ratios and responsive behaviors are verified separately.

Conflict

The two copies address different layers of the same task. The bergside copy is a design-system authoring workflow: it defines tokens, accessibility gates, component-state expectations, and a required output structure for writing neumorphism guidelines. The sickn33 copy is an implementation guide: it gives concrete CSS, SwiftUI, and Flutter code for dual-shadow extruded elements, pressed/inset states, and platform-specific tricks. Neither copy contains the other's material steps; crowning one would hide either the implementation code or the design-system authoring process. They do not conflict on shared facts; they simply operate at different levels of abstraction.
