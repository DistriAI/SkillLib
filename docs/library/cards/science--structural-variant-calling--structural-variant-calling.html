structural-variant-calling

combined

Call structural variants (>=50 bp deletions, insertions, inversions, duplications, translocations) from short- or long-read data by reconstructing four orthogonal signals (discordant pairs, split reads via the SA tag, read depth, local assembly). Covers Manta, DELLY, LUMPY/smoove, GRIDSS2, SvABA for short reads and Sniffles2, cuteSV, pbsv, dipcall/PAV for long reads, each mapped to the signals it fuses and the blind spots that follow. Use when choosing an SV caller from its signal set and failure modes, decoding the SVLEN-sign / symbolic-vs-BND / CIPOS VCF representation minefield, force-genotyping a cohort matrix instead of unioning discovery VCFs, merging populations with sequence-aware Truvari vs position-only SURVIVOR, parameterizing a Truvari benchmark, or deciding when short-read insertion recall forces a switch to long reads. Not for pure copy-number dosage (see copy-number/cnvkit-analysis).

When to use

  • Detecting structural variants from short-read data
  • Calling germline SVs
  • Calling somatic SVs
  • Merging multiple SV callsets
  • Filtering SV calls
  • Annotating SVs

When not to use

  • Long-read SV calling
  • Standard SNV calling

Skill page

Conflict

The two skills cover the same task but with different depth and scope. The first copy (OpenClaw) is a practical, command-line recipe book for short-read SV calling (Manta, Delly, LUMPY) with specific bash commands for configuration, execution, merging, and filtering. The second copy (GPTomics) is a conceptual and strategic guide that explains the underlying signals (RP, SR, RD, Assembly), maps callers to their signal strengths/blind spots, includes long-read callers (Sniffles2, cuteSV, pbsv), and discusses version compatibility and benchmarking (Truvari). The first copy lacks the theoretical framework and long-read details; the second copy lacks the specific, copy-pasteable command workflows for the short-read tools it mentions. Combining them provides both the 'how' (commands) and the 'why/when' (signal logic and caller selection).
