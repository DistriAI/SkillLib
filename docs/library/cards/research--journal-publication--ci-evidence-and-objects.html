ci-evidence-and-objects

separate

Use to choose and read the objects a Critical Inquiry (CI) essay analyzes — texts, images, artworks, films, performances, events, or cases. In CI the "evidence" is not data but objects read closely through theory; this skill helps select objects that test and earn the intervention and handle images to journal standard. It guides selection and reading; it does not run statistics or build datasets.

When to use

  • Choosing which texts, images, or cases the essay will read
  • Selecting objects that test the claim
  • Reading objects so the claim is earned
  • Preparing figures and image permissions for submission
  • Creating an object dossier before drafting
  • Handling interdisciplinary objects

When not to use

  • Running statistics
  • Building datasets
