create-site

separate

Creates a new Power Pages code site (SPA) from a curated template or from scratch using React, Angular, Vue, or Astro. Guides through the full process from initial concept to deployed site: requirements discovery, template selection or scaffolding, component planning, design, implementation, validation, and deployment. Use when the user wants to create, build, use a template for, or scaffold a new Power Pages website or portal.

When to use

  • create a new Power Pages website
  • build a Power Pages portal
  • use a template for a Power Pages site
  • scaffold a new Power Pages website
  • requirements discovery
  • template selection or scaffolding
  • component planning
  • deployment

When not to use

  • Next.js
  • Nuxt.js
  • Remix
  • SvelteKit
  • Liquid
