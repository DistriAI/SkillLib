skillshare-code-review

separate

Review a skillshare change before it becomes a pull request, or review an open pull request. Use this skill whenever the user asks to: review a diff, branch, commit range or PR, check a change before opening a PR, run a pre-Codex review, or find what a change missed. It checks correctness, the repository's documented rules, the originating issue or spec, every consumer of a changed concept, and cleanup (reuse, simplification, efficiency, depth of fix), then verifies each finding against the code before reporting it. Read-only unless the user asks for fixes.

When to use

  • review a diff
  • review a branch
  • review a commit range
  • review a PR
  • check a change before opening a PR
  • run a pre-Codex review
  • find what a change missed

When not to use

  • commit changes
  • push changes
  • comment on GitHub
  • run go test on host
  • run make test on host
  • run skillshare on host
  • run frontend scripts on host
