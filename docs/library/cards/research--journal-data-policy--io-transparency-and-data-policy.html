io-transparency-and-data-policy

separate

Use when preparing the replication/transparency materials for an International Organization (IO) manuscript. IO's signature requirement is verification BEFORE final acceptance — the editorial staff request data and code at conditional acceptance, IO staff re-run quantitative results and check proofs of formal models, and editors withhold final acceptance until all reported results are confirmed; materials then deposit to the IO Dataverse with a DOI and a Data Availability Statement. Prepares the package; it does not waive requirements.

When to use

  • Building the reproducibility/replication package
  • Responding to data and code requests at conditional acceptance
  • Preparing formal model proofs for verification
  • Handling data that cannot be fully shared
  • Writing the Data Availability Statement
  • Depositing materials to the IO Dataverse

When not to use

  • Waiving IO requirements
  • Initial submission data provision
