qe-rebuttal

separate

Use when a Quantitative Economics (QE) decision letter arrives (R&R or major/conditional revision) and a response strategy and letter are needed. Structures the revision and response; it does not redo the analysis (route to the relevant qe-* skill for that).

When to use

  • Structuring revision and response strategy
  • Triaging referee comments
  • Drafting the response letter
  • Prioritizing conflicting referee demands
  • Classifying comments as fundamental, clarification, or disagreement

When not to use

  • Redoing the analysis
  • Performing identification strategy
  • Conducting data analysis
  • Creating tables and figures
  • Updating replication package
