Display HTML content on connected OpenClaw nodes (Mac app, iOS, Android) using the canvas tool.

When to use

  • Displaying games, visualizations, dashboards
  • Showing generated HTML content
  • Interactive demos
  • Presenting web content on node canvas view
  • Navigating canvas to new URLs
  • Capturing canvas screenshots
  • Executing JavaScript in canvas

When not to use

  • A2UI JSON push
