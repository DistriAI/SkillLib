hlr-footnotes-and-cite-check

separate

Use when building and stress-testing the heavy footnote apparatus of a Harvard Law Review (HLR) piece so it survives the student-editor cite-check / source-pull. Builds and audits the apparatus for pull-readiness; it does not set Bluebook form per citation (hlr-sources-and-bluebook) or manage the editor relationship (hlr-student-editor-review).

When to use

  • Building footnotes as you draft
  • Auditing footnotes before submission
  • Preparing for the source-pull after an offer
  • Verifying footnote support for propositions
  • Checking quotation accuracy and pincites
  • Assembling a source file with cited pages marked
  • Self-running cite-check before editors do
  • Verifying short forms like Id. and supra

When not to use

  • Setting Bluebook form per citation
  • Managing the editor relationship
