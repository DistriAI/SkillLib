Design and diagnose list experiments (item count technique).

When to use

  • Designing list experiments
  • Diagnosing list experiment issues
  • Assessing sensitivity bias
  • Selecting control items
  • Choosing control list design variants
  • Evaluating precision costs

When not to use

  • Direct questions with neutral framing when bias is small
  • Topics with near-zero sensitivity bias
