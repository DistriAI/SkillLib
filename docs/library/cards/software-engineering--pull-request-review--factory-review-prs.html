factory-review-prs

separate

Experimental workflow for reviewing configured repositories' pull requests. Use for manual or scheduled PR triage, approval, or merge decisions.

When to use

  • reviewing configured repositories' pull requests
  • manual or scheduled PR triage
  • PR approval decisions
  • PR merge decisions
  • inspecting diffs and linked issues
  • reporting actionable findings

When not to use

  • one long-lived, explicitly authorized PR
  • tasks not matching configured filters
  • draft PRs
  • PRs outside configured filters
