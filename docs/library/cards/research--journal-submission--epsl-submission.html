epsl-submission

separate

Use when running the final pre-submission preflight for Earth and Planetary Science Letters (EPSL) via Editorial Manager — letters-format length check, title page and highlights, declarations (competing interests, authorship, AI use), data-availability statement with repository DOIs, and figure/table file compliance. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • letters-format length check
  • title page and highlights verification
  • declarations check
  • data-availability statement verification
  • figure/table file compliance
  • verifying letters-format constraints

When not to use

  • drafting content
