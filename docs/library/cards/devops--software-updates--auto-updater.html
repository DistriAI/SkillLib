auto-updater

separate

Automatically update Clawdbot and all installed skills once daily. Runs via cron, checks for updates, applies them, and messages the user with a summary of what changed.

When to use

  • Daily auto-updates for Clawdbot
  • Updating all installed skills
  • Setting up daily cron jobs for updates
  • Checking for Clawdbot updates
  • Applying skill updates via clawdhub
  • Reporting update summaries

When not to use

  • Manual update checks without applying
  • Viewing current skill versions
  • Checking Clawdbot version
  • Disabling auto-updates
