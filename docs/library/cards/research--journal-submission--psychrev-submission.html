psychrev-submission

separate

Use when running the final pre-submission preflight for a Psychological Review manuscript — Editorial Manager portal, APA format and length, abstract, masking, references, ethics, and (for computational models) sharing the author's own model code. Theory journal; there is no empirical data-availability/replication-package step.

When to use

  • final pre-submission preflight
  • Editorial Manager portal check
  • APA format and length verification
  • abstract word count check
  • masking and anonymity verification
  • references and citations check
  • ethics and originality verification
  • computational model code sharing preparation

When not to use

  • empirical data-availability
  • replication-package step
  • experimental dataset deposit
  • empirical-analysis kit sharing
