replica-design

separate

Rebuilds an app's design system for a clone: colour roles, type scale, spacing, radius, shadows and every component with its states, as design tokens plus component specs, with original assets instead of the target's logos, icons, illustrations or licensed fonts. Includes a WCAG contrast checker. Use when the user says "match the design", "rebuild the design system", "get the colours and fonts", "make it look like X", "design tokens for my clone", or after /replica-architect.

When to use

  • rebuild the design system
  • match the design
  • get the colours and fonts
  • make it look like X
  • design tokens for my clone
  • after /replica-architect

When not to use

  • using original logos
  • using original icons
  • using original illustrations
  • using original licensed fonts
  • using original copy
  • using original brand colour as final
