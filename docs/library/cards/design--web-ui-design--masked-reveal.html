masked-reveal

separate

Create masked staggered word reveals on scroll with GSAP ScrollTrigger. Use when headings, hero copy, section titles, or editorial text should reveal word-by-word through an overflow mask as they enter the viewport.

When to use

  • headlines or short text blocks needing premium reveal on scroll
  • words rising through an invisible mask with staggered sequence
  • projects using GSAP or needing ScrollTrigger-based motion
  • short headlines, labels, and section intros

When not to use

  • long paragraphs
  • text containing links, buttons, or meaningful inline markup
  • combining with blur unless explicitly called for
