renew-or-churn-call

authentic

Score an account's renewal likelihood on a five-level scale with probabilities, and name the next move for the account owner. Use when asked will this account renew, what's the churn risk on this account, should we run a save play, or when a renewal is 30–120 days out and the owner needs a calibrated read rather than a gut feel. Produces the account state in a fixed schema, the five-level renewal score with a probability per level and confidence, the mapped next move, and the single signal that would change the call.

When to use

  • Will this account renew
  • What's the churn risk on this account
  • Should we run a save play
  • Renewal is 30–120 days out
  • Owner needs a calibrated read
  • Score this renewal and tell me the next move

When not to use

  • Gathering health score dimensions
  • Running the renewal playbook
  • Creating a CS escalation brief
