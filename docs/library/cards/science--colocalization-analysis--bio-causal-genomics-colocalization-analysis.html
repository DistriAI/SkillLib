bio-causal-genomics-colocalization-analysis

separate

Test whether two traits share a causal variant at a genomic locus using Bayesian colocalization with coloc. Computes posterior probabilities for shared vs distinct causal variants between GWAS and eQTL signals. Use when determining if a GWAS signal and an eQTL share the same causal variant.

When to use

  • Test whether GWAS signal and eQTL share the same causal variant
  • Compute Bayesian posterior probabilities for colocalization hypotheses
  • Distinguish true causal overlap from LD-driven coincidence
  • Test colocalization at loci with multiple independent causal signals
  • Test colocalization across three or more traits simultaneously
