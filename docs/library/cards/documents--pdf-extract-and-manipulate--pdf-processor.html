pdf-processor

combined

Perform basic local PDF operations (merge, split, extract pages/text/tables, create) when users request offline PDF processing without external services. Process PDFs - extract text, tables, and structured data from documents

When to use

  • You need to merge multiple PDFs into a single document offline.
  • You need to split a PDF into per-page files for review, annotation, or distribution.
  • You need to extract a specific page range (e.g., `1-3,5`) into a new PDF.
  • You need to extract selectable text from a PDF into a `.txt` file without using any cloud API.
  • You need to extract tables from PDFs into CSV files locally.

When not to use

  • Do not use this skill when the required source data, identifiers, files, or credentials are missing.
  • Do not use this skill when the user asks for fabricated results, unsupported claims, or out-of-scope conclusions.
  • Do not use this skill when a simpler direct answer is more appropriate than the documented workflow.

Skill page

Conflict

The two copies describe different procedures for the same skill name. The gooseworks copy is a cloud-based workflow that fetches PDFs via URLs and uses external APIs (Linkup, ScrapeGraph, Riveter) to extract text, tables, and markdown. The aipoch copy is a local-only CLI workflow that merges, splits, extracts pages, extracts text, extracts tables, and creates PDFs without network access. They overlap on extracting text and tables, but each has material steps and constraints the other lacks (cloud API calls vs local CLI operations, merge/split/create vs markdown conversion). Crowning one would hide a real alternative.
