lancet-statistics

separate

Use to enforce The Lancet's clinical-statistics reporting — confidence intervals over bare P values, a pre-specified primary analysis, intention-to-treat with per-protocol sensitivity, multiplicity control for secondary endpoints, cautious pre-specified subgroup analyses with interaction tests, missing-data handling, and absolute plus relative effects.

When to use

  • clinical-statistics reporting
  • confidence intervals over bare P values
  • pre-specified primary analysis
  • intention-to-treat with per-protocol sensitivity
  • multiplicity control for secondary endpoints
  • pre-specified subgroup analyses with interaction tests
  • missing-data handling
  • absolute plus relative effects

When not to use

  • reporting P values without confidence intervals or effect sizes
  • reporting only relative effects when absolute effects change clinical message
  • presenting per-protocol as primary analysis for superiority trials
  • mining subgroups with separate within-subgroup P values without interaction tests
