create-motion-graphics

separate

Use whenever the agent needs to add, create, hand-author, patch, or place Motion Graphic JSX assets in a OpenChatCut project. This is the direct-authoring path: use create_motion_graphic_from_code / edit_asset / edit_item, not motion-graphic-gen or submit_motion_graphic. Covers project/timeline intake, project visual language, editable properties, asset binding, inline JSX authoring, existing asset updates, timeline placement, and verification.

When to use

  • add Motion Graphic JSX assets
  • create Motion Graphic JSX assets
  • hand-author Motion Graphic JSX
  • patch Motion Graphic JSX
  • place Motion Graphic JSX assets
  • project/timeline intake
  • project visual language
  • editable properties

When not to use

  • motion-graphic-gen
  • submit_motion_graphic
  • translating request into a Gemini prompt
  • generation brief
  • staging code in OpenChatCut repository
  • staging code in ai-working/
  • staging code in /tmp
  • staging code in local HTTP server
