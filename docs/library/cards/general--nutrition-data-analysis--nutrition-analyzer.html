nutrition-analyzer

combined

分析营养数据、识别营养模式、评估营养状况，并提供个性化营养建议。支持与运动、睡眠、慢性病数据的关联分析。

When to use

  • 需要分析营养摄入、饮食模式或营养素达标情况时使用。
  • 任务涉及宏量/微量营养素评估、RDA 对比、饮食趋势或膳食改进建议。
  • 需要把营养数据与运动、睡眠或慢性病数据关联分析时使用。

When not to use

  • Use this skill only when the task clearly matches the scope described above.
  • Do not treat the output as a substitute for environment-specific validation, testing, or expert review.
  • Stop and ask for clarification if required inputs, permissions, safety boundaries, or success criteria are missing.

Skill page

Conflict

The two copies share the same name and high-level purpose but diverge in how they instruct the agent. The first copy is a thin wrapper that defers to an external detailed guide and adds safety/limitation constraints. The second copy is a self-contained procedure with specific data file paths, analysis algorithms (RDA achievement thresholds, nutrient density scoring, Pearson correlation), and a detailed output report format. Neither copy contains the other's material steps, so crowning one would hide a real alternative.
