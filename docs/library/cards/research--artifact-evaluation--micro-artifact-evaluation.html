micro-artifact-evaluation

separate

Use when preparing a MICRO artifact for post-acceptance evaluation — packaging simulators, configs, traces, and scripts so evaluators can regenerate the paper's figures, targeting the ACM Available/Functional/Reproducible badges, handling licensed workloads and long simulations, and earning the optional artifact appendix.

When to use

  • preparing MICRO artifact for post-acceptance evaluation
  • packaging simulators, configs, traces, and scripts
  • targeting ACM Available/Functional/Reproducible badges
  • handling licensed workloads and long simulations
  • earning the optional artifact appendix
  • designing nested entry points for simulation time budgets
  • documenting figure-to-command maps and hardware requirements
  • managing licensed and unshippable inputs

When not to use

  • pre-acceptance paper submission
  • camera-ready formatting
  • general software development
  • non-MICRO conference artifact evaluation
