arbor

separate

Applies Arbor Hypothesis Tree Refinement to research artifacts with repeatable evaluators, including model training, agent harnesses, data synthesis and benchmark optimization. Uses persistent hypotheses, isolated experiments, evidence propagation and held-out candidate comparison for multi-experiment research runs. Includes a standard-library state manager and guidance for the RUC-NLPIR Arbor CLI.

When to use

  • Model training: optimizer/architecture/recipe changes to lower loss or hit a target in fewer steps.
  • Harness/agent engineering: raising pass rate or accuracy of an agent loop, search harness, or tool-use scaffold.
  • Data synthesis: improving a generation/filtering pipeline judged by downstream model behavior.
  • Benchmark optimization: MLE-bench / Kaggle-style "improve the submission" tasks.
  • Prompt/system optimization where you can score outputs automatically.

When not to use

  • Single fix or one-shot answer
  • Open-ended ideation with no evaluator
