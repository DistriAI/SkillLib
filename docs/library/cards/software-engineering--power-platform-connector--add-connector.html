add-connector

authentic

Adds any Power Platform connector to a Power Apps code app. Generic fallback for connectors not covered by a specific skill.

When to use

  • Adding generic Power Platform connectors
  • Adding non-tabular connectors
  • Adding tabular connectors
  • Configuring connector operations
  • Building the app after adding a connector

When not to use

  • Adding Dataverse tables
  • Adding Azure DevOps
  • Adding Microsoft Teams
  • Adding Excel Online (Business)
  • Adding OneDrive for Business
  • Adding SharePoint Online
  • Adding Office 365 Outlook
  • Adding Work IQ (M365 Copilot Search)
