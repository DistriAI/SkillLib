ecta-tables-figures

separate

Use when finalizing the simulation tables and any empirical / illustrative exhibits in an Econometrica manuscript so each is self-contained, precise, and reproducible. Formats and audits exhibits; it does not design the Monte Carlo (use ecta-robustness) or run the estimation.

When to use

  • finalizing simulation tables
  • formatting empirical exhibits
  • auditing table self-containment
  • checking figure labels and legends
  • verifying traceability to scripts
  • ensuring consistent decimal precision
  • applying booktabs style

When not to use

  • designing the Monte Carlo
  • running the estimation
