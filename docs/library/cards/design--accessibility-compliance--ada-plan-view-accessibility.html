ada-plan-view-accessibility

separate

Use when checking simplified ADA-derived plan-view bathroom accessibility constraints such as turning space, door clear width, toilet centerline, grab bars, and lavatory knee/toe clearance.

When to use

  • plan-view accessibility checks
  • door clear opening verification
  • door swing analysis
  • turning space verification
  • lavatory overlap checks
  • toilet centerline measurement
  • grab bar classification and length comparison
  • violation reporting and repair principles

When not to use

  • full legal ADA compliance review
  • vertical requirements such as seat height
  • mounting height checks
  • mirror height checks
  • signage height checks
  • pipe protection checks
