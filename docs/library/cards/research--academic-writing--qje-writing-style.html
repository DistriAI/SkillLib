qje-writing-style

separate

Use when polishing prose, abstract, and introduction for a Quarterly Journal of Economics (QJE) manuscript so the big idea lands fast for a general-interest reader. Reflects QJE's house style — long, ambitious, narrative-driven empirical papers. Polishes exposition; it does not change results or design.

When to use

  • polishing prose
  • polishing abstract
  • polishing introduction
  • making big idea legible
  • QJE manuscript editing
  • sentence-level craft
  • relocating technical detail to appendix

When not to use

  • changing results
  • changing design
  • identification strategy
  • data analysis
