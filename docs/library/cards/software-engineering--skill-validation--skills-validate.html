skills-validate

separate

Use when explicitly asked to run a live or plan-only application test for a published Scenario skill.

When to use

  • run a live application test for a published Scenario skill
  • run a plan-only application test for a published Scenario skill
  • validate skill named in invocation arguments
  • report where the agent got stuck

When not to use

  • fixing defects in the agent
  • validating skills not named in invocation arguments
