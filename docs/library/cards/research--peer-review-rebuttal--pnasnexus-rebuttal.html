pnasnexus-rebuttal

separate

Use after PNAS Nexus reviews arrive to triage the decision, prioritize experiments, and draft a point-by-point response that is respectful, evidence-led, and honest about limits. Covers the case where reviews were carried over from a PNAS transfer. Do not run before the main text is actually revised.

When to use

  • triage the decision
  • prioritize experiments
  • draft a point-by-point response
  • handle transferred PNAS reviews
  • build a PNAS Nexus revision ledger

When not to use

  • run before the main text is actually revised
