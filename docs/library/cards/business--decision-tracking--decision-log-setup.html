decision-log-setup

authentic

Set up the team decision log that ends relitigation — the one-line-per-decision format (what, why, who, when, reopening rule), the capture moments wired into existing rituals, and the lookup habit that makes it pay. Use when asked set up a decision log, we keep re-deciding the same things, where do decisions get recorded, or new people keep asking why we do X. Produces the log format, the capture wiring, the reopening rule, and the retrieval habits.

When to use

  • Set up a decision log
  • Stop re-deciding the same things
  • Define where decisions get recorded
  • Address new people asking why we do X
  • Create a log format with rejected alternatives
  • Wire capture into existing rituals
  • Define reopening rules
  • Establish retrieval habits

When not to use

  • Full historical back-fill of all decisions
  • Logging operational micro-calls
  • Building new ceremony for capture
  • Logging without rejected alternatives
  • Reopening settled calls based on new mood or people
