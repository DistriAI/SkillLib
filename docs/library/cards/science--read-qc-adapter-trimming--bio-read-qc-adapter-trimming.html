bio-read-qc-adapter-trimming

separate

Remove sequencing adapters from FASTQ files using Cutadapt and Trimmomatic. Supports single-end and paired-end reads, Illumina TruSeq, Nextera, and custom adapter sequences. Use when FastQC shows adapter contamination or before alignment of short reads.

When to use

  • Remove sequencing adapters from FASTQ files
  • Single-end read adapter trimming
  • Paired-end read adapter trimming
  • Illumina TruSeq adapter removal
  • Nextera adapter removal
  • Custom adapter sequence trimming
  • FastQC adapter contamination resolution
  • Pre-alignment short read processing
