myvariant-queries

separate

Queries myvariant.info BioThings aggregator for ClinVar, gnomAD, dbSNP, dbNSFP, COSMIC, CADD, and CIViC annotations in batched, version-tracked requests. Use when annotating variant lists from multiple databases simultaneously without managing per-source APIs, and when reproducibility-grade analyses require recording source data versions via _meta.

When to use

  • annotating variant lists from multiple databases simultaneously
  • reproducibility-grade analyses requiring recording source data versions
  • batched, version-tracked requests
  • querying ClinVar, gnomAD, dbSNP, dbNSFP, COSMIC, CADD, and CIViC annotations
  • single canonical-ID lookup
  • batch lookup up to 1000 IDs
  • flexible Elasticsearch search
  • per-source version metadata retrieval

When not to use

  • producing ACMG calls
  • offline or PHI-sensitive analysis
  • local annotation tool pipeline integration
  • family or cohort analysis
  • clinical lab ACMG criteria auto-application
