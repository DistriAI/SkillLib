jru-submission

separate

Use when running the final pre-submission preflight for the Journal of Risk and Uncertainty (JRU) via Springer's portal — file set, anonymization, Data Availability Statement, ethics and AI disclosures, and house-style checks. Final checks; it does not draft content.

When to use

  • final pre-submission preflight
  • checking file set for Springer portal
  • verifying anonymization for review
  • confirming Data Availability Statement
  • checking ethics and AI disclosures
  • verifying house-style checks
  • checking abstract and reference style

When not to use

  • drafting content
