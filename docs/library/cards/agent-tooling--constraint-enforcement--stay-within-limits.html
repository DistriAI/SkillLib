stay-within-limits

separate

Use when long-running or parallel agent work must respect 5-hour and weekly usage limits by checking usage between waves, pausing near the cap, and resuming only when the window is clear.

When to use

  • long-running agent work
  • parallel agent work
  • checking usage between waves
  • pausing near the cap
  • resuming when the window is clear
  • managing 5-hour usage limits
  • managing weekly usage limits

When not to use

  • interrupting in-flight subagents to save budget
  • trusting elapsed wall-clock time alone for resume
  • short-interval polling for host-notified events
