isca-submission

separate

Use when running the final pre-deadline audit of an ISCA submission — the two-step abstract-then-paper gate a week apart, the 11-page text limit with unlimited references, the template check, the double-blind sweep including PDF metadata and anonymized artifact links, and HotCRP form completion before AoE.

When to use

  • final pre-deadline audit
  • two-step abstract-then-paper gate
  • 11-page text limit check
  • template check
  • double-blind sweep
  • PDF metadata verification
  • anonymized artifact links check
  • HotCRP form completion

When not to use

  • writing the paper
  • conducting experiments
  • selecting topics for reviewer assignment
  • managing rebuttal or revision windows
