# Senior Data Engineer

## Core Capabilities
- **Batch Pipeline Orchestration**: Design ETL/ELT pipelines with Airflow, dependency resolution, and monitoring.
- **Real-Time Streaming**: Build event-driven pipelines with Kafka, Flink, and Spark Streaming with exactly-once semantics.
- **Data Quality Management**: Validate completeness, accuracy, consistency, and timeliness.
- **Performance Optimization**: Optimize query performance, Spark tuning, and cost analysis.

## Architecture Decision Framework

### Batch vs Streaming
| Criteria | Batch | Streaming |
|----------|-------|-----------|
| **Latency** | Hours to days | Seconds to minutes |
| **Volume** | Large historical | Continuous streams |
| **Complexity** | Complex transformations | Simple aggregations |

**Decision Tree:**
```
Is real-time insight required?
├── Yes → Use streaming
│   └── Is exactly-once semantics needed?
│       ├── Yes → Kafka + Flink/Spark Structured Streaming
│       └── No → Kafka + consumer groups
└── No → Use batch
    └── Is data volume > 1TB daily?
        ├── Yes → Spark/Databricks
        └── No → dbt + warehouse compute
```

### Lambda vs Kappa
- **Lambda**: Two codebases (batch + stream). Use for ML training + real-time serving.
- **Kappa**: Single codebase. Use for event-sourced architectures or fresh starts.

## Key Workflows

### Workflow 1: Build ETL Pipeline
1. Design pipeline architecture (Lambda, Kappa, or Medallion).
2. Configure YAML pipeline definition with sources, transformations, and targets.
3. Generate Airflow DAG using `pipeline_orchestrator.py`.
4. Define data quality validation rules.
5. Deploy and configure monitoring/alerting.

**Expected Output:** Production-ready ETL pipeline with 99%+ success rate and automated quality checks.

### Workflow 2: Build Real-Time Streaming Pipeline
1. Select streaming architecture (Kappa vs Lambda).
2. Configure streaming pipeline YAML (sources, processing, sinks, quality).
3. Generate Kafka configurations with `kafka_config_generator.py`.
4. Generate Flink/Spark job scaffolding with `stream_processor.py`.
5. Deploy and monitor with `streaming_quality_validator.py`.

**Expected Output:** Streaming pipeline processing 10K+ events/sec with P99 latency < 1s and exactly-once delivery.

## Quick Start Commands

```bash
# Generate Airflow DAG
python scripts/pipeline_orchestrator.py --config pipeline_config.yaml --output dags/

# Validate data quality
python scripts/data_quality_validator.py --input data/sales.csv --output report.html

# Optimize ETL performance
python scripts/etl_performance_optimizer.py analyze --query queries/daily_aggregation.sql --engine spark --recommend
```
