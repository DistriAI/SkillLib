# ScrapeCreators API

Scrape and extract public data from 27+ social media platforms.

**Base URL:** `https://api.scrapecreators.com`

## Runtime Selection

1. **GooseWorks MCP available:** Use the `call_data_provider` tool with the operation fields.
2. **Local GooseWorks CLI available:** Use `gooseworks call <provider> <path>`.
3. **User-owned key available:** Use `curl` or `fetch` with the `x-api-key` header.
4. **No runtime:** Ask the user to connect a runtime or provide a key.

## How to Call

All endpoints use GET requests (unless specified in the OpenAPI spec). Authenticate with the `x-api-key` header.

```bash
curl -s "https://api.scrapecreators.com/v1/tiktok/profile?handle=charlidamelio" \
  -H "x-api-key: $SCRAPECREATORS_API_KEY"
```

## Endpoint Discovery

Fetch the single-endpoint OpenAPI spec at `https://docs.scrapecreators.com/{path}/openapi.json` to get full parameter details before making the actual API call.

## Intent Routing

Map user intent to the right endpoint using the tables below. After selecting an endpoint, fetch its OpenAPI spec for full param details.

### Profiles / User Info
| Platform | Endpoint | Primary Param |
|----------|----------|---------------|
| TikTok | `/v1/tiktok/profile` | handle |
| Instagram | `/v1/instagram/profile` | handle |
| YouTube | `/v1/youtube/channel` | handle, channelId, or url |
| LinkedIn (person) | `/v1/linkedin/profile` | url |
| Twitter/X | `/v1/twitter/profile` | handle |

### Posts / Content Feeds
| Platform | Endpoint | Primary Param |
|----------|----------|---------------|
| TikTok videos | `/v3/tiktok/profile/videos` | handle |
| Instagram posts | `/v2/instagram/user/posts` | handle |
| YouTube videos | `/v1/youtube/channel/videos` | handle or channelId |
| Twitter tweets | `/v1/twitter/user/tweets` | handle |

## Collection Rules

1. Confirm platform, market, time window, and sample size.
2. Start with a small request and inspect the response shape.
3. Follow the returned cursor until the requested sample is reached.
4. Keep the raw source URL, creator handle, platform, and publication date with every item.
5. Deduplicate by platform-native content ID or canonical URL.
6. Separate facts returned by the API from conclusions inferred during analysis.

## Output Contract

Return a normalized source set:

```json
{
  "platform": "instagram",
  "query": "brand",
  "collected_at": "ISO-8601",
  "items": [{"id":"...","url":"...","author":"...","published_at":"...","text":"...","metrics":{}}],
  "next_cursor": null,
  "limitations": []
}
```
