# E-Commerce Video Marketing

This skill supports two modes of operation: **Strategy Planning** and **Script Generation**.

## Mode 1: Strategy Planning (Western/Global Focus)
Use this mode when the user asks for a video marketing plan, UGC strategy, or platform-specific optimization for Amazon, TikTok, YouTube, or Instagram.

1. **Define Funnel Stage**: Determine if the video targets Awareness, Consideration, or Purchase.
2. **Select Content Type**: Choose between Product Demo, Tutorial, UGC, or Live Stream.
3. **Platform Optimization**:
   - **Amazon**: Focus on A+ content video, clear product benefits, and high-resolution specs.
   - **TikTok/Reels/Shorts**: Prioritize short-form (15-60s), hook in first 3 seconds, and trending audio.
   - **YouTube**: Focus on SEO (titles, tags, thumbnails) and longer-form tutorials or reviews.
4. **UGC Workflow**: Define how to collect, curate, and repurpose user-generated content.
5. **Output**: Provide a structured plan with benchmarks and actionable steps.

## Mode 2: Script Generation (Chinese/Local Focus)
Use this mode when the user asks for a specific video script for Douyin, Xiaohongshu, Taobao, or JD, or when detailed shot-by-shot instructions are needed.

1. **Task Initiation**: Collect product info (name, price, selling points), target platform, duration (15s/30s/60s), and brand tone.
2. **Requirement Definition**:
   - **Audience**: Define age, gender, occupation, and pain points.
   - **Style**: Choose Lifestyle, Demo, Emotional, Humorous, Tech, or Minimalist.
   - **Pain Point**: Identify the core problem the product solves.
3. **Product Understanding**: Analyze product features and extract 3-5 core selling points with supporting evidence.
4. **Script Creation (Golden Narrative Structure)**:
   - **Pain Point Hook (3-5s)**: Show the user's struggle to create empathy.
   - **Product Display (5-8s)**: Demonstrate how the product solves the pain point.
   - **Solution/CTA (3-5s)**: Show the positive outcome and call to action.
5. **Shot Design**:
   - **Camera Types**: Use Close-up for details, Medium for interaction, Wide for context.
   - **Movement**: Use Dolly In/Out, Pan, Truck, Follow, or Orbit to enhance visual interest.
6. **Post-Production & Optimization**:
   - Suggest subtitles, background music, and sound effects.
   - Recommend A/B testing for different versions.
   - Ensure cultural adaptation and localization for the target market.

## Conflicts
- **Platform Focus**: Nexscope targets Western platforms (Amazon, YouTube, TikTok); anbeime targets Chinese platforms (Douyin, Xiaohongshu, Taobao). Select the mode based on the user's target market.
- **Granularity**: Nexscope provides high-level strategy; anbeime provides detailed script and shot instructions. If the user asks for a "plan," use Mode 1. If they ask for a "script" or "shot list," use Mode 2.
