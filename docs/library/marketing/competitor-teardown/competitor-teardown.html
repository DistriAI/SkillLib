# Competitor Teardown

Produce a structured competitive analysis. Choose the mode based on the user's request: single-page conversion audit or multi-competitor market landscape.

## Inputs
- **Mode**: single-page teardown (URL or screenshot) or multi-competitor landscape (2–5 competitor names).
- **Your product**: name and one-line description.
- **Competitors**: list of names (required for landscape mode; single name for page mode).
- **Depth**: quick overview or detailed teardown.
- **Use case**: sales enablement, investor deck, internal strategy, or product planning.

If inputs are missing, proceed with reasonable assumptions marked *(assumed, confirm)* and list them at the end. Ask only when the core subject is absent.

## Single-Page Conversion Audit
1. Capture the page from the URL or screenshot. If only a screenshot is provided, note any sections not visible.
2. Extract the value proposition: problem solved, ICP, promised transformation, unique mechanism.
3. Map the messaging hierarchy: headline, subheadline, body copy, CTA, trust signals.
4. Extract exact quotes for each messaging element.
5. Score using the 100-point rubric below.
6. Identify red flags, strengths, and weaknesses.
7. Generate strategic differentiation recommendations.

### 100-Point Rubric
| Category | Max Points |
|----------|------------|
| Positioning Clarity | 15 |
| Headline Effectiveness | 15 |
| Copy Quality | 15 |
| CTA Strategy | 15 |
| Trust Signals | 10 |
| Visual Hierarchy | 10 |
| Objection Handling | 10 |
| Pricing Presentation | 5 |
| Brand Voice | 5 |

### Red Flags
- Vague headlines, feature-heavy copy without benefits, multiple audiences on one page, missing value proposition, weak CTAs, no social proof, cluttered design.

## Multi-Competitor Market Landscape
1. Write a landscape overview under 150 words: key players, market segmentation, white space.
2. Describe a 2x2 positioning map in text. Define two market-specific axes, place each competitor with a one-sentence justification, and place your product with the strategic implication.
3. Build a feature comparison table (10–15 rows) using ✅ / ❌ / 🟡 and a strategic notes column. Mark cells that need verification if details are missing.
4. Analyze messaging for each competitor: main claim, target audience signal, emotional hook, and messaging gap your product can own.
5. Produce an honest SWOT for your product in this landscape (2–3 items per quadrant).
6. Write 3–5 recommendations in the form: "Given [observation], [product] should [action] to [outcome]."

### 0–40 Rubric
| Dimension | 0 | 5 | 10 |
|---|---|---|---|
| Map significance | Generic axes | Market-specific but unjustified | Captures real purchase tension, defensible positions |
| Comparative depth | Checkboxes | Some notes | Strategic notes explain why gaps matter |
| SWOT honesty | Softened | Honest but unprioritized | Clear, prioritized by concern level |
| Recommendation specificity | Generic | Actionable but disconnected | Each tied to a finding |

Score the output before delivery; 32+ is send-ready.

## Sourcing and Confidence Labels
Apply [verified], [reported], or [assumed] to every substantive claim. Use the intel-sourcing guide for source levels and ethical lines. List all assumptions at the end.

## Quality Checks
- Positioning map axes are market-specific and meaningful.
- Feature table includes strategic notes on key differentiators.
- Messaging analysis covers all named competitors.
- SWOT is honest; weaknesses and threats are not softened.
- Recommendations are specific and actionable.
- Exact quotes are used for single-page messaging analysis.
- All assumptions are listed.

## Output Format
Use the mode-appropriate structure. For single-page audits, include the value proposition analysis, messaging hierarchy table, scoring breakdown, strengths, weaknesses, strategic recommendations, and confidence level. For landscape analyses, include the overview, positioning map, feature table, messaging analysis, SWOT, recommendations, and confidence labels.
