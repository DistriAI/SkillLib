# SEO/GEO Optimization

## When to Use
Use when the user wants to improve search visibility in traditional engines (Google, Bing) and AI search engines (ChatGPT, Perplexity, Gemini, Copilot, Claude), or when evaluating GEO, AI citations, llms.txt readiness, or crawler accessibility.

## Step 1: Website Audit
1. Run a basic technical SEO audit (title, meta, H1, robots, sitemap, load time). If a local script is available, use it; otherwise use curl to fetch the page and inspect meta tags, robots.txt, and sitemap.xml.
2. Verify AI crawler access in robots.txt. Allow search-oriented AI crawlers (GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, PerplexityBot, Googlebot, Bingbot). Decide whether to block training crawlers (CCBot, anthropic-ai, Bytespider, cohere-ai) based on the user's policy.
3. Check for the presence and correctness of /llms.txt at the domain root. Ensure it lists key pages, descriptions, and authority/contact information.
4. Check for RSL 1.0 (Really Simple Licensing) implementation and appropriate machine-readable licensing terms.

## Step 2: Keyword Research
1. Research target keywords for search volume, difficulty, and long-tail opportunities.
2. Analyze competitor keyword strategies and international keyword conflicts.

## Step 3: GEO Optimization (AI Search Engines)
Apply both the Princeton GEO methods and the weighted GEO analysis criteria:

### Princeton GEO Methods
- Cite Sources (+40%): Add authoritative citations and references.
- Statistics Addition (+37%): Include specific numbers and data points.
- Quotation Addition (+30%): Add expert quotes with attribution.
- Authoritative Tone (+25%): Use confident, expert language.
- Easy-to-understand (+20%): Simplify complex concepts.
- Technical Terms (+18%): Include domain-specific terminology.
- Unique Words (+15%): Increase vocabulary diversity.
- Fluency Optimization (+15-30%): Improve readability and flow.
- Avoid keyword stuffing (-10%).
- Best combination: Fluency + Statistics.

### Weighted GEO Analysis Criteria
1. Citability Score (25%): Optimal passage length 134-167 words. Use clear, quotable sentences with specific facts. Provide self-contained answer blocks. Put the direct answer in the first 40-60 words. Attribute claims with specific sources. Use "X is..." or "X refers to..." definitions. Include unique data points.
2. Structural Readability (20%): Use clean H1->H2->H3 hierarchy. Use question-based headings. Keep paragraphs to 2-4 sentences. Use tables for comparative data. Use lists for step-by-step or multi-item content. Include FAQ sections with clear Q&A format.
3. Multi-Modal Content (15%): Include text + relevant images, video, infographics, charts, and interactive elements. Add structured data supporting media.
4. Authority & Brand Signals (20%): Include author byline with credentials, publication and last-updated dates, citations to primary sources, organization credentials, expert quotes with attribution, and entity presence in Wikipedia, Wikidata, Reddit, YouTube, and LinkedIn. Note that brand mentions correlate 3x more strongly with AI visibility than backlinks.
5. Technical Accessibility (20%): Ensure server-side rendering (AI crawlers do not execute JavaScript). Verify AI crawler access in robots.txt. Check llms.txt and RSL 1.0.

### Platform-Specific Optimization
- Google AI Overviews: Focus on top-10 ranking pages (92% of citations) and passage optimization.
- ChatGPT: Focus on entity presence and authoritative sources (Wikipedia 47.9%, Reddit 11.3%).
- Perplexity: Focus on community validation and discussions (Reddit 46.7%, Wikipedia).
- Bing Copilot: Focus on Bing index and authoritative sites.

## Step 4: Traditional SEO Optimization
1. Optimize meta tags (title, description, Open Graph, Twitter Cards) using the template: title with primary keyword and brand, description 150-160 chars, og:image 1200x630.
2. Add JSON-LD schema markup: WebPage/Article for content, FAQPage for FAQs, Product for products, Organization for about pages, SoftwareApplication for tools.
3. Check content: H1 contains primary keyword, images have alt text, internal links to related content, external links have rel="noopener noreferrer", mobile-friendly, page loads in < 3 seconds.

## Step 5: Validate & Monitor
1. Validate schema using Google Rich Results Test and Schema.org Validator.
2. Check indexing status via site: queries on Google and Bing.
3. Generate a report covering audit findings, GEO scores, keyword opportunities, and recommended actions.
