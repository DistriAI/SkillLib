# Keyword Research

## 1. Scope & Context
- Clarify product/service, target audience, business goal, site domain authority (DR), geography, and language.
- If a project context file (e.g., `contextus.md`) exists, read it and load only relevant modules.
- Identify available tool access: Google Keyword Planner, Google Trends, SEO tools, Search Console, or MCP connectors.

## 2. Discovery
- **Seed Expansion**: Start with core, problem, solution, audience, and industry terms.
- **Manual Methods**:
  - **Alphabet Autocomplete**: Type seed + space + each letter (a-z, 0-9) to capture long-tail queries with real traffic.
  - **Position Variants**: Try prefix (`a keyword`), suffix (`keyword a`), and middle (`how to keyword a`) patterns.
  - **Question Modifiers**: Use `how to`, `what is`, `why`, `vs`, `for beginners`, etc.
  - **PAA & Related Searches**: Extract high-value signals from Google People Also Ask and Related Searches.
  - **Competitor Reverse**: Analyze competitor titles, H1s, and URLs to find topics they rank for (positions 4-10 are opportunities).
  - **User Feedback**: Mine support tickets, reviews, and community forums (Reddit, Quora) for unmet search demand.
- **Tool-Based Methods** (if available):
  - **Ryze MCP**: Use `google_ads__generateKeywordIdeas` to collect up to ~200 ideas.
  - **GSC Striking Distance**: If Search Console is connected, mine query data for terms already ranking in positions 5-20. These are proven demand and the fastest opportunity set.
  - **Keyless Helpers**: Use local scripts for Google Autocomplete expansion, Firecrawl for live SERP sampling (to see who ranks), and Wikipedia pageviews for topic demand/seasonality proxies.

## 3. Classification & Intent
- Tag each keyword by intent: Informational, Navigational, Commercial, or Transactional.
- **Intent Signals**:
  - Informational: "how," "what," "guide," "tutorial."
  - Commercial: "best," "compare," "vs," "review."
  - Transactional: "buy," "price," "coupon," "free shipping."
- **SERP Check**: Search the term to verify intent. Knowledge cards suggest informational; product lists suggest commercial; brand sites suggest navigational.

## 4. Scoring & Evaluation
- **Metrics**: Assign search volume, keyword difficulty (1-100), and CPC (if available).
- **Evidence Labels**: Label every metric as **Measured** (tool/export), **User-provided**, **Calculated**, **Estimated**, **Proxy**, or **Unknown**. Never invent volumes; if data is missing, mark it Unknown with a reason.
- **Opportunity Score**: Compute `Opportunity = (Volume × Intent Value) / Difficulty`. Use Intent Values: Informational=1, Navigational=1, Commercial=2, Transactional=3.
- **GEO-Check**: Flag AI-answer-friendly queries (questions, definitions, comparisons, lists, how-tos) for Generative Engine Optimization.

## 5. Clustering & Topical Map
- Group keywords into pillar (hub) and cluster (spoke) topic hubs.
- **Clustering Methods**:
  - **SERP Overlap**: Keywords with overlapping top-ranking pages belong in the same cluster.
  - **Semantic**: Group by meaning and related concepts.
  - **Intent-Based**: Separate pages if intent differs within a cluster.
- For each cluster, identify the target keyword, supporting keywords, total volume, and whether an existing page should be optimized or a new page created.

## 6. Deliverable
- **Executive Summary**: High-level findings and top opportunities.
- **Prioritized Plan**: Rank clusters by volume × winnability. Favor clusters where the site already has striking-distance positions (5-20).
- **Cluster Tables**: One table per cluster showing keyword, volume, CPC, intent, and current position.
- **Quick Wins / Growth / GEO Opportunities**: Name at least 3 specific opportunities in each category.
- **Next Steps**: Recommend the next skill (e.g., competitor-analysis or content-strategy) based on the keyword set.
