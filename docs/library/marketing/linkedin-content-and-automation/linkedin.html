# LinkedIn Marketing & Automation

This skill covers three distinct areas of LinkedIn interaction: content creation, content operations, and account automation.

## 1. Content Creation & Optimization
Use this section when the user wants to write or optimize LinkedIn post copy.

- **Post Types**: Choose the right format (Text, Photo, Video, Article, Document, Poll, Newsletter) based on the goal. Match CTA and length to the form.
- **Platform Positioning**: Maintain a professional tone suitable for B2B networking and career identity.
- **Feed Ranking**: Optimize for the first line (hook) and on-topic depth. Avoid engagement bait and inauthentic patterns.
- **SEO/GEO**: Use the Headline and About section for search visibility. Note that short feed posts are login-gated and not indexed by search engines, while Articles and Profiles are.

## 2. Content Operations (Drafting & Publishing)
Use this section when the user wants to plan, draft, audit, or publish content using the Publora API.

- **Workflow**: Follow the Draft → Approval → Publish pattern.
- **Tools**: Use specific sub-skills for writing (`linkedin-post-writer`), commenting (`linkedin-comment-drafter`), and auditing (`linkedin-humanizer`).
- **Publishing**: Use the Publora API for auto-posting. Ensure `PUBLORA_API_KEY` and `LINKEDIN_PLATFORM_ID` are configured in `.env`.
- **Founders Edition**: If the user is a founder, use the dedicated founder angles and structural formulas from `references/founder-topics.md`.

## 3. Account Automation (CLI)
Use this section when the user wants to search, fetch data, send messages, or manage connections via the `linkedin` CLI.

- **Setup**: Install `@linkedapi/linkedin-cli` and configure tokens using `linkedin setup`.
- **Commands**: Use `linkedin person fetch`, `linkedin company search`, `linkedin message send`, etc.
- **Output**: Always use `--json -q` for machine-readable output.
- **Error Handling**: Check exit codes and the `success` field in JSON responses. Exit code 2 indicates authentication issues.

## Conflicts
- **Publishing Method**: `kostja94` does not specify an API, `sergebulaev` uses Publora, and `LeoYeAI` uses Linked API. Choose the method based on the user's existing setup or preference.
- **Scope**: `kostja94` is copy-only, `sergebulaev` is content-ops, and `LeoYeAI` is data/automation. Do not mix these workflows unless the user explicitly requests a combined action (e.g., "Find 10 engineers and send them a personalized message based on this post copy").
