# SocialClaw

SocialClaw is a workspace-scoped social publishing service at `https://getsocialclaw.com` that allows scheduling and publishing posts across 13 platforms (X, LinkedIn, Instagram, Facebook Pages, TikTok, Discord, Telegram, YouTube, Reddit, WordPress, Pinterest) using a single workspace API key.

## Runtime Requirements

- A valid SocialClaw workspace API key.
- CLI (optional): `npm install -g socialclaw` or `npm install socialclaw@0.1.12`.
- Active trial or paid plan required for CLI/API execution.

## Configuration

Set your workspace API key in your environment. Note that different documentation sources may use different variable names; verify which one your installed CLI version expects:

```bash
# Option A (from davepoon/buildwithclaude)
export SC_API_KEY="<workspace-key>"

# Option B (from sickn33/agentic-awesome-skills)
export SOCIALCLAW_API_KEY="<workspace-key>"
```

Get your API key at [getsocialclaw.com](https://getsocialclaw.com).

## Workflow

### Step 1: Authenticate

```bash
socialclaw login --api-key <workspace-key>
# or
socialclaw login
```

### Step 2: Manage Accounts

List connected accounts:
```bash
socialclaw accounts list --json
```

Connect a new account (requires browser OAuth):
```bash
socialclaw accounts connect --provider x --open
```

### Step 3: Create a Campaign

Define your campaign with target platforms, content, and schedule in a JSON file (e.g., `schedule.json`).

### Step 4: Upload Media (Optional)

Upload images or videos to attach to posts:
```bash
socialclaw assets upload --file ./image.png --json
```

### Step 5: Validate Schedule

Confirm platform-specific timing rules are met (e.g., rate limits, posting windows):
```bash
socialclaw validate -f schedule.json --json
```

### Step 6: Publish or Schedule

**Safety Constraint:** Treat every publish, schedule, delete, or account-changing action as state-changing. Show the target platforms, content, media, and timing to the user, then wait for explicit user confirmation before proceeding.

Apply the schedule:
```bash
socialclaw apply -f schedule.json --json
```

Check run status:
```bash
socialclaw status --run-id <id> --json
```

### Step 7: Analytics

Retrieve post performance metrics after publishing:
```bash
socialclaw posts list --json
socialclaw analytics post --post-id <id> --json
socialclaw workspace health --json
```

## Limitations

- Requires a valid SocialClaw workspace API key; do not attempt publishing without explicit user-provided credentials.
- Platform availability, rate limits, analytics fields, and scheduling behavior depend on the upstream SocialClaw service.
- This skill describes the publishing workflow; it does not replace platform-specific compliance, brand review, or legal approval before posting.
