# Email Campaign Skill

This skill covers the full lifecycle of an email campaign: acquiring and verifying the audience list, and writing the campaign content.

## Part 1: List Building & Verification

Use the Gooseworks API to find, verify, and enrich email addresses.

### Setup
Read credentials from `~/.gooseworks/credentials.json`:
```bash
export GOOSEWORKS_API_KEY=$(python3 -c "import json;print(json.load(open('$HOME/.gooseworks/credentials.json'))['api_key'])")
export GOOSEWORKS_API_BASE=$(python3 -c "import json;print(json.load(open('$HOME/.gooseworks/credentials.json')).get('api_base','https://api.gooseworks.ai'))")
```

### Workflow
1. **Find Emails by Domain**: Use `hunter` API `/v2/domain-search`.
2. **Find Specific Person**: Use `hunter` API `/v2/email-finder`.
3. **Verify Emails**: Use `hunter` API `/v2/email-verifier` or `fiber` API `/v1/validate-email/single`.
4. **Enrich for Personalization**: Use `sixtyfour` API `/enrich-lead`.
5. **Get Company Context**: Use `brand-dev` API `/v1/brand/retrieve`.

## Part 2: Campaign Content & Sequencing

Write the actual email content for the verified list.

### Required Inputs
- **Campaign goal** (onboard, launch, nurture, re-engage)
- **Audience** (job title, lifecycle stage)
- **Product/offer**
- **Number of emails** (default: Onboarding=4, Launch=3, Nurture=5, Re-engage=3)
- **Tone**
- **Sender name**

### Output Structure Per Email
For each email in the sequence, produce:
- **Send timing**
- **Subject line** (under 50 chars) and **A/B variant**
- **Preview text** (40-90 chars, distinct from subject)
- **Body** (2-3 short paragraphs, one primary CTA)
- **CTA button text** and **destination**
- **Strategic note** (intent of the email)

### Writing Rules
- One primary CTA per email.
- Opening line must earn attention (no generic greetings).
- Use "you" more than "we".
- Each email must stand alone.
- Preview text must not repeat the subject line.
