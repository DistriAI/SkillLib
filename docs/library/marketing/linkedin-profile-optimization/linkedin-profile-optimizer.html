# LinkedIn Profile Optimizer

## When to Use
Use this skill when the user wants to optimize their LinkedIn profile for job searching, client acquisition, or authority building. Triggers include "review my profile", "rewrite my headline", or "optimize LinkedIn".

## Input & Intake
1. **Collect Source Material:** Ask for the profile text (Headline, About, Experience) or a PDF export. If the user provides only a URL, ask for the text or PDF, as the profile cannot be fetched directly. Also request a CV/resume and any portfolio links.
2. **Determine Goal:** Identify if the goal is **clients**, **job seeking**, or **authority**. This determines the Featured section and CTA strategy.
3. **Expand Context:** Cross-reference the provided sources (LinkedIn, CV, Portfolio) to find a consistent "Red Thread" or throughline in the person's work. If sources conflict, ask the user to clarify.

## Optimization Steps
1. **Photo & Banner:** Ensure the photo is a professional headshot (face fills 60% of frame) and the banner is 1584x396 pixels with a clear value proposition.
2. **Headline:** Rewrite using the formula `[What You Do] | [Who You Help] [Achieve What Result]`. Use all 220 characters. Include keywords recruiters search for.
3. **About Section:** Rebuild using a 7-step structure or a hook-achievements-CTA format. Ensure the first 265-275 characters act as a strong hook before the "see more" fold. Use first-person voice.
4. **Experience:** Rewrite bullets as `action verb + specific metric`. Add 5+ skills per role. Attach media where possible.
5. **Skills:** List up to 50 skills. Pin the top 3 that mirror the target job description or client needs.
6. **Featured Section:** Curate 3 items matched to the goal:
   - **Clients:** Lead magnet + case study + calendar link.
   - **Job Seeking:** Portfolio + work samples + top post.
   - **Authority:** Best content + media features + newsletter.
7. **Custom URL & Recommendations:** Ensure the URL is `linkedin.com/in/firstnamelastname`. Draft specific recommendation requests.

## Output Format
*Note: The user may prefer a visible audit or a silent rewrite. Default to a visible audit unless the user requests a "silent" or "ready-to-paste" result.*

**Option A: Visible Audit (Default)**
1. **Scorecard:** Pass/fail/needs-work for 9 sections.
2. **Priority Fixes:** Ranked by impact.
3. **Before → After:** Rewrites for each failing section.
4. **Expected Uplift:** Based on benchmarks (e.g., 3.9x more views).

**Option B: Silent Rewrite**
1. **Final Profile:** Deliver only the finished, ready-to-paste text for each section.
2. **No Critique:** Do not list what was wrong with the original.

## Hard Rules
- Use first-person voice ("I help...").
- Avoid AI-sounding vocabulary ("passionate thought leader", "results-oriented").
- Never fabricate roles or metrics; ask for clarification if data is missing.
- Do not infer profile content from the URL slug alone.
