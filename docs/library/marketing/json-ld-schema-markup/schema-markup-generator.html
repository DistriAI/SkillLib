# Schema Markup Generator

## When to Use
- Use when asked to add schema markup, generate structured data, JSON-LD, rich snippets, FAQ schema, product markup, or any structured data task.
- Use when adding or auditing JSON-LD schema for websites, SaaS apps, tools, articles, FAQs, breadcrumbs, or organization pages.
- Use when schema must be implemented in Next.js App Router or validated against Google Rich Results and Schema.org tooling.

## Implementation in Next.js App Router

Create a reusable JsonLd component:

```jsx
// components/JsonLd.jsx
export function JsonLd({ data }) {
  const json = JSON.stringify(data).replace(/</g, '\\u003c');
  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: json }}
    />
  );
}
```

Use it in any page:

```jsx
import { JsonLd } from '@/components/JsonLd';

export default function MyPage() {
  return (
    <>
      <JsonLd data={mySchemaObject} />
      {/* rest of page */}
    </>
  );
}
```

## Schema Types by Page Type

### WebSite + Sitelinks Searchbox (homepage only)
Provide a WebSite schema with name, url, description, and a potentialAction SearchAction with urlTemplate and query-input.

### SoftwareApplication (tool / SaaS app pages)
Provide a SoftwareApplication schema with name, applicationCategory, operatingSystem, url, description, offers, featureList, and provider.

### Article / BlogPosting (blog posts)
Provide a BlogPosting schema with headline, description, url, datePublished, dateModified, author, publisher, image, and mainEntityOfPage.

### FAQPage (FAQ sections, tool help pages)
Provide a FAQPage schema with a mainEntity array of Question objects, each with name and acceptedAnswer.

### HowTo (step-by-step tool guides)
Provide a HowTo schema with name, description, totalTime, and a step array of HowToStep objects with position, name, text, and optional image.

### BreadcrumbList (all non-homepage pages)
Provide a BreadcrumbList schema with an itemListElement array of ListItem objects with position, name, and item.

### Product
Provide a Product schema with name, description, image, sku, brand, and offers.

### LocalBusiness
Provide a LocalBusiness schema with name, address, geo, openingHoursSpecification, and telephone.

## Validation
- Validate generated JSON-LD against Google Rich Results Test and Schema.org validator.
- Ensure all required properties for the chosen schema type are present.
- Verify that the JSON is valid and properly escaped for HTML embedding.
