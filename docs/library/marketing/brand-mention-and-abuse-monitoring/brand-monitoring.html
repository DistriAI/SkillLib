# Brand Monitoring

Use this skill when the user wants to monitor brand mentions, detect trademark infringement, set up brand monitoring, or track brand sentiment. For enforcement, takedown, or evidence collection, use a brand-protection skill.

## Initial Assessment

1. Read root contextus.md when present and load only relevant modules. Without it, use available project material or user-provided facts and ask for missing information.
2. Identify scope: domains, social media, marketplaces, paid search, app stores, web, dark web, and mention platforms such as Reddit, Google News, YouTube, and DuckDuckGo.
3. Identify budget: manual vs automated; DIY vs vendor.
4. Identify risk level: high-value brand, prior incidents, or preventive.

## What to Monitor

| Channel | Threats / Signals |
|---------|-------------------|
| Domains | Typosquatting, brand+ai, brand+app, impersonation sites |
| Social media | Fake accounts, impersonation, unauthorized use, brand mentions |
| Marketplaces | Counterfeit products, unauthorized sellers (Amazon, eBay, Temu) |
| Paid search | Competitors bidding on brand terms; impersonator ads |
| App stores | Fake apps, trademark misuse |
| Web | Phishing sites, spoofed pages |
| Mention platforms | Reddit, Google News, YouTube, DuckDuckGo mentions, sentiment, trends |

## Manual Monitoring

| Method | Frequency |
|--------|-----------|
| Search | Brand name + variants (brand+ai, brand+app, brand+official) |
| Google Alerts | Brand name, product names |
| Social search | X, LinkedIn, Instagram for brand mentions |
| Marketplace search | Amazon, eBay for counterfeit listings |

Document findings. Escalate to brand-protection for takedown when infringement is confirmed.

## Automated Mention Monitoring

Use the provided script when available:

```bash
python3 scripts/monitor.py "YourBrand"
```

With competitors and platform selection:

```bash
python3 scripts/monitor.py '{
  "brand": "YourBrand",
  "competitors": ["CompA", "CompB"],
  "platforms": ["reddit", "google_news"]
}'
```

Demo mode:

```bash
python3 scripts/monitor.py --demo
```

Supported platforms and stability:

| Platform | Method | Stability |
|----------|--------|-----------|
| Reddit | Public JSON API | Rate limited |
| Google News | RSS Feed | Stable |
| DuckDuckGo | Instant Answer API | Stable |
| YouTube | HTML/RSS | Unstable |

Analysis dimensions:

| Dimension | Method | Output |
|-----------|--------|--------|
| Volume | Mention count | Trend graph |
| Sentiment | NLP analysis | Sentiment score |
| Sources | Platform breakdown | Source distribution |
| Keywords | Topic extraction | Word cloud |
| Competitors | Share of voice | Comparison chart |

## Automated Brand-Abuse Tools

| Capability | Description |
|------------|-------------|
| AI detection | Machine learning, image recognition, NLP to detect abuse across channels |
| Multi-channel | Domains, social, marketplaces, paid search, dark web |
| Enforcement | Case management, takedown workflows, platform integrations |
| Trademark watch | USPTO, trademark office monitoring; litigation insights |

Vendor types: BrandShield, Tracer Protect, CompuMark, CounterFind. Evaluate by coverage, enforcement rate, and budget.

## Monitoring Cadence

| Level | Cadence | Use |
|-------|---------|-----|
| Basic | Weekly search; Google Alerts | Low-risk; preventive |
| Standard | Daily alerts; monthly marketplace check | Moderate risk |
| Enterprise | Real-time monitoring; dedicated vendor | High-value brand; prior incidents |

## Crisis Detection

| Alert Level | Trigger | Action |
|-------------|---------|--------|
| Normal | < 20% negative | Continue monitoring |
| Warning | 20-40% negative | Investigate sources |
| Crisis | > 40% negative | Immediate response needed |

## Monitoring Workflow

1. Set up brand keywords and variants.
2. Monitor selected channels and platforms.
3. Analyze sentiment and mention volume.
4. Detect anomalies, negative spikes, or abuse signals.
5. Generate alerts and reports.
6. Escalate confirmed infringement to brand-protection.

## Output Format

- Monitoring plan: channels, cadence, tools.
- Search queries: brand + variants for manual check.
- Alert setup: Google Alerts, social, mention-platform alerts.
- Mention report: total mentions, platform breakdown, sentiment, trend, keywords, competitor comparison.
- Escalation path: when to use brand-protection for takedown.
