# Competitor Research

Select the appropriate research track based on the user's goal:

## 1. SEO & Content Gap Analysis
Use when the user wants to improve organic traffic or content.
- **Tools**: Ahrefs, Semrush, SimilarWeb.
- **Steps**:
  1. Identify competitors ranking for target keywords.
  2. Perform a 'Link Gap' analysis to find sites linking to competitors but not the user.
  3. Analyze top-ranking content for word count, H2 structure, and content gaps.
  4. Output: Keyword opportunities, content briefs, and outreach targets.

## 2. Business & Growth Intelligence
Use when the user wants to understand a competitor's market position, pricing, or growth strategy.
- **Tools**: Public web search, browser, or supplied materials.
- **Steps**:
  1. Define the research question (e.g., 'How did X acquire users?').
  2. Gather evidence from the competitor's site, changelogs, and independent news.
  3. Distinguish between observed facts, attributed claims, and hypotheses.
  4. Output: A cited brief with a supported timeline and 1-3 testable experiments for the user.

## 3. API-Driven Data Scraping (Gooseworks)
Use when the user has a Gooseworks API key and wants automated data extraction.
- **Setup**: Load credentials from `~/.gooseworks/credentials.json`.
- **Steps**:
  1. Use the `brand-dev` API to retrieve company overview.
  2. Use the `exa` API to find similar companies.
  3. Use the `scrapegraph` API to extract pricing and features from specific pages.
  4. Output: Structured JSON data on products, pricing, and team.
