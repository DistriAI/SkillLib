# State Machine

This skill covers two complementary approaches to handling UI component states: conceptual modeling and visual inspection.

## 1. Conceptual Modeling (Specification)
Use this when defining the behavior of a component to ensure exhaustiveness and predictability.

1. **Identify Components**: Define States (modes), Events (triggers), Transitions (rules), Actions (side effects), and Guards (conditions).
2. **Model the Flow**:
   - List all possible states.
   - List all events/triggers.
   - Define valid transitions.
   - Identify and prevent impossible states.
   - Add guards for conditional transitions.
   - Define entry/exit actions.
3. **Best Practices**:
   - Start with the happy path, then add error states.
   - Ensure every state has an exit (no dead ends).
   - Keep machines focused (one per concern).
   - Document with visual diagrams.

## 2. Visual Inspection (Implementation)
Use this when you need to see and debug a specific component's states in the browser.

1. **Scope**: Select one component. Restate its purpose and data source.
2. **Find States**: Read the code to identify existing branches (Data, Account, Feature). Do not add states the code cannot reach.
3. **Build Throwaway Page**:
   - Create a scratch route inside the app (client-side if using Next.js).
   - Import the real component; do not rebuild it.
   - Keep the page, fixtures, and switcher in one folder for easy deletion.
4. **Feed Data**:
   - Supply mock data at the data boundary (props or app data seam).
   - Use product-shaped data (real names, timestamps, counts).
   - Keep loading states pending until the switcher moves.
5. **Add Switcher**:
   - Add a grouped list or select to flip between states via a search param (e.g., `__state`).
   - Keep the switcher visually distinct from the design system.
6. **Verify & Handover**:
   - Load the page and flip through every state to ensure mock data renders.
   - Hand over the URL and state list.
7. **Cleanup**:
   - Delete the page folder and any approved seams when done.
   - Search for remaining references to ensure clean removal.
