# DepMap — Cancer Dependency Map

## When to use

Use this skill to rank dependencies in cancer models, compare prespecified biomarker cohorts, inspect co-essentiality, or relate genetic dependencies to PRISM compound response. These analyses generate target and synthetic-lethality hypotheses; they do not establish clinical efficacy.

## 1. Discover a release, then obtain its files

**Do not use the legacy API endpoints** (`/api/gene`, `/api/data/gene_dependency`) as they are not verified for current releases. Instead, use the verified public endpoint to discover the latest release and file metadata.

1. **Fetch Catalogue**: Use `GET https://depmap.org/portal/api/no-captcha/download/files` to get the CSV catalogue.
2. **Select Release**: Identify the latest `DepMap Public` release (e.g., 26Q1). Note that recent releases may have blank `url` fields in the catalogue; you must obtain files via the DepMap Portal UI if direct links are missing.
3. **Verify Integrity**: Always verify the `md5_hash` of downloaded files against the catalogue. If a checksum is missing, record a local SHA-256 and note the discrepancy.

```python
from scripts.depmap_data import fetch_catalogue, select_file, verify_md5

catalogue = fetch_catalogue()
public = catalogue[catalogue["release"].str.startswith("DepMap Public ")]
release = public["release"].iloc[0] # Select latest
record = select_file(catalogue, release, "CRISPRGeneEffect.csv")
# Download file from portal if record['url'] is blank
```

## 2. Inspect File Contracts

Key files in the release:
- `CRISPRGeneEffect.csv`: Integrated Chronos effects. Rows are `ModelID`, columns are `Symbol (EntrezID)`.
- `Model.csv`: Metadata keyed by `ModelID` (includes `CellLineName`, `OncotreeLineage`, etc.).
- `OmicsExpressionTPMLogp1HumanProteinCodingGenes.csv`: Expression data. Exclude metadata columns from calculations.

## 3. Analyze Dependencies

Load the local CSVs into pandas. 

**Score Interpretation:**
- **Chronos**: More negative = more essential.
- **Thresholds**: 
  - `<= -0.5`: Likely dependent.
  - `<= -1.0`: Strongly dependent (common essential range).

### Identifying Selective Dependencies

```python
import pandas as pd
import numpy as np

def find_selective_dependencies(gene_effect_df, model_df, target_gene, 
                                 cancer_type=None, threshold=-0.5):
    """Find cell lines selectively dependent on a gene."""
    if target_gene not in gene_effect_df.columns:
        return None

    scores = gene_effect_df[target_gene].dropna()
    dependent = scores[scores <= threshold]

    result = pd.DataFrame({
        "ModelID": dependent.index,
        "gene_effect": dependent.values
    }).merge(model_df[["ModelID", "CellLineName", "OncotreePrimaryDisease"]], on="ModelID")

    if cancer_type:
        result = result[result["OncotreePrimaryDisease"].str.contains(cancer_type, case=False, na=False)]

    return result.sort_values("gene_effect")
```
