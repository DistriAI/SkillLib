# Molfeat — Small-molecule featurization

## When to use
Use this skill to turn SMILES or RDKit molecules into fingerprints, descriptors, pharmacophores, or pretrained embeddings for QSAR/QSPR, chemical similarity, virtual screening, and molecular ML. Compare representations on the same molecular split and assay endpoint.

## Installation
Create an isolated environment. Pin the Molfeat version you intend to use and install only the extras you need with the same interpreter. Core fingerprints run offline; pretrained inference may download substantial weights, so check model licensing, disk space, and device requirements first.

```bash
uv venv --python 3.13 .venv-molfeat
uv pip install --python .venv-molfeat/bin/python "molfeat==1.0.0"
```

On Windows use `.venv-molfeat\Scripts\python.exe` as the interpreter path. Let Molfeat's platform markers resolve platform-specific constraints; do not copy pins from one platform to another.

## Workflow
1. Preserve source record IDs, labels, original structures, and a declared policy for salts, stereochemistry, tautomers, charge, and duplicate compounds. Standardization changes chemical identity; apply the same policy to training and prediction.
2. Start with an explicit ECFP baseline. A calculator processes one molecule; `MoleculeTransformer` batches it. `datamol.Mol` is RDKit's molecule type.
3. Record rejected positions and align every associated array. Inspect descriptor NaN/Inf separately: successful parsing does not guarantee finite features.
4. Fit any feature selection, imputation, scaling, and model inside the training fold. Prefer scaffold/group or temporal splits appropriate to the scientific question; random splits can leak close analogues or repeated measurements.
5. Save the featurizer state, ordered feature names, package versions, molecular preprocessing policy, and input IDs. Revalidate old state after migrating versions.

### Fingerprint baseline and invalid records

```python
import numpy as np
from molfeat.calc import FPCalculator
from molfeat.trans import MoleculeTransformer

smiles = ["CCO", "invalid", "CC(=O)O", "c1ccccc1"]
record_ids = np.array(["ethanol", "rejected", "acetate", "benzene"])
y = np.array([0.1, 9.9, 0.2, 0.3])  # toy labels only
calc = FPCalculator("ecfp", radius=2, fpSize=2048, includeChirality=True)
transformer = MoleculeTransformer(calc, n_jobs=1, dtype=np.float32)
X, valid_ids = transformer(smiles, ignore_errors=True)
assert X.shape == (3, 2048)
X_ids, y_valid = record_ids[valid_ids], y[valid_ids]
assert valid_ids == [0, 2, 3]
assert np.isfinite(X).all()
```

`ignore_errors` belongs on the call, not the constructor. With `True`, `__call__` returns filtered features and original input positions; with `False`, it raises on failed molecules. `transform(..., ignore_errors=True)` preserves positions using `None` for failures. Never filter each feature block independently and then concatenate.

ECFP radius is a bond radius: `radius=2` means ECFP4; radius 3 means ECFP6. In 1.0.0 `FPCalculator("ecfp")` defaults to radius 2 and 2048 bits. `FPVecTransformer` has a different default length of 2000, so specify `length=2048` when using it.

### Configuration round trip

```python
transformer.to_state_yaml_file("featurizer.yml")
loaded = MoleculeTransformer.from_state_yaml_file("featurizer.yml")
np.testing.assert_array_equal(loaded(["CCO"]), transformer(["CCO"]))
```

Load only trusted configuration/artifacts. State can identify Python classes and custom serialized callables; YAML/JSON does not make arbitrary third-party state safe. State saves configuration, not assay labels, preprocessing decisions, or a trained QSAR model.

### Pretrained embeddings

Use the concrete adapter for the model family you need. Embedding width depends on checkpoint, pooling, and selected layers; do not assume a fixed width. Inspect token lengths: truncation can change meaning.

```python
from molfeat.trans.pretrained import PretrainedHFTransformer

embedder = PretrainedHFTransformer(
    kind="ChemBERTa-77M-MLM", pooling="mean", concat_layers=-1,
    device="cpu", max_length=128, preload=False,
)
# First inference downloads/loads the model.
# embeddings = embedder(["CCO", "c1ccccc1"])
```

`PretrainedMolTransformer` is a base class, not a model-name factory. Use the concrete adapter.

## Choosing the right featurizer

### For traditional machine learning (RF, SVM, XGBoost)
Start with fingerprints:

```python
# ECFP - Most popular, general-purpose
FPCalculator("ecfp", radius=2, fpSize=2048)

# MACCS - Fast, good for scaffold hopping
FPCalculator("maccs")
```

For interpretable models:

```python
# RDKit 2D descriptors (200+ named properties)
from molfeat.calc import RDKitDescriptors2D
RDKitDescriptors2D()

# Mordred (1800+ comprehensive descriptors)
from molfeat.calc import MordredDescriptors
MordredDescriptors()
```

Combine multiple featurizers:

```python
from molfeat.trans import FeatConcat

concat = FeatConcat([
    FPCalculator("maccs"),      # 167 dimensions
    FPCalculator("ecfp")         # 2048 dimensions
])  # Result: 2215-dimensional combined features
```

### For deep learning
Use transformer-based embeddings via the concrete pretrained adapter. Graph neural network and Graphormer adapters are available in older Molfeat releases; verify they exist in the version you installed before using them.

### For similarity searching
Use ECFP for general-purpose similarity, MACCS for fast scaffold-based similarity, or MAP4 for efficient large-database screening where available in your Molfeat version.
