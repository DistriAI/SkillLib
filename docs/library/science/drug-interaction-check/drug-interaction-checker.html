# Drug Interaction Checker

Check for interactions between multiple medications, including severity classification and mechanism explanations.

## When to Use

- Reviewing patient medication lists.
- Prescribing new medications.
- Pharmacovigilance monitoring.
- Any task requiring explicit assumptions, bounded scope, and a reproducible output format.

## Workflow

1. Confirm the user objective, required inputs (list of drug names), and non-negotiable constraints before doing detailed work.
2. Validate that the request matches the documented scope and stop early if the task would require unsupported assumptions.
3. Run the packaged script with the validated inputs:
   - aipoch path: `python scripts/main.py --drugs "Warfarin" "Aspirin" "Ibuprofen"`
   - FreedomIntelligence path: `python3 Skills/Pharma/Drug_Interaction/impl.py --drugs "Warfarin, Aspirin"`
4. Return a structured result that separates assumptions, deliverables, risks, and unresolved items.
5. If execution fails or inputs are incomplete, switch to the fallback path and state exactly what blocked full completion.

## Severity Levels

| Level | Description | Action Required |
|-------|-------------|-----------------|
| Critical | Life-threatening interaction | Absolute contraindication |
| Major | Significant risk, may need medical intervention | Avoid combination or monitor closely |
| Moderate | Moderate risk, may require dose adjustment | Monitor for adverse effects |
| Minor | Mild interaction, unlikely to cause issues | Be aware, usually acceptable |
| Unknown | Insufficient data | Proceed with caution |

## Output Format

Return a JSON object with the following structure:

```json
{
  "drugs_checked": ["Drug A", "Drug B"],
  "interactions": [
    {
      "drug_pair": ["Drug A", "Drug B"],
      "severity": "Major",
      "mechanism": "Pharmacodynamic synergism...",
      "effect": "Increased bleeding risk",
      "recommendation": "Avoid combination or monitor INR closely"
    }
  ],
  "summary": {
    "critical": 0,
    "major": 1,
    "moderate": 0,
    "minor": 0
  }
}
```

## Parameters

| Parameter | Type | Default | Required | Description |
|-----------|------|---------|----------|-------------|
| `--drugs` | list | - | Yes | List of drug names (generic or brand names accepted) |
| `--format` | string | text | No | Output format (text, json, markdown) |
| `--include-mechanism` | flag | true | No | Include pharmacological mechanism |
| `--include-management` | flag | true | No | Include clinical recommendations |
| `--output`, `-o` | string | - | No | Output file path |

## Data Sources

This skill uses a curated drug interaction database. The database includes FDA-approved drug interaction data and known metabolic pathways (CYP450 enzymes).

## Measurable Outcome

Execute skill workflow successfully with valid output within 15 minutes.
