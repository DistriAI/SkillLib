# Physics

This skill covers two distinct domains: Unity physics configuration and physics research.

## 1. Unity Physics (Editor)
Use this section for Unity editor-time physics queries and configuration.

- **Queries**: Use `physics_raycast`, `physics_check_overlap`, `physics_get_gravity`, or `physics_get_layer_collision` for read-only operations.
- **Configuration**: Use `physics_set_gravity`, `physics_create_material`, `physics_set_material`, or `physics_set_layer_collision` for changes (requires user grant in SemiAuto mode).
- **Components**: Do not use non-existent skills like `physics_add_rigidbody`. Use the `component` module to add Rigidbody or Collider components.
- **Simulation**: This module does not run physics simulation. Simulation only occurs in Play mode.

## 2. Physics Research
Use this section for research tasks involving simulations, astronomical data, or computational methods.

- **Astrophysics**: Use `astrophysics-data-guide` for Astropy, FITS files, and sky surveys.
- **Computational Physics**: Use `computational-physics-guide` for simulation methods and research tools.
- **Literature**: Use `nasa-ads-api` to search the NASA ADS bibliographic database.
- **Particle Physics**: Use `particle-physics-guide` for ROOT, HEPData, and event processing.
- **Quantum Computing**: Use `quantum-computing-guide` for Qiskit and Cirq frameworks.
