# Spatial Multi-omics Analysis

## 1. High-Resolution Spatial Analysis (Squidpy)
Use this section for subcellular or high-density data (Slide-seq, Stereo-seq, Visium HD).

```python
import squidpy as sq
import scanpy as sc

# Load spatial data
adata = sc.read_h5ad('spatial_multiomics.h5ad')

# Spatial neighbors
sq.gr.spatial_neighbors(adata, coord_type='generic', n_neighs=10, spatial_key='spatial')

# Spatial autocorrelation
sq.gr.spatial_autocorr(adata, mode='moran', genes=adata.var_names[:100])

# Neighborhood enrichment
sq.gr.nhood_enrichment(adata, cluster_key='cell_type')
```

## 2. Multi-Modal Integration (Muon)
Use this section when integrating spatial RNA with protein or ATAC data.

### Determine Integration Regime
- **Vertical (Same-pixel):** Modalities are co-measured on the same pixels (e.g., spatial-CITE-seq, DBiT-seq). Use joint factor methods like MOFA or WNN.
- **Diagonal (Serial-section):** Modalities are from different sections (e.g., RNA on section N, ATAC on N+1). Use registration methods like PASTE or STalign. Do NOT use same-cell coupling methods.
