# LabArchives Integration

This skill covers three distinct workflows for interacting with LabArchives: API integration, academic writing, and general ELN automation. Select the appropriate section based on the user's goal.

## 1. API Integration & Authentication
Use this section when implementing direct API calls or debugging authentication.

### Regional Endpoints
- **US/International:** `https://api.labarchives.com/api`
- **Australia:** `https://auapi.labarchives.com/api`
- **UK:** `https://ukapi.labarchives.com/api`
- **Inventory API:** `https://iapi.labarchives.com` (Append `/public/v1/...` routes)

### Authentication Model
- **ELN API:** Uses signed query parameters (`akid`, `expires`, `sig`).
  1. Set `expires` to current Unix epoch in milliseconds.
  2. Concatenate: `<Access Key ID><API method name><expires>`.
  3. Compute HMAC-SHA-512 using Access Password as key.
  4. Base64-encode and URI-encode the signature.
- **Inventory API v1:** Uses signed headers (`X-LabArchives-*`).
  - Signs the exact relative route (excluding query string).
  - `GET /public/v1/users/me` exempts `X-LabArchives-LabId`.

### Configuration
- Use `scripts/setup_config.py` to validate environment variables.
- Required env vars: `LABARCHIVES_ELN_API_URL`, `LABARCHIVES_ACCESS_KEY_ID`, `LABARCHIVES_ACCESS_PASSWORD`.

## 2. Academic Writing Workflow
Use this section when converting LabArchives data into manuscript-ready text.

### Primary Outputs
- **Methods Draft:** Chronological workflow based on notebook entries.
- **Data Availability Statement:** Based on repository links and sharing constraints.
- **Reproducibility Appendix:** Based on protocol versions and software environments.
- **Experiment Timeline:** Based on dated entries and milestones.

### Workflow
1. **Validate Authorization:** Confirm the user has access to the source data.
2. **Acquire Data:** Use `scripts/notebook_operations.py` or `scripts/entry_operations.py` to export data, or use pasted text.
3. **Normalize Evidence:** Extract dates, protocol names, sample descriptors, and QC notes.
4. **Draft Output:** Write factual, audit-trail-grounded prose.
5. **Safety Pass:** Ensure every claim maps to source evidence; label missing data as missing.

### Refusal Contract
If data is missing or unauthorized, respond with:
```
Cannot generate the requested LabArchives-based writing output yet.
Reason: <missing authorization / insufficient export / incomplete metadata>
Minimum next step:
- <step 1>
```

## 3. General ELN Automation
Use this section for notebook management, backups, and entry creation.

### Notebook Operations
- **Backup:** `python3 scripts/notebook_operations.py backup --uid USER_ID --nbid NOTEBOOK_ID`
- **List Notebooks:** Use `notebooks/notebook_list` API method.

### Entry Management
- **Create Entry:** `python3 scripts/entry_operations.py create --uid USER_ID --nbid NOTEBOOK_ID --title "Title" --content "Content"`
- **Upload Attachment:** `python3 scripts/entry_operations.py upload --uid USER_ID --nbid NOTEBOOK_ID --entry-id ENTRY_ID --file /path/to/file`

### Third-Party Integrations
- **Protocols.io:** Export protocols to notebooks.
- **Jupyter/REDCap:** Use product-specific UI or file workflows; do not assume a general OAuth API.
