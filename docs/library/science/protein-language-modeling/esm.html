# ESM: Protein Generation, Embeddings, and Folding

## When to use
Use for Biohub's `esm` SDK: ESM3 masked multimodal generation, ESMC sequence representations, and ESMFold2 all-atom prediction. The former Forge platform migrated to `https://biohub.ai`. This skill targets **esm 3.4.1.post1**.

`fair-esm` is Meta's separate, older distribution. Both packages import as `esm`; install them in separate environments.

## Setup

```bash
uv venv --python 3.12 .venv-esm
uv pip install --python .venv-esm/bin/python "esm==3.4.1.post1"
```

The release declares Python >=3.12, Torch >=2.11,<2.12 and Transformers >=4.57.6,<5.

## Workflow

1. **Specify Input**: Define sequence/chain/residue mapping. Reject accidental gaps or headers in plain sequences.
2. **Choose Model**: Select local checkpoint (e.g., `esm3-sm-open-v1`) or hosted ID (e.g., `esm3-medium-2024-08`).
3. **Execute & Validate**: Check for `ESMProteinError`. Use finite timeouts. Validate output contract (length, fixed residues, confidence).
4. **Save**: Save with settings and identifiers. Avoid caches keyed only by sequence.

## ESM3 Generation

### Sequence Completion
```python
import torch
from esm.models.esm3 import ESM3
from esm.sdk.api import ESMProtein, ESMProteinError, GenerationConfig

model = ESM3.from_pretrained("esm3-sm-open-v1", device=torch.device("cpu"))
prompt = "MPRT___KEND"
completed = model.generate(
    ESMProtein(sequence=prompt),
    GenerationConfig(track="sequence", num_steps=3, temperature=0.7),
)
if isinstance(completed, ESMProteinError):
    raise completed
```

### Structure Prediction & Inverse Folding
*   **Structure**: Generate on `track="structure"` to get coordinates/PDB.
*   **Inverse Folding**: Load PDB, set `sequence=None`, generate on `track="sequence"`.

### Chain-of-Thought Generation
Iteratively refine designs by alternating tracks:
1. Generate structure from partial sequence.
2. Refine sequence based on structure.
3. Predict function.

## ESMC Embeddings

Use `EsmcForMaskedLM` and `EsmcTokenizer` for correct residue pooling. The legacy `ESMC` class is deprecated.

```python
from esm.models.esmc import EsmcForMaskedLM, EsmcTokenizer

model = EsmcForMaskedLM.from_pretrained("biohub/ESMC-300M")
tokenizer = EsmcTokenizer.from_pretrained("biohub/ESMC-300M")
# Use tokenizer to process sequence, then model for embeddings
```
