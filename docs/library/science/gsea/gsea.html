# GSEA Analysis

## 1. Statistical Foundation
Before running GSEA, ensure the input is a **named vector** of genes sorted **decreasingly** by a signed, variance-calibrated statistic (e.g., DESeq2 `stat` or limma `t`). Do not use raw p-values, as they erase directionality. 

**Critical Choices:**
- **Ranking Statistic:** Must be signed and variance-calibrated.
- **Permutation Type:** Gene permutation (default in preranked tools) is anti-conservative for correlated genes. If an expression matrix is available and n >= 7 per group, prefer phenotype permutation or CAMERA for valid type-I error control.
- **Reporting:** Always log the ranking metric, weight exponent, permutation type, and gene-set version.

## 2. Execution Options

### Option A: Using the `gsea` CLI Wrapper (aipoch/medical-research-skills)
Use this for a streamlined pipeline with pre-configured gene sets (KEGG, Hallmarks, GO).

**Analysis Mode:**
```bash
Rscript scripts/main.R --input <ranked_genes.csv> --outdir ./GSEA_analysis --type KEGG --species human --seed 42
```

**Plot Mode:**
```bash
Rscript scripts/main.R --running_file ./GSEA_analysis/Table/gsea_running_scores.csv --enrich_file ./GSEA_analysis/Table/enrichGSEA.csv --plot_output ./GSEA_analysis/plot/gsea_plot.pdf --top_n 5
```

### Option B: Using R Packages Directly (GPTomics/bioSkills)
Use this for maximum control over permutation and gene-set sources.

**Preranked GSEA (clusterProfiler):**
```r
library(clusterProfiler)
# geneList is a named vector sorted by statistic
gseGO(geneList, OrgDb = org.Hs.eg.db, ont = "BP")
gseKEGG(geneList, organism = "hsa")
```

**Phenotype-Permutation GSEA (if matrix available):**
Use `fgsea` or `camera` from `limma` for correlation-aware testing.

## 3. Validation
- Check installed package versions (`packageVersion('clusterProfiler')`).
- Verify that the ranking statistic preserves sign and variance calibration.
- If using gene permutation, acknowledge the potential for false positives due to gene-gene correlation.
