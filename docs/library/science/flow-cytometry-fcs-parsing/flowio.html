# FlowIO

## Purpose
Use FlowIO for low-level reading and writing of FCS files. It is appropriate for:
- Reading FCS 2.0, 3.0, and 3.1 files.
- Inspecting HEADER, TEXT, ANALYSIS, and channel metadata.
- Retrieving event data as NumPy arrays.
- Writing list-mode, single-precision FCS 3.1 files.

It does **not** perform compensation, gating, or logicle transforms. Use FlowKit for those.

## Install
```bash
uv pip install "flowio==1.4.0"
```

## Critical Semantics

### TEXT Keys
`FlowData.text` keys are **lowercase** and **do not** include the leading `$`.
- Correct: `flow.text.get('date')`, `flow.text.get('cyt')`
- Incorrect: `flow.text.get('$DATE')`, `flow.text.get('$CYT')`

### Event Extraction
- `flow.as_array(preprocess=True)`: Applies gain, log, and time scaling from FCS metadata.
- `flow.as_array(preprocess=False)`: Returns decoded DATA values without scaling.
- Note: `as_array()` returns a 2D NumPy array `(events, channels)`. `flow.events` is a 1D flattened array.

### Channel Indices
- `flow.scatter_indices`, `flow.fluoro_indices`, `flow.time_index` use **zero-based** indices.
- `flow.channels` uses FCS parameter numbers (1-based).

## Operating Workflow

1. **Inspect Metadata First**
   Use `only_text=True` for large files to avoid loading event data into memory.
   ```python
   from flowio import FlowData
   flow = FlowData('sample.fcs', only_text=True)
   print(flow.text.get('date'))
   ```

2. **Handle Parsing Errors**
   By default, parsing is strict. If you encounter `DataOffsetDiscrepancyError` or `FCSParsingError` with known vendor files, you may relax checks, but validate the resulting data carefully.
   ```python
   from flowio import FlowData, DataOffsetDiscrepancyError
   
   try:
       flow = FlowData('sample.fcs')
   except DataOffsetDiscrepancyError:
       # Only use for known problematic files
       flow = FlowData('sample.fcs', ignore_offset_discrepancy=True)
   ```

3. **Extract Events**
   ```python
   events = flow.as_array(preprocess=True)
   # Verify shape matches declared counts
   assert events.shape == (flow.event_count, flow.channel_count)
   ```

4. **Multi-Dataset Files**
   If a file contains multiple datasets, use `read_multiple_data_sets`.
   ```python
   from flowio import read_multiple_data_sets
   datasets = read_multiple_data_sets('multi.fcs')
   flow = datasets[0]
   ```

5. **Writing FCS**
   `create_fcs` requires a file handle or path, flattened 1D event data (row-major), and PnN labels.
   ```python
   from flowio import create_fcs
   import numpy as np
   
   # Note: create_fcs expects flattened 1D data in row-major order (event, channel)
   # If you have a 2D array, flatten it: data.flatten(order='C')
   create_fcs('output.fcs', events.flatten(order='C'), flow.pnn_labels)
   ```

## Validation
Always reopen written files to verify event counts, channel labels, and representative values.
