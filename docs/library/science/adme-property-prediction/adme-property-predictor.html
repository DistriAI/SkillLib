# ADME Property Predictor

## When to Use
- Screening compound libraries for drug-like properties.
- Prioritizing lead compounds based on predicted PK.
- Identifying ADME liabilities.

**Do NOT use when:**
- Exact PK parameters needed for dosing (use experimental studies).
- Biologics or prodrugs.
- Clinical dosing decisions (experimental validation required).

## Workflow
1. Confirm user objective and inputs.
2. Validate request scope.
3. Run `python scripts/main.py` with validated inputs.
4. Return structured results separating assumptions and deliverables.

## Audit-Ready Commands
```bash
python -m py_compile scripts/main.py
python scripts/main.py --help
```

## Core Capabilities

### 1. Absorption (A) Prediction
Predict HIA, Caco-2, Solubility, LogS, Lipinski, and Veber rules.

```python
from scripts.adme_predictor import ADMEPredictor
predictor = ADMEPredictor()
absorption = predictor.predict_absorption(smiles="CC(=O)Oc1ccccc1C(=O)O", properties=["all"])
```

**Best Practices:**
- Consider HIA and solubility together.
- Use both rule-based and ML-based predictions for consensus.

### 2. Distribution (D) Prediction
Predict Vd, PPB, BBB, and fu.

```python
distribution = predictor.predict_distribution(smiles="CC(=O)Oc1ccccc1C(=O)O", properties=["vd", "ppb", "bbb"])
```

**Best Practices:**
- High PPB may require higher doses.
- Low Vd indicates plasma retention.
