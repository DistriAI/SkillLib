# COBRApy - Constraint-Based Reconstruction and Analysis

## When to use
Use for loading/building metabolic networks, optimizing steady-state fluxes, knockout screens, medium design, feasible-space sampling, and gap-filling. FBA is a constraint-based prediction; it does not infer kinetic rates.

## Setup and reproducibility
Targets **cobra 0.32.1**.

```bash
uv pip install "cobra==0.32.1"
```

Record model source/version/checksum, cobra and solver versions, objective, medium, bounds, tolerances, and random seeds. Start with `processes=1` for multiprocessing safety.

## Workflow

### 1. Load, inspect, and validate a model

```python
from cobra.io import load_model, read_sbml_model, write_sbml_model

# Bundled models: textbook, iJO1366, salmonella
model = load_model("textbook")
model.solver = "glpk"

# File I/O
# model = read_sbml_model("path/to/model.xml")
# write_sbml_model(model, "output.xml")

solution = model.optimize(raise_error=True)
assert solution.status == "optimal"
```

Note: `e_coli_core` is a remote BiGG identifier, not a bundled alias for `textbook`. Check chemical formulas/charges separately from solver feasibility.

### 2. Compare FBA, pFBA, and FVA

```python
from cobra.flux_analysis import pfba, geometric_fba, flux_variability_analysis

biomass_id = "Biomass_Ecoli_core"
parsimonious = pfba(model)
centered = geometric_fba(model, processes=1)

# Use string methods for loopless, not boolean (deprecated)
fva = flux_variability_analysis(
    model, reaction_list=["PFK", "FBA", "PGI"],
    fraction_of_optimum=0.9, processes=1,
)
loopless_fva = flux_variability_analysis(
    model, reaction_list=["PFK", "FBA", "PGI"],
    fraction_of_optimum=0.9, loopless="fastSNP", processes=1,
)
```

### 4. Flux Sampling

```python
from cobra.sampling import sample

# In 0.32.1, method="auto" defaults to CHRR if hopsy is installed, else OptGP.
# Choose explicitly to avoid environment-dependent changes.

```
