# Image Analysis for Spatial Transcriptomics

## 1. Strategic Segmentation Decision
Before processing, determine the available signal (nuclear stain, membrane stain, or transcript points) to choose the appropriate segmentation method.
- **Nuclear stain only (DAPI):** Use StarDist for round nuclei or Cellpose (nuclei mode). Note that whole-cell segmentation is inference.
- **Nuclear + Membrane stain:** Use Cellpose (2-channel) or Mesmer/DeepCell for true whole-cell segmentation.
- **Transcript points (Xenium/MERFISH):** Use Baysor or proseg for transcript-aware segmentation.
- **Visium/H&E:** Use Squidpy watershed or Cellpose for approximate boundaries.

**Warning:** Segmentation is a hypothesis, not an observation. Over/under-segmentation and spillover can fabricate false co-expression and cell-cell communication signals. Treat the resulting cell-by-gene matrix as provisional and run contamination QC.

## 2. Access Tissue Images
```python
import squidpy as sq
import scanpy as sc
import numpy as np
import matplotlib.pyplot as plt
from skimage import io, filters, segmentation

# For Visium data
library_id = list(adata.uns['spatial'].keys())[0]
img_dict = adata.uns['spatial'][library_id]['images']
hires = img_dict['hires']
lowres = img_dict['lowres']
scalef = adata.uns['spatial'][library_id]['scalefactors']

# Create ImageContainer
img = sq.im.ImageContainer(hires)
```

## 3. Segmentation
### Option A: Squidpy Watershed (Baseline)
```python
sq.im.segment(img, layer='image', method='watershed', channel=0, thresh=0.5)
seg_mask = img['segmented_watershed'].values
```

### Option B: Cellpose (Generalist)
```python
from cellpose import models
model = models.Cellpose(model_type='nuclei') # or 'cyto' for whole cell
image = img['image'].values[:, :, 0]
masks, flows, styles, diams = model.eval(image, diameter=30, channels=[0, 0])
img.add_img(masks, layer='cellpose_masks')
```

### Option C: Transcript-based (Baysor/proseg)
*Use CLI tools on the molecule table for imaging platforms like Xenium/MERFISH.*
