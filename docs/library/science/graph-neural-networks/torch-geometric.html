# PyTorch Geometric (PyG)

PyG is the standard library for Graph Neural Networks built on PyTorch.

## Installation

**Critical:** Always pin versions. `torch-cluster` and `torch-spline-conv` are deprecated and should not be installed.

```bash
# Example for PyTorch 2.14.1 / PyG 2.8.0.post1
uv pip install torch==2.14.1
uv pip install torch-geometric==2.8.0.post1

# Only install pyg-lib if neighbor sampling or spatial k-NN is required
# Check https://data.pyg.org/whl/ for the correct wheel for your platform
```

## Core Concepts

### Graph Data: `Data`

```python
from torch_geometric.data import Data

data = Data(
    x=node_features,      # [num_nodes, num_node_features]
    edge_index=edge_index, # [2, num_edges] — COO format
    y=labels
)
```

**Edge Index Format:** `edge_index` is a `[2, num_edges]` tensor. `edge_index[0]` are source nodes, `edge_index[1]` are target nodes. For undirected graphs, include both directions.

### Datasets

```python
from torch_geometric.datasets import Planetoid

dataset = Planetoid(root='./data/Cora', name='Cora', split='public')
data = dataset[0]
```

## Building GNNs

### Message Passing

GNNs follow: Transform -> Propagate -> Aggregate -> Update.

### Common Layers

**GCNConv:**
```python
from torch_geometric.nn import GCNConv
import torch.nn.functional as F

class GCN(torch.nn.Module):
    def __init__(self, num_features, num_classes):
        super().__init__()
        self.conv1 = GCNConv(num_features, 16)
        self.conv2 = GCNConv(16, num_classes)

    def forward(self, data):
        x, edge_index = data.x, data.edge_index
        x = self.conv1(x, edge_index)
        x = F.relu(x)
        x = F.dropout(x, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)
```

**GATConv:**
```python
from torch_geometric.nn import GATConv

class GAT(torch.nn.Module):
    def __init__(self, num_features, num_classes):
        super().__init__()
        self.conv1 = GATConv(num_features, 8, heads=8, dropout=0.6)
        self.conv2 = GATConv(8 * 8, num_classes, heads=1, concat=False, dropout=0.6)

    def forward(self, data):
        x, edge_index = data.x, data.edge_index
        x = F.dropout(x, p=0.6, training=self.training)
        x = F.elu(self.conv1(x, edge_index))
        x = F.dropout(x, p=0.6, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)
```

## Mini-Batch Processing

Use `DataLoader` for batching. It concatenates graphs and provides a `batch` vector mapping nodes to their source graph.

```python
from torch_geometric.loader import DataLoader

loader = DataLoader(dataset, batch_size=32, shuffle=True)
for batch in loader:
    # batch.batch maps nodes to graphs
    pass
```
