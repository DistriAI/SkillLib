# /math - Unified Math Capabilities

**One entry point for all computation and explanation.** Route to the right tool based on the request.

## 1. Direct Computation (Execution)
Use these scripts for immediate calculation and symbolic manipulation:

### SymPy (Symbolic Math)
```bash
uv run python "$CLAUDE_PROJECT_DIR/.claude/scripts/cc_math/sympy_compute.py" <command> <args>
```
Commands: `solve`, `integrate`, `diff`, `simplify`, `limit`, `series`, `dsolve`, `laplace`, `det`, `eigenvalues`, `factor`, `isprime`, etc.

### Z3 (Constraint Solving)
```bash
uv run python "$CLAUDE_PROJECT_DIR/.claude/scripts/cc_math/z3_solve.py" <command> <args>
```
Commands: `sat`, `prove`, `optimize`

### Pint (Units)
```bash
uv run python "$CLAUDE_PROJECT_DIR/.claude/scripts/cc_math/pint_compute.py" convert <value> <from_unit> <to_unit>
```

## 2. Specialized Sub-Skills (Guides & APIs)
For specific domains or formal verification, read the corresponding sub-skill:

| Skill | Description |
|-------|-------------|
| `lean-theorem-proving-guide` | LLM agent for formal theorem proving in Lean 4 |
| `linear-algebra-applications` | Apply linear algebra concepts to research computing |
| `numerical-methods-guide` | Apply numerical methods and scientific computing techniques |
| `oeis-api` | On-Line Encyclopedia of Integer Sequences API |
| `symbolic-computation-guide` | Computer algebra systems: SymPy, SageMath, and Mathematica |
| `topology-data-analysis` | Topological data analysis: persistent homology, Mapper, and TDA tools |

## Routing Logic
- "solve/calculate/compute" → SymPy script
- "is X always true?" → Z3 script
- "convert units" → Pint script
- "prove formally in Lean" → Read `lean-theorem-proving-guide`
- "topological data analysis" → Read `topology-data-analysis`
- "integer sequence lookup" → Read `oeis-api`
- "explain/what is" → Reference topic skills or sub-skills for context
