# Benchling Integration

## When to use

Use this skill for Benchling registry entities, sequence imports, inventory, ELN entries, workflow tasks, apps, event-driven integrations, and warehouse analytics.

**Important:** Examples target **benchling-sdk 1.25.0** and the **v2** API. Do not mechanically rewrite to V3 without confirming tenant availability, as V3 is in early access for many endpoints.

## Workflow

1. **Identify Tenant & Auth**: Determine the tenant URL and authentication method. Use OAuth for background apps, API Key for scripts.
2. **Resolve IDs**: Read schemas to resolve folder, registry, and status IDs. A valid Python model does not guarantee biological correctness.
3. **Read Before Write**: Fetch a small filtered page to verify permissions and data structure.
4. **Construct Payload**: Use typed SDK models. For imports, retain external IDs for reconciliation.
5. **Execute & Verify**: Perform the operation and read back the result. Check async status carefully (completed polling can still mean `FAILED`).

## Setup & Authentication

```bash
uv pip install "benchling-sdk==1.25.0"
```

### API Key (Scripts)
```python
import os
from benchling_sdk.benchling import Benchling
from benchling_sdk.auth.api_key_auth import ApiKeyAuth

benchling = Benchling(
    url=os.environ["BENCHLING_TENANT_URL"].rstrip("/"),
    auth_method=ApiKeyAuth(os.environ["BENCHLING_API_KEY"])
)
```

### OAuth Client Credentials (Apps)
```python
from benchling_sdk.auth.client_credentials_oauth2 import ClientCredentialsOAuth2

benchling = Benchling(
    url=tenant_url,
    auth_method=ClientCredentialsOAuth2(
        client_id=os.environ["BENCHLING_CLIENT_ID"],
        client_secret=os.environ["BENCHLING_CLIENT_SECRET"],
        token_url=f"{tenant_url}/oauth/token",
    ),
)
```

## Core Capabilities

### 1. Registry & Entities

**Create DNA Sequence:**
```python
from benchling_sdk.models import DnaSequenceCreate

# Note: Use either entity_registry_id OR naming_strategy, not both.
created = benchling.dna_sequences.create(
    DnaSequenceCreate(
        name="My Plasmid",
        bases="ATCGATCG",
        is_circular=True,
        folder_id="fld_abc123",
        # entity_registry_id="src_abc123", 
        # naming_strategy="NEW_IDS",
    )
)
```

**Update Entity:**
```python
from benchling_sdk.models import DnaSequenceUpdate

updated = benchling.dna_sequences.update(
    dna_sequence_id="seq_abc123", # Use dna_sequence_id for DNA updates
    dna_sequence=DnaSequenceUpdate(
        name="Updated Name"
    )
)
```

**Pagination & Counting:**
```python
# list() returns pages; iterate twice to reach objects.
for page in benchling.dna_sequences.list(page_size=10):
    for seq in page:
        print(seq.id, seq.name)
    break

# WARNING: estimated_count is a property, not a method, and may raise NotImplementedError.
# Do not rely on it for guaranteed counts.
```

### 2. Inventory Management

**Create Container:**
```python
from benchling_sdk.models import ContainerCreate

container = benchling.containers.create(
    ContainerCreate(
        name="Sample Tube 001",
        parent_storage_id="box_abc123",
    )
)
```

**Move vs Transfer:**
- **Move**: `ContainerUpdate(parent_storage_id=...)` changes location only.
- **Transfer**: A separate operation that changes contents and quantities.

### 3. ELN & Workflows

**Create Entry:**
```python
from benchling_sdk.models import EntryCreate

entry = benchling.entries.create(
    EntryCreate(
        name="Experiment 1",
        folder_id="fld_abc123",
    )
)
```

**Workflow Tasks:**
- Creation requires `workflow_task_group_id`.
- Updates use `workflow_task_id`.

### 4. Advanced Integrations

**Event-Driven (AWS EventBridge):**
Configure Benchling to publish events to AWS EventBridge for downstream automation. Ensure your Lambda functions or other consumers handle the event schema correctly.

**Data Warehouse:**
Use the Benchling Data Warehouse for SQL-based analytics. Connect via standard SQL clients using the warehouse credentials provided in your Benchling settings.

## Important SDK Conventions

- **Fields Serialization**: Import `fields` from `benchling_sdk.helpers.serialization_helpers`. Input format is `{"field_name": {"value": value}}`.
- **ID Naming**: Use `dna_sequence_id` for DNA updates, `workflow_task_id` for workflow updates.
- **Entry Methods**: `create_entry`, `get_entry_by_id`, `list_entries`, `update_entry`.
- **No `users/me`**: There is no documented v2 `users/me` route or SDK `users.get_me()`. Use specific resource lists to verify access.
