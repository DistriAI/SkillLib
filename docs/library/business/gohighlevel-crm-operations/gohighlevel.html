# GoHighLevel

GoHighLevel is an all-in-one marketing and sales platform for agencies and small businesses, covering CRM, email, SMS, funnels, and automation.

## Conflicts

- nowork-studio/notfair-plugin: Read `<plugin-root>/gohighlevel/WORKFLOW.md` completely and follow it as the active workflow. Resolve relative references from that file against `<plugin-root>/gohighlevel/`. If the file cannot be read, stop and report the packaging error; never substitute a similarly named skill from another plugin.
- LeoYeAI/openclaw-master-skills: Requires network access and a valid Membrane account (Free tier supported). Interact with GoHighLevel data through the Membrane integration. Official docs: https://developers.gohighlevel.com/

## Steps

1. Determine which integration is available in the current environment: NotFair MCP or Membrane.
2. If NotFair MCP is available, follow the nowork-studio/notfair-plugin step: read the canonical WORKFLOW.md and follow it. Do not substitute another skill.
3. If Membrane is available, follow the LeoYeAI/openclaw-master-skills step: use the Membrane account to manage GoHighLevel entities such as Contact, Location, Opportunity, Pipeline, Campaign, Form, Invoice, Product, Calendar, and Workflow.
4. If neither integration is available, report that no supported GoHighLevel connector is configured.

## Notes

- Do not mix steps from the two integrations in a single operation.
- Respect the packaging error rule from the NotFair copy when the canonical file is missing.
