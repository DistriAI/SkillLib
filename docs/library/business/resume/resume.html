# Resume Skill

This skill handles two distinct tasks based on user intent:

## Task 1: Resume a Paused Experiment

Use when the user wants to continue a paused or context-limited automated experiment.

### Steps
1. **List experiments if needed**: If no experiment is specified, run `python {skill_path}/scripts/setup_experiment.py --list` to show status for each experiment. Let the user pick.
2. **Load full context**:
   - Checkout the experiment branch: `git checkout autoresearch/{domain}/{name}`
   - Read config: `cat .autoresearch/{domain}/{name}/config.cfg`
   - Read strategy: `cat .autoresearch/{domain}/{name}/program.md`
   - Read full results history: `cat .autoresearch/{domain}/{name}/results.tsv`
   - Read recent git log: `git log --oneline -20`
3. **Report current state**: Summarize the experiment's target, metric, total experiments, best result, and recent patterns.
4. **Ask next action**: Offer options to run a single iteration, start an autonomous loop, or just review results.

## Task 2: Write a Professional Resume/CV

Use when the user asks to write, rewrite, or tailor a resume or CV.

### Steps
1. **Gather inputs**: Infer any missing details (target role, experience, skills, education) from the user's brief. Label any inferred details as *(assumed — confirm)*.
2. **Quantify achievements**: Lead with the user's real numbers. Only add defensible, conservative estimates if a metric is genuinely absent, and mark them clearly.
3. **Structure the resume**:
   - **Header**: Full name, target title, contact info.
   - **Summary**: 2–3 lines highlighting strongest proof and target role.
   - **Experience**: Reverse-chronological, with 3–5 accomplishment bullets per recent role (action verb → what you did → quantified impact).
   - **Skills**: Grouped, keyword-rich, mirroring the job description.
   - **Education**: Degree, institution, year, certifications.
4. **Tailor to the job**: Ensure keywords from the target job description appear naturally in skills and bullets.
5. **Quality checks**:
   - Every bullet is an achievement with a metric, not a duty.
   - Single-column, ATS-friendly format (no tables, text-boxes, or graphics).
   - Length fits seniority (1 page for <10 years experience, 2 max).
6. **Output**: Provide only the finished resume and a short tailoring note. No preamble or meta-commentary.
