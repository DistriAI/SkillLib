# Company Intelligence

## Method Selection
Determine if the user has access to the Gooseworks API or if a pure research approach is preferred.

### Method A: API-Based Retrieval (Gooseworks)
1. **Setup**: Read credentials from `~/.gooseworks/credentials.json`. If missing, instruct user to run `npx gooseworks login`.
2. **Overview**: Call `brand-dev` API via `POST /v1/proxy/orthogonal/run` with the company domain.
3. **Leadership**: Call `fiber` API (`/v1/people-search`) with company name and job titles.
4. **Products**: Call `scrapegraph` API (`/v1/smartscraper`) on the company's pricing/product pages.
5. **Growth**: Call `fiber` API (`/v1/company-search`) for employee count and growth data.

### Method B: Analytical Research (Web Search)
1. **Entry Point**: Identify if the target is a single company, industry, or competitor set.
2. **Lenses**: Apply seven analytical lenses:
   - Financial Landscape
   - Market Offer & Business Model
   - Product Portfolio
   - Competitive Dynamics
   - Rising Trends
   - PM Implications
   - Strategic Signals (patents, hiring, leadership)
3. **Output**: Structure findings into an 11-section report. If a competitor set is provided, add a Section 12 for cross-company comparison.

## Conflicts
- **gooseworks-ai/goose-skills** requires a specific API key and uses curl commands to fetch data.
- **deanpeters/Product-Manager-Skills** relies on general web search and analytical reasoning without specific API dependencies.
