# Performance Analysis

This skill covers two distinct domains. Determine the context from the user's request.

## Option A: Power Platform Process Intelligence
Use when investigating slow activities, waiting, handoff duration, or bottlenecks in a Power Platform process.

1. **Slow activities by mean:** Call `get_bottleneck_analysis_v2` with the selected scope (S) and filter (F). Do not pass `attributeName`, `metrics`, `aggregation`, or `limit`.
2. **Cumulative activity duration:** If requested, call `get_attribute_statistics` with the exact Activity import attribute. Use `metricToSortBy: "TotalDuration"`.
3. **Drilldown:** For unresolved evidence, use `get_edges_with_metrics_v2` for handoffs or `get_cases_with_metrics_v2` for waiting time.
4. **Reporting:** Report native edge Duration mean. Do not derive population totals from top-five averages.

## Option B: Marketing Channel Performance
Use when reviewing weekly ad performance, ROAS, or creative testing results.

1. **Setup:** Run `marketing-guide` skill to connect and read the brand brain.
2. **Read Context:** Load the last run records and the current campaign plan.
3. **Data Collection:** Read performance views from connected ad platforms (Meta, TikTok, etc.) and the brand's internal metrics.
4. **Analysis:** Compare current week's performance against the baseline and previous weeks. Identify winning/losing creatives and channels.
5. **Reporting:** Generate the Monday report saved to `reports/performance/<YYYY-MM-DD>.md`. Include learnings and recommendations for the next cycle.

## Conflicts
- **microsoft/power-platform-skills**: Focuses on process activity duration and handoff bottlenecks using specific MCP tools.
- **gooseworks-ai/goose-skills**: Focuses on marketing channel revenue, ROAS, and creative testing using marketing connectors and brand brain.
